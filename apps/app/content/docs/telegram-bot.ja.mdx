QRdxボットは、リンクや任意のテキストをTelegram内でQRコードに変換します。無料で、QRdxアカウントは必要ありません。

<IfAvailable feature="telegramBot">
始めるには、[Telegram連携ページ](/integrations/telegram)で **Telegramで開く** をクリックし、ボットのチャットで **Start** をタップします。
</IfAvailable>

## プライベートチャット [#private-chat]

ボットにリンクまたはテキストを送ると、QRコードと4つのボタンが返信されます。

- **PNGをダウンロード** は、保存や共有ができる状態で画像を開きます。
- **SVGをダウンロード** は、印刷やデザインツール向けのベクター版を開きます。
- **エディタで開く** は、同じデザインのQRdxエディタを開きます。ウェブアドレスの場合は、アドレスも一緒に渡されます。それ以外のテキストは渡されないため、エディタに自分で貼り付けてください。
- **スタイル** は、チャット内でコードの見た目を変更します（下記参照）。

コードには、送信した内容がそのまま入ります。改行も含まれます。`/help`（または `/start`）を送ると、ボットの使い方が表示されます。テキストが長すぎて1つのQRコードに収まらない場合は、ボットがその旨を知らせます。全文を載せたページへのリンクにすると、コードが小さくなり、スキャンしやすくなります。

## コードのスタイルを変更する [#style-your-code]

コードの下にある **スタイル** をタップすると、ほかのボタンが **見た目**、**色**、**フレーム**、**ロゴ** の4つのボタンに切り替わります。それぞれ選択肢が開き、現在のコードで使われているものには ✓ が付きます。選択肢をタップすると、ボットが画像を描き直します。**戻る** で4つのグループに戻り、**完了** でダウンロードボタンが元に戻ります。変更は、そのときのコードの状態に重ねて適用されます。グループでは、コードをリクエストした本人だけがスタイルを変更できます。ほかの人がタップした場合は、短いメッセージが表示されます。

見た目は、エディタ内蔵のデザインのうち、小さいサイズでも読み取りやすいものです。**シンプル** を選ぶと、白地に黒に戻ります。色を選ぶと、コード全体がその色になり、背景は白になります。フレームには「Scan me」というラベルが付き、ロゴはエディタのクイックアイコンです。

リンクやテキストの後にオプションを付けると、コードを作成するときにスタイルを指定することもできます。オプション名は [QRdx CLI](/docs/developers/cli) と同じです。この方法は、プライベートチャット、グループでの `/qr` の後、そしてインラインモードで使えます。インラインモードでは、まだ変更するメッセージがないため、スタイルを指定できる唯一の方法です。

```text
qrdx.dev --look modern --fg 0051ff --frame banner-bottom --frame-text "Scan me"
```

最初のオプションより前の部分が内容になります。見た目が最初に適用され、その上にほかのオプションが適用されるため、`--look royal --fg 0051ff` とすると、Royalの形のまま青色になります。スマートフォンが `--` を長いダッシュに変換しても、そのまま使えます。誤ったオプションや値を指定すると、使用できる値の一覧が返信されます。

| オプション | 変更する内容 | 値 |
| --- | --- | --- |
| `--look` | エディタのプリセットから選ぶデザイン全体 | `plain`, `classic`, `modern`, `royal`, `folio`, `caffeine`, `retro`, `bordeaux`, `blossom` |
| `--fg`（または `--color`） | ドットの色。コーナーアイも別に指定しない限り同じ色になります | `0051ff` のような16進数カラー、または `black`, `blue`, `green`, `red`, `purple`, `orange` |
| `--bg` | 背景 | `--fg` と同じ |
| `--eye-color` | 3つのコーナーアイ | `--fg` と同じ |
| `--dot-color` | コーナーアイの中心 | `--fg` と同じ |
| `--body` | ドットの形 | エディタの{facts.bodyPatterns}種類のドット形状のいずれか（`rounded`、`circle`、`classy` など） |
| `--eye` | コーナーアイの形 | {facts.eyeShapes}種類のアイ形状のいずれか（`square`、`rounded`、`gear` など） |
| `--dot` | アイ中心の形 | {facts.eyeCentres}種類の中心形状のいずれか（`square`、`rounded`、`circle` など） |
| `--frame` | コードを囲むフレーム | `none`、または{facts.frameStyles}種類の内蔵フレームのいずれか（`banner-bottom`、`banner-top`、`speech-bubble`、`polaroid` など） |
| `--frame-text` | フレームのラベル（24文字まで） | 任意のテキスト。スペースを含む場合は引用符で囲みます。`--frame` がない場合は、コードの下のバナーに表示されます |
| `--template` | テンプレートとして描くフレーム | `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `Halloween` |
| `--logo` | 中央のアイコン | `link`, `wifi`, `location`, `phone`, `email`, `whatsapp`, `instagram`, `file`, `calendar`, `none` |

スタイルを適用したコードをボットが送信する前に、QRdxはエディタと同じスキャンスコアで確認します。デザインがスマートフォンで読み取りにくい場合は、QRdxが色を濃くする、形をシンプルにする、誤り訂正を強めるなどの調整を行い、キャプションでお知らせします。それでも足りない場合（多くは内容が長いとき）は、白地に黒のコードがメモ付きで届きます。

**エディタで開く** を選ぶと、色、形、フレーム、枠など、同じデザインでエディタが開きます。ロゴアイコンはリンクに含まれないため、エディタでもう一度選んでください。

## 任意のチャットでのインラインモード [#inline-mode-in-any-chat]

ボットをチャットに追加しなくても、任意のチャットにコードを送れます。メッセージ欄に `@`、ボットのユーザー名、スペース、リンクまたはテキストの順に入力します。しばらくすると、入力欄の上にコードが表示されます。タップすると、同じ3つのボタン付きで送信されます。送信先の相手がボットを使っている必要はありません。

## グループ [#groups]

ボットをグループに追加し、`/qr` の後にリンクまたはテキストを付けて送信します（例：`/qr https://example.com/menu`）。ボットは、あなたのメッセージへの返信としてコードを送ります。

グループ内のボットは、デフォルトでプライバシーモードがオンになっています。このボットもオンのままなので、グループの会話は見えません。Telegramがボットに渡すのは、ボット宛てのコマンドと、ボット自身のメッセージへの返信だけです。ボットが応答するのは `/qr`、`/start`、`/help` のみで、それ以外はすべて無視します。グループに複数のボットがいる場合や、`/qr` だけではボットが応答しない場合は、コマンドにユーザー名を付けてください。`/qr@` の後にユーザー名、続けてリンクまたはテキストを入力します。

## プライバシー [#privacy]

QRdxは、作成したコードを保存しません。ボットは、返信するためだけに各メッセージを読み取ります。

内容は画像リンクに含まれます。Telegramは、あなたのテキストと選択したデザインを含むQRdxのリンクから、各コードの画像を読み込みます。コードのスタイルを変更するときは、そのリンクから両方を読み戻すため、QRdxはスタイル変更のためにコードを保存しません。ほかのリンクと同様に、このリンクもログやキャッシュに残る可能性があります。パスワードなどの機密情報でコードを作成しないでください。Telegramは、ほかのメッセージと同様に、チャット内のメッセージを保持します。

短時間に大量のコードを作成すると、ボットから次のコードまで1分待つよう求められます。スタイル変更は1回ごとに1つのコードとして数えられます。多くの人が同時に使っている場合は、混雑しているというメッセージが表示されることがあります。1分後にもう一度お試しください。

## ボットを削除する [#remove-the-bot]

プライベートチャットでは、ボットのプロフィールを開いてブロックするか、チャットを削除します。グループでは、管理者がメンバー一覧からボットを削除します。

ボットがすでに送信したコードは、チャットに残ります。ボタンはQRdxに直接リンクしているため、そのまま使えます。

## セルフホスティング [#self-hosting]

セルフホストしたQRdxサーバーでは、独自のボットを実行できます。[@BotFather](https://t.me/BotFather) でボットを作成し、サーバーに `TELEGRAM_BOT_TOKEN`、`TELEGRAM_WEBHOOK_SECRET`、`TELEGRAM_BOT_USERNAME` を設定して、セットアップスクリプトを実行します。手順は [`plugins/telegram/README.md`](https://github.com/qrdxinc/qrdx/blob/main/plugins/telegram/README.md) をご覧ください。3つの変数がすべて設定されるまでは、ボットのルートは404を返し、サイトにもボットは表示されません。
