## URL di base e autenticazione [#base-url-and-authentication]

La REST API si trova all'indirizzo `https://api.qrdx.dev/v1`. Le stesse route rispondono anche su `https://qrdx.dev/api/v1`.

Le richieste si autenticano con una [chiave API](/docs/developers/api-keys) nell'header `Authorization: Bearer`. Le app che agiscono per conto di altri utenti QRdx inviano invece un [token di accesso OAuth 2.0](/docs/developers/rest-api#get-an-access-token). La [guida rapida](/docs/developers/quickstart#create-an-api-key) crea una chiave ed esegue una prima richiesta.
