Totals, a daily series and the top countries, cities, devices, systems, browsers and referrers. `sources` splits the scans into QR scans and NFC taps (visits through the code's `nfcLink`), and each listed scan has its `source`. The range is clamped to how far back the plan's analytics reach: 1 year on Free, the whole history on Pro and Business (`retentionDays` is then null). With `limit` above 0 the response also lists individual scans, newest first: pass the response's `nextBefore` as `before` for the next page.

On Pro and Business, `preciseLocations` lists the locations scanners chose to share (rounded to about 100 m) for codes that ask for them, and each scan has `latitude`, `longitude`, `locationAccuracyM` and `locationSource`. On Free, `preciseLocations` is null and those fields are null. More in [Precise location and geofencing](https://qrdx.dev/docs/precise-location).

**Scope:** `codes:read` or `codes:write`, for API keys and OAuth tokens alike.
