## 基础 URL 与身份验证 [#base-url-and-authentication]

REST API 位于 `https://api.qrdx.dev/v1`。相同的路由也可通过 `https://qrdx.dev/api/v1` 访问。

请求通过 `Authorization: Bearer` 请求头中的 [API 密钥](/docs/developers/api-keys)进行身份验证。代表其他 QRdx 用户操作的应用则改为在此处发送 [OAuth 2.0 访问令牌](/docs/developers/rest-api#get-an-access-token)。[快速入门](/docs/developers/quickstart#create-an-api-key)会创建一个密钥并发出第一个请求。
