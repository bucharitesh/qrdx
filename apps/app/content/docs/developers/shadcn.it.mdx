QRdx pubblica una registry di [shadcn/ui](https://ui.shadcn.com) con componenti QR code basati sulla libreria [`qrdx`](https://www.npmjs.com/package/qrdx). La CLI di shadcn copia il sorgente nel tuo progetto, quindi il codice è tuo e puoi modificarlo.

<NpmStatus package="qrdx" />

<PackageManagerTabs command="npx shadcn@latest add https://qrdx.dev/r/qr-code.json" />

Ogni componente ha la propria pagina con anteprima dal vivo, sorgente, passaggi di installazione, esempi e riferimento API.

[Provalo nel Playground](/playground?open=code&lang=shadcn): personalizza lo stile di un codice e poi copialo per il componente QR Code della registry.

## Cosa viene installato [#what-gets-installed]

Ogni componente è un singolo file in `components/`. La CLI installa anche `qrdx` (più `lucide-react` per le icone usate da alcuni componenti) e aggiunge i componenti shadcn/ui su cui si basa, come `button`, `card`, `dialog`, `dropdown-menu` o `input`.

L'indice completo si trova in [`https://qrdx.dev/r/registry.json`](https://qrdx.dev/r/registry.json).

## Usare il namespace della registry [#using-the-registry-namespace]

Per installare con un nome breve, aggiungi la registry al tuo `components.json`:

```json
{
  "registries": {
    "@qrdx": "https://qrdx.dev/r/{name}.json"
  }
}
```

Poi aggiungi uno o più componenti per nome:

<PackageManagerTabs command="npx shadcn@latest add @qrdx/qr-code @qrdx/qr-code-download @qrdx/qr-code-share-dialog" />

## Stile [#styling]

I componenti usano classi Tailwind con i token standard del tema shadcn/ui (`bg-card`, `border`, `text-muted-foreground`, `ring-ring`) e i tuoi Button, Card, Dialog e Input, quindi seguono il tuo tema e la modalità scura. I QR code mantengono per impostazione predefinita uno sfondo chiaro, perché i moduli scuri su un riquadro chiaro vengono letti da qualsiasi lettore.

I download in PDF richiedono il pacchetto opzionale `jspdf` (`npm install jspdf`).
