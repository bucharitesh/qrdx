## Base URL और ऑथेंटिकेशन [#base-url-and-authentication]

REST API `https://api.qrdx.dev/v1` पर चलता है। यही routes `https://qrdx.dev/api/v1` पर भी जवाब देते हैं।

रिक्वेस्ट `Authorization: Bearer` हेडर में [API key](/docs/developers/api-keys) से ऑथेंटिकेट होते हैं। जो app दूसरे QRdx यूज़र्स की ओर से काम करते हैं, वे वहाँ [OAuth 2.0 access token](/docs/developers/rest-api#get-an-access-token) भेजते हैं। [क्विकस्टार्ट](/docs/developers/quickstart#create-an-api-key) में key बनाई जाती है और पहला रिक्वेस्ट किया जाता है।
