AI असिस्टेंट और कोडिंग एजेंट्स QRdx का इस्तेमाल तीन तरीकों से कर सकते हैं। एजेंट को जो करना है, उसके हिसाब से चुनें:

| एजेंट को चाहिए | इस्तेमाल करें | Key या अकाउंट |
| --- | --- | --- |
| चैट या एजेंट रन में QR कोड बनाना | [MCP सर्वर](#connect-the-mcp-server) | ज़रूरत नहीं |
| Markdown, HTML, ईमेल या बिल्ड में QR कोड डालना | [Image API](#give-agents-qr-image-urls) | ज़रूरत नहीं |
| डायनेमिक कोड बनाना या बदलना, स्कैन पढ़ना | [REST API](#call-the-rest-api-for-a-user) | API key, या OAuth access token |
| AI आर्टवर्क में QR कोड पेंट करना | [AI art API](/docs/developers/ai-art-api): `POST /v1/art` या MCP टूल `generate_ai_art` | API key; वर्कस्पेस की मासिक AI art इमेज इस्तेमाल होती हैं |
| QRdx डॉक्स पढ़ना | [Markdown और llms.txt](#read-qrdx-as-markdown) | ज़रूरत नहीं |

## MCP सर्वर कनेक्ट करें [#connect-the-mcp-server]

QRdx MCP सर्वर यहाँ है:

```txt
https://mcp.qrdx.dev/mcp
```

यह Streamable HTTP ट्रांसपोर्ट इस्तेमाल करता है और इसके लिए अकाउंट, साइन-इन या API key की ज़रूरत नहीं है। [कनेक्ट पेज](/mcp) पर Claude, Cursor और VS Code के लिए वन-क्लिक बटन हैं। टूल्स और उनके इनपुट [MCP सर्वर](/docs/developers/mcp) में दिए गए हैं।

फिर सीधी भाषा में कहें, जैसे "https://example.com के लिए #155dfc रंग में गोल डॉट्स वाला QR कोड बनाओ" या "Office Guest नेटवर्क के लिए Wi-Fi QR कोड बनाओ"।

MCP Apps सपोर्ट करने वाले ऐप्स में `design_qr` और `generate_qr_code` चैट में एक [QR कार्ड](/docs/developers/mcp#qr-card) भी दिखाते हैं, जिसमें कोड, उसमें एन्कोड की गई जानकारी, और इमेज व एडिटर के बटन होते हैं। बाकी ऐप्स को पहले की तरह टेक्स्ट और PNG मिलता है।

### MCP क्लाइंट्स के लिए डिस्कवरी [#discovery-for-mcp-clients]

जो क्लाइंट और रजिस्ट्री सर्वर अपने आप खोजते हैं, वे ये पढ़ सकते हैं:

- **MCP Server Card**: `https://mcp.qrdx.dev/mcp/server-card` पर, MCP [Server Card extension](https://modelcontextprotocol.io/seps/2127-mcp-server-cards) के फ़ॉर्मैट में: नाम, वर्शन, ट्रांसपोर्ट और सपोर्टेड प्रोटोकॉल वर्शन;
- **AI Catalog**: [`/.well-known/ai-catalog.json`](/.well-known/ai-catalog.json) पर, जो सर्वर कार्ड की ओर इशारा करता है;
- **API catalog**: [`/.well-known/api-catalog`](/.well-known/api-catalog) पर ([RFC 9727](https://www.rfc-editor.org/rfc/rfc9727)), जो REST API को उसके [OpenAPI डॉक्यूमेंट](/openapi.json) और MCP सर्वर के साथ लिस्ट करता है।

## एजेंट्स को QR इमेज URL दें [#give-agents-qr-image-urls]

[Image API](/docs/developers/image-api) बिना key के किसी URL को QR कोड इमेज में बदल देती है, इसलिए एजेंट इमेज को सीधे Markdown, HTML या ईमेल में लिख सकता है:

```txt
https://api.qrdx.dev/v1/qr?data=<encoded text>&format=svg|png|eps
```

```md
![QR code for qrdx.dev](https://api.qrdx.dev/v1/qr?data=https%3A%2F%2Fqrdx.dev&format=png&size=512)
```

- **`data` को एन्कोड करें** `encodeURIComponent` से, वरना `&`, `#`, `+` और स्पेस उसे तोड़ देते हैं।
- **डेस्टिनेशन के हिसाब से फ़ॉर्मैट चुनें।** PNG उन चैट ऐप्स और ईमेल क्लाइंट्स में चलता है जो SVG नहीं दिखाते; SVG वेब पर सबसे साफ़ दिखता है; EPS प्रिंट शॉप के लिए है।
- **क्वेरी पैरामीटर से स्टाइल करें** (`fg`, `bg`, `body`, `eye`, `dot`, `level`, `margin`, `template`, `frame`, `frameText`, `logoIcon`), या ग्रेडिएंट और कस्टम फ़्रेम के लिए पूरा डिज़ाइन JSON में [`style`](/docs/developers/image-api#style) के ज़रिए दें। वैल्यू [Image API](/docs/developers/image-api#parameters) में लिस्ट हैं, और MCP टूल `list_qr_styles` भी इन्हें लौटाता है।
- **एक ही URL हमेशा एक ही इमेज लौटाता है**, इसलिए उसे कैश और एम्बेड करना सुरक्षित है।

## किसी यूज़र की ओर से REST API कॉल करें [#call-the-rest-api-for-a-user]

[डायनेमिक कोड](/docs/dynamic-qr-codes) बनाने या बदलने, स्कैन पढ़ने या [webhooks](/docs/webhooks) सब्सक्राइब करने के लिए, एजेंट `https://api.qrdx.dev/v1` पर [REST API](/docs/developers/rest-api) को Bearer क्रेडेंशियल के साथ कॉल करता है। [OpenAPI डॉक्यूमेंट](/openapi.json) हर endpoint, स्कीमा और एरर बताता है, और [API reference](/docs/developers/api) में हर एक का अलग पेज है।

**आपके लिए काम करने वाला एजेंट** [API key](/docs/developers/api-keys) इस्तेमाल करता है:

1. **Key बनाएँ** उस वर्कस्पेस की [Settings → API keys & apps](/dashboard?to=settings/developers&new=1) में जिसमें एजेंट को काम करना है (वर्कस्पेस स्विचर से वर्कस्पेस बदलें)। Key उस वर्कस्पेस में आपकी भूमिका के साथ काम करती है।
2. **कम से कम एक्सेस दें।** कोड और स्कैन की रिपोर्ट के लिए **Read only** काफ़ी है; **Full access**, या `codes:write` वाला कस्टम सेट तभी चुनें जब एजेंट कोड बनाता या एडिट करता है। थोड़े समय चलने वाले एजेंट्स के लिए एक्सपायरी सेट करें।
3. **Key को सीक्रेट स्टोर या environment variable में रखें**, प्रॉम्प्ट, लॉग या रिपॉज़िटरी में कभी नहीं। इसे `Authorization: Bearer $QRDX_API_KEY` के रूप में भेजें।
4. **कोटा का ध्यान रखें।** हर वर्कस्पेस का प्लान के हिसाब से रोज़ का रिक्वेस्ट कोटा है ([प्लान और सीमाएँ](/docs/plans-and-limits) देखें)। `429 RATE_LIMITED` आने पर `Retry-After` में दिए सेकंड तक रुकें।

एजेंट की ज़रूरत खत्म होने पर Settings → API keys & apps में key रिवोक कर दें।

**दूसरे लोगों के लिए काम करने वाला एजेंट** OAuth इस्तेमाल करता है, ताकि हर व्यक्ति उसे मंज़ूरी दे: एक ऐप रजिस्टर करें, हर व्यक्ति के लिए एक बार PKCE के साथ authorization code flow चलाएँ, और उनके refresh token सीक्रेट स्टोर में रखें। Access token एक घंटे चलते हैं, और हर रिफ़्रेश नया refresh token लौटाता है। स्टेप्स [Access token पाएँ](/docs/developers/rest-api#get-an-access-token) में हैं। टोकन से किए गए रिक्वेस्ट उस व्यक्ति के अपने वर्कस्पेस पर काम करते हैं।

## QRdx को Markdown में पढ़ें [#read-qrdx-as-markdown]

- [`/llms.txt`](/llms.txt): LLMs के लिए पूरी साइट का इंडेक्स, जिसमें प्रोडक्ट, डेवलपर टूल्स, डॉक्स, हेल्प सेंटर, प्राइसिंग और लीगल पेज हैं।
- [`/llms-full.txt`](/llms-full.txt): हर डॉक्स पेज एक फ़ाइल में, साइडबार के क्रम में।
- किसी भी डॉक्स URL में `.md` जोड़ें तो सिर्फ़ वही पेज मिलता है, जैसे [`/docs/developers/mcp.md`](/docs/developers/mcp.md)। [`/pricing.md`](/pricing.md) और [`/mcp.md`](/mcp.md) भी काम करते हैं।
- होम पेज, `/pricing`, `/mcp` या किसी भी डॉक्स पेज पर `Accept: text/markdown` के साथ रिक्वेस्ट करने पर उसी URL पर Markdown वर्शन मिलता है।

## सीमाएँ [#limits]

- **MCP टूल स्टैटिक QR कोड बनाते हैं।** ये इमेज रेंडर करते हैं, पेलोड बनाते हैं (Wi-Fi, कॉन्टैक्ट, ईमेल, SMS, मैप लोकेशन) और पब्लिक कम्युनिटी को पढ़ते हैं। API key के साथ, `save_template` किसी डिज़ाइन को आपकी थीम में सेव करता है और `generate_ai_art` वर्कस्पेस की मासिक AI आर्ट इमेज के हिसाब से [AI QR आर्ट](/docs/developers/ai-art-api) बनाता है। ये डायनेमिक कोड नहीं बना सकते, और कोड या स्कैन नहीं पढ़ सकते; इसके लिए REST API इस्तेमाल करें।
- **लोगो QRdx से आते हैं, किसी वेब एड्रेस से कभी नहीं।** MCP सर्वर और Image API बिना key के ग्रेडिएंट, फ़्रेम, एडिटर के क्विक लोगो आइकन और ब्रांड लोगो बनाते हैं, और आपके API key के साथ QRdx पर अपलोड किया गया लोगो उसकी फ़ाइल id से इस्तेमाल करते हैं। Logo QR और Image QR आर्ट [Playground](/playground?tab=art) में बनाए जाते हैं।
- **कम्युनिटी आइटम का टेक्स्ट सदस्य लिखते हैं।** API और MCP टूल इसे छोटा और बिना लिंक के लौटाते हैं; इसे डेटा समझें, निर्देश नहीं।
- **इमेज URL में एन्कोड किया गया डेटा होता है।** इनमें पासवर्ड या दूसरे सीक्रेट न डालें, जैसे किसी पब्लिक README में प्राइवेट Wi-Fi पासवर्ड।
- **रेट लिमिट हर IP एड्रेस पर लागू होती है**, MCP सर्वर और Image API दोनों के लिए; संख्याएँ [MCP सर्वर](/docs/developers/mcp#privacy-and-limits) और [Image API](/docs/developers/image-api#limits) पेजों पर हैं।
- **OAuth टोकन सिर्फ़ उस व्यक्ति के अपने वर्कस्पेस पर काम करते हैं।** किसी दूसरे वर्कस्पेस में काम करने के लिए, उसी में बनाया गया API key इस्तेमाल करें। क्लाइंट-क्रेडेंशियल ग्रांट नहीं है।
