## Base URL and authentication

The REST API lives at `https://api.qrdx.dev/v1`. The same routes also answer at `https://qrdx.dev/api/v1`.

Requests authenticate with an [API key](/docs/developers/api-keys) in the `Authorization: Bearer` header. Apps that act for other QRdx users send an [OAuth 2.0 access token](/docs/developers/rest-api#get-an-access-token) there instead. The [quickstart](/docs/developers/quickstart#create-an-api-key) creates a key and makes a first request.
