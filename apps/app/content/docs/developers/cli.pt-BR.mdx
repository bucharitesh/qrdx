O `@qrdx/cli` gera os mesmos QR codes do Playground e da [biblioteca `qrdx`](/docs/getting-started) pela linha de comando. Ele nunca faz perguntas em scripts e no CI, e, quando você roda `qrdx generate` sem argumentos em um terminal, ele pergunta o conteúdo e as opções passo a passo.

<NpmStatus package="@qrdx/cli" />

```bash
npx @qrdx/cli generate "https://example.com" -o qr.svg
```

Instale globalmente para ter o comando `qrdx`:

```bash
npm install -g @qrdx/cli
qrdx generate "https://example.com" -o qr.png --size 1024
```

Ele exige Node.js 22 ou superior. A saída em PNG e WebP usa o [sharp](https://sharp.pixelplumbing.com), uma dependência opcional que o npm instala onde a sua plataforma oferece suporte; SVG e EPS funcionam sem ele. O pacote `qrdx` do npm é a biblioteca React: a CLI está apenas em `@qrdx/cli`.

## Formatos de saída [#output-formats]

A extensão do arquivo define o formato, ou use `--format` quando o nome do arquivo não tiver extensão.

| Formato | Use para | `--size` significa |
| --- | --- | --- |
| `.svg` | Páginas web, ferramentas de design, ampliar sem perda | Largura em pixels (padrão 512) |
| `.png` | Documentos, slides, qualquer lugar que precise de uma imagem | Largura em pixels |
| `.webp` | Sites: os pixels do PNG, sem perda, em um arquivo menor | Largura em pixels |
| `.eps` | Gráficas, Illustrator, InDesign | Largura em pontos (72 por polegada, então `144` são 2 polegadas) |

Os arquivos EPS são PostScript vetorial. Logos em PNG e JPEG são incorporados como estão; outros formatos de logo são convertidos com o sharp quando ele está instalado e, caso contrário, são omitidos com um aviso.

## Opções [#options]

| Flag | Padrão | Descrição |
| --- | --- | --- |
| `-o`, `--output` | `qr.svg` | Arquivo de saída |
| `--format` | pela extensão | `svg`, `png`, `webp` ou `eps` |
| `--size` | `512` | Tamanho da saída (veja acima) |
| `-l`, `--level` | `Q` | Correção de erros: `L`, `M`, `Q` ou `H` |
| `--body` | `square` | [Padrão](/docs/features/patterns) dos módulos de dados |
| `--eye` | `square` | Padrão do olho dos cantos |
| `--dot` | `square` | Padrão do ponto do olho dos cantos |
| `--fg`, `--bg` | `#000000`, `#ffffff` | Primeiro plano e fundo: uma cor hexadecimal ou um gradiente em JSON |
| `--eye-color`, `--dot-color` | `--fg` | Cores do olho e do ponto do olho dos cantos |
| `--logo` | | URL da imagem do logo central (use com `--level H`) |
| `--margin` | `0` | Zona de silêncio, em módulos |
| `--template` | | `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox` ou `Halloween` |
| `--frame` | | [Moldura](/docs/features/frames) com chamada para ação: qualquer uma das {facts.frameStyles} molduras integradas, como `banner-bottom`, `rounded-border`, `circle`, `sticker` ou `phone` (veja [todas elas](/docs/styles#frames)) |
| `--frame-text` | `Scan me` | Texto da moldura, até 24 caracteres |
| `--frame-color`, `--frame-text-color` | | Cores da moldura e do texto (hexadecimal) |

`qrdx --help` lista o nome de todos os padrões. Valores inválidos encerram com o código `1` e uma mensagem listando os valores aceitos.

## Vários códigos a partir de um CSV [#many-codes-from-a-csv]

`qrdx batch` grava em uma pasta um QR code estático para cada linha de um arquivo CSV:

```bash
qrdx batch products.csv -o codes --format png --size 1024 --body circle
```

Ele lê as mesmas colunas do [gerador em massa](/tools/bulk): o conteúdo vem de uma coluna chamada `value`, `url`, `link`, `data`, `content`, `text` ou `qr` (senão, a primeira coluna), e os nomes dos arquivos vêm de uma chamada `file name`, `name`, `label`, `id`, `title` ou `sku` (senão, `qr-00001`, `qr-00002` e assim por diante). Escolha outras pelo nome do cabeçalho ou pelo número da coluna:

| Flag | Padrão | Descrição |
| --- | --- | --- |
| `-o`, `--out` | `qr-codes` | Pasta para os códigos |
| `--format` | `svg` | `svg`, `png` ou `eps` |
| `--value-column` | detectada | Coluna com o conteúdo de cada código |
| `--name-column` | detectada | Coluna com os nomes dos arquivos |
| `--no-header` | | A primeira linha é um código, não nomes de colunas |
| `--jobs` | `4` para SVG, `8` nos demais | Códigos gerados ao mesmo tempo |

Todas as opções de estilo acima valem para todos os códigos. O CSV é lido como um fluxo e cada código é salvo assim que fica pronto, então o comando não tem limite de linhas: em um notebook, 10.000 códigos SVG levaram cerca de 40 segundos e menos de 200 MB de memória. Nada é enviado e não é preciso ter conta. As linhas que não podem ser codificadas são puladas e listadas com o motivo em `errors.csv` na pasta de saída.

Para imprimir [QR codes dinâmicos](/docs/dynamic-qr-codes) em massa, crie-os primeiro (pela importação de CSV do painel ou pela API) e rode `qrdx batch` no CSV de resultados que a importação entrega, com `--value-column short_link`.

## Exemplos [#examples]

```bash
# High-resolution PNG for print
qrdx generate "https://example.com" -o qr.png --size 2048 --level H

# Vector EPS, 2 inches wide, for a print shop
qrdx generate "https://example.com" -o qr.eps --size 144

# Branded colors and patterns
qrdx generate "https://example.com" --body circle --eye rounded --fg "#1a1a2e" -o brand.svg

# Gradient foreground
qrdx generate "https://example.com" -o gradient.svg \
  --fg '{"type":"linear","stops":[{"color":"#6366f1","offset":0},{"color":"#ec4899","offset":100}],"angle":135}'

# "Scan for the menu" frame
qrdx generate "https://example.com/menu" --frame banner-bottom --frame-text "Scan for the menu" -o menu.png

# Wi-Fi network
qrdx generate "WIFI:T:WPA;S:MyNetwork;P:MyPassword;;" -o wifi.svg
```

Para imprimir um [QR code dinâmico](/docs/dynamic-qr-codes), passe o link curto dele (`https://qrdx.dev/q/<slug>`) como dado.
