`@qrdx/cli` は、Playground や [`qrdx` ライブラリ](/docs/getting-started)と同じ QR コードをコマンドラインから生成します。スクリプトや CI では入力を求めることはありません。ターミナルで引数なしの `qrdx generate` を実行すると、内容とオプションを順に尋ねます。

<NpmStatus package="@qrdx/cli" />

```bash
npx @qrdx/cli generate "https://example.com" -o qr.svg
```

グローバルにインストールすると、`qrdx` コマンドが使えるようになります。

```bash
npm install -g @qrdx/cli
qrdx generate "https://example.com" -o qr.png --size 1024
```

Node.js 22 以降が必要です。PNG と WebP の出力には [sharp](https://sharp.pixelplumbing.com) を使います。sharp はオプションの依存関係で、お使いのプラットフォームが対応していれば npm がインストールします。SVG と EPS は sharp がなくても動作します。`qrdx` npm パッケージは React ライブラリです。CLI は `@qrdx/cli` にのみ含まれています。

## 出力形式 [#output-formats]

形式はファイルの拡張子で決まります。ファイル名に拡張子がない場合は `--format` を使います。

| 形式 | 用途 | `--size` の意味 |
| --- | --- | --- |
| `.svg` | Web ページ、デザインツール、劣化のない拡大縮小 | 幅（ピクセル、デフォルトは 512） |
| `.png` | ドキュメント、スライドなど、画像が必要な場所 | 幅（ピクセル） |
| `.webp` | Web サイト：PNG と同じピクセルをロスレスで、より小さいファイルに | 幅（ピクセル） |
| `.eps` | 印刷会社、Illustrator、InDesign | 幅（ポイント、1 インチ = 72 ポイントなので `144` は 2 インチ） |

EPS ファイルはベクターの PostScript です。PNG と JPEG のロゴはそのまま埋め込まれます。それ以外の形式のロゴは、sharp がインストールされていれば sharp で変換され、なければ警告を出して除外されます。

## オプション [#options]

| フラグ | デフォルト | 説明 |
| --- | --- | --- |
| `-o`, `--output` | `qr.svg` | 出力ファイル |
| `--format` | 拡張子から判定 | `svg`、`png`、`webp`、`eps` |
| `--size` | `512` | 出力サイズ（上記参照） |
| `-l`, `--level` | `Q` | 誤り訂正レベル：`L`、`M`、`Q`、`H` |
| `--body` | `square` | データモジュールの[パターン](/docs/features/patterns) |
| `--eye` | `square` | 角のアイのパターン |
| `--dot` | `square` | 角のアイドットのパターン |
| `--fg`, `--bg` | `#000000`, `#ffffff` | 前景色と背景色：16 進カラーまたは JSON のグラデーション |
| `--eye-color`, `--dot-color` | `--fg` | 角のアイとアイドットの色 |
| `--logo` | | 中央に配置するロゴ画像の URL（`--level H` と併用） |
| `--margin` | `0` | クワイエットゾーン（モジュール単位） |
| `--template` | | `Arrow`、`StandardBox`、`SquareBorder`、`StrikedBox`、`Halloween` |
| `--frame` | | 行動を促す[フレーム](/docs/features/frames)：{facts.frameStyles} 種類の組み込みフレームから選べます。例：`banner-bottom`、`rounded-border`、`circle`、`sticker`、`phone`（[すべてのフレーム](/docs/styles#frames)を参照） |
| `--frame-text` | `Scan me` | フレームのラベル（最大 24 文字） |
| `--frame-color`, `--frame-text-color` | | フレームとラベルの色（16 進） |

`qrdx --help` で、すべてのパターン名を確認できます。無効な値を指定すると、終了コード `1` で終了し、指定できる値を示すメッセージが表示されます。

## CSV から大量のコードを生成する [#many-codes-from-a-csv]

`qrdx batch` は、CSV ファイルの各行について静的QRコードを作成し、フォルダーに書き出します。

```bash
qrdx batch products.csv -o codes --format png --size 1024 --body circle
```

読み込む列は[一括ジェネレーター](/tools/bulk)と同じです。内容は `value`、`url`、`link`、`data`、`content`、`text`、`qr` のいずれかの名前の列から取得します（該当する列がなければ最初の列）。ファイル名は `file name`、`name`、`label`、`id`、`title`、`sku` のいずれかの名前の列から取得します（該当する列がなければ `qr-00001`、`qr-00002` のように連番になります）。別の列を使う場合は、ヘッダー名または列番号で指定します。

| フラグ | デフォルト | 説明 |
| --- | --- | --- |
| `-o`, `--out` | `qr-codes` | コードの出力先フォルダー |
| `--format` | `svg` | `svg`、`png`、`eps` |
| `--value-column` | 自動判定 | 各コードの内容が入った列 |
| `--name-column` | 自動判定 | ファイル名が入った列 |
| `--no-header` | | 最初の行を列名ではなくコードとして扱う |
| `--jobs` | SVG は `4`、それ以外は `8` | 同時に生成するコード数 |

上記のスタイルオプションは、すべてのコードに適用されます。CSV はストリームとして読み込まれ、各コードは生成されるたびに保存されるため、行数の上限はありません。ノート PC で SVG のコード 10,000 件を生成したところ、約 40 秒で、メモリ使用量は 200 MB 未満でした。何もアップロードされず、アカウントも不要です。エンコードできなかった行はスキップされ、その理由とともに出力フォルダー内の `errors.csv` に一覧されます。

[動的QRコード](/docs/dynamic-qr-codes)を一括で印刷するには、先にそれらを作成し（ダッシュボードの CSV インポートまたは API）、インポートで得られる結果の CSV に対して `--value-column short_link` を付けて `qrdx batch` を実行します。

## 例 [#examples]

```bash
# High-resolution PNG for print
qrdx generate "https://example.com" -o qr.png --size 2048 --level H

# Vector EPS, 2 inches wide, for a print shop
qrdx generate "https://example.com" -o qr.eps --size 144

# Branded colors and patterns
qrdx generate "https://example.com" --body circle --eye rounded --fg "#1a1a2e" -o brand.svg

# Gradient foreground
qrdx generate "https://example.com" -o gradient.svg \
  --fg '{"type":"linear","stops":[{"color":"#6366f1","offset":0},{"color":"#ec4899","offset":100}],"angle":135}'

# "Scan for the menu" frame
qrdx generate "https://example.com/menu" --frame banner-bottom --frame-text "Scan for the menu" -o menu.png

# Wi-Fi network
qrdx generate "WIFI:T:WPA;S:MyNetwork;P:MyPassword;;" -o wifi.svg
```

[動的QRコード](/docs/dynamic-qr-codes)を印刷するには、データとして短縮リンク（`https://qrdx.dev/q/<slug>`）を渡します。

## AI コーディングエージェントから使う [#use-it-from-an-ai-coding-agent]

リポジトリの [`generate-qr` スキル](https://github.com/bucharitesh/qrdx/tree/main/skills/generate-qr)は、Claude Code などのエージェントに CLI の呼び出し方を教えます。MCP に対応したエージェントなら、[MCP サーバー](/docs/developers/mcp)を使うことでインストールはまったく不要です。
