## Basis-URL und Authentifizierung [#base-url-and-authentication]

Die REST API erreichst du unter `https://api.qrdx.dev/v1`. Dieselben Routen antworten auch unter `https://qrdx.dev/api/v1`.

Anfragen authentifizierst du mit einem [API-Schlüssel](/docs/developers/api-keys) im Header `Authorization: Bearer`. Apps, die im Namen anderer QRdx-Nutzer handeln, senden dort stattdessen ein [OAuth-2.0-Zugriffstoken](/docs/developers/rest-api#get-an-access-token). Der [Schnellstart](/docs/developers/quickstart#create-an-api-key) erstellt einen Schlüssel und führt eine erste Anfrage aus.
