API QRdx terdiri dari dua bagian. Gambar tidak memerlukan apa pun: tanpa akun, tanpa kunci. Kode dinamis, pemindaian, dan webhook milik sebuah workspace, sehingga memerlukan kunci API.

## 1. Buat kode QR (tanpa kunci) [#1-make-a-qr-code-no-key]

Jalankan perintah ini. Perintah ini menyimpan PNG kode QR yang membuka qrdx.dev:

<Tabs groupId="language" persist items={["curl", "JavaScript", "Python"]}>
  <Tab value="curl">
    ```bash
    curl "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png" -o qr.png
    ```
  </Tab>
  <Tab value="JavaScript">
    ```js
    // Node 18 or later (save as qr.mjs)
    import { writeFile } from "node:fs/promises";

    const url = new URL("https://api.qrdx.dev/v1/qr");
    url.searchParams.set("data", "https://qrdx.dev");
    url.searchParams.set("format", "png");

    const response = await fetch(url);
    await writeFile("qr.png", Buffer.from(await response.arrayBuffer()));
    ```
  </Tab>
  <Tab value="Python">
    ```python
    # pip install requests
    import requests

    response = requests.get(
        "https://api.qrdx.dev/v1/qr",
        params={"data": "https://qrdx.dev", "format": "png"},
    )
    response.raise_for_status()
    open("qr.png", "wb").write(response.content)
    ```
  </Tab>
</Tabs>

Itu adalah panggilan API yang berfungsi. URL itu sendiri adalah gambarnya, sehingga bisa langsung dipakai di tag `<img>`:

```html
<img src="https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&fg=111111&body=circle" alt="QR code for qrdx.dev" />
```

Ubah warna, bentuk, ukuran, dan format dengan parameter query, atau coba langsung di browser pada halaman [Render a QR code image](/docs/developers/api/get-qr-image): panel **Try it** mengirim permintaan dan menampilkan gambarnya. Gambar tidak dihitung dalam kuota apa pun; batasnya adalah 300 permintaan per menit untuk setiap alamat IP.

## 2. Buat kunci API [#create-an-api-key]

Semua hal lainnya di API bekerja pada sebuah workspace: membuat kode dinamis, mengubah tujuannya, membaca data pemindaiannya. Permintaan tersebut membawa kunci API di header `Authorization`.

1. Buka [Settings → API keys & apps](/dashboard?to=settings/developers&new=1) (masuk terlebih dahulu jika perlu). Formulir **Create key** akan terbuka.
2. Biarkan **Full access** dan pilih **Create key**.
3. Salin kuncinya. Kunci hanya ditampilkan sekali. Dialog ini juga menampilkan permintaan curl untuk membuat kode dinamis, lengkap dengan kunci Anda, jika Anda lebih suka menempelkannya.

Ekspor kunci untuk langkah berikutnya:

```bash
export QRDX_API_KEY=qrdx_...
```

Kunci ini bertindak sebagai Anda di workspace yang sedang terbuka saat Anda membuatnya, dan permintaan yang memakainya dihitung dalam kuota harian workspace tersebut (1.000 permintaan di paket Gratis). [Kunci API](/docs/developers/api-keys) membahas scope, tim, masa berlaku, dan pencabutan.

## 3. Buat kode dinamis [#3-create-a-dynamic-code]

Kode dinamis adalah tautan pendek yang bisa Anda arahkan ke tempat lain setelah dicetak:

<Tabs groupId="language" persist items={["curl", "JavaScript", "Python"]}>
  <Tab value="curl">
    ```bash
    curl -X POST https://api.qrdx.dev/v1/codes \
      -H "Authorization: Bearer $QRDX_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"destinationUrl": "https://example.com", "title": "My first code"}'
    ```
  </Tab>
  <Tab value="JavaScript">
    ```js
    const response = await fetch("https://api.qrdx.dev/v1/codes", {
      method: "POST",
      headers: {
        Authorization: `Bearer ${process.env.QRDX_API_KEY}`,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        destinationUrl: "https://example.com",
        title: "My first code",
      }),
    });
    const { data: code } = await response.json();
    console.log(code.shortLink);
    ```
  </Tab>
  <Tab value="Python">
    ```python
    import os
    import requests

    response = requests.post(
        "https://api.qrdx.dev/v1/codes",
        headers={"Authorization": f"Bearer {os.environ['QRDX_API_KEY']}"},
        json={"destinationUrl": "https://example.com", "title": "My first code"},
    )
    response.raise_for_status()
    code = response.json()["data"]
    print(code["shortLink"])
    ```
  </Tab>
</Tabs>

Responsnya adalah `201 Created` beserta kode baru:

```json
{
  "data": {
    "id": "cm5code0spring0menu00001",
    "slug": "aB3dE5f",
    "shortLink": "https://qrdx.dev/q/aB3dE5f",
    "destinationUrl": "https://example.com/",
    "title": "My first code",
    "status": "active",
    "scanCount": 0
  }
}
```

(Disingkat: [Create codes](/docs/developers/api/create-codes) menampilkan semua field.) Kode QR menyandikan `shortLink`. Render dengan API gambar dari langkah 1, `https://api.qrdx.dev/v1/qr?data=https://qrdx.dev/q/aB3dE5f`, lalu cetak.

## 4. Arahkan ke tempat lain [#4-point-it-somewhere-else]

Ubah tujuan kapan saja; kode yang sudah dicetak tetap berfungsi:

```bash
curl -X PATCH https://api.qrdx.dev/v1/codes/$CODE_ID \
  -H "Authorization: Bearer $QRDX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"destinationUrl": "https://example.com/new-page"}'
```

Lakukan pemindaian kode sekali, lalu baca analitiknya dengan `GET /v1/codes/$CODE_ID/scans` ([Get scan analytics](/docs/developers/api/get-code-scans)).

## Saat terjadi masalah [#when-something-goes-wrong]

Setiap error berbentuk JSON dengan `code` yang stabil dan pesan yang menjelaskan apa yang harus dilakukan:

```json
{
  "code": "UNAUTHORIZED",
  "message": "Missing API key. Send an API key as \"Authorization: Bearer <key>\"; create one at https://qrdx.dev/dashboard?to=settings/developers. OAuth access tokens go in the same header.",
  "status": 401,
  "docs": "https://qrdx.dev/docs/developers/api-keys"
}
```

[Halaman error](/docs/developers/errors) mencantumkan setiap kode beserta solusinya.

## Bertindak untuk orang lain [#get-an-access-token]

Kunci API bertindak sebagai Anda. Jika produk Anda memanggil QRdx untuk orang lain, daftarkan aplikasi OAuth: setiap orang menyetujuinya sekali, dan server Anda mendapat token akses untuk akun mereka, yang dikirim di header `Authorization: Bearer` yang sama. Semua permintaan di atas berfungsi tanpa perubahan dengan token sebagai pengganti kunci. Lihat [REST API dan OAuth](/docs/developers/rest-api#get-an-access-token) dan [Membangun integrasi](/docs/developers/build-an-integration).
