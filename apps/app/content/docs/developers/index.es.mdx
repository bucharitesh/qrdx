## URL base y autenticación [#base-url-and-authentication]

La REST API está en `https://api.qrdx.dev/v1`. Las mismas rutas también responden en `https://qrdx.dev/api/v1`.

Las solicitudes se autentican con una [clave de API](/docs/developers/api-keys) en el encabezado `Authorization: Bearer`. Las aplicaciones que actúan en nombre de otros usuarios de QRdx envían ahí un [token de acceso OAuth 2.0](/docs/developers/rest-api#get-an-access-token). El [inicio rápido](/docs/developers/quickstart#create-an-api-key) crea una clave y hace una primera solicitud.
