## URL de base et authentification [#base-url-and-authentication]

La REST API se trouve à l'adresse `https://api.qrdx.dev/v1`. Les mêmes routes répondent aussi à l'adresse `https://qrdx.dev/api/v1`.

Les requêtes s'authentifient avec une [clé API](/docs/developers/api-keys) dans l'en-tête `Authorization: Bearer`. Les applications qui agissent pour d'autres utilisateurs de QRdx y envoient à la place un [jeton d'accès OAuth 2.0](/docs/developers/rest-api#get-an-access-token). Le [démarrage rapide](/docs/developers/quickstart#create-an-api-key) crée une clé et effectue une première requête.
