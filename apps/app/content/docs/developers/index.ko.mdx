## 기본 URL과 인증 [#base-url-and-authentication]

REST API는 `https://api.qrdx.dev/v1`에서 제공됩니다. 같은 경로가 `https://qrdx.dev/api/v1`에서도 응답합니다.

요청은 `Authorization: Bearer` 헤더에 [API 키](/docs/developers/api-keys)를 넣어 인증합니다. 다른 QRdx 사용자를 대신해 동작하는 앱은 API 키 대신 [OAuth 2.0 액세스 토큰](/docs/developers/rest-api#get-an-access-token)을 보냅니다. [빠른 시작](/docs/developers/quickstart#create-an-api-key)에서 키를 만들고 첫 요청을 보내 볼 수 있습니다.
