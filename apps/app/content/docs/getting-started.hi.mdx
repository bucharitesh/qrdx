`qrdx` इंस्टॉल करें और कुछ ही मिनटों में अपना पहला QR कोड बनाएँ।

<NpmStatus package="qrdx" />

## पैकेज इंस्टॉल करें [#install-the-package]

```package-install
qrdx@latest
```

`react` और `react-dom` (18 या नया वर्शन) peer dependencies हैं, इसलिए `qrdx` वही वर्शन इस्तेमाल करता है जो आपके app में पहले से हैं। PDF export वैकल्पिक है: `jspdf` तभी इंस्टॉल करें जब आपको इसकी ज़रूरत हो।

## क्विक स्टार्ट [#quick-start]

अपना पहला QR कोड बनाएँ:

```tsx
import { QRCode } from 'qrdx';

export default function App() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
    />
  );
}
```

बस इतना ही। अब आपके पास एक काम करता हुआ QR कोड है।

पहले डिज़ाइन करना चाहते हैं? [Playground में आज़माएँ](/playground?open=code&lang=react): वहाँ QR कोड को स्टाइल करें, फिर उसे React component के रूप में कॉपी करें।
