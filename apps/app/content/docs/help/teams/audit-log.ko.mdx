감사 로그는 QRdx 상용 라이선스에 포함된 Business 기능입니다. 자체 호스팅 QRdx 서버에서 사용하려면 라이선스 키(`QRDX_EE_LICENSE`)가 필요합니다. [자체 호스팅](/docs/self-hosting#optional-services)을 참고하세요.

<IfAvailable feature="auditLog">

감사 로그에는 워크스페이스에서 사람들이 만든 변경 내용이 누가, 무엇을, 언제 변경했는지와 함께 나열됩니다. 소유자와 관리자는 **설정** → **감사 로그**에서 이를 확인하고, 필터링하고, CSV 파일로 내보낼 수 있습니다.

## 사용 가능한 대상 [#who-has-it]

감사 로그는 **Business** 요금제에 포함된 기능입니다. 워크스페이스의 소유자 또는 결제 멤버 중 한 명이 Business를 사용하면 해당 워크스페이스에서 감사 로그를 쓸 수 있습니다. [좌석과 워크스페이스 한도](/docs/help/teams/seats)를 참고하세요.

기록은 워크스페이스가 Business를 사용하기 시작한 시점부터 쌓입니다. 그 전이나 다른 요금제를 쓰던 동안의 변경은 기록되지 않습니다. 워크스페이스가 Business를 떠나면 기록이 중단됩니다. 이미 저장된 항목은 {facts.auditLogRetentionDays}일이 될 때까지 남아 있고, 워크스페이스가 Business로 돌아오면 다시 볼 수 있습니다.

감사 로그를 열고 내보낼 수 있는 사람은 **소유자**와 **관리자**뿐입니다. 멤버, 뷰어, 결제 멤버는 할 수 없습니다. [역할](/docs/help/teams/roles)을 참고하세요.

## 기록되는 내용 [#whats-recorded]

각 항목에는 시간, 변경한 사람, 변경한 내용, 대상(코드, 페이지, 사람, 도메인)이 담깁니다. 해당하는 경우 코드의 이전 목적지와 새 목적지처럼 이전 값과 새 값도 함께 저장됩니다. 항목의 화살표를 클릭하면 볼 수 있어요.

변경한 주체는 사람이거나, 사람을 대신해 동작하는 API 키 또는 앱입니다. API 키로 [REST API](/docs/developers/rest-api)를 통해 한 변경에는 키 이름이, 사용자가 승인한 앱을 통해 한 변경에는 앱 이름이 표시됩니다.<IfAvailable feature="slackBot"> Slack에서 `/qr track`으로 만든 코드에는 연결된 사람이 "via Slack"으로 표시되고, Slack 사용자 ID와 워크스페이스 ID도 함께 기록됩니다. 소유자나 관리자가 [설정 → API 키 및 앱](/dashboard?to=settings/developers)에서 Slack 계정 연결을 해제하면 개발자 항목에 기록됩니다.</IfAvailable>

각 항목에는 요청의 IP 주소와 기기도 저장됩니다. 기기는 "Chrome on macOS"처럼 브라우저와 시스템으로 표시됩니다. 결제에 따른 요금제 변경처럼 시스템이 수행한 변경에는 둘 다 없습니다.

다음 변경이 기록됩니다.

- **코드:** 생성(가져오기와 복사 포함), 목적지 변경, 이름 변경, 디자인 변경, 짧은 링크 변경, 링크 제어 변경(비밀번호 켜기/끄기, 시작일과 종료일, 스캔 한도, 대체 URL), 라우팅 규칙 변경, 일시 중지 또는 재개, 보관 또는 보관 해제, 휴지통으로 이동, 복원, 영구 삭제, 이전 버전 복원, 다른 폴더로 이동, 다른 워크스페이스로 또는 다른 워크스페이스에서 이동. 폴더와 태그의 생성, 이름 변경, 삭제.
- **페이지:** 생성, 게시, 삭제.
- **팀:** 초대 전송과 취소, 초대·참여 링크·싱글 사인온으로 참여한 사람, 역할 변경, 제거된 사람, 탈퇴한 사람, 참여 링크 켜기·변경·끄기. 이 변경은 QRdx에서 했든 API로 했든 모두 기록됩니다.
- **보안:** "2단계 인증 필수"와 "싱글 사인온 필수"의 켜기 또는 끄기(싱글 사인온을 켜면 로그아웃된 세션 수도 함께 기록), 싱글 사인온 설정·변경·확인·삭제, 싱글 사인온으로 처음 로그인하는 사람에게 부여되는 역할, 감사 로그 내보내기.
- **개발자:** API 키 생성과 폐기(이름과 범위), 앱 승인 또는 해제, 웹훅 엔드포인트 추가·변경·삭제, 웹훅 서명 시크릿 교체. 엔드포인트는 웹훅 URL의 나머지 부분이 비밀인 경우가 많아서 `https://hooks.zapier.com/…`처럼 서버만 저장됩니다.
- **도메인:** 사용자 지정 도메인 추가, 확인, 삭제.
- **워크스페이스:** 이름 또는 URL 변경, Business로의 전환("결제"로 기록).

감사 로그에는 API 키, OAuth 토큰, 비밀번호, 웹훅 URL의 경로나 쿼리, 웹훅 서명 시크릿, 싱글 사인온 클라이언트 시크릿이나 인증서가 저장되지 않습니다. 생성, 교체, 삭제되었다는 사실만 기록하고 값은 기록하지 않습니다.

사용자가 승인한 앱은 사용자의 워크스페이스에서 동작하므로, 앱을 승인하거나 해제한 내용도 그곳에 기록됩니다.

다음은 감사 로그에 포함되지 않습니다.

- 스캔, 양식 응답, 분석 데이터: 워크스페이스에 대한 변경이 아니기 때문입니다(분석과 응답에서 확인하세요).
- 이름, 이메일, 2단계 인증처럼 본인 계정에 대한 변경.

## 로그 필터링 [#filter-the-log]

최신 변경이 먼저 표시되며 한 번에 50개씩 보여요. 이전 항목은 맨 아래의 **더 보기**를 클릭하세요.

- **사용자**: 한 사람과 그 사람을 대신해 동작하는 API 키 및 앱.
- **카테고리**: 코드(폴더와 태그 포함), 페이지, 팀, 보안, 개발자, 도메인, 워크스페이스.
- **시작일**과 **종료일**: 표시할 첫날과 마지막 날. 날짜는 UTC 기준이며, 각 항목의 시간은 사용자의 시간대로 표시됩니다.

## CSV로 내보내기 [#export-as-csv]

**CSV 내보내기**를 클릭하면 현재 필터에 표시된 내용을 최신순으로 내려받습니다. 한 번에 최대 {facts.auditLogExportRows}개의 항목을 내보낼 수 있습니다. 더 많이 내보내려면 날짜 범위를 짧게 나눠서 내보내세요.

파일에는 변경 하나당 한 행이 들어가며, UTC 기준 시간, 카테고리, 동작, 변경을 설명하는 문장, 변경한 사람(API 키나 앱이 있으면 함께), 대상, IP 주소, 기기, 이전 값과 새 값(JSON)이 포함됩니다.

내보내기도 사용한 필터와 함께 기록됩니다.

## 항목 보관 기간 [#how-long-entries-are-kept]

항목은 {facts.auditLogRetentionDays}일 동안 보관된 후 삭제됩니다. 워크스페이스를 삭제하면 감사 로그도 함께 삭제됩니다.

감사 로그에 있는 IP 주소와 기기는 워크스페이스에서 일하는 사람들의 개인 데이터입니다. QRdx가 이를 어떻게 처리하는지는 [개인정보 처리방침](/legal/privacy-policy)에서 확인하세요.
