## Aus einer CSV-Datei [#from-a-csv-file]

1. Gehe zu **Codes** und klicke auf **CSV importieren**.
2. Lade eine CSV-Datei mit einem Code pro Zeile hoch.

Die einzige Pflichtspalte ist das Ziel. Du kannst auch einen Titel, einen Ordner, Tags und einen eigenen Back-Half angeben. Eine Datei kann bis zu {facts.importRows} Zeilen enthalten und bis zu 10 MB groß sein. Jede Zeile wird geprüft, bevor etwas erstellt wird. Zeilen mit Problemen werden übersprungen und aufgelistet.

Du kannst außerdem einen Ordner und Tags für alle Codes in der Datei auswählen. Eine Zeile mit eigenem Ordner behält ihn, und die tags der Datei werden zu den von dir gewählten hinzugefügt.

Große Dateien werden in Teilen gesendet, während sich ein Fortschrittsbalken füllt. Du kannst pausieren und fortsetzen. Wenn die Seite neu lädt oder die Verbindung abbricht, stoppt der Import und bietet an, ihn fortzusetzen oder es erneut zu versuchen. Dabei wird kein Code doppelt erstellt. Wenn der Import abgeschlossen ist, kannst du eine Ergebnis-CSV mit dem Short-Link jeder Zeile herunterladen, oder eine ZIP-Datei mit den neuen Codes als PNG- oder SVG-Dateien.

Mit Kostenlos kannst du jeweils einen Code importieren. Mit Pro und Business kannst du viele auf einmal importieren.

## Von einem anderen Dienst [#from-another-service]

Klicke auf der Seite **Codes** auf **Importieren** und wähle aus, wo sich deine Codes gerade befinden.

- **Bitly**: Melde dich bei Bitly an und wähle die Links aus.
- **Rebrandly** und **Short.io**: Füge einen API-Schlüssel von diesem Dienst ein.
- **QR Code Generator PRO, Uniqode, Flowcode, QR TIGER, ME-QR, TinyURL, Hovercode, Scanova** und andere: Lade die Exportdatei dieses Dienstes hoch.
