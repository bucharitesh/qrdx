---
title: Archive, delete and restore codes
description: What happens to a printed code when you archive it, move it to the trash or delete it forever.
---

<Callout type="warn">
  Archiving, trashing or deleting a code **stops it from working**. To retire a printed code gently, [pause it](/docs/help/dynamic-codes/pause-schedule-limit) and add a fallback URL instead.
</Callout>

## Archive

Choose **Archive** from the code's menu in **Codes**.

- Scanners see "This QR code is no longer active".
- Archived codes don't count toward your plan's code limit.
- Choose **Unarchive** to turn the code back on. On Free, you need a free code slot.

## Move to the trash

Choose **Move to trash** from the code's menu.

- Scanners see "This QR code is no longer active".
- Open **Trash** in the Codes sidebar and choose **Restore** to bring it back.
- QRdx never empties the trash on its own.

## Delete forever

In **Trash**, choose **Delete forever**.

- Scanners see "QR code not found".
- The code's scan history is deleted.
- This can't be undone.
