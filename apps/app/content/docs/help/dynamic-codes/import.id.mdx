## Dari file CSV [#from-a-csv-file]

1. Buka **Codes** lalu klik **Import CSV**.
2. Unggah file CSV dengan satu kode per baris.

Satu-satunya kolom yang wajib adalah tujuan. Anda juga dapat menyertakan judul, folder, tag, dan back-half kustom. Satu file dapat memiliki hingga {facts.importRows} baris dan berukuran hingga 10 MB. Setiap baris diperiksa sebelum ada yang dibuat; baris yang bermasalah dilewati dan ditampilkan dalam daftar.

Anda juga dapat memilih folder dan tag untuk setiap kode dalam file. Baris dengan folder sendiri tetap memakai folder tersebut, dan tag dari file ditambahkan ke tag yang Anda pilih.

File besar dikirim secara bertahap sementara bilah progres terisi. Anda dapat menjeda dan melanjutkan. Jika halaman dimuat ulang atau koneksi terputus, impor berhenti dan menawarkan untuk melanjutkan atau mencoba lagi, dan tidak ada kode yang dibuat dua kali. Setelah selesai, unduh CSV hasil berisi tautan pendek setiap baris, atau ZIP berisi kode baru sebagai file PNG atau SVG.

Pada paket Gratis, Anda dapat mengimpor satu kode sekaligus. Pro dan Business dapat mengimpor banyak kode sekaligus.

## Dari layanan lain [#from-another-service]

Klik **Import** di halaman **Codes** lalu pilih tempat kode Anda berada sekarang.

- **Bitly**: masuk ke Bitly lalu pilih tautannya.
- **Rebrandly** dan **Short.io**: tempel kunci API dari layanan tersebut.
- **QR Code Generator PRO, Uniqode, Flowcode, QR TIGER, ME-QR, TinyURL, Hovercode, Scanova** dan lainnya: unggah file ekspor dari layanan tersebut.

## Pastikan kode yang sudah dicetak tetap berfungsi [#keep-printed-codes-working]

Kode yang sudah dicetak masih mengarah ke layanan lama. Panduan migrasi menjelaskan cara menjaganya tetap berfungsi, dan cara mempertahankan back-half asli Anda.

Lihat [Pindah dari Bitly, Rebrandly, dan lainnya](/docs/migrate).
