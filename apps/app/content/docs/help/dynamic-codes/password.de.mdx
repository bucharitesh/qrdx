---
title: "Einen Code mit einem Passwort schützen"
description: "Frage ein Passwort ab, bevor ein dynamischer QR-Code sein Ziel öffnet."
---

In den Tarifen Pro und Business kannst du einen dynamischen Code mit einem Passwort versehen.

## Passwort hinzufügen [#add-a-password]

1. Öffne den Code unter **Codes**.
2. Öffne unter **Settings** den Bereich **Access & schedule**.
3. Gib ein **Password** mit 4 bis 64 Zeichen ein und speichere.

## Was Scanner sehen [#what-scanners-see]

Beim Scan sehen Nutzer die Meldung „This QR code is password protected“ mit einem Feld **Password** und einer Schaltfläche **Continue**.

Nach Eingabe des richtigen Passworts bleibt dieser Browser 6 Stunden lang freigeschaltet.

## Passwort getrennt weitergeben [#share-the-password-separately]

Jeder, der das Passwort kennt, kann den Code öffnen. Gib es so weiter, wie du jedes andere Passwort weitergeben würdest, und drucke es nicht neben den Code.

## Passwort entfernen [#remove-the-password]

Leere das Feld **Password** und speichere. Das Entfernen funktioniert in jedem Tarif.
