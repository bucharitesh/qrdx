---
title: Pause, schedule or limit a code
description: Turn a dynamic QR code off, set start and end dates, cap its scans, and choose where ended codes send people.
---

All of these are in one place: open the code from **Codes**, then under **Settings**, open **Access & schedule**.

## Pause a code

Turn on **Pause code** and save. You can also choose **Pause** from the code's menu in **Codes**, and **Resume** to turn it back on.

Pausing works on every plan.

## Set start and end dates

Fill in **Starts**, **Ends** or both. Scans before the start or after the end don't reach your destination.

Use this for a campaign with fixed dates. Pro and Business only.

## Cap the scans

Set a **Scan limit**. After that many scans, the code ends. Pro and Business only.

## What people see

When a code isn't active, scanners see a plain page with no QRdx branding:

- Paused: "This campaign is paused".
- Before the start date: "This campaign hasn't started yet".
- After the end date or the scan limit: "This campaign has ended".

## Send people somewhere useful instead

Fill in **Fallback URL** to send scans of a paused or ended code to a page you choose, such as your homepage. It doesn't apply before the start date.

## After a downgrade

Settings you already saved keep working. Removing a setting never needs a paid plan.
