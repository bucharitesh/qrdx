---
title: "Protéger un code par mot de passe"
description: "Demandez un mot de passe avant qu'un QR code dynamique n'ouvre sa destination."
---

Les offres Pro et Business permettent d'ajouter un mot de passe à un code dynamique.

## Ajouter un mot de passe [#add-a-password]

1. Ouvrez le code depuis **Codes**.
2. Sous **Paramètres**, ouvrez **Accès et planification**.
3. Saisissez un **Mot de passe** de 4 à 64 caractères, puis enregistrez.

## Ce que voient les personnes qui scannent [#what-scanners-see]

Les personnes qui scannent le code voient « Ce QR code est protégé par un mot de passe », avec un champ **Mot de passe** et un bouton **Continuer**.

Une fois le bon mot de passe saisi, ce navigateur reste déverrouillé pendant 6 heures.

## Partager le mot de passe séparément [#share-the-password-separately]

Toute personne qui connaît le mot de passe peut ouvrir le code. Transmettez-le comme vous le feriez pour n'importe quel mot de passe, et non imprimé à côté du code.

## Supprimer le mot de passe [#remove-the-password]

Videz le champ **Mot de passe** et enregistrez. La suppression est possible avec toutes les offres.
