동적 코드에는 목적지로 전달해 주는 짧은 링크가 들어 있습니다. 무료 QRdx 계정이 필요합니다. 무료 플랜에는 동적 코드 10개가 포함되며, Pro와 Business는 개수 제한이 없습니다.

## Playground에서 만들기 [#from-the-playground]

1. [Playground](/playground?type=url)를 열고 **Website address**에 링크를 입력하세요.
2. 주소 입력란 아래에서 **Dynamic QR code** 카드를 찾으세요.
3. 로그인하지 않았다면 **Sign in to make it dynamic**을 클릭하고 로그인하세요. 돌아오면 입력한 링크가 그대로 남아 있습니다.
4. **Make it dynamic**을 클릭하세요.

이제 카드에 짧은 링크와 "Scans go to" 목적지가 표시됩니다. 코드는 평소처럼 다운로드하면 됩니다. 이 코드에는 이제 짧은 링크가 담겨 있습니다.

Playground에서 만든 동적 코드는 웹사이트 링크에 사용할 수 있습니다. 다른 콘텐츠는 [모바일 페이지](/docs/help/pages-and-forms/create-a-page)를 만드세요. 모바일 페이지에도 동적 코드가 함께 만들어집니다.

## 대시보드에서 만들기 [#from-your-dashboard]

1. 대시보드에서 **Codes**로 이동해 **New code**를 클릭하세요.
2. **Link**에서 **Website link**를 선택하세요.
3. **Destination URL**을 입력하고, 원하면 **Title**도 입력하세요.
4. **Create code**를 클릭하세요.

그런 다음 코드를 다운로드하거나 **View analytics**를 클릭해 열 수 있습니다.

## 짧은 링크 끝부분 직접 정하기 [#choose-your-own-short-link-ending]

Pro와 Business에서는 **Custom back-half**를 입력해 짧은 링크의 끝부분을 직접 정할 수 있습니다. 예: `qrdx.dev/q/spring-menu`. 영문자, 숫자, 대시, 밑줄을 사용해 3~64자로 입력할 수 있습니다.

무료 플랜에서는 QRdx가 짧은 무작위 끝부분을 정해 드립니다.

## 한도에 도달했을 때 [#when-you-reach-the-limit]

무료 플랜에서는 활성 코드만 10개에 포함됩니다. 보관된 코드와 휴지통에 있는 코드는 포함되지 않습니다. 더 이상 쓰지 않는 코드를 보관하거나 [Pro로 업그레이드](/pricing)하세요.
