---

## Faça a denúncia [#report-it]

1. Abra o [formulário de denúncia](/report-abuse). Você não precisa de uma conta.
2. Cole o link curto do código, o link da página ou o código curto de 7 caracteres.
3. Escolha um motivo, adicione os detalhes que quiser e envie.

Deixe seu e-mail se quiser saber o que fizemos. É opcional.

Toda página aberta por um QR code dinâmico do QRdx, incluindo as páginas de senha e de "campanha encerrada", tem um link para o formulário.

## O que acontece depois [#what-happens-next]

Uma pessoa analisa cada denúncia em 24 a 48 horas. Os códigos que violam nossas regras são desativados para todos, e o dono não consegue reativá-los.

## Fique seguro [#stay-safe]

Não digite senhas, números de cartão nem códigos de uso único em uma página que você acessou por um QR code em que não confia.

## Códigos estáticos [#static-codes]

Um QR code estático guarda o conteúdo diretamente e nunca passa pelo QRdx, então não conseguimos desativá-lo. Denuncie o site prejudicial ao provedor de hospedagem dele ou ao [Google Safe Browsing](https://safebrowsing.google.com/safebrowsing/report_phish/).

## Se o seu código foi desativado [#if-your-code-was-switched-off]

Se você acha que cometemos um erro, envie um e-mail para [support@qrdx.dev](mailto:support@qrdx.dev) com "[appeal]" no assunto e o link curto do código.

Leia a [política de abuso](/legal/report-abuse) completa.
