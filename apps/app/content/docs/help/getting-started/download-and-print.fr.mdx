## Télécharger [#download]

Dans le [Playground](/playground), cliquez sur l'icône de téléchargement au-dessus de l'aperçu, ou appuyez sur <kbd>D</kbd>. La boîte de dialogue **Télécharger le QR code** s'ouvre avec deux onglets.

### Fichier image [#image-file]

À utiliser pour les écrans, les e-mails, les présentations et la plupart des impressions.

1. Choisissez un format : **PNG**, **JPG**, **WebP**, **SVG**, **PDF** ou **EPS**.
2. Choisissez une taille : E-mail (200 px), Web (400 px), Réseaux sociaux (800 px), Impression (1200 px), Affiche (2000 px), ou saisissez la vôtre.
3. Activez **Fond transparent** si nécessaire. Le format JPG ne peut pas être transparent.
4. Cliquez sur le bouton de téléchargement en bas.

### Prêt à imprimer [#print-ready]

À utiliser lorsqu'un imprimeur vous demande un fichier.

1. Définissez la **largeur du code** en millimètres ou en pouces.
2. Choisissez **RVB** ou **CMJN**. Les imprimeurs demandent généralement du CMJN.
3. Ajoutez **3 mm de fond perdu** si l'arrière-plan va jusqu'au bord de la page, afin que le rognage ne laisse jamais de ligne blanche.
4. Activez **Traits de coupe** pour indiquer où couper. Les traits de coupe sont ajoutés aux PDF.
5. Téléchargez un fichier **PDF**, **SVG** ou **EPS**.

## Quel format choisir [#which-format-to-choose]

- **PNG**, **JPG** ou **WebP** : images en pixels pour les écrans, les e-mails et les documents. Le WebP offre les mêmes pixels que le PNG dans un fichier plus léger, ce qui convient aux sites web.
- **SVG**, **EPS**, ou un **PDF** issu de **Prêt à imprimer** : fichiers vectoriels qui restent nets à toutes les tailles. Les imprimeurs les préfèrent. Un PDF issu de l'onglet **Fichier image** contient une image du code ; utilisez donc Prêt à imprimer pour tout ce que vous imprimez.

## Quelle taille imprimer [#how-big-to-print]

Donnez au code environ un dixième de la distance de scan.

- Une carte de visite lue à 20 cm nécessite un code d'environ 2 cm de large.
- Une affiche lue à 1 m nécessite un code d'environ 10 cm de large.

Les codes qui contiennent plus de données demandent plus de place. Le [calculateur de taille d'impression](/tools/print-size) détermine la taille minimale pour vous.

## Laissez une bordure dégagée [#leave-a-clear-border]

Conservez un espace vide autour du code. Les lecteurs en ont besoin pour repérer le code. Le réglage **Marge** de l'onglet **Design** l'ajoute pour vous ; **Standard** (4 modules) est le choix le plus sûr.

## Testez avant d'imprimer [#test-before-you-print]

Imprimez un exemplaire et scannez-le avec deux téléphones différents, à la distance à laquelle les gens le scanneront. Vous pouvez aussi importer la photo d'un code imprimé dans le [vérificateur de scan](/tools/scan-checker).
