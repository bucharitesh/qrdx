---
title: "Créez votre premier QR code"
description: "Créez un QR code dans le Playground et téléchargez-le. Gratuit, sans compte et sans filigrane."
---

Vous pouvez créer un QR code en une minute environ. Aucun compte n'est nécessaire.

## Créer le code [#make-the-code]

1. Ouvrez le [Playground](/playground). C'est l'éditeur de QRdx.
2. **URL** est déjà sélectionné. Pour un Wi-Fi, une carte de contact, WhatsApp ou autre chose, cliquez sur **Modifier** à côté de **Type de QR code** et choisissez un type.
3. Saisissez votre lien dans **Adresse du site web**. L'aperçu affiche votre code dès que l'adresse est valide.
4. Facultatif : choisissez un aspect sous **Partir d'un style**, ou ouvrez l'onglet **Design** pour modifier les couleurs, les points, les yeux, le logo et le cadre.
5. Cliquez sur l'icône de téléchargement au-dessus de l'aperçu, ou appuyez sur <kbd>D</kbd>. Choisissez un format et une taille, puis téléchargez.

Sous l'adresse, QRdx indique où les scans s'ouvriront, par exemple « Les scans s'ouvrent sur example.com ». Vérifiez-le avant d'imprimer.

## Avant d'imprimer [#before-you-print]

Vérifiez le **Score de scan** sous l'aperçu. Un score de 85 ou plus est excellent. En dessous de 65, corrigez les contrôles marqués d'une croix. Voir [Vérifier un design avec le score de scan](/docs/help/designing/scan-score).

Scannez ensuite le code avec votre propre téléphone.

## Les codes du Playground sont statiques [#codes-from-the-playground-are-static]

Un code que vous téléchargez depuis le Playground est **statique** : le lien est stocké dans le code lui-même. Il fonctionne indéfiniment, mais vous ne pouvez plus le modifier après l'impression.

Si vous pensez devoir changer le lien plus tard, créez plutôt un QR code dynamique. Voir [Statique ou dynamique](/docs/help/getting-started/static-vs-dynamic).
