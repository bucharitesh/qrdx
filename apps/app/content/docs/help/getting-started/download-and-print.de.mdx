## Download [#download]

Klicke im [Playground](/playground) auf das Download-Symbol über der Vorschau oder drücke <kbd>D</kbd>. Der Dialog **QR-Code herunterladen** öffnet sich mit zwei Tabs.

### Bilddatei [#image-file]

Nutze diese Option für Bildschirme, E-Mail, Folien und die meisten Drucke.

1. Wähle ein Format: **PNG**, **JPG**, **WebP**, **SVG**, **PDF** oder **EPS**.
2. Wähle eine Größe: E-Mail (200 px), Web (400 px), Social (800 px), Druck (1200 px), Poster (2000 px) oder gib eine eigene Größe ein.
3. Aktiviere **Transparenter Hintergrund**, falls du ihn brauchst. JPG kann nicht transparent sein.
4. Klicke unten auf die Download-Schaltfläche.

### Druckfertig [#print-ready]

Nutze diese Option, wenn eine Druckerei eine Datei verlangt.

1. Lege die **Breite des Codes** in Millimetern oder Zoll fest.
2. Wähle **RGB** oder **CMYK**. Druckereien wollen meist CMYK.
3. Füge **3 mm Beschnitt** hinzu, wenn der Hintergrund bis zum Seitenrand reicht, damit beim Zuschneiden nie ein weißer Rand bleibt.
4. Aktiviere **Schnittmarken**, um zu zeigen, wo geschnitten wird. Schnittmarken werden zu PDFs hinzugefügt.
5. Lade eine **PDF**-, **SVG**- oder **EPS**-Datei herunter.

## Welches Format du wählen solltest [#which-format-to-choose]

- **PNG**, **JPG** oder **WebP**: Pixelbilder für Bildschirme, E-Mail und Dokumente. WebP hat dieselben Pixel wie PNG in einer kleineren Datei, was sich für Websites eignet.
- **SVG**, **EPS** oder ein **PDF** aus **Druckfertig**: Vektordateien, die in jeder Größe scharf bleiben. Druckereien bevorzugen sie. Ein PDF aus dem Tab **Bilddatei** enthält ein Bild des Codes, also nutze für alles, was du druckst, „Druckfertig“.

## Wie groß du drucken solltest [#how-big-to-print]

Mach den Code etwa ein Zehntel so breit wie die Scan-Entfernung.

- Eine Visitenkarte, die aus 20 cm Entfernung gelesen wird, braucht einen Code von etwa 2 cm Breite.
- Ein Poster, das aus 1 m Entfernung gelesen wird, braucht einen Code von etwa 10 cm Breite.

Codes mit mehr Inhalt brauchen mehr Platz. Der [Druckgrößen-Rechner](/tools/print-size) ermittelt die Mindestgröße für dich.

## Lass einen freien Rand [#leave-a-clear-border]

Lass um den Code herum Platz frei. Scanner brauchen ihn, um den Code zu finden. Die Einstellung **Abstand** im Tab **Design** fügt ihn für dich hinzu; **Standard** (4 Module) ist die sichere Wahl.

## Vor dem Drucken testen [#test-before-you-print]

Drucke ein Exemplar und scanne es mit zwei verschiedenen Handys aus der Entfernung, aus der die Leute es scannen werden. Du kannst auch ein Foto eines gedruckten Codes in den [Scan-Checker](/tools/scan-checker) hochladen.
