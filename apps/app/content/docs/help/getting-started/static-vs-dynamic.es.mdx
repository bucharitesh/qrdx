## Códigos QR estáticos [#static-qr-codes]

Un código estático guarda tu contenido dentro del propio código: el enlace, la contraseña de Wi-Fi o la tarjeta de contacto.

- Funciona para siempre, sin cuenta y sin servidor.
- Es gratis e ilimitado.
- **No puedes cambiarlo** después de imprimirlo. Para cambiar el contenido, tienes que imprimir un código nuevo.
- Los escaneos no se cuentan.

Todo código que descargas desde el [Playground](/playground) sin hacerlo dinámico es estático.

## Códigos QR dinámicos [#dynamic-qr-codes]

Un código dinámico guarda un enlace corto, como `qrdx.dev/q/aB3xY7k`. El enlace corto redirige cada escaneo a tu destino.

- Puedes **cambiar el destino** cuando quieras, incluso después de imprimir.
- Cada escaneo se cuenta, con cuándo, dónde y en qué dispositivo.
- Puedes pausarlo, programarlo, añadirle una contraseña o enviar los escaneos a enlaces distintos.
- Necesita una cuenta gratuita de QRdx. El plan Gratis incluye 10 códigos dinámicos; Pro y Business no tienen límite.

Consulta [Crear un código QR dinámico](/docs/help/dynamic-codes/create).

## Cuál elegir [#which-to-choose]

Elige **dinámico** cuando:

- el código va en algo impreso que no puedes reemplazar fácilmente, como envases, carteles o menús;
- el enlace puede cambiar, como una oferta de temporada o un menú;
- quieres saber cuántas personas lo escanean.

Elige **estático** cuando:

- el contenido nunca cambia, como los datos de Wi-Fi o una tarjeta de contacto;
- no quieres una cuenta;
- no quieres nada entre el escaneo y tu contenido.

## Las páginas también son dinámicas [#pages-are-dynamic-too]

Una [página móvil](/docs/help/pages-and-forms/create-a-page) alojada por QRdx recibe un código dinámico. Puedes editar la página cuando quieras y el código impreso sigue funcionando.

## Los códigos dinámicos siguen funcionando [#dynamic-codes-keep-working]

Un código dinámico sigue redirigiendo si cambias a un plan inferior, cancelas o falla un pago. Consulta [Qué pasa con tus códigos si dejas de pagar](/docs/help/account-and-billing/never-hostage).
