<IfAvailable feature="nonprofitDiscounts" id="non-profit-discount" title="비영리 단체 할인">

등록된 비영리 단체와 자선 단체는 Pro 또는 Business를 월간 또는 연간 결제로 이용할 때 {facts.nonprofitDiscountPercent}% 할인을 받을 수 있습니다. 할인은 코드로 제공되며, 결제할 때 입력하면 됩니다.

코드를 요청하는 방법은 다음과 같습니다.

1. 로그인한 후 [요금제 페이지](/pricing)를 엽니다.
2. 요금제 아래 비영리 단체용 줄에서 **코드 요청하기**를 클릭해요.
3. 단체 이름과 국가, 자선 단체 또는 비영리 단체 등록부에 기재된 등록 번호(또는 공개 등록부에 있는 단체 정보 링크), 답변을 받을 이메일 주소, 원하는 요금제를 입력합니다.
4. **요청 보내기**를 클릭해요.

요청은 이메일로 QRdx 팀에 전달되며, 저희가 등록 여부를 확인합니다. 보통 며칠 안에 답변을 드립니다. 단체가 자격 요건을 충족하면 답변에 할인 코드가 포함됩니다. 결제를 완료하기 전에는 아무 금액도 청구되지 않습니다.

양식에서 요청을 보내지 못하면 같은 내용을 담아 [support@qrdx.dev](mailto:support@qrdx.dev)로 이메일을 보내 주세요.

코드를 사용하는 방법은 다음과 같습니다.

1. [요금제 페이지](/pricing)에서 **월간** 또는 **연간**를 선택하고 해당 요금제의 업그레이드 버튼을 클릭해요.
2. 결제 화면의 할인 입력란에 코드를 입력합니다. 결제하기 전에 가격이 내려갑니다.

할인은 갱신을 포함해 해당 구독의 모든 결제에 적용됩니다.

유료 요금제의 첫 결제와 마찬가지로 {facts.moneyBackDays}일 환불 보장이 적용됩니다. [환불 정책](/legal/refunds)을 참고하세요.
