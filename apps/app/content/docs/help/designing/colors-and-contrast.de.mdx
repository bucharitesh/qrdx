---
title: "Wähle Farben, die sich scannen lassen"
description: "Halte den Code dunkel und den Hintergrund hell, sorge für starken Kontrast und setze Farbverläufe mit Bedacht ein."
---

Scanner suchen nach dunklen Quadraten auf hellem Hintergrund. Die meisten Farbprobleme entstehen, weil diese Regel verletzt wird.

## Farben ändern [#change-the-colors]

Öffne im [Playground](/playground?tab=design&section=colors) den Tab **Design** und dann **Farben**.

- **Hintergrund** ist die Fläche hinter dem Code.
- **Vordergrund** färbt die kleinen Quadrate, die deine Daten enthalten.
- **Augen** färbt die drei großen Quadrate in den Ecken.
- **Punkte** färbt die Mitte jedes Eckquadrats.

Jede Farbe kann einfarbig sein oder ein linearer oder radialer Farbverlauf. Mit den Paletten unter den vier Farben stellst du alle auf einmal ein.

## Regeln für einen gut scannbaren Code [#rules-that-keep-a-code-scannable]

- **Dunkler Code, heller Hintergrund.** Helle Codes auf dunklem Hintergrund funktionieren in manchen Kamera-Apps nicht.
- **Starker Kontrast.** Strebe ein Kontrastverhältnis von mindestens 4.5:1 zwischen Code und Hintergrund an.
- **Verläufe bleiben dunkel.** Ein Farbverlauf ist in Ordnung, wenn jede Farbe darin dunkel genug gegenüber dem Hintergrund ist.
- **Schlichter Hintergrund.** Ein unruhiges Foto hinter dem Code erschwert das Lesen.

## Kontrast prüfen [#check-the-contrast]

Die Kontrastprüfung in der Symbolleiste über der Vorschau zeigt das Verhältnis für deine Farben an. Sie markiert Paare unter 4.5:1.

Der **Scan-Score** unter der Vorschau prüft ebenfalls den Kontrast, außerdem Größe, Ruhezone und Logo. Siehe [Design mit dem Scan-Score prüfen](/docs/help/designing/scan-score).
