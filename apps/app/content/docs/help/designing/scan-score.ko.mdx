Playground의 모든 디자인에는 0부터 100까지의 **스캔 점수**가 표시됩니다. 점수는 미리보기 아래에 나타나며, 예를 들어 "스캔 점수 92 · 훌륭함"처럼 표시됩니다.

## 점수의 의미 [#what-the-score-means]

- **훌륭함**(85 이상): 바로 인쇄해도 좋습니다.
- **보통**(65~84): 스캔은 되겠지만 경고를 확인해 보세요.
- **위험**(65 미만): X 표시가 있는 검사 항목을 수정하세요.
- **실패**: 테스트에서 코드가 해독되지 않았거나 대비가 너무 낮습니다. 인쇄하지 마세요.

## 고칠 부분 확인하기 [#see-what-to-fix]

점수를 클릭하세요. **스캔될까요?** 패널에 모든 검사 항목이 나열되며, 실패한 항목이 맨 위에 표시됩니다.

스캔 점수는 다음을 검사합니다.

- **해독**: 카메라처럼 흐릿하게 처리한 작은 크기에서 코드를 읽습니다.
- **대비**: 코드와 배경의 대비는 4.5:1 이상이어야 합니다.
- **밝은 배경에 어두운 코드**: 밝은 배경에 어두운 코드가 더 많은 앱에서 스캔됩니다.
- **로고 크기**: 로고는 오류 정정으로 복원할 수 있는 범위를 넘어 코드를 가리면 안 됩니다.
- **눈 모양**: 원형과 곡선형 눈은 일부 스캐너 앱에서 인식되지 않습니다.
- **여백**: 코드 주변의 빈 테두리입니다. 4모듈이 이상적입니다.

## 빠른 해결 방법 [#quick-fixes]

- 대비가 낮을 때: 코드를 더 어둡게 하거나 배경을 더 밝게 하세요. [스캔이 잘 되는 색상 선택하기](/docs/help/designing/colors-and-contrast)를 참고하세요.
- 로고가 너무 많이 가릴 때: **오류 정정**을 **높음**으로 설정하세요. [로고 추가하기](/docs/help/designing/logos)를 참고하세요.
- 눈 모양: 사각형, 둥근 사각형, 톱니바퀴 모양 눈으로 바꾸세요.
- 여백: **패딩**을 **표준** 또는 **크게**로 설정하세요.

## 인쇄된 코드 확인하기 [#check-a-printed-code]

스캔 점수는 화면상의 디자인을 테스트합니다. 이미 인쇄한 코드를 테스트하려면 사진을 찍어 [스캔 검사기](/tools/scan-checker)에 올려 주세요. 이미지는 기기 밖으로 나가지 않습니다.
