title: "Créer des QR codes dans Discord"

---

<IfAvailable feature="discordBot">

Le bot QRdx crée des QR codes directement dans Discord, sans que vous ayez besoin d'un compte QRdx. Chaque réponse affiche le code avec des boutons pour le télécharger en PNG ou en SVG, ou pour l'ouvrir dans l'[éditeur](/playground) et modifier son apparence.

</IfAvailable>

<IfAvailable feature="discordBot" id="add-the-bot" title="Ajouter le bot">

1. Ouvrez la page [Bot Discord](/integrations/discord-bot) et cliquez sur **Ajouter à Discord**.
2. Discord vous demande où l'ajouter :
   - **Votre compte :** utilisez-le dans les messages privés, les groupes privés et les serveurs dont vous faites partie.
   - **Un serveur :** tous les membres du serveur peuvent l'utiliser. Vous devez y disposer de l'autorisation **Gérer le serveur**.

Certains serveurs n'autorisent pas les applications personnelles des membres à publier pour tout le monde. Dans ce cas, les réponses du bot installé sur votre compte ne sont visibles que par vous.

</IfAvailable>

<IfAvailable feature="discordBot" id="make-a-code-with-qr" title="Créer un code avec /qr">

1. Dans n'importe quelle conversation, saisissez `/qr` et choisissez la commande dans la liste.
2. Saisissez ou collez un lien ou du texte dans **content**, puis appuyez sur Enter.

Le bot répond avec le code, son contenu comme titre, trois boutons et les menus de style décrits ci-dessous. Les boutons sont **Télécharger PNG** (1024 px), **Télécharger SVG** et **Ouvrir dans l'éditeur**. Un lien s'ouvre dans l'éditeur avec le design du code. Le texte n'est pas transmis dans le lien vers l'éditeur : collez-le vous-même.

Pour garder le code pour vous, réglez **private** sur **True**. Vous seul voyez cette réponse, et Discord la supprime lorsque vous la fermez ou rechargez l'application.

Un contenu très long peut ne pas tenir dans un seul QR code, ou être trop long pour que Discord l'affiche comme image. Le bot vous en informe par un message que vous seul pouvez voir.

</IfAvailable>

<IfAvailable feature="discordBot" id="style-your-code" title="Personnaliser votre code">

`/qr` propose trois options supplémentaires à remplir avant d'appuyer sur Enter :

| Option | Effet | Choix |
| --- | --- | --- |
| **look** | Applique l'un des designs intégrés de l'éditeur | Plain, Classic, Modern, Royal, Folio, Caffeine, Retro, Bordeaux, Blossom |
| **color** | Met tout le code dans une seule couleur sur fond blanc | Noir, Bleu, Vert, Rouge, Violet, Orange |
| **frame** | Ajoute un cadre avec la mention « Scan me » | Sans cadre, Bannière, Bannière en haut, Bulle, Polaroid |

Le style est appliqué en premier et la couleur par-dessus : **look** Royal avec **color** Bleu conserve donc les formes de Royal en bleu.

Sous chaque code se trouvent quatre menus, **Look**, **Couleur**, **Cadre** et **Logo**, avec les mêmes choix, plus les icônes de logo rapides de l'éditeur. Faites un choix et le code change sur place. Chaque modification s'appuie sur le code tel qu'il est à ce moment-là. Seule la personne qui a créé le code peut le modifier. Toute autre personne qui fait un choix reçoit une note visible par elle seule, et le code reste inchangé.

Avant qu'un code personnalisé apparaisse, QRdx le vérifie avec le même score de scan que l'éditeur ; Discord indique donc brièvement que QRdx réfléchit. Lorsqu'un design serait difficile à lire pour les téléphones, QRdx l'ajuste (couleurs plus foncées, formes plus simples ou correction d'erreurs renforcée) et l'indique sous le code. Si cela ne suffit toujours pas, généralement parce que le contenu est long, vous obtenez le code en noir sur blanc, avec une note.

**Ouvrir dans l'éditeur** ouvre l'éditeur avec le même design : couleurs, formes et cadre. L'icône du logo n'est pas transmise dans le lien ; choisissez-la à nouveau dans l'éditeur.

</IfAvailable>

<IfAvailable feature="discordBot" id="make-a-code-from-a-message" title="Créer un code à partir d'un message">

Sur ordinateur, faites un clic droit sur un message et choisissez **Applications** → **Créer un QR code**. Sur mobile, appuyez longuement sur le message puis touchez **Applications** → **Créer un QR code**.

Le code contient la première adresse web du message. Un message sans adresse devient un code de son texte. Tous les membres de la conversation voient la réponse.

Les réponses ne mentionnent ni ne notifient jamais personne, quel que soit le contenu du message.

</IfAvailable>

<IfAvailable feature="discordBot" id="privacy" title="Confidentialité">

QRdx n'enregistre pas les codes que vous créez, et le bot ne peut pas lire vos conversations. Discord transmet à QRdx ce que vous saisissez après `/qr`, ou le seul message que vous avez choisi pour **Créer un QR code**.

Le contenu et le design choisi sont intégrés au lien de l'image, et Discord charge l'image depuis l'[Image API](/docs/developers/image-api) de QRdx. Modifier le style d'un code relit les deux à partir de ce lien : QRdx n'enregistre donc pas le code pour le modifier. Comme n'importe quel lien, il peut se retrouver dans des journaux et des caches ; ne créez donc pas de codes contenant des mots de passe ou d'autres secrets.

Pour éviter qu'une personne inonde un salon, QRdx compte les codes que chaque compte Discord crée ou modifie en une minute. Il compte aussi les codes créés par l'ensemble des utilisateurs, et lorsqu'il en arrive trop en une minute, le bot indique qu'il est occupé. Aucun de ces compteurs ne conserve de contenu, et les deux expirent après cette minute.

</IfAvailable>

<IfAvailable feature="discordBot" id="remove-the-bot" title="Supprimer le bot">

- **De votre compte :** ouvrez **Paramètres utilisateur** → **Applications autorisées** et cliquez sur **Désautoriser** à côté de QRdx.
- **D'un serveur :** une personne disposant de **Gérer le serveur** ouvre **Paramètres du serveur** → **Intégrations**, choisit QRdx et le supprime.

</IfAvailable>

## Auto-hébergement [#self-hosting]

Le bot fonctionne sur votre propre instance de QRdx une fois que vous avez enregistré une application Discord et défini `DISCORD_APPLICATION_ID` et `DISCORD_PUBLIC_KEY`. Les étapes se trouvent dans [`plugins/discord/README.md`](https://github.com/qrdxinc/qrdx/tree/main/plugins/discord).
