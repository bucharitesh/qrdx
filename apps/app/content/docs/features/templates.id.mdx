Template adalah bingkai yang menempatkan kode di dalam karya seninya sendiri. Di Playground, template bukan daftar terpisah. Arrow, Standard Box, Square Border, Striked Box, Halloween, dan Dot Ring adalah kotak pilihan di grup **Classic** pada pemilih bingkai, bersama [bingkai](/docs/features/frames) lainnya, dan memilih bingkai apa pun akan menggantikan bingkai sebelumnya.

Template berbeda dari bingkai lain dalam satu hal: ukuran. Bingkai menambahkan ruang di sekitar kode, sehingga `size` adalah lebar kode dan gambar menjadi lebih besar. Template menggambar seluruh karya seninya pada `size`, dengan kode yang lebih kecil di dalamnya.

## Template bawaan [#built-in-templates]

Berikan id sebagai `templateId`. Image API menerimanya sebagai `template` dan CLI sebagai `--template`.

| `templateId` | Nama | Warna |
|--------------|------|-------|
| `Arrow` | Arrow | Warna gelap kode (`fgColor`) |
| `StandardBox` | Standard Box | `fgColor` |
| `SquareBorder` | Square Border | `fgColor` |
| `StrikedBox` | Striked Box | Warna gelapnya sendiri |
| `Halloween` | Halloween | Oranye, hijau, dan hitam miliknya sendiri |
| `DotRing` | Dot Ring | Cincinnya dalam `fgColor`, teksnya berwarna putih; keduanya dapat diubah (lihat di bawah) |

`default` tidak menggambar karya seni. Template ini hanya menggeser kode sedikit ke dalam, menjadi 95% dari `size`.

```tsx
import { QRCode } from 'qrdx';

<QRCode value="https://example.com" templateId="Arrow" fgColor="#1a56db" size={256} />
```

Warna, pola, dan logo tetap diatur lewat properti kode itu sendiri, sehingga template bekerja dengan gaya apa pun:

```tsx
<QRCode
  value="https://example.com"
  templateId="StandardBox"
  fgColor="#1a56db"
  imageSettings={{
    src: "/your-logo.png",
    width: 48,
    height: 48,
    excavate: true,
  }}
  size={512}
/>
```

## Dot Ring [#dot-ring]

Kode berbentuk bulat. Kode berada di dalam cakram titik-titik di dalam cincin gelap, dengan satu baris teks yang mengikuti cincin. Titik mana yang tampil ditentukan oleh hash dari isi kode, sehingga setiap tautan mendapat cincinnya sendiri dan tautan yang sama selalu mendapat cincin yang sama.

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  bodyPattern="circle-large"
  size={512}
/>
```

Pengaturannya ada di `customProps` (bertipe `DotRingProps`):

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  customProps={{
    customText: "Scan for the menu",
    textPosition: "bottom",
    textColor: "#fde047",
    outerCircleColor: "#1e3a8a",
  }}
  size={512}
/>
```

| Properti | Default | Catatan |
| --- | --- | --- |
| `customText` | "Scan the QR code" empat kali mengelilingi cincin | Teks di sepanjang cincin; `""` membiarkan cincin kosong. Teks yang terlalu panjang untuk cincin akan disesuaikan (lihat di bawah) |
| `textFill` | `"none"` | `"repeat"` mengulang teks mengelilingi seluruh cincin (lihat di bawah) |
| `textPosition` | `"top"` | `"top"`: di tengah bagian atas, terbaca searah jarum jam. `"bottom"`: di tengah sepanjang bagian bawah, terbaca dari kiri ke kanan |
| `textRotation` | `0` | Memutar teks mengelilingi pusat, dalam derajat |
| `textColor` | `#ffffff` | Warna teks |
| `fontFamily` | system font stack | Keluarga font CSS untuk teks |
| `fontWeight` | `900` | Ketebalan font |
| `fontSize` | `32` | Dalam gambar template berukuran 593 unit, tempat kode selebar 300. Teks panjang bisa digambar lebih kecil |
| `fontLetterSpacing` | `3.5` | Spasi tambahan antarhuruf, dalam satuan yang sama. Teks panjang dan `textFill` menyesuaikannya |
| `outerCircleColor` | `fgColor` | Warna cincin |
| `strokeWidth`, `strokeColor` | `0`, `#000000` | Garis tepi di kedua sisi cincin |
| `outerStrokeWidth`, `outerStrokeColor` | `strokeWidth`, `strokeColor` | Hanya tepi luar cincin |
| `innerStrokeWidth`, `innerStrokeColor` | `strokeWidth`, `strokeColor` | Hanya tepi dalam cincin |

Teks yang muat di cincin ditampilkan apa adanya, di tengah bagian atas atau sepanjang bagian bawah. Teks yang terlalu panjang tidak akan bertabrakan dengan awal teksnya sendiri. Huruf dirapatkan lebih dulu, lalu font diperkecil hingga setengah ukuran default (ukuran terkecil untuk label bingkai). Setelah itu teks menutup cincin dengan spasi antarkata di titik pertemuan dengan awal teks. Jika pada ukuran itu teks masih tidak muat, teks yang mengulang satu frasa mempertahankan salinan utuh sebanyak yang muat, sedangkan teks lain dipotong setelah kata utuh terakhir yang muat dan diakhiri "…".

Logo ditempatkan di tengah seperti pada kode mana pun. Tautan panjang (kode dengan lebar lebih dari 49 modul) mempertahankan pita terang di antara kode dan titik-titik, sehingga tetap dapat dipindai saat dicetak kecil.

Teksnya adalah teks SVG dengan font pilihan Anda; defaultnya adalah system font stack, sehingga tidak ada yang diunduh. Unduhan SVG dan PNG di browser memakai font milik pengguna yang melihatnya. PDF dan EPS mencetaknya dalam Helvetica Bold, jadi gunakan teks Latin-1 di sana. `getQRAsPNG` dari `qrdx/node` memerlukan font yang terpasang di server, seperti halnya label bingkai.

### Mengisi cincin [#filling-the-ring]

Frasa pendek menyisakan sebagian cincin kosong. Atur `textFill: "repeat"` untuk mengulangnya sebanyak yang muat, dengan jarak yang diratakan sehingga cincin tertutup dengan celah yang sama seperti di antara salinan teks:

```tsx
<QRCode
  value="https://example.com/docs"
  templateId="DotRing"
  customProps={{ customText: "Read the docs *", textFill: "repeat" }}
  size={512}
/>
```

Tuliskan frasa satu kali saja. Teks yang sudah mengulang suatu frasa, seperti `"Make your own * Make your own *"`, dibaca sebagai frasa tersebut, sehingga mengisi cincin dengan cara yang sama.

## Template adalah spesifikasi bingkai [#templates-are-frame-specs]

Karya seni Arrow, Standard Box, Square Border, Striked Box, dan Halloween adalah [spesifikasi bingkai](/docs/features/frames#frame-specs), dengan format JSON yang sama seperti bingkai lainnya, digambar oleh mesin yang sama. `getTemplate(id).spec` mengembalikannya. Gunakan sebagai bingkai bila Anda menginginkan ukuran bingkai (kode mempertahankan ukurannya dan karya seni membesar di sekelilingnya) serta opsi warna bingkai:

```tsx
import { getTemplate, QRCode } from 'qrdx';

const spec = getTemplate('Arrow')?.spec;

<QRCode
  value="https://example.com"
  frame={spec && { style: 'custom', spec, color: '#1a56db' }}
  size={256}
/>
```

Dot Ring tidak memiliki spesifikasi: titik-titiknya berasal dari isi kode, sehingga digambar lewat kode (lihat [Bingkai yang Anda gambar lewat kode](#frames-you-draw-in-code)).

`templateId` menggambar karya seni yang sama seperti sebelumnya. Desain tersimpan, URL gambar, perintah CLI, dan kode yang memakai id template tampil sama seperti biasanya.

## Registri template [#template-registry]

```tsx
import { getAllTemplates, getTemplate, getTemplateIds } from 'qrdx';

getTemplateIds(); // ['default', 'Arrow', 'StandardBox', ...]
getAllTemplates(); // every TemplateDefinition, with its id and name
getTemplate('Halloween'); // one by id
```

## Bingkai yang Anda gambar lewat kode [#frames-you-draw-in-code]

Spesifikasi bingkai menggambarkan karya seni yang tetap. Bila karya seni harus dihitung, tulis `TemplateDefinition` lalu berikan sebagai `customTemplate`. `wrapper`-nya menerima kode sebagai `children` dan mengembalikan SVG yang akan digambar. Ia menggambar pada kanvas 300 kali 300, dan kode juga tiba dalam ukuran itu, jadi perkecil kode agar ada ruang untuk karya seni Anda. `props` membawa `fgColor` dan `bgColor` kode, dan argumen ketiga berisi `url` dan `pixelSize` kode.

Contoh ini menggambar cincin di sekitar kode:

```tsx
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg viewBox="0 0 300 300" width="300" height="300" xmlns="http://www.w3.org/2000/svg">
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

<QRCode
  value="https://example.com"
  customTemplate={ringTemplate}
  fgColor="#1a56db"
  size={256}
/>
```

Jaga agar kode cukup besar untuk dipindai dari jarak tempat orang memegang ponsel, dan sisakan celah terang antara kode dan karya seni Anda. Periksa hasilnya dengan [skor pemindaian](/docs/features/frames#will-it-scan).
