Template adalah bingkai yang menyesuaikan kode di dalam karya seninya sendiri. Di Playground, template bukan daftar tersendiri. Arrow, Standard Box, Square Border, Striked Box, Halloween, dan Dot Ring adalah ubin di grup **Classic** pada pemilih bingkai, bersama [bingkai](/docs/features/frames) lainnya, dan memilih bingkai apa pun akan menggantikan bingkai sebelumnya.

Template berbeda dari bingkai lain dalam satu hal: ukuran. Bingkai menambahkan ruang di sekitar kode, sehingga `size` adalah lebar kode dan gambar menjadi lebih besar. Template menggambar seluruh karya seninya pada `size`, dengan kode yang lebih kecil di dalamnya.

## Template bawaan [#built-in-templates]

Berikan id sebagai `templateId`. Image API menerimanya sebagai `template` dan CLI sebagai `--template`.

| `templateId` | Nama | Warna |
|--------------|------|-------|
| `Arrow` | Arrow | Warna gelap kode (`fgColor`) |
| `StandardBox` | Standard Box | `fgColor` |
| `SquareBorder` | Square Border | `fgColor` |
| `StrikedBox` | Striked Box | Warna gelapnya sendiri |
| `Halloween` | Halloween | Oranye, hijau, dan hitam miliknya sendiri |
| `DotRing` | Dot Ring | Cincinnya dalam `fgColor`, teksnya berwarna putih; keduanya dapat diubah (lihat di bawah) |

`default` tidak menggambar karya seni. Template ini hanya memberi sedikit inset pada kode, menjadi 95% dari `size`.

```tsx
import { QRCode } from 'qrdx';

<QRCode value="https://example.com" templateId="Arrow" fgColor="#1a56db" size={256} />
```

Warna, pola, dan logo tetap diatur lewat prop kode itu sendiri, sehingga template bekerja dengan gaya apa pun:

```tsx
<QRCode
  value="https://example.com"
  templateId="StandardBox"
  fgColor="#1a56db"
  imageSettings={{
    src: "/your-logo.png",
    width: 48,
    height: 48,
    excavate: true,
  }}
  size={512}
/>
```

## Dot Ring [#dot-ring]

Kode berbentuk bulat. Kode berada di dalam cakram titik-titik di dalam cincin gelap, dengan satu baris teks yang mengikuti cincin. Titik mana yang tampil ditentukan dari hash isi kode, sehingga setiap tautan mendapat cincin tersendiri dan tautan yang sama selalu mendapat cincin yang sama.

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  bodyPattern="circle-large"
  size={512}
/>
```

Pengaturannya ditulis di `customProps` (bertipe `DotRingProps`):

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  customProps={{
    customText: "Scan for the menu",
    textPosition: "bottom",
    textColor: "#fde047",
    outerCircleColor: "#1e3a8a",
  }}
  size={512}
/>
```

| Prop | Default | Catatan |
| --- | --- | --- |
| `customText` | "Scan the QR code" empat kali mengelilingi cincin | Teks di sepanjang cincin. Huruf yang tidak muat di sekelilingnya dihilangkan; `""` membiarkan cincin kosong |
| `textPosition` | `"top"` | `"top"`: di tengah bagian atas, dibaca searah jarum jam. `"bottom"`: di tengah bagian bawah, dibaca dari kiri ke kanan |
| `textRotation` | `0` | Memutar teks mengelilingi pusat, dalam derajat |
| `textColor` | `#ffffff` | Warna teks |
| `fontFamily` | susunan font sistem | Keluarga font CSS untuk teks |
| `fontWeight` | `900` | Ketebalan font |
| `fontSize` | `32` | Dalam gambar template berukuran 593 unit, tempat kode selebar 300 |
| `fontLetterSpacing` | `3.5` | Jarak tambahan antarhuruf, dalam satuan yang sama |
| `outerCircleColor` | `fgColor` | Warna cincin |
| `strokeWidth`, `strokeColor` | `0`, `#000000` | Garis tepi di sepanjang kedua sisi cincin |
| `outerStrokeWidth`, `outerStrokeColor` | `strokeWidth`, `strokeColor` | Hanya tepi luar cincin |
| `innerStrokeWidth`, `innerStrokeColor` | `strokeWidth`, `strokeColor` | Hanya tepi dalam cincin |

Logo diletakkan di tengah seperti pada kode mana pun. Tautan panjang (kode dengan lebar lebih dari 49 modul) mempertahankan pita terang di antara kode dan titik-titik, sehingga tetap dapat dipindai saat dicetak kecil.

Teksnya adalah teks SVG dengan font pilihan Anda; defaultnya adalah susunan font sistem, jadi tidak ada yang diunduh. Unduhan SVG dan PNG di browser memakai font milik pengguna yang melihatnya. PDF dan EPS mencetaknya dalam Helvetica Bold, jadi gunakan teks Latin-1 di sana. `getQRAsPNG` dari `qrdx/node` memerlukan font yang terpasang di server, seperti halnya label bingkai.

## Template adalah spesifikasi bingkai [#templates-are-frame-specs]

Karya seni Arrow, Standard Box, Square Border, Striked Box, dan Halloween adalah [spesifikasi bingkai](/docs/features/frames#frame-specs), dengan format JSON yang sama seperti bingkai lainnya, digambar oleh mesin yang sama. `getTemplate(id).spec` mengembalikannya. Gunakan sebagai bingkai bila Anda menginginkan ukuran bingkai (kode mempertahankan ukurannya dan karya seni membesar di sekelilingnya) serta opsi warna bingkai:

```tsx
import { getTemplate, QRCode } from 'qrdx';

const spec = getTemplate('Arrow')?.spec;

<QRCode
  value="https://example.com"
  frame={spec && { style: 'custom', spec, color: '#1a56db' }}
  size={256}
/>
```

Dot Ring tidak punya spesifikasi: titik-titiknya berasal dari isi kode, sehingga digambar lewat kode (lihat [Bingkai yang Anda gambar lewat kode](#frames-you-draw-in-code)).

`templateId` menggambar karya seni yang sama seperti sebelumnya. Desain tersimpan, URL gambar, perintah CLI, dan kode yang memakai id template tampil sama seperti biasa.

## Registri template [#template-registry]

```tsx
import { getAllTemplates, getTemplate, getTemplateIds } from 'qrdx';

getTemplateIds(); // ['default', 'Arrow', 'StandardBox', ...]
getAllTemplates(); // every TemplateDefinition, with its id and name
getTemplate('Halloween'); // one by id
```

## Bingkai yang Anda gambar lewat kode [#frames-you-draw-in-code]

Spesifikasi bingkai menjelaskan karya seni yang tetap. Bila karya seni harus dihitung, tulis `TemplateDefinition` dan berikan sebagai `customTemplate`. `wrapper`-nya menerima kode sebagai `children` dan mengembalikan SVG yang akan digambar. Ia menggambar pada kanvas 300 kali 300, dan kode juga tiba dengan ukuran itu, jadi perkecil agar tersisa ruang untuk karya seni Anda. `props` membawa `fgColor` dan `bgColor` kode, dan argumen ketiga berisi `url` dan `pixelSize` kode.

Contoh ini menggambar cincin di sekitar kode:

```tsx
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg viewBox="0 0 300 300" width="300" height="300" xmlns="http://www.w3.org/2000/svg">
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

<QRCode
  value="https://example.com"
  customTemplate={ringTemplate}
  fgColor="#1a56db"
  size={256}
/>
```

Jaga agar kode cukup besar untuk dipindai dari jarak tempat orang memegang ponsel mereka, dan sisakan celah terang antara kode dan karya seni Anda. Periksa hasilnya dengan [skor pemindaian](/docs/features/frames#will-it-scan).
