模板是一种把二维码嵌入自身图案中的边框。在 Playground 中，模板并不是单独的列表。Arrow、Standard Box、Square Border、Striked Box、Halloween 和 Dot Ring 都是边框选择器 **Classic** 分组里的图块，与其他[边框](/docs/features/frames)并列，选择任何一个边框都会替换之前选的那个。

模板与其他边框只有一点不同：尺寸。边框会在二维码周围增加空白，所以 `size` 是二维码的宽度，图像会随之变大。模板则以 `size` 绘制整个图案，二维码在其中会更小。

## 内置模板 [#built-in-templates]

将 id 作为 `templateId` 传入。Image API 中对应的参数是 `template`，CLI 中是 `--template`。

| `templateId` | 名称 | 颜色 |
|--------------|------|-------|
| `Arrow` | Arrow | 二维码的深色（`fgColor`） |
| `StandardBox` | Standard Box | `fgColor` |
| `SquareBorder` | Square Border | `fgColor` |
| `StrikedBox` | Striked Box | 自带的深色 |
| `Halloween` | Halloween | 自带的橙色、绿色和黑色 |
| `DotRing` | Dot Ring | 圆环用 `fgColor`，文字为白色；两者都可以更改（见下文） |

`default` 不绘制任何图案，只是把二维码略微内缩到 `size` 的 95%。

```tsx
import { QRCode } from 'qrdx';

<QRCode value="https://example.com" templateId="Arrow" fgColor="#1a56db" size={256} />
```

颜色、图案样式和徽标仍由二维码自身的属性控制，因此模板可以搭配任意样式使用：

```tsx
<QRCode
  value="https://example.com"
  templateId="StandardBox"
  fgColor="#1a56db"
  imageSettings={{
    src: "/your-logo.png",
    width: 48,
    height: 48,
    excavate: true,
  }}
  size={512}
/>
```

## Dot Ring [#dot-ring]

圆形二维码。二维码位于深色圆环内的点阵圆盘中，圆环上沿环排布一行文字。显示哪些点由二维码内容的哈希值决定，所以每个链接都有专属的圆环，同一个链接始终得到同样的圆环。

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  bodyPattern="circle-large"
  size={512}
/>
```

相关设置放在 `customProps` 中（类型为 `DotRingProps`）：

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  customProps={{
    customText: "Scan for the menu",
    textPosition: "bottom",
    textColor: "#fde047",
    outerCircleColor: "#1e3a8a",
  }}
  size={512}
/>
```

| 属性 | 默认值 | 说明 |
| --- | --- | --- |
| `customText` | 重复四圈的 “Scan the QR code” | 沿圆环排布的文字；`""` 表示圆环上不放文字。文字过长时会自动适配圆环（见下文） |
| `textFill` | `"none"` | `"repeat"` 会让文字重复排满整个圆环（见下文） |
| `textPosition` | `"top"` | `"top"`：在顶部居中，顺时针阅读。`"bottom"`：沿底部居中，从左到右阅读 |
| `textRotation` | `0` | 让文字绕中心旋转，单位为度 |
| `textColor` | `#ffffff` | 文字颜色 |
| `fontFamily` | 系统字体栈 | 文字的 CSS 字体族 |
| `fontWeight` | `900` | 字重 |
| `fontSize` | `32` | 以模板 593 单位的绘图为准，其中二维码宽 300。较长的文字可能会以更小的字号绘制 |
| `fontLetterSpacing` | `3.5` | 字母之间的额外间距，单位相同。长文字和 `textFill` 会对其进行调整 |
| `outerCircleColor` | `fgColor` | 圆环颜色 |
| `strokeWidth`, `strokeColor` | `0`, `#000000` | 圆环两侧边缘的描边 |
| `outerStrokeWidth`, `outerStrokeColor` | `strokeWidth`, `strokeColor` | 仅圆环外缘 |
| `innerStrokeWidth`, `innerStrokeColor` | `strokeWidth`, `strokeColor` | 仅圆环内缘 |

能放进圆环的文字按原样排布，在顶部居中或沿底部排列。过长的文字不会与自己的开头相接。系统会先缩小字母间距，再缩小字号，最小缩到默认字号的一半（这也是边框标签允许的最小字号）。随后，文字会在与开头相接处留出一个词间距，让圆环闭合。如果在该字号下仍然放不下，就会在能完整放下的最后一个词之后截断。

与任何二维码一样，徽标放在中间。长链接（宽度超过 49 个模块的二维码）会在二维码和点阵之间保留一圈浅色带，这样即使印得很小也能扫描。

文字是 SVG 文本，使用你选择的字体；默认是系统字体栈，因此不会下载任何字体。在浏览器中下载 SVG 和 PNG 时使用查看者的字体。PDF 和 EPS 会以 Helvetica Bold 打印文字，所以这两种格式请使用 Latin-1 文本。`qrdx/node` 中的 `getQRAsPNG` 需要服务器上安装有字体，边框标签也是如此。

### 填满圆环 [#filling-the-ring]

较短的短语会让圆环的一部分留空。设置 `textFill: "repeat"`，可以让短语尽可能多次地重复，并均匀调整间距，使圆环闭合处的间隔与各份文字之间的间隔相同：

```tsx
<QRCode
  value="https://example.com/docs"
  templateId="DotRing"
  customProps={{ customText: "Read the docs *", textFill: "repeat" }}
  size={512}
/>
```

短语只需给出一次。已经重复了某个短语的文字，比如 `"Make your own * Make your own *"`，会被识别为那个短语，因此填满圆环的方式相同。

## 模板就是边框规范 [#templates-are-frame-specs]

Arrow、Standard Box、Square Border、Striked Box 和 Halloween 的图案是一份[边框规范](/docs/features/frames#frame-specs)，与其他所有边框使用相同的 JSON 格式，由同一个引擎绘制。`getTemplate(id).spec` 会返回它。如果你想要边框式的尺寸（二维码保持原有大小，图案在其周围扩展）以及边框的颜色选项，就把它当作边框使用：

```tsx
import { getTemplate, QRCode } from 'qrdx';

const spec = getTemplate('Arrow')?.spec;

<QRCode
  value="https://example.com"
  frame={spec && { style: 'custom', spec, color: '#1a56db' }}
  size={256}
/>
```

Dot Ring 没有规范：它的点阵由二维码内容生成，因此在代码中绘制（参见[在代码中绘制边框](#frames-you-draw-in-code)）。

`templateId` 绘制的图案与之前相同。使用模板 id 的已保存设计、图像 URL、CLI 命令和代码，外观都与以往一致。

## 模板注册表 [#template-registry]

```tsx
import { getAllTemplates, getTemplate, getTemplateIds } from 'qrdx';

getTemplateIds(); // ['default', 'Arrow', 'StandardBox', ...]
getAllTemplates(); // every TemplateDefinition, with its id and name
getTemplate('Halloween'); // one by id
```

## 在代码中绘制边框 [#frames-you-draw-in-code]

边框规范描述的是固定的图案。如果图案需要计算生成，就编写一个 `TemplateDefinition`，并将它作为 `customTemplate` 传入。它的 `wrapper` 会以 `children` 接收二维码，并返回要绘制的 SVG。绘制在 300×300 的画布上进行，二维码也以该尺寸传入，因此请先缩小它，为你的图案留出空间。`props` 携带二维码的 `fgColor` 和 `bgColor`，第三个参数包含二维码的 `url` 和 `pixelSize`。

下面的例子在二维码周围画了一个圆环：

```tsx
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg viewBox="0 0 300 300" width="300" height="300" xmlns="http://www.w3.org/2000/svg">
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

<QRCode
  value="https://example.com"
  customTemplate={ringTemplate}
  fgColor="#1a56db"
  size={256}
/>
```

请让二维码保持足够大，确保人们在手机所处的距离上也能扫描，并在二维码与你的图案之间留出一道浅色间隙。用[扫描评分](/docs/features/frames#will-it-scan)检查结果。
