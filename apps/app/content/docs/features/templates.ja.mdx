テンプレートは、自身のアートワークの中にコードをはめ込むフレームです。Playground では、テンプレートは別のリストになっていません。Arrow、Standard Box、Square Border、Striked Box、Halloween、Dot Ring は、フレームピッカーの **Classic** グループにあるタイルで、他の[フレーム](/docs/features/frames)と並んでいます。どれかのフレームを選ぶと、それまでのフレームは置き換わります。

テンプレートが他のフレームと異なる点はサイズです。フレームはコードの周囲に余白を加えるため、`size` はコードの幅となり、画像は大きくなります。テンプレートはアートワーク全体を `size` で描き、コードはその内側で小さくなります。

## 組み込みテンプレート [#built-in-templates]

ID を `templateId` として渡します。Image API では `template`、CLI では `--template` として指定します。

| `templateId` | 名前 | 色 |
|--------------|------|-------|
| `Arrow` | Arrow | コードの濃い色（`fgColor`） |
| `StandardBox` | Standard Box | `fgColor` |
| `SquareBorder` | Square Border | `fgColor` |
| `StrikedBox` | Striked Box | テンプレート固有の濃い色 |
| `Halloween` | Halloween | テンプレート固有のオレンジ、緑、黒 |
| `DotRing` | Dot Ring | リングは `fgColor`、テキストは白。どちらも変更できます（後述） |

`default` はアートワークを描きません。コードを `size` の 95% にわずかに内側へ寄せるだけです。

```tsx
import { QRCode } from 'qrdx';

<QRCode value="https://example.com" templateId="Arrow" fgColor="#1a56db" size={256} />
```

色、パターン、ロゴはコード自体のプロパティで指定するので、テンプレートはどのスタイルでも使えます。

```tsx
<QRCode
  value="https://example.com"
  templateId="StandardBox"
  fgColor="#1a56db"
  imageSettings={{
    src: "/your-logo.png",
    width: 48,
    height: 48,
    excavate: true,
  }}
  size={512}
/>
```

## Dot Ring [#dot-ring]

円形のコードです。コードは濃いリングの内側にあるドットの円盤に置かれ、リングに沿ってテキストが一行配置されます。どのドットを表示するかはコード内容のハッシュで決まるため、リンクごとに固有のリングになり、同じリンクなら常に同じリングになります。

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  bodyPattern="circle-large"
  size={512}
/>
```

設定は `customProps`（型は `DotRingProps`）に指定します。

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  customProps={{
    customText: "Scan for the menu",
    textPosition: "bottom",
    textColor: "#fde047",
    outerCircleColor: "#1e3a8a",
  }}
  size={512}
/>
```

| プロパティ | デフォルト | 補足 |
| --- | --- | --- |
| `customText` | 「Scan the QR code」をリング沿いに 4 回 | リングに沿うテキスト。`""` にするとリングは空になります。リングに収まらない長いテキストは調整されます（後述） |
| `textFill` | `"none"` | `"repeat"` にするとテキストをリング全体に繰り返します（後述） |
| `textPosition` | `"top"` | `"top"`：上部の中央に、時計回りに読む向きで配置します。`"bottom"`：下部に沿って中央に、左から右へ読む向きで配置します |
| `textRotation` | `0` | テキストを中心まわりに回転させます（単位は度） |
| `textColor` | `#ffffff` | テキストの色 |
| `fontFamily` | システムフォントスタック | テキストの CSS フォントファミリー |
| `fontWeight` | `900` | フォントの太さ |
| `fontSize` | `32` | コードの幅が 300 となる、テンプレートの 593 単位の描画上での値です。長いテキストは小さく描かれることがあります |
| `fontLetterSpacing` | `3.5` | 文字間の追加スペース（同じ単位）。長いテキストや `textFill` により調整されます |
| `outerCircleColor` | `fgColor` | リングの色 |
| `strokeWidth`, `strokeColor` | `0`, `#000000` | リングの両縁に沿う線 |
| `outerStrokeWidth`, `outerStrokeColor` | `strokeWidth`, `strokeColor` | リングの外縁のみ |
| `innerStrokeWidth`, `innerStrokeColor` | `strokeWidth`, `strokeColor` | リングの内縁のみ |

リングに収まるテキストは、指定どおりに上部の中央または下部に沿って配置されます。収まらない長いテキストが、自身の先頭に重なることはありません。まず文字間が詰められ、次にフォントがデフォルトサイズの半分まで小さくなります（フレームのラベルで使える最小サイズです）。そのうえで、テキストの終わりと先頭がつながる位置に単語間のスペースを入れてリングを閉じます。それでもそのサイズで収まらない場合は、収まる最後の単語の後ろで切り捨てられます。

ロゴは、他のコードと同様に中央へ配置できます。長いリンク（幅が 49 モジュールを超えるコード）では、小さく印刷してもスキャンできるように、コードとドットの間に明るい帯が残ります。

テキストは、選んだフォントによる SVG テキストです。デフォルトはシステムフォントスタックなので、ダウンロードされるフォントはありません。ブラウザでの SVG と PNG のダウンロードには、閲覧している環境のフォントが使われます。PDF と EPS では Helvetica Bold で出力されるため、Latin-1 のテキストを使ってください。`qrdx/node` の `getQRAsPNG` では、フレームのラベルと同様に、サーバーにフォントがインストールされている必要があります。

### リングを埋める [#filling-the-ring]

短いフレーズでは、リングの一部が空いたままになります。`textFill: "repeat"` を設定すると、収まる回数だけフレーズを繰り返します。間隔は均等に調整され、リングは各コピーの間と同じ間隔で閉じます。

```tsx
<QRCode
  value="https://example.com/docs"
  templateId="DotRing"
  customProps={{ customText: "Read the docs *", textFill: "repeat" }}
  size={512}
/>
```

フレーズは 1 回分だけ指定してください。`"Make your own * Make your own *"` のようにすでにフレーズを繰り返しているテキストは、そのフレーズとして扱われるため、同じようにリングを埋めます。

## テンプレートはフレーム仕様です [#templates-are-frame-specs]

Arrow、Standard Box、Square Border、Striked Box、Halloween のアートワークは、他のすべてのフレームと同じ JSON 形式の[フレーム仕様](/docs/features/frames#frame-specs)で、同じエンジンによって描画されます。`getTemplate(id).spec` でその仕様を取得できます。フレームのサイズの扱い（コードはサイズを保ち、アートワークがその周囲に広がる）とフレームの色オプションを使いたい場合は、これをフレームとして使います。

```tsx
import { getTemplate, QRCode } from 'qrdx';

const spec = getTemplate('Arrow')?.spec;

<QRCode
  value="https://example.com"
  frame={spec && { style: 'custom', spec, color: '#1a56db' }}
  size={256}
/>
```

Dot Ring にはフレーム仕様がありません。ドットはコードの内容から決まるため、コードで描画します（[コードで描くフレーム](#frames-you-draw-in-code)を参照）。

`templateId` は、従来と同じアートワークを描きます。テンプレート ID を使用している保存済みのデザイン、画像 URL、CLI コマンド、コードの見た目は、これまでと変わりません。

## テンプレートレジストリ [#template-registry]

```tsx
import { getAllTemplates, getTemplate, getTemplateIds } from 'qrdx';

getTemplateIds(); // ['default', 'Arrow', 'StandardBox', ...]
getAllTemplates(); // every TemplateDefinition, with its id and name
getTemplate('Halloween'); // one by id
```

## コードで描くフレーム [#frames-you-draw-in-code]

フレーム仕様は固定のアートワークを記述するものです。アートワークを計算で求める必要がある場合は、`TemplateDefinition` を書いて `customTemplate` として渡します。その `wrapper` はコードを `children` として受け取り、描画する SVG を返します。描画は 300 × 300 のキャンバス上で行われ、コードも同じサイズで渡されるため、アートワークの余地を残すように縮小してください。`props` にはコードの `fgColor` と `bgColor` が入り、第 3 引数にはコードの `url` と `pixelSize` が入ります。

次の例は、コードの周囲にリングを描きます。

```tsx
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg viewBox="0 0 300 300" width="300" height="300" xmlns="http://www.w3.org/2000/svg">
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

<QRCode
  value="https://example.com"
  customTemplate={ringTemplate}
  fgColor="#1a56db"
  size={256}
/>
```

コードは、人がスマートフォンを構える位置からスキャンできる大きさに保ち、アートワークとの間に明るい余白を残してください。結果は[スキャンスコア](/docs/features/frames#will-it-scan)で確認できます。
