टेम्पलेट एक ऐसा फ़्रेम है जो कोड को अपनी आर्टवर्क के अंदर फ़िट करता है। Playground में टेम्पलेट कोई अलग सूची नहीं हैं। Arrow, Standard Box, Square Border, Striked Box, Halloween और Dot Ring फ़्रेम पिकर के **Classic** ग्रुप में टाइल के रूप में मिलते हैं, बाकी [फ़्रेम](/docs/features/frames) के बगल में। कोई भी फ़्रेम चुनने पर पहले वाला फ़्रेम बदल जाता है।

टेम्पलेट बाकी फ़्रेम से एक बात में अलग हैं: साइज़। फ़्रेम कोड के चारों ओर जगह जोड़ता है, इसलिए `size` कोड की चौड़ाई होती है और इमेज बड़ी हो जाती है। टेम्पलेट अपनी पूरी आर्टवर्क `size` पर बनाता है, और कोड उसके अंदर छोटा रहता है।

## बिल्ट-इन टेम्पलेट [#built-in-templates]

id को `templateId` के रूप में पास करें। Image API में इसे `template` और CLI में `--template` के रूप में लिया जाता है।

| `templateId` | नाम | रंग |
|--------------|------|-------|
| `Arrow` | Arrow | कोड का गहरा रंग (`fgColor`) |
| `StandardBox` | Standard Box | `fgColor` |
| `SquareBorder` | Square Border | `fgColor` |
| `StrikedBox` | Striked Box | अपना गहरा रंग |
| `Halloween` | Halloween | अपने नारंगी, हरे और काले रंग |
| `DotRing` | Dot Ring | रिंग `fgColor` में, टेक्स्ट सफ़ेद में; दोनों बदले जा सकते हैं (नीचे देखें) |

`default` कोई आर्टवर्क नहीं बनाता। यह कोड को बस थोड़ा अंदर की ओर रखता है, `size` के 95% पर।

```tsx
import { QRCode } from 'qrdx';

<QRCode value="https://example.com" templateId="Arrow" fgColor="#1a56db" size={256} />
```

रंग, पैटर्न और लोगो कोड के अपने props पर ही रहते हैं, इसलिए टेम्पलेट किसी भी स्टाइल के साथ काम करता है:

```tsx
<QRCode
  value="https://example.com"
  templateId="StandardBox"
  fgColor="#1a56db"
  imageSettings={{
    src: "/your-logo.png",
    width: 48,
    height: 48,
    excavate: true,
  }}
  size={512}
/>
```

## Dot Ring [#dot-ring]

एक गोल कोड। कोड डॉट्स की एक डिस्क में बैठता है जो एक गहरी रिंग के अंदर है, और रिंग के साथ-साथ टेक्स्ट की एक लाइन लगी होती है। कौन से डॉट्स दिखेंगे, यह कोड के कंटेंट के हैश से तय होता है, इसलिए हर link को अपनी अलग रिंग मिलती है और एक ही link को हमेशा वही रिंग मिलती है।

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  bodyPattern="circle-large"
  size={512}
/>
```

इसकी सेटिंग `customProps` में जाती हैं (टाइप `DotRingProps`):

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  customProps={{
    customText: "Scan for the menu",
    textPosition: "bottom",
    textColor: "#fde047",
    outerCircleColor: "#1e3a8a",
  }}
  size={512}
/>
```

| Prop | डिफ़ॉल्ट | नोट्स |
| --- | --- | --- |
| `customText` | "Scan the QR code" चार बार पूरी रिंग में | रिंग के साथ लगा टेक्स्ट। जो अक्षर रिंग में नहीं समाते, वे छोड़ दिए जाते हैं; `""` रिंग को खाली छोड़ देता है |
| `textPosition` | `"top"` | `"top"`: ऊपर बीच में, घड़ी की दिशा में पढ़ा जाता है। `"bottom"`: नीचे बीच में, बाएँ से दाएँ पढ़ा जाता है |
| `textRotation` | `0` | टेक्स्ट को केंद्र के चारों ओर घुमाता है, डिग्री में |
| `textColor` | `#ffffff` | टेक्स्ट का रंग |
| `fontFamily` | सिस्टम फ़ॉन्ट स्टैक | टेक्स्ट की CSS फ़ॉन्ट फ़ैमिली |
| `fontWeight` | `900` | फ़ॉन्ट वेट |
| `fontSize` | `32` | टेम्पलेट की 593 यूनिट की ड्रॉइंग में, जहाँ कोड 300 चौड़ा होता है |
| `fontLetterSpacing` | `3.5` | अक्षरों के बीच अतिरिक्त जगह, उन्हीं यूनिट में |
| `outerCircleColor` | `fgColor` | रिंग का रंग |
| `strokeWidth`, `strokeColor` | `0`, `#000000` | रिंग के दोनों किनारों पर एक स्ट्रोक |
| `outerStrokeWidth`, `outerStrokeColor` | `strokeWidth`, `strokeColor` | सिर्फ़ रिंग का बाहरी किनारा |
| `innerStrokeWidth`, `innerStrokeColor` | `strokeWidth`, `strokeColor` | सिर्फ़ रिंग का भीतरी किनारा |

लोगो किसी भी कोड की तरह बीच में लगता है। लंबे link (जिन कोड की चौड़ाई 49 मॉड्यूल से ज़्यादा हो) में कोड और डॉट्स के बीच एक हल्की पट्टी रहती है, ताकि छोटे प्रिंट में भी वे स्कैन हो सकें।

टेक्स्ट आपके चुने फ़ॉन्ट में SVG टेक्स्ट होता है; डिफ़ॉल्ट सिस्टम फ़ॉन्ट स्टैक है, इसलिए कुछ भी डाउनलोड नहीं होता। ब्राउज़र में SVG और PNG डाउनलोड देखने वाले के फ़ॉन्ट इस्तेमाल करते हैं। PDF और EPS इसे Helvetica Bold में प्रिंट करते हैं, इसलिए वहाँ Latin-1 टेक्स्ट इस्तेमाल करें। `qrdx/node` का `getQRAsPNG` चलाने के लिए सर्वर पर फ़ॉन्ट इंस्टॉल होना ज़रूरी है, जैसा फ़्रेम लेबल के लिए होता है।

## टेम्पलेट फ़्रेम स्पेक होते हैं [#templates-are-frame-specs]

Arrow, Standard Box, Square Border, Striked Box और Halloween की आर्टवर्क एक [फ़्रेम स्पेक](/docs/features/frames#frame-specs) है, यानी हर दूसरे फ़्रेम जैसा ही JSON फ़ॉर्मैट, जिसे वही इंजन बनाता है। `getTemplate(id).spec` इसे लौटाता है। जब आपको फ़्रेम वाली साइज़िंग (कोड अपना साइज़ रखता है और आर्टवर्क उसके चारों ओर बढ़ती है) और फ़्रेम का रंग विकल्प चाहिए, तब इसे फ़्रेम की तरह इस्तेमाल करें:

```tsx
import { getTemplate, QRCode } from 'qrdx';

const spec = getTemplate('Arrow')?.spec;

<QRCode
  value="https://example.com"
  frame={spec && { style: 'custom', spec, color: '#1a56db' }}
  size={256}
/>
```

Dot Ring का कोई स्पेक नहीं है: इसके डॉट्स कोड के कंटेंट से आते हैं, इसलिए यह उन्हें कोड में बनाता है (देखें [कोड में बनाए जाने वाले फ़्रेम](#frames-you-draw-in-code))।

`templateId` पहले जैसी ही आर्टवर्क बनाता है। जो सेव किए हुए डिज़ाइन, इमेज URL, CLI कमांड और कोड टेम्पलेट id इस्तेमाल करते हैं, वे हमेशा की तरह ही दिखते हैं।

## टेम्पलेट रजिस्ट्री [#template-registry]

```tsx
import { getAllTemplates, getTemplate, getTemplateIds } from 'qrdx';

getTemplateIds(); // ['default', 'Arrow', 'StandardBox', ...]
getAllTemplates(); // every TemplateDefinition, with its id and name
getTemplate('Halloween'); // one by id
```

## कोड में बनाए जाने वाले फ़्रेम [#frames-you-draw-in-code]

फ़्रेम स्पेक तय आर्टवर्क बताता है। जब आर्टवर्क की गणना करनी हो, तो `TemplateDefinition` लिखें और उसे `customTemplate` के रूप में पास करें। इसका `wrapper` कोड को `children` के रूप में लेता है और बनाने के लिए SVG लौटाता है। यह 300 गुणा 300 के कैनवास पर बनाता है, और कोड भी उसी साइज़ में आता है, इसलिए अपनी आर्टवर्क के लिए जगह छोड़ने के लिए उसे छोटा करें। `props` में कोड के `fgColor` और `bgColor` होते हैं, और तीसरे आर्गुमेंट में कोड का `url` और `pixelSize` होता है।

यह कोड के चारों ओर एक रिंग बनाता है:

```tsx
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg viewBox="0 0 300 300" width="300" height="300" xmlns="http://www.w3.org/2000/svg">
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

<QRCode
  value="https://example.com"
  customTemplate={ringTemplate}
  fgColor="#1a56db"
  size={256}
/>
```

कोड को इतना बड़ा रखें कि लोग जहाँ से फ़ोन पकड़ेंगे वहाँ से स्कैन हो सके, और उसके व उसकी आर्टवर्क के बीच हल्की खाली जगह छोड़ें। नतीजे को [स्कैन स्कोर](/docs/features/frames#will-it-scan) से जाँचें।
