टेम्पलेट एक ऐसा फ़्रेम है जो कोड को अपने आर्टवर्क के अंदर फ़िट करता है। Playground में टेम्पलेट कोई अलग सूची नहीं हैं। Arrow, Standard Box, Square Border, Striked Box, Halloween और Dot Ring फ़्रेम पिकर के **Classic** ग्रुप में टाइल के रूप में दिखते हैं, बाकी [फ़्रेम](/docs/features/frames) के साथ। कोई भी फ़्रेम चुनने पर पहले वाला फ़्रेम हट जाता है।

टेम्पलेट बाकी फ़्रेम से एक बात में अलग हैं: साइज़। फ़्रेम कोड के चारों ओर जगह जोड़ता है, इसलिए `size` कोड की चौड़ाई होती है और इमेज बड़ी हो जाती है। टेम्पलेट अपना पूरा आर्टवर्क `size` पर बनाता है, और कोड उसके अंदर छोटा रहता है।

## बिल्ट-इन टेम्पलेट [#built-in-templates]

id को `templateId` के रूप में दें। Image API में यह `template` और CLI में `--template` के रूप में जाता है।

| `templateId` | नाम | रंग |
|--------------|------|-------|
| `Arrow` | Arrow | कोड का गहरा रंग (`fgColor`) |
| `StandardBox` | Standard Box | `fgColor` |
| `SquareBorder` | Square Border | `fgColor` |
| `StrikedBox` | Striked Box | इसका अपना गहरा रंग |
| `Halloween` | Halloween | इसके अपने नारंगी, हरे और काले रंग |
| `DotRing` | Dot Ring | रिंग `fgColor` में, टेक्स्ट सफ़ेद में; दोनों बदले जा सकते हैं (नीचे देखें) |

`default` कोई आर्टवर्क नहीं बनाता। यह बस कोड को थोड़ा अंदर की ओर कर देता है, `size` के 95% तक।

```tsx
import { QRCode } from 'qrdx';

<QRCode value="https://example.com" templateId="Arrow" fgColor="#1a56db" size={256} />
```

रंग, पैटर्न और लोगो कोड की अपनी props पर ही रहते हैं, इसलिए टेम्पलेट किसी भी स्टाइल के साथ काम करता है:

```tsx
<QRCode
  value="https://example.com"
  templateId="StandardBox"
  fgColor="#1a56db"
  imageSettings={{
    src: "/your-logo.png",
    width: 48,
    height: 48,
    excavate: true,
  }}
  size={512}
/>
```

## Dot Ring [#dot-ring]

एक गोल कोड। कोड डॉट्स की एक डिस्क में बैठता है जो गहरी रिंग के अंदर है, और रिंग के साथ-साथ टेक्स्ट की एक लाइन लगी होती है। कौन-से डॉट्स दिखें, यह कोड के कंटेंट के हैश से तय होता है, इसलिए हर लिंक की अपनी अलग रिंग बनती है और एक ही लिंक को हमेशा वही रिंग मिलती है।

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  bodyPattern="circle-large"
  size={512}
/>
```

इसकी सेटिंग `customProps` में जाती हैं (टाइप `DotRingProps`):

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  customProps={{
    customText: "Scan for the menu",
    textPosition: "bottom",
    textColor: "#fde047",
    outerCircleColor: "#1e3a8a",
  }}
  size={512}
/>
```

| Prop | डिफ़ॉल्ट | नोट्स |
| --- | --- | --- |
| `customText` | "Scan the QR code" चार बार पूरी रिंग में | रिंग के साथ चलने वाला टेक्स्ट; `""` देने पर रिंग खाली रहती है। रिंग के लिए बहुत लंबा टेक्स्ट फ़िट कर दिया जाता है (नीचे देखें) |
| `textFill` | `"none"` | `"repeat"` टेक्स्ट को पूरी रिंग में दोहराता है (नीचे देखें) |
| `textPosition` | `"top"` | `"top"`: ऊपर बीच में, घड़ी की दिशा में पढ़ा जाता है। `"bottom"`: नीचे बीच में, बाएँ से दाएँ पढ़ा जाता है |
| `textRotation` | `0` | टेक्स्ट को केंद्र के चारों ओर घुमाता है, डिग्री में |
| `textColor` | `#ffffff` | टेक्स्ट का रंग |
| `fontFamily` | सिस्टम फ़ॉन्ट स्टैक | टेक्स्ट का CSS फ़ॉन्ट फ़ैमिली |
| `fontWeight` | `900` | फ़ॉन्ट वेट |
| `fontSize` | `32` | टेम्पलेट की 593-यूनिट वाली ड्रॉइंग में, जहाँ कोड 300 चौड़ा है। लंबा टेक्स्ट छोटा बन सकता है |
| `fontLetterSpacing` | `3.5` | अक्षरों के बीच अतिरिक्त जगह, उन्हीं यूनिट में। लंबा टेक्स्ट और `textFill` इसे एडजस्ट करते हैं |
| `outerCircleColor` | `fgColor` | रिंग का रंग |
| `strokeWidth`, `strokeColor` | `0`, `#000000` | रिंग के दोनों किनारों पर एक स्ट्रोक |
| `outerStrokeWidth`, `outerStrokeColor` | `strokeWidth`, `strokeColor` | सिर्फ़ रिंग का बाहरी किनारा |
| `innerStrokeWidth`, `innerStrokeColor` | `strokeWidth`, `strokeColor` | सिर्फ़ रिंग का अंदरूनी किनारा |

जो टेक्स्ट रिंग में फ़िट हो जाता है, वह जैसा दिया गया है वैसा ही लगता है, ऊपर बीच में या नीचे के साथ। जो टेक्स्ट रिंग के लिए बहुत लंबा हो, वह कभी अपनी ही शुरुआत से नहीं टकराता। पहले अक्षर पास लाए जाते हैं, फिर फ़ॉन्ट छोटा किया जाता है, डिफ़ॉल्ट साइज़ के आधे तक (फ़्रेम लेबल का सबसे छोटा साइज़ यही है)। इसके बाद टेक्स्ट अपनी शुरुआत से मिलने की जगह पर एक शब्द-जितनी जगह छोड़कर रिंग बंद करता है। अगर उस साइज़ पर भी फ़िट न हो, तो किसी वाक्यांश को दोहराने वाले टेक्स्ट की उतनी ही पूरी कॉपियाँ रखी जाती हैं जितनी फ़िट हों, और बाक़ी टेक्स्ट को आख़िरी उस पूरे शब्द के बाद काटकर अंत में "…" लगा दिया जाता है जो फ़िट होता है।

लोगो किसी भी कोड की तरह बीच में लगता है। लंबे लिंक (जिन कोड की चौड़ाई 49 मॉड्यूल से ज़्यादा हो) में कोड और डॉट्स के बीच हल्की पट्टी रहती है, ताकि छोटा प्रिंट होने पर भी वे स्कैन हो सकें।

टेक्स्ट आपके चुने फ़ॉन्ट में SVG टेक्स्ट होता है; डिफ़ॉल्ट सिस्टम फ़ॉन्ट स्टैक है, इसलिए कुछ डाउनलोड नहीं होता। ब्राउज़र में SVG और PNG डाउनलोड देखने वाले के फ़ॉन्ट इस्तेमाल करते हैं। PDF और EPS इसे Helvetica Bold में प्रिंट करते हैं, इसलिए वहाँ Latin-1 टेक्स्ट इस्तेमाल करें। `qrdx/node` का `getQRAsPNG` सर्वर पर इंस्टॉल किया हुआ फ़ॉन्ट माँगता है, जैसे फ़्रेम लेबल माँगते हैं।

### रिंग भरना [#filling-the-ring]

छोटा वाक्यांश रिंग का कुछ हिस्सा खाली छोड़ देता है। `textFill: "repeat"` सेट करें ताकि वह जितनी बार फ़िट हो उतनी बार दोहराया जाए, और स्पेसिंग बराबर कर दी जाती है ताकि रिंग उतने ही गैप से बंद हो जितना कॉपियों के बीच होता है:

```tsx
<QRCode
  value="https://example.com/docs"
  templateId="DotRing"
  customProps={{ customText: "Read the docs *", textFill: "repeat" }}
  size={512}
/>
```

वाक्यांश एक ही बार दें। जो टेक्स्ट पहले से किसी वाक्यांश को दोहराता है, जैसे `"Make your own * Make your own *"`, उसे वही एक वाक्यांश माना जाता है, इसलिए वह रिंग को उसी तरह भरता है।

## टेम्पलेट फ़्रेम स्पेक हैं [#templates-are-frame-specs]

Arrow, Standard Box, Square Border, Striked Box और Halloween का आर्टवर्क एक [फ़्रेम स्पेक](/docs/features/frames#frame-specs) है, यानी हर दूसरे फ़्रेम जैसा ही JSON फ़ॉर्मेट, जिसे वही इंजन बनाता है। `getTemplate(id).spec` इसे लौटाता है। जब आपको फ़्रेम वाली साइज़िंग (कोड अपना साइज़ रखता है और आर्टवर्क उसके चारों ओर बढ़ता है) और फ़्रेम का रंग विकल्प चाहिए, तब इसे फ़्रेम की तरह इस्तेमाल करें:

```tsx
import { getTemplate, QRCode } from 'qrdx';

const spec = getTemplate('Arrow')?.spec;

<QRCode
  value="https://example.com"
  frame={spec && { style: 'custom', spec, color: '#1a56db' }}
  size={256}
/>
```

Dot Ring का कोई स्पेक नहीं है: इसके डॉट्स कोड के कंटेंट से बनते हैं, इसलिए यह उन्हें कोड में बनाता है (देखें [कोड में बनाए जाने वाले फ़्रेम](#frames-you-draw-in-code))।

`templateId` पहले जैसा ही आर्टवर्क बनाता है। जो सेव किए हुए डिज़ाइन, इमेज URL, CLI कमांड और कोड टेम्पलेट id इस्तेमाल करते हैं, वे वैसे ही दिखते हैं जैसे हमेशा दिखते थे।

## टेम्पलेट रजिस्ट्री [#template-registry]

```tsx
import { getAllTemplates, getTemplate, getTemplateIds } from 'qrdx';

getTemplateIds(); // ['default', 'Arrow', 'StandardBox', ...]
getAllTemplates(); // every TemplateDefinition, with its id and name
getTemplate('Halloween'); // one by id
```

## कोड में बनाए जाने वाले फ़्रेम [#frames-you-draw-in-code]

फ़्रेम स्पेक तय आर्टवर्क का वर्णन करता है। जब आर्टवर्क की गणना करनी हो, तब `TemplateDefinition` लिखें और उसे `customTemplate` के रूप में दें। इसका `wrapper` कोड को `children` के रूप में पाता है और बनाने के लिए SVG लौटाता है। यह 300 गुणा 300 के कैनवास पर बनाता है, और कोड भी उसी साइज़ में आता है, इसलिए अपने आर्टवर्क के लिए जगह छोड़ने को उसे छोटा करें। `props` में कोड के `fgColor` और `bgColor` होते हैं, और तीसरे आर्ग्युमेंट में कोड का `url` और `pixelSize` होता है।

यह कोड के चारों ओर एक रिंग बनाता है:

```tsx
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg viewBox="0 0 300 300" width="300" height="300" xmlns="http://www.w3.org/2000/svg">
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

<QRCode
  value="https://example.com"
  customTemplate={ringTemplate}
  fgColor="#1a56db"
  size={256}
/>
```

कोड को इतना बड़ा रखें कि लोग जहाँ से फ़ोन पकड़ेंगे वहाँ से स्कैन हो सके, और उसके और आपके आर्टवर्क के बीच हल्का गैप छोड़ें। नतीजे को [स्कैन स्कोर](/docs/features/frames#will-it-scan) से जाँचें।
