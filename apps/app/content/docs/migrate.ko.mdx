QRdx는 다른 제공업체의 링크와 동적 코드를 한 번에 가져옵니다. [대시보드 → 코드](/dashboard?to=codes)를 열고 **가져오기**를 클릭하세요. 모든 가져오기는 같은 세 단계로 진행됩니다. 가져올 항목을 고르고, 미리 보고, 가져옵니다.

- **연결된 계정:** Bitly, Rebrandly, Short.io. QRdx는 제공업체의 API를 통해 링크 목록을 불러옵니다.
- **내보내기 파일:** QR Code Generator PRO, Uniqode (Beaconstac), Flowcode, QR TIGER, ME-QR, TinyURL, Hovercode, Scanova 또는 대상 URL이 있는 모든 CSV.

가져오는 동안 기존 계정에는 아무 변경도 일어나지 않습니다.

## 가져오기로 만들어지는 것 [#what-an-import-creates]

각 링크나 코드는 다음 내용을 갖춘 [동적 QR 코드](/docs/dynamic-qr-codes)가 됩니다.

- 대상과 제목
- 태그(선택 사항), 그리고 "Imported from Bitly" 같은 폴더(이름을 바꾸거나 끌 수 있습니다)
- `Imported from Bitly bit.ly/3AbCdEf on 2026-11-01.` 같은 메모와 링크의 원래 생성 날짜. 새 코드의 생성 날짜는 QRdx가 직접 설정합니다.

미리 보기에서는 만들어질 코드 수, 새로 생기는 태그, 건너뛰는 항목을 보여 줍니다.

- **이미 가져옴:** 이전에 가져온 링크(이전 실행 포함)는 항상 건너뛰므로, 가져오기를 두 번 실행해도 중복이 생기지 않습니다.
- **같은 대상:** 대상에 이미 QRdx 코드가 있는 링크는 기본적으로 건너뜁니다. 그래도 가져오려면 해당 옵션을 선택하세요.
- **가져올 수 없음:** 대상이 없거나 올바르지 않은 링크, 이미 QRdx 단축 링크를 가리키는 링크.

가져오기는 진행률 표시줄과 함께 50개씩 일괄 처리됩니다. 대화 상자를 닫아도 안전합니다. **가져오기**를 다시 열면 **최근 가져오기**에서 이어서 진행됩니다. 요약에는 생성, 건너뜀, 실패한 코드가 이유와 함께 나열됩니다.

<Callout type="info">
요금제 한도는 다른 새 코드와 똑같이 적용됩니다. 무료에는 활성 동적 코드 10개가 포함됩니다. 가져오기에 더 필요하면 미리 보기에서 몇 개가 들어갈 수 있는지 알려 주고, 처음 항목만 가져오거나 업그레이드할 수 있게 안내합니다. Pro와 Business에는 한도가 없습니다.
</Callout>

## 연결된 계정에서 가져오기 [#from-a-connected-account]

1. **가져오기**를 클릭하고 제공업체를 선택하세요. 아직 연결되지 않았다면 그 자리에서 연결하세요(로그인하거나 API 키 또는 토큰을 붙여넣기). 토큰은 암호화되어 저장되며, 설정 → 통합에서 연결을 해제할 수 있습니다.
2. 검색하고, 도메인이나 태그로 필터링한 다음 링크를 선택하세요. **조건에 맞는 링크 모두 선택**은 한 번에 최대 1,000개까지 가져옵니다. 나머지는 다시 실행하세요.
3. 미리 보기를 확인하고 **가져오기**를 클릭하세요.

| 제공업체 | 연결 방법 | 링크 목록 | 인쇄한 코드 계속 작동 |
|---|---|---|---|
| Bitly | 로그인 또는 일반 액세스 토큰 | 예 | 유료 Bitly 요금제만 가능: 월 링크 리디렉션 Core 5회, Growth 20회, Premium 110회 |
| Rebrandly | API 키 | 예 | Rebrandly의 월별 대상 수정 한도 내에서 가능: Essentials 10회, Professional 50회, Growth 150회(Free는 없음) |
| Short.io | API 키 | 예, 한 번에 도메인 하나씩 | 예, 모든 요금제에서 가능 |

요금제 한도는 각 제공업체의 정책이며 시간이 지나면서 바뀔 수 있습니다. 해당 업체의 요금 페이지를 확인하세요.

## 인쇄한 코드 계속 작동하게 하기 [#keep-printed-codes-working]

다른 제공업체로 인쇄한 QR 코드에는 그 제공업체의 단축 링크가 담겨 있습니다. 연결된 계정에서 가져온 뒤에는 요약에 **인쇄한 코드 계속 작동하게 하기**가 나타납니다.

1. **사전 실행**에서 기존 링크와 그 링크가 가리키게 될 QRdx 링크를 모두 나열합니다. 아직 아무것도 바뀌지 않습니다.
2. 확인하면 QRdx가 각 기존 링크의 대상을 새 QRdx 코드로 변경합니다. 방문자는 여전히 같은 페이지에 도착하고, 이제 모든 스캔이 QRdx 분석에 표시됩니다. 기존 제공업체에서는 여전히 클릭이 먼저 기록됩니다.
3. **실행 취소**를 누르면 가져올 때 QRdx가 저장해 둔 원래 대상으로 되돌립니다.

제공업체가 거부하면(예: 남은 링크 리디렉션이 없는 Bitly 요금제) QRdx는 중단하고 이유를 알려 주며 나머지 링크는 변경하지 않습니다. 대상에 이미 QRdx 코드가 있어 건너뛴 링크는 그 기존 코드를 가리킵니다.<IfAvailable feature="customDomains"> 백하프가 사용자의 도메인과 함께 이동하는 링크(아래 참고)는 변경되지 않습니다. DNS를 전환하면 그 링크가 곧 QRdx 링크가 됩니다.</IfAvailable>

## 원래 백하프 유지하기 [#keep-the-original-back-halves]

Pro와 Business에서는 가져오기 미리 보기에서 **원래 백하프 유지**를 선택하세요. 그러면 QRdx가 유지할 수 있는 경우 각 코드가 무작위 백하프 대신 기존 백하프를 받아, `bit.ly/spring-menu`가 `qrdx.dev/q/spring-menu`가 됩니다.

- 백하프가 3~64자의 영문자, 숫자, `-`, `_`로 이루어져 있고([사용자 지정 백하프](/docs/dynamic-qr-codes#custom-back-halves) 참고), 예약어가 아니며, `qrdx.dev`에서 어떤 QRdx 코드도 아직 사용하지 않으면 그대로 유지됩니다<IfAvailable feature="customDomains"> (사용자의 도메인에서는 그 도메인의 내 코드만 해당)</IfAvailable>.
- 그렇지 않으면 코드에 생성된 백하프가 적용되며, 미리 보기에 변경 내용이 이유와 함께 표시됩니다. 예: `spring-menu → Ab3xK9q · Another QRdx code already uses this back-half on qrdx.dev`. 가져오기는 미리 보기에 표시된 백하프를 그대로 사용합니다.
- 백하프는 Bitly와 Short.io처럼 대소문자를 구분합니다.

<Callout type="warn">
확신이 들 때까지 제공업체 연결을 유지하세요. 실행 취소에는 연결이 필요합니다. 또한 기존 링크가 계속 리디렉션되려면 기존 계정이 활성 상태로 유지되어야 합니다.
</Callout>

<IfAvailable feature="customDomains" id="your-own-domain-go-yourbrand-com" title="내 도메인 (go.yourbrand.com)">

링크에 내 도메인을 사용하고 있다면, 그 도메인을 QRdx로 옮기고 백하프를 유지할 수 있습니다. 그러면 DNS를 전환한 뒤에도 `go.yourbrand.com/spring-menu`가 계속 작동합니다.

1. 먼저 [설정 → 도메인](/dashboard?to=settings/domains)에서 도메인을 추가하세요. 지금은 인증하지 않아도 됩니다. 이 경우 백하프는 도메인 자체에서 유지되며, 내 코드끼리만 고유하면 되고 `api`, `p`, `q`만 예약되어 있습니다.
2. 가져오기 미리 보기에서 **원래 백하프 유지**를 선택하고 **링크 위치**에서 도메인을 고르세요. 미리 보기에 어떤 백하프가 유지되는지 표시됩니다.
3. 가져오세요. 코드가 도메인에 만들어지고 백하프를 바로 차지합니다.
4. 도메인의 DNS를 QRdx로 지정하고 인증하세요([사용자 지정 도메인](/docs/custom-domains) 참고). 한가한 시간에 진행하세요. DNS가 바뀌는 즉시 해당 도메인의 링크는 기존 제공업체에서 작동을 멈추고, 인증이 끝나면 QRdx에서 작동하기 시작합니다.

가져올 때 도메인이 아직 QRdx에 없으면 백하프는 대신 `qrdx.dev`에서 유지됩니다(이 경우 QRdx 전체에서 사용 중이 아니어야 합니다). 도메인을 추가하고 인증한 뒤 가져오기 요약에서 **코드 연결**을 클릭하면 해당 코드를 도메인으로 옮길 수 있습니다.

</IfAvailable>

유지할 수 없는 백하프에는 생성된 백하프가 적용되며, 해당 링크는 다시 인쇄하거나 기존 제공업체에서 리디렉션해야 합니다. 사용자 지정 백하프는 Pro와 Business에 포함됩니다.

## 내보내기 파일에서 가져오기 [#from-an-export-file]

1. 파일을 준비해요(아래 단계 참고). QRdx는 CSV를 읽을 수 있어요. Excel 파일은 먼저 CSV로 저장하거나 다운로드해 주세요.
2. **Import**를 클릭하고 제공업체를 선택한 다음 파일을 업로드해요. QRdx는 가능한 한 제공업체의 열을 자동으로 인식하며, 매핑은 직접 바꿀 수 있어요. 필수 항목은 대상 주소뿐이에요. 이전 단축 링크(또는 코드 ID)가 있으면 다시 업로드할 때 이미 가져온 코드를 건너뛸 수 있어요.
3. 미리 보고 가져온 다음 **Copy all new links** 또는 **Download mapping CSV**(이전 링크 → 새 QRdx 링크)를 사용해요.

이 제공업체들의 코드는 제공업체의 도메인에 있어서 QRdx에서 바꿀 수 없어요. 인쇄된 코드가 계속 작동하게 하려면 이전 제공업체에서 각 동적 QR 코드를 열고, 대상 주소를 매핑에 있는 새 QRdx 링크로 설정해 주세요. 이 코드들이 리디렉션되려면 이전 계정이 활성 상태로 유지되어야 해요. 해지하기 전에 QRdx 코드로 다시 인쇄해 주세요.

### QR Code Generator PRO [#qr-code-generator-pro]

코드 목록을 내보내는 기능은 문서화되어 있지 않아요. 각 코드의 **Name**, **Short URL**, **Destination URL**을 담은 스프레드시트를 만들어 주세요. 코드를 다시 연결하려면 코드를 열고 **Details** → **Edit**에서 URL을 바꾼 뒤 저장해요. 코드가 많다면 일괄 업데이트 기능에 새 URL이 담긴 CSV를 넣으면 최대 500개까지 처리할 수 있어요.

### Uniqode (Beaconstac) [#uniqode-beaconstac]

**QR Codes → Dynamic**에서 모두 선택하고 **⋯ → Export**를 선택해요. 조직별 또는 폴더별로 내보내요. 내보낸 파일의 열(QR Code Name, QR Code URL, Destination URL, Labels 등)은 자동으로 인식돼요. 다시 연결하려면 코드를 열고 **Edit** → 새 URL → **Next** → **Save**를 선택해요.

### Flowcode [#flowcode]

코드 목록을 내보내는 기능은 문서화되어 있지 않아요. 일괄 생성에 사용한 시트(Flowcode Name, Flowcode Scan URL)를 재사용하거나 Name, Scan URL, Destination을 정리해 주세요. 다시 연결하려면 **Assets** → 해당 코드 → **Overview** → **Destination** → **Save**를 선택해요.

### QR TIGER [#qr-tiger]

**My Account**에서 카테고리(예: URL)를 선택하고 **Download QR List**를 클릭해요. 카테고리마다 한 번씩 해야 해요. 다시 연결하려면 **My Account → Dashboard → URL** → 해당 캠페인 → **Edit** → **Save**를 선택해요.

### ME-QR [#me-qr]

내보내기 기능이 없어요. 각 코드의 Name, QR link, Destination URL을 정리해 주세요. 다시 연결하려면 ME-QR 코드 목록에서 코드를 편집해요.

### TinyURL [#tinyurl]

TinyURL은 유료 플랜에서 CSV 내보내기를 제공한다고 안내해요. 링크를 CSV로 내보내거나 Alias와 Long URL을 정리해 주세요. TinyURL의 대상 주소를 수정하려면 유료 TinyURL 플랜이 필요해요.

### Hovercode, Scanova 및 기타 제공업체 [#hovercode-scanova-and-others]

제공업체에서 코드를 CSV로 내보낸 다음(Hovercode는 Business 플랜에서 CSV 내보내기를 제공한다고 안내하고, Scanova는 다운로드 링크를 이메일로 보내요) 열 매핑을 확인해 주세요. 대상 주소 열이 있는 CSV라면 **Another provider (CSV)**로 가져올 수 있어요.

정적 QR 코드(goQR.me, QR Code Monkey, Adobe Express 등의 도구로 만든 코드)는 대상 주소 자체를 담고 있어서 해당 도구 없이도 계속 작동해요. 새로 인쇄할 때 편집하고 추적할 수 있는 코드가 필요한 경우에만 CSV에서 이 코드들의 대상 주소를 가져오세요.

## QR 코드 라이브러리에서 가져오기 [#from-a-qr-code-library]

라이브러리는 정적 QR 코드를 렌더링하므로 따로 마이그레이션할 것은 없어요. 이미 인쇄된 코드는 계속 작동해요. 앱의 렌더링 방식을 바꾸려면 `qrdx`를 설치하고 컴포넌트를 교체해 주세요.

### qrcode.react에서 [#from-qrcode-react]

```tsx
// Before
import { QRCodeSVG } from "qrcode.react";

<QRCodeSVG value="https://example.com" size={256} fgColor="#111827" />;

// After
import { QRCodeSVG } from "qrdx";

<QRCodeSVG
  value="https://example.com"
  size={256}
  fgColor="#111827"
  bodyPattern="rounded"
/>;
```

`value`, `size`, `level`, `fgColor`, `bgColor`, `marginSize`(`margin`으로), `imageSettings`는 그대로 사용할 수 있어요. qrdx는 패턴, 그라데이션, 템플릿을 추가로 제공해요. [API 레퍼런스](/docs/api-reference)를 참고하세요.

### qr-code-styling에서 [#from-qr-code-styling]

```tsx
// Before
import QRCodeStyling from "qr-code-styling";

const qr = new QRCodeStyling({
  data: "https://example.com",
  width: 256,
  dotsOptions: { type: "rounded", color: "#111827" },
  image: "/logo.png",
});
qr.append(ref.current);

// After
import { QRCodeSVG } from "qrdx";

<QRCodeSVG
  value="https://example.com"
  size={256}
  bodyPattern="rounded"
  fgColor="#111827"
  imageSettings={{ src: "/logo.png", width: 64, height: 64, excavate: true }}
/>;
```

qrdx는 React 컴포넌트이므로 추가할 인스턴스가 없어요. 다른 요소처럼 렌더링하면 돼요. 다운로드는 [API 레퍼런스](/docs/api-reference)의 헬퍼를 사용해요.
