托管页面可以展示你上传到 QRdx 的文件：PDF 格式的菜单或宣传册、照片图集、音乐或播客，或者视频。上传的文件位于 **控制台 → 文件**，归属于你上传时所在的工作区，每个文件都有一个固定链接，替换文件后该链接依然有效。

## 可上传的文件 [#what-you-can-upload]

| 类型 | 格式 |
| --- | --- |
| PDF | PDF |
| 图片 | JPEG、PNG、WebP、GIF、AVIF |
| 音频 | MP3、M4A、AAC、Ogg、WAV |
| 视频 | MP4、WebM、MOV |

采用 H.264 编码的 MP4 视频可在所有浏览器中播放。手机拍摄的 MOV 文件通常也能播放，但如果某个浏览器无法播放，请先转换为 MP4。SVG、HTML、压缩包和办公文档无法上传，因此存储中提供的任何内容都不会在访客的浏览器中运行代码。

每个上传的文件在使用前都会经过检查：文件大小必须与上传前声明的一致，文件开头的字节也必须确实属于对应类型（改名为 `.pdf` 的 HTML 页面会被拒绝）。被拒绝的上传会从存储中删除，并标记为 **已拦截**。

## 各套餐的限制 [#limits-per-plan]

| 套餐 | 每个工作区的存储空间 | 单个文件上限 |
| --- | --- | --- |
| 免费版 | 50 MB | 10 MB |
| Pro | 5 GB | 100 MB |
| Business | 50 GB | 250 MB |

工作区按其所有者中最高的套餐计算。限制只会阻止新的上传：降级后，或工作区的存储空间已超出时，你之前上传的所有文件仍会继续在使用它们的每个页面上提供。删除不再需要的文件（或升级套餐）后才能上传新文件。

## 在页面中使用文件 [#use-files-on-a-page]

有五种区块可以展示文件。每种区块既可以使用上传的文件，也可以使用指向其他位置所托管文件的链接：

- **PDF** 在平板和电脑上内嵌显示文档，并提供 **打开 PDF**（在手机上为全屏查看器）和 **下载** 按钮。
- **图集** 以 1–3 列的网格展示照片。点按照片可全屏打开；滑动或使用方向键即可浏览。
- **音频** 播放带封面和播放列表的曲目；一首播放结束后会自动播放下一首。下载按钮为可选项。
- **视频文件** 播放你上传的 MP4 或 WebM，也可以像 GIF 一样静音循环播放。若要使用 YouTube、Vimeo 或 Loom 的视频，请改用 **视频** 区块：在有人点按播放之前，它不会从 YouTube 加载任何内容。
- **下载** 列出可供保存的文件，每个文件都有各自的标签。

在 **新建二维码** 中，**PDF**、**图片**、**MP3 / 音频** 和 **视频** 这几种页面类型会直接带有这些区块。

在区块中，选择 **上传** 可从你的设备添加文件，选择 **从我的文件** 可重复使用之前上传的文件，也可以粘贴链接。

## 替换或删除文件 [#replace-or-delete-a-file]

打开 **控制台 → 文件**，使用文件旁边的菜单：

- **复制链接** 会复制该文件自己的链接（`https://qrdx.dev/api/files/<id>`）。你也可以将它用作动态二维码的目标地址。
- **替换文件** 会在同一个链接下上传新内容，例如下一季的菜单。使用该文件的页面和二维码会在一分钟内显示新版本。文件只能用同类型的文件替换（PDF 只能用 PDF 替换）。
- **删除** 会永久删除该文件。如果仍有页面或二维码在使用它，QRdx 会先列出这些页面或二维码；删除后，这些页面在原来放置文件的位置会显示“文件不可用”。

成员可以替换和删除自己上传的文件；所有者和管理员可以管理工作区中的所有文件。

## 被举报的文件 [#reported-files]

每个托管页面都有一个 **举报滥用** 链接。如果文件违反规则，或版权所有者要求将其移除，QRdx 可以将其拦截。被拦截的文件会在一分钟内停止在所有页面以及通过其 QRdx 链接提供（页面会显示“文件不可用”），并且它的相同副本（最大 25 MB）也无法再次上传。

## 配置存储（自托管） [#set-up-storage-self-hosting]

文件上传使用 [Cloudflare R2](https://developers.cloudflare.com/r2/)。如果没有配置，文件页面会显示“此服务器未配置存储”，上传 API 会返回 `503`，区块仍然可以使用指向其他位置所托管文件的链接。

1. 在 Cloudflare 控制台中打开 **R2**，创建一个存储桶，例如 `qrdx-files`。
2. 在 **R2 → Manage API tokens** 下，创建一个对该存储桶具有 **Object Read & Write** 权限的令牌。
3. 设置以下环境变量并重启：

   ```bash
   R2_ACCOUNT_ID=your-cloudflare-account-id
   R2_ACCESS_KEY_ID=token-access-key-id
   R2_SECRET_ACCESS_KEY=token-secret-access-key
   R2_BUCKET=qrdx-files
   # Optional: serve files from a public bucket URL or custom domain
   R2_PUBLIC_BASE_URL=https://files.example.com
   ```

4. 为存储桶添加 CORS 策略（**Settings → CORS policy**）。浏览器会直接上传到 R2，因此存储桶必须接受来自你应用所在源、带有 `Content-Type` 请求头的 `PUT` 请求：

   ```json
   [
     {
       "AllowedOrigins": ["https://qrdx.example.com", "http://localhost:3000"],
       "AllowedMethods": ["PUT", "GET", "HEAD"],
       "AllowedHeaders": ["Content-Type"],
       "ExposeHeaders": ["ETag"],
       "MaxAgeSeconds": 3600
     }
   ]
   ```

   请将 `https://qrdx.example.com` 替换为人们打开你的控制台时所用的源（协议加主机，末尾不带斜杠）。只有在从本地开发服务器上传时，才需要保留 `http://localhost:3000`。

### 公开文件或预签名链接 [#public-files-or-presigned-links]

访客始终通过 `/api/files/<id>` 打开文件，该地址会重定向到已存储的对象：

- 如果设置了 `R2_PUBLIC_BASE_URL`（连接到存储桶的自定义域名，或其 `r2.dev` 地址；Cloudflare 会对后者限速，并建议仅用于测试），则重定向到公开地址。对象键中包含随机 ID，因此文件无法被列出或猜到。
- 如果未设置，存储桶保持私有，每次重定向都是一个一小时后过期的预签名链接。

无论哪种方式，被替换、删除或拦截的文件都会在一分钟内停止通过其 QRdx 链接提供。被拦截的文件还会立即从其公开地址消失：它的对象会移到带有随机部分的 `quarantine/` 键下（保留以便管理员恢复），其 QRdx 链接会返回 `410 Gone`。

浏览器会上传到 `staging/` 键。上传检查通过后，QRdx 会把经过检查的版本原样复制到该文件自己的键下，因此仍然有效的上传链接无法替换已检查的文件。

<Callout type="info">
  从未完成的上传会在两小时后不再计入存储空间，并在下次有人向该工作区上传时被清理。请为存储桶添加对象生命周期规则（**Settings → Object lifecycle rules**），在一天后删除前缀为 `staging/` 的对象，这样被放弃的上传所留下的残余文件也会被清除。
</Callout>
