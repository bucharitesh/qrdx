`qrdx/element`는 `<qrdx-code>` 커스텀 엘리먼트입니다. `qrdx/core`를 기반으로 만들어져, `QRCodeSVG`와 같은 SVG를 모든 스타일, 프레임, 로고, 내보내기와 함께 그립니다. 프레임워크가 필요 없습니다. 일반 HTML과 DOM 엘리먼트를 렌더링하는 프레임워크에서 모두 동작합니다. React 19와 Vue 3에서 테스트했습니다.

## CDN에서 사용하기 [#from-a-cdn]

```html
<script
  type="module"
  src="https://cdn.jsdelivr.net/npm/qrdx/dist/element-define.browser.mjs"
></script>

<qrdx-code
  value="https://example.com"
  size="256"
  body-pattern="rounded"
  label="Link to example.com"
></qrdx-code>
```

`dist/element-define.browser.mjs`는 `<qrdx-code>`를 등록합니다. 이 파일은 엔진이 포함된 ES 모듈 하나인 `dist/element.browser.mjs`를 불러옵니다. 버전을 고정하려면 URL의 `qrdx` 뒤에 `@`와 버전을 붙이세요. 같은 경로가 unpkg에서도 동작합니다.

## 번들러와 함께 사용하기 [#with-a-bundler]

```package-install
qrdx@latest
```

```js
import "qrdx/element/define"; // registers <qrdx-code>
```

`qrdx/element`를 import해도 아무것도 등록되지 않습니다. 태그 이름을 직접 정하려면 `defineQRdxCode`를 호출하세요.

```js
import { defineQRdxCode } from "qrdx/element";

defineQRdxCode(); // <qrdx-code>
defineQRdxCode("brand-qr"); // <brand-qr> as well
```

여러 번 호출해도 안전하며, 서버에서는 아무 일도 하지 않습니다. 같은 이름을 다른 엘리먼트가 이미 사용 중이면 오류가 발생합니다.

## 속성 [#attributes]

| 속성 | 설정하는 값 |
| --- | --- |
| `value` | 인코딩할 텍스트 또는 URL입니다. 이 값이 없으면 아무것도 그리지 않습니다 |
| `size` | 너비와 높이(픽셀)입니다. 프레임이 있으면 그만큼 더해집니다 |
| `level` | 오류 정정 수준: `L`, `M`, `Q`, `H` |
| `fg-color`, `bg-color`, `eye-color`, `dot-color` | 단색 |
| `body-pattern`, `corner-eye-pattern`, `corner-eye-dot-pattern` | 점, 눈, 눈 점의 모양 |
| `margin` | 여백 영역(모듈 단위)입니다 |
| `template-id` | 기본 제공 템플릿 |
| `module-scale` | 각 점의 크기(0.5~1)입니다 |
| `auto-level` | 로고에 필요하면 오류 정정 수준을 `H`로 높입니다 |
| `shape` | `square`, `circle`, `heart` |
| `label` | 스크린 리더가 읽어 주는 내용입니다(기본값 "QR code") |
| `props` | 그 밖의 모든 옵션(JSON)입니다 |

읽을 수 없는 숫자와 수준 값은 무시됩니다. 모든 패턴은 [스타일](/docs/styles)에서 확인하세요.

## 프로퍼티 [#properties]

각 속성은 옵션 이름과 같은 프로퍼티로도 사용할 수 있습니다. 예: `qr.fgColor`, `qr.bodyPattern`, `qr.templateId`. 객체인 옵션은 프로퍼티로만 사용할 수 있습니다. 그라디언트와 이미지 채우기, `frame`, `imageSettings`, `eyeColors`, `art`, `customTemplate`, `customProps`가 해당합니다. `props`는 모든 옵션을 한 번에 받습니다.

```js
const qr = document.querySelector("qrdx-code");

qr.fgColor = {
  type: "linear",
  angle: 45,
  stops: [
    { color: "#1d4ed8", offset: 0 },
    { color: "#0f172a", offset: 100 },
  ],
};
qr.frame = { style: "banner-bottom", text: "Scan me" };
qr.imageSettings = { src: "/logo.png", width: 40, height: 40, excavate: true };
qr.props = { margin: 2, eyeColor: "#be123c" };
```

- 속성이나 이름이 있는 프로퍼티는 `props`의 같은 옵션보다 우선합니다. 속성과 해당 프로퍼티 사이에서는 나중에 설정한 쪽이 우선합니다. 프로퍼티를 `undefined`로 설정하면 해당 값이 제거됩니다.
- 프로퍼티는 속성에 다시 기록되지 않습니다.
- 변경 사항은 일괄 처리됩니다. 연속으로 몇 번을 바꿔도 마이크로태스크에서 코드를 한 번만 다시 그리며, 마크업이 바뀐 경우에만 그립니다.
- `qr.options`는 코드를 그릴 때 사용하는 옵션이고, `qr.svg`는 그려진 `<svg>`입니다.
- 엘리먼트가 정의되기 전에 설정한 프로퍼티는 정의되는 시점에 반영됩니다.

스크립트 없이 사용하려면 객체 옵션을 JSON으로 `props` 속성에 넣으세요.

```html
<qrdx-code
  value="https://example.com"
  props='{"frame": {"style": "banner-bottom", "text": "Scan me"}}'
></qrdx-code>
```

공식 프레임은 엘리먼트 옆에 있는 파일에서 가져옵니다.

```js
import { getOfficialFrame } from "https://cdn.jsdelivr.net/npm/qrdx/dist/frames-official.mjs";

qr.frame = { style: "custom", spec: getOfficialFrame("wifi-card").spec };
```

## 내보내기 [#export]

```js
qr.toSVGString(); // the SVG markup
await qr.toDataURL("png", { size: 1024 }); // "png", "jpg", "webp", "svg", "pdf" or "eps"
await qr.download({ format: "svg", filename: "menu.svg" });
```

`qrdx/core`의 `toSVGString`과 `downloadQRCode`처럼 `qr.options`의 코드를 내보내며, 엘리먼트의 `part`, `role`, `aria-label`은 포함하지 않습니다. `toDataURL`과 `download`는 기본적으로 코드의 `size` 크기로 PNG를 만듭니다. 값이 없으면 오류가 발생하거나(`toSVGString`) 거부됩니다.

PDF에는 선택 사항인 `jspdf` 패키지가 필요합니다. CDN에서는 모듈 스크립트보다 앞에 import map을 두어 매핑하세요.

```html
<script type="importmap">
  { "imports": { "jspdf": "https://cdn.jsdelivr.net/npm/jspdf@4/+esm" } }
</script>
```

## 스타일링과 접근성 [#styling-and-accessibility]

코드는 열린 shadow root 안에 그려집니다. 페이지의 CSS는 경로(path)에 닿지 않으므로 `svg path { fill: red }`나 `svg { width: 100% }` 같은 규칙이 코드를 망가뜨릴 수 없습니다. 바깥에서 `<svg>`를 꾸미려면 `::part(svg)`를 사용하세요.

```css
qrdx-code::part(svg) {
  border-radius: 12px;
}
```

엘리먼트는 `inline-block`입니다. `<svg>`는 `size`를 유지하지만 더 좁은 컨테이너에서는 맞게 줄어듭니다.

`<svg>`에는 `role="img"`와, `label` 속성에서 가져온 `aria-label`이 있습니다. `label`이 없으면 "QR code"가 됩니다. 레이블은 값으로 대체되지 않습니다. 값에는 Wi-Fi 비밀번호나 연락처 정보가 들어 있을 수 있기 때문입니다.

## 오류 [#errors]

값이 QR 코드에 넣기에 너무 긴 경우처럼 코드를 그릴 수 없으면, 엘리먼트는 이전 코드를 지우고 `qrdx-error` 이벤트를 발생시킵니다. 오류는 `event.detail.error`에 담깁니다. 리스너가 `event.preventDefault()`를 호출하지 않으면 오류를 콘솔에 기록합니다. JSON 객체가 아닌 `props` 속성도 이 이벤트를 발생시킵니다.

```js
qr.addEventListener("qrdx-error", (event) => {
  event.preventDefault();
  showMessage("That text is too long for a QR code.");
});
```

## 서버 렌더링 [#server-rendering]

`toQRdxCodeHTML(options)`는 선언적 shadow root 안에 코드가 이미 그려진 엘리먼트 마크업을 반환합니다. 브라우저는 스크립트가 실행되기 전에 코드를 보여 주고, 엘리먼트가 정의되면 그때부터 엘리먼트가 이어받습니다. Node에서 실행되며 DOM이 필요 없습니다.

```js
import { toQRdxCodeHTML } from "qrdx/element";

const html = toQRdxCodeHTML(
  {
    value: "https://example.com",
    size: 256,
    frame: { style: "banner-bottom", text: "Scan me" },
  },
  { label: "Link to example.com" }
);
// <qrdx-code value="https://example.com" size="256" label="Link to example.com"
//   props="{…}"><template shadowrootmode="open">…</template></qrdx-code>
```

단순한 옵션은 속성이 되고 나머지는 JSON으로 `props`에 들어가므로, 엘리먼트는 같은 옵션을 그대로 읽어 들입니다. `customTemplate`은 마크업으로 쓸 수 없으니 브라우저에서 프로퍼티로 설정하세요. 다른 이름으로 등록했다면 `tagName`을 전달하세요.

## React 19 [#react-19]

React 19는 엘리먼트에 해당 프로퍼티가 있으면 prop을 프로퍼티로 설정하므로, 객체도 prop으로 사용할 수 있습니다. 렌더링하기 전에 엘리먼트를 한 번 등록하세요.

```tsx
import "qrdx/element/define";

export function MenuCode({ url }: { url: string }) {
  return (
    <qrdx-code
      value={url}
      size={256}
      body-pattern="rounded"
      frame={{ style: "banner-bottom", text: "Scan me" }}
      label="Menu"
    />
  );
}
```

TypeScript에서는 `.d.ts` 파일에서 엘리먼트를 JSX에 추가하세요.

```ts
import type { QRdxCodeElement, QRdxCodeJSXProps } from "qrdx/element";

declare module "react" {
  namespace JSX {
    interface IntrinsicElements {
      "qrdx-code": React.DetailedHTMLProps<
        React.HTMLAttributes<QRdxCodeElement>,
        QRdxCodeElement
      > &
        QRdxCodeJSXProps;
    }
  }
}
```

`ref`로 엘리먼트를 가져와 `toDataURL`과 `download`에 사용할 수 있습니다.

## Vue [#vue]

Vue 컴파일러에 `qrdx-code`가 커스텀 엘리먼트라고 알려 주세요.

```js
// vite.config.js
import vue from "@vitejs/plugin-vue";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [
    vue({
      template: {
        compilerOptions: { isCustomElement: (tag) => tag === "qrdx-code" },
      },
    }),
  ],
});
```

그런 다음 `main.js`에서 `qrdx/element/define`을 한 번 import하고 템플릿에서 옵션을 바인딩하세요. 엘리먼트에 해당 프로퍼티가 있으면 Vue는 바인딩을 프로퍼티로 설정합니다.

```vue
<qrdx-code
  :value="url"
  :size="256"
  body-pattern="rounded"
  :frame="{ style: 'banner-bottom', text: 'Scan me' }"
  label="Menu"
/>
```
