ホスト型のランディングページは、QRdx が `https://qrdx.dev/p/<slug>`（または[カスタムドメイン](/docs/custom-domains)）で配信するモバイル向けページです。どのページにも[動的QRコード](/docs/dynamic-qr-codes)が付属するため、コードを印刷した後でもページを編集でき、すべてのスキャンを確認できます。

## ページを作成する [#create-a-page]

1. [ダッシュボード → ページとフォーム](/dashboard?to=pages)を開いて **新規ページ** をクリックします。または、コード一覧で **新規コード** をクリックし、**Webサイトリンク** の代わりにページタイプを選びます。
2. {facts.hostedPageTypes}種類の[ページタイプ](#page-types)から1つ選び、そのギャラリーからテンプレートを選びます。
3. **ページを作成** をクリックします。テンプレートのブロックが入った状態でエディタが開き、QRコードは **QRコード** からダウンロードできます。

すでにWebサイトを開くコードを印刷済みですか？そのコードを開いて **タイプを変更** をクリックすると、同じ短縮リンクのままページに切り替えられます。[印刷済みのコードの開き先を変更する](/docs/help/dynamic-codes/change-the-type)をご覧ください。

テンプレートには、ページの構成がわかるようにサンプルの名前、価格、数値、写真が入っています。初めて公開するまでは、エディタが自分の内容に置き換えるよう通知します。

## ページタイプ [#page-types]

どのページタイプも出発点にすぎません。どのページにも任意のブロックを追加でき、あるタイプで作ったページを別のタイプのような見た目にすることもできます。

| ページタイプ | 用途 | 初期の内容 |
| --- | --- | --- |
| **リンク集** | プロフィール用リンク、クリエイター、ポッドキャスト | プロフィールヘッダー、リンク、SNSアイコン |
| **ソーシャルメディア** | すべてのプロフィールを1つのコードにまとめる | プロフィールヘッダー、ネットワークごとに1行（ハンドル名入り） |
| **ビジネス** | 店舗、サロン、オフィス | 営業時間、住所と地図、連絡先、行動喚起 |
| **vCard Plus** | デジタル名刺 | **連絡先を保存** 付きの連絡先カード |
| **メニュー** | カフェ、レストラン、バー | メニュー、Wi-Fi、営業時間（[詳細](/docs/forms-and-pages#menu)） |
| **クーポン** | 割引や無料特典 | バーコードと **利用する** 付きのクーポン（[詳細](/docs/forms-and-pages#coupon)） |
| **イベント** | パーティー、カンファレンス、ウェビナー、結婚式 | カレンダー追加付きのイベント（[詳細](/docs/forms-and-pages#event)） |
| **アプリダウンロード** | 1つのコードですべてのアプリストアに対応 | アプリダウンロード（[詳細](/docs/forms-and-pages#app-download)） |
| **フィードバックとフォーム** | レビュー、NPSアンケート、登録 | フォームとレビューのリンク（[詳細](/docs/forms-and-pages#forms)） |
| **商品** | パッケージ、ラベル、下げ札 | 原材料、アレルゲン、栄養成分、認証、お手入れ方法、GS1 Digital Link（[詳細](/docs/product-pages)） |
| **予約** | サロン、クリニック、家庭教師 | サービスと料金、予約リクエストフォーム、営業時間 |
| **支払いとチップ** | チップ箱、寄付、請求書 | 支払いリンクと、コピーできる銀行口座情報 |
| **不動産物件** | 売買・賃貸物件、オープンハウス | 価格と物件情報、写真、担当者、内覧リクエストまたは受付フォーム |
| **ペットIDタグ** | 首輪のタグ、迷子ペットのポスター | 通話ボタン、ペットの情報、「見つけました」フォーム |
| **医療ID** | タグ、リストバンド、アレルギーカード | 緊急連絡先、持病、アレルギー、服用中の薬 |
| **PDF** | パンフレット、マニュアル、資料ライブラリ | 閲覧またはダウンロードできるPDF、または複数のファイル |
| **画像** | ギャラリー、ポートフォリオ | フォトギャラリー |
| **MP3 / オーディオ** | 音楽、ポッドキャスト、音声メッセージ | オーディオプレーヤー |
| **動画** | 商品動画、クリップ | 動画 |
| **プレイリスト** | ミックス、音声ツアー、オーディオブック | 続けて再生される複数のトラック |
| **カスタムページ** | その他すべて | 空白のページまたはお知らせ |

ファイルのアップロードが設定されていない環境では、アップロードを前提とするタイプ（PDF、画像、MP3 / オーディオ、動画、プレイリスト）は選択画面に表示されません。

**予約** は、予約リクエストをページの[回答](/docs/forms-and-pages#responses)と通知に送信し、お使いの予約ツールへのリンクも設定できます。空き時間をリアルタイムで表示するカレンダーはなく、各リクエストはご自身で確定します。

**支払いとチップ** がお支払いを受け付けることはありません。各ボタンは決済アプリ（PayPal、Venmo、Cash App、Revolut、Wise）の専用ページを開き、銀行口座情報、UPI ID、ウォレットアドレスにはコピーボタンが付いています。

**ペットIDタグ** と **医療ID** のページは、コードをスキャンした人なら誰でも閲覧できます。ペットを見つけた人や緊急時に助けてくれる人の役に立つ情報だけを追加してください。

## 編集と公開 [#edit-and-publish]

エディタには3つのタブとスマートフォンのライブプレビューがあります。プレビュー内のブロックをタップすると、そのブロックの設定に移動します。

- **ブロック**: **ブロックを追加** でブロックを追加し、ドラッグ（または矢印ボタン）で並べ替えます。ブロックは削除せずに非表示にしたり、複製や削除をしたりできます。ブロックごとに専用のフォームがあります。問題（たとえば `https://` のないリンク）はブロック上に表示され、公開前に修正が必要です。
- **デザイン**: [保存済みのQRテーマ](/dashboard?to=themes)のいずれかの色を使うと、印刷したコードとページの見た目をそろえられます。プリセットのパレットを選ぶことも、各色を自分で設定することもできます。フォント、角丸の半径、単色・グラデーション・画像の背景、任意のロゴを選べます。**色を合わせる** は、背景色とアクセントカラーから読みやすい文字色とカードの色を自動で決め、文字のコントラストが低いと警告が表示されます。
- **設定**: 共有プレビューの説明と画像、検索エンジンにページのインデックスを許可するか（デフォルトはオフ）、ビジネスのカスタムCSSを設定します。

**公開** をクリックする（または <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>S</kbd> を押す）と、変更が反映されます。公開するまで、訪問者には何も変わりません。未公開の編集内容はブラウザーに保存されるため、タブを閉じた後でも復元できます。公開するたびにバージョンとして保存されます。編集中にチームメンバーが同じページを公開した場合、QRdx は相手の変更を上書きせず、再読み込みをお願いします。

## 基本ブロック [#core-blocks]

| ブロック | 表示内容 |
| --- | --- |
| プロフィールヘッダー | 写真またはロゴ、名前、自己紹介、任意のカバー画像 |
| テキスト | 見出しと段落（改行は保持されます） |
| ボタン | 行動喚起を1つ：Webリンク、メールアドレス、電話番号 |
| リンク集 | リンクボタンの積み重ね。Instagram、YouTube、WhatsApp などのサイトアイコン付き |
| SNSアイコン | プロフィールを丸いアイコン、ボタン、またはハンドル名付きのリストで表示 |
| 画像 | 写真またはバナー（リンクの設定も可能） |
| 動画 | YouTube、Vimeo、Loom の動画。訪問者が再生をタップして初めて動画サイトから読み込まれます |
| 連絡先カード | 名前、役職、電話番号、メールアドレス、Webサイト、住所、クイックアクション（通話、WhatsApp、メール、道順）、**連絡先を保存**、**共有** |
| 住所と地図 | 住所と、Google マップおよび Apple マップの道順。埋め込み地図も任意で表示できます |
| 営業時間 | 曜日ごとの時間（中抜けの営業や深夜0時をまたぐ営業にも対応）と、お使いのタイムゾーンでの **営業中** バッジ |
| 詳細 | ラベルと値を、リストまたはタイルのグリッドで表示（寝室数、品種、血液型、内容量など） |
| 商品詳細 | 認証、原材料、アレルゲン、栄養成分表、タップで開くセクション、GTIN（[詳細](/docs/product-pages)） |
| 支払いリンク | PayPal、Venmo、Cash App、Revolut、Wise、UPI、銀行振込、暗号資産ウォレット。ボタンで各アプリを開き、詳細情報にはコピーボタンが付きます。ページがお支払いを受け付けることはありません。 |
| 区切り線、スペーサー | レイアウト用の補助ブロック |

### vCard Plus と連絡先の保存 [#vcard-plus-and-save-contact]

**連絡先を保存** をタップすると、スマートフォンの連絡先アプリで開ける vCard 3.0 ファイル（`.vcf`）がダウンロードされます。ファイルには、名前、会社名、役職、電話番号、メールアドレス、Webサイト、住所、自己紹介、ページのSNSプロフィール、写真が含まれます。QRdx のストレージにアップロードした写真はファイルに埋め込まれ、他のサイトにある写真はリンクとして含まれます（QRdx が他のサイトの画像をダウンロードすることはありません）。**共有** をタップするとスマートフォンの共有シートが開き、パソコンではページのリンクがコピーされます。

## プラン [#plans]

| | フリー | Pro | Business |
| --- | --- | --- | --- |
| ホスト型ページ | 3 | 無制限 | 無制限 |
| 「Made with QRdx」フッター | 表示 | 非表示 | 非表示 |
| ホワイトラベル（ブラウザのアイコンに自分のロゴを使用、QRdxのブランド表示なし） | — | — | ✓ |
| カスタムCSS | — | — | ✓ |

上限によって制限されるのは、新しいページの作成だけです。すでに作成したページは、ダウングレード後も含め、どのプランでも引き続き動作します。Businessからダウングレードした場合は、カスタムCSSが適用されなくなるだけです。また、各ページはご利用プランの動的QRコードを1つ使用します。詳しくは[プランと上限](/docs/plans-and-limits)をご覧ください。

### カスタムCSS（Business） [#custom-css-business]

**設定 → カスタムCSS** に通常のCSSを記述します。ルールはページ内でのみ適用されます。すべてのセレクタはページコンテンツにスコープされ、各ブロックは `.lp-block-<type>` で指定できます。たとえば `.lp-block-links a` や `.lp-block-contact h1` のように指定します。安全のため、CSSからファイルを読み込むこと（`url()`、`@import`、`@font-face`）やバックスラッシュによるエスケープは使用できません。また、使用できるアットルールは `@media`、`@supports`、`@container`、`@keyframes` のみです。

## 訪問者が得られるもの [#what-visitors-get]

- スマートフォン向けに作られた、サーバーレンダリングによる高速なページです。QRdxのアナリティクスやチャットのスクリプトは含まれません。トラッキングピクセルは、コードに自分で追加した場合にのみ読み込まれます。
- **検索エンジンに表示** をオンにしない限り、検索エンジンには表示されません。
- チャットアプリやSNS向けの共有プレビュー（タイトル、説明、画像）に対応しています。パスワードで保護されたコードでは、プレビューにページの詳細が表示されることはありません。
- すべてのページに、小さな **不正を報告** リンクが表示されます。ホワイトラベルのページも同様です。

[コードの管理](/docs/code-controls)にあるパスワード保護、開始日と終了日、スキャン数の上限、一時停止は、ページとその **連絡先を保存** ファイルにも適用されます。ページのリンクを直接開いた場合も同様です。
