QRdxには3つのプランがあります。Playgroundと`qrdx`ライブラリで作成する静的QRコードは、アカウント不要で、どのプランでも無料かつ無制限です。料金は[料金ページ](/pricing)で比較できます。

| | フリー | Pro | Business |
| --- | --- | --- | --- |
| 料金（米ドル） | $0 | $5/月 または $48/年 | $15/月 または $144/年 |
| 料金（インド） | ₹0 | ₹199/月 または ₹1,499/年 | ₹599/月 または ₹4,999/年 |

インドからのアクセスでは、料金がルピーで表示されます。決済は[Polar](https://polar.sh)が処理します。Polarはインドのお客様にはルピー（₹）、それ以外のお客様には米ドル（US$）で請求し、該当する場合は現地の税金を加算します。

## 制限 [#limits]

| | フリー | Pro | Business |
| --- | --- | --- | --- |
| 動的QRコード | 10 | 無制限 | 無制限 |
| スキャン | 無制限 | 無制限 | 無制限 |
| ホスト型ランディングページ | 3（フッターに「Made with QRdx」を表示） | 無制限、フッターなし | 無制限、ホワイトラベル、カスタムCSS |
| 分析の履歴 | 90日 | 3年 | 無制限 |
| カスタムドメイン | なし | 5 | 25 |
| カスタムバックハーフ（`qrdx.dev/q/spring-menu`） | 不可 | 可 | 可 |
| ワークスペースあたりのメンバー数 | 1（自分のみ） | 3 | 無制限 |
| ワークスペースの追加 | 不可 | 可 | 可 |
| スマートルーティング、A/Bテスト、UTMタグ | 不可 | 可 | 可 |
| パスワード、スケジュール、有効期限、スキャン数の上限 | 不可 | 可 | 可 |
| リターゲティングピクセル | 不可 | 可 | 可 |
| コンバージョン計測 | 不可 | 不可 | 可 |
| メールダイジェストとアラート | 不可 | 可 | 可 |
| Webhook、Zapier、Slack | 不可 | 不可 | 可 |
| OAuthアプリ（[インテグレーションを作成する](/docs/developers/build-an-integration)） | 1 | 5 | 25 |
| ファイルストレージ（最大ファイルサイズ） | 50 MB（10 MB） | 5 GB（100 MB） | 50 GB（250 MB） |
| 月間のフォーム回答数 | 50 | 1,000 | 10,000 |
| 1日あたりのAPIリクエスト数 | 1,000 | 10,000、一括作成を含む | 100,000、一括作成を含む |
| 月間のAIアート画像数 | 3 | 30 | 150（ワークスペース全体で共有） |
| AIテーマ生成 | 合計5回 | 無制限 | 無制限 |
| 保存済みテーマ | 10 | 無制限、ワークスペースと共有可能 | 無制限、ワークスペースと共有可能 |
| 保存済み[バーコード](/docs/developers/barcode-api#saved-barcodes) | 1,000 | 10,000 | 100,000 |

コード数の上限に含まれるのは、有効な動的QRコードのみです。アーカイブしたコードは含まれません。スキャンはどの項目にも数えられず、アクセス量を理由にコードが一時停止されることもありません。スキャン数の上限は、コードごとにご自身で設定したものだけです。

API の利用枠はワークスペースごとで、00:00 UTCにリセットされます。カウント対象の各リクエストは`X-RateLimit-Limit`、`X-RateLimit-Remaining`、`X-RateLimit-Reset`を返すので、残りを確認できます。1分あたりの制限については[REST API](/docs/developers/rest-api)をご覧ください。

## ワークスペース [#workspaces]

制限は[ワークスペース](/docs/teams)ごとに個別に適用されます。ワークスペースには、オーナーと[請求担当メンバー](/docs/teams#roles)のうち最上位のプランが適用されます。すべてのユーザーには、自分がオーナーとなるワークスペースが自動で作成され、そのワークスペースにはご自身のプランが適用されます。それ以外のワークスペースでは、オーナーの1人がBusinessであれば、全員にBusinessの制限が適用されます。メンバーが個別にサブスクリプションを契約する必要はありません。

ワークスペースを追加で作成するには、ProまたはBusinessが必要です。オーナーと請求担当メンバーがフリーのワークスペースは1席（自分のみ）、Proは最大3席、Businessは無制限です。席数には、オーナーを含むメンバーと保留中の招待が数えられます。席を空けるには、不要になった招待を取り消してください。オーナーのプランが変わっても、現在のメンバーはそのままです。ブロックされるのは新しい招待のみです。

## 制限を超えた場合、ダウングレード、キャンセル [#going-over-a-limit-downgrading-and-cancelling]

<Callout type="info">
  制限で止まるのは、新しく作成する操作だけです。既存のコードは、ダウングレード、支払いの失敗、キャンセルの後でも、どのプランでもリダイレクトされ続けます。これが[Never-Hostage保証](/guarantee)です。
</Callout>

- **制限を超えた場合：** 上限を下回るまで、新しく作成できません。すでにあるものの編集、アーカイブ、エクスポートは引き続き可能です。
- **1日のAPI利用枠を超えた場合：** 00:00 UTCまで、API呼び出しは`429`を返します。コードのリダイレクトとウェブサイトは引き続き動作します。
- **ダウングレード：** コード、ランディングページ、確認済みのカスタムドメインは引き続き動作します。分析には、新しいプランに含まれる期間の履歴が表示されます。
- **キャンセル：** お支払い済みの期間が終わるまでプランは有効で、その後アカウントはフリーに移行します。
- **支払いの失敗：** サブスクリプションが失効した時点で、キャンセルと同じ扱いになります。一時停止されるものはありません。

有効期限、一時停止、スキャン数の上限など、ご自身で選んだ理由で終了したコードは、スキャンした人をフォールバックURL、または中立的な「This campaign has ended」ページに案内します。QRdxのページに案内されることはありません。

## 請求 [#billing]

アップグレードは[料金ページ](/pricing)から行います。プランの変更、月払いと年払いの切り替え、カードの更新、キャンセルを行うには、設定の**Manage subscription**を開いてください。Polarの請求ポータルに移動します。サブスクリプションはアカウントごとに1つなので、契約中のプラン変更は、新しいチェックアウトではなくポータルから行います。

## セルフホスト [#self-hosting]

[セルフホスト](/docs/self-hosting)したインスタンスにも、同じプランが適用されます。制限は`apps/docs/lib/plans.ts`という1つのファイルで定義されており、インスタンスに合わせて変更できます。Polarを設定していない場合、アップグレードは利用できず、すべてのアカウントにフリーの制限が適用されます。
