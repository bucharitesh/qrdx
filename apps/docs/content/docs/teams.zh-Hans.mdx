你在 QRdx 中创建的一切都属于某个工作区：动态二维码和[托管页面](/docs/landing-pages)、[文件](/docs/files)、[自定义域名](/docs/custom-domains)、文件夹和标签、表单回复、[Webhook](/docs/webhooks)以及 API 密钥。已保存的主题归你个人所有，所有者和管理员可以把副本共享到工作区，让每位成员都使用同样的配色进行设计。控制台的每个页面，网址中都包含工作区（`/dashboard/<workspace>/…`）。使用侧边栏底部的工作区切换器切换工作区（在手机上位于菜单中）；切换后你会停留在同一个栏目，例如所选工作区的二维码或设置 → 域名。

## 你自己的工作区 [#your-own-workspace]

每个账户都有一个自己的工作区，由系统自动创建，你是它的所有者。它使用你的套餐。你可以重命名它并更改其网址，但不能退出或删除它：只有在你[删除账户](/docs/help/account-and-billing/delete-your-account)时它才会随之删除。在 Pro 或 Business 上，你可以邀请其他人加入这个工作区，也可以只自己使用，再为每个团队或客户单独创建工作区。

## 创建其他工作区 [#create-another-workspace]

创建更多工作区需要 Pro 或 Business。任何人都可以加入受邀的工作区，包括使用免费版的用户。

1. 打开工作区切换器，点击 **创建工作区**。
2. 输入 **工作区名称** 和 **工作区网址**（3 到 48 个小写字母、数字和短横线）。你输入时，QRdx 会实时检查该网址是否可用；`codes`、`settings` 等少数词语为保留词。
3. 点击 **创建工作区**。工作区会打开，你是它的所有者。

## 邀请成员 [#invite-people]

所有者和管理员可以在[设置 → 团队](/dashboard?to=settings/team)中邀请成员：

1. 输入对方的邮箱地址并选择角色：**管理员**、**成员** 或 **查看者**。所有者还可以将对方邀请为 **账单**。
2. QRdx 会通过邮件向对方发送邀请。每个邀请还附带一个链接，你可以复制后自行发送。
3. 对方打开链接，使用受邀的邮箱地址登录，然后点击 **接受邀请**。随后工作区就会为对方打开。

邀请他人成为管理员时，需要你先[确认是你本人操作](/docs/help/privacy-and-security/two-step-verification#confirm-its-you)，除非你在该浏览器中 10 分钟内已确认过。

邀请在 48 小时后过期，并且只对收件的邮箱地址有效，因此转发的链接无法被其他人使用。待处理的邀请在被接受之前会占用一个席位，所以请撤销不再需要的邀请。

## 加入链接 [#join-link]

加入链接是面向整个团队的同一个链接：只要还有空闲席位，任何已登录并打开它的人都会加入工作区。所有者和管理员可以在 Pro 和 Business 上于[设置 → 团队](/dashboard?to=settings/team)中管理它：

1. 选择人们加入时获得的角色（默认为 **成员**；不能是所有者，且只有所有者可以创建 **账单** 链接），然后点击 **创建加入链接**。以管理员身份添加成员的链接，需要你先[确认是你本人操作](/docs/help/privacy-and-security/two-step-verification#confirm-its-you)。
2. 复制链接并分享。出于安全考虑，它只显示一次；QRdx 保存的是它的指纹，而不是链接本身。
3. 链接丢了，或者被发到了不该去的地方？点击 **重置链接**：旧链接会失效，你会得到一个新链接。**关闭** 则会永久停用它。

未登录的人会先登录，然后回到该链接。已经是成员的人会收到相应提示。席位用完后，将无法再加入，直到有席位空出。

## 角色 [#roles]

| | 查看者 | 账单 | 成员 | 管理员 | 所有者 |
| --- | --- | --- | --- | --- | --- |
| 查看二维码、页面和分析数据 | 是 | 是 | 是 | 是 | 是 |
| 创建和编辑二维码与页面、上传文件 | 否 | 否 | 是 | 是 | 是 |
| 删除二维码、文件和表单回复 | 否 | 否 | 仅限自己创建的 | 任意 | 任意 |
| 创建 API 密钥 | 否 | 否 | 是 | 是 | 是 |
| 与工作区共享已保存的主题 | 否 | 否 | 否 | 是 | 是 |
| 邀请和移除成员、更改角色 | 否 | 否 | 否 | 是 | 是 |
| 重命名工作区、更改其网址和徽标 | 否 | 否 | 否 | 是 | 是 |
| 添加、验证和移除自定义域名 | 否 | 否 | 否 | 是 | 是 |
| 管理 Webhook 端点并查看签名密钥 | 否 | 否 | 否 | 是 | 是 |
| 升级工作区套餐 | 否 | 是 | 否 | 否 | 是 |
| 创建和更改 OAuth 应用 | 否 | 否 | 否 | 否 | 是 |
| 将某人设为所有者或账单成员 | 否 | 否 | 否 | 否 | 是 |
| 删除工作区 | 否 | 否 | 否 | 否 | 是 |

查看者和账单成员只能读取：他们不能在工作区中创建、编辑或删除任何内容，并且 API 密钥的权限不会超过其创建者的角色。成员可以查看 Webhook 端点及其投递日志，并可以为自己的二维码使用工作区中已验证的域名。[通知设置](/docs/notifications)是个人设置：每位成员为每个工作区各自选择自己的提醒。

## 套餐与席位 [#plans-and-seats]

工作区使用其所有者和账单成员中最高的套餐，因此其中任何一人使用 Business，整个工作区就拥有 Business 的限额，成员无需各自订阅。这正是 **账单** 角色的用途：为工作区付费但不管理它的人。动态二维码、页面、存储空间和表单回复等限额按工作区计算。请参阅[套餐与限额](/docs/plans-and-limits)。

席位包括成员（含所有者）以及待处理的邀请：当所有者和账单成员使用免费版时为 1 个（仅你自己），Pro 最多 3 个，Business 不限。如果他们的套餐发生变化，现有成员会保留，所有二维码也会继续正常使用；只有新的邀请和超出限额的新内容会被阻止。

## 重命名、退出或删除工作区 [#rename-leave-or-delete-a-workspace]

这些操作位于工作区的[设置 → 常规](/dashboard?to=settings)中。

- **重命名：** 所有者和管理员可以更改名称和网址。指向旧网址的链接将失效；已印刷的二维码不受影响。
- **徽标：** 所有者和管理员可以上传徽标（需在服务器上配置文件存储），也可以使用 https 图片网址。它会显示在工作区切换器中；没有徽标时，切换器会显示名称的第一个字母。
- **退出：** 点击危险区域中的 **退出工作区**。最后一位所有者不能退出：请先将另一位成员设为所有者，或者删除工作区。任何人都不能退出自己的工作区。
- **移除成员：** 在[设置 → 团队](/dashboard?to=settings/team)中操作。该成员创建的二维码和页面会保留在工作区中。任何人都不能从自己的工作区中被移除。移除成员与更改其角色一样，需要你先[确认是你本人操作](/docs/help/privacy-and-security/two-step-verification#confirm-its-you)。
- **删除工作区：** 仅限所有者，且不能是任何人自己的工作区。你需要输入工作区网址来确认，QRdx 也会要求你确认是本人操作。不会有任何内容停止工作：二维码、页面、文件、域名和其他项目都会转移到其创建者各自的工作区。工作区的 API 密钥会随之一并删除。

## 将二维码移动到其他工作区 [#move-a-code-to-another-workspace]

在二维码页面中，打开该二维码的 **⋯** 菜单，选择 **移动到工作区...**，然后选择一个你有权创建二维码的工作区。短链接保持不变，因此已印刷的二维码仍可使用，其扫描记录和版本历史也会一并移动。它所在的文件夹和标签会留在原处，因为它们属于旧工作区。

- 成员可以移动自己创建的二维码；所有者和管理员可以移动任何二维码。
- 目标工作区的套餐必须还有空间容纳另一个启用中的二维码。已归档的二维码不计入。
- 链接使用自定义域名的二维码无法移动，因为该域名属于旧工作区，移动后其已印刷的链接将失效。打开托管页面的二维码会与其页面留在一起。

## API 访问 [#api-access]

使用 OAuth 访问令牌发出的 [REST API](/docs/developers/rest-api) 请求，作用于令牌所有者自己的工作区。[API 密钥](/docs/developers/api-keys)作用于创建它的工作区，并使用你在该工作区中的角色。从已登录的浏览器会话发出的请求，作用于该会话中最近打开的工作区。
