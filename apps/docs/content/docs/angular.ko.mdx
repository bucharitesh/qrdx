`qrdx/angular`는 독립형(standalone) Angular 컴포넌트 `<qrdx-qr-code>`를 제공하며, React 컴포넌트와 같은 엔진을 기반으로 합니다. React `<QRCode>`의 props를 시그널 입력으로 받고, 패턴, 색상과 그라디언트, 로고, 프레임, 모양, Art QR, 템플릿까지 바이트 단위로 동일한 SVG를 그려 냅니다. `@angular/ssr`로 서버에서 렌더링할 수 있고, 오류 없이 하이드레이션됩니다.

Angular 20 이상에서 동작하며, 프로덕션 빌드와 `ng serve` 모두에서 사용할 수 있습니다.

## 설치 [#install]

```package-install
qrdx@latest
```

`@angular/core`는 `qrdx`의 선택적 피어 의존성입니다. 따라서 설치해도 Angular를 쓰지 않는 앱에는 Angular가 추가되지 않고, 여러분의 앱에 React가 추가되는 일도 없습니다.

## 코드 그리기 [#draw-a-code]

`QRCode`를 가져와 컴포넌트의 `imports`에 추가하세요. NgModule은 필요 없습니다.

```ts title="app.ts"
import { Component, signal } from "@angular/core";
import { QRCode, type QRCodeProps } from "qrdx/angular";

@Component({
  selector: "app-root",
  imports: [QRCode],
  template: `
    <qrdx-qr-code
      [value]="url()"
      [size]="240"
      level="Q"
      bodyPattern="rounded"
      [fgColor]="fgColor"
      [frame]="{ style: 'banner-bottom', text: 'Scan me' }"
      aria-label="QR code for example.com"
    />
  `,
})
export class App {
  protected readonly url = signal("https://example.com");
  protected readonly fgColor: QRCodeProps["fgColor"] = {
    type: "linear",
    angle: 45,
    stops: [
      { color: "#1d4ed8", offset: 0 },
      { color: "#0f172a", offset: 100 },
    ],
  };
}
```

입력이 바뀌면 코드를 다시 그립니다. 변경되어도 마크업이 같으면 페이지는 건드리지 않습니다.

## 입력 [#inputs]

React `<QRCode>`의 모든 prop은 이름과 타입이 같은 입력으로 제공되며, Angular가 템플릿을 컴파일할 때 바인딩을 이에 맞춰 검사합니다. `value`는 필수입니다.

| 입력 | 역할 |
| --- | --- |
| `value`, `size`, `level`, `margin`, `autoLevel` | 콘텐츠, 픽셀 크기, 오류 정정, 여백(quiet zone), 큰 로고를 위한 레벨 자동 상향 |
| `fgColor`, `bgColor`, `eyeColor`, `dotColor`, `eyeColors` | 색상, 그라디언트, 이미지 채우기 |
| `bodyPattern`, `cornerEyePattern`, `cornerEyeDotPattern`, `moduleScale` | 점과 눈 모양 |
| `logo`, `logoOptions`, `hideLogo`, `scale` | 가운데 로고. `<QRCode>`와 같은 방식으로 배치됩니다 |
| `frame`, `shape`, `art` | 행동 유도 문구가 있는 프레임, 원형과 하트 윤곽, Logo QR, Image QR |
| `templateId`, `customTemplate`, `customProps` | 템플릿 |
| `frameLabelMarkers`, `partMarkers` | 에디터 실시간 미리보기용 마커 |
| `svgStyle` | `<svg>`에 적용하는 인라인 스타일(`QRCode`의 `style`) |

`style` 대신 `svgStyle`이라는 이름을 쓰는 이유는, `style`이라는 입력이 요소 자체의 `style` 속성을 가로채기 때문입니다. `<qrdx-qr-code>`에 지정한 `class`, `style`, `aria-label` 같은 속성은 이 요소에 그대로 남고, `<svg>`는 그 안쪽에 있습니다.

컴포넌트 자체 스타일은 `<svg>`에 적용되지 않습니다. Angular가 스타일 범위를 템플릿 안의 요소로 제한하기 때문입니다. 코드가 컨테이너를 가득 채우게 하려면 `svgStyle`을 사용하세요.

```html
<qrdx-qr-code value="https://example.com" [svgStyle]="{ width: '100%', height: 'auto' }" />
```

## 다운로드와 내보내기 [#download-and-export]

이 컴포넌트는 `qrdx/vanilla`처럼 그려 낸 코드를 다운로드하고 내보낼 수 있습니다. 템플릿 참조 변수나 `viewChild(QRCode)`로 접근하세요.

```html
<qrdx-qr-code #qr value="https://example.com" [size]="256" />
<button type="button" (click)="qr.download({ format: 'svg' })">Download SVG</button>
```

- `download({ format, size, filename, quality })`는 파일을 저장합니다. 기본값은 PNG이며, `"jpg"`, `"webp"`, `"svg"`, `"pdf"`, `"eps"`도 사용할 수 있습니다. PDF에는 선택 패키지인 `jspdf`가 필요합니다.
- `toDataURL(format, { size, quality })`는 코드를 데이터 URL로 반환합니다.
- `markup()`은 SVG 마크업, `options()`는 코드를 그리는 데 쓰인 props, `svg`는 `<svg>` 요소입니다.

`qrdx/core`의 모든 항목은 `qrdx/angular`에서도 내보내므로, `toSVGString`, `downloadQRCode`, `getScanScore` 등을 같은 import에서 가져올 수 있습니다.

## 서버 렌더링과 하이드레이션 [#server-rendering-and-hydration]

`@angular/ssr`를 사용하면 서버가 보내는 HTML에 이미 코드가 들어 있어, 앱이 로드되기 전에도 코드가 표시됩니다. 브라우저에서는 Angular가 페이지를 하이드레이션하면서 `<qrdx-qr-code>` 요소를 유지하고, 컴포넌트는 서버와 동일한 코드를 다시 그립니다. `ngSkipHydration`은 필요 없습니다.

출력에는 무작위 id가 없으므로 서버와 브라우저가 같은 마크업을 그립니다.
