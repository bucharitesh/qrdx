QRdxは、[`qrdx`](https://www.npmjs.com/package/qrdx)ライブラリをベースにしたQRコードコンポーネントの[shadcn/ui](https://ui.shadcn.com)レジストリを公開しています。shadcn CLIがソースコードをプロジェクトにコピーするため、コードは自分のものとして扱え、自由に変更できます。

<NpmStatus package="qrdx" />

<PackageManagerTabs command="npx shadcn@latest add https://qrdx.dev/r/qr-code.json" />

各コンポーネントには専用のページがあり、ライブプレビュー、ソースコード、インストール手順、使用例、APIリファレンスを掲載しています。

[Playgroundで試す](/playground?open=code&lang=shadcn)：Playgroundでコードのスタイルを整えたら、レジストリのQR Codeコンポーネント用にコピーできます。

## インストールされるもの [#what-gets-installed]

各コンポーネントは`components/`内の単一ファイルです。CLIは`qrdx`（コンポーネントによってはアイコン用の`lucide-react`も）をインストールし、ベースとなるshadcn/uiのコンポーネント（`button`、`card`、`dialog`、`dropdown-menu`、`input`など）も追加します。

全体のインデックスは[`https://qrdx.dev/r/registry.json`](https://qrdx.dev/r/registry.json)にあります。

## レジストリの名前空間を使う [#using-the-registry-namespace]

短い名前でインストールするには、`components.json`にレジストリを追加します。

```json
{
  "registries": {
    "@qrdx": "https://qrdx.dev/r/{name}.json"
  }
}
```

そのあと、名前を指定してコンポーネントを1つまたは複数追加します。

<PackageManagerTabs command="npx shadcn@latest add @qrdx/qr-code @qrdx/qr-code-download @qrdx/qr-code-share-dialog" />

## スタイリング [#styling]

コンポーネントはTailwindのクラスと、標準のshadcn/uiテーマトークン（`bg-card`、`border`、`text-muted-foreground`、`ring-ring`）を使い、プロジェクト内のButton、Card、Dialog、Inputを利用します。そのため、テーマやダークモードにそのまま従います。QRコードの背景は、デフォルトでは明るい色のままです。明るいタイル上の暗いモジュールは、どのリーダーでもスキャンできるためです。

PDFのダウンロードには、オプションの`jspdf`パッケージが必要です（`npm install jspdf`）。
