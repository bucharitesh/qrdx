`@qrdx/cli` genera los mismos códigos QR que el Playground y la [biblioteca `qrdx`](/docs/getting-started) desde la línea de comandos. Nunca hace preguntas en scripts ni en CI, y cuando ejecutas `qrdx generate` sin argumentos en una terminal, te pide el contenido y las opciones paso a paso.

<NpmStatus package="@qrdx/cli" />

```bash
npx @qrdx/cli generate "https://example.com" -o qr.svg
```

Instálalo de forma global para obtener el comando `qrdx`:

```bash
npm install -g @qrdx/cli
qrdx generate "https://example.com" -o qr.png --size 1024
```

Requiere Node.js 22 o posterior. La salida en PNG y WebP usa [sharp](https://sharp.pixelplumbing.com), una dependencia opcional que npm instala donde tu plataforma lo permite; SVG y EPS funcionan sin ella. El paquete `qrdx` de npm es la biblioteca de React: la CLI solo está en `@qrdx/cli`.

## Formatos de salida [#output-formats]

La extensión del archivo determina el formato; usa `--format` cuando el nombre del archivo no tenga extensión.

| Formato | Úsalo para | Qué significa `--size` |
| --- | --- | --- |
| `.svg` | Páginas web, herramientas de diseño, escalar sin pérdida | Ancho en píxeles (por defecto 512) |
| `.png` | Documentos, presentaciones, cualquier lugar que necesite una imagen | Ancho en píxeles |
| `.webp` | Sitios web: los píxeles del PNG, sin pérdida, en un archivo más pequeño | Ancho en píxeles |
| `.eps` | Imprentas, Illustrator, InDesign | Ancho en puntos (72 por pulgada, así que `144` son 2 pulgadas) |

Los archivos EPS son PostScript vectorial. Los logotipos PNG y JPEG se incrustan tal cual; los demás formatos de logotipo se convierten con sharp si está instalado y, si no, se omiten con una advertencia.

## Opciones [#options]

| Opción | Por defecto | Descripción |
| --- | --- | --- |
| `-o`, `--output` | `qr.svg` | Archivo de salida |
| `--format` | según la extensión | `svg`, `png`, `webp` o `eps` |
| `--size` | `512` | Tamaño de salida (ver arriba) |
| `-l`, `--level` | `Q` | Corrección de errores: `L`, `M`, `Q` o `H` |
| `--body` | `square` | [Patrón](/docs/features/patterns) de los módulos de datos |
| `--eye` | `square` | Patrón del ojo de las esquinas |
| `--dot` | `square` | Patrón del punto del ojo de las esquinas |
| `--fg`, `--bg` | `#000000`, `#ffffff` | Primer plano y fondo: un color hexadecimal o un degradado en JSON |
| `--eye-color`, `--dot-color` | `--fg` | Colores del ojo y del punto del ojo de las esquinas |
| `--logo` | | URL de la imagen del logotipo central (úsalo con `--level H`) |
| `--margin` | `0` | Zona de silencio, en módulos |
| `--template` | | `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox` o `Halloween` |
| `--frame` | | [Marco](/docs/features/frames) con llamada a la acción: cualquiera de los {facts.frameStyles} estilos de marco, como `banner-bottom`, `rounded-border`, `circle`, `sticker` o `phone` (consulta [todos](/docs/styles#frames)) |
| `--frame-text` | `Scan me` | Etiqueta del marco, hasta 24 caracteres |
| `--frame-color`, `--frame-text-color` | | Colores del marco y de la etiqueta (hexadecimal) |

`qrdx --help` muestra todos los nombres de patrones. Los valores no válidos terminan con el código `1` y un mensaje que lista los valores aceptados.

## Muchos códigos desde un CSV [#many-codes-from-a-csv]

`qrdx batch` escribe en una carpeta un código QR estático por cada fila de un archivo CSV:

```bash
qrdx batch products.csv -o codes --format png --size 1024 --body circle
```

Lee las mismas columnas que el [generador masivo](/tools/bulk): el contenido, de una columna llamada `value`, `url`, `link`, `data`, `content`, `text` o `qr` (si no, la primera columna), y los nombres de archivo, de una llamada `file name`, `name`, `label`, `id`, `title` o `sku` (si no, `qr-00001`, `qr-00002` y así sucesivamente). Elige otras por el nombre del encabezado o el número de columna:

| Opción | Por defecto | Descripción |
| --- | --- | --- |
| `-o`, `--out` | `qr-codes` | Carpeta para los códigos |
| `--format` | `svg` | `svg`, `png` o `eps` |
| `--value-column` | se deduce | Columna con el contenido de cada código |
| `--name-column` | se deduce | Columna con los nombres de archivo |
| `--no-header` | | La primera fila es un código, no nombres de columna |
| `--jobs` | `4` para SVG, `8` en los demás casos | Códigos generados a la vez |

Todas las opciones de estilo anteriores se aplican a todos los códigos. El CSV se lee como un flujo y cada código se guarda en cuanto se genera, así que el comando no tiene límite de filas: en un portátil, 10.000 códigos SVG tardaron unos 40 segundos y usaron menos de 200 MB de memoria. No se sube nada y no hace falta cuenta. Las filas que no se pueden codificar se omiten y se listan con el motivo en `errors.csv`, dentro de la carpeta de salida.

Para imprimir [códigos dinámicos](/docs/dynamic-qr-codes) en masa, créalos primero (con la importación CSV del panel o con la API) y ejecuta `qrdx batch` sobre el CSV de resultados que te da la importación, con `--value-column short_link`.

## Ejemplos [#examples]

```bash
# High-resolution PNG for print
qrdx generate "https://example.com" -o qr.png --size 2048 --level H

# Vector EPS, 2 inches wide, for a print shop
qrdx generate "https://example.com" -o qr.eps --size 144

# Branded colors and patterns
qrdx generate "https://example.com" --body circle --eye rounded --fg "#1a1a2e" -o brand.svg

# Gradient foreground
qrdx generate "https://example.com" -o gradient.svg \
  --fg '{"type":"linear","stops":[{"color":"#6366f1","offset":0},{"color":"#ec4899","offset":100}],"angle":135}'

# "Scan for the menu" frame
qrdx generate "https://example.com/menu" --frame banner-bottom --frame-text "Scan for the menu" -o menu.png

# Wi-Fi network
qrdx generate "WIFI:T:WPA;S:MyNetwork;P:MyPassword;;" -o wifi.svg
```

Para imprimir un [código QR dinámico](/docs/dynamic-qr-codes), pasa su enlace corto (`https://qrdx.dev/q/<slug>`) como dato.
