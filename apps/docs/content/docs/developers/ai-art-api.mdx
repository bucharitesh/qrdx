`POST https://api.qrdx.dev/v1/art` paints a QR code into AI artwork from a description and returns the image. It's the same [AI QR art](/ai/art) as the playground's Art tab and the studio: {facts.artModel} paints the picture, then QRdx checks that it scans to your content before you get it. Where the model's image doesn't scan as drawn, QRdx strengthens the code just enough, on the model's own pixels.

It needs an [API key](/docs/developers/api-keys) with the `codes:write` scope (**Full access** keys have it). Each image uses one of the monthly AI art images of the key's workspace, the same allowance the app uses.

```bash
curl https://api.qrdx.dev/v1/art \
  -H "Authorization: Bearer $QRDX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text": "https://qrdx.dev", "prompt": "a koi pond at dusk, ink and watercolor"}' \
  --max-time 90 -o art.json
```

A call takes about 15 to 45 seconds. Give your HTTP client a timeout of at least 60 seconds.

## Encode a link or a dynamic code [#encode]

Send exactly one of these:

- `text`: the link or text the code holds, up to 300 characters. The art is a picture, so its content can't change after you print it.
- `code`: the `id` of one of the workspace's [dynamic codes](/docs/dynamic-qr-codes). The art encodes the code's short link, so you can change where it goes after printing, and its scans show in analytics. A code from another workspace, or one in the trash, is a `404`.

```bash
curl https://api.qrdx.dev/v1/art \
  -H "Authorization: Bearer $QRDX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"code": "cm5code0spring0menu00001", "prompt": "a bistro chalkboard menu on a brick wall", "mode": "scene"}' \
  --max-time 90
```

Get a code's `id` from [`GET /v1/codes`](/docs/developers/api/list-codes) or when you [create one](/docs/developers/api/create-codes).

## Request

| Field | Default | Description |
| --- | --- | --- |
| `text` | | What the code encodes. Send this or `code` |
| `code` | | A dynamic code's `id`, in place of `text` |
| `prompt` | | The artwork to paint, in plain words |
| `mode` | `code` | How the code sits in the art; see [Modes](#modes) |
| `style` | | A quick look's id, combined with your prompt; see [Quick looks](#quick-looks) |
| `negativePrompt` | | What to keep out of the picture |
| `visibility` | `50` | QR visibility, `0` to `100`: higher shows the code more clearly, lower favors the picture |
| `creativity` | `45` | `0` follows the prompt literally, `100` interprets it freely |
| `seed` | random | Send a seed from an earlier response for a similar image |
| `reference` | | A reference image for colors and shapes, such as a logo or a palette |
| `photo` | | Photo mode only: the picture to paint the code into |

`reference` and `photo` are PNG or JPEG `data:` URLs (`data:image/jpeg;base64,…`), downsized to about 512 px on the longest side. They go to the model and are discarded: QRdx never stores or logs them. Larger images are refused with `413 AI_ART_IMAGE_TOO_LARGE`.

The [API reference](/docs/developers/api/create-art) has the full schema.

## Modes [#modes]

| `mode` | What you get |
| --- | --- |
| `code` | The code is the whole picture: your artwork painted into its modules, with plain finder squares and a light quiet zone around it. Scans most reliably |
| `scene` | A full-bleed picture with the code painted into something in it, such as a tiled wall, a field or a window, with the finder squares drawn as part of the scene |
| `photo` | Your own `photo`, with the code painted into it. Send the photo with this mode only |

## Quick looks [#quick-looks]

A quick look is a ready-made style, such as a medium or a mood, that QRdx combines with your own `prompt`. Send its id as `style`. The looks are the ones offered as chips in the [AI art studio](/ai/art) and the playground's Art tab.

## Response

```json
{
  "data": {
    "imageUrl": "data:image/png;base64,iVBORw0KGgo…",
    "width": 1024,
    "height": 1024,
    "seed": 2841337190,
    "mode": "code",
    "blend": "least",
    "blendStrength": 0.35,
    "text": "https://qrdx.dev/q/aB3dE5f",
    "code": { "id": "cm5code0spring0menu00001", "shortLink": "https://qrdx.dev/q/aB3dE5f" },
    "visibility": 50,
    "creativity": 45
  },
  "credits": {
    "plan": "pro",
    "limit": 30,
    "used": 7,
    "remaining": 23,
    "pooled": false,
    "resetsAt": "2026-02-01T00:00:00.000Z"
  }
}
```

- `imageUrl` is a 1024 px square PNG as a `data:` URL. QRdx doesn't keep a copy, so save it.
- `text` is exactly what the image scans to. QRdx decoded it before answering.
- `blend` says how the image was made to scan: `none` (the model's image as drawn), `least` (the finder squares, quiet zone and modules strengthened just enough, on the model's image) or `image-qr` (redrawn as an Image QR code, the last resort). `blendStrength` goes from `0` (as drawn) to `1` (Image QR).
- `credits` is the workspace's allowance after this image.

To get the PNG itself instead of JSON, add `?format=png` or send `Accept: image/png`. The seed, mode, blend and images left then come as the `X-QRdx-Seed`, `X-QRdx-Mode`, `X-QRdx-Blend`, `X-QRdx-Blend-Strength` and `X-QRdx-Credits-Remaining` headers.

```bash
curl "https://api.qrdx.dev/v1/art?format=png" \
  -H "Authorization: Bearer $QRDX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text": "https://qrdx.dev", "prompt": "a lighthouse on a cliff, woodcut print"}' \
  --max-time 90 -o art.png
```

## Credits

The API draws on the same monthly AI art images as the app, counted for the workspace the key belongs to. Free, Pro and Business each include a number of images a month, and Business shares them across the whole team; [Plans and limits](/docs/plans-and-limits) has the numbers. They reset on the 1st of each month (UTC).

- A call that fails, or whose image can't be made to scan, uses no image.
- When the month's images are used, the API answers `AI_ART_CREDITS_EXHAUSTED`: `402` on Free and Pro, where an upgrade adds more, and `429` on Business.
- Each person can make at most 25 images a day, on top of the monthly allowance (`429 AI_ART_DAILY_LIMIT`).
- Each person can start up to 12 images a minute.
- Each call also counts toward the workspace's daily API quota and the per-minute limit on writes ([Rate limits](/docs/developers/rest-api#rate-limits)).

## Errors

Errors have the API's usual shape (`code`, `message`, `status`); [Errors](/docs/developers/errors) lists them all. The ones specific to AI art:

| Status | `code` | What to do |
| --- | --- | --- |
| 400 | `AI_ART_TEXT_TOO_LONG` | Shorten `text`, or send a dynamic code's `code` |
| 402 | `AI_ART_CREDITS_EXHAUSTED` | Wait for the 1st of the month, or upgrade |
| 413 | `AI_ART_IMAGE_TOO_LARGE` | Downsize `photo` or `reference` |
| 429 | `AI_ART_CREDITS_EXHAUSTED` | Business: wait for the 1st of the month |
| 429 | `AI_ART_DAILY_LIMIT` | Try again tomorrow (UTC) |
| 502 | `AI_ART_FAILED` | The model failed or declined the prompt. Try again or reword it |
| 502 | `AI_ART_UNSCANNABLE` | Try again with a higher `visibility` or another seed |
| 503 | `AI_ART_BUSY` | The model is busy. Wait a minute and try again |
| 503 | `AI_NOT_CONFIGURED` | AI art isn't set up on this server (self-hosted) |
| 504 | `AI_ART_TIMEOUT` | The model took too long. Try again |

None of the `5xx` errors uses an image.

## MCP

With a QRdx API key on the connection, the [MCP server](/docs/developers/mcp) has a `generate_ai_art` tool. It takes the same fields as the request body and returns the PNG, what it scans to and the images left this month. Ask your assistant in plain words:

```txt
Make AI QR art for my code cm5code0spring0menu00001: a bistro chalkboard menu on a brick wall, as a scene.
```

Without a key, the tool answers with how to add one. The call takes up to a minute, like the REST API.

## Self-hosting

AI art runs through Vercel AI Gateway. On your own instance, set `AI_GATEWAY_API_KEY`; without it, `POST /v1/art` and `generate_ai_art` answer `503 AI_NOT_CONFIGURED`.
