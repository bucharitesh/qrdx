`@qrdx/cli` menghasilkan kode QR yang sama seperti Playground dan [pustaka `qrdx`](/docs/getting-started) dari baris perintah. Alat ini tidak pernah meminta masukan di skrip dan CI, dan saat Anda menjalankan `qrdx generate` tanpa argumen di terminal, alat ini menanyakan konten dan opsi langkah demi langkah.

<NpmStatus package="@qrdx/cli" />

```bash
npx @qrdx/cli generate "https://example.com" -o qr.svg
```

Instal secara global untuk mendapatkan perintah `qrdx`:

```bash
npm install -g @qrdx/cli
qrdx generate "https://example.com" -o qr.png --size 1024
```

Alat ini membutuhkan Node.js 22 atau lebih baru. Keluaran PNG dan WebP menggunakan [sharp](https://sharp.pixelplumbing.com), dependensi opsional yang diinstal npm jika platform Anda mendukungnya; SVG dan EPS berfungsi tanpanya. Paket npm `qrdx` adalah pustaka React: CLI hanya ada di `@qrdx/cli`.

## Format keluaran [#output-formats]

Ekstensi file menentukan format, atau gunakan `--format` jika nama file tidak memiliki ekstensi.

| Format | Gunakan untuk | Arti `--size` |
| --- | --- | --- |
| `.svg` | Halaman web, alat desain, perbesaran tanpa kehilangan kualitas | Lebar dalam piksel (default 512) |
| `.png` | Dokumen, slide, di mana pun yang membutuhkan gambar | Lebar dalam piksel |
| `.webp` | Situs web: piksel PNG, lossless, dalam file yang lebih kecil | Lebar dalam piksel |
| `.eps` | Percetakan, Illustrator, InDesign | Lebar dalam poin (72 per inci, jadi `144` adalah 2 inci) |

File EPS adalah PostScript vektor. Logo PNG dan JPEG disematkan apa adanya; format logo lain dikonversi dengan sharp jika terinstal, dan jika tidak, dihilangkan disertai peringatan.

## Opsi [#options]

| Flag | Default | Deskripsi |
| --- | --- | --- |
| `-o`, `--output` | `qr.svg` | File keluaran |
| `--format` | dari ekstensi | `svg`, `png`, `webp`, atau `eps` |
| `--size` | `512` | Ukuran keluaran (lihat di atas) |
| `-l`, `--level` | `Q` | Koreksi kesalahan: `L`, `M`, `Q`, atau `H` |
| `--body` | `square` | [Pola](/docs/features/patterns) modul data |
| `--eye` | `square` | Pola mata sudut |
| `--dot` | `square` | Pola titik mata sudut |
| `--fg`, `--bg` | `#000000`, `#ffffff` | Latar depan dan latar belakang: warna hex atau gradien JSON |
| `--eye-color`, `--dot-color` | `--fg` | Warna mata sudut dan titik mata |
| `--logo` | | URL gambar logo di tengah (gunakan bersama `--level H`) |
| `--margin` | `0` | Zona tenang, dalam modul |
| `--template` | | `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, atau `Halloween` |
| `--frame` | | [Bingkai](/docs/features/frames) ajakan bertindak: salah satu dari {facts.frameStyles} gaya bingkai, seperti `banner-bottom`, `rounded-border`, `circle`, `sticker`, atau `phone` (lihat [semuanya](/docs/styles#frames)) |
| `--frame-text` | `Scan me` | Label bingkai, hingga 24 karakter |
| `--frame-color`, `--frame-text-color` | | Warna bingkai dan label (hex) |

`qrdx --help` menampilkan setiap nama pola. Nilai yang tidak valid keluar dengan kode `1` dan pesan yang mencantumkan nilai yang diterima.

## Banyak kode dari CSV [#many-codes-from-a-csv]

`qrdx batch` menulis kode QR statis untuk setiap baris file CSV ke dalam sebuah folder:

```bash
qrdx batch products.csv -o codes --format png --size 1024 --body circle
```

Alat ini membaca kolom yang sama seperti [generator massal](/tools/bulk): konten dari kolom bernama `value`, `url`, `link`, `data`, `content`, `text`, atau `qr` (jika tidak ada, kolom pertama), dan nama file dari kolom bernama `file name`, `name`, `label`, `id`, `title`, atau `sku` (jika tidak ada, `qr-00001`, `qr-00002`, dan seterusnya). Pilih kolom lain berdasarkan nama header atau nomor kolom:

| Flag | Default | Deskripsi |
| --- | --- | --- |
| `-o`, `--out` | `qr-codes` | Folder untuk kode |
| `--format` | `svg` | `svg`, `png`, atau `eps` |
| `--value-column` | ditebak | Kolom berisi konten setiap kode |
| `--name-column` | ditebak | Kolom berisi nama file |
| `--no-header` | | Baris pertama adalah kode, bukan nama kolom |
| `--jobs` | `4` untuk SVG, `8` selain itu | Jumlah kode yang dirender sekaligus |

Setiap opsi gaya di atas berlaku untuk semua kode. CSV dibaca sebagai aliran dan setiap kode disimpan segera setelah dibuat, sehingga perintah ini tidak memiliki batas baris: di laptop, 10.000 kode SVG memakan waktu sekitar 40 detik dan memori di bawah 200 MB. Tidak ada yang diunggah dan tidak perlu akun. Baris yang tidak dapat dienkode dilewati dan dicantumkan beserta alasannya di `errors.csv` di folder keluaran.

Untuk mencetak [kode dinamis](/docs/dynamic-qr-codes) secara massal, buat terlebih dahulu (impor CSV di dasbor atau API) lalu jalankan `qrdx batch` pada CSV hasil yang diberikan oleh impor tersebut, dengan `--value-column short_link`.

## Contoh [#examples]

```bash
# High-resolution PNG for print
qrdx generate "https://example.com" -o qr.png --size 2048 --level H

# Vector EPS, 2 inches wide, for a print shop
qrdx generate "https://example.com" -o qr.eps --size 144

# Branded colors and patterns
qrdx generate "https://example.com" --body circle --eye rounded --fg "#1a1a2e" -o brand.svg

# Gradient foreground
qrdx generate "https://example.com" -o gradient.svg \
  --fg '{"type":"linear","stops":[{"color":"#6366f1","offset":0},{"color":"#ec4899","offset":100}],"angle":135}'

# "Scan for the menu" frame
qrdx generate "https://example.com/menu" --frame banner-bottom --frame-text "Scan for the menu" -o menu.png

# Wi-Fi network
qrdx generate "WIFI:T:WPA;S:MyNetwork;P:MyPassword;;" -o wifi.svg
```

Untuk mencetak [kode QR dinamis](/docs/dynamic-qr-codes), berikan tautan pendeknya (`https://qrdx.dev/q/<slug>`) sebagai data.
