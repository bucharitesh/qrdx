QRdx menerbitkan registry [shadcn/ui](https://ui.shadcn.com) berisi komponen kode QR yang dibangun di atas pustaka [`qrdx`](https://www.npmjs.com/package/qrdx). CLI shadcn menyalin kode sumbernya ke proyek Anda, sehingga Anda memiliki kodenya dan bisa mengubahnya.

<NpmStatus package="qrdx" />

<PackageManagerTabs command="npx shadcn@latest add https://qrdx.dev/r/qr-code.json" />

Setiap komponen memiliki halamannya sendiri dengan pratinjau langsung, kode sumber, langkah pemasangan, contoh, dan referensi API.

[Coba di playground](/playground?open=code&lang=shadcn): atur gaya kode di sana, lalu salin untuk komponen QR Code dari registry.

## Yang ikut terpasang [#what-gets-installed]

Setiap komponen adalah satu berkas di `components/`. CLI juga memasang `qrdx` (serta `lucide-react` untuk ikon yang dipakai beberapa komponen) dan menambahkan komponen shadcn/ui yang menjadi dasarnya, seperti `button`, `card`, `dialog`, `dropdown-menu`, atau `input`.

Indeks lengkapnya ada di [`https://qrdx.dev/r/registry.json`](https://qrdx.dev/r/registry.json).

## Menggunakan namespace registry [#using-the-registry-namespace]

Untuk memasang dengan nama singkat, tambahkan registry ke `components.json` Anda:

```json
{
  "registries": {
    "@qrdx": "https://qrdx.dev/r/{name}.json"
  }
}
```

Lalu tambahkan satu atau beberapa komponen berdasarkan nama:

<PackageManagerTabs command="npx shadcn@latest add @qrdx/qr-code @qrdx/qr-code-download @qrdx/qr-code-share-dialog" />

## Gaya tampilan [#styling]

Komponen menggunakan kelas Tailwind dengan token tema standar shadcn/ui (`bg-card`, `border`, `text-muted-foreground`, `ring-ring`) dan Button, Card, Dialog, serta Input milik Anda sendiri, sehingga mengikuti tema dan mode gelap Anda. Kode QR secara default memakai latar terang, karena modul gelap pada ubin terang bisa dipindai oleh semua pembaca.

Unduhan PDF memerlukan paket opsional `jspdf` (`npm install jspdf`).
