QRdx [`qrdx`](https://www.npmjs.com/package/qrdx) लाइब्रेरी पर बने QR कोड कंपोनेंट की एक [shadcn/ui](https://ui.shadcn.com) रजिस्ट्री पब्लिश करता है। shadcn CLI सोर्स कोड को आपके प्रोजेक्ट में कॉपी कर देता है, इसलिए कोड आपका अपना होता है और आप उसे बदल सकते हैं।

<NpmStatus package="qrdx" />

<PackageManagerTabs command="npx shadcn@latest add https://qrdx.dev/r/qr-code.json" />

हर कंपोनेंट का अपना पेज है, जिसमें लाइव प्रीव्यू, सोर्स कोड, इंस्टॉलेशन के स्टेप, उदाहरण और API रेफ़रेंस मिलता है।

[Playground में आज़माएँ](/playground?open=code&lang=shadcn): वहाँ कोई कोड स्टाइल करें, फिर उसे रजिस्ट्री के QR Code कंपोनेंट के लिए कॉपी करें।

## क्या इंस्टॉल होता है [#what-gets-installed]

हर कंपोनेंट `components/` में एक अकेली फ़ाइल होता है। CLI `qrdx` भी इंस्टॉल करता है (साथ में `lucide-react`, जिसे कुछ कंपोनेंट आइकन के लिए इस्तेमाल करते हैं) और वे shadcn/ui कंपोनेंट भी जोड़ देता है जिन पर यह बना है, जैसे `button`, `card`, `dialog`, `dropdown-menu` या `input`।

पूरा इंडेक्स [`https://qrdx.dev/r/registry.json`](https://qrdx.dev/r/registry.json) पर है।

## रजिस्ट्री नेमस्पेस का इस्तेमाल [#using-the-registry-namespace]

छोटे नाम से इंस्टॉल करने के लिए, रजिस्ट्री को अपनी `components.json` में जोड़ें:

```json
{
  "registries": {
    "@qrdx": "https://qrdx.dev/r/{name}.json"
  }
}
```

फिर नाम से एक या कई कंपोनेंट जोड़ें:

<PackageManagerTabs command="npx shadcn@latest add @qrdx/qr-code @qrdx/qr-code-download @qrdx/qr-code-share-dialog" />

## स्टाइलिंग [#styling]

कंपोनेंट Tailwind क्लास और shadcn/ui के स्टैंडर्ड थीम टोकन (`bg-card`, `border`, `text-muted-foreground`, `ring-ring`) इस्तेमाल करते हैं, और आपके अपने Button, Card, Dialog और Input पर चलते हैं, इसलिए वे आपकी थीम और डार्क मोड को फ़ॉलो करते हैं। QR कोड में डिफ़ॉल्ट रूप से हल्का बैकग्राउंड रहता है, क्योंकि हल्की टाइल पर गहरे मॉड्यूल हर रीडर से स्कैन हो जाते हैं।

PDF डाउनलोड के लिए वैकल्पिक `jspdf` पैकेज चाहिए (`npm install jspdf`)।
