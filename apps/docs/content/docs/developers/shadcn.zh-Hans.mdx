QRdx 发布了一个 [shadcn/ui](https://ui.shadcn.com) 注册表，其中的二维码组件基于 [`qrdx`](https://www.npmjs.com/package/qrdx) 库构建。shadcn CLI 会把源代码复制到你的项目中，因此代码归你所有，你可以随意修改。

<NpmStatus package="qrdx" />

<PackageManagerTabs command="npx shadcn@latest add https://qrdx.dev/r/qr-code.json" />

每个组件都有独立的页面，提供实时预览、源代码、安装步骤、示例和 API 参考。

[在 Playground 中试用](/playground?open=code&lang=shadcn)：在那里设计好二维码样式，然后复制为注册表中的 QR Code 组件。

## 会安装哪些内容 [#what-gets-installed]

每个组件都是 `components/` 中的单个文件。CLI 还会安装 `qrdx`（部分组件用到图标时还会安装 `lucide-react`），并添加其所依赖的 shadcn/ui 组件，例如 `button`、`card`、`dialog`、`dropdown-menu` 或 `input`。

完整索引位于 [`https://qrdx.dev/r/registry.json`](https://qrdx.dev/r/registry.json)。

## 使用注册表命名空间 [#using-the-registry-namespace]

若想用简短名称安装，请把该注册表添加到你的 `components.json`：

```json
{
  "registries": {
    "@qrdx": "https://qrdx.dev/r/{name}.json"
  }
}
```

然后按名称添加一个或多个组件：

<PackageManagerTabs command="npx shadcn@latest add @qrdx/qr-code @qrdx/qr-code-download @qrdx/qr-code-share-dialog" />

## 样式 [#styling]

组件使用 Tailwind 类名和标准的 shadcn/ui 主题令牌（`bg-card`、`border`、`text-muted-foreground`、`ring-ring`），并使用你自己的 Button、Card、Dialog 和 Input，因此会跟随你的主题和深色模式。二维码默认保留浅色背景，因为浅色底块上的深色模块能被所有读码器扫描。

下载 PDF 需要可选的 `jspdf` 包（`npm install jspdf`）。
