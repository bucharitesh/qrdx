## URL base e autenticação [#base-url-and-authentication]

A REST API fica em `https://api.qrdx.dev/v1`. As mesmas rotas também respondem em `https://qrdx.dev/api/v1`.

As requisições se autenticam com uma [chave de API](/docs/developers/api-keys) no header `Authorization: Bearer`. Apps que agem em nome de outros usuários do QRdx enviam ali um [token de acesso OAuth 2.0](/docs/developers/rest-api#get-an-access-token). O [início rápido](/docs/developers/quickstart#create-an-api-key) cria uma chave e faz uma primeira requisição.
