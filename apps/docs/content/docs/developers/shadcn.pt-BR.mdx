A QRdx publica um registry do [shadcn/ui](https://ui.shadcn.com) com componentes de QR code construídos sobre a biblioteca [`qrdx`](https://www.npmjs.com/package/qrdx). A CLI do shadcn copia o código-fonte para o seu projeto, então o código é seu e você pode alterá-lo.

<NpmStatus package="qrdx" />

<PackageManagerTabs command="npx shadcn@latest add https://qrdx.dev/r/qr-code.json" />

Cada componente tem sua própria página, com prévia ao vivo, código-fonte, passos de instalação, exemplos e referência da API.

[Experimente no Playground](/playground?open=code&lang=shadcn): estilize um código lá e depois copie para o componente QR Code do registry.

## O que é instalado [#what-gets-installed]

Cada componente é um único arquivo em `components/`. A CLI também instala `qrdx` (e `lucide-react` para os ícones usados por alguns componentes) e adiciona os componentes do shadcn/ui em que ele se baseia, como `button`, `card`, `dialog`, `dropdown-menu` ou `input`.

O índice completo está em [`https://qrdx.dev/r/registry.json`](https://qrdx.dev/r/registry.json).

## Usando o namespace do registry [#using-the-registry-namespace]

Para instalar com um nome curto, adicione o registry ao seu `components.json`:

```json
{
  "registries": {
    "@qrdx": "https://qrdx.dev/r/{name}.json"
  }
}
```

Depois, adicione um ou vários componentes pelo nome:

<PackageManagerTabs command="npx shadcn@latest add @qrdx/qr-code @qrdx/qr-code-download @qrdx/qr-code-share-dialog" />

## Estilização [#styling]

Os componentes usam classes do Tailwind com os tokens padrão do tema do shadcn/ui (`bg-card`, `border`, `text-muted-foreground`, `ring-ring`) e o seu próprio Button, Card, Dialog e Input, então acompanham o seu tema e o modo escuro. Os QR codes mantêm um fundo claro por padrão, porque módulos escuros sobre um bloco claro são lidos por qualquer leitor.

Downloads em PDF exigem o pacote opcional `jspdf` (`npm install jspdf`).
