Setiap kesalahan REST API berbentuk JSON dengan struktur yang sama, apa pun endpoint yang mengembalikannya:

```json
{
  "code": "INSUFFICIENT_SCOPE",
  "message": "This API key needs the 'codes:write' scope. Create a key that includes it at https://qrdx.dev/dashboard?to=settings/developers; a key's scopes can't be changed.",
  "status": 403,
  "docs": "https://qrdx.dev/docs/developers/api-keys"
}
```

| Kolom | Penjelasan |
| --- | --- |
| `code` | Kode stabil yang dapat dibaca mesin, diambil dari tabel di bawah. Gunakan kode ini untuk percabangan logika. |
| `message` | Penjelasan untuk manusia tentang apa yang salah dan cara memperbaikinya. Kalimatnya dapat berubah. |
| `status` | Status HTTP, diulang di sini. |
| `docs` | Halaman yang menjelaskan cara memperbaikinya, jika ada. |
| `data` | Detail tambahan pada beberapa kesalahan. `VALIDATION_ERROR` mencantumkan setiap masalah di `data.details`. |

Kesalahan validasi menyebutkan setiap kolom yang gagal:

```json
{
  "code": "VALIDATION_ERROR",
  "message": "Invalid request body",
  "status": 400,
  "data": {
    "details": [
      { "path": "destinationUrl", "message": "Enter a full URL, starting with https://" }
    ]
  }
}
```

Image API melaporkan parameter kueri sebagai `{ "param", "message" }`, bukan `{ "path", "message" }`.

## Kode error [#error-codes]

| Status | Kode | Arti | Solusi |
| --- | --- | --- | --- |
| 400 | `VALIDATION_ERROR` | Isi permintaan (body), query, atau path gagal divalidasi. `data.details` mencantumkan setiap masalah sebagai `{ path, message }` (`{ param, message }` pada Image API), disertai `index` baris saat body berupa array kode. | Perbaiki kolom yang tercantum di `data.details`, lalu kirim permintaan lagi. |
| 400 | `INVALID_SLUG` | Back-half kustom (`slug`) melanggar aturan: kata yang dicadangkan, atau back-half yang sama muncul dua kali dalam satu permintaan. Untuk array, `data.details` mencantumkan setiap baris berdasarkan `index`. | Pilih back-half lain. Pesan error menyebutkan aturannya. |
| 400 | `TOO_MANY_CODES` | Lebih dari 1.000 kode dalam satu permintaan. Biasanya skema body menolaknya lebih dulu sebagai `VALIDATION_ERROR`. | Kirim paling banyak 1.000 kode per permintaan. |
| 400 | `DOMAIN_NOT_VERIFIED` | `domainId` merujuk ke domain kustom yang belum terverifikasi. | Selesaikan verifikasi domain di halaman Domain, atau hilangkan `domainId`. |
| 400 | `SID_REQUIRED` | Konversi tanpa `qrdx_sid` dari pemindaian (dari browser), atau tanpa `sid` atau `code` (dari server). | Kirim `qrdx_sid` yang ditambahkan tautan pendek ke URL halaman Anda, atau, dengan kunci API atau token, kirim id kode sebagai `code`. |
| 400 | `AI_ART_TEXT_TOO_LONG` | `text` terlalu panjang untuk seni AI (lebih dari 300 karakter). | Kirim id kode dinamis sebagai `code`: seni tersebut mengodekan tautan pendeknya, yang singkat dan tetap bisa diedit. |
| 401 | `UNAUTHORIZED` | Tidak ada kredensial: permintaan tidak memiliki header `Authorization: Bearer` (dan tidak ada sesi browser QRdx). | Kirim kunci API sebagai `Authorization: Bearer <key>`; buat di Pengaturan → Kunci API & aplikasi. Token akses OAuth dikirim di header yang sama. |
| 401 | `INVALID_TOKEN` | Kunci API atau token akses tidak dikenal, dicabut, atau kedaluwarsa (token akses berlaku satu jam), atau pembuat kunci diblokir atau keluar dari workspace kunci tersebut. | Pastikan Anda mengirim kunci secara lengkap, atau buat yang baru. Untuk token akses, dapatkan yang baru dengan refresh token Anda, atau arahkan pengguna untuk melakukan otorisasi lagi. |
| 402 | `PLAN_REQUIRED` | Fitur tidak tersedia di paket workspace: pembuatan massal, back-half kustom, dan domain kustom memerlukan Pro; konversi dan hook memerlukan Business. | Upgrade workspace, atau hilangkan fitur tersebut dari permintaan. |
| 402 | `LIMIT_REACHED` | Workspace sudah memiliki kode dinamis aktif sebanyak yang disertakan paketnya (10 di paket Gratis). | Arsipkan sebuah kode (kode yang diarsipkan tidak dihitung) atau upgrade ke Pro untuk kode tanpa batas. |
| 402 | `AI_ART_CREDITS_EXHAUSTED` | Workspace sudah menggunakan seluruh gambar seni AI bulan ini (Gratis dan Pro). Permintaan ini tidak dikenai biaya. | Tunggu kuota diatur ulang pada tanggal 1 setiap bulan (UTC), atau upgrade untuk mendapat lebih banyak gambar. |
| 403 | `INSUFFICIENT_SCOPE` | Kunci API atau token valid, tetapi tidak memiliki scope yang dibutuhkan endpoint ini. | Buat kunci dengan scope yang disebutkan dalam pesan (scope kunci tidak dapat diubah). Untuk aplikasi OAuth, tambahkan scope tersebut dan mintalah saat pengguna memberi otorisasi. |
| 403 | `FORBIDDEN` | Pemanggil tidak diizinkan melakukan ini: anggota workspace menghapus kode yang dibuat orang lain, anggota mengelola hook, atau penulisan lewat sesi browser dari situs lain. Kunci API hanya dapat melakukan apa yang diizinkan oleh peran pembuatnya di workspace tersebut. | Minta pemilik atau admin workspace, atau panggil API dengan kunci API dari server Anda. |
| 403 | `CONFIRMATION_REQUIRED` | Membuat hook dengan sesi browser yang sedang masuk memerlukan "Konfirmasi bahwa ini Anda" yang baru. Kunci API dan token OAuth tidak dimintai konfirmasi. | Konfirmasi bahwa ini Anda di QRdx, lalu coba lagi dalam 10 menit, atau buat hook dengan kunci API dari server Anda. |
| 403 | `CONVERSIONS_OFF` | Konversi dari browser untuk kode yang pelacakan konversinya tidak diaktifkan. | Aktifkan pelacakan konversi untuk kode tersebut, atau laporkan konversi dari server Anda dengan kunci API. |
| 403 | `LIMIT_REACHED` | Workspace sudah memiliki 20 endpoint webhook dan hook. | Hapus endpoint atau hook yang tidak lagi Anda gunakan. |
| 404 | `NOT_FOUND` | Endpoint tidak ada, atau kode, hook, tema, atau domain kustom tidak ada di workspace tempat kunci atau token bekerja. | Periksa path dan id. Kunci API bekerja di workspace tempat kunci itu dibuat; token OAuth bekerja di workspace milik penggunanya sendiri. |
| 404 | `INVALID_SID` | `qrdx_sid` tidak dikenal atau lebih lama dari 30 hari, yaitu jendela atribusi. | Kirim `qrdx_sid` dari pemindaian terbaru, atau laporkan konversi berdasarkan id kode dari server Anda. |
| 409 | `SLUG_TAKEN` | Kode lain sudah menggunakan back-half tersebut di domain itu. Untuk array, `data.details` mencantumkan setiap back-half yang sudah dipakai berdasarkan `index`, dan tidak ada yang dibuat. | Pilih back-half lain. |
| 413 | `PAYLOAD_TOO_LARGE` | Body melebihi batas endpoint: 4 MB untuk kode, 16 KB untuk hook, 8 KB untuk konversi. Juga untuk batch kode yang responsnya (setiap kode beserta desainnya) akan melebihi 4 MB; tidak ada yang dibuat. | Kirim body yang lebih kecil. Untuk kode, penyebab yang umum adalah logo inline yang besar; untuk batch, kirim `Prefer: return=minimal` atau kurangi jumlah kode. |
| 413 | `AI_ART_IMAGE_TOO_LARGE` | Gambar `photo` atau `reference` melebihi batas ukuran seni AI (pesan menyebutkan yang mana). | Perkecil gambar (`reference` menjadi sekitar 512 px pada sisi terpanjangnya, `photo` menjadi sekitar 1024 px persegi), lalu kirim lagi sebagai data URL PNG atau JPEG. |
| 415 | `UNSUPPORTED_MEDIA_TYPE` | Permintaan tulis tanpa `Content-Type: application/json`. | Kirim body JSON dengan `Content-Type: application/json`. |
| 422 | `UNSAFE_DESTINATION` | Google Web Risk menandai URL tujuan (malware, phishing, atau perangkat lunak yang tidak diinginkan). Untuk array, `data.details` mencantumkan setiap baris yang ditandai berdasarkan `index`, dan tidak ada yang dibuat. | Gunakan tujuan lain. Jika penandaan itu keliru, minta Google meninjau situs tersebut. |
| 429 | `RATE_LIMITED` | Terlalu banyak permintaan: batas per menit (hanya `Retry-After` yang diatur) atau kuota harian workspace (`Retry-After` ditambah `X-RateLimit-*`). | Tunggu selama `Retry-After` detik. Untuk kuota harian, tunggu hingga pukul 00:00 UTC atau upgrade paket. |
| 429 | `AI_ART_CREDITS_EXHAUSTED` | Workspace Business sudah menggunakan seluruh gambar seni AI bulan ini, yang dipakai bersama oleh seluruh tim. | Tunggu kuota diatur ulang pada tanggal 1 setiap bulan (UTC). |
| 429 | `AI_ART_DAILY_LIMIT` | Pembuat kunci sudah membuat 25 gambar seni AI hari ini (UTC), batas pengaman di luar kuota bulanan. | Coba lagi besok (UTC). |
| 500 | `INTERNAL_ERROR` | Terjadi kegagalan di sisi QRdx. Kejadian ini sudah dicatat. | Coba lagi sebentar lagi. Jika terus terjadi, laporkan dengan menyertakan waktu permintaan. |
| 502 | `AI_ART_FAILED` | Model gambar gagal, menolak prompt, atau mengembalikan gambar yang tidak dapat dibaca QRdx. Tidak ada kredit seni AI yang terpakai. | Coba lagi, atau ubah kata-kata prompt. Pesan error menjelaskan apa yang terjadi. |
| 502 | `AI_ART_UNSCANNABLE` | Gambar dari model tidak dapat dibuat agar bisa dipindai dalam tingkat visibilitas QR yang Anda pilih. Tidak ada kredit seni AI yang terpakai. | Coba lagi dengan `visibility` yang lebih tinggi, atau seed lain. |
| 502 | `AI_ART_DESCRIBE_FAILED` | Anda tidak menyertakan `prompt`, dan model teks yang menuliskannya untuk Anda gagal. Tidak ada kredit seni AI yang terpakai. | Coba lagi, atau kirim `prompt` Anda sendiri. |
| 503 | `SLUG_UNAVAILABLE` | Tidak ada slug tautan pendek yang bebas yang dapat dicadangkan tepat waktu. | Kirim permintaan yang sama lagi. |
| 503 | `AI_ART_BUSY` | Model gambar sedang melebihi kapasitas. Tidak ada kredit seni AI yang terpakai. | Tunggu semenit lalu coba lagi. |
| 503 | `AI_NOT_CONFIGURED` | Seni AI belum disiapkan pada deployment ini (instance self-hosted tanpa `AI_GATEWAY_API_KEY`). | Gunakan API QRdx yang di-hosting, atau siapkan Vercel AI Gateway di instance Anda. |
| 503 | `UNAVAILABLE` | Domain kustom belum disiapkan pada deployment ini (instance self-hosted tanpa fitur tersebut). | Hilangkan `domainId`, atau konfigurasikan domain kustom di instance Anda. |
| 504 | `AI_ART_TIMEOUT` | Model gambar terlalu lama merespons, dan QRdx berhenti menunggu sebelum batas satu menit permintaan. Tidak ada kredit seni AI yang terpakai. | Coba lagi. Panggilan biasanya memakan waktu 15 hingga 45 detik. |

## Mencoba ulang [#retrying]

- **`429`:** tunggu sejumlah detik yang tertera di `Retry-After`, lalu kirim permintaan yang sama. Saat kuota harian habis, header `X-RateLimit-*` menunjukkan berapa banyak permintaan yang diizinkan paket Anda dan kapan hitungan diatur ulang (00:00 UTC). Lihat [batas laju](/docs/developers/rest-api#rate-limits).
- **`500` dan `503`:** coba lagi dengan exponential backoff, mulai dari sekitar satu detik.
- **`4xx` lainnya:** permintaan yang sama akan gagal dengan cara yang sama. Perbaiki dulu.

Pembuatan kode tidak bersifat idempoten: jika `POST /v1/codes` mengalami waktu habis, lihat daftar kode Anda sebelum mengirimnya lagi, atau kode bisa terbuat dua kali. Konversi bersifat idempoten: kirim `id` Anda sendiri, dan pengulangan akan mengembalikan `200` dengan `duplicate: true`.

## `/v1/me` dan `/v1/themes` [#v1me-and-v1themes]

Kedua endpoint ini mengirim isi respons yang sama ditambah kolom OAuth yang selama ini selalu dikirim, yaitu `error` dan `error_description` (teksnya sama dengan `message`), sehingga klien lama tetap berfungsi:

| `error` | `code` |
| --- | --- |
| `invalid_token` | UNAUTHORIZED atau INVALID_TOKEN |
| `insufficient_scope` | INSUFFICIENT_SCOPE |
| `rate_limited` | RATE_LIMITED (kuota harian) |
| `not_found` | NOT_FOUND (themes) |

## Endpoint OAuth [#oauth-endpoints]

Endpoint OAuth di bawah `https://qrdx.dev/api/oauth` (authorize, token, revoke, userinfo) mengikuti standar OAuth 2.0: `{ "error", "error_description" }`, dengan `error` berupa salah satu dari `invalid_request`, `invalid_client`, `invalid_grant`, `unsupported_grant_type`, `invalid_token`, atau `access_denied`. Jika Anda menerima `invalid_grant` saat refresh, artinya refresh token sudah pernah digunakan (setiap refresh mengembalikan token baru), kedaluwarsa setelah 30 hari, atau pengguna telah mencabut akses aplikasi Anda: arahkan pengguna melalui otorisasi sekali lagi. Lihat [REST API dan OAuth](/docs/developers/rest-api#get-an-access-token).

## Endpoint yang tidak dikenal [#unknown-endpoints]

Path di bawah `/v1` yang tidak ada akan mengembalikan `404 NOT_FOUND` dalam bentuk JSON, tidak pernah berupa halaman HTML. [Referensi API](/docs/developers/api) mencantumkan semua endpoint.
