`@qrdx/cli` は、Playground や [`qrdx` ライブラリ](/docs/getting-started)と同じQRコードをコマンドラインから生成します。スクリプトや CI ではプロンプトを表示しません。ターミナルで引数なしの `qrdx generate` を実行した場合は、内容とオプションを順番に尋ねます。

<NpmStatus package="@qrdx/cli" />

```bash
npx @qrdx/cli generate "https://example.com" -o qr.svg
```

グローバルにインストールすると、`qrdx` コマンドを使えます。

```bash
npm install -g @qrdx/cli
qrdx generate "https://example.com" -o qr.png --size 1024
```

Node.js 22 以降が必要です。PNG と WebP の出力には [sharp](https://sharp.pixelplumbing.com) を使います。sharp はオプションの依存パッケージで、お使いのプラットフォームが対応していれば npm が自動でインストールします。SVG と EPS は sharp がなくても動作します。`qrdx` という npm パッケージは React ライブラリです。CLI は `@qrdx/cli` にのみ含まれています。

## 出力形式 [#output-formats]

形式はファイル拡張子で決まります。ファイル名に拡張子がない場合は `--format` を使います。

| 形式 | 用途 | `--size` の意味 |
| --- | --- | --- |
| `.svg` | Web ページ、デザインツール、劣化のない拡大縮小 | ピクセル単位の幅（デフォルトは 512） |
| `.png` | ドキュメント、スライドなど、画像が必要なあらゆる場面 | ピクセル単位の幅 |
| `.webp` | Web サイト向け。PNG と同じピクセルを可逆圧縮し、ファイルサイズを小さくします | ピクセル単位の幅 |
| `.eps` | 印刷会社、Illustrator、InDesign | ポイント単位の幅（1 インチ 72 ポイントなので、`144` は 2 インチ） |

EPS ファイルはベクターの PostScript です。PNG と JPEG のロゴはそのまま埋め込まれます。それ以外の形式のロゴは、sharp がインストールされていれば変換され、ない場合は警告を表示して除外されます。

## オプション [#options]

| フラグ | デフォルト | 説明 |
| --- | --- | --- |
| `-o`, `--output` | `qr.svg` | 出力ファイル |
| `--format` | 拡張子から判定 | `svg`、`png`、`webp`、`eps` |
| `--size` | `512` | 出力サイズ（上記参照） |
| `-l`, `--level` | `Q` | 誤り訂正レベル：`L`、`M`、`Q`、`H` |
| `--body` | `square` | データモジュールの[パターン](/docs/features/patterns) |
| `--eye` | `square` | コーナーアイのパターン |
| `--dot` | `square` | コーナーアイのドットのパターン |
| `--fg`, `--bg` | `#000000`, `#ffffff` | 前景色と背景色：16 進カラーまたは JSON のグラデーション |
| `--eye-color`, `--dot-color` | `--fg` | コーナーアイとアイドットの色 |
| `--logo` | | 中央に配置するロゴ画像の URL（`--level H` と併用） |
| `--margin` | `0` | クワイエットゾーン（モジュール単位） |
| `--template` | | `Arrow`、`StandardBox`、`SquareBorder`、`StrikedBox`、`Halloween` |
| `--frame` | | 行動喚起の[フレーム](/docs/features/frames)：{facts.frameStyles} 種類のフレームスタイルのいずれか。`banner-bottom`、`rounded-border`、`circle`、`sticker`、`phone` など（[すべてを見る](/docs/styles#frames)） |
| `--frame-text` | `Scan me` | フレームのラベル（最大 24 文字） |
| `--frame-color`, `--frame-text-color` | | フレームとラベルの色（16 進） |

`qrdx --help` で、使用できるすべてのパターン名を確認できます。無効な値を指定すると、終了コード `1` で終了し、指定できる値を示すメッセージが表示されます。

## CSV から大量のコードを生成 [#many-codes-from-a-csv]

`qrdx batch` は、CSV ファイルの各行に対応する静的QRコードをフォルダに書き出します。

```bash
qrdx batch products.csv -o codes --format png --size 1024 --body circle
```

[一括ジェネレーター](/tools/bulk)と同じ列を読み取ります。内容は `value`、`url`、`link`、`data`、`content`、`text`、`qr` のいずれかの名前の列から取得します（該当がなければ最初の列）。ファイル名は `file name`、`name`、`label`、`id`、`title`、`sku` のいずれかの名前の列から取得します（該当がなければ `qr-00001`、`qr-00002` のように連番）。別の列を使う場合は、ヘッダー名または列番号で指定します。

| フラグ | デフォルト | 説明 |
| --- | --- | --- |
| `-o`, `--out` | `qr-codes` | コードを保存するフォルダ |
| `--format` | `svg` | `svg`、`png`、`eps` |
| `--value-column` | 自動判定 | 各コードの内容が入っている列 |
| `--name-column` | 自動判定 | ファイル名が入っている列 |
| `--no-header` | | 先頭行を列名ではなくコードとして扱います |
| `--jobs` | SVG は `4`、それ以外は `8` | 同時にレンダリングするコードの数 |

上記のスタイルオプションはすべて、全コードに適用されます。CSV はストリームとして読み込まれ、各コードは生成されるとすぐに保存されるため、行数の上限はありません。ノート PC では、10,000 個の SVG コードの生成に約 40 秒、使用メモリは 200 MB 未満でした。何もアップロードされず、アカウントも不要です。エンコードできなかった行はスキップされ、理由とともに出力フォルダの `errors.csv` に記録されます。

[動的コード](/docs/dynamic-qr-codes)を大量に印刷するには、先にそれらを作成し（ダッシュボードの CSV インポートまたは API）、インポート結果の CSV に対して `--value-column short_link` を付けて `qrdx batch` を実行します。

## 使用例 [#examples]

```bash
# High-resolution PNG for print
qrdx generate "https://example.com" -o qr.png --size 2048 --level H

# Vector EPS, 2 inches wide, for a print shop
qrdx generate "https://example.com" -o qr.eps --size 144

# Branded colors and patterns
qrdx generate "https://example.com" --body circle --eye rounded --fg "#1a1a2e" -o brand.svg

# Gradient foreground
qrdx generate "https://example.com" -o gradient.svg \
  --fg '{"type":"linear","stops":[{"color":"#6366f1","offset":0},{"color":"#ec4899","offset":100}],"angle":135}'

# "Scan for the menu" frame
qrdx generate "https://example.com/menu" --frame banner-bottom --frame-text "Scan for the menu" -o menu.png

# Wi-Fi network
qrdx generate "WIFI:T:WPA;S:MyNetwork;P:MyPassword;;" -o wifi.svg
```

[動的QRコード](/docs/dynamic-qr-codes)を印刷するには、そのショートリンク（`https://qrdx.dev/q/<slug>`）をデータとして渡します。

## AI コーディングエージェントから使う [#use-it-from-an-ai-coding-agent]

リポジトリの [`generate-qr` スキル](https://github.com/bucharitesh/qrdx/tree/main/skills/generate-qr)は、Claude Code などのエージェントに CLI の呼び出し方を教えます。MCP に対応したエージェントでは、[MCP サーバー](/docs/developers/mcp)を使えばインストールは一切不要です。
