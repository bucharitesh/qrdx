QRdx publishes a [shadcn/ui](https://ui.shadcn.com) registry of QR code components built on the [`qrdx`](https://www.npmjs.com/package/qrdx) library. The shadcn CLI copies the source into your project, so you own the code and can change it.

<PackageManagerTabs command="npx shadcn@latest add https://qrdx.dev/r/qr-code.json" />

Each component has its own page with a live preview, the source, installation steps, examples and an API reference.

## What gets installed

Each component is a single file in `components/`. The CLI also installs `qrdx` (plus `lucide-react` for the icons some components use) and adds the shadcn/ui components it builds on, such as `button`, `card`, `dialog`, `dropdown-menu` or `input`.

The full index is at [`https://qrdx.dev/r/registry.json`](https://qrdx.dev/r/registry.json).

## Using the registry namespace

To install with a short name, add the registry to your `components.json`:

```json
{
  "registries": {
    "@qrdx": "https://qrdx.dev/r/{name}.json"
  }
}
```

Then add one or several components by name:

<PackageManagerTabs command="npx shadcn@latest add @qrdx/qr-code @qrdx/qr-code-download @qrdx/qr-code-share-dialog" />

## Styling

The components use Tailwind classes with the standard shadcn/ui theme tokens (`bg-card`, `border`, `text-muted-foreground`, `ring-ring`) and your own Button, Card, Dialog and Input, so they follow your theme and dark mode. QR codes keep a light background by default, because dark modules on a light tile scan with every reader.

PDF downloads need the optional `jspdf` package (`npm install jspdf`).
