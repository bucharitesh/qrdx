`GET https://api.qrdx.dev/v1/qr` QR कोड को SVG, PNG या WebP इमेज के रूप में लौटाता है, या प्रिंट और डिज़ाइन टूल के लिए वेक्टर EPS फ़ाइल के रूप में। सब कुछ query string में होता है, इसलिए URL ही इमेज है: इसे README, `<img>` टैग या ईमेल टेम्पलेट में पेस्ट करें। यह एडिटर की स्टाइल भी लेता है: ग्रेडिएंट, फ़्रेम (कस्टम फ़्रेम सहित), बॉर्डर, आई और डॉट के रंग और लोगो आइकन।

```md
![QR code](https://api.qrdx.dev/v1/qr?data=https://github.com/you/repo)
```

अकाउंट या API key की ज़रूरत नहीं है। एक अपवाद है: वह लोगो जो आपने QRdx पर अपलोड किया हो ([Logos](#logos) देखें)।

[Playground में आज़माएँ](/playground?open=code&lang=image): वहाँ कोड को स्टाइल करें, फिर उसका इमेज URL कॉपी करें।

## उदाहरण [#examples]

```html
<img
  src="https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&size=256&fg=155dfc"
  width="256"
  height="256"
  alt="QR code for qrdx.dev"
/>
```

curl से PNG डाउनलोड करें (URL को quotes में रखें ताकि आपका शेल `&` को न छेड़े):

```bash
curl -o qr.png "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png&size=1024"
```

या WebP: PNG जैसे ही पिक्सल, लॉसलेस और ट्रांसपेरेंसी समेत, लेकिन छोटी फ़ाइल में:

```bash
curl -o qr.webp "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=webp&size=1024"
```

Illustrator, InDesign या प्रिंट शॉप के लिए वेक्टर EPS पाएँ (`size` पॉइंट में चौड़ाई है, 72 प्रति इंच, इसलिए `144` यानी 2 इंच):

```bash
curl -o qr.eps "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=eps&size=144"
```

फ़्रेम के साथ स्टाइल वाले डॉट:

```txt
https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&body=rounded&eye=rounded&dot=rounded&template=Arrow
```

लेबल के साथ एक बिल्ट-इन फ़्रेम, और id से एक कम्युनिटी फ़्रेम:

```txt
https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&frame=banner-bottom&frameText=Scan%20the%20menu
https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&item=frame:wifi-card
```

पूरा डिज़ाइन `style` में JSON के रूप में, यहाँ ग्रेडिएंट, लाल आई और एक फ़्रेम:

```js
const style = {
  fgColor: {
    type: "linear",
    angle: 45,
    stops: [
      { color: "#1d4ed8", offset: 0 },
      { color: "#7c3aed", offset: 100 },
    ],
  },
  eyeColor: "#b91c1c",
  frame: { style: "banner-bottom", text: "Scan the menu" },
};
const src = `https://api.qrdx.dev/v1/qr?data=${encodeURIComponent(link)}&style=${encodeURIComponent(JSON.stringify(style))}`;
```

<Callout>
  जब `data` की वैल्यू में `&`, `#`, `+` या स्पेस हों, तो उसे एन्कोड करें, जैसे JavaScript में `encodeURIComponent` से। नहीं तो URL उन्हीं अक्षरों पर टूट जाता है। `style` को भी इसी तरह एन्कोड करें।
</Callout>

## पैरामीटर [#parameters]

| पैरामीटर | डिफ़ॉल्ट | विवरण |
|-----------|---------|-------------|
| `data` | ज़रूरी | एन्कोड करने के लिए टेक्स्ट या URL, अधिकतम 2048 अक्षर |
| `format` | `svg` | `svg`, `png`, `webp` (लॉसलेस) या `eps` (वेक्टर PostScript; तब `size` पॉइंट में चौड़ाई होती है) |
| `size` | `512` | पिक्सल में चौड़ाई और ऊँचाई, `64` से `2048` |
| `fg` | `000000` | मॉड्यूल का रंग, hex में (`155dfc`, `fff`, या alpha के साथ 8 अंक) |
| `bg` | `ffffff` | बैकग्राउंड का रंग, hex में। `00000000` से बैकग्राउंड ट्रांसपेरेंट होता है |
| `eyeColor` | `fg` | तीनों कॉर्नर आई का रंग |
| `dotColor` | `fg` | हर कॉर्नर आई के अंदर के डॉट का रंग |
| `body` | `square` | डेटा मॉड्यूल का आकार |
| `eye` | `square` | कॉर्नर आई फ़्रेम का आकार |
| `dot` | `square` | हर कॉर्नर आई के अंदर के डॉट का आकार |
| `level` | `Q` | एरर करेक्शन: `L` (~7%), `M` (~15%), `Q` (~25%) या `H` (~30%) |
| `margin` | `4` | कोड के चारों ओर खाली जगह (quiet zone), मॉड्यूल में, `0` से `16` |
| `template` | none | सजावटी बॉर्डर टेम्पलेट |
| `frame` | none | एक बिल्ट-इन कॉल-टू-एक्शन [फ़्रेम](/docs/features/frames), जैसे `banner-bottom`, `speech-bubble` या `circle` ({facts.frameStyles} बिल्ट-इन फ़्रेम में से कोई भी, हर एक अपने frame spec से बना) |
| `frameText` | `Scan me` | फ़्रेम का लेबल, अधिकतम 24 अक्षर। यह `style` या `item` के फ़्रेम का लेबल भी बदल देता है |
| `style` | none | एडिटर का पूरा डिज़ाइन JSON के रूप में; देखें [Styles](#style) |
| `item` | none | id से एक कम्युनिटी फ़्रेम या थीम, जैसे `frame:wifi-card`; देखें [कम्युनिटी आइटम](#community-items) |
| `logoIcon` | none | बीच में एक क्विक आइकन या ब्रांड लोगो; देखें [Logos](#logos) |
| `logoFileId` | none | आपका अपलोड किया हुआ लोगो, file id से; इसके लिए API key चाहिए; देखें [Logos](#logos) |

रंग `#` के बिना लिखें, या उसे `%23` के रूप में एन्कोड करें: सीधा `#` URL फ़्रैगमेंट शुरू कर देता है और कभी भेजा नहीं जाता। Enum वैल्यू (`level`, `format`, `template`, `frame`) में अक्षरों का केस मायने नहीं रखता।

फ़्रेम के साथ, `size` कोड की अपनी चौड़ाई है और फ़्रेम इमेज में जुड़ता है, हर format में।

## Styles [#style]

`style` डिज़ाइन को JSON के रूप में लेता है, जिसके फ़ील्ड सेव की गई थीम जैसे ही हैं। इसलिए [`GET /v1/themes`](/docs/developers/api/list-themes) की कोई थीम, या [MCP server](/docs/developers/mcp) के `design_qr` से लौटा `qrdxStyle`, जैसा है वैसा पास किया जा सकता है (अपलोड किए गए लोगो को छोड़कर, नीचे देखें):

| फ़ील्ड | क्या लेता है |
| --- | --- |
| `bgColor`, `fgColor`, `eyeColor`, `dotColor` | एक रंग (hex जैसे `#155dfc`, `rgb()`, `hsl()` या रंग का नाम), या एक ग्रेडिएंट: `{ "type": "linear", "angle": 45, "stops": [...] }` या `{ "type": "radial", "stops": [...] }`, जिसमें `{ "color", "offset" }` के 2 से 8 stop हों (offset 0 से 100) |
| `bodyPattern`, `cornerEyePattern`, `cornerEyeDotPattern` | [पैटर्न वैल्यू](#pattern-values) |
| `level`, `margin` | ऊपर दिए पैरामीटर जैसे (`margin` 0 से 16) |
| `templateId` | एक बॉर्डर टेम्पलेट, कोई नहीं के लिए `default` |
| `frame` | एक बिल्ट-इन फ़्रेम, `{ "style": "banner-bottom", "text": "Scan me", "color": "#155dfc", "textColor": "#ffffff" }`, या एक कस्टम फ़्रेम, `{ "style": "custom", "spec": { … } }`, जिसमें [कम्युनिटी](#community-items) से लिया गया या Playground के Frame सेक्शन में बनाया गया frame spec हो। Spec की जाँच इंजन के frame-spec नियमों से होती है (कोई मार्कअप, लिंक या इमेज नहीं; अधिकतम 32 KB) |
| `eyeColors` | हर आई के अलग रंग, जो `eyeColor` और `dotColor` पर लागू होते हैं: `{ "topLeft": { "outer": "#b91c1c", "inner": "#1d4ed8" }, "topRight": …, "bottomLeft": … }`, हर एक रंग या ग्रेडिएंट |
| `moduleScale` | हर डॉट का आकार, `0.5` से `1` (डिफ़ॉल्ट `1`) |
| `shape` | `square` (डिफ़ॉल्ट) या `circle`: सजावटी डॉट की डिस्क में कोड |
| `autoLevel` | जब लोगो कोड के 7% से ज़्यादा हिस्से को ढके, तो एरर करेक्शन `H` कर दें (लोगो होने पर यहाँ हमेशा चालू रहता है) |
| `logoOptions` | लोगो का लेआउट: `size` (कोड की चौड़ाई का `0.1` से `0.3`; जब कोड के पास उतने मॉड्यूल नहीं बचते तो QRdx इसे छोटा कर देता है), `padding` (`0` से `2` मॉड्यूल), `x` और `y` (`0` से `1`), `shape` (`square`, `rounded` या `circle` क्रॉप) और `plate` (उसके पीछे का रंग) |
| `showLogo`, `logoIcon`, `logoFileId` | देखें [Logos](#logos) |

`style` Playground लिंक की `style` वैल्यू भी लेता है (यह `1.` से शुरू होती है), इसलिए [Playground](/playground) से शेयर किया गया डिज़ाइन वैसा ही रेंडर होता है जैसा वहाँ दिखता है, लेकिन उसके लोगो के बिना।

फ़्लैट पैरामीटर (`fg`, `body`, `frame` और बाकी) से सेट किए गए फ़ील्ड `style` पर भारी पड़ते हैं, और `style` `item` पर भारी पड़ता है। अज्ञात फ़ील्ड, लोगो के पते (`customLogo`) और Logo QR या Image QR आर्ट (`art`) को `400` के साथ मना कर दिया जाता है, जो वजह भी बताता है।

## कम्युनिटी आइटम [#community-items]

`item` एक प्रकाशित [कम्युनिटी](/community) फ़्रेम या थीम रेंडर करता है, जो CC0 के तहत फ़्री है। id [`GET /v1/community/items`](/docs/developers/api/list-community-items) से खोजें, या किसी आइटम का पेज खोलकर उसका type और slug इस्तेमाल करें: `/community/frames/wifi-card` यानी `frame:wifi-card`। फ़्रेम आइटम सादे काले-पर-सफ़ेद कोड पर लगता है; उसके नीचे का कोड बदलने के लिए `style` या फ़्लैट पैरामीटर जोड़ें।

## लोगो [#logos]

- **क्विक आइकन।** `logoIcon` एडिटर के आइकन में से एक को बीच में सफ़ेद टाइल पर लगाता है: `wifi`, `location`, `phone`, `email`, `link`, `file`, `calendar`, `whatsapp` या `instagram`। इन्हें QRdx खुद बनाता है और इनके लिए किसी key की ज़रूरत नहीं होती।
- **ब्रैंड लोगो।** `logoIcon` [Simple Icons](https://simpleicons.org) के {facts.brandLogos} ब्रैंड में से किसी को भी उसके slug से ले सकता है: `spotify`, `paypal`, `googlemaps`, `appstore`। मार्क बिना प्लेट के, ब्रैंड के अपने रंग में बनता है। काले या सफ़ेद रंग के लिए `:black` या `:white` जोड़ें (`whatsapp:white`), और उसके पीछे प्लेट के लिए `style` में `logoOptions.plate` इस्तेमाल करें। [`GET /api/brand-logos`](https://qrdx.dev/api/brand-logos) सभी slug की सूची देता है। जो slug QRdx में नहीं है, उस पर `400` मिलता है।
- **QRdx मार्क**, जो एडिटर में डिफ़ॉल्ट रूप से दिखता है, यहाँ नहीं बनता: सिर्फ़ `showLogo: true` से कोई लोगो नहीं जुड़ता।
- **लोगो के लिए error correction बढ़ जाता है।** जब कोई लोगो कोड के 7% से ज़्यादा हिस्से को ढकता है, तो `level` में कुछ भी हो, कोड `H` लेवल पर बनता है, ताकि वह फिर भी स्कैन हो सके।

<IfAvailable feature="fileStorage">

**आपका अपना लोगो।** `logoFileId` आपके [डैशबोर्ड → Files](/docs/files) में अपलोड की गई 1 MB तक की PNG या JPEG फ़ाइल को लोगो के रूप में बनाता है। id फ़ाइल के लिंक का आख़िरी हिस्सा होती है, `https://qrdx.dev/api/files/<id>`। उस वर्कस्पेस की [API key](/docs/developers/api-keys) भेजें जिसकी वह फ़ाइल है:

```bash
curl -o qr.png -H "Authorization: Bearer $QRDX_API_KEY" \
  "https://api.qrdx.dev/v1/qr?data=https://qrdx.dev&format=png&logoFileId=<id>"
```

रिस्पॉन्स प्राइवेट होता है (`Cache-Control: private, no-store`) और वर्कस्पेस के रोज़ाना API कोटा में गिना जाता है। दूसरे वर्कस्पेस की फ़ाइल पर `404` मिलता है, और key के बिना रिक्वेस्ट पर `401`। QRdx इमेज को अपनी ही स्टोरेज से पढ़ता है और जाँचता है कि वह सच में PNG या JPEG है; वह आपके भेजे वेब पते से कभी कोई लोगो नहीं लाता।

</IfAvailable>

`logoOptions` इनमें से किसी भी लोगो का साइज़, जगह, क्रॉप और बैकग्राउंड तय करता है। अपलोड किए गए लोगो का अपना बैकग्राउंड हटाना Playground में होता है; image API अपलोड की गई फ़ाइल को जैसी है वैसी ही बनाता है।

Logo QR और Image QR आर्ट यहाँ उपलब्ध नहीं हैं: Playground उन्हें आपकी तस्वीर से ब्राउज़र में बनाता है, और image API अपलोड से आर्ट नहीं बनाता। आर्ट कोड [Playground](/playground?tab=art) में डिज़ाइन करें।

### पैटर्न की वैल्यू [#pattern-values]

- `body`: `circle`, `circle-large`, `square`, `diamond`, `circle-mixed`, `pacman`, `rounded`, `small-square`, `vertical-line`, `horizontal-line`, `liquid`, `liquid-horizontal`, `liquid-vertical`, `classy`, `classy-rounded`, `leaf`, `plus`, `hexagon`, `star`, `heart`, `random-dots`, `mosaic`, `octagon`
- `eye`: `square`, `rounded`, `gear`, `circle`, `diya`, `extra-rounded`, `message`, `pointy`, `leaf`, `drop`, `octagon`, `bevel`, `squircle`, `cushion`, `shield`, `petal`, `leaf-reverse`
- `dot`: `square`, `rounded`, `circle`, `message`, `message-reverse`, `diya`, `diya-reverse`, `rounded-triangle`, `leaf`, `drop`, `plus`, `cross-rounded`, `hexagon`, `octagon`, `flower`, `heart`, `squircle`, `dots`, `extra-rounded`, `leaf-reverse`, `drop-reverse`
- `template`: `default`, `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `Halloween`

ये वही स्टाइल हैं जो [`qrdx` React लाइब्रेरी](/docs/features/patterns) में हैं। [MCP सर्वर](/docs/developers/mcp) भी इन्हें छोटे विवरण के साथ सूची में दिखा सकता है।

## रिस्पॉन्स [#responses]

सफल रिक्वेस्ट इमेज लौटाती है, इन के साथ:

- `Content-Type: image/svg+xml`, `image/png` या `application/postscript` (EPS `qr-code.eps` डाउनलोड के रूप में भेजा जाता है)
- `Cache-Control: public, max-age=31536000, immutable`, सिवाय `item` वाले रेंडर के (5 मिनट, CDN पर 10, क्योंकि किसी item का नया वर्शन आ सकता है या उसे हटाया जा सकता है) और `logoFileId` वाले रेंडर के (`private, no-store`)
- `Access-Control-Allow-Origin: *`, ताकि आप इसे किसी भी वेबसाइट से `fetch` कर सकें

रेंडरिंग डिटरमिनिस्टिक है: एक ही query string हमेशा वही बाइट्स लौटाती है, इसीलिए रिस्पॉन्स एक साल तक cache किए जा सकते हैं। सिर्फ़ मूल पैरामीटर वाले URL बिल्कुल वैसे ही रेंडर होते हैं जैसे हमेशा होते आए हैं।

गलत पैरामीटर पर `400` मिलता है, जिसकी JSON बॉडी हर समस्या का नाम बताती है:

```json
{
  "code": "VALIDATION_ERROR",
  "message": "Invalid query parameters",
  "data": {
    "details": [
      { "param": "size", "message": "Too small: expected number to be >=64" }
    ]
  },
  "status": 400
}
```

जो डेटा चुने गए error correction लेवल पर QR कोड में नहीं समाता, उस पर भी `param: "data"` के साथ `400` मिलता है। कम `level` या छोटा डेटा इस्तेमाल करें।

## सीमाएँ [#limits]

- **रेट लिमिट:** हर IP एड्रेस के लिए प्रति मिनट 300 रिक्वेस्ट। सीमा पार होने पर `Retry-After` हेडर के साथ `429` मिलता है।
- **कोई स्कैन जाँच नहीं।** image API वही बनाता है जो आप माँगते हैं। किसी डिज़ाइन का स्कैन स्कोर पहले जाँचने और ठीक करने के लिए [MCP सर्वर](/docs/developers/mcp) पर `design_qr` इस्तेमाल करें, या [Playground](/playground?tab=design) में स्कैन स्कोर देखें।
- **`style` URL में 8,192 अक्षरों तक** हो सकता है, और उसका JSON 40 KB तक।
- **डेटा URL का हिस्सा है।** किसी भी URL की तरह यह सर्वर लॉग, ब्राउज़र हिस्ट्री और cache में पहुँच सकता है। इसमें पासवर्ड या दूसरी गोपनीय जानकारी न डालें।

## स्कैन करने के सुझाव [#scanning-tips]

- जब इमेज गहरे या भरे-भरे बैकग्राउंड पर हो, जैसे GitHub के डार्क मोड में README, तो `margin` को `2` या उससे ज़्यादा रखें।
- `fg` और `bg` के बीच अच्छा कंट्रास्ट रखें। हल्के बैकग्राउंड पर गहरे मॉड्यूल सबसे भरोसेमंद तरीके से स्कैन होते हैं।
- डिफ़ॉल्ट (चौकोर मॉड्यूल, 4 मॉड्यूल का margin) हर रीडर पर स्कैन होते हैं। `circle` डॉट जैसे स्टाइल वाले आकार ज़्यादा मुलायम दिखते हैं, लेकिन कुछ पुराने स्कैनर उन्हें कम भरोसेमंद ढंग से पढ़ते हैं — [स्कैन चेकर](/tools/scan-checker) से जाँच लें।
- प्रिंट करने से पहले कोड को कुछ फ़ोन से टेस्ट करें।

## सेल्फ-होस्टिंग [#self-hosting]

यह endpoint QRdx वेब ऐप का हिस्सा है, इसलिए [सेल्फ-होस्टेड](/docs/self-hosting) इंस्टेंस इसे आपके अपने डोमेन पर `/api/v1/qr` पर चलाता है (उदाहरण के लिए `https://qr.example.com/api/v1/qr?data=…`)। छोटा `/v1/qr` पाथ सिर्फ़ `api.qrdx.dev` पर काम करता है। रेट लिमिटिंग तब Upstash Redis इस्तेमाल करती है जब वह कॉन्फ़िगर हो, वरना बंद रहती है।
