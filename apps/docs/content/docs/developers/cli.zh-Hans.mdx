`@qrdx/cli` 可在命令行中渲染出与 Playground 和 [`qrdx` 库](/docs/getting-started)相同的二维码。在脚本和 CI 中它从不弹出提示;如果在终端中不带参数运行 `qrdx generate`,它会逐步询问内容和选项。

<NpmStatus package="@qrdx/cli" />

```bash
npx @qrdx/cli generate "https://example.com" -o qr.svg
```

全局安装后即可使用 `qrdx` 命令:

```bash
npm install -g @qrdx/cli
qrdx generate "https://example.com" -o qr.png --size 1024
```

需要 Node.js 22 或更高版本。PNG 和 WebP 输出使用 [sharp](https://sharp.pixelplumbing.com),这是一个可选依赖,npm 会在你的平台支持时自动安装;SVG 和 EPS 不依赖它。npm 上的 `qrdx` 包是 React 库,CLI 只在 `@qrdx/cli` 中。

## 输出格式 [#output-formats]

文件扩展名决定输出格式;如果文件名没有扩展名,请使用 `--format`。

| 格式 | 适用场景 | `--size` 的含义 |
| --- | --- | --- |
| `.svg` | 网页、设计工具、无损缩放 | 宽度(像素,默认 512) |
| `.png` | 文档、幻灯片等任何需要图片的场合 | 宽度(像素) |
| `.webp` | 网站:与 PNG 像素相同、无损,文件更小 | 宽度(像素) |
| `.eps` | 印刷厂、Illustrator、InDesign | 宽度(点,每英寸 72 点,因此 `144` 为 2 英寸) |

EPS 文件是矢量 PostScript。PNG 和 JPEG 格式的 Logo 会原样嵌入;其他格式的 Logo 在已安装 sharp 时会先转换,否则会被忽略并给出警告。

## 选项 [#options]

| 标志 | 默认值 | 说明 |
| --- | --- | --- |
| `-o`, `--output` | `qr.svg` | 输出文件 |
| `--format` | 取自扩展名 | `svg`、`png`、`webp` 或 `eps` |
| `--size` | `512` | 输出尺寸(见上文) |
| `-l`, `--level` | `Q` | 纠错级别:`L`、`M`、`Q` 或 `H` |
| `--body` | `square` | 数据模块的[图案](/docs/features/patterns) |
| `--eye` | `square` | 角落定位眼图案 |
| `--dot` | `square` | 角落定位眼中心点图案 |
| `--fg`, `--bg` | `#000000`, `#ffffff` | 前景色和背景色:十六进制颜色或 JSON 渐变 |
| `--eye-color`, `--dot-color` | `--fg` | 角落定位眼和眼中心点的颜色 |
| `--logo` | | 中心 Logo 图片的 URL(请配合 `--level H` 使用) |
| `--margin` | `0` | 静区,以模块为单位 |
| `--template` | | `Arrow`、`StandardBox`、`SquareBorder`、`StrikedBox` 或 `Halloween` |
| `--frame` | | 行动号召[边框](/docs/features/frames):支持全部 {facts.frameStyles} 种边框样式,如 `banner-bottom`、`rounded-border`、`circle`、`sticker` 或 `phone`(参见[全部样式](/docs/styles#frames)) |
| `--frame-text` | `Scan me` | 边框标签文字,最多 24 个字符 |
| `--frame-color`, `--frame-text-color` | | 边框和标签的颜色(十六进制) |

`qrdx --help` 会列出所有图案名称。传入无效值时,命令会以退出码 `1` 结束,并给出列有可接受值的提示信息。

## 通过 CSV 批量生成 [#many-codes-from-a-csv]

`qrdx batch` 会为 CSV 文件的每一行生成一个静态二维码,并保存到一个文件夹中:

```bash
qrdx batch products.csv -o codes --format png --size 1024 --body circle
```

它读取的列与[批量生成器](/tools/bulk)相同:内容取自名为 `value`、`url`、`link`、`data`、`content`、`text` 或 `qr` 的列(否则取第一列),文件名取自名为 `file name`、`name`、`label`、`id`、`title` 或 `sku` 的列(否则使用 `qr-00001`、`qr-00002`,依此类推)。你也可以按表头名称或列号指定其他列:

| 标志 | 默认值 | 说明 |
| --- | --- | --- |
| `-o`, `--out` | `qr-codes` | 存放二维码的文件夹 |
| `--format` | `svg` | `svg`、`png` 或 `eps` |
| `--value-column` | 自动识别 | 包含每个二维码内容的列 |
| `--name-column` | 自动识别 | 包含文件名的列 |
| `--no-header` | | 第一行是二维码内容,而不是列名 |
| `--jobs` | SVG 为 `4`,其他为 `8` | 同时渲染的二维码数量 |

上面所有样式选项都适用于全部二维码。CSV 以流的方式读取,每个二维码生成后立即保存,因此该命令没有行数限制:在笔记本电脑上,生成 10,000 个 SVG 二维码约用时 40 秒,内存占用不到 200 MB。不会上传任何内容,也无需账号。无法编码的行会被跳过,并连同原因一起列在输出文件夹的 `errors.csv` 中。

如需批量打印[动态二维码](/docs/dynamic-qr-codes),请先创建它们(使用控制台的 CSV 导入或 API),然后对导入后得到的结果 CSV 运行 `qrdx batch`,并加上 `--value-column short_link`。

## 示例 [#examples]

```bash
# High-resolution PNG for print
qrdx generate "https://example.com" -o qr.png --size 2048 --level H

# Vector EPS, 2 inches wide, for a print shop
qrdx generate "https://example.com" -o qr.eps --size 144

# Branded colors and patterns
qrdx generate "https://example.com" --body circle --eye rounded --fg "#1a1a2e" -o brand.svg

# Gradient foreground
qrdx generate "https://example.com" -o gradient.svg \
  --fg '{"type":"linear","stops":[{"color":"#6366f1","offset":0},{"color":"#ec4899","offset":100}],"angle":135}'

# "Scan for the menu" frame
qrdx generate "https://example.com/menu" --frame banner-bottom --frame-text "Scan for the menu" -o menu.png

# Wi-Fi network
qrdx generate "WIFI:T:WPA;S:MyNetwork;P:MyPassword;;" -o wifi.svg
```

如需打印[动态二维码](/docs/dynamic-qr-codes),请把它的短链接(`https://qrdx.dev/q/<slug>`)作为数据传入。
