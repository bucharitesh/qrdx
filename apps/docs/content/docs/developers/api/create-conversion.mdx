From your server, send an API key (or token) and the scan's `sid`, or the code id as `code`. From the browser, `conversions.js` sends `sid` with no key, for codes with conversion tracking turned on. An `id`, such as your order id, makes retries safe: a repeat returns 200 with `duplicate: true`. More in [Tracking and conversions](https://qrdx.dev/docs/tracking-and-conversions).

**Scope:** `codes:write`, for API keys and OAuth tokens alike (when you send a key or token).
