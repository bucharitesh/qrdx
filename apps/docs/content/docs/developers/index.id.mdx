## URL dasar dan autentikasi [#base-url-and-authentication]

REST API berada di `https://api.qrdx.dev/v1`. Rute yang sama juga dapat diakses di `https://qrdx.dev/api/v1`.

Permintaan diautentikasi dengan [kunci API](/docs/developers/api-keys) pada header `Authorization: Bearer`. Aplikasi yang bertindak atas nama pengguna QRdx lain mengirim [token akses OAuth 2.0](/docs/developers/rest-api#get-an-access-token) di sana. [Panduan mulai cepat](/docs/developers/quickstart#create-an-api-key) membuat kunci dan melakukan permintaan pertama.
