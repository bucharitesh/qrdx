QRdxは、次のURLで公開の [Model Context Protocol](https://modelcontextprotocol.io) サーバーを運用しています。

```txt
https://mcp.qrdx.dev/mcp
```

どのクライアントでも、このURLを使用してください。同じサーバーは `https://qrdx.dev/api/mcp` でも応答します。[接続ページ](/mcp)では、qrdx.dev、プレビューデプロイ、ローカル開発環境それぞれの公開URLを確認できます。

このサーバーはStreamable HTTPトランスポートを使用し、セッション状態を保持しません。AIアシスタントはこのサーバーを呼び出して、あらゆるコンテンツタイプのQRコードをスキャンスコアの確認付きでデザインしたり、QRコードをレンダリングしたり、利用可能なスタイルを一覧したり、コミュニティのフレームやテーマを探したりできます。また、Wi-Fi、連絡先、メール、SMS、地図の位置情報について、正しい形式のペイロードを作成することもできます。いずれもアカウントやAPIキーは不要です。接続にQRdxのAPIキーを指定すると、デザインを自分のテーマに保存したり、アップロード済みのロゴを使用したりすることもできます（[APIキーを使用する](#use-an-api-key)を参照）。

[Playgroundで試す](/playground?open=code&lang=mcp)：Playgroundでコードをスタイル設定し、アシスタント向けの `design_qr` の引数としてコピーできます。

設定が済んだら、必要な内容を依頼してください。例:

- 「https://example.com のQRコードを、ブランドカラーの青 #155dfc で、角丸のモジュールで作って。」
- 「ネットワーク名 Office Guest、パスワード correct-horse-battery のWi-FiのQRコードを作成して。」
- 「Ada Lovelace、ada@example.com の連絡先QRコードを生成して、READMEに追加して。」
- 「Cafe Guest用のWi-FiのQRコードを、温かみのある茶色系で、Free Wi-Fi のフレーム付きでデザインして。スキャンスコアも教えて。」
- 「レストランのメニュー向けのコミュニティフレームを探して、https://example.com/menu に使って。」

## ツール [#tools]

| ツール | 機能 |
|------|--------------|
| `design_qr` | 任意のコンテンツタイプのコードを、アシスタントが選んだスタイル、または組み込みテーマやコミュニティアイテムをもとにデザインし、スキャンスコアを確認して、Great になるまでスタイルを修正します。スコア、変更内容、スタイル JSON、Playground へのリンク、PNG、SVG を返します。 |
| `list_options` | `design_qr` が受け付けるすべての値を一覧にします。コンテンツタイプとそのフィールド、色とグラデーション、形状、フレーム（QRdx 公式フレームの ID を含む）、枠線、ロゴアイコンとブランドロゴ、組み込みテーマ、誤り訂正レベル、制限が含まれます。 |
| `generate_qr_code` | エディタのスタイルで QR コードを描画します。PNG 画像と、Markdown、HTML、印刷にそのまま使える公開 [Image API](/docs/developers/image-api) の URL（SVG、PNG、ロスレス WebP、ベクター EPS）を返します。リクエストに応じて SVG マークアップも返します。 |
| `list_qr_styles` | ボディパターン、コーナーアイとアイドットの形状、枠線テンプレート、フレーム、ロゴアイコン、誤り訂正レベル、デフォルト値、制限を一覧にします。 |
| `search_community` | 公開されている[コミュニティ](/community)のフレーム、テーマ、コレクションを、キーワード、タイプ、タグで検索します。 |
| `get_community_item` | コミュニティアイテムを 1 件、適用されるスタイルとともに返します。`design_qr` や `generate_qr_code` にそのまま渡せます。 |
| `save_template` | デザインをテーマとしてワークスペースに保存します。[API キー](#use-an-api-key)が必要です。 |
| `generate_barcode` | 値（チェックディジット、桁数、文字）を確認したうえで、EAN-13、UPC-A、UPC-E、EAN-8、ITF-14、GS1-128、Code 128、Code 39、Data Matrix、PDF417、Aztec のバーコードを描画します。PNG と公開[バーコード API](/docs/developers/barcode-api)の URL を返します。 |
| `save_barcode` | バーコードをワークスペースのバーコードに保存します。[API キー](#use-an-api-key)が必要です。 |
| `qr_payload_wifi` | 特殊文字をエスケープした `WIFI:` ネットワークペイロードを作成します（WPA、WEP、オープン、非公開ネットワークにも対応）。 |
| `qr_payload_vcard` | vCard 3.0 の連絡先（RFC 2426）を作成します。氏名、組織、役職、電話番号、メールアドレス、ウェブサイト、住所、メモに対応します。 |
| `qr_payload_email` | `mailto:` リンク（RFC 6068）を作成します。cc、bcc、件名、本文は任意です。 |
| `qr_payload_sms` | `sms:` リンク（RFC 5724）を作成します。メッセージは任意で、従来の `SMSTO:` 形式にも対応します。 |
| `qr_payload_geo` | 緯度と経度から `geo:` 位置情報（RFC 5870）を作成します。 |
| `qr_payload_payment` | 銀行決済コードを作成します。Pix BR Code、SEPA クレジット振込（EPC069-12）、PayNow、PromptPay、VietQR コード（EMV、CRC 付き）に対応します。Playground のフォームと同様にフィールドを検証します。 |

ペイロードツールは単純な文字列を返します。アシスタントはそれを `data` として `generate_qr_code` に渡します。

### design_qr [#design_qr]

`design_qr` は、コンテンツをタイプとそのフィールドで受け取ります。タイプと検証はエディタのコンテンツフォームと同じです（`list_options` で一覧を確認できます）。スタイルは任意です。

```json
{
  "content": { "type": "wifi", "ssid": "Cafe Guest", "password": "sunshine123", "encryption": "WPA" },
  "style": {
    "bgColor": "#FFF7ED",
    "fgColor": "#9A3412",
    "bodyPattern": "rounded",
    "cornerEyePattern": "rounded",
    "frame": { "style": "banner-bottom", "text": "Free Wi-Fi" }
  }
}
```

指定しなかったオプションにはデフォルト値が使われます（アイはドットの色に合わせ、形状は四角、マージンは 4、誤り訂正は Q、フレームなし）。そのうえで QRdx は、エディタと同じスキャンチェックをデザインに対して実行します。コードを描画し、スマートフォンのカメラモデルで 96、160、320 px でデコードし、コントラスト、クワイエットゾーン、アイの形状、形状の組み合わせを確認します。スコアが Great（85）に届かない場合は、スタイルを最大 3 回まで、できるだけ小さな変更で修正します（色相を保ったまま暗くする、より安全なアイの形状にする、長いコンテンツでは誤り訂正を下げる、など）。それでも足りない場合は、フレームはそのままに、白地に黒の標準的なコードに切り替えます。結果には、何をなぜ変更したかが示されます。

`design_qr` では、QRdx 側で AI モデルは動作しません。スタイルを選ぶのはアシスタントで、QRdx はそれを検証、チェック、修正します。無効なコンテンツ（8 文字未満の WPA パスワード、不正な形式のメールアドレスなど）は、理由とともに拒否されます。`design_qr` には独自の制限があり、IP アドレスごとに 1 分あたり 20 回までです。

その他の入力:

- **`preset`**: ID を指定して組み込みテーマから始めます（`list_options` で一覧を確認できます）。指定したスタイルオプションが優先されます。
- **`community_item`**: `frame:wifi-card` のように、ID を指定してコミュニティのフレームやテーマから始めます。フレームアイテムは標準的なコードの上に配置され、スタイルオプションはその下のコードを変更します。
- **公式フレーム**: QRdx の公式フレームもコミュニティアイテムです。`list_options` がグループ別（祝日、季節、用途）に ID を一覧にするので、`frame:diwali-diya` や `frame:menu-cutlery` を `community_item` として使えます。
- **カスタムフレーム**: `style.frame` には、`get_community_item` で得られるコミュニティフレームのようなフレームスペックを使って `{ "style": "custom", "spec": … }` を指定できます。そのまま描画され、スコアリングされます。修正で変更されるのはコードのみで、フレームは変更されません。
- **`style.logo`**: クイックロゴアイコン（`wifi`、`location`、`phone`、`email`、`link`、`file`、`calendar`、`whatsapp`、`instagram`）、または [Simple Icons](https://simpleicons.org) のスラッグによるブランドロゴ（`spotify`、`paypal:white`）。`list_options` が主要なブランドのスラッグを一覧にします。
- **エンジンオプション**: `style.eyeColors`（アイごとの `#RRGGBB` 色）、`moduleScale`（ドットサイズ、`0.5` から `1`）、`shape`（丸いコードにするには `circle`）、`autoLevel`、`logoOptions`（ロゴのサイズ、余白、位置、トリミング、プレート）。指定どおりに描画、スコアリングされ、修正では変更されません。

<IfAvailable feature="fileStorage">
`logo_file_id` を使うと、代わりに QRdx にアップロードしたロゴを描画できます。[API キー](#use-an-api-key)が必要です。
</IfAvailable>

ロゴはエディタと同様に、覆われるモジュールの数でスコアリングされるため、修正によって誤り訂正が H に引き上げられたり、ロゴが取り除かれたりすることがあります。エディタがデフォルトで表示する QRdx マークは、ここでは描画されません。

結果の `qrdxStyle` は、エディタのスタイル JSON 形式のデザインです。これを `save_template` に渡すか、`generate_qr_code` に `style` として渡せば、同じデザインを別のサイズで描画できます。Image API の [`style`](/docs/developers/image-api#style) にも渡せます。`playground_url` は、デザインを [Playground](/playground) で開きます。含まれるのはスタイルだけで、ロゴやコンテンツは含まれません。含まれないものは `playgroundLeftOut` に示されます。

### generate_qr_code の入力 [#generate_qr_code-inputs]

入力は [Image API のパラメータ](/docs/developers/image-api#parameters)と同じです。`data`（必須）、`size`、`fg`、`bg`、`eyeColor`、`dotColor`、`body`、`eye`、`dot`、`level`、`margin`、`template`、`frame`、`frameText`、`logoIcon`、`logoFileId`、`item`（コミュニティアイテムの ID）、`style`（エディタのスタイル JSON。`design_qr` が返す、グラデーションやカスタムフレームなどを含む形式）です。個別のオプションは `style` より優先され、`style` は `item` より優先されます。`include_svg` を `true` にすると、たとえば `.svg` ファイルとして保存するために、SVG マークアップもテキストで取得できます。マークアップは 50〜150 KB になることが多く、会話を埋めてしまうため、デフォルトではオフです。

`generate_qr_code` はスキャンスコアを確認しません。確認には `design_qr` を使ってください。アップロードしたロゴを使ったコードには公開画像 URL がありません。Image API がそのロゴを描画するのは、API キー付きのリクエストだけだからです。

### QR カード [#qr-card]

[MCP Apps](https://modelcontextprotocol.io/extensions/apps/overview) に対応したアプリでは、`design_qr` と `generate_qr_code` がチャットに QR カードも表示します。カードには、コード、エンコードされた内容（Wi-Fi コードではネットワーク名を表示し、パスワードは表示しません）、サイズ、誤り訂正またはスキャンスコア、そして **Open in editor** ボタンが含まれます。エディタへのリンクには、`playground_url` と同様にスタイルのみが含まれます。

PNG ボタンと SVG ボタンの動作は、アプリが許可する内容によって異なります。カードからファイルを保存できるアプリでは、ファイルが保存されます。それ以外では、Image API の URL がブラウザで開きます。そのため `design_qr` のカードは、ファイルを保存できるアプリでのみこれらのボタンを表示します。そのコンテンツが画像 URL に含まれることはありません。アプリによっては、リンクを開く前に確認を求められる場合があります。

MCP Apps に対応していないアプリでは、これまでと同じテキストと画像が返されます。クライアント開発者向けの情報:

- カードはリソース `ui://qrdx/qr-card`（`text/html;profile=mcp-app`）で、`resources/list` に一覧表示されます。どちらのツールも `_meta.ui.resourceUri` でこのリソースを指します。
- カードのデータは、ツール結果の `_meta` の `dev.qrdx/qr-card` に格納されます。これはモデル向けではなくカード向けです。ツールは `structuredContent` を返しません。
- カードは、スタイルとスクリプトをインラインで含む単一の HTML ファイルです。読み込むのは Image API（`https://api.qrdx.dev`、セルフホストの場合は独自ドメイン）からのコード画像だけで、コンテンツセキュリティポリシー（`_meta.ui.csp.resourceDomains`）もそのホストのみを許可します。

カードが追加される前に QRdx を接続していた場合は、コネクタを削除して再追加するか、ツールを更新してください。これで、アプリが新しいツールメタデータを取得します。

### コミュニティ [#community]

`search_community` は、公開されている[コミュニティ](/community)のフレーム、テーマ、コレクション（CC0 で無料）を、キーワード（`q`）、`type`、`tag` で検索します。`get_community_item` は、アイテムを 1 件、適用されるスタイルとともに返します。その ID を、`design_qr` には `community_item` として、`generate_qr_code` には `item` として渡します。同じデータは REST API の [`/v1/community/items`](/docs/developers/api/list-community-items) でも取得できます。

アイテムのテキストはコミュニティのメンバーが書いたものです。名前、説明、ハンドル、タグ、フレームのラベルは、短く、1 行で、リンク、メールアドレス、マークアップなしで返されます。また、すべての結果には、それらを指示ではなくデータとして扱うよう明記されています。

## APIキーを使う [#use-an-api-key]

一部のツールでは、接続にQRdxの[APIキー](/docs/developers/api-keys)が必要です。キーは `Authorization: Bearer qrdx_…` の形式で送信します。

- **`save_template`** はデザインをテーマとして保存します。保存したテーマはダッシュボードの「テーマ」に表示され、エディターでも使えます。`codes:write` を持つキーが必要で、**フルアクセス**のキーにはこの権限があります。自分のワークスペースのキーで保存した場合は自分のテーマに保存されます。チームキーで保存した場合は、キーの作成者がオーナーまたは管理者で、かつプランにチームテーマが含まれていれば、チームの共有テーマに保存されます。保存数はプランの保存テーマ数の上限に含まれます（[プランと制限](/docs/plans-and-limits)を参照）。上限を超えると、ツールはAPIの `LIMIT_REACHED` エラー（`402`）を返します。キーがない場合は、キーの追加方法を示す `401` エラーを返します。
- **`save_barcode`** はバーコード（フォーマット、値、任意のタイトル、描画オプション）をキーのワークスペースに保存します。保存したバーコードはダッシュボードの「バーコード」に表示されます。`codes:write` を持つキーが必要です。バーコードはすべてのプランで保存でき、フリーでは最大1,000件です。上限を超えると `LIMIT_REACHED`（`402`）を返します。
<IfAvailable feature="fileStorage">
- **アップロードしたロゴ**は、[ダッシュボード → ファイル](/docs/files)にアップロードしたものを、ファイルIDで指定します（`design_qr` では `logo_file_id`、`generate_qr_code` では `logoFileId`）。PNGまたはJPEGで、1 MBまでです。キーは、そのファイルを所有するワークスペースのものである必要があります。
</IfAvailable>

## プライバシーと制限 [#privacy-and-limits]

- ツールは、画像の生成、デザインのチェック、テキストの整形、公開コミュニティの読み取りを行います。書き込みを行うのは `save_template` と `save_barcode` だけで、保存を指示したテーマまたはバーコードを、APIキーのワークスペースに保存します。サーバーは、生成したコードを保存しません。
- `generate_qr_code` と `generate_barcode` が返す画像URLには、エンコードされたデータが含まれます。Wi-Fiのパスワードなど、データが非公開の場合は、URLを共有しないでください。
- リクエストは、IPアドレスごとに1分あたり120件までで、`design_qr` は20件までです。キーを使う場合、`save_template` はユーザーごとに1分あたり30件までにも制限されます。

## セルフホストとローカル開発 [#self-hosting-and-local-development]

MCPサーバーはQRdxのWebアプリの一部なので、どのインスタンスでも `/api/mcp` で提供されます。

- **セルフホスト。** `NEXT_PUBLIC_APP_URL` が自分のドメインの場合、接続ページ、スニペット、インストールリンクには `https://<your-domain>/api/mcp` が使われます。
- **ローカル開発。** `bun run dev` を実行すると、`http://localhost:3000/api/mcp` で提供されます。接続ページには引き続き公開URLが表示され、ローカルのURLはヒントとして案内されます。これにより、クライアントを自分のマシンに向けて、サーバーの変更を公開前にテストできます。

ブラウザーで `/api/mcp` を開くと、接続ページにリダイレクトされます。MCPクライアントはHTMLを要求しないため、通常どおりサーバーにアクセスできます。
