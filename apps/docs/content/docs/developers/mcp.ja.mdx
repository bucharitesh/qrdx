QRdx は、次のURLで公開の [Model Context Protocol](https://modelcontextprotocol.io) サーバーを運用しています。

```txt
https://mcp.qrdx.dev/mcp
```

どのクライアントでもこのURLを使用してください。同じサーバーは `https://qrdx.dev/api/mcp` でも応答します。[接続ページ](/mcp)には、qrdx.dev、プレビューデプロイ、ローカル開発環境それぞれの公開URLが表示されます。

このサーバーはStreamable HTTPトランスポートを使用し、セッション状態を保持しません。AIアシスタントはこのサーバーを呼び出して、あらゆるコンテンツタイプのQRコードをスキャンスコアの確認付きでデザインしたり、QRコードをレンダリングしたり、利用可能なスタイルを一覧表示したり、コミュニティのフレームやテーマを検索したりできます。Wi-Fi、連絡先、メール、SMS、地図の位置情報については、正しい形式のペイロードも作成できます。これらはいずれもアカウントやAPIキーを必要としません。接続時に QRdx のAPIキーを指定すると、デザインを自分のテーマに保存したり、アップロード済みのロゴを使用したりすることもできます（[APIキーを使う](#use-an-api-key)を参照）。

[Playgroundで試す](/playground?open=code&lang=mcp)：Playgroundでコードをスタイル設定し、アシスタント用の `design_qr` の引数としてコピーできます。

あとは、必要な内容を依頼するだけです。例：

- 「https://example.com のQRコードを、ブランドカラーのブルー #155dfc、角丸のモジュールで作って。」
- 「ネットワーク名 Office Guest、パスワード correct-horse-battery のWi-Fi QRコードを作って。」
- 「Ada Lovelace、ada@example.com の連絡先QRコードを生成して、READMEに追加して。」
- 「Cafe Guest 用のWi-Fi QRコードを、温かみのあるブラウン系で、Free Wi-Fi のフレーム付きでデザインして。スキャンスコアも教えて。」
- 「レストランのメニュー向けのコミュニティフレームを探して、https://example.com/menu に使って。」

## ツール [#tools]

| ツール | 内容 |
|------|--------------|
| `design_qr` | アシスタントが選んだスタイル、または組み込みテーマやコミュニティのアイテムをもとに、あらゆるコンテンツタイプのコードをデザインします。スキャンスコアを確認し、Great になるまでスタイルを修正します。スコア、変更内容、スタイルJSON、Playground へのリンク、PNG、SVG を返します。 |
| `list_options` | `design_qr` が受け付けるすべての値を一覧表示します。コンテンツタイプとそのフィールド、色とグラデーション、形状、フレーム(QRdx 公式フレームの ID を含む)、枠線、ロゴアイコンとブランドロゴ、組み込みテーマ、誤り訂正レベル、制限値が対象です。 |
| `generate_qr_code` | エディターのスタイルで QRコードを描画します。PNG 画像と、Markdown、HTML、印刷にそのまま使える公開 [Image API](/docs/developers/image-api) の URL(SVG、PNG、ロスレス WebP、ベクター EPS)を返します。リクエストに応じて SVG マークアップも返します。 |
| `list_qr_styles` | ボディパターン、コーナーアイとアイドットの形状、枠線テンプレート、フレーム、ロゴアイコン、誤り訂正レベル、デフォルト値、制限値を一覧表示します。 |
| `search_community` | 公開されている[コミュニティ](/community)のフレーム、テーマ、コレクションを、キーワード、タイプ、タグで検索します。 |
| `get_community_item` | コミュニティのアイテムを1件取得します。適用されるスタイルが含まれ、`design_qr` や `generate_qr_code` にそのまま渡せます。 |
| `save_template` | デザインをワークスペースのテーマとして保存します。[API キー](#use-an-api-key)が必要です。 |
| `generate_barcode` | 値(チェックディジット、長さ、文字)を検証したうえで、EAN-13、UPC-A、UPC-E、EAN-8、ITF-14、GS1-128、Code 128、Code 39、Data Matrix、PDF417、Aztec のバーコードを描画します。PNG と公開 [バーコードAPI](/docs/developers/barcode-api) の URL を返します。 |
| `save_barcode` | バーコードをワークスペースのバーコードに保存します。[API キー](#use-an-api-key)が必要です。 |
| `qr_payload_wifi` | 特殊文字をエスケープした `WIFI:` ネットワークペイロード(WPA、WEP、オープン、非公開も指定可)を作成します。 |
| `qr_payload_vcard` | vCard 3.0 の連絡先(RFC 2426)を作成します。氏名、組織、役職、電話番号、メール、ウェブサイト、住所、メモに対応しています。 |
| `qr_payload_email` | `mailto:` リンク(RFC 6068)を作成します。cc、bcc、件名、本文は任意です。 |
| `qr_payload_sms` | `sms:` リンク(RFC 5724)を作成します。メッセージは任意です。従来の `SMSTO:` 形式も使えます。 |
| `qr_payload_geo` | 緯度と経度から `geo:` 位置情報(RFC 5870)を作成します。 |

ペイロードツールはプレーンな文字列を返します。アシスタントはその文字列を `data` として `generate_qr_code` に渡します。

### design_qr [#design_qr]

`design_qr` は、コンテンツをタイプとそのフィールドで受け取ります。タイプとチェックはエディターのコンテンツフォームと同じです(`list_options` で一覧できます)。スタイルは任意です。

```json
{
  "content": { "type": "wifi", "ssid": "Cafe Guest", "password": "sunshine123", "encryption": "WPA" },
  "style": {
    "bgColor": "#FFF7ED",
    "fgColor": "#9A3412",
    "bodyPattern": "rounded",
    "cornerEyePattern": "rounded",
    "frame": { "style": "banner-bottom", "text": "Free Wi-Fi" }
  }
}
```

省略したオプションにはデフォルト値が使われます(アイはドットの色に従い、形状は四角、マージンは 4、誤り訂正は Q、フレームなし)。その後、QRdx がデザインに対してエディターと同じスキャンチェックを実行します。コードを描画し、スマートフォンのカメラを模したモデルで 96、160、320 px の各サイズでデコードし、コントラスト、クワイエットゾーン、アイの形状、形状の組み合わせを確認します。スコアが Great(85)未満の場合は、最大 3 回までスタイルを修正します。変更はできるだけ小さく抑えます(色相を保ったまま暗くする、より安全なアイの形状にする、長いコンテンツでは誤り訂正を下げる、など)。それでも足りない場合は、指定したフレーム付きの、白地に黒の標準的なコードに切り替えます。結果には、何をなぜ変更したかが示されます。

`design_qr` では、QRdx 側で AI モデルは動きません。スタイルを選ぶのはアシスタントで、QRdx はそれを検証、チェック、修正します。無効なコンテンツ(8 文字未満の WPA パスワード、不正な形式のメールアドレスなど)は、理由とともに拒否されます。`design_qr` には、IP アドレスごとに 1 分あたり 20 回という独自の制限があります。

その他の入力:

- **`preset`**: ID で組み込みテーマから始めます(`list_options` で一覧できます)。設定したスタイルオプションが優先されます。
- **`community_item`**: `frame:wifi-card` のように、ID でコミュニティのフレームやテーマから始めます。フレームのアイテムは標準的なコードの上に置かれ、スタイルオプションはその下のコードに作用します。
- **公式フレーム**: QRdx の公式フレームもコミュニティのアイテムです。`list_options` がグループ別(祝日、季節、用途)に ID を一覧表示するので、`frame:diwali-diya` や `frame:menu-cutlery` を `community_item` として使えます。
- **カスタムフレーム**: `style.frame` には、`get_community_item` で取得したコミュニティフレームのものなど、フレーム仕様を使った `{ "style": "custom", "spec": … }` を指定できます。そのまま描画され、スコアリングされます。修正で変わるのはコードだけで、フレームは変わりません。
- **`style.logo`**: クイックロゴアイコン(`wifi`、`location`、`phone`、`email`、`link`、`file`、`calendar`、`whatsapp`、`instagram`)、または [Simple Icons](https://simpleicons.org) のスラッグによるブランドロゴ(`spotify`、`paypal:white`)。人気のブランドスラッグは `list_options` で一覧できます。
- **エンジンオプション**: `style.eyeColors`(アイごとの `#RRGGBB` カラー)、`moduleScale`(ドットサイズ、`0.5` から `1`)、`shape`(円形のコードにするには `circle`)、`autoLevel`、`logoOptions`(ロゴのサイズ、余白、位置、トリミング、プレート)。指定どおりに描画およびスコアリングされ、修正では変更されません。

<IfAvailable feature="fileStorage">
`logo_file_id` を使うと、代わりに QRdx にアップロードしたロゴを描画します。[API キー](#use-an-api-key)が必要です。
</IfAvailable>

ロゴは、エディターと同様に覆うモジュール数でスコアリングされるため、修正によって誤り訂正が H に引き上げられたり、ロゴが取り除かれたりすることがあります。エディターがデフォルトで表示する QRdx のマークは、ここでは描画されません。

結果の `qrdxStyle` は、エディターのスタイルJSONとしてのデザインです。これを `save_template` に渡すか、`style` として `generate_qr_code` に渡せば、同じデザインを別のサイズで描画できます。Image API の [`style`](/docs/developers/image-api#style) にも渡せます。`playground_url` は [Playground](/playground) でデザインを開きます。含まれるのはスタイルだけで、ロゴやコンテンツは含まれません。含まれないものは `playgroundLeftOut` に示されます。

### generate_qr_code の入力 [#generate_qr_code-inputs]

入力は [Image API のパラメーター](/docs/developers/image-api#parameters)と同じです。`data`(必須)、`size`、`fg`、`bg`、`eyeColor`、`dotColor`、`body`、`eye`、`dot`、`level`、`margin`、`template`、`frame`、`frameText`、`logoIcon`、`logoFileId`、`item`(コミュニティアイテムの ID)、`style`(`design_qr` が返すような、グラデーションやカスタムフレームなどを含むエディターのスタイルJSON)です。個別のオプションは `style` より優先され、`style` は `item` より優先されます。`include_svg` を `true` に設定すると、SVG マークアップもテキストで取得できます。たとえば `.svg` ファイルとして保存したいときに使います。マークアップは 50〜150 KB になることが多く、会話を埋めてしまうため、デフォルトではオフです。

`generate_qr_code` はスキャンスコアを確認しません。確認には `design_qr` を使ってください。アップロードしたロゴを使ったコードには、公開の画像 URL がありません。Image API は、あなたのキーを使ったリクエストにだけそのロゴを描画するためです。

### QRカード [#qr-card]

[MCP Apps](https://modelcontextprotocol.io/extensions/apps/overview) に対応したアプリでは、`design_qr` と `generate_qr_code` がチャットに QRカードも表示します。カードには、コード、エンコードされた内容(Wi-Fi のコードではネットワーク名を表示し、パスワードは表示しません)、サイズと誤り訂正またはスキャンスコア、**エディターで開く** ボタンが表示されます。エディターへのリンクには、`playground_url` と同様にスタイルだけが含まれます。

PNG ボタンと SVG ボタンの動作は、アプリが許可する内容によって異なります。カードからファイルを保存できるアプリでは、ファイルが保存されます。それ以外では、Image API の URL がブラウザーで開きます。そのため、`design_qr` のカードでは、ファイルを保存できるアプリでのみこれらのボタンが表示されます。コンテンツが画像 URL に含まれることはありません。アプリによっては、リンクを開く前に確認を求められる場合があります。

MCP Apps に対応していないアプリでは、従来どおりのテキストと画像が返されます。クライアント開発者向けの情報:

- カードはリソース `ui://qrdx/qr-card`(`text/html;profile=mcp-app`)で、`resources/list` に一覧表示されます。どちらのツールも `_meta.ui.resourceUri` でこれを指します。
- カードのデータは、ツール結果の `_meta` の `dev.qrdx/qr-card` に入っており、モデルではなくカード向けです。ツールは `structuredContent` を返しません。
- カードは、スタイルとスクリプトをインラインで含む単一の HTML ファイルです。読み込むのは Image API(`https://api.qrdx.dev`、セルフホストの場合は独自ドメイン)からのコード画像だけで、コンテンツセキュリティポリシー(`_meta.ui.csp.resourceDomains`)もそのホストだけを許可します。

カードが登場する前に QRdx を接続していた場合は、コネクターを削除して再度追加するか、ツールを更新してください。アプリが新しいツールメタデータを取得します。

### コミュニティ [#community]

`search_community` は、公開されている[コミュニティ](/community)のフレーム、テーマ、コレクション(CC0 で無料)を、キーワード(`q`)、`type`、`tag` で検索します。`get_community_item` は、適用されるスタイルを含むアイテムを 1 件返します。その ID を `community_item` として `design_qr` に、または `item` として `generate_qr_code` に渡してください。同じデータは REST API の [`/v1/community/items`](/docs/developers/api/list-community-items) でも取得できます。

アイテムのテキストはコミュニティのメンバーが書いたものです。名前、説明、ハンドル、タグ、フレームのラベルは、短く、1 行で、リンク、メールアドレス、マークアップを除いた形で返されます。また、すべての結果に、これらを指示ではなくデータとして扱うよう促す文が付きます。

## APIキーを使う [#use-an-api-key]

一部のツールでは、接続時に QRdx の [APIキー](/docs/developers/api-keys) が必要です。キーは `Authorization: Bearer qrdx_…` として送信します。

- **`save_template`** はデザインをテーマとして保存します。保存したテーマはダッシュボードの「テーマ」に表示され、エディタでも選択できます。`codes:write` を持つキーが必要で、**フルアクセス**のキーにはこの権限があります。自分のワークスペースのキーで保存すると自分のテーマに保存されます。チームキーの場合は、キーの作成者がオーナーまたは管理者で、プランにチームテーマが含まれていれば、チームの共有テーマに保存されます。保存数はプランの保存テーマ数の上限にカウントされます（[プランと制限](/docs/plans-and-limits)を参照）。上限を超えると、ツールは API の `LIMIT_REACHED` エラー（`402`）を返します。キーがない場合は、キーの追加方法を示す `401` エラーを返します。
- **`save_barcode`** はバーコード（フォーマット、値、任意のタイトル、描画オプション）をキーのワークスペースに保存します。保存したバーコードはダッシュボードの「バーコード」に表示されます。`codes:write` を持つキーが必要です。バーコードはすべてのプランで保存でき、フリーでは最大 1,000 件です。上限を超えると `LIMIT_REACHED`（`402`）を返します。
<IfAvailable feature="fileStorage">
- [ダッシュボード → ファイル](/docs/files)で**アップロードしたロゴ**は、ファイル ID で指定できます（`design_qr` では `logo_file_id`、`generate_qr_code` では `logoFileId`）。対象は 1 MB までの PNG または JPEG です。キーは、そのファイルを所有するワークスペースのものである必要があります。
</IfAvailable>

## プライバシーと制限 [#privacy-and-limits]

- ツールは、画像の生成、デザインのチェック、テキストの整形、公開コミュニティの閲覧を行います。書き込みを行うのは `save_template` と `save_barcode` だけで、保存を依頼したテーマやバーコードを APIキーのワークスペースに保存します。生成したコードをサーバーが保存することはありません。
- `generate_qr_code` と `generate_barcode` が返す画像 URL には、エンコードしたデータが含まれます。Wi-Fi のパスワードなど非公開のデータの場合は、URL を共有しないでください。
- リクエストは IP アドレスごとに 1 分あたり 120 件までで、`design_qr` は 20 件までです。キーを使う場合、`save_template` にはさらにユーザーごとに 1 分あたり 30 件の制限があります。

## セルフホストとローカル開発 [#self-hosting-and-local-development]

MCP サーバーは QRdx の Web アプリに含まれているため、どのインスタンスでも `/api/mcp` で提供されます。

- **セルフホスト。** `NEXT_PUBLIC_APP_URL` が独自ドメインの場合、接続ページ、スニペット、インストールリンクでは `https://<your-domain>/api/mcp` が使われます。
- **ローカル開発。** `bun run dev` を実行すると、`http://localhost:3000/api/mcp` で提供されます。接続ページには引き続き公開 URL が表示され、ローカルの URL はヒントとして示されます。クライアントを自分のマシンに向ければ、サーバーの変更を公開前にテストできます。

ブラウザーで `/api/mcp` を開くと、接続ページにリダイレクトされます。MCP クライアントは HTML を要求しないため、通常どおりサーバーに接続できます。
