QRdxは、次のURLで公開の[Model Context Protocol](https://modelcontextprotocol.io)サーバーを運営しています。

```txt
https://mcp.qrdx.dev/mcp
```

どのクライアントでも、このURLを使用してください。同じサーバーは `https://qrdx.dev/api/mcp` でも応答します。また、[接続ページ](/mcp)では、qrdx.dev、プレビューデプロイ、ローカル開発それぞれの公開URLを確認できます。

このサーバーはStreamable HTTPトランスポートを使用し、セッション状態を保持しません。AIアシスタントはこのサーバーを呼び出して、あらゆるコンテンツタイプのQRコードをスキャンスコアの確認付きでデザインしたり、QRコードを描画したり、利用可能なスタイルを一覧表示したり、コミュニティのフレームやテーマを検索したりできます。また、Wi-Fi、連絡先、メール、SMS、地図の位置情報について、正しい形式のペイロードも作成できます。いずれもアカウントやAPIキーは不要です。接続にQRdxのAPIキーを付けると、デザインを自分のテーマに保存したり、アップロード済みのロゴを使用したりすることもできます（[APIキーを使用する](#use-an-api-key)を参照してください）。

[Playgroundで試す](/playground?open=code&lang=mcp)：Playgroundでコードをスタイリングし、アシスタント向けの `design_qr` の引数としてコピーできます。

設定が済んだら、必要なことを依頼してみましょう。例：

- 「https://example.com のQRコードを、ブランドカラーの青 #155dfc で、角丸のモジュールで作って。」
- 「ネットワーク名 Office Guest、パスワード correct-horse-battery のWi-Fi QRコードを作成して。」
- 「Ada Lovelace、ada@example.com の連絡先QRコードを生成して、READMEに追加して。」
- 「Cafe Guest 用のWi-Fi QRコードを、温かみのある茶色で、Free Wi-Fi のフレーム付きでデザインして。スキャンスコアも教えて。」
- 「レストランのメニュー向けのコミュニティフレームを探して、https://example.com/menu に使って。」

## ツール [#tools]

| ツール | 機能 |
|------|--------------|
| `design_qr` | アシスタントが選んだスタイル、または組み込みテーマやコミュニティアイテムをもとに、あらゆるコンテンツタイプのコードをデザインします。スキャンスコアを確認し、Great になるまでスタイルを修正します。スコア、変更内容、スタイル JSON、Playground のリンク、PNG、SVG を返します。 |
| `list_options` | `design_qr` が受け付けるすべての値を一覧表示します。コンテンツタイプとそのフィールド、色とグラデーション、形状、フレーム（QRdx 公式フレームの ID を含む）、枠線、ロゴアイコンとブランドロゴ、組み込みテーマ、誤り訂正レベル、制限です。 |
| `generate_qr_code` | エディタのスタイルで QR コードを描画します。PNG 画像と、Markdown、HTML、印刷にそのまま使える公開 [Image API](/docs/developers/image-api) の URL（SVG、PNG、ロスレス WebP、ベクター EPS）を返します。リクエストに応じて SVG マークアップも返します。 |
| `list_qr_styles` | ボディパターン、コーナーアイとアイドットの形状、枠線テンプレート、フレーム、ロゴアイコン、誤り訂正レベル、デフォルト値、制限を一覧表示します。 |
| `search_community` | 公開されている[コミュニティ](/community)のフレーム、テーマ、コレクションを、キーワード、タイプ、タグで検索します。 |
| `get_community_item` | コミュニティアイテムを1件取得し、適用されるスタイルを返します。`design_qr` や `generate_qr_code` にそのまま渡せます。 |
| `save_template` | デザインをテーマとしてワークスペースに保存します。[API キー](#use-an-api-key)が必要です。 |
| `generate_barcode` | 値（チェックディジット、長さ、文字）を確認したうえで、EAN-13、UPC-A、UPC-E、EAN-8、ITF-14、GS1-128、Code 128、Code 39、Data Matrix、PDF417、Aztec のバーコードを描画します。PNG と公開[バーコード API](/docs/developers/barcode-api) の URL を返します。 |
| `save_barcode` | バーコードをワークスペースのバーコードに保存します。[API キー](#use-an-api-key)が必要です。 |
| `qr_payload_wifi` | 特殊文字をエスケープした `WIFI:` ネットワークペイロードを作成します（WPA、WEP、オープン。非表示ネットワークも指定可能）。 |
| `qr_payload_vcard` | vCard 3.0 の連絡先（RFC 2426）を作成します。氏名、組織、役職、電話番号、メール、ウェブサイト、住所、メモに対応します。 |
| `qr_payload_email` | `mailto:` リンク（RFC 6068）を作成します。cc、bcc、件名、本文は任意です。 |
| `qr_payload_sms` | `sms:` リンク（RFC 5724）を作成します。メッセージは任意です。従来の `SMSTO:` 形式にも対応します。 |
| `qr_payload_geo` | 緯度と経度から `geo:` 位置情報（RFC 5870）を作成します。 |
| `qr_payload_payment` | 銀行支払いコードを作成します。Pix BR Code、SEPA クレジットトランスファー（EPC069-12）、PayNow、PromptPay、VietQR コード（EMV、CRC 付き）に対応します。Playground のフォームと同じようにフィールドを確認します。 |

ペイロードツールはプレーンな文字列を返します。アシスタントはそれを `data` として `generate_qr_code` に渡します。

### design_qr [#design_qr]

`design_qr` は、コンテンツをタイプとそのフィールドで受け取ります。タイプとチェック内容はエディタのコンテンツフォームと同じです（`list_options` で一覧を確認できます）。スタイルは任意です。

```json
{
  "content": { "type": "wifi", "ssid": "Cafe Guest", "password": "sunshine123", "encryption": "WPA" },
  "style": {
    "bgColor": "#FFF7ED",
    "fgColor": "#9A3412",
    "bodyPattern": "rounded",
    "cornerEyePattern": "rounded",
    "frame": { "style": "banner-bottom", "text": "Free Wi-Fi" }
  }
}
```

省略したオプションにはデフォルト値が使われます（アイの色はドットの色に合わせる、四角い形状、マージン 4、誤り訂正 Q、フレームなし）。そのうえで QRdx は、エディタのスキャンチェックをデザインに対して実行します。コードを描画し、スマートフォンのカメラモデルで 96、160、320 px でデコードし、コントラスト、クワイエットゾーン、アイの形状、形状の組み合わせを確認します。Great（85）に届かない場合は、スタイルを最大3回まで修正します。変更はできるだけ小さくします（色相を保ったまま色を濃くする、より安全なアイの形状にする、長いコンテンツでは誤り訂正を下げるなど）。それでも足りない場合は、白地に黒の標準的なコードに、指定したフレームを組み合わせたものに切り替えます。結果には、何をなぜ変更したかが示されます。

`design_qr` では、QRdx 側で AI モデルは動きません。スタイルはアシスタントが選び、QRdx が検証、チェック、修正を行います。無効なコンテンツ（8文字未満の WPA パスワード、不正な形式のメールアドレスなど）は、理由を添えて拒否されます。`design_qr` には独自の制限があり、IP アドレスごとに1分あたり20回までです。

その他の入力:

- **`preset`**: ID で組み込みテーマから始めます（`list_options` で一覧を確認できます）。設定したスタイルオプションが優先されます。
- **`community_item`**: `frame:wifi-card` のように、ID でコミュニティのフレームやテーマから始めます。フレームアイテムは標準的なコードの上に配置され、スタイルオプションはその下のコードを変更します。
- **公式フレーム**: QRdx の公式フレームもコミュニティアイテムです。`list_options` が ID をグループ別（祝日、季節、用途）に一覧表示するので、`frame:diwali-diya` や `frame:menu-cutlery` を `community_item` として使えます。
- **カスタムフレーム**: `style.frame` には、`get_community_item` で取得したコミュニティフレームのようなフレーム仕様を使い、`{ "style": "custom", "spec": … }` と指定できます。そのまま描画され、スコアが付けられます。修正でコードは変更されますが、フレームは変更されません。
- **`style.logo`**: クイックロゴアイコン（`wifi`、`location`、`phone`、`email`、`link`、`file`、`calendar`、`whatsapp`、`instagram`）、または [Simple Icons](https://simpleicons.org) のスラッグによるブランドロゴ（`spotify`、`paypal:white`）。`list_options` に人気のブランドスラッグが一覧表示されます。
- **エンジンオプション**: `style.eyeColors`（アイごとの `#RRGGBB` 色）、`moduleScale`（ドットサイズ、`0.5` から `1`）、`shape`（丸いコードには `circle`）、`autoLevel`、`logoOptions`（ロゴのサイズ、余白、位置、切り抜き、プレート）。指定どおりに描画され、スコアが付けられます。修正では変更されません。

<IfAvailable feature="fileStorage">
`logo_file_id` を使うと、代わりに QRdx にアップロードしたロゴを描画します。[API キー](#use-an-api-key)が必要です。
</IfAvailable>

ロゴは、エディタと同様に、覆うモジュールの数でスコアが付けられます。そのため、修正で誤り訂正が H に引き上げられたり、ロゴが削除されたりすることがあります。エディタがデフォルトで表示する QRdx マークは、ここでは描画されません。

結果の `qrdxStyle` は、エディタのスタイル JSON 形式のデザインです。これを `save_template` に渡すか、`generate_qr_code` に `style` として渡すと、同じデザインを別のサイズで描画できます。Image API の [`style`](/docs/developers/image-api#style) に渡すこともできます。`playground_url` は、[Playground](/playground) でデザインを開きます。含まれるのはスタイルだけで、ロゴやコンテンツは含まれません。含まれないものは `playgroundLeftOut` に示されます。

### generate_qr_code の入力 [#generate_qr_code-inputs]

入力は [Image API のパラメータ](/docs/developers/image-api#parameters)と同じです。`data`（必須）、`size`、`fg`、`bg`、`eyeColor`、`dotColor`、`body`、`eye`、`dot`、`level`、`margin`、`template`、`frame`、`frameText`、`logoIcon`、`logoFileId`、`item`（コミュニティアイテムの ID）、`style`（グラデーション、カスタムフレームなどを含む、`design_qr` が返すエディタのスタイル JSON）です。個別のオプションは `style` より優先され、`style` は `item` より優先されます。`include_svg` を `true` にすると、`.svg` ファイルとして保存する場合などのために、SVG マークアップもテキストで取得できます。マークアップは 50 から 150 KB になることが多く、会話を埋めてしまうため、デフォルトではオフです。

`generate_qr_code` はスキャンスコアを確認しません。確認には `design_qr` を使ってください。アップロードしたロゴ付きのコードには、公開の画像 URL はありません。Image API は、そのロゴをあなたのキーでのリクエストに対してのみ描画するためです。

### QR カード [#qr-card]

[MCP Apps](https://modelcontextprotocol.io/extensions/apps/overview) に対応したアプリでは、`design_qr` と `generate_qr_code` がチャットに QR カードも表示します。カードには、コード、エンコードされた内容（Wi-Fi コードではネットワーク名を表示し、パスワードは表示しません）、サイズ、誤り訂正またはスキャンスコア、**エディタで開く**ボタンがあります。エディタへのリンクには、`playground_url` と同様にスタイルだけが含まれます。

PNG と SVG のボタンは、アプリが許可する内容によって異なります。カードからファイルを保存できるアプリでは、ファイルが保存されます。それ以外では、Image API の URL がブラウザで開きます。そのため、`design_qr` のカードでは、ファイルを保存できるアプリでのみこれらのボタンが表示されます。そのコンテンツが画像 URL に含まれることはありません。リンクを開く前に、アプリが確認を求める場合があります。

MCP Apps に対応していないアプリでは、従来どおりのテキストと画像が返されます。クライアント開発者向けの情報:

- カードはリソース `ui://qrdx/qr-card`（`text/html;profile=mcp-app`）で、`resources/list` に一覧表示されます。両方のツールが `_meta.ui.resourceUri` でこれを指します。
- カードのデータは、ツール結果の `_meta` の `dev.qrdx/qr-card` に入っています。これはモデルではなくカード向けです。ツールは `structuredContent` を返しません。
- カードは、スタイルとスクリプトをインラインで含む単一の HTML ファイルです。読み込むのは Image API（`https://api.qrdx.dev`、セルフホストの場合は独自ドメイン）からのコード画像だけで、コンテンツセキュリティポリシー（`_meta.ui.csp.resourceDomains`）もそのホストのみを許可します。

カードが登場する前に QRdx を接続していた場合は、コネクタを削除して追加し直すか、ツールを更新してください。これで、アプリが新しいツールメタデータを取得します。

### コミュニティ [#community]

`search_community` は、公開されている[コミュニティ](/community)のフレーム、テーマ、コレクション（CC0 で無料）を、キーワード（`q`）、`type`、`tag` で検索します。`get_community_item` は、1件のアイテムと、それが適用するスタイルを返します。その ID を `design_qr` に `community_item` として、または `generate_qr_code` に `item` として渡します。同じデータは REST API の [`/v1/community/items`](/docs/developers/api/list-community-items) でも取得できます。

アイテムのテキストはコミュニティのメンバーが書いたものです。名前、説明、ハンドル、タグ、フレームのラベルは、短く、1行で、リンク、メールアドレス、マークアップを除いた形で返されます。また、すべての結果に、これらを指示ではなくデータとして扱うよう注意が添えられます。

## APIキーを使う [#use-an-api-key]

一部のツールでは、接続時に QRdx の [APIキー](/docs/developers/api-keys) が必要です。キーは `Authorization: Bearer qrdx_…` の形式で送信します。

- **`save_template`** は、デザインをテーマとして保存します。保存したテーマは、ダッシュボードの「テーマ」に一覧表示され、エディタでも選択できます。`codes:write` を持つキーが必要で、**Full access** のキーにはこの権限が含まれます。自分のワークスペースのキーで保存すると、自分のテーマに保存されます。チームのキーの場合は、作成者がオーナーまたは管理者で、かつプランにチームテーマが含まれていれば、チームの共有テーマに保存されます。保存数はプランの保存テーマ数の上限に含まれます(詳しくは[プランと制限](/docs/plans-and-limits)をご覧ください)。上限を超えると、ツールは API の `LIMIT_REACHED` エラー(`402`)を返します。キーがない場合は、キーの追加方法を示す `401` エラーを返します。
- **`save_barcode`** は、バーコード(フォーマット、値、任意のタイトル、描画オプション)をキーのワークスペースに保存します。保存したバーコードは、ダッシュボードの「バーコード」に一覧表示されます。`codes:write` を持つキーが必要です。バーコードはどのプランでも保存でき、フリーでは最大 1,000 件です。上限を超えると `LIMIT_REACHED`(`402`)を返します。
<IfAvailable feature="fileStorage">
- **アップロードしたロゴ**: [ダッシュボード → ファイル](/docs/files)にアップロードしたロゴを、ファイルIDで指定できます(`design_qr` では `logo_file_id`、`generate_qr_code` では `logoFileId`)。対応するのは 1 MB までの PNG または JPEG です。キーは、そのファイルを所有するワークスペースのものである必要があります。
</IfAvailable>

## プライバシーと制限 [#privacy-and-limits]

- これらのツールは、画像の生成、デザインのチェック、テキストの整形、公開コミュニティの閲覧を行います。書き込みを行うのは `save_template` と `save_barcode` だけで、保存を依頼したテーマまたはバーコードを API キーのワークスペースに保存します。生成したコードがサーバーに保存されることはありません。
- `generate_qr_code` と `generate_barcode` が返す画像URLには、エンコードしたデータが含まれます。Wi-Fi のパスワードなど、非公開のデータの場合は共有しないでください。
- リクエストは IP アドレスごとに 1 分あたり 120 件までで、`design_qr` は 20 件までです。キーを使う場合、`save_template` はさらにユーザーごとに 1 分あたり 30 件までに制限されます。

## セルフホストとローカル開発 [#self-hosting-and-local-development]

MCP サーバーは QRdx の Web アプリの一部のため、どのインスタンスでも `/api/mcp` で提供されます。

- **セルフホスト。** `NEXT_PUBLIC_APP_URL` が独自ドメインの場合、接続ページ、スニペット、インストールリンクには `https://<your-domain>/api/mcp` が使われます。
- **ローカル開発。** `bun run dev` を実行すると、`http://localhost:3000/api/mcp` で提供されます。接続ページには引き続き公開URLが表示され、ローカルのURLはヒントとして案内されます。クライアントを手元のマシンに向ければ、サーバーの変更を公開前にテストできます。

ブラウザで `/api/mcp` を開くと、接続ページにリダイレクトされます。MCP クライアントが HTML を要求することはないため、通常どおりサーバーに接続できます。
