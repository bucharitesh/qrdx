## ベースURLと認証 [#base-url-and-authentication]

REST API は `https://api.qrdx.dev/v1` で提供されています。同じルートは `https://qrdx.dev/api/v1` でも利用できます。

リクエストの認証には、`Authorization: Bearer` ヘッダーに [APIキー](/docs/developers/api-keys) を指定します。ほかの QRdx ユーザーに代わって動作するアプリは、代わりに [OAuth 2.0 アクセストークン](/docs/developers/rest-api#get-an-access-token) を送ります。[クイックスタート](/docs/developers/quickstart#create-an-api-key) では、キーの作成と最初のリクエストを行います。
