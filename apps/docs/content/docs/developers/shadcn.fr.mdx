QRdx publie un registre [shadcn/ui](https://ui.shadcn.com) de composants QR code basés sur la bibliothèque [`qrdx`](https://www.npmjs.com/package/qrdx). La CLI shadcn copie le code source dans votre projet : le code vous appartient et vous pouvez le modifier.

<NpmStatus package="qrdx" />

<PackageManagerTabs command="npx shadcn@latest add https://qrdx.dev/r/qr-code.json" />

Chaque composant dispose de sa propre page, avec un aperçu en direct, le code source, les étapes d'installation, des exemples et une référence de l'API.

[Essayer dans le Playground](/playground?open=code&lang=shadcn) : stylisez-y un code, puis copiez-le pour le composant QR Code du registre.

## Ce qui est installé [#what-gets-installed]

Chaque composant est un fichier unique dans `components/`. La CLI installe aussi `qrdx` (ainsi que `lucide-react` pour les icônes utilisées par certains composants) et ajoute les composants shadcn/ui sur lesquels il repose, tels que `button`, `card`, `dialog`, `dropdown-menu` ou `input`.

L'index complet se trouve à l'adresse [`https://qrdx.dev/r/registry.json`](https://qrdx.dev/r/registry.json).

## Utiliser l'espace de noms du registre [#using-the-registry-namespace]

Pour installer avec un nom court, ajoutez le registre à votre `components.json` :

```json
{
  "registries": {
    "@qrdx": "https://qrdx.dev/r/{name}.json"
  }
}
```

Ajoutez ensuite un ou plusieurs composants par leur nom :

<PackageManagerTabs command="npx shadcn@latest add @qrdx/qr-code @qrdx/qr-code-download @qrdx/qr-code-share-dialog" />

## Style [#styling]

Les composants utilisent des classes Tailwind avec les jetons de thème standard de shadcn/ui (`bg-card`, `border`, `text-muted-foreground`, `ring-ring`) ainsi que vos propres composants Button, Card, Dialog et Input : ils suivent donc votre thème et le mode sombre. Les QR codes gardent par défaut un fond clair, car des modules sombres sur une tuile claire sont lus par tous les lecteurs.

Les téléchargements PDF nécessitent le paquet facultatif `jspdf` (`npm install jspdf`).
