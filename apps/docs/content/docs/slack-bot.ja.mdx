QRdxにはSlack内でQRコードを作成するSlackアプリがあります。ボットが追加されているSlackワークスペースなら、誰でもリンクや任意のテキストからコードを作成できます。QRdxアカウントを連携すると、トラッキング付き（動的）のコードも作成できます。動的QRコードはスキャン数をカウントし、あとからリンク先を変更することもできます。

<IfAvailable feature="slackBot" id="add-the-bot-to-slack" title="ボットをSlackに追加する">

1. QRdxで[設定 → 連携 → Slack](/settings/integrations/slack)を開き、**ボットをSlackに追加**をクリックします。どのプランのQRdxアカウントでも追加できます。
2. Slackワークスペースを選択して承認します。ボットは、スラッシュコマンド、自身へのメンション、自身へのダイレクトメッセージの閲覧と、メッセージの投稿の許可を求めます。
3. 設定ページに戻ります。ページには、ボットを追加したSlackワークスペースが一覧表示されます。

同じSlackアプリは、チャンネルへの[アラート](/docs/notifications#slack-and-discord)の投稿にも使われます。ボットを追加してもアラートは有効になりません。アラートを追加してもボットは追加されません。

</IfAvailable>

<IfAvailable feature="slackBot" id="make-a-qr-code" title="QRコードを作成する">

| 場所 | 操作 | コードが表示される場所 |
| --- | --- | --- |
| 任意のチャンネル | `/qr` のあとにリンクまたはテキストを入力 | チャンネル内 |
| ボットが参加しているチャンネル | リンクまたはテキストを付けてボットにメンション | スレッド内 |
| ボットのダイレクトメッセージ | リンクまたはテキストを送信 | DM内 |
| 任意のメッセージ | **その他のアクション** → **QRコードを作成** | そのメッセージのスレッド内 |

返信はQRコード画像で、その下に内容、3つのボタン、後述のスタイルメニューが表示されます。ボタンは**PNGをダウンロード**（1024ピクセル）、**SVGをダウンロード**、**エディタで開く**です。エディタではデザインをさらに調整できます。リンクの場合はそのリンクが入力された状態でエディタが開きます。テキストの場合は、テキストがリンクに入ることはないため、空のエディタが開きます。

ショートカットは、メッセージ内の最初のWebアドレスからコードを作成します。Webアドレスがない場合は、メッセージ全文から作成します。ボットがそのチャンネルに参加していない場合は、コードはあなたにだけ表示され、アプリをチャンネルに追加するよう促すメモが付きます。

`/qr` だけを入力するか `/qr help` を入力すると、コマンド一覧が表示されます。QRコードにするには長すぎる内容の場合は、画像の代わりに短い説明が表示され、あなたにだけ見えます。

</IfAvailable>

<IfAvailable feature="slackBot" id="style-your-code" title="コードのスタイルを変更する">

各コードの下には、**デザイン**、**色**、**フレーム**、**ロゴ**の4つのメニューがあります。項目を選ぶとコードがその場で変わり、新しいダウンロードリンクが表示されます。選択は、その時点のコードを土台に重ねて適用されます。コードのスタイルを変更できるのは、コードを作成した本人だけです。ほかの人が選択すると、その人にだけ見えるメモがSlackに表示され、コードは変わりません。

デザインには、エディタ内蔵のデザインのうち、小さいサイズでも読み取りやすいものが用意されています。**Plain**を選ぶと白地に黒に戻ります。色を選ぶと、コード全体がその色になり、背景は白になります。フレームには「Scan me」ラベルが付き、ロゴにはエディタのクイックアイコンが使われます。

コードを作成するときに、リンクまたはテキストの後ろにオプションを追加してスタイルを指定することもできます。オプション名は[QRdx CLI](/docs/developers/cli)と同じです。

```text
/qr qrdx.dev --look modern --fg 0051ff --frame banner-bottom --frame-text "Scan me"
```

最初のオプションより前の部分がすべてコンテンツになります。デザインが最初に適用され、その上にほかのオプションが適用されます。たとえば `--look royal --fg 0051ff` なら、Royalの形のまま青色になります。オプションはメンションやダイレクトメッセージでも使えます。オプションまたは値が正しくない場合は、ボットがあなたにだけ知らせ、指定できる値を一覧で示します。

| オプション | 変更される内容 | 値 |
| --- | --- | --- |
| `--look` | エディタのプリセットから選ぶデザイン全体 | `plain`, `classic`, `modern`, `royal`, `folio`, `caffeine`, `retro`, `bordeaux`, `blossom` |
| `--fg`（または `--color`） | ドット。コーナーの目は、別途指定しない限り同じ色になります | `0051ff` のような16進数カラー、または `black`, `blue`, `green`, `red`, `purple`, `orange` |
| `--bg` | 背景 | `--fg` と同じ |
| `--eye-color` | 3つのコーナーの目 | `--fg` と同じ |
| `--dot-color` | コーナーの目の中心 | `--fg` と同じ |
| `--body` | ドットの形 | エディタの{facts.bodyPatterns}種類のドット形状のいずれか（`rounded`、`circle`、`classy` など） |
| `--eye` | コーナーの目の形 | {facts.eyeShapes}種類の目の形状のいずれか（`square`、`rounded`、`gear` など） |
| `--dot` | 目の中心の形 | {facts.eyeCentres}種類の中心形状のいずれか（`square`、`rounded`、`circle` など） |
| `--frame` | コードを囲むフレーム | `none`、または{facts.frameStyles}種類の内蔵フレームのいずれか（`banner-bottom`、`banner-top`、`speech-bubble`、`polaroid` など） |
| `--frame-text` | フレームのラベル（24文字まで） | 任意のテキスト。スペースを含む場合は引用符で囲みます。`--frame` がない場合は、コードの下のバナーに表示されます |
| `--template` | 装飾的な枠線 | `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `Halloween` |
| `--logo` | 中央のアイコン | `link`, `wifi`, `location`, `phone`, `email`, `whatsapp`, `instagram`, `file`, `calendar`, `none` |

スタイルを適用したコードは、投稿される前に、エディタと同じスキャンスコアでQRdxがチェックします。スマートフォンで読み取りにくいデザインの場合、QRdxは色を濃くする、形をシンプルにする、誤り訂正を強めるなどの調整を行い、その旨をコードの下に表示します。それでも十分でない場合（多くはコンテンツが長いときです）は、白地に黒のコードがメモ付きで届きます。`/qr` でスタイルを指定したコードは、チェックが終わってから投稿されるため、コマンドの送信から少し遅れて届きます。

**エディタで開く**を押すと、色、形、フレーム、枠線など同じデザインでエディタが開きます。ロゴのアイコンはリンクに含まれないため、エディタでもう一度選んでください。

ショートカットで作成した、あなたにだけ見えるコードにはメニューがありません。トラッキング付きのコードは、シンプルなデザインのままです。

</IfAvailable>

<IfAvailable feature="slackBot" id="tracked-codes" title="トラッキング付きコード">

通常のコードにはリンクそのものが入っています。トラッキング付きコードには短縮リンク（`https://qrdx.dev/q/<slug>`）が入っており、これがあなたのリンクへリダイレクトします。そのため、QRdxがスキャン数をカウントでき、リンク先も変更できます。Slackからトラッキング付きコードを作成するには、QRdxアカウントを一度連携します。

1. `/qr link` を実行します。あなたにだけ見えるボタンが表示され、押すとQRdxが開きます。このボタンは10分間有効です。
2. 求められた場合はQRdxにサインインします。次に**Slackでサインイン**をクリックし、`/qr link` を実行したのと同じSlackアカウントでサインインします。QRdxに伝わるのはSlackのユーザーとワークスペースだけで、QRdxはそれらが一致することを確認します。別のSlackアカウントでサインインした場合は、何も連携されません。
3. トラッキング付きコードの保存先にするQRdxワークスペースを選び、**確認**をクリックします。この連携によって、そのSlackアカウントがあなたのワークスペースにコードを作成できるようになるため、QRdxはまず[本人確認](/docs/help/privacy-and-security/two-step-verification#confirm-its-you)を求めます。
4. Slackに戻ると、連携したQRdxアカウントとワークスペースの名前を記載したダイレクトメッセージがボットから届きます。自分で連携した覚えがない場合は、`/qr unlink` を実行してください。
5. `/qr track` に続けて、`https://` または `http://` で始まるリンクを入力します。ボットに `track` とリンクを付けてメンションすることもできます。

コードは、短縮リンクとコードが属するQRdxワークスペース名とともにチャンネルに表示されます。ダッシュボード内のコードへ移動する**QRdxで開く**ボタンは、あなたにだけ見える別のメッセージで届きます。コードの名前は、リンク先サイト名に「from Slack」を付けたものになり、ワークスペースのコード一覧にほかのコードと同じように表示されます。

トラッキング付きコードには、ダッシュボードで作成したコードと同じルールが適用されます。ロールがコードの作成を許可していること、2段階認証を必須にしているワークスペースでは自分のアカウントで2段階認証が有効になっていること、そしてプランの有効な動的QRコードの上限が適用されます。上限に達している場合は、ボットがそのことを伝え、プランのページへのリンクを表示します。これらは毎回チェックされるため、ワークスペースから退出したりアクセス権を失ったりすると、そのワークスペースでは連携が機能しなくなります。

Slackアカウントごとに、Slackワークスペース1つにつき1つの連携を持てます。すでに連携済みのSlackアカウントで `/qr link` を実行すると、ページに連携先のQRdxワークスペースが表示され、別のQRdxアカウントへの連携である場合はその旨も表示されます。このときボタンは**連携を置き換える**となり、クリックするまで何も変わりません。連携は `/qr unlink` で解除できます。[設定 → 連携 → Slack](/settings/integrations/slack)の**連携済みのSlackアカウント**にある**連携を解除**でも解除できます。

QRdxワークスペースのオーナーと管理者は、[設定 → APIキーとアプリ](/dashboard?to=settings/developers)で、そのワークスペースに連携されているすべてのSlackアカウントを確認できます。表示されるのは、Slackワークスペース、SlackユーザーID、代理で操作するメンバー、連携された日時です。ここで**取り消す**を押すと連携が解除されます。ワークスペースで[監査ログ](/docs/help/teams/audit-log)が使える場合、`/qr track` で作成されたコードには、メンバーの名前に「via Slack」が付き、SlackのユーザーIDとワークスペースIDも記録されます。連携の取り消しも記録されます。

## ボットが保持する情報 [#what-the-bot-keeps]

ボットがメッセージを読み取るのは、誰かが `/qr` を実行したとき、ボットにメンションしたとき、ボットにダイレクトメッセージを送ったとき、そのメッセージでショートカットを使ったときだけです。メッセージの本文は保存しません。QRコード画像は QRdx の [Image API](/docs/developers/image-api) から取得されます。Slack がメッセージ内のリンクから読み込むため、アップロードは行われません。

QRdx は Slack ワークスペースごとに、その ID と名前、ボットの Slack ユーザー ID、ボットのトークン（暗号化済み）、追加した QRdx アカウントを保持します。連携済みの Slack アカウントごとには、Slack ユーザー ID、あなたの QRdx アカウント、選択したワークスペースを保持します。連携時の Slack でのサインインによって、これ以外の情報が増えることはありません。QRdx は Slack のユーザーとワークスペースを照合し、そのあとサインイン情報を破棄します。<IfAvailable feature="slackBot"> 連携済みの Slack アカウントは[データエクスポート](/docs/help/account-and-billing/export-your-data)に含まれます。</IfAvailable>

<IfAvailable feature="slackBot" id="remove-the-bot" title="ボットを削除する">

Slack でアプリのページを開き、**Remove App** を選択します（Slack の管理者に依頼することもできます）。すると QRdx は、その Slack ワークスペースのボットトークンと、そこで作成されたすべての Slack アカウント連携を削除します。すでに作成したコードは QRdx に残り、トラッキング対象のコードも引き続き動作します。

</IfAvailable>

## セルフホスティング [#self-hosting]

ボットは、「Add to Slack」のアラートと同じ Slack アプリを使用し、そこに署名シークレットを追加します。`SLACK_CLIENT_ID`、`SLACK_CLIENT_SECRET`、`SLACK_SIGNING_SECRET` を設定してください。本番環境では、ボットのトークンを暗号化する `INTEGRATION_ENCRYPTION_KEY` も設定します。これらが設定されていない場合、ボットのページとエンドポイントは存在しません。リポジトリ内の `plugins/slack/manifest.json` がアプリのマニフェストで、`plugins/slack/README.md` にそのマニフェストからアプリを作成する手順が書かれています。マニフェストには、`openid` ユーザースコープとリダイレクト URL `/api/integrations/slack/link/callback` が含まれています。これらは、アカウントを連携する際の Sign in with Slack に必要です。
