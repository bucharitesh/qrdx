`qrdx/preact` में React लाइब्रेरी के दोनों SVG कॉम्पोनेंट, `QRCodeSVG` और `QRCode`, Preact के लिए मिलते हैं। ये Preact के अपने `h` से बनते हैं, इसलिए `preact/compat` की ज़रूरत नहीं पड़ती, और ये React कॉम्पोनेंट जैसा ही SVG बनाते हैं।

## इंस्टॉल करें [#install]

```package-install
qrdx@latest
```

`preact` 10 या उसके बाद का वर्शन `qrdx` की एक optional peer dependency है। यह आपके app में पहले से होता है, और `react` की ज़रूरत नहीं है।

## QR कोड बनाएँ [#draw-a-code]

```tsx
import { QRCodeSVG } from "qrdx/preact";

export function MenuCode() {
  return (
    <QRCodeSVG
      value="https://example.com/menu"
      size={256}
      bodyPattern="rounded"
      frame={{ style: "banner-bottom", text: "Scan me" }}
      aria-label="QR code for the menu"
    />
  );
}
```

`QRCodeSVG` वे सभी ऑप्शन लेता है जो React का `QRCodeSVG` लेता है: पैटर्न, रंग और ग्रेडिएंट, लोगो (`imageSettings`), फ़्रेम, शेप, टेम्पलेट और Art QR। `class`, `style` या `aria-label` जैसी attributes `<svg>` पर लगती हैं, और फ़्रेम होने पर फ़्रेम के बाहरी `<svg>` पर लगती हैं।

`QRCode` में React के `QRCode` का लोगो शॉर्टकट जुड़ा है: `logo`, `logoOptions`, `hideLogo` और `scale`।

```tsx
import { QRCode } from "qrdx/preact";

<QRCode value="https://example.com" logo="/logo.png" level="H" />;
```

कोई prop बदलने पर दोनों कॉम्पोनेंट दोबारा बनते हैं, और कोई prop न बदले तो काम छोड़ देते हैं। React की तरह, props में दिए गए इवेंट हैंडलर `<svg>` पर नहीं लगाए जाते। उन्हें QR कोड के आसपास के किसी एलिमेंट पर लगाएँ।

## सर्वर रेंडरिंग [#server-rendering]

`preact-render-to-string` का `renderToString` वही SVG लिखता है जो `qrdx/core` का `toSVGString` लिखता है। फ़र्क़ सिर्फ़ escaping में है: Preact टेक्स्ट में `>` और `'` को जैसा है वैसा रखता है, जबकि core `&gt;` और `&#x27;` लिखता है। ब्राउज़र दोनों को एक जैसा पढ़ते हैं।

`hydrate` सर्वर का `<svg>` रखता है और उसे दोबारा नहीं बनाता। मार्कअप में कोई random id नहीं होती, इसलिए सर्वर और ब्राउज़र हमेशा मेल खाते हैं।

## डाउनलोड, मार्कअप और स्कैन स्कोर [#downloads-markup-and-the-scan-score]

कॉम्पोनेंट सिर्फ़ QR कोड बनाते हैं। डाउनलोड, `toSVGString`, स्कैन स्कोर और बाकी फ़ंक्शन `qrdx/core` से आते हैं। यह वही इंजन है जिसे कॉम्पोनेंट पहले से इस्तेमाल करते हैं, इसलिए यह दो बार बंडल नहीं होता।

```tsx
import { downloadQRCode } from "qrdx/core";
import { QRCodeSVG } from "qrdx/preact";

const options = { value: "https://example.com", size: 256 };

export function DownloadableCode() {
  return (
    <>
      <QRCodeSVG {...options} />
      <button
        type="button"
        onClick={() =>
          downloadQRCode(options, {
            format: "png",
            size: { width: 1024, height: 1024 },
          })
        }
      >
        Download PNG
      </button>
    </>
  );
}
```

`qrdx/core` की पूरी जानकारी [Vanilla JavaScript](/docs/vanilla-js) में है।

## preact/compat के साथ [#with-preactcompat]

अगर आपका app पहले से `react` को `preact/compat` का alias बनाता है, तो `qrdx` के React कॉम्पोनेंट भी काम करते हैं: `import { QRCodeSVG } from "qrdx"`। `qrdx/preact` बिना alias के वही QR कोड बनाता है, इसलिए Preact app में `qrdx` जोड़ते समय इसी को चुनें।
