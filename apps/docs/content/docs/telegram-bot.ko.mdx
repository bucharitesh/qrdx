QRdx 봇은 링크나 아무 텍스트를 Telegram 안에서 QR 코드로 만들어 줍니다. 무료이며 QRdx 계정이 필요하지 않습니다.

<IfAvailable feature="telegramBot">
시작하려면 [Telegram 연동 페이지](/integrations/telegram)에서 **Telegram에서 열기**를 클릭한 다음, 봇 채팅에서 **Start**를 탭하세요.
</IfAvailable>

## 개인 채팅 [#private-chat]

봇에 링크나 텍스트를 보내면 QR 코드와 버튼 네 개로 답합니다.

- **PNG 다운로드**는 저장하거나 공유할 수 있는 이미지를 엽니다.
- **SVG 다운로드**는 인쇄와 디자인 도구에 쓸 수 있는 벡터 버전을 엽니다.
- **편집기에서 열기**는 같은 디자인으로 QRdx 편집기를 엽니다. 웹 주소는 함께 전달됩니다. 다른 텍스트는 전달되지 않으니 편집기에 직접 붙여넣으세요.
- **스타일**은 채팅에서 바로 코드의 모양을 바꿉니다(아래 참고).

코드에는 줄바꿈을 포함해 보낸 내용이 그대로 담깁니다. `/help`(또는 `/start`)를 보내면 봇 사용법을 볼 수 있습니다. 텍스트가 너무 길어 QR 코드 하나에 담기지 않으면 봇이 알려 줍니다. 전체 텍스트가 있는 페이지의 링크를 사용하면 코드가 더 작아져 스캔하기 쉬워집니다.

## 코드 꾸미기 [#style-your-code]

코드 아래의 **스타일**을 탭하면 기존 버튼 대신 **모양**, **색상**, **프레임**, **로고** 버튼 네 개가 나타납니다. 각 버튼은 해당 옵션을 보여 주며, 코드에 현재 적용된 옵션 옆에는 ✓가 표시됩니다. 옵션을 탭하면 봇이 사진을 다시 그립니다. **뒤로**를 탭하면 네 가지 그룹으로 돌아가고, **완료**를 탭하면 다운로드 버튼이 다시 나타납니다. 각 변경은 현재 코드 위에 이어서 적용됩니다. 그룹에서는 코드를 요청한 사람만 스타일을 바꿀 수 있으며, 다른 사람이 탭하면 짧은 안내가 표시됩니다.

모양은 편집기의 기본 제공 디자인 중 작은 크기에서도 잘 읽히는 것들이며, **Plain**을 고르면 흰색 바탕에 검은색으로 돌아갑니다. 색상을 고르면 코드 전체가 흰색 바탕에 그 색으로 표시됩니다. 프레임에는 "Scan me" 라벨이 추가되고, 로고는 편집기의 빠른 아이콘입니다.

코드를 만들 때 링크나 텍스트 뒤에 옵션을 붙여 스타일을 지정할 수도 있습니다. 옵션 이름은 [QRdx CLI](/docs/developers/cli)와 같습니다. 개인 채팅, 그룹의 `/qr` 뒤, 인라인 모드에서 사용할 수 있으며, 인라인 모드에서는 아직 바꿀 메시지가 없으므로 이 방법이 코드를 꾸미는 유일한 방법입니다.

```text
qrdx.dev --look modern --fg 0051ff --frame banner-bottom --frame-text "Scan me"
```

첫 번째 옵션 앞의 내용이 모두 콘텐츠로 취급됩니다. 모양이 먼저 적용되고 그 위에 다른 옵션이 적용되므로, `--look royal --fg 0051ff`는 Royal의 모양을 유지한 채 파란색으로 표시합니다. 휴대폰이 `--`를 긴 대시로 바꿔도 동작합니다. 잘못된 옵션이나 값을 입력하면 사용할 수 있는 값을 나열한 답장이 옵니다.

| 옵션 | 바뀌는 항목 | 값 |
| --- | --- | --- |
| `--look` | 편집기의 프리셋 중 하나로 적용하는 전체 디자인 | `plain`, `classic`, `modern`, `royal`, `folio`, `caffeine`, `retro`, `bordeaux`, `blossom` |
| `--fg` (또는 `--color`) | 점, 그리고 따로 지정하지 않으면 모서리 눈 | `0051ff` 같은 16진수 색상, 또는 `black`, `blue`, `green`, `red`, `purple`, `orange` |
| `--bg` | 배경 | `--fg`와 같음 |
| `--eye-color` | 모서리 눈 세 개 | `--fg`와 같음 |
| `--dot-color` | 모서리 눈의 중심 | `--fg`와 같음 |
| `--body` | 점의 모양 | 편집기의 {facts.bodyPatterns}가지 점 모양 중 하나(예: `rounded`, `circle`, `classy`) |
| `--eye` | 모서리 눈의 모양 | {facts.eyeShapes}가지 눈 모양 중 하나(예: `square`, `rounded`, `gear`) |
| `--dot` | 눈 중심의 모양 | {facts.eyeCentres}가지 중심 모양 중 하나(예: `square`, `rounded`, `circle`) |
| `--frame` | 코드를 둘러싼 프레임 | `none` 또는 기본 제공 프레임 {facts.frameStyles}가지 중 하나(예: `banner-bottom`, `banner-top`, `speech-bubble`, `polaroid`) |
| `--frame-text` | 프레임의 라벨(최대 24자) | 아무 텍스트. 공백이 있으면 따옴표로 묶습니다. `--frame`이 없으면 코드 아래 배너에 들어갑니다 |
| `--template` | 장식용 테두리 | `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `Halloween` |
| `--logo` | 가운데 아이콘 | `link`, `wifi`, `location`, `phone`, `email`, `whatsapp`, `instagram`, `file`, `calendar`, `none` |

봇이 스타일을 적용한 코드를 보내기 전에, QRdx는 편집기와 같은 스캔 점수로 코드를 검사합니다. 휴대폰이 읽기 어려운 디자인이면 QRdx가 이를 조정하고(더 어두운 색, 더 단순한 모양, 더 높은 오류 정정) 캡션에 그 사실을 알립니다. 그래도 부족하면(대개 콘텐츠가 길 때) 안내와 함께 흰색 바탕에 검은색 코드가 전송됩니다.

**편집기에서 열기**는 색상, 모양, 프레임, 테두리 등 같은 디자인으로 편집기를 엽니다. 로고 아이콘은 링크에 포함되지 않으므로 편집기에서 다시 선택하세요.

## 어느 채팅에서나 인라인 모드 [#inline-mode-in-any-chat]

봇을 추가하지 않고도 어느 채팅에든 코드를 보낼 수 있습니다. 메시지 입력란에 `@`, 봇의 사용자 이름, 공백, 링크나 텍스트를 차례로 입력하세요. 잠시 후 입력란 위에 코드가 나타납니다. 탭하면 같은 버튼 세 개와 함께 전송됩니다. 메시지를 받는 사람들은 봇이 없어도 됩니다.

## 그룹 [#groups]

그룹에 봇을 추가한 다음 `/qr` 뒤에 링크나 텍스트를 붙여 보내세요. 예: `/qr https://example.com/menu`. 봇이 내 메시지에 답장으로 코드를 보냅니다.

그룹의 봇은 기본적으로 개인정보 보호 모드가 켜져 있으며, 이 봇도 켠 상태를 유지하므로 그룹의 대화를 볼 수 없습니다. Telegram은 봇을 대상으로 한 명령과 봇 자신의 메시지에 대한 답장만 전달합니다. 봇은 `/qr`, `/start`, `/help`에만 응답하고 나머지는 모두 무시합니다. 그룹에 봇이 둘 이상이거나 봇이 단순한 `/qr`에 응답하지 않으면 명령에 사용자 이름을 붙이세요. `/qr@` 뒤에 사용자 이름, 그다음 링크나 텍스트를 입력합니다.

## 개인정보 보호 [#privacy]

QRdx는 만든 코드를 저장하지 않으며, 봇은 답하기 위해서만 각 메시지를 읽습니다.

콘텐츠는 이미지 링크에 포함됩니다. Telegram은 각 코드의 그림을 내 텍스트와 선택한 디자인이 담긴 QRdx 링크에서 불러옵니다. 코드의 스타일을 다시 바꿀 때도 그 링크에서 둘 다 읽어 오므로, QRdx는 스타일을 바꾸기 위해 코드를 저장하지 않습니다. 다른 링크와 마찬가지로 로그와 캐시에 남을 수 있으니 비밀번호나 기타 비밀 정보는 코드로 만들지 마세요. Telegram은 다른 메시지와 마찬가지로 채팅의 메시지를 보관합니다.

짧은 시간에 코드를 많이 만들면 봇이 다음 코드를 만들기 전에 1분 기다려 달라고 요청합니다. 스타일을 바꿀 때마다 코드 한 개로 계산됩니다. 한꺼번에 많은 사람이 사용하면 바쁘다는 메시지가 나올 수 있습니다. 1분 뒤에 다시 시도하세요.

## 봇 제거 [#remove-the-bot]

개인 채팅에서는 봇의 프로필을 열어 차단하거나 채팅을 삭제하세요. 그룹에서는 관리자가 멤버 목록에서 봇을 제거합니다.

봇이 이미 보낸 코드는 채팅에 남습니다. 버튼은 QRdx로 바로 연결되므로 계속 작동합니다.

## 셀프 호스팅 [#self-hosting]

셀프 호스팅한 QRdx 서버에서 자체 봇을 운영할 수 있습니다. [@BotFather](https://t.me/BotFather)로 봇을 만들고, 서버에 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET`, `TELEGRAM_BOT_USERNAME`을 설정한 다음 설정 스크립트를 실행하세요. 자세한 단계는 [`plugins/telegram/README.md`](https://github.com/bucharitesh/qrdx/blob/main/plugins/telegram/README.md)에 있습니다. 세 변수가 모두 설정되기 전에는 봇의 경로가 404로 응답하며 사이트에 봇이 표시되지 않습니다.
