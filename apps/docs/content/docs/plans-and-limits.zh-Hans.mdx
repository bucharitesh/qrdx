QRdx 有三种套餐。通过 Playground 和 `qrdx` 库生成的静态二维码在所有套餐中均免费且不限量,无需账号。价格请参阅[定价页面](/pricing)。

| | 免费版 | Pro | Business |
| --- | --- | --- | --- |
| 价格(美元) | $0 | $5/月 或 $48/年 | $15/月 或 $144/年 |
| 价格(印度) | ₹0 | ₹199/月 或 ₹1,499/年 | ₹599/月 或 ₹4,999/年 |

来自印度的访客会看到以卢比计价的价格。结账由 [Polar](https://polar.sh) 处理,印度客户以 ₹ 付款,其他客户以美元付款,并在适用时加收当地税费。

Business 的年付也可以通过银行转账支付:请参阅[凭发票付款](/docs/help/account-and-billing/pay-by-invoice)。

</IfAvailable>

| 转化追踪 | 否 | 否 | 是 |

只有处于活跃状态的动态二维码才计入二维码数量限制,已归档的二维码不计入。扫描次数不计入任何限制,任何套餐都不会因流量而暂停二维码。唯一的扫描上限是你自己在二维码上设置的上限。

API 额度按工作区计算,并在 UTC 00:00 重置。每个计入额度的请求都会返回 `X-RateLimit-Limit`、`X-RateLimit-Remaining` 和 `X-RateLimit-Reset`,方便你随时查看。每分钟的限制请参阅 [REST API](/docs/developers/rest-api)。

## 工作区 [#workspaces]

限制按每个[工作区](/docs/teams)分别计算,工作区采用其所有者和[账单成员](/docs/teams#roles)中最高的套餐。每个人都有一个自己的工作区,创建账号时自动生成,并由本人担任所有者,因此使用其本人的套餐。在其他工作区中,只要有一位所有者使用 Business,所有成员都享有 Business 的限制;成员无需自己订阅。

创建更多工作区需要 Pro 或 Business。若工作区的所有者和账单成员都使用免费版,则有 1 个席位(仅你自己);使用 Pro 最多 3 个;使用 Business 则不限。席位包括成员(含所有者)以及待处理的邀请,因此请撤销不再需要的邀请以释放席位。如果所有者的套餐发生变化,现有成员会保留,仅新的邀请会被阻止。

## 超出限制、降级与取消 [#going-over-a-limit-downgrading-and-cancelling]

<Callout type="info">
  限制只会阻止新增内容。无论在哪种套餐下,包括降级、付款失败或取消之后,现有二维码都会继续跳转。这就是 [Never-Hostage 保障](/guarantee)。
</Callout>

- **超出限制:** 在回到限制以内之前,你无法再创建。你仍然可以编辑、归档和导出现有内容。
- **超出每日 API 额度:** API 调用会返回 `429`,直到 UTC 00:00。你的二维码会继续跳转,网站也会继续正常运行。
- **降级:** 二维码、落地页和已验证的自定义域名会继续工作。分析数据只显示新套餐所包含的历史时长。
- **取消:** 你的套餐会保持有效,直到已付费周期结束,之后你的账号将转为免费版。
- **付款失败:** 订阅失效后,与取消相同。不会暂停任何内容。

因你自己选择的原因而结束的二维码,例如设置了过期日期、暂停或扫描次数上限,会将扫描者引导到你的备用 URL 或一个中性的“此活动已结束”页面,绝不会引导到 QRdx 的页面。

## 账单 [#billing]

请在[定价页面](/pricing)升级。如需更改套餐、在月付与年付之间切换、更新银行卡或取消订阅,请在设置中打开 **Manage subscription**,这会带你进入 Polar 账单门户。一个订阅涵盖你的整个账号,因此在你已有订阅期间,套餐变更需通过该门户进行,而不是重新结账。

## 自托管 [#self-hosting]

[自托管](/docs/self-hosting)实例使用相同的套餐。这些限制定义在一个文件中,即 `apps/docs/lib/plans.ts`,你可以为自己的实例修改它。未配置 Polar 时,无法升级,所有账号都使用免费版的限制。
