QRdx 有三种套餐。通过 Playground 和 `qrdx` 库生成的静态二维码在所有套餐中均免费且不限量,无需账号。价格请查看[定价页面](/pricing)。

| | 免费版 | Pro | Business |
| --- | --- | --- | --- |
| 价格(美元) | $0 | $5/月 或 $48/年 | $15/月 或 $144/年 |
| 价格(印度) | ₹0 | ₹199/月 或 ₹1,499/年 | ₹599/月 或 ₹4,999/年 |

来自印度的访问者会看到以卢比计价的价格。结账由 [Polar](https://polar.sh) 处理:印度的客户以 ₹ 付款,其他客户以美元付款,并在适用时加收当地税费。

## 限额 [#limits]

| | 免费版 | Pro | Business |
| --- | --- | --- | --- |
| 动态二维码 | 10 | 不限 | 不限 |
| 扫描 | 不限 | 不限 | 不限 |
| 托管落地页 | 3 个,页脚带有“Made with QRdx” | 不限,无页脚 | 不限,白标,自定义 CSS |
| 分析数据历史 | 90 天 | 3 年 | 不限 |
| 自定义域名 | 无 | 5 | 25 |
| 自定义后缀(`qrdx.dev/q/spring-menu`) | 否 | 是 | 是 |
| 每个工作区的成员数 | 1(仅你自己) | 3 | 不限 |
| 更多工作区 | 否 | 是 | 是 |
| 智能路由、A/B 测试、UTM 标签 | 否 | 是 | 是 |
| 密码、定时、过期、扫描次数限制 | 否 | 是 | 是 |
| 再营销像素 | 否 | 是 | 是 |
| 转化跟踪 | 否 | 否 | 是 |
| 邮件摘要与提醒 | 否 | 是 | 是 |
| Webhook、Zapier 和 Slack | 否 | 否 | 是 |
| OAuth 应用([构建集成](/docs/developers/build-an-integration)) | 1 | 5 | 25 |
| 文件存储(单个文件上限) | 50 MB(10 MB) | 5 GB(100 MB) | 50 GB(250 MB) |
| 每月表单回复数 | 50 | 1,000 | 10,000 |
| 每日 API 请求数 | 1,000 | 10,000,另支持批量创建 | 100,000,另支持批量创建 |
| 每月 AI 艺术图片数 | 3 | 30 | 150,按工作区共享 |
| AI 主题生成次数 | 共 5 次 | 不限 | 不限 |
| 已保存的主题 | 10 | 不限,可与工作区共享 | 不限,可与工作区共享 |
| 已保存的[条形码](/docs/developers/barcode-api#saved-barcodes) | 1,000 | 10,000 | 100,000 |

只有处于启用状态的动态二维码才计入二维码数量限额,已归档的不计入。扫描不计入任何限额,也没有任何套餐会因流量而暂停二维码。唯一的扫描上限是你自己在二维码上设置的上限。

API 额度按工作区计算,并在 UTC 00:00 重置。每个计入额度的请求都会返回 `X-RateLimit-Limit`、`X-RateLimit-Remaining` 和 `X-RateLimit-Reset`,方便你随时查看。每分钟限额请参阅 [REST API](/docs/developers/rest-api)。

## 工作区 [#workspaces]

限额按[工作区](/docs/teams)分别计算,工作区使用其所有者和[账单成员](/docs/teams#roles)中最高的套餐。每个人都有一个自己的工作区,创建账号时自动生成,并以你为所有者,因此使用你的套餐。在其他工作区中,只要有一位所有者使用 Business,工作区内所有人都享有 Business 限额,成员无需各自订阅。

创建更多工作区需要 Pro 或 Business。所有者和账单成员都使用免费版的工作区有 1 个席位(仅你自己),使用 Pro 的最多 3 个,使用 Business 的不限。席位包括成员(含所有者)以及待处理的邀请,因此请撤销不再需要的邀请以释放席位。如果所有者的套餐发生变化,现有成员会保留,只会阻止新的邀请。

## 超出限额、降级与取消 [#going-over-a-limit-downgrading-and-cancelling]

<Callout type="info">
  限额只会阻止新建内容。在所有套餐下,现有二维码都会继续跳转,降级、付款失败或取消订阅之后也一样。这就是 [Never-Hostage 保障](/guarantee)。
</Callout>

- **超出限额:**在降到限额以内之前,无法再创建。你仍可编辑、归档和导出已有内容。
- **超出每日 API 额度:**在 UTC 00:00 之前,API 调用会返回 `429`。你的二维码会继续跳转,网站也会继续正常运行。
- **降级:**二维码、落地页和已验证的自定义域名会继续生效。分析数据只显示新套餐包含的历史范围。
- **取消:**你的套餐会保持有效,直到已付费周期结束,之后账号会转为免费版。
- **付款失败:**订阅失效后,等同于取消。不会暂停任何内容。

因你自己选择的原因而结束的二维码,例如设置了过期日期、暂停或扫描次数限制,会把扫描者引导到你的备用 URL 或一个中性的“This campaign has ended”页面,绝不会跳转到 QRdx 的页面。

## 账单 [#billing]

请在[定价页面](/pricing)升级。如需更改套餐、在按月和按年之间切换、更新银行卡或取消订阅,请在设置中打开 **Manage subscription**,它会带你进入 Polar 账单门户。一个订阅覆盖你的整个账号,因此在已有订阅期间,套餐变更需通过该门户办理,而不是重新结账。

## 自托管 [#self-hosting]

[自托管](/docs/self-hosting)实例使用相同的套餐。限额统一定义在一个文件 `apps/docs/lib/plans.ts` 中,你可以为自己的实例修改它。如果未配置 Polar,则无法升级,所有账号都使用免费版限额。
