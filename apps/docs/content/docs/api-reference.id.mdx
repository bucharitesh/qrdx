## Komponen [#components]

### QRCode [#qrcode]

Komponen utama untuk merender kode QR.

```tsx
import { QRCode } from 'qrdx';

<QRCode
  value="https://example.com"
  size={256}
  fgColor="#000000"
  bgColor="#ffffff"
/>
```

#### Props [#props]

| Prop | Tipe | Default | Deskripsi |
|------|------|---------|-----------|
| `value` | `string` | **wajib** | URL atau teks yang akan di-encode |
| `size` | `number` | `128` | Ukuran dalam piksel |
| `scale` | `number` | `1` | Pengali skala |
| `fgColor` | `ColorConfig` | `#000000` | Warna kode QR |
| `bgColor` | `ColorConfig` | `#ffffff` | Warna latar belakang |
| `eyeColor` | `ColorConfig` | `fgColor` | Warna penanda sudut |
| `dotColor` | `ColorConfig` | `fgColor` | Warna titik di dalam setiap mata sudut |
| `bodyPattern` | `BodyPattern` | `'circle'` | Pola titik data |
| `cornerEyePattern` | `CornerEyePattern` | `'gear'` | Pola penanda sudut |
| `cornerEyeDotPattern` | `CornerEyeDotPattern` | `'circle'` | Pola titik sudut |
| `hideLogo` | `boolean` | `false` | Sembunyikan logo. Tidak ada logo yang digambar kecuali `logo` diatur |
| `logo` | `string` | — | URL logo |
| `templateId` | `string` | `'default'` | [Bingkai yang digambar sebagai template](/docs/features/templates) (`'Arrow'`, `'StandardBox'`, …): seluruh gambar selebar `size` |
| `customTemplate` | `TemplateDefinition` | — | Bingkai yang Anda gambar dengan kode (menggantikan `templateId`) |
| `level` | `ErrorLevel` | `'Q'` | Koreksi kesalahan |
| `autoLevel` | `boolean` | `false` | Naikkan `level` ke H saat logo menutupi lebih dari 7% kode (`AUTO_LEVEL_LOGO_COVERAGE`) |
| `margin` | `number` | `0` | Margin dalam modul |
| `imageSettings` | `ImageSettings` | — | Pengaturan logo |
| `eyeColors` | `EyeColors` | — | Warna `outer` / `inner` per mata untuk `topLeft`, `topRight`, dan `bottomLeft`; masing-masing menimpa `eyeColor` / `dotColor` |
| `moduleScale` | `number` | `1` | Ukuran modul data, 0,5 sampai 1. Setiap pola berhenti pada ukuran terkecil yang masih dapat dipindai (`MODULE_SCALE_FLOOR`) |
| `frame` | `QRFrame` | — | Bingkai ajakan bertindak; lihat [Bingkai & cetak](/docs/features/frames) |
| `art` | `QRArt` | — | Memadukan logo atau foto ke dalam modul (Logo QR, Image QR); lihat [Art QR](/docs/features/art-qr) |
| `frameLabelMarkers` | `boolean` | `false` | Untuk editor: menandai setiap label bingkai `<text>` dengan `data-qrdx-frame-label` (`"text"`, `"secondaryText"`, atau id label spesifikasi). Unduhan dan ekspor tidak pernah menyertakannya |

Semua {facts.bodyPatterns} pola badan, {facts.eyeShapes} mata, {facts.eyeCentres} pusat mata, dan {facts.frameStyles} bingkai bawaan ditampilkan langsung di [Bentuk, mata, dan bingkai](/docs/styles).

## Fungsi Unduhan [#download-functions]

### downloadQRCode [#downloadqrcode]

Unduh kode QR dalam berbagai format.

```tsx
downloadQRCode(
  qrProps: QRProps,
  options: {
    format: 'png' | 'jpg' | 'webp' | 'svg' | 'pdf' | 'eps';
    size: { width: number; height: number };
    filename?: string;
    quality?: number; // WebP only: 0 to 1 for lossy; lossless when left out
  }
): Promise<void>
```

### getQRCodeDataUrl [#getqrcodedataurl]

Dapatkan sebagai data URL.

```tsx
getQRCodeDataUrl(
  qrProps: QRProps,
  format: DownloadFormat,
  size: DownloadSize,
  options?: { quality?: number } // WebP only
): Promise<string>
```

### getQRAsWebP [#getqraswebp]

Kode sebagai `Blob` WebP, lossless kecuali `quality` diatur. Jika browser tidak dapat meng-encode WebP (Safari), encoder lossless bawaan qrdx yang membuatnya. `canvasToWebP(canvas, options)` melakukan hal yang sama untuk canvas apa pun, dan `encodeWebPLossless(rgba, width, height)` meng-encode piksel RGBA tanpa DOM.

```tsx
getQRAsWebP(
  qrProps: QRProps,
  options?: { quality?: number }
): Promise<Blob>
```

### copyQRCodeToClipboard [#copyqrcodetoclipboard]

Salin ke papan klip.

```tsx
copyQRCodeToClipboard(
  qrProps: QRProps,
  size?: DownloadSize
): Promise<void>
```

### getSVGString [#getsvgstring]

Dapatkan markup SVG.

```tsx
getSVGString(qrProps: QRProps): Promise<string>
```

## Fungsi cetak dan pemindaian [#print-and-scan-functions]

Fungsi-fungsi ini didokumentasikan dengan contoh di halaman fiturnya masing-masing.

| Fungsi | Kegunaan | Dokumen |
|--------|----------|---------|
| `getQRAsSVG(props)` | Markup SVG untuk sebuah kode, termasuk bingkainya | [Bingkai](/docs/features/frames) |
| `getQRAsPrintPDF`, `downloadPrintPDF` | PDF vektor pada ukuran fisik yang tepat, dengan bleed, crop mark, dan CMYK (memerlukan `jspdf`) | [Ekspor siap cetak](/docs/features/frames#print-ready-export) |
| `downloadPrintSVG` | SVG siap cetak pada ukuran fisik yang tepat | [Ekspor siap cetak](/docs/features/frames#print-ready-export) |
| `getQRAsEPS`, `downloadPrintEPS` | EPS vektor untuk percetakan dan alat desain | [Unduhan](/docs/features/downloads) |
| `getScanScore(props)` | Memperkirakan seberapa andal sebuah desain dapat dipindai | [Apakah bisa dipindai?](/docs/features/frames#will-it-scan) |
| `getImageScanScore(image)` | Menilai gambar kode QR yang sudah Anda miliki (hanya di browser) | [Apakah bisa dipindai?](/docs/features/frames#will-it-scan) |
| `getQRAsPNG(props, { size })` | Byte PNG di Node biasa, tanpa DOM. Impor dari `qrdx/node`; memerlukan `@resvg/resvg-js` atau `sharp` terpasang | — |
| `scanQRPixels(pixels, expected)` | Memeriksa apakah piksel RGBA mentah ter-decode menjadi `expected`, juga saat diburamkan dan diperkecil; berjalan di Node | — |
| `getStylePairRisk(...)` | Memperingatkan tentang pasangan mata dan pola yang terlewat oleh beberapa pemindai | [Pola](/docs/features/patterns) |

## Tipe [#types]

### Tipe Inti [#core-types]

```tsx
type QRProps = {
  value: string;
  size?: number;
  level?: ErrorLevel;
  bgColor?: ColorConfig;
  fgColor?: ColorConfig;
  margin?: number;
  imageSettings?: ImageSettings;
  // ...
};

type ColorConfig =
  | string
  | { type: 'solid'; color: string }
  | LinearGradient
  | RadialGradient;

type ErrorLevel = 'L' | 'M' | 'Q' | 'H';
```

### Tipe Pola [#pattern-types]

```tsx
// The arrays BODY_PATTERN, CORNER_EYE_PATTERNS, CORNER_EYE_DOT_PATTERNS and
// FRAME_STYLES (and their zod schemas) are exported from 'qrdx/types'.
// FRAME_STYLES names the built-in frames; each is a frame spec in
// BUILT_IN_FRAMES (from 'qrdx').

type BodyPattern =
  | 'circle' | 'circle-large' | 'square' | 'diamond' | 'circle-mixed'
  | 'pacman' | 'rounded' | 'small-square' | 'vertical-line'
  | 'horizontal-line' | 'liquid' | 'liquid-horizontal' | 'liquid-vertical'
  | 'classy' | 'classy-rounded' | 'leaf' | 'plus' | 'hexagon' | 'star'
  | 'heart' | 'random-dots' | 'mosaic' | 'octagon';

type CornerEyePattern =
  | 'square' | 'rounded' | 'gear' | 'circle' | 'diya' | 'extra-rounded'
  | 'message' | 'pointy' | 'leaf' | 'drop' | 'octagon' | 'bevel'
  | 'squircle' | 'cushion' | 'shield' | 'petal' | 'leaf-reverse';

type CornerEyeDotPattern =
  | 'square' | 'rounded' | 'circle' | 'message' | 'message-reverse'
  | 'diya' | 'diya-reverse' | 'rounded-triangle' | 'leaf' | 'drop' | 'plus'
  | 'cross-rounded' | 'hexagon' | 'octagon' | 'flower' | 'heart'
  | 'squircle' | 'dots' | 'extra-rounded' | 'leaf-reverse' | 'drop-reverse';

// Retired (deprecated) values still render for saved designs but are not
// offered: RETIRED_CORNER_EYE_PATTERNS, RETIRED_CORNER_EYE_DOT_PATTERNS.

type EyeColors = {
  topLeft?: { outer?: ColorConfig; inner?: ColorConfig };
  topRight?: { outer?: ColorConfig; inner?: ColorConfig };
  bottomLeft?: { outer?: ColorConfig; inner?: ColorConfig };
};

type QRFrame = {
  style: FrameStyle; // "none" or a built-in frame, see FRAME_STYLES
  text?: string; // up to 24 characters, default "Scan me"
  color?: string;
  textColor?: string;
  secondaryText?: string; // banner-top-bottom, circle, menu-card
  secondaryColor?: string; // gradient-border end color
  fontScale?: number; // 0.5 to 1.5
};
```

## Penanganan Kesalahan [#error-handling]

Bungkus fungsi async dengan try-catch:

```tsx
try {
  await downloadQRCode(props, options);
} catch (error) {
  console.error('Failed:', error);
}
```

Kesalahan umum:
- URL gambar tidak valid
- Kegagalan jaringan
- Parameter ukuran tidak valid
- Konteks canvas tidak tersedia
