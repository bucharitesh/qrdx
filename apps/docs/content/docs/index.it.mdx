QRdx è una piattaforma open source (AGPL-3.0) per QR code. Crea QR code statici gratis e senza account, oppure accedi per usare QR code dinamici che puoi modificare dopo la stampa, pagine mobile e statistiche sulle scansioni.

Ogni QR code dinamico continua a reindirizzare su qualsiasi piano, anche dopo un downgrade o una cancellazione. È la [Garanzia Never-Hostage](/guarantee).
