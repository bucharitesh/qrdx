每个[动态二维码](/docs/dynamic-qr-codes)在[控制台](/dashboard?to=codes)中的页面上都有一个**访问与定时**面板（打开二维码，再打开其**设置**标签页）。更改会在下一次扫描时生效，你无需重新印刷二维码。

| 控制项 | 扫描者看到的内容 | 套餐 |
| --- | --- | --- |
| 暂停 | 你的备用网址，或一个中性的“此活动已暂停”页面 | 所有套餐 |
| 密码 | 密码页面；输入正确密码即可打开二维码 | Pro 和 Business |
| 开始时间 | 开始之前：显示“尚未开始”页面 | Pro 和 Business |
| 结束时间 | 结束之后：跳转到你的备用网址，或显示中性的“活动已结束”页面 | Pro 和 Business |
| 扫描次数上限 | 达到上限后：跳转到你的备用网址，或显示“已结束”页面 | Pro 和 Business |
| 备用网址 | 已暂停、已结束和超出上限的二维码将用户带到的地址 | Pro 和 Business |

## 暂停 [#pause]

开启**暂停二维码**可临时停用二维码，例如在两场活动之间；关闭即可恢复。暂停期间的扫描，如果你设置了备用网址，就会跳转到该网址，否则会显示一个说明活动已暂停的简单页面。暂停功能在所有套餐中均免费。

## 密码 [#password]

设置一个密码（至少 4 个字符），任何扫描该二维码的人会先看到密码页面。输入正确密码后，该浏览器会保持解锁状态 6 小时，对短链接及其打开的托管页面都有效。更改或移除密码后，所有用旧密码解锁的浏览器都会被重新锁定。

密码以 bcrypt 哈希形式存储；QRdx 之后无法向你显示密码，只能替换。同一访问者反复输入错误密码会被限速。

## 开始和结束日期 [#start-and-end-dates]

- **开始时间：**在此之前，扫描会显示“此活动尚未开始，请稍后再扫描此二维码。”
- **结束时间：**从此刻起，扫描会跳转到你的备用网址，或显示“此活动已结束”。

日期按你自己的时区输入，并以精确时刻存储，因此二维码在各地都会在同一时刻结束。结束时间必须晚于开始时间。

## 扫描次数上限 [#scan-limit]

上限的计数方式与你的分析数据相同：机器人、链接预览以及同一设备的快速重复扫描不会计入。二维码达到上限后，之后的扫描会跳转到你的备用网址或显示“已结束”页面。提高或清除上限即可重新开放二维码。

## 备用网址 [#fallback-url]

已暂停、已过期和超出上限的二维码将用户带到的地址，例如你的主页或下一个活动。如果没有设置，扫描者会看到一个简单的中性页面。该页面从不显示广告、QRdx 推广或注册提示，只显示活动状态和一个“举报滥用”链接。

备用网址与二维码的目标网址一样，要经过相同的安全检查。

## 套餐与降级 [#plans-and-downgrades]

- 暂停功能在所有套餐中均可使用。
- 设置或更改密码、日期、扫描次数上限或备用网址需要 Pro 或 Business。
- **降级绝不会使二维码结束或被锁定。**你在 Pro 期间设置的控制项会完全按原配置继续生效，并且你可以在任何套餐中移除其中任何一项。

## 链接安全检查 [#safety-checks-on-links]

QRdx 会在你保存时检查每个目标网址和备用网址：

- 被 [Google Web Risk](https://cloud.google.com/web-risk) 列为恶意软件、网络钓鱼或不受欢迎软件的链接会被拒绝（前提是服务器配置了 Web Risk 密钥）。如果 Web Risk 未能及时响应（大批量操作时可能出现），二维码仍会创建，并在稍后再次查询其链接；如果此时 Web Risk 将其列入名单，该二维码会被关闭，并由审核人员查看；
- `javascript:`、`data:` 及其他非网页链接会被拒绝；
- 在账户的前 7 天内，指向网址缩短服务、纯 IP 地址或形似域名（同形异义字）的二维码会以关闭状态保存，并**进入待审核**。面板会显示相应提示，你无需做任何其他操作，待检查通过后审核人员会开启该二维码。新账户每小时最多还可创建 30 个动态二维码，付费套餐的工作区则为 {facts.newPaidAccountHourlyCodes} 个。超出后，错误提示会告知还需多少分钟才能继续创建，控制台导入会暂停到那时。

任何人都可以在 [qrdx.dev/report-abuse](/report-abuse) 举报二维码。经审核后被关闭的二维码对所有人都会失效，其所有者无法重新开启。

## 自托管 [#self-hosting]

- `WEB_RISK_API_KEY`：已启用 Web Risk API 的 Google Cloud API 密钥。没有它时，链接只会按上述离线规则检查。
- `NEXT_PUBLIC_TURNSTILE_SITE_KEY` 和 `TURNSTILE_SECRET_KEY`：用于公开举报表单的 Cloudflare Turnstile（可选）。
- 解锁 Cookie 使用 `BETTER_AUTH_SECRET` 签名。
