By the end of this page you will have a styled QR code drawn into a plain HTML page, updated from your code and saved as a PNG, with a bundler or with a single script tag. `qrdx/vanilla` is the same engine the React components draw with, so it draws the same SVG, with every pattern, color, logo, frame and export, and it imports neither `react` nor `react-dom`.

<NpmStatus package="qrdx" />

## Before you start

- A page with a bundler (Vite, webpack, Parcel or any other) for steps 1 to 3. Without a bundler, skip to [step 4](#4-use-it-without-a-bundler).
- Node.js 18 or newer for the bundler.

## Build it

### 1. Install qrdx

```package-install
qrdx
```

`react` and `react-dom` are optional peer dependencies. You do not need them for `qrdx/vanilla` or `qrdx/core`.

### 2. Draw a code into an element

```html title="index.html"
<div id="qr"></div>
<script type="module" src="/main.js"></script>
```

```js title="main.js"
import { createQRCode } from "qrdx/vanilla";

const qr = createQRCode("#qr", {
  value: "https://example.com/menu",
  size: 256,
  margin: 4,
  bodyPattern: "rounded",
  frame: { style: "banner-bottom", text: "Scan for the menu" },
  "aria-label": "QR code for the menu",
});
```

An `<svg>` appears inside `#qr`: a 256 px code with rounded modules and a banner under it. `createQRCode(element, options)` takes an element or a CSS selector, and every option the React `QRCodeSVG` takes: patterns, colors and gradients, logos (`imageSettings`), frames, shapes, templates and art. Attributes such as `className`, `style` or `aria-label` go on the `<svg>`. The element is built with `createElementNS`, so no HTML is parsed.

{/* shot: vanilla-first-code | the framed code from main.js inside an otherwise empty page served by Vite | run the example in a Vite vanilla project */}

### 3. Update, export and remove it

```js title="main.js"
qr.update({ fgColor: "#1d4ed8" }); // redraws the code in place, now blue

qr.toSVGString(); // '<svg xmlns="http://www.w3.org/2000/svg" …'
await qr.toDataURL("png", { size: 1024 }); // "data:image/png;base64,…"
await qr.download({ format: "png", size: 1024, filename: "menu.png" });

qr.destroy(); // removes the <svg>
```

- `update` merges new options into the current ones and redraws. Pass `undefined` to drop an option. When the markup does not change, the page is not touched.
- `toDataURL` and `download` default to PNG at the code's own `size`. The formats are `png`, `jpg`, `webp`, `svg`, `pdf` and `eps`. A frame makes the image bigger than the code. PDF needs the optional `jspdf` package.
- `qr.svg` is the `<svg>` element and `qr.options` the current options.
- `destroy` removes the `<svg>`. `update` throws after it.

### 4. Use it without a bundler

```html title="index.html"
<div id="qr"></div>
<script type="module">
  import { createQRCode } from "https://cdn.jsdelivr.net/npm/qrdx/dist/vanilla.browser.mjs";

  createQRCode("#qr", { value: "https://example.com", size: 256, margin: 4 });
</script>
```

`dist/vanilla.browser.mjs` is the same API as one ES module. Add `@` and a version after `qrdx` in the URL to pin one. The same path works on unpkg.

The file leaves out the official frame library's data, so pages that do not use it do not download it. To use an official frame, import it from the file next to it:

```js title="index.html"
import { getOfficialFrame } from "https://cdn.jsdelivr.net/npm/qrdx/dist/frames-official.mjs";

const wifi = getOfficialFrame("wifi-card");
qr.update({ frame: { style: "custom", spec: wifi.spec } });
```

PDF export and the scan score load `jspdf` and `jsqr` when they run. A page that uses them maps both with an import map, placed before the module script:

```html title="index.html"
<script type="importmap">
  {
    "imports": {
      "jspdf": "https://cdn.jsdelivr.net/npm/jspdf@4/+esm",
      "jsqr": "https://cdn.jsdelivr.net/npm/jsqr@1/+esm"
    }
  }
</script>
```

## Markup and DOM nodes with qrdx/core

`qrdx/core` has everything the main `qrdx` entry has except the React components. It works in Node and in the browser.

```ts title="code.ts"
import {
  createQRCodeTree,
  renderToDOM,
  renderToString,
  resolveQRCodeProps,
  toSVGElement,
  toSVGString,
} from "qrdx/core";

// What <QRCodeSVG> renders, as a string (no DOM needed)
const svg = toSVGString({ value: "https://example.com", size: 256 });

// The same code as an <svg> element
document.body.append(toSVGElement({ value: "https://example.com" }));

// The code as plain { type, props, key } nodes, then markup or DOM nodes
const tree = createQRCodeTree({ value: "https://example.com" });
renderToString(tree);
renderToDOM(tree);

// <QRCode>'s logo API (logo, logoOptions, hideLogo, scale)
toSVGString(resolveQRCodeProps({ value: "https://example.com", logo: "/logo.png" }));
```

The output has no random ids, so markup rendered on a server matches the browser's. Downloads, the scan score and print-ready PDF and EPS come from the same functions as in the React library: `downloadQRCode`, `getQRCodeDataUrl`, `getScanScore`, `downloadPrintPDF` and the rest. For PNG on a server, use `getQRAsPNG` from `qrdx/node`.

## Custom templates without JSX

A template's `wrapper` receives the drawn code and returns it wrapped. `h(type, props, ...children)` writes one without JSX:

```js title="labelled-template.js"
import { h, toSVGString } from "qrdx/core";

const Labelled = {
  id: "Labelled",
  name: "Labelled",
  wrapper: (children, props) =>
    h(
      "svg",
      { viewBox: "0 0 300 340", xmlns: "http://www.w3.org/2000/svg" },
      h("g", { transform: "translate(20, 20) scale(0.87)" }, children),
      h("text", { x: "150", y: "325", textAnchor: "middle" }, props?.label)
    ),
};

toSVGString({
  value: "https://example.com",
  customTemplate: Labelled,
  customProps: { label: "Scan me" },
});
```

The same wrapper works in the React components when `h` is imported from `qrdx` instead.

## If something goes wrong

- **`qrdx: no element matches #qr`.** The script ran before the element existed. Put the `<script type="module">` after the element, or wait for `DOMContentLoaded`.
- **`qrdx: this QR code was destroyed`.** You called `update` after `destroy`. Create a new code with `createQRCode`.
- **`PDF export needs the optional "jspdf" package`.** Install `jspdf` next to `qrdx`, or add it to the import map on a page without a bundler.
- **The code is drawn but a phone does not read it.** Add `margin: 4`, keep dark modules on a light background, and check the design with `getScanScore`. See [A code won't scan](/docs/help/troubleshooting/wont-scan).
