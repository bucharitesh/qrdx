호스팅 랜딩 페이지는 QRdx가 `https://qrdx.dev/p/<slug>` 주소(또는 [사용자 지정 도메인](/docs/custom-domains))로 제공하는 모바일 페이지입니다. 모든 페이지에는 [동적 QR 코드](/docs/dynamic-qr-codes)가 함께 제공되므로, 코드를 인쇄한 뒤에도 페이지를 계속 수정할 수 있고 모든 스캔을 확인할 수 있습니다.

## 페이지 만들기 [#create-a-page]

1. [대시보드 → 페이지 및 폼](/dashboard?to=pages)을 열고 **새 페이지**를 클릭하세요. 또는 코드 목록에서 **새 코드**를 클릭한 다음 **웹사이트 링크** 대신 페이지 유형을 선택하세요.
2. {facts.hostedPageTypes}가지 [페이지 유형](#page-types) 중 하나를 고르고, 해당 갤러리에서 템플릿을 선택하세요.
3. **페이지 만들기**를 클릭하세요. 템플릿의 블록이 담긴 편집기가 열리고, **QR 코드**에서 QR 코드를 바로 다운로드할 수 있어요.

이미 웹사이트를 여는 코드를 인쇄하셨나요? 해당 코드를 열고 **유형 변경**을 클릭하면 같은 짧은 링크를 유지한 채 페이지로 바꿀 수 있습니다. [인쇄된 코드가 여는 대상 변경하기](/docs/help/dynamic-codes/change-the-type)를 참고하세요.

템플릿에는 페이지가 어떻게 구성되는지 볼 수 있도록 샘플 이름, 가격, 숫자, 사진이 들어 있습니다. 처음 게시하기 전까지는 편집기가 이를 직접 작성한 내용으로 바꾸라고 알려 드립니다.

## 페이지 유형 [#page-types]

모든 페이지 유형은 시작점일 뿐입니다. 어떤 페이지에든 원하는 블록을 추가할 수 있으며, 한 유형으로 만든 페이지를 다른 유형처럼 꾸밀 수도 있습니다.

| 페이지 유형 | 용도 | 기본 구성 |
| --- | --- | --- |
| **링크 목록** | 프로필 링크, 크리에이터, 팟캐스트 | 프로필 헤더, 링크, 소셜 아이콘 |
| **소셜 미디어** | 하나의 코드로 모든 프로필 연결 | 프로필 헤더, 네트워크별 한 줄과 내 핸들 |
| **비즈니스** | 상점, 미용실, 사무실 | 영업시간, 주소와 지도, 연락처, 행동 유도 버튼 |
| **vCard Plus** | 디지털 명함 | **연락처 저장**이 있는 연락처 카드 |
| **메뉴** | 카페, 레스토랑, 바 | 메뉴, Wi-Fi, 영업시간 ([자세히](/docs/forms-and-pages#menu)) |
| **쿠폰** | 할인과 무료 증정 | 바코드와 **사용하기**가 있는 쿠폰 ([자세히](/docs/forms-and-pages#coupon)) |
| **이벤트** | 파티, 콘퍼런스, 웨비나, 결혼식 | 캘린더에 추가 기능이 있는 이벤트 ([자세히](/docs/forms-and-pages#event)) |
| **앱 다운로드** | 모든 앱 스토어를 하나의 코드로 | 앱 다운로드 ([자세히](/docs/forms-and-pages#app-download)) |
| **피드백 및 폼** | 리뷰, NPS 설문, 가입 | 폼 및 리뷰 링크 ([자세히](/docs/forms-and-pages#forms)) |
| **제품** | 포장, 라벨, 행택 | 성분, 알레르기 유발 물질, 영양 정보, 인증, 관리 방법, GS1 Digital Link ([자세히](/docs/product-pages)) |
| **예약** | 미용실, 병원, 과외 | 서비스와 가격, 예약 요청 폼, 영업시간 |
| **결제 및 팁** | 팁 통, 기부, 청구서 | 결제 링크와 복사할 수 있는 은행 정보 |
| **부동산 매물** | 매매 또는 임대 주택, 오픈 하우스 | 가격과 정보, 사진, 중개인, 방문 요청 또는 방문 등록 폼 |
| **반려동물 ID 태그** | 목걸이 태그, 실종 동물 포스터 | 전화 버튼, 반려동물 정보, "찾았어요" 폼 |
| **의료 ID** | 태그, 손목밴드, 알레르기 카드 | 비상 연락처, 질환, 알레르기, 복용 약물 |
| **PDF** | 브로슈어, 매뉴얼, 문서 보관함 | 읽거나 다운로드할 PDF 또는 여러 파일 |
| **이미지** | 갤러리와 포트폴리오 | 사진 갤러리 |
| **MP3 / 오디오** | 음악, 팟캐스트, 음성 메시지 | 오디오 플레이어 |
| **비디오** | 제품 영상, 클립 | 비디오 |
| **플레이리스트** | 믹스, 오디오 투어, 오디오북 | 연속 재생되는 여러 트랙 |
| **사용자 지정 페이지** | 그 밖의 모든 용도 | 빈 페이지 또는 공지 |

파일 업로드가 설정되지 않은 곳에서는 업로드를 기반으로 하는 유형(PDF, 이미지, MP3 / 오디오, 비디오, 플레이리스트)이 선택 목록에 표시되지 않습니다.

**예약**은 예약 요청을 페이지의 [응답](/docs/forms-and-pages#responses)과 알림으로 보내며, 사용 중인 예약 도구로 연결되는 링크를 둘 수도 있습니다. 예약 가능한 시간을 실시간 캘린더로 보여 주지는 않으므로, 각 요청은 직접 확정해야 합니다.

**결제 및 팁**은 결제를 직접 처리하지 않습니다. 각 버튼은 결제 앱 자체의 페이지(PayPal, Venmo, Cash App, Revolut, Wise)를 열며, 은행 정보, UPI ID, 지갑 주소에는 복사 버튼이 있습니다.

**반려동물 ID 태그**와 **의료 ID** 페이지는 코드를 스캔하는 누구나 볼 수 있습니다. 반려동물을 발견한 사람이나 긴급 상황에서 나를 도와줄 사람에게 도움이 되는 정보만 추가하세요.

## 편집과 게시 [#edit-and-publish]

편집기에는 세 개의 탭과 실시간 휴대폰 미리보기가 있습니다. 미리보기에서 블록을 탭하면 해당 블록의 설정으로 이동합니다.

- **블록**: **블록 추가**로 블록을 추가하고, 드래그(또는 화살표 버튼)로 순서를 바꾸며, 삭제하지 않고 블록을 숨기거나 복제하거나 제거할 수 있어요. 블록마다 고유한 폼이 있으며, 문제(예: `https://`가 없는 링크)는 해당 블록에 표시되고 게시하기 전에 해결해야 합니다.
- **디자인**: [저장한 QR 테마](/dashboard?to=themes) 중 하나의 색상을 사용해 페이지를 인쇄된 코드와 맞추거나, 미리 정의된 팔레트를 고르거나, 각 색상을 직접 설정하세요. 글꼴, 모서리 둥글기, 단색·그라데이션·이미지 배경, 선택 사항인 로고를 지정할 수 있어요. **색상 맞춤**은 배경색과 강조색을 바탕으로 읽기 쉬운 텍스트와 카드 색상을 만들어 주며, 텍스트 대비가 낮으면 경고가 표시됩니다.
- **설정**: 공유 미리보기 설명과 이미지, 검색 엔진의 페이지 색인 허용 여부(기본값은 꺼짐), 비즈니스 페이지의 사용자 지정 CSS를 설정해요.

**게시**를 클릭하거나 <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>S</kbd>를 누르면 변경 사항이 실제 페이지에 반영됩니다. 게시하기 전에는 방문자에게 아무것도 바뀌지 않으며, 게시하지 않은 수정 내용은 브라우저에 보관되므로 탭을 닫은 뒤에도 복원할 수 있습니다. 게시할 때마다 하나의 버전으로 저장됩니다. 편집하는 동안 팀원이 같은 페이지를 게시하면, QRdx는 팀원의 변경 사항을 덮어쓰지 않고 새로 고치라고 안내합니다.

## 핵심 블록 [#core-blocks]

| 블록 | 표시되는 내용 |
| --- | --- |
| 프로필 헤더 | 사진 또는 로고, 이름, 소개, 선택 사항인 커버 이미지 |
| 텍스트 | 제목과 단락 (줄바꿈 유지) |
| 버튼 | 하나의 행동 유도: 웹 링크, 이메일 주소 또는 전화번호 |
| 링크 목록 | 링크 버튼 모음. Instagram, YouTube, WhatsApp 등의 사이트 아이콘 포함 |
| 소셜 아이콘 | 프로필을 둥근 아이콘, 버튼 또는 각 핸들이 있는 목록으로 표시 |
| 이미지 | 사진 또는 배너, 링크 연결은 선택 사항 |
| 비디오 | YouTube, Vimeo 또는 Loom 비디오. 방문자가 재생을 탭한 뒤에만 해당 비디오 사이트에서 불러옴 |
| 연락처 카드 | 이름, 직함, 전화번호, 이메일, 웹사이트, 주소, 빠른 동작(전화, WhatsApp, 이메일, 길찾기), **연락처 저장**, **공유** |
| 주소 및 지도 | Google Maps와 Apple Maps 길찾기가 연결된 주소, 선택 사항인 임베드 지도 |
| 영업시간 | 요일별 시간(분할 근무와 자정을 넘기는 시간 포함)과 사용자 시간대 기준의 **영업 중** 배지 |
| 상세 정보 | 라벨과 값을 목록 또는 타일 그리드로 표시 (침실 수, 품종, 혈액형, 순중량) |
| 제품 상세 정보 | 인증, 성분, 알레르기 유발 물질, 영양 정보 표, 탭하면 열리는 섹션, GTIN ([자세히](/docs/product-pages)) |
| 결제 링크 | PayPal, Venmo, Cash App, Revolut, Wise, UPI, 계좌 이체, 암호화폐 지갑. 버튼은 각 앱을 열고, 상세 정보에는 복사 버튼이 있습니다. 페이지가 결제를 직접 처리하지는 않습니다. |
| 구분선, 여백 | 레이아웃 보조 요소 |

### vCard Plus와 연락처 저장 [#vcard-plus-and-save-contact]

**연락처 저장**은 휴대폰의 연락처 앱에서 열 수 있는 vCard 3.0 파일(`.vcf`)을 다운로드합니다. 파일에는 이름, 회사, 직함, 전화번호, 이메일, 웹사이트, 주소, 소개, 페이지의 소셜 프로필, 사진이 포함됩니다. QRdx 저장소에 업로드한 사진은 파일에 포함되고, 다른 사이트에서 링크한 사진은 링크로 포함됩니다(QRdx는 다른 사이트의 이미지를 다운로드하지 않습니다). **공유**는 휴대폰의 공유 시트를 열거나, 컴퓨터에서는 페이지 링크를 복사합니다.

## 요금제 [#plans]

| | 무료 | Pro | Business |
| --- | --- | --- | --- |
| 호스팅 페이지 | 3 | 무제한 | 무제한 |
| "Made with QRdx" 푸터 | 표시됨 | 제거됨 | 제거됨 |
| 화이트 라벨 (브라우저 아이콘에 내 로고 사용, QRdx 브랜딩 없음) | — | — | ✓ |
| 사용자 지정 CSS | — | — | ✓ |

한도는 새 페이지를 만드는 것만 막습니다. 이미 만든 페이지는 요금제를 다운그레이드한 뒤에도 모든 요금제에서 계속 작동합니다. Business에서 다운그레이드하면 사용자 지정 CSS만 적용되지 않습니다. 또한 각 페이지는 요금제에 포함된 동적 QR 코드 한도 중 하나를 사용합니다. [요금제와 한도](/docs/plans-and-limits)를 참고하세요.

### 사용자 지정 CSS (Business) [#custom-css-business]

**설정 → 사용자 지정 CSS**에 일반 CSS를 작성하세요. 규칙은 페이지 안에서만 적용됩니다. 모든 선택자의 범위가 페이지 콘텐츠로 제한되며, 각 블록은 `.lp-block-<type>`으로 지정할 수 있습니다. 예를 들면 `.lp-block-links a` 또는 `.lp-block-contact h1`입니다. 보안을 위해 CSS에서는 파일을 불러올 수 없고(`url()`, `@import`, `@font-face`), 백슬래시 이스케이프도 사용할 수 없으며, at-rule은 `@media`, `@supports`, `@container`, `@keyframes`만 지원합니다.

## 방문자가 받는 경험 [#what-visitors-get]

- 휴대폰에 맞춰 만든 빠른 서버 렌더링 페이지이며, QRdx 분석 스크립트나 채팅 스크립트는 없습니다. 추적 픽셀은 코드에 직접 추가한 경우에만 로드됩니다.
- **검색 엔진에 표시**를 켜지 않으면 검색 엔진에 노출되지 않습니다.
- 채팅 앱과 소셜 네트워크용 공유 미리보기(제목, 설명, 이미지)를 제공합니다. 비밀번호로 보호된 코드는 미리보기에 페이지 정보를 절대 보여주지 않습니다.
- 화이트 라벨 페이지를 포함한 모든 페이지에 작은 **악용 신고** 링크가 있습니다.

[코드 제어](/docs/code-controls)의 비밀번호 보호, 시작일과 종료일, 스캔 한도, 일시 중지는 페이지와 **연락처 저장** 파일에도 적용되며, 누군가 페이지 링크를 직접 열 때도 마찬가지입니다.
