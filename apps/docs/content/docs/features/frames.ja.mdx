「Scan me」フレームを追加し、公開前にデザインがスキャンできるかを確認し、正確な実寸のベクターファイルをエクスポートします。

## 行動喚起フレーム [#call-to-action-frames]

QRdxが描画するフレームはすべてフレーム仕様です。図形、ラベル、色を記述した小さなJSONです。1つのエンジンがすべての仕様を描画するため、フレームはSVG、PNG、PDF、EPSのどれでも同じ見た目になります。QRdxには{facts.frames}個のフレームがあります。内訳は、{facts.frameStyles}個の組み込みフレームと{facts.officialFrames}個の[公式フレーム](#official-frames)です。独自のフレームを作ることも、[コミュニティ](/community/frames)から選ぶこともできます。

`frame` プロパティで、コードの周囲にフレームを描画します。`QRCode`、`QRCodeSVG`、`QRCodeCanvas`、`getQRAsSVG`、`getQRData`、およびすべてのダウンロードヘルパーで使えます。

```tsx
import { QRCode } from "qrdx";

<QRCode
  value="https://example.com/menu"
  frame={{ style: "banner-bottom", text: "Scan for the menu", color: "#1e3a8a" }}
/>
```

フレームはコードの**周囲**に追加されます。出力サイズは大きくなりますが、QRモジュールとクワイエットゾーンが覆われることはないため、スキャンのしやすさは変わりません。コードの背景色の明るい隙間が、コードとフレームを分けます。

### 組み込みフレーム [#built-in-frames]

組み込みフレームは `style` で指定します。オプションで、仕様のラベルと色を設定します。

| オプション | デフォルト | 備考 |
| --- | --- | --- |
| `style` | — | 以下の{facts.frameStyles}個の組み込みフレームのいずれか、または `none` (`FRAME_STYLES`) |
| `text` | `"Scan me"` | 最大24文字。ラベルを非表示にするには `""` を渡します |
| `color` | `#000000` | フレームの色 (`gradient-border` では開始色で、デフォルトは紫) |
| `textColor` | フレーム上は白、明るい領域では `color` | ラベルの色 |
| `secondaryText` | なし | 2つ目のラベル（最大24文字）。`banner-top-bottom` の下部バンド、`circle` の下側の弧、`menu-card` のフッターになります |
| `secondaryColor` | `#db2777` | `gradient-border` の終了色 |
| `fontScale` | `1` | ラベルのサイズ（0.5から1.5）。ラベルは収まるように縮小されます |

`style` ごとの組み込みフレームは次のとおりです。

- バナーと枠線: `banner-bottom`、`banner-top`、`banner-top-bottom`、`border`、`rounded-border`、`gradient-border`、`focus` (四隅のブラケット)
- 吹き出し: `speech-bubble`、`speech-bubble-top`、`chat-bubble`
- バッジ: `circle` (リングに沿って配置した文字)、`badge` (リボン)、`sticker` (影付きの型抜き)
- オブジェクト: `polaroid`、`phone`、`ticket`、`tag` (穴のあるぶら下げ札)、`envelope`、`menu-card`

これらの名前はそれぞれエンジン内の仕様を表しており、今後も有効です。これらを使う保存済みデザイン、Image API のリンク、CLIフラグ、コードは、引き続き同じフレームを描画します。枠線のように、ラベルがないときにラベルの行を省くフレームは、これまでどおり省きます。

`BUILT_IN_FRAMES` は、名前と仕様の一覧です (`BUILT_IN_FRAME_SPECS` は `style` ごとの仕様です)。`frameSpecOf` は任意のフレームが描画する仕様を返し、`getFrameColors` はそのフレームが使う色を返します。

```tsx
import { BUILT_IN_FRAMES, frameSpecOf, getFrameColors } from "qrdx";

BUILT_IN_FRAMES.map((frame) => frame.name); // ["Banner", "Top banner", …]

// A built-in style's spec, or a custom frame's own
const ticket = frameSpecOf({ style: "ticket" });

// The frame's options, else its spec's defaults
getFrameColors({ style: "border", color: "#1e3a8a" });
// { frame: "#1e3a8a", text: "#1e3a8a", accent: "#1e3a8a" }
```

ラベルと色以外も変更したい場合は、組み込みの仕様からカスタムフレームを作り始めます。`{ style: "custom", spec: frameSpecOf({ style: "ticket" }) }` は同じチケットを描画し、その図形を編集できます。

すべてのフレームは、ブラウザー上でデコードして確認できます。[シェイプ、アイ、フレーム](/docs/styles#frames)をご覧ください。どのフレームも、不透明な色の単純な図形とテキストだけでできているため、SVG、PNG、PDF、EPSのエクスポートは一致します (グラデーション枠は細かい単色のステップで描画され、`circle` フレームの曲線状の文字は、どの形式でも回転したテキストです)。

```tsx
<QRCode
  value="https://example.com"
  frame={{ style: "circle", text: "Scan me", secondaryText: "example.com", fontScale: 1.2 }}
/>
```

ラベルにはシステムフォントスタックを使うため、ダウンロードは発生しません。出力サイズは大きくなるので、最終的な幅と高さが必要なときは `getFrameDimensions(size, frame)` を使います。

```ts
import { getFrameDimensions } from "qrdx";

getFrameDimensions(400, { style: "banner-bottom" }); // { width: 496, height: 568 }
```

`FRAME_STYLES`、`frameSchema` (zod)、および `QRFrame` / `FrameStyle` 型も、サーバー側の検証用に `qrdx/types` からエクスポートされています。`GRADIENT_FRAME_DEFAULTS` (グラデーション枠のデフォルト色) と `FRAME_GAP_RATIO` は、これらを使っていたコードのために引き続きエクスポートされています。各フレームの隙間は、その仕様のパディングです (`getFrameGapRatio`)。

### Playgroundでの操作 [#in-the-playground]

**デザイン → フレーム** には、すべてのフレームを選ぶ1つのピッカーがあります。**クラシック**グループには、組み込みフレームと[テンプレート](/docs/features/templates) (矢印、スタンダードボックスなど) があり、その隣に図形コード、公式フレーム、保存したフレームが並びます。どれを選んでも、直前のものと置き換わります。すべてのフレームは同じ方法で編集します。ラベル、2行目、色、文字サイズを設定でき、アイコンのあるフレームではアイコンも設定できます。組み込みフレームを使ったデザインは `style` 名を保持するため、リンク、画像URL、コードスニペットは短いままです。

**図形コード**グループでは、コード自体を図形にできます。装飾的なドットによる円やハート、またはアップロードした図形です ([`shape`](/docs/features/patterns#circle-codes))。図形コードはフレームの代わりになります。図形コードを選ぶとフレームが解除され、フレームを選ぶと図形が解除されます。

### CLIでの操作 [#in-the-cli]

```bash
qrdx generate "https://example.com/menu" --frame banner-bottom --frame-text "Scan for the menu" -o menu.png
```

`--frame-color` と `--frame-text-color` には16進カラーを指定します。`--frame` なしでテキストや色を渡すと、`banner-bottom` が使われます。

### フレーム仕様 [#frame-specs]

フレーム仕様は、`kind: "qrdx.frame"`、`version: 1`、`artboard` のサイズ、コードを置く `qr` ボックス、デフォルトの `colors`、コードの背後に描画する `shapes`、そして `labels` を持つJSONです。図形には、矩形 (任意で穴付き)、円とリング、楕円、多角形、パス、線、組み込みアイコンがあります。塗りには、テーマトークン (`frame`、`text`、`accent`、`background`)、16進カラー、2色の混合、またはグラデーションを使えます。仕様にはマークアップ、リンク、画像は含まれません。自分で書いていない仕様は、保存する前に `qrdx/types` の `frameSpecSchema` または `getFrameSpecIssues` で確認してください。エンジンも描画前に再度確認します。

組み込みフレームとテンプレートで、次の任意フィールドが加わりました。これらのないスペックは、従来どおり描画されます。

| フィールド | 機能 |
| --- | --- |
| `labels[].collapse` | `{ y, height }`。ラベルにテキストがないとき、`y` から `y + height` までのバンドが切り取られます。その下の行は上に移動し、アートワークは短くなります。バンドの内側に完全に収まる図形は除かれ、バンドをまたぐ図形は短くなります。バンドは、コード、そのパディング、他のバンドをまたげません。 |
| `qr.plate` | `"opaque"` (デフォルト)、`"background"`、`"none"`。エンジンは、コードの背景色のプレートをコードの下に描画します。その背景が透明の場合、`"opaque"` はプレートを描画し、`background` は白で塗りつぶすため、クワイエットゾーンからアートワークが透けることはありません。`"background"` は透明のままにし、プレートを描画しません。プレートの下にあるのが `background` の塗りだけ、または穴にプレートが収まるリングだけの場合にのみ使えます。`"none"` はプレートをまったく描画しないため、コード自身の背景とマージンだけが明るい余白になり、`qr.padding` は4%未満にできます。テンプレートではこれを使っています。 |
| `stroke` | 矩形、円、楕円、多角形、パスに指定する `{ color, width }`。図形の縁を中心とした輪郭線で、塗りの後に描画され、アートボードの短辺の最大10%までです。Halloweenテンプレートは、これでカボチャの輪郭を描いています。 |
| `colors.text` | 16進カラー、または `frame`、`accent`、`background`、16進カラーの混合。たとえばグラデーション枠のラベルには `{ "mix": ["frame", "accent"], "amount": 0.5 }` を使います。これはデフォルト値で、`textColor` が指定されていればそちらが優先されます。 |

テキストラベルの行は、コードに重ならず、最大のテキストサイズ (`fontScale` 1.5) でも大文字がパディングに入り込まない限り、プレートのパディングにかかってもかまいません。枠線フレームは、この方法でラベルをコードのすぐ下に配置しています。

qrdx 0.0.51 以前は、これらのフィールドを使う仕様や、ラベルの行をパディング内に置く仕様を受け付けません。そのような仕様を別の場所で描画する前に、エンジンを更新してください。

## 公式フレーム [#official-frames]

組み込みフレームに加えて、QRdxには{facts.officialFrames}個の公式フレームがあります。行動喚起、レストランとカフェ、店舗とパッケージ、美容とウェルネス、イベントと結婚式、ホテルと旅行、不動産、車と駐車場、健康と教育、スポーツとフィットネス、ビジネスとSNS、非営利団体と地域グループ向けの、すぐに使えるデザインです。そのうち{facts.seasonalFrames}個は祝祭や季節向けで、旧正月、ホーリー、イード、ディワリから、ハヌカ、イースター、感謝祭、クリスマスまでそろっています。どれも、変更可能なラベルと色を持つフレーム仕様で、CC0で公開されており、スマートフォンで読み取る距離でスキャンできることをテスト済みです。

[Playground](/playground) で**フレーム**を開きます。名前、用途、祝祭で検索するか、グループを選びます。これから迎える祝祭や季節のフレームは、先頭に表示されます。@qrdx が公開している[コミュニティ](/community/frames)でも見つかります。

エンジンは、これらを `OFFICIAL_FRAMES` としてエクスポートしています。

```tsx
import { getOfficialFrame, QRCode } from "qrdx";

const diwali = getOfficialFrame("diwali-diya"); // undefined for an unknown id

{diwali && (
  <QRCode
    value="https://example.com/offers"
    frame={{ style: "custom", spec: diwali.spec, text: "Scan for offers" }}
  />
)}
```

`OFFICIAL_FRAME_INDEX` は、仕様を除いたすべてのフレームの一覧です。ピッカーでライブラリ全体を表示し、必要になったときだけ仕様を読み込めます。[Image API](/docs/developers/image-api#community-items) と [MCPサーバー](/docs/developers/mcp) では、公式フレームをコミュニティアイテムとして使います。たとえば `item=frame:diwali-diya` のように指定します。

## スキャンできるか確認する [#will-it-scan]

`getScanScore` は、デザインがどのくらい確実にスキャンできるかを推定します。ブラウザー上で動作し、必要に応じて [jsQR](https://github.com/cozmo/jsQR) を読み込みます。

```ts
import { getScanScore } from "qrdx";

const { score, grade, checks } = await getScanScore({
  value: "https://example.com",
  bodyPattern: "circle",
  cornerEyePattern: "gear",
});
// score: 0–100, grade: "great" | "ok" | "risky" | "fails"
// checks: [{ id, passed, message, fix? }]
```

チェックする項目は次のとおりです。

- **96px、160px、320pxでのデコード。** それぞれの幅でデザインを描画し、カメラで撮影したようなぼかしとコントラストの低下を加えたうえで、少しずつ縮尺を変えて数回デコードします。
- **コントラスト**：コードのすべての色（グラデーションの色stop、アイの色、ドットの色を含む）と背景とのコントラスト、およびコードが明るい背景に暗い色で描かれているかどうか。
- **ロゴの占有率**：エラー訂正レベルで復元できる範囲との比較。
- **クワイエットゾーン**：マージンに、フレームによって加わる余白を足したもの。
- **アイの形状のリスク**：`circle` のアイは、一部のスキャナーアプリで読み取れないことがあります（また、廃止された `curly` のアイが保存済みのデザインで使われている場合は、厳密なデコーダーで失敗します）。
- **スタイルの組み合わせ**（`style-pair`）：デコードテストで一緒に失敗した形状の組み合わせです。たとえば `small-square` のドットと四角いアイの組み合わせや、保存済みデザインに残っている廃止された中心パーツなどが該当します（`getStylePairRisk` を参照）。

`getImageScanScore(fileOrImage)` は、既存の画像に対して同様のチェックを行います。デコードした内容に加え、ピクセルから測定したデコード、コントラスト、極性、クワイエットゾーン、解像度のチェック結果を返します。[スキャンチェッカー](/tools/scan-checker)はこの関数をもとに作られています。

<Callout type="info">
  このスコアは、1つのオープンソースのデコーダーに基づくヒューリスティックです。スマートフォンのカメラアプリはより寛容な場合が多いため、目安として使い、重要な印刷物は実際にスキャンしてテストしてください。
</Callout>

## 印刷用エクスポート [#print-ready-export]

`downloadPrintPDF` は、正確な物理サイズのベクターPDFを書き出します。モジュール、アイ、フレームはベクターパスです（ロゴはラスター画像のままです）。

```ts
import { downloadPrintPDF, downloadPrintSVG, getPrintLayout } from "qrdx";

const props = { value: "https://example.com", frame: { style: "banner-bottom" } } as const;

await downloadPrintPDF(props, {
  size: 40, // width of the code itself
  unit: "mm", // or "in"
  bleed: 3, // millimetres on every side
  cropMarks: true,
  colorMode: "cmyk",
});

await downloadPrintSVG(props, { size: 1.5, unit: "in" }); // width="…in" height="…in"

const layout = getPrintLayout(props, { size: 40 });
layout.trimWidth; // finished width in mm, frame included
layout.maxScanDistance; // 400 (mm)
```

- `size` はコードの幅です。フレームを付けると、完成サイズはその分大きくなります。
- 裁ち落としを付けると、背景（または四角いフレームの色）が仕上がり線の外側まで広がるため、裁断しても白い隙間が残りません。トンボは裁ち落としの外側に配置されます。
- `colorMode: "cmyk"` は簡易的な変換（`rgbToCmyk`：K = 1 − max(R, G, B)、ICCプロファイルなし。純粋な黒はKのみで印刷されます）を使います。ブランドカラーを正確に再現したい場合は、印刷会社にカラーマネジメントされた変換を依頼してください。
- 線形グラデーションと放射状グラデーションは、PDF内で滑らかなシェーディングとして印刷されます。PDFがCMYKの場合はCMYKになります。印刷用SVGでもグラデーションは保持されますが、RGBのままです。
- PDF内のフレームテキストにはHelvetica Boldを使用するため、Latin-1以外の文字は表示されない場合があります。それ以外の文字体系にはSVGを使用してください。
- `getQRAsPrintPDF` と `getQRAsPrintPDFBuffer` は、ダウンロードせずにファイルを返します。Nodeでも動作します。

**印刷サイズの目安：** コードは、幅のおよそ10倍の距離からスキャンできます。つまり、サイズ ≈ スキャン距離 ÷ 10 です（20cmの距離なら幅2cm）。密度の高いコードはより大きなサイズが必要です。[印刷サイズ計算ツール](/tools/print-size)はこの点も考慮します。
