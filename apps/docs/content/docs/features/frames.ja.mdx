「Scan me」フレームを追加し、公開前にデザインがスキャンできるかを確認して、正確な物理サイズのベクターファイルを書き出せます。

## 行動喚起フレーム [#call-to-action-frames]

`frame` プロパティを使うと、コードの周囲に短いラベル付きのフレームを描画できます。`QRCode`、`QRCodeSVG`、`QRCodeCanvas`、`getQRAsSVG`、`getQRData` と、すべてのダウンロードヘルパーで使えます。

```tsx
import { QRCode } from "qrdx";

<QRCode
  value="https://example.com/menu"
  frame={{ style: "banner-bottom", text: "Scan for the menu", color: "#1e3a8a" }}
/>
```

フレームはコードの**外側**に追加されます。出力サイズは大きくなりますが、QRのモジュールとクワイエットゾーンが隠れることはないため、スキャンのしやすさは変わりません。コードの背景色の細い隙間が、コードとフレームを区切ります。

| Option | Default | Notes |
| --- | --- | --- |
| `style` | — | 下記の{facts.frameStyles}種類のスタイルのいずれか、または `none`（`FRAME_STYLES`） |
| `text` | `"Scan me"` | 最大24文字。ラベルを非表示にするには `""` を渡します |
| `color` | `#000000` | フレームの色（`gradient-border` では開始色。デフォルトは紫） |
| `textColor` | フレーム上は白、明るい領域では `color` | ラベルの色 |
| `secondaryText` | なし | 2つ目のラベル（最大24文字）。`banner-top-bottom` の下部バンド、`circle` の下側の弧、`menu-card` のフッターに使われます |
| `secondaryColor` | `#db2777` | `gradient-border` の終了色 |
| `fontScale` | `1` | ラベルのサイズ（0.5〜1.5）。ラベルは収まるように縮小されます |

スタイル:

- バナーと枠線: `banner-bottom`、`banner-top`、`banner-top-bottom`、`border`、`rounded-border`、`gradient-border`、`focus`（角のブラケット）
- 吹き出し: `speech-bubble`、`speech-bubble-top`、`chat-bubble`
- バッジ: `circle`（リングに沿って配置したテキスト）、`badge`（リボン）、`sticker`（影付きのダイカット）
- オブジェクト: `polaroid`、`phone`、`ticket`、`tag`（穴の開いた下げ札）、`envelope`、`menu-card`

すべてのスタイルは、ブラウザー上でデコードした状態で [Shapes, eyes and frames](/docs/styles#frames) で確認できます。どのフレームも不透明な色の単純な図形とテキストでできているため、SVG、PNG、PDF、EPSのどの書き出しでも同じ見た目になります（グラデーション枠は細かい単色の段階で描画され、円形フレームの曲線状の文字は、どの形式でも回転したテキストです）。

```tsx
<QRCode
  value="https://example.com"
  frame={{ style: "circle", text: "Scan me", secondaryText: "example.com", fontScale: 1.2 }}
/>
```

ラベルにはシステムのフォントスタックを使うため、ダウンロードは発生しません。出力サイズは大きくなるので、最終的な幅と高さが必要な場合は `getFrameDimensions(size, frame)` を使ってください。

```ts
import { getFrameDimensions } from "qrdx";

getFrameDimensions(400, { style: "banner-bottom" }); // { width: 496, height: 568 }
```

`FRAME_STYLES`、`frameSchema`（zod）、`QRFrame` / `FrameStyle` 型は `qrdx/types` からもエクスポートされており、サーバー側の検証に使えます。

### CLIでの使い方 [#in-the-cli]

```bash
qrdx generate "https://example.com/menu" --frame banner-bottom --frame-text "Scan for the menu" -o menu.png
```

`--frame-color` と `--frame-text-color` には16進カラーを指定します。`--frame` なしでテキストや色を渡した場合は `banner-bottom` が使われます。

## 公式フレーム [#official-frames]

組み込みスタイルに加えて、QRdxには{facts.officialFrames}種類の公式フレームがあります。行動喚起、レストランとカフェ、店舗とパッケージ、イベントと結婚式、ホテル、旅行と不動産、健康、フィットネスと教育、ビジネスとソーシャルなど、用途別に作られたデザインです。そのうち{facts.seasonalFrames}種類は祝日と季節向けで、旧正月、ホーリー、イード、ディワリから、ハヌカ、イースター、感謝祭、クリスマスまでそろっています。どれもラベルと色を変更できるフレーム仕様で、CC0で公開されており、スマートフォンで読み取る距離でスキャンできることをテスト済みです。

[Playground](/playground) で **Frame**、続けて **More** を開きます。名前、用途、祝日で検索するか、グループを選んでください。これから迎える祝日や季節のフレームが先頭に表示されます。[コミュニティ](/community/frames)でも、@qrdx が公開したフレームを見つけられます。

エンジンは、これらを `OFFICIAL_FRAMES` としてエクスポートしています。

```tsx
import { getOfficialFrame, QRCode } from "qrdx";

const diwali = getOfficialFrame("diwali-diya"); // undefined for an unknown id

{diwali && (
  <QRCode
    value="https://example.com/offers"
    frame={{ style: "custom", spec: diwali.spec, text: "Scan for offers" }}
  />
)}
```

`OFFICIAL_FRAME_INDEX` は、仕様を含めずにすべてのフレームを一覧にしたものです。ピッカーでライブラリ全体を表示し、仕様は必要になったときだけ読み込めます。[Image API](/docs/developers/image-api#community-items) と [MCP server](/docs/developers/mcp) では、公式フレームをコミュニティアイテムとして使えます。たとえば `item=frame:diwali-diya` のように指定します。

## スキャンできる? [#will-it-scan]

`getScanScore` は、デザインがどれだけ確実にスキャンできるかを推定します。ブラウザー上で動作し、必要に応じて [jsQR](https://github.com/cozmo/jsQR) を読み込みます。

```ts
import { getScanScore } from "qrdx";

const { score, grade, checks } = await getScanScore({
  value: "https://example.com",
  bodyPattern: "circle",
  cornerEyePattern: "gear",
});
// score: 0–100, grade: "great" | "ok" | "risky" | "fails"
// checks: [{ id, passed, message, fix? }]
```

チェック内容:

- **96px、160px、320pxでのデコード。** デザインをそれぞれの幅で描画し、カメラのようなぼかしとコントラストの低下を加えたうえで、わずかに異なる倍率で数回デコードします。
- **コントラスト。** コードのすべての色（グラデーションの色stop、アイや ドットの色を含む）と背景とのコントラスト、およびコードが明るい背景に暗い色で描かれているかどうか。
- **ロゴの占有率。** エラー訂正レベルで復元できる範囲との比較。
- **クワイエットゾーン。** マージンに、フレームによって加わる隙間を足したもの。
- **アイの形状のリスク。** `circle` のアイは、一部のスキャナーアプリで読み取れないことがあります（廃止された `curly` のアイも、保存済みのデザインがまだ使っている場合は、厳密なデコーダーで失敗します）。
- **スタイルの組み合わせ**（`style-pair`）。当社のデコードテストで一緒に使うと失敗する形状の組み合わせです。たとえば、四角いアイの隣に `small-square` のドットを置いた場合や、保存済みデザインに残っている廃止済みの中心部などです（`getStylePairRisk` を参照）。

`getImageScanScore(fileOrImage)` は、既存の画像に対して同じ処理を行います。デコードされた内容に加えて、ピクセルから測定したデコード、コントラスト、極性、クワイエットゾーン、解像度のチェック結果を返します。[スキャンチェッカー](/tools/scan-checker)はこの関数をもとに作られています。

<Callout type="info">
  このスコアは、1つのオープンソースデコーダーに基づくヒューリスティックです。スマートフォンのカメラアプリのほうが寛容なことも多いため、目安として扱い、重要な印刷物は実際にスキャンして確認してください。
</Callout>

## 印刷用エクスポート [#print-ready-export]

`downloadPrintPDF` は、正確な物理サイズのベクターPDFを書き出します。モジュール、アイ、フレームはベクターパスです（ロゴはラスター画像のままです）。

```ts
import { downloadPrintPDF, downloadPrintSVG, getPrintLayout } from "qrdx";

const props = { value: "https://example.com", frame: { style: "banner-bottom" } } as const;

await downloadPrintPDF(props, {
  size: 40, // width of the code itself
  unit: "mm", // or "in"
  bleed: 3, // millimetres on every side
  cropMarks: true,
  colorMode: "cmyk",
});

await downloadPrintSVG(props, { size: 1.5, unit: "in" }); // width="…in" height="…in"

const layout = getPrintLayout(props, { size: 40 });
layout.trimWidth; // finished width in mm, frame included
layout.maxScanDistance; // 400 (mm)
```

- `size` はコードの幅です。フレームを付けると、仕上がりサイズはその分大きくなります。
- 裁ち落としを付けると、背景（または四角いフレームの色）が仕上がり線の外側まで広がるため、断裁しても白い隙間が残りません。トンボは裁ち落としの外側に置かれます。
- `colorMode: "cmyk"` は簡易的な変換（`rgbToCmyk`: K = 1 − max(R, G, B)、ICCプロファイルなし。純粋な黒はKのみで印刷されます）を使います。ブランドカラーを正確に再現したい場合は、印刷会社にカラーマネジメント済みの変換を依頼してください。
- 線形グラデーションと放射グラデーションは、PDF内で滑らかなシェーディングとして印刷されます。PDFがCMYKの場合はCMYKになります。印刷用SVGでもグラデーションは保持されますが、RGBのままです。
- PDF内のフレームテキストにはHelvetica Boldを使うため、Latin-1以外の文字は表示されないことがあります。ほかの文字体系にはSVGを使ってください。
- `getQRAsPrintPDF` と `getQRAsPrintPDFBuffer` は、ダウンロードせずにファイルを返します。Nodeでも動作します。

**印刷サイズの目安:** コードは、幅のおよそ10倍の距離からスキャンできます。つまり、サイズ ≈ スキャン距離 ÷ 10 です（20cmの距離なら幅2cm）。密度の高いコードにはもっと大きなサイズが必要です。[印刷サイズ計算ツール](/tools/print-size)では、その点も考慮されます。
