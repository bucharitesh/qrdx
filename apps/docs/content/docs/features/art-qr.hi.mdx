QRdx में QR कोड को आर्टवर्क बनाने के तीन तरीके हैं:

| | यह कैसे काम करता है | आउटपुट | लागत |
|---|---|---|---|
| **Logo QR** | आपके लोगो के आकार के अंदर के मॉड्यूल उसके रंग लेते हैं; बाकी हल्के रंग में फीके पड़ जाते हैं | वेक्टर (SVG, PDF, EPS, PNG) | फ़्री |
| **Image QR** | हर मॉड्यूल में आपकी फ़ोटो दिखती है, बीच के एक वर्ग को छोड़कर जो असली वैल्यू रखता है (हाफ़टोन) | वेक्टर (SVG, PDF, EPS, PNG) | फ़्री |
| **AI art** | एक AI इमेज मॉडल कोड को एक दृश्य के रूप में दोबारा बनाता है, और हर इमेज की जाँच की जाती है कि वह स्कैन हो | 1024 px इमेज, 2048 px प्रिंट कॉपी | AI art क्रेडिट |

Logo QR और Image QR को `qrdx` लाइब्रेरी खुद बनाती है, इसलिए ये ऑफ़लाइन, एडिटर में, सर्वर पर और Node में काम करते हैं, और नतीजा हमेशा असली QR कोड होता है: फ़ाइंडर, टाइमिंग और अलाइनमेंट पैटर्न को कभी छुआ नहीं जाता।

## एडिटर में [#in-the-editor]

[playground](/playground?tab=art) खोलें, **Art** टैब पर जाएँ और **Logo QR** या **Image QR** चुनें:

1. लोगो या फ़ोटो अपलोड करें (PNG, JPG, WebP या SVG, अधिकतम 1 MB)। पारदर्शी PNG या SVG से सबसे साफ़ Logo QR बनता है।
2. **intensity** सेट करें: कम रखने पर कोड सादा दिखता है, ज़्यादा रखने पर तस्वीर ज़्यादा दिखती है।
3. स्लाइडर के पास **scan check** देखें। यह आपके ब्राउज़र में आर्ट कोड को तीन साइज़ पर डिकोड करता है, ठीक प्रीव्यू के [स्कैन स्कोर](/docs/qr-detection) की तरह।

आर्ट इमेज अपलोड करने पर एरर करेक्शन `H` पर सेट हो जाता है, जिससे आर्ट को सबसे ज़्यादा जगह मिलती है। इमेज आपके ब्राउज़र से बाहर नहीं जाती: डिज़ाइन के साथ केवल एक छोटा कलर ग्रिड (64 या 96 पिक्सेल चौड़ा) सेव होता है।

## कोड में [#in-code]

`art` प्रॉप दें, जिसमें एक मोड, एक सैंपल की गई इमेज और वैकल्पिक intensity (0 से 1, डिफ़ॉल्ट 0.6) हो:

```tsx
import { QRCodeSVG, loadQRArtImage } from 'qrdx';

// Browser: sample an uploaded file, a data URL or an <img>
const image = await loadQRArtImage(file, { mode: 'logo' });

<QRCodeSVG
  value="https://example.com"
  size={512}
  level="H"
  art={{ mode: 'logo', image, intensity: 0.7 }}
/>;
```

सर्वर पर या Node में, इमेज को खुद डिकोड करें और RGBA पिक्सेल `createQRArtImage` को दें:

```ts
import sharp from 'sharp';
import { createQRArtImage } from 'qrdx';

const { data, info } = await sharp('photo.jpg')
  .ensureAlpha()
  .raw()
  .toBuffer({ resolveWithObject: true });

const image = createQRArtImage(
  { data, width: info.width, height: info.height },
  { maxSize: 96 }
);
// art={{ mode: 'halftone', image, intensity: 0.8 }}
```

`art.image` सादा JSON है (`{ width, height, data }`, जिसमें data base64 RGBA है), इसलिए आप इसे सेव किए गए डिज़ाइन के साथ रख सकते हैं और तस्वीर दोबारा लाए बिना कहीं भी वही कोड सिंक्रोनस रूप से बना सकते हैं।

| विकल्प | वैल्यू | नोट्स |
|---|---|---|
| `mode` | `logo`, `halftone` | एडिटर में `halftone` को "Image QR" कहा गया है |
| `image` | `loadQRArtImage` या `createQRArtImage` से | अधिकतम 192 × 192 सैंपल |
| `intensity` | `0` से `1` | डिफ़ॉल्ट `0.6`; `0` सादे कोड जैसा दिखता है |

आर्ट बॉडी पैटर्न की जगह ले लेता है; कोने की आँखें अपने `cornerEyePattern`, `cornerEyeDotPattern` और रंग रखती हैं। आर्ट ग्रेडिएंट `fgColor`/`bgColor` का पहला रंग इस्तेमाल करता है, और हल्के बैकग्राउंड पर गहरा फ़ोरग्राउंड चाहिए (उल्टे रंगों में यह सादे रूप पर लौट जाता है)।

### स्कैन होने की क्षमता कैसे बनी रहती है [#how-scannability-is-kept]

- **Logo QR**: लोगो के अंदर के गहरे मॉड्यूल का रंग बदला जाता है, पर उन्हें केवल उतना ही गहरा रखा जाता है कि स्कैनर उन्हें अब भी गहरा पढ़े; लोगो के अंदर के हल्के मॉड्यूल को हल्का टिंट मिलता है जो लाइट थ्रेशोल्ड से ऊपर रहता है। लोगो के बाहर के गहरे मॉड्यूल ग्रे में फीके पड़ते हैं, डार्क थ्रेशोल्ड से हल्के कभी नहीं।
- **Logo QR बैज**: प्लेट के नीचे का हर मॉड्यूल एक कोडवर्ड बिगाड़ सकता है। प्लेट का साइज़ ऐसा रखा जाता है कि कोई भी एरर करेक्शन ब्लॉक अपने ठीक किए जा सकने वाले कोडवर्ड का 60% से ज़्यादा न खोए, जिससे बाकी कैमरे के लिए बचा रहता है। Intensity बढ़ने पर प्लेट उस साइज़ तक बढ़ती है। छोटे कोड में छोटा लोगो आता है, और सबसे छोटे कोड (वर्शन 1, L या M पर वर्शन 2, L पर वर्शन 3) में कोई प्लेट नहीं बनती।
- **Image QR**: हर मॉड्यूल को 3 × 3 ग्रिड में बाँटा जाता है। बाहरी सेल फ़ोटो दिखाते हैं, जिन्हें मॉड्यूल की वैल्यू के अनुसार गहरा या हल्का किया जाता है, और बीच का सेल सटीक फ़ोरग्राउंड या बैकग्राउंड रंग रखता है, जहाँ से स्कैनर सैंपल लेते हैं।
- फ़ाइंडर, टाइमिंग, अलाइनमेंट, फ़ॉर्मैट और वर्शन मॉड्यूल हमेशा ठोस रंग में बनते हैं।

प्रिंट करने से पहले किसी भी डिज़ाइन को `getScanScore(props)` से जाँचें, और असली फ़ोन कैमरे से टेस्ट करें।

## आर्ट कोड एक्सपोर्ट करना [#exporting-art-codes]

आर्ट कोड वेक्टर आकार हैं, इसलिए हर एक्सपोर्ट में वे साफ़ रहते हैं:

```ts
import { downloadQRCode, getQRAsEPS, getQRAsPrintPDF } from 'qrdx';

await downloadQRCode(props, { format: 'svg', size: { width: 1024, height: 1024 } });
const pdf = await getQRAsPrintPDF(props, { size: 40, unit: 'mm', colorMode: 'cmyk' });
const eps = await getQRAsEPS(props, { sizeMm: 40, bleedMm: 3, colorMode: 'cmyk' });
```

`getQRAsEPS` पॉइंट में `%%BoundingBox` वाली EPSF-3.0 फ़ाइल लिखता है, और हर मॉड्यूल, आँख और फ़्रेम को PostScript पाथ के रूप में रखता है। प्रिंट PDF की तरह यह लीनियर और रेडियल ग्रेडिएंट रखता है (PostScript Level 3 शेडिंग के रूप में) और इसमें पारदर्शिता नहीं होती। PNG और JPEG लोगो इमेज के रूप में एम्बेड होते हैं; दूसरे लोगो फ़ॉर्मैट ब्राउज़र में बदले जाते हैं और सर्वर पर छोड़ दिए जाते हैं। फ़्रेम टेक्स्ट Helvetica इस्तेमाल करता है, इसलिए Latin-1 से बाहर के अक्षर `?` के रूप में प्रिंट होते हैं। `svgToEPS(svg, { width })` इस लाइब्रेरी से बने किसी भी SVG को बदल देता है।

CLI भी EPS लिखता है: `qrdx generate "https://example.com" -o qr.eps`।

[AI QR art](/ai/art) Vercel AI Gateway के ज़रिए {facts.artModel} से आपके कोड को एक दृश्य में बदल देता है। आपको {facts.aiArtStyles} स्टाइल प्रीसेट मिलते हैं, जिन्हें आप कैटेगरी से ब्राउज़ या सर्च कर सकते हैं, और हर एक का प्रीव्यू स्कैन चेक पास कर चुका होता है। इसके अलावा बचने वाली चीज़ें, एक **QR visibility** स्लाइडर (मॉडल कोड को कितना प्राथमिकता दे), एक **creativity** स्लाइडर (मॉडल आपके प्रॉम्प्ट को कितनी आज़ादी से पढ़े), हर रन में 1 से 4 वेरिएशन और एक वैकल्पिक रेफ़रेंस इमेज भी है, जैसे लोगो या पैलेट, जिसके रंग और आकार आगे आते हैं।

हर इमेज आपको दिखने से पहले सर्वर पर जाँची जाती है। QRdx मॉडल को सादा ब्लैक-एंड-व्हाइट कोड भेजता है (एरर करेक्शन H, चौकोर मॉड्यूल, चौड़ा क्वाइट ज़ोन) और कहता है कि मॉड्यूल ग्रिड, फ़ाइंडर आँखें और क्वाइट ज़ोन बनाए रखे। फिर वह मॉडल की इमेज को jsQR से डिकोड करता है, जैसी है वैसी और फ़ोन-कैमरा मॉडल से गुज़ारकर। अगर यह विफल हो, तो वह मॉडल ने जहाँ मॉड्यूल ग्रिड बनाया है वहाँ उसे ढूँढता है और मॉडल की अपनी इमेज पर कोड को जितना कम हो सके उतना मज़बूत करता है: पहले फ़ाइंडर आँखें और क्वाइट ज़ोन, फिर मॉड्यूल, और इमेज के स्कैन होने तक स्ट्रेंथ को कदम-दर-कदम बढ़ाता है, तब भी जब कैमरे के व्यू में कोड छोटा हो। QR visibility तय करता है कि वह कितनी दूर तक जा सकता है। केवल तब, जब यह काफ़ी न हो, वह इमेज को Image QR कोड के रूप में दोबारा बनाता है। जो इमेज फिर भी आपके सटीक कंटेंट पर डिकोड नहीं होती, वह दी नहीं जाती। फिर आपका ब्राउज़र वेरिएशन को स्कोर करता है और सबसे अच्छा चुनता है; उसे 1024 px पर या 2048 px प्रिंट कॉपी के रूप में डाउनलोड करें (दोबारा रीसैंपल और जाँची हुई)।

हर दी गई इमेज एक AI art क्रेडिट इस्तेमाल करती है: फ़्री अकाउंट को महीने में 3, Pro को 30, और Business को 150 मिलते हैं, जो वर्कस्पेस में सबके बीच साझा होते हैं। जो इमेज विफल हों या स्कैन चेक पास न करें, उनमें कोई क्रेडिट नहीं लगता, और प्रिंट कॉपी मुफ़्त है। AI art एक रास्टर इमेज है और उसका कंटेंट तय होता है, इसलिए बदले जा सकने वाले लिंक के लिए उसमें [डायनेमिक कोड](/docs/dynamic-qr-codes) का शॉर्ट लिंक डालें।
