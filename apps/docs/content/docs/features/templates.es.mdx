Envuelve un código QR en un diseño listo para usar o en uno propio.

## ¿Qué son las plantillas? [#what-are-templates]

Una plantilla es un diseño SVG dibujado alrededor del código: un recuadro, un borde, una insignia. Recibe el código como `children` y lo coloca dentro de su propio dibujo. Los colores, los patrones y los logotipos se mantienen en las props de `QRCode`, así que una plantilla funciona con cualquier estilo.

## Plantillas disponibles [#available-templates]

### Default [#default]
Blanco y negro clásico.

```tsx
import { QRCode } from 'qrdx';

<QRCode value="https://example.com" templateId="default" size={256} />
```

### Arrow [#arrow]
Diseño geométrico moderno.

```tsx
<QRCode value="https://example.com" templateId="Arrow" size={256} />
```

### Standard Box [#standard-box]
Diseño limpio y estructurado.

```tsx
<QRCode value="https://example.com" templateId="StandardBox" size={256} />
```

### Square Border [#square-border]
Diseño con borde y contornos definidos.

```tsx
<QRCode value="https://example.com" templateId="SquareBorder" size={256} />
```

### Striked Box [#striked-box]
Diseño dinámico con elementos diagonales.

```tsx
<QRCode value="https://example.com" templateId="StrikedBox" size={256} />
```

### Halloween [#halloween]
Tema estacional de Halloween.

```tsx
<QRCode value="https://example.com" templateId="Halloween" size={256} />
```

## Personalizar plantillas [#customize-templates]

Las plantillas integradas dibujan su diseño con `fgColor`. Todo lo demás, como los patrones y un logotipo, se configura en el código de la forma habitual:

```tsx
<QRCode
  value="https://example.com"
  templateId="Arrow"
  fgColor="#1a56db"
  imageSettings={{
    src: "/your-logo.png",
    width: 48,
    height: 48,
    excavate: true,
  }}
  size={512}
/>
```

## Registro de plantillas [#template-registry]

### Obtener todas las plantillas [#get-all-templates]

```tsx
import { getAllTemplates } from 'qrdx';

const templates = getAllTemplates();
```

### Obtener los ID de las plantillas [#get-template-ids]

```tsx
import { getTemplateIds } from 'qrdx';

const ids = getTemplateIds();
// Returns: ['default', 'Arrow', 'StandardBox', ...]
```

## Plantillas personalizadas [#custom-templates]

Escribe tu propia plantilla como un `TemplateDefinition`. Su `wrapper` recibe el código como `children` y devuelve el SVG que se va a dibujar. Dibuja sobre un lienzo de 300 por 300, y el código llega también con ese tamaño, así que redúcelo para dejar espacio a tu diseño. `props` incluye los valores `fgColor` y `bgColor` del código.

Este ejemplo dibuja un anillo alrededor del código:

```tsx
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg viewBox="0 0 300 300" width="300" height="300" xmlns="http://www.w3.org/2000/svg">
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

<QRCode
  value="https://example.com"
  customTemplate={ringTemplate}
  fgColor="#1a56db"
  size={256}
/>
```

Mantén el código lo bastante grande para que se pueda escanear desde la distancia a la que la gente sostendrá el teléfono, y deja un espacio claro entre el código y tu diseño. Comprueba el resultado con la [puntuación de escaneo](/docs/features/frames#will-it-scan).

## Cuándo usar plantillas [#when-to-use-templates]

- **Coherencia de marca** — Asegura que todos los códigos QR combinen
- **Configuración rápida** — Obtén resultados profesionales en poco tiempo
- **Campañas estacionales** — Usa plantillas temáticas
- **Generación por lotes** — Aplica estilos uniformes

## Guía de selección de plantillas [#template-selection-guide]
