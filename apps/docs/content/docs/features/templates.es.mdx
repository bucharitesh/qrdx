Aplica estilos profesionales a tus códigos QR al instante.

## ¿Qué son las plantillas? [#what-are-templates]

Las plantillas combinan colores, patrones y estilos visuales en paquetes listos para usar.

## Plantillas disponibles [#available-templates]

### Default [#default]
Clásico en blanco y negro.

```tsx
import { QRCode } from 'qrdx';

<QRCode value="https://example.com" templateId="default" size={256} />
```

### Arrow [#arrow]
Diseño geométrico moderno.

```tsx
<QRCode value="https://example.com" templateId="Arrow" size={256} />
```

### Standard Box [#standard-box]
Diseño limpio y estructurado.

```tsx
<QRCode value="https://example.com" templateId="StandardBox" size={256} />
```

### Square Border [#square-border]
Diseño con borde y límites definidos.

```tsx
<QRCode value="https://example.com" templateId="SquareBorder" size={256} />
```

### Striked Box [#striked-box]
Diseño dinámico con elementos diagonales.

```tsx
<QRCode value="https://example.com" templateId="StrikedBox" size={256} />
```

### Halloween [#halloween]
Tema estacional de Halloween.

```tsx
<QRCode value="https://example.com" templateId="Halloween" size={256} />
```

## Personalizar plantillas [#customize-templates]

Reemplaza los valores predeterminados de una plantilla:

```tsx
<QRCode
  value="https://example.com"
  templateId="Arrow"
  fgColor="#your-brand-color"
  hideLogo={false}
  logo="/your-logo.png"
  size={512}
/>
```

## Registro de plantillas [#template-registry]

### Obtener todas las plantillas [#get-all-templates]

```tsx
import { getAllTemplates } from 'qrdx';

const templates = getAllTemplates();
```

### Obtener los ID de las plantillas [#get-template-ids]

```tsx
import { getTemplateIds } from 'qrdx';

const ids = getTemplateIds();
// Returns: ['default', 'Arrow', 'StandardBox', ...]
```

## Plantillas personalizadas [#custom-templates]

Crea tus propias plantillas:

```tsx
const brandTemplate = {
  id: 'brand-template',
  name: 'Brand Template',
  colors: {
    fgColor: '#1a56db',
    bgColor: '#ffffff',
    eyeColor: '#0d47a1',
    dotColor: '#3b82f6'
  },
  bodyPattern: 'rounded',
  cornerEyePattern: 'rounded',
  cornerEyeDotPattern: 'rounded'
};

<QRCode
  value="https://example.com"
  customTemplate={brandTemplate}
  size={256}
/>
```

## Cuándo usar plantillas [#when-to-use-templates]

- **Coherencia de marca** — Asegura que todos los códigos QR sean iguales
- **Configuración rápida** — Obtén resultados profesionales en poco tiempo
- **Campañas estacionales** — Usa plantillas temáticas
- **Generación por lotes** — Aplica estilos consistentes

## Guía para elegir una plantilla [#template-selection-guide]

| Plantilla | Ideal para | Ambiente |
|----------|----------|------|
| Default | Profesional | Neutral |
| Arrow | Tecnología, moderno | Dinámico |
| Standard Box | Corporativo | Profesional |
| Square Border | Formal | Estructurado |
| Striked Box | Marketing | Enérgico |
| Halloween | Estacional | Divertido |
