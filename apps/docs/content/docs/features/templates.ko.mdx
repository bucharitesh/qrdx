QR 코드를 기본 제공 디자인이나 직접 만든 디자인으로 감싸 보세요.

## 템플릿이란? [#what-are-templates]

템플릿은 코드 주위에 그려지는 SVG 디자인입니다. 상자, 테두리, 배지 같은 요소가 여기에 해당합니다. 템플릿은 코드를 `children`으로 받아 자신의 그림 안쪽에 배치합니다. 색상, 패턴, 로고는 `QRCode` props에 그대로 두므로 어떤 스타일에서도 템플릿을 사용할 수 있습니다.

## 사용 가능한 템플릿 [#available-templates]

### Default [#default]
클래식한 흑백 디자인입니다.

```tsx
import { QRCode } from 'qrdx';

<QRCode value="https://example.com" templateId="default" size={256} />
```

### Arrow [#arrow]
모던한 기하학적 디자인입니다.

```tsx
<QRCode value="https://example.com" templateId="Arrow" size={256} />
```

### Standard Box [#standard-box]
깔끔하고 구조적인 디자인입니다.

```tsx
<QRCode value="https://example.com" templateId="StandardBox" size={256} />
```

### Square Border [#square-border]
모서리가 분명한 테두리 디자인입니다.

```tsx
<QRCode value="https://example.com" templateId="SquareBorder" size={256} />
```

### Striked Box [#striked-box]
대각선 요소가 있는 역동적인 디자인입니다.

```tsx
<QRCode value="https://example.com" templateId="StrikedBox" size={256} />
```

### Halloween [#halloween]
할로윈 시즌 테마입니다.

```tsx
<QRCode value="https://example.com" templateId="Halloween" size={256} />
```

### Dot Ring [#dot-ring]
둥근 형태의 코드입니다. 어두운 링 안쪽의 점으로 된 원판 위에 코드가 놓이고, 링을 따라 한 줄의 텍스트가 배치됩니다. 어떤 점이 보일지는 코드 내용의 해시로 정해지므로 링크마다 고유한 링이 만들어지고, 같은 링크는 항상 같은 링을 얻습니다.

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  bodyPattern="circle-large"
  size={512}
/>
```

설정은 `customProps`에 넣습니다(타입은 `DotRingProps`).

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  customProps={{
    customText: "Scan for the menu",
    textPosition: "bottom",
    textColor: "#fde047",
    outerCircleColor: "#1e3a8a",
  }}
  size={512}
/>
```

| Prop | 기본값 | 설명 |
| --- | --- | --- |
| `customText` | "Scan the QR code"를 링 둘레에 네 번 반복 | 링을 따라 배치되는 텍스트입니다. 링에 들어가지 않는 글자는 생략되며, `""`로 설정하면 링이 비어 있게 됩니다 |
| `textPosition` | `"top"` | `"top"`: 위쪽 중앙에 배치되어 시계 방향으로 읽힙니다. `"bottom"`: 아래쪽 중앙을 따라 배치되어 왼쪽에서 오른쪽으로 읽힙니다 |
| `textRotation` | `0` | 텍스트를 중심을 기준으로 회전합니다(단위: 도) |
| `textColor` | `#ffffff` | 텍스트 색상 |
| `fontFamily` | 시스템 글꼴 스택 | 텍스트의 CSS 글꼴 패밀리 |
| `fontWeight` | `900` | 글꼴 굵기 |
| `fontSize` | `32` | 템플릿의 593단위 그림 기준이며, 이 그림에서 코드의 너비는 300입니다 |
| `fontLetterSpacing` | `3.5` | 글자 사이의 추가 간격이며, 같은 단위를 사용합니다 |
| `outerCircleColor` | `fgColor` | 링 색상 |
| `strokeWidth`, `strokeColor` | `0`, `#000000` | 링의 양쪽 가장자리를 따라 그려지는 선 |
| `outerStrokeWidth`, `outerStrokeColor` | `strokeWidth`, `strokeColor` | 링의 바깥쪽 가장자리에만 적용됩니다 |
| `innerStrokeWidth`, `innerStrokeColor` | `strokeWidth`, `strokeColor` | 링의 안쪽 가장자리에만 적용됩니다 |

로고는 다른 코드와 마찬가지로 가운데에 넣습니다. 긴 링크(가로 49모듈을 넘는 코드)는 코드와 점 사이에 밝은 띠를 유지하므로, 작게 인쇄해도 스캔할 수 있습니다.

텍스트는 선택한 글꼴로 그려지는 SVG 텍스트입니다. 기본값은 시스템 글꼴 스택이므로 내려받는 글꼴은 없습니다. 브라우저에서 SVG와 PNG를 다운로드하면 보는 사람의 글꼴이 사용됩니다. PDF와 EPS는 Helvetica Bold로 출력하므로 이 형식에서는 Latin-1 텍스트를 사용하세요. `qrdx/node`의 `getQRAsPNG`는 프레임 라벨과 마찬가지로 서버에 설치된 글꼴이 필요합니다.

## 템플릿 사용자 지정 [#customize-templates]

기본 제공 템플릿은 `fgColor`로 디자인을 그립니다. 패턴이나 로고 같은 나머지 요소는 평소처럼 코드에 설정합니다.

```tsx
<QRCode
  value="https://example.com"
  templateId="Arrow"
  fgColor="#1a56db"
  imageSettings={{
    src: "/your-logo.png",
    width: 48,
    height: 48,
    excavate: true,
  }}
  size={512}
/>
```

## 템플릿 레지스트리 [#template-registry]

### 모든 템플릿 가져오기 [#get-all-templates]

```tsx
import { getAllTemplates } from 'qrdx';

const templates = getAllTemplates();
```

### 템플릿 ID 가져오기 [#get-template-ids]

```tsx
import { getTemplateIds } from 'qrdx';

const ids = getTemplateIds();
// Returns: ['default', 'Arrow', 'StandardBox', ...]
```

## 사용자 지정 템플릿 [#custom-templates]

직접 만든 템플릿은 `TemplateDefinition`으로 작성합니다. `wrapper`는 코드를 `children`으로 받아 그릴 SVG를 반환합니다. 300×300 캔버스에 그리며 코드도 같은 크기로 전달되므로, 디자인을 넣을 공간이 생기도록 코드를 축소하세요. `props`에는 코드의 `fgColor`와 `bgColor`가 들어 있습니다.

다음은 코드 둘레에 링을 그리는 예시입니다.

```tsx
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg viewBox="0 0 300 300" width="300" height="300" xmlns="http://www.w3.org/2000/svg">
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

<QRCode
  value="https://example.com"
  customTemplate={ringTemplate}
  fgColor="#1a56db"
  size={256}
/>
```

사람들이 휴대폰을 들고 스캔할 거리에서도 인식되도록 코드를 충분히 크게 유지하고, 코드와 디자인 사이에 밝은 여백을 두세요. 결과는 [스캔 점수](/docs/features/frames#will-it-scan)로 확인하세요.

## 템플릿을 사용하면 좋은 경우 [#when-to-use-templates]

- **브랜드 일관성** — 모든 QR 코드를 통일합니다
- **빠른 설정** — 전문적인 결과를 빠르게 얻습니다
- **시즌 캠페인** — 테마 템플릿을 사용합니다
- **일괄 생성** — 일관된 스타일을 적용합니다

## 템플릿 선택 가이드 [#template-selection-guide]

| 템플릿 | 적합한 용도 | 분위기 |
|----------|----------|------|
| Default | 비즈니스 | 중립적 |
| Arrow | 기술, 모던 | 역동적 |
| Standard Box | 기업 | 전문적 |
| Square Border | 공식 문서 | 구조적 |
| Striked Box | 마케팅 | 활기찬 |
| Halloween | 시즌 | 재미있는 |
| Dot Ring | 둥근 코드, 포스터, 스티커 | 대담한 |
