템플릿은 자체 아트워크 안에 코드를 맞춰 넣는 프레임입니다. Playground에서 템플릿은 별도 목록이 아닙니다. Arrow, Standard Box, Square Border, Striked Box, Halloween, Dot Ring은 프레임 선택기의 **Classic** 그룹에 있는 타일이고, 다른 [프레임](/docs/features/frames)과 나란히 놓여 있습니다. 프레임을 하나 고르면 이전에 고른 프레임은 바뀝니다.

템플릿이 다른 프레임과 다른 점은 크기 하나입니다. 프레임은 코드 주위에 여백을 더하므로 `size`가 코드의 너비가 되고 이미지가 커집니다. 템플릿은 전체 아트워크를 `size`에 맞춰 그리고, 코드는 그 안에서 더 작게 들어갑니다.

## 기본 제공 템플릿 [#built-in-templates]

id를 `templateId`로 전달합니다. 이미지 API에서는 `template`, CLI에서는 `--template`으로 받습니다.

| `templateId` | 이름 | 색상 |
|--------------|------|-------|
| `Arrow` | Arrow | 코드의 어두운 색(`fgColor`) |
| `StandardBox` | Standard Box | `fgColor` |
| `SquareBorder` | Square Border | `fgColor` |
| `StrikedBox` | Striked Box | 자체 어두운 색 |
| `Halloween` | Halloween | 자체 주황, 초록, 검정 |
| `DotRing` | Dot Ring | 링은 `fgColor`, 텍스트는 흰색이며 둘 다 변경할 수 있습니다(아래 참고) |

`default`는 아트워크를 그리지 않습니다. 코드를 `size`의 95%로 약간 안쪽에 넣을 뿐입니다.

```tsx
import { QRCode } from 'qrdx';

<QRCode value="https://example.com" templateId="Arrow" fgColor="#1a56db" size={256} />
```

색상, 패턴, 로고는 코드 자체의 props로 유지되므로 템플릿은 어떤 스타일과도 함께 쓸 수 있습니다.

```tsx
<QRCode
  value="https://example.com"
  templateId="StandardBox"
  fgColor="#1a56db"
  imageSettings={{
    src: "/your-logo.png",
    width: 48,
    height: 48,
    excavate: true,
  }}
  size={512}
/>
```

## Dot Ring [#dot-ring]

둥근 코드입니다. 코드는 어두운 링 안쪽의 점으로 이루어진 원판 위에 놓이고, 링을 따라 한 줄의 텍스트가 배치됩니다. 어떤 점이 보일지는 코드 내용의 해시로 정해지므로, 링크마다 고유한 링이 만들어지고 같은 링크는 항상 같은 링을 얻습니다.

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  bodyPattern="circle-large"
  size={512}
/>
```

설정은 `customProps`에 넣습니다(타입은 `DotRingProps`).

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  customProps={{
    customText: "Scan for the menu",
    textPosition: "bottom",
    textColor: "#fde047",
    outerCircleColor: "#1e3a8a",
  }}
  size={512}
/>
```

| Prop | 기본값 | 참고 |
| --- | --- | --- |
| `customText` | "Scan the QR code"를 링 둘레에 네 번 | 링을 따라 배치되는 텍스트입니다. 둘레에 들어가지 않는 글자는 생략되며, `""`로 두면 링이 비어 있게 됩니다 |
| `textPosition` | `"top"` | `"top"`: 위쪽 중앙에 시계 방향으로 읽히게 배치합니다. `"bottom"`: 아래쪽 중앙에 왼쪽에서 오른쪽으로 읽히게 배치합니다 |
| `textRotation` | `0` | 텍스트를 중심 주위로 회전합니다(단위: 도) |
| `textColor` | `#ffffff` | 텍스트 색상 |
| `fontFamily` | 시스템 폰트 스택 | 텍스트의 CSS 글꼴 패밀리 |
| `fontWeight` | `900` | 글꼴 굵기 |
| `fontSize` | `32` | 코드의 너비가 300인 템플릿의 593 단위 도면 기준입니다 |
| `fontLetterSpacing` | `3.5` | 글자 사이의 추가 간격이며 같은 단위를 씁니다 |
| `outerCircleColor` | `fgColor` | 링 색상 |
| `strokeWidth`, `strokeColor` | `0`, `#000000` | 링의 양쪽 가장자리를 따라 그리는 테두리 |
| `outerStrokeWidth`, `outerStrokeColor` | `strokeWidth`, `strokeColor` | 링의 바깥쪽 가장자리에만 적용 |
| `innerStrokeWidth`, `innerStrokeColor` | `strokeWidth`, `strokeColor` | 링의 안쪽 가장자리에만 적용 |

로고는 다른 코드와 마찬가지로 가운데에 들어갑니다. 긴 링크(너비가 49모듈을 넘는 코드)는 코드와 점 사이에 밝은 띠를 유지하므로, 작게 인쇄해도 스캔됩니다.

텍스트는 선택한 글꼴의 SVG 텍스트입니다. 기본값은 시스템 폰트 스택이라 내려받는 것이 없습니다. 브라우저에서 SVG와 PNG를 다운로드하면 보는 사람의 글꼴이 사용됩니다. PDF와 EPS는 Helvetica Bold로 출력하므로 여기서는 Latin-1 텍스트를 사용하세요. `qrdx/node`의 `getQRAsPNG`는 프레임 라벨과 마찬가지로 서버에 설치된 글꼴이 필요합니다.

## 템플릿은 프레임 스펙입니다 [#templates-are-frame-specs]

Arrow, Standard Box, Square Border, Striked Box, Halloween의 아트워크는 다른 모든 프레임과 같은 JSON 형식의 [프레임 스펙](/docs/features/frames#frame-specs)이며, 같은 엔진으로 그려집니다. `getTemplate(id).spec`이 이를 반환합니다. 프레임 크기 방식(코드는 크기를 유지하고 아트워크가 주위로 커집니다)과 프레임의 색상 옵션을 쓰고 싶을 때는 이를 프레임으로 사용하세요.

```tsx
import { getTemplate, QRCode } from 'qrdx';

const spec = getTemplate('Arrow')?.spec;

<QRCode
  value="https://example.com"
  frame={spec && { style: 'custom', spec, color: '#1a56db' }}
  size={256}
/>
```

Dot Ring에는 스펙이 없습니다. 점이 코드의 내용에서 만들어지므로 코드로 그립니다([코드로 그리는 프레임](#frames-you-draw-in-code) 참고).

`templateId`는 이전과 같은 아트워크를 그립니다. 템플릿 id를 사용하는 저장된 디자인, 이미지 URL, CLI 명령, 코드는 예전과 똑같이 보입니다.

## 템플릿 레지스트리 [#template-registry]

```tsx
import { getAllTemplates, getTemplate, getTemplateIds } from 'qrdx';

getTemplateIds(); // ['default', 'Arrow', 'StandardBox', ...]
getAllTemplates(); // every TemplateDefinition, with its id and name
getTemplate('Halloween'); // one by id
```

## 코드로 그리는 프레임 [#frames-you-draw-in-code]

프레임 스펙은 고정된 아트워크를 설명합니다. 아트워크를 계산해야 할 때는 `TemplateDefinition`을 작성해 `customTemplate`으로 전달하세요. `wrapper`는 코드를 `children`으로 받아 그릴 SVG를 반환합니다. 300 x 300 캔버스에 그리며 코드도 같은 크기로 전달되므로, 아트워크가 들어갈 공간이 남도록 코드를 줄이세요. `props`에는 코드의 `fgColor`와 `bgColor`가 들어 있고, 세 번째 인자에는 코드의 `url`과 `pixelSize`가 들어 있습니다.

다음 예시는 코드 주위에 링을 그립니다.

```tsx
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg viewBox="0 0 300 300" width="300" height="300" xmlns="http://www.w3.org/2000/svg">
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

<QRCode
  value="https://example.com"
  customTemplate={ringTemplate}
  fgColor="#1a56db"
  size={256}
/>
```

사람들이 휴대폰을 들 위치에서 스캔할 수 있도록 코드를 충분히 크게 유지하고, 코드와 아트워크 사이에 밝은 간격을 두세요. 결과는 [스캔 점수](/docs/features/frames#will-it-scan)로 확인하세요.
