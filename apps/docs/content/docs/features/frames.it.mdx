Aggiungi una cornice "Scan me", verifica che un design si scansioni prima di pubblicarlo ed esporta un file vettoriale a una dimensione fisica esatta.

## Cornici con invito all'azione [#call-to-action-frames]

La prop `frame` disegna attorno al codice una cornice con una breve etichetta. Funziona su `QRCode`, `QRCodeSVG`, `QRCodeCanvas`, `getQRAsSVG`, `getQRData` e su tutti gli helper di download.

```tsx
import { QRCode } from "qrdx";

<QRCode
  value="https://example.com/menu"
  frame={{ style: "banner-bottom", text: "Scan for the menu", color: "#1e3a8a" }}
/>
```

La cornice viene aggiunta **attorno** al codice: l'output diventa più grande e i moduli del QR e la zona di quiete non vengono mai coperti, quindi la leggibilità alla scansione non cambia. Un leggero spazio nel colore di sfondo del codice separa il codice dalla cornice.

| Opzione | Predefinito | Note |
| --- | --- | --- |
| `style` | — | Uno dei {facts.frameStyles} stili qui sotto, oppure `none` (`FRAME_STYLES`) |
| `text` | `"Scan me"` | Fino a 24 caratteri. Passa `""` per nascondere l'etichetta |
| `color` | `#000000` | Colore della cornice (`gradient-border`: colore iniziale, viola per impostazione predefinita) |
| `textColor` | bianco sulla cornice, `color` sulle aree chiare | Colore dell'etichetta |
| `secondaryText` | nessuno | Seconda etichetta, fino a 24 caratteri: la fascia inferiore di `banner-top-bottom`, l'arco inferiore di `circle`, il piè di pagina di `menu-card` |
| `secondaryColor` | `#db2777` | Colore finale di `gradient-border` |
| `fontScale` | `1` | Dimensione dell'etichetta da 0.5 a 1.5; le etichette si riducono comunque per adattarsi |

Stili:

- Banner e bordi: `banner-bottom`, `banner-top`, `banner-top-bottom`, `border`, `rounded-border`, `gradient-border`, `focus` (angoli a parentesi)
- Fumetti: `speech-bubble`, `speech-bubble-top`, `chat-bubble`
- Badge: `circle` (testo disposto attorno a un anello), `badge` (nastro), `sticker` (sagomato con ombra)
- Oggetti: `polaroid`, `phone`, `ticket`, `tag` (cartellino con foro), `envelope`, `menu-card`

Vedili tutti, decodificati nel tuo browser, in [Forme, occhi e cornici](/docs/styles#frames). Ogni cornice è fatta solo di forme semplici e testo con colori opachi, quindi le esportazioni in SVG, PNG, PDF e EPS coincidono (il bordo sfumato è disegnato con sottili gradini di colore pieno e le lettere curve della cornice circle sono testo ruotato in ogni formato).

```tsx
<QRCode
  value="https://example.com"
  frame={{ style: "circle", text: "Scan me", secondaryText: "example.com", fontScale: 1.2 }}
/>
```

L'etichetta usa lo stack di font di sistema, quindi non viene scaricato nulla. Poiché l'output cresce, usa `getFrameDimensions(size, frame)` quando ti servono larghezza e altezza finali:

```ts
import { getFrameDimensions } from "qrdx";

getFrameDimensions(400, { style: "banner-bottom" }); // { width: 496, height: 568 }
```

`FRAME_STYLES`, `frameSchema` (zod) e i tipi `QRFrame` / `FrameStyle` sono esportati anche da `qrdx/types` per la validazione lato server.

### Nella CLI [#in-the-cli]

```bash
qrdx generate "https://example.com/menu" --frame banner-bottom --frame-text "Scan for the menu" -o menu.png
```

`--frame-color` e `--frame-text-color` accettano colori esadecimali. Se passi testo o colori senza `--frame`, viene usato `banner-bottom`.

## Cornici ufficiali [#official-frames]

Oltre agli stili integrati, QRdx ha {facts.officialFrames} cornici ufficiali: design già pronti per inviti all'azione, ristoranti e caffè, negozi e confezioni, eventi e matrimoni, hotel, viaggi e immobiliare, salute, fitness e istruzione, e business e social. {facts.seasonalFrames} di queste sono dedicate a festività e stagioni, dal Capodanno lunare, Holi, Eid e Diwali a Hanukkah, Pasqua, Thanksgiving e Natale. Ognuna è una specifica di cornice con etichette e colori che puoi modificare, rilasciata con licenza CC0, e ognuna è testata per scansionarsi alle distanze tipiche di uno smartphone.

Nel [playground](/playground) apri **Cornice** e poi **Altro**. Cerca per nome, uso o festività, oppure scegli un gruppo. Le cornici per le festività e le stagioni in arrivo sono elencate per prime. Le trovi anche nella [community](/community/frames), pubblicate da @qrdx.

Il motore le esporta come `OFFICIAL_FRAMES`:

```tsx
import { getOfficialFrame, QRCode } from "qrdx";

const diwali = getOfficialFrame("diwali-diya"); // undefined for an unknown id

{diwali && (
  <QRCode
    value="https://example.com/offers"
    frame={{ style: "custom", spec: diwali.spec, text: "Scan for offers" }}
  />
)}
```

`OFFICIAL_FRAME_INDEX` elenca ogni cornice senza la sua specifica, così un selettore può mostrare l'intera libreria e caricare le specifiche solo quando servono. Nella [image API](/docs/developers/image-api#community-items) e nel [server MCP](/docs/developers/mcp) usa una cornice ufficiale come elemento della community, ad esempio `item=frame:diwali-diya`.

## Si scansiona? [#will-it-scan]

`getScanScore` stima con quanta affidabilità un design viene scansionato. Gira nel browser e carica [jsQR](https://github.com/cozmo/jsQR) su richiesta.

```ts
import { getScanScore } from "qrdx";

const { score, grade, checks } = await getScanScore({
  value: "https://example.com",
  bodyPattern: "circle",
  cornerEyePattern: "gear",
});
// score: 0–100, grade: "great" | "ok" | "risky" | "fails"
// checks: [{ id, passed, message, fix? }]
```

Cosa controlla:

- **Decodifica a 96, 160 e 320 px.** Il design viene renderizzato a ciascuna larghezza, con sfocatura e perdita di contrasto simili a quelle di una fotocamera, e decodificato più volte a scale leggermente diverse.
- **Contrasto** tra ogni colore del codice (inclusi i punti del gradiente e i colori di occhi e punti) e lo sfondo, e se il codice è scuro su chiaro.
- **Copertura del logo** rispetto a ciò che il livello di correzione degli errori può recuperare.
- **Zona di quiete**: il margine, più lo spazio che aggiunge una cornice.
- **Rischio della forma degli occhi**: gli occhi `circle` potrebbero non essere riconosciuti da alcune app di scansione (e gli occhi `curly`, ormai ritirati, se un design salvato li usa ancora, non passano i decoder rigorosi).
- **Coppie di stili** (`style-pair`): forme che falliscono insieme nei nostri test di decodifica, come i punti `small-square` accanto a occhi quadrati, e i centri ritirati nei design salvati (vedi `getStylePairRisk`).

`getImageScanScore(fileOrImage)` fa lo stesso per un'immagine esistente: restituisce il contenuto decodificato più i controlli di decodifica, contrasto, polarità, zona di quiete e risoluzione misurati dai pixel. Il [controllo scansione](/tools/scan-checker) si basa su questa funzione.

<Callout type="info">
  Il punteggio è un'euristica basata su un solo decoder open source. Le app fotocamera degli smartphone sono spesso più tolleranti, quindi usalo come indicazione e fai una scansione di prova delle stampe importanti.
</Callout>

## Esportazione pronta per la stampa [#print-ready-export]

`downloadPrintPDF` scrive un PDF vettoriale a una dimensione fisica esatta. Moduli, occhi e cornici sono tracciati vettoriali (un logo resta un'immagine raster).

```ts
import { downloadPrintPDF, downloadPrintSVG, getPrintLayout } from "qrdx";

const props = { value: "https://example.com", frame: { style: "banner-bottom" } } as const;

await downloadPrintPDF(props, {
  size: 40, // width of the code itself
  unit: "mm", // or "in"
  bleed: 3, // millimetres on every side
  cropMarks: true,
  colorMode: "cmyk",
});

await downloadPrintSVG(props, { size: 1.5, unit: "in" }); // width="…in" height="…in"

const layout = getPrintLayout(props, { size: 40 });
layout.trimWidth; // finished width in mm, frame included
layout.maxScanDistance; // 400 (mm)
```

- `size` è la larghezza del codice; una cornice si aggiunge alla dimensione finale.
- Con l'abbondanza, lo sfondo (o il colore di una cornice quadrata) si estende oltre il bordo di taglio, così il taglio non lascia bordi bianchi. I crocini di taglio si trovano fuori dall'abbondanza.
- `colorMode: "cmyk"` usa una conversione semplice (`rgbToCmyk`: K = 1 − max(R, G, B), nessun profilo ICC; il nero puro si stampa solo con K). Chiedi al tuo stampatore una conversione con gestione del colore quando i colori esatti del brand sono importanti.
- I gradienti lineari e radiali vengono stampati come sfumature morbide nel PDF, in CMYK quando il PDF è CMYK; l'SVG di stampa li mantiene ma resta in RGB.
- Il testo della cornice nel PDF usa Helvetica Bold, quindi i caratteri fuori da Latin-1 potrebbero non essere visualizzati. Usa l'SVG per altri alfabeti.
- `getQRAsPrintPDF` e `getQRAsPrintPDFBuffer` restituiscono il file invece di scaricarlo e funzionano anche in Node.

**Quanto grande stampare:** un codice si scansiona da una distanza pari a circa dieci volte la sua larghezza, quindi dimensione ≈ distanza di scansione ÷ 10 (2 cm di larghezza per 20 cm). I codici più densi richiedono di più; il [calcolatore delle dimensioni di stampa](/tools/print-size) ne tiene conto.
