Adicione uma moldura "Scan me", confira se um design é lido antes de publicá-lo e exporte um arquivo vetorial em um tamanho físico exato.

## Molduras de chamada para ação [#call-to-action-frames]

A prop `frame` desenha em volta do código uma moldura com um rótulo curto. Ela funciona em `QRCode`, `QRCodeSVG`, `QRCodeCanvas`, `getQRAsSVG`, `getQRData` e em todos os helpers de download.

```tsx
import { QRCode } from "qrdx";

<QRCode
  value="https://example.com/menu"
  frame={{ style: "banner-bottom", text: "Scan for the menu", color: "#1e3a8a" }}
/>
```

A moldura é adicionada **em volta** do código: o resultado fica maior, e os módulos do QR e a zona de silêncio nunca são cobertos, então a leitura não muda. Um espaço claro, na cor de fundo do código, separa o código da moldura.

| Opção | Padrão | Observações |
| --- | --- | --- |
| `style` | — | Um dos {facts.frameStyles} estilos abaixo, ou `none` (`FRAME_STYLES`) |
| `text` | `"Scan me"` | Até 24 caracteres. Passe `""` para ocultar o rótulo |
| `color` | `#000000` | Cor da moldura (`gradient-border`: cor inicial, violeta por padrão) |
| `textColor` | branco na moldura, `color` nas áreas claras | Cor do rótulo |
| `secondaryText` | nenhum | Segundo rótulo, até 24 caracteres: a faixa inferior de `banner-top-bottom`, o arco inferior de `circle`, o rodapé de `menu-card` |
| `secondaryColor` | `#db2777` | Cor final de `gradient-border` |
| `fontScale` | `1` | Tamanho do rótulo de 0,5 a 1,5; os rótulos ainda diminuem para caber |

Estilos:

- Faixas e bordas: `banner-bottom`, `banner-top`, `banner-top-bottom`, `border`, `rounded-border`, `gradient-border`, `focus` (colchetes nos cantos)
- Balões: `speech-bubble`, `speech-bubble-top`, `chat-bubble`
- Selos: `circle` (texto disposto em um anel), `badge` (fita), `sticker` (adesivo recortado com sombra)
- Objetos: `polaroid`, `phone`, `ticket`, `tag` (etiqueta de pendurar com furo), `envelope`, `menu-card`

Veja todos, decodificados no seu navegador, em [Formas, olhos e molduras](/docs/styles#frames). Toda moldura é feita só de formas e texto com cores opacas, então as exportações em SVG, PNG, PDF e EPS ficam iguais (a borda em gradiente é desenhada como degraus finos de cor sólida, e as letras curvas da moldura circle são texto rotacionado em todos os formatos).

```tsx
<QRCode
  value="https://example.com"
  frame={{ style: "circle", text: "Scan me", secondaryText: "example.com", fontScale: 1.2 }}
/>
```

O rótulo usa a pilha de fontes do sistema, então nada é baixado. Como o resultado cresce, use `getFrameDimensions(size, frame)` quando precisar da largura e da altura finais:

```ts
import { getFrameDimensions } from "qrdx";

getFrameDimensions(400, { style: "banner-bottom" }); // { width: 496, height: 568 }
```

`FRAME_STYLES`, `frameSchema` (zod) e os tipos `QRFrame` / `FrameStyle` também são exportados de `qrdx/types` para validação no servidor.

### Na CLI [#in-the-cli]

```bash
qrdx generate "https://example.com/menu" --frame banner-bottom --frame-text "Scan for the menu" -o menu.png
```

`--frame-color` e `--frame-text-color` aceitam cores hex. Passar texto ou cores sem `--frame` usa `banner-bottom`.

## Molduras oficiais [#official-frames]

Além dos estilos integrados, o QRdx tem {facts.officialFrames} molduras oficiais: designs prontos para chamadas para ação, restaurantes e cafés, lojas e embalagens, eventos e casamentos, hotéis, viagens e imóveis, saúde, fitness e educação, e negócios e redes sociais. {facts.seasonalFrames} delas são para feriados e estações, do Ano Novo Lunar, Holi, Eid e Diwali até Hanukkah, Páscoa, Ação de Graças e Natal. Cada uma é uma especificação de moldura com rótulos e cores que você pode mudar, liberada sob CC0, e cada uma é testada para ser lida a distâncias de celular.

No [playground](/playground), abra **Moldura** e depois **Mais**. Busque por nome, uso ou feriado, ou escolha um grupo. As molduras dos feriados e estações que estão chegando aparecem primeiro. Você também as encontra na [comunidade](/community/frames), publicadas por @qrdx.

O motor as exporta como `OFFICIAL_FRAMES`:

```tsx
import { getOfficialFrame, QRCode } from "qrdx";

const diwali = getOfficialFrame("diwali-diya"); // undefined for an unknown id

{diwali && (
  <QRCode
    value="https://example.com/offers"
    frame={{ style: "custom", spec: diwali.spec, text: "Scan for offers" }}
  />
)}
```

`OFFICIAL_FRAME_INDEX` lista todas as molduras sem a especificação, para que um seletor mostre a biblioteca inteira e carregue as especificações só quando forem necessárias. Na [Image API](/docs/developers/image-api#community-items) e no [servidor MCP](/docs/developers/mcp), use uma moldura oficial como item da comunidade, por exemplo `item=frame:diwali-diya`.

## Vai ler? [#will-it-scan]

`getScanScore` estima com que confiabilidade um design é lido. Ele roda no navegador e carrega o [jsQR](https://github.com/cozmo/jsQR) sob demanda.

```ts
import { getScanScore } from "qrdx";

const { score, grade, checks } = await getScanScore({
  value: "https://example.com",
  bodyPattern: "circle",
  cornerEyePattern: "gear",
});
// score: 0–100, grade: "great" | "ok" | "risky" | "fails"
// checks: [{ id, passed, message, fix? }]
```

O que ele verifica:

- **Decodificação a 96, 160 e 320 px.** O design é renderizado em cada largura, recebe desfoque e perda de contraste como os de uma câmera, e é decodificado algumas vezes em escalas ligeiramente diferentes.
- **Contraste** entre cada cor do código (incluindo pontos de gradiente, cores dos olhos e dos pontos) e o fundo, e se o código é escuro sobre claro.
- **Cobertura do logo** em comparação com o que o nível de correção de erros consegue recuperar.
- **Zona de silêncio**: a margem, mais o espaço que uma moldura adiciona.
- **Risco do formato dos olhos**: olhos `circle` podem não ser detectados por alguns apps de leitura (e os olhos `curly`, já aposentados, falham em decodificadores estritos se um design salvo ainda os usar).
- **Pares de estilos** (`style-pair`): formas que falham juntas nos nossos testes de decodificação, como pontos `small-square` ao lado de olhos quadrados, e centros aposentados em designs salvos (veja `getStylePairRisk`).

`getImageScanScore(fileOrImage)` faz o mesmo para uma imagem existente: retorna o conteúdo decodificado mais verificações de decodificação, contraste, polaridade, zona de silêncio e resolução medidas a partir dos pixels. O [verificador de leitura](/tools/scan-checker) é construído sobre ele.

<Callout type="info">
  A nota é uma heurística baseada em um único decodificador de código aberto. Os apps de câmera dos celulares costumam ser mais tolerantes, então use-a como guia e teste a leitura de impressões importantes.
</Callout>

## Exportação pronta para impressão [#print-ready-export]

`downloadPrintPDF` gera um PDF vetorial em um tamanho físico exato. Módulos, olhos e molduras são caminhos vetoriais (o logo continua sendo uma imagem raster).

```ts
import { downloadPrintPDF, downloadPrintSVG, getPrintLayout } from "qrdx";

const props = { value: "https://example.com", frame: { style: "banner-bottom" } } as const;

await downloadPrintPDF(props, {
  size: 40, // width of the code itself
  unit: "mm", // or "in"
  bleed: 3, // millimetres on every side
  cropMarks: true,
  colorMode: "cmyk",
});

await downloadPrintSVG(props, { size: 1.5, unit: "in" }); // width="…in" height="…in"

const layout = getPrintLayout(props, { size: 40 });
layout.trimWidth; // finished width in mm, frame included
layout.maxScanDistance; // 400 (mm)
```

- `size` é a largura do código; uma moldura aumenta o tamanho final.
- Com sangria, o fundo (ou a cor de uma moldura quadrada) se estende além da borda de corte, para que o corte não deixe uma fresta branca. As marcas de corte ficam fora da sangria.
- `colorMode: "cmyk"` usa uma conversão simples (`rgbToCmyk`: K = 1 − max(R, G, B), sem perfil ICC; o preto puro é impresso só com K). Peça à gráfica uma conversão com gerenciamento de cor quando as cores exatas da marca importarem.
- Gradientes lineares e radiais são impressos como degradês suaves no PDF, em CMYK quando o PDF é CMYK; o SVG de impressão os mantém, mas continua em RGB.
- O texto da moldura no PDF usa Helvetica Bold, então caracteres fora do Latin-1 podem não aparecer. Use o SVG para outros alfabetos.
- `getQRAsPrintPDF` e `getQRAsPrintPDFBuffer` retornam o arquivo em vez de baixá-lo, e também funcionam no Node.

**Qual tamanho imprimir:** um código é lido a uma distância de cerca de dez vezes a sua largura, então tamanho ≈ distância de leitura ÷ 10 (2 cm de largura para 20 cm). Códigos mais densos precisam de mais; a [calculadora de tamanho de impressão](/tools/print-size) leva isso em conta.
