"Scan me" 프레임을 추가하고, 배포하기 전에 디자인이 스캔되는지 확인하고, 정확한 실제 크기의 벡터 파일로 내보내세요.

## 행동 유도 프레임 [#call-to-action-frames]

`frame` prop은 코드 주위에 짧은 라벨이 있는 프레임을 그립니다. `QRCode`, `QRCodeSVG`, `QRCodeCanvas`, `getQRAsSVG`, `getQRData` 및 모든 다운로드 헬퍼에서 사용할 수 있습니다.

```tsx
import { QRCode } from "qrdx";

<QRCode
  value="https://example.com/menu"
  frame={{ style: "banner-bottom", text: "Scan for the menu", color: "#1e3a8a" }}
/>
```

프레임은 코드 **바깥쪽**에 추가됩니다. 출력물은 더 커지지만 QR 모듈과 여백(quiet zone)은 절대 가려지지 않으므로 스캔 성능은 그대로입니다. 코드 배경색과 같은 밝은 간격이 코드와 프레임을 구분합니다.

| 옵션 | 기본값 | 참고 |
| --- | --- | --- |
| `style` | — | 아래의 {facts.frameStyles}가지 스타일 중 하나 또는 `none` (`FRAME_STYLES`) |
| `text` | `"Scan me"` | 최대 24자. 라벨을 숨기려면 `""`를 전달하세요 |
| `color` | `#000000` | 프레임 색상 (`gradient-border`: 시작 색상, 기본값은 보라색) |
| `textColor` | 프레임 위에서는 흰색, 밝은 영역에서는 `color` | 라벨 색상 |
| `secondaryText` | 없음 | 두 번째 라벨, 최대 24자: `banner-top-bottom`의 아래쪽 띠, `circle`의 아래쪽 호, `menu-card`의 푸터 |
| `secondaryColor` | `#db2777` | `gradient-border`의 끝 색상 |
| `fontScale` | `1` | 0.5에서 1.5 사이의 라벨 크기. 라벨은 맞도록 여전히 줄어듭니다 |

스타일:

- 배너와 테두리: `banner-bottom`, `banner-top`, `banner-top-bottom`, `border`, `rounded-border`, `gradient-border`, `focus` (모서리 괄호)
- 말풍선: `speech-bubble`, `speech-bubble-top`, `chat-bubble`
- 배지: `circle` (고리를 따라 배치된 텍스트), `badge` (리본), `sticker` (그림자가 있는 도무송 스티커)
- 오브젝트: `polaroid`, `phone`, `ticket`, `tag` (구멍이 있는 행택), `envelope`, `menu-card`

브라우저에서 디코딩된 모든 스타일은 [도형, 눈, 프레임](/docs/styles#frames)에서 확인할 수 있습니다. 모든 프레임은 불투명한 색상의 단순한 도형과 텍스트로 이루어져 있어 SVG, PNG, PDF, EPS로 내보내도 결과가 같습니다. 그라디언트 테두리는 가는 단색 단계로 그려지고, 원형 프레임의 곡선 글자는 모든 형식에서 회전된 텍스트입니다.

```tsx
<QRCode
  value="https://example.com"
  frame={{ style: "circle", text: "Scan me", secondaryText: "example.com", fontScale: 1.2 }}
/>
```

라벨은 시스템 글꼴 스택을 사용하므로 다운로드되는 것이 없습니다. 출력물이 커지기 때문에 최종 너비와 높이가 필요하면 `getFrameDimensions(size, frame)`를 사용하세요.

```ts
import { getFrameDimensions } from "qrdx";

getFrameDimensions(400, { style: "banner-bottom" }); // { width: 496, height: 568 }
```

`FRAME_STYLES`, `frameSchema` (zod), `QRFrame` / `FrameStyle` 타입은 서버 측 검증을 위해 `qrdx/types`에서도 내보내집니다.

### CLI에서 [#in-the-cli]

```bash
qrdx generate "https://example.com/menu" --frame banner-bottom --frame-text "Scan for the menu" -o menu.png
```

`--frame-color`와 `--frame-text-color`는 16진수 색상을 받습니다. `--frame` 없이 텍스트나 색상을 전달하면 `banner-bottom`이 사용됩니다.

## 공식 프레임 [#official-frames]

QRdx에는 기본 제공 스타일 외에 {facts.officialFrames}개의 공식 프레임이 있습니다. 행동 유도, 레스토랑과 카페, 상점과 포장, 이벤트와 결혼식, 호텔, 여행과 부동산, 건강, 피트니스와 교육, 비즈니스와 소셜용으로 미리 만들어진 디자인입니다. 그중 {facts.seasonalFrames}개는 설날, 홀리, 이드, 디왈리부터 하누카, 부활절, 추수감사절, 크리스마스까지 명절과 계절용입니다. 각 프레임은 라벨과 색상을 바꿀 수 있는 프레임 스펙이며 CC0로 공개되어 있고, 휴대폰으로 스캔하는 거리에서 스캔되는지 테스트를 거쳤습니다.

[Playground](/playground)에서 **프레임**을 열고 **더 보기**를 선택하세요. 이름, 용도, 명절로 검색하거나 그룹을 고를 수 있습니다. 다가오는 명절과 계절의 프레임이 먼저 표시됩니다. @qrdx가 게시한 프레임은 [커뮤니티](/community/frames)에서도 볼 수 있습니다.

엔진은 이 프레임들을 `OFFICIAL_FRAMES`로 내보냅니다.

```tsx
import { getOfficialFrame, QRCode } from "qrdx";

const diwali = getOfficialFrame("diwali-diya"); // undefined for an unknown id

{diwali && (
  <QRCode
    value="https://example.com/offers"
    frame={{ style: "custom", spec: diwali.spec, text: "Scan for offers" }}
  />
)}
```

`OFFICIAL_FRAME_INDEX`는 스펙 없이 모든 프레임을 나열하므로, 선택기가 전체 라이브러리를 보여주고 필요할 때만 스펙을 불러올 수 있습니다. [Image API](/docs/developers/image-api#community-items)와 [MCP 서버](/docs/developers/mcp)에서는 `item=frame:diwali-diya`처럼 공식 프레임을 커뮤니티 항목으로 사용하세요.

## 스캔될까요? [#will-it-scan]

`getScanScore`는 디자인이 얼마나 안정적으로 스캔되는지 추정합니다. 브라우저에서 실행되며 [jsQR](https://github.com/cozmo/jsQR)를 필요할 때 불러옵니다.

```ts
import { getScanScore } from "qrdx";

const { score, grade, checks } = await getScanScore({
  value: "https://example.com",
  bodyPattern: "circle",
  cornerEyePattern: "gear",
});
// score: 0–100, grade: "great" | "ok" | "risky" | "fails"
// checks: [{ id, passed, message, fix? }]
```

확인하는 항목:

- **96, 160, 320 px 너비에서의 디코딩.** 각 너비로 디자인을 렌더링하고 카메라와 비슷한 흐림과 대비 손실을 적용한 뒤, 약간씩 다른 배율로 여러 번 디코딩합니다.
- 모든 코드 색상(그라디언트 정지점, 눈 색상, 점 색상 포함)과 배경 사이의 **대비**, 그리고 코드가 밝은 배경에 어두운 색인지 여부.
- 오류 정정 수준이 복구할 수 있는 범위와 비교한 **로고 점유율**.
- **여백(quiet zone)**: 마진과 프레임이 추가하는 간격.
- **눈 모양 위험**: `circle` 눈은 일부 스캐너 앱에서 인식되지 않을 수 있습니다. (저장된 디자인이 아직 사용 중인 단종된 `curly` 눈은 엄격한 디코더에서 실패합니다.)
- **스타일 조합** (`style-pair`): 디코딩 테스트에서 함께 쓰면 실패하는 모양입니다. 예를 들어 사각 눈 옆의 `small-square` 점, 저장된 디자인에 남아 있는 단종된 중앙 모양이 있습니다 (`getStylePairRisk` 참고).

`getImageScanScore(fileOrImage)`는 기존 이미지에 대해 같은 검사를 수행합니다. 디코딩된 내용과 함께 픽셀에서 측정한 디코딩, 대비, 극성, 여백, 해상도 검사 결과를 반환합니다. [스캔 검사기](/tools/scan-checker)가 이 기능을 기반으로 만들어졌습니다.

<Callout type="info">
  이 점수는 하나의 오픈 소스 디코더를 기반으로 한 휴리스틱입니다. 휴대폰 카메라 앱은 대개 더 너그럽게 인식하므로 참고용으로 사용하고, 중요한 인쇄물은 직접 스캔해 테스트하세요.
</Callout>

## 인쇄용 내보내기 [#print-ready-export]

`downloadPrintPDF`는 정확한 실제 크기의 벡터 PDF를 만듭니다. 모듈, 눈, 프레임은 벡터 경로이고 로고는 래스터 이미지로 유지됩니다.

```ts
import { downloadPrintPDF, downloadPrintSVG, getPrintLayout } from "qrdx";

const props = { value: "https://example.com", frame: { style: "banner-bottom" } } as const;

await downloadPrintPDF(props, {
  size: 40, // width of the code itself
  unit: "mm", // or "in"
  bleed: 3, // millimetres on every side
  cropMarks: true,
  colorMode: "cmyk",
});

await downloadPrintSVG(props, { size: 1.5, unit: "in" }); // width="…in" height="…in"

const layout = getPrintLayout(props, { size: 40 });
layout.trimWidth; // finished width in mm, frame included
layout.maxScanDistance; // 400 (mm)
```

- `size`는 코드의 너비이며, 프레임은 완성된 크기에 더해집니다.
- 블리드를 설정하면 배경(또는 사각형 프레임의 색상)이 재단선 바깥까지 확장되어, 재단 후 흰 틈이 남지 않습니다. 재단 표시는 블리드 바깥에 놓입니다.
- `colorMode: "cmyk"`는 단순 변환을 사용합니다 (`rgbToCmyk`: K = 1 − max(R, G, B), ICC 프로파일 없음, 순수한 검은색은 K만으로 인쇄). 정확한 브랜드 색상이 중요하다면 인쇄소에 색상 관리된 변환을 요청하세요.
- 선형 및 방사형 그라디언트는 PDF에서 부드러운 셰이딩으로 인쇄되며, PDF가 CMYK이면 CMYK로 인쇄됩니다. 인쇄용 SVG는 그라디언트를 유지하지만 RGB로 남습니다.
- PDF의 프레임 텍스트는 Helvetica Bold를 사용하므로 Latin-1 범위 밖의 문자는 표시되지 않을 수 있습니다. 다른 문자 체계에는 SVG를 사용하세요.
- `getQRAsPrintPDF`와 `getQRAsPrintPDFBuffer`는 파일을 다운로드하지 않고 반환하며, Node에서도 작동합니다.

**인쇄 크기:** 코드는 너비의 약 10배 거리에서 스캔되므로, 크기 ≈ 스캔 거리 ÷ 10입니다 (20 cm 거리라면 너비 2 cm). 밀도가 높은 코드는 더 큰 크기가 필요하며, [인쇄 크기 계산기](/tools/print-size)가 이를 반영합니다.
