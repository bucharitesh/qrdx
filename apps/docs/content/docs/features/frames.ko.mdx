"Scan me" 프레임을 추가하고, 배포하기 전에 디자인이 스캔되는지 확인하고, 정확한 실제 크기의 벡터 파일로 내보내 보세요.

## 행동 유도 프레임 [#call-to-action-frames]

QRdx가 그리는 모든 프레임은 프레임 스펙입니다. 도형, 라벨, 색상을 담은 작은 JSON 설명이에요. 하나의 엔진이 모든 스펙을 그리므로 프레임은 SVG, PNG, PDF, EPS에서 모두 똑같이 보입니다. QRdx에는 {facts.frames}개의 프레임이 있습니다. 기본 제공 프레임 {facts.frameStyles}개와 [공식 프레임](#official-frames) {facts.officialFrames}개예요. 직접 만들거나 [커뮤니티](/community/frames)에서 골라 쓸 수도 있습니다.

`frame` prop은 코드 주위에 프레임을 그립니다. `QRCode`, `QRCodeSVG`, `QRCodeCanvas`, `getQRAsSVG`, `getQRData`, 그리고 모든 다운로드 헬퍼에서 동작합니다.

```tsx
import { QRCode } from "qrdx";

<QRCode
  value="https://example.com/menu"
  frame={{ style: "banner-bottom", text: "Scan for the menu", color: "#1e3a8a" }}
/>
```

프레임은 코드 **바깥쪽에** 추가됩니다. 출력 크기가 커질 뿐 QR 모듈과 여백(quiet zone)은 절대 가려지지 않으므로 스캔 가능성은 그대로입니다. 코드 배경색의 밝은 간격이 코드와 프레임을 구분해 줍니다.

### 기본 제공 프레임 [#built-in-frames]

기본 제공 프레임은 `style`로 이름을 지정합니다. 옵션은 스펙의 라벨과 색상을 채웁니다.

| 옵션 | 기본값 | 참고 |
| --- | --- | --- |
| `style` | — | 아래의 기본 제공 프레임 {facts.frameStyles}개 중 하나 또는 `none` (`FRAME_STYLES`) |
| `text` | `"Scan me"` | 최대 24자. 라벨을 숨기려면 `""`를 전달하세요 |
| `color` | `#000000` | 프레임 색상 (`gradient-border`: 시작 색상, 기본값은 보라색) |
| `textColor` | 프레임 위에서는 흰색, 밝은 영역에서는 `color` | 라벨 색상 |
| `secondaryText` | 없음 | 두 번째 라벨, 최대 24자: `banner-top-bottom`의 하단 띠, `circle`의 아래쪽 호, `menu-card`의 푸터 |
| `secondaryColor` | `#db2777` | `gradient-border`의 끝 색상 |
| `fontScale` | `1` | 0.5에서 1.5까지의 라벨 크기. 라벨은 여전히 공간에 맞게 줄어듭니다 |

`style`별 기본 제공 프레임은 다음과 같습니다.

- 배너와 테두리: `banner-bottom`, `banner-top`, `banner-top-bottom`, `border`, `rounded-border`, `gradient-border`, `focus` (모서리 괄호)
- 말풍선: `speech-bubble`, `speech-bubble-top`, `chat-bubble`
- 배지: `circle` (링을 따라 배치된 텍스트), `badge` (리본), `sticker` (그림자가 있는 다이컷)
- 오브젝트: `polaroid`, `phone`, `ticket`, `tag` (구멍이 있는 행택), `envelope`, `menu-card`

이 이름들은 각각 엔진의 스펙을 가리키며, 앞으로도 계속 유효합니다. 이름을 사용하는 저장된 디자인, Image API 링크, CLI 플래그, 코드는 계속 같은 프레임을 그립니다. 테두리처럼 라벨이 없으면 라벨 행을 없애는 프레임은 지금도 그렇게 동작합니다.

`BUILT_IN_FRAMES`는 이름과 스펙을 함께 나열합니다 (`BUILT_IN_FRAME_SPECS`에는 style별 스펙이 있습니다). `frameSpecOf`는 프레임이 그리는 스펙을 반환하고, `getFrameColors`는 프레임이 칠하는 색상을 반환합니다.

```tsx
import { BUILT_IN_FRAMES, frameSpecOf, getFrameColors } from "qrdx";

BUILT_IN_FRAMES.map((frame) => frame.name); // ["Banner", "Top banner", …]

// A built-in style's spec, or a custom frame's own
const ticket = frameSpecOf({ style: "ticket" });

// The frame's options, else its spec's defaults
getFrameColors({ style: "border", color: "#1e3a8a" });
// { frame: "#1e3a8a", text: "#1e3a8a", accent: "#1e3a8a" }
```

라벨과 색상 외에 더 많은 부분을 바꾸려면 기본 제공 스펙에서 커스텀 프레임을 시작하세요. `{ style: "custom", spec: frameSpecOf({ style: "ticket" }) }`는 같은 티켓을 그리며, 도형을 직접 편집할 수 있습니다.

브라우저에서 디코딩된 모든 프레임은 [도형, 눈, 프레임](/docs/styles#frames)에서 볼 수 있습니다. 모든 프레임은 불투명한 색상의 단순한 도형과 텍스트로 이루어져 있어 SVG, PNG, PDF, EPS 내보내기 결과가 일치합니다 (그라데이션 테두리는 가는 단색 단계로 그려지고, circle 프레임의 곡선 글자는 모든 형식에서 회전된 텍스트입니다).

```tsx
<QRCode
  value="https://example.com"
  frame={{ style: "circle", text: "Scan me", secondaryText: "example.com", fontScale: 1.2 }}
/>
```

라벨은 시스템 글꼴 스택을 사용하므로 내려받는 파일이 없습니다. 출력 크기가 커지므로 최종 너비와 높이가 필요하면 `getFrameDimensions(size, frame)`를 사용하세요.

```ts
import { getFrameDimensions } from "qrdx";

getFrameDimensions(400, { style: "banner-bottom" }); // { width: 496, height: 568 }
```

`FRAME_STYLES`, `frameSchema` (zod), `QRFrame` / `FrameStyle` 타입도 서버 측 검증용으로 `qrdx/types`에서 내보내집니다. `GRADIENT_FRAME_DEFAULTS` (그라데이션 테두리의 기본 색상)와 `FRAME_GAP_RATIO`는 이를 사용하던 코드를 위해 계속 내보내집니다. 각 프레임의 간격은 해당 스펙의 패딩입니다 (`getFrameGapRatio`).

### Playground에서 [#in-the-playground]

**Design → Frame**에는 모든 프레임을 위한 선택기가 하나 있어요. **Classic** 그룹에는 기본 제공 프레임이 있으며, 모양 코드, 공식 프레임, 저장한 프레임과 나란히 표시됩니다. 모든 프레임은 같은 방식으로 편집합니다. 라벨, 두 번째 줄, 색상, 텍스트 크기를 바꿀 수 있고, 아이콘이 있는 프레임은 아이콘도 바꿀 수 있어요. 기본 제공 프레임을 사용한 디자인은 `style` 이름을 유지하므로 링크, 이미지 URL, 코드 스니펫이 짧게 유지됩니다.

**Shaped codes** 그룹은 코드 자체를 도형으로 만듭니다. 장식용 점으로 이루어진 원이나 하트, 또는 업로드한 도형이에요 ([`shape`](/docs/features/patterns#circle-codes)). 모양 코드는 프레임을 대신합니다. 모양 코드를 고르면 프레임이 지워지고, 프레임을 고르면 모양이 지워져요.

### CLI에서 [#in-the-cli]

```bash
qrdx generate "https://example.com/menu" --frame banner-bottom --frame-text "Scan for the menu" -o menu.png
```

`--frame-color`와 `--frame-text-color`는 hex 색상을 받습니다. `--frame` 없이 텍스트나 색상을 전달하면 `banner-bottom`을 사용합니다.

### 프레임 스펙 [#frame-specs]

프레임 스펙은 `kind: "qrdx.frame"`, `version: 1`, `artboard` 크기, 코드가 들어가는 `qr` 박스, 기본 `colors`, 코드 뒤에 그려지는 `shapes`, 그리고 `labels`를 가진 JSON입니다. 도형에는 사각형(선택적 구멍 포함), 원과 링, 타원, 다각형, 경로, 선, 기본 제공 아이콘이 있습니다. 도형은 테마 토큰(`frame`, `text`, `accent`, `background`), hex 색상, 두 색의 혼합, 또는 그라데이션으로 채웁니다. 스펙에는 마크업, 링크, 이미지가 들어가지 않습니다. 직접 작성하지 않은 스펙은 저장하기 전에 `qrdx/types`의 `frameSpecSchema` 또는 `getFrameSpecIssues`로 확인하세요. 엔진도 그리기 전에 다시 확인합니다.

기본 제공 프레임과 함께 다음 선택 필드가 추가되었습니다. 이 필드가 없는 스펙은 이전처럼 그려집니다.

| 필드 | 기능 |
| --- | --- |
| `labels[].collapse` | `{ y, height }`. 라벨에 텍스트가 없으면 `y`부터 `y + height`까지의 띠가 잘려 나갑니다. 그 아래 행은 위로 올라가고 아트워크는 더 짧아집니다. 띠 안에 완전히 들어가는 도형은 제외되고, 띠를 가로지르는 도형은 짧아집니다. 띠는 코드, 코드의 패딩, 다른 띠를 가로지를 수 없습니다. |
| `qr.plate` | `"opaque"`(기본값) 또는 `"background"`. 엔진은 코드 아래에 코드 배경색의 플레이트를 칠합니다. 그 배경이 투명하면 `"opaque"`는 플레이트를 칠하고 `background` 채움은 흰색이 되어, 아트워크가 여백 사이로 비치지 않습니다. `"background"`는 이들을 투명하게 유지하고 플레이트를 생략합니다. 플레이트 아래에 `background` 채움만 있거나, 구멍 안에 플레이트가 들어가는 링만 있을 때에만 허용됩니다. |
| `colors.text` | hex 색상, 또는 `frame`, `accent`, `background`, hex 색상의 혼합입니다. 예를 들어 그라데이션 테두리의 라벨에는 `{ "mix": ["frame", "accent"], "amount": 0.5 }`를 씁니다. 기본값이며, `textColor`가 여전히 우선합니다. |

텍스트 라벨의 행은 코드를 침범하지 않고, 가장 큰 텍스트 크기(`fontScale` 1.5)에서 대문자가 패딩 밖에 머문다면 플레이트의 패딩 안까지 들어갈 수도 있습니다. 테두리 프레임은 이 방식으로 라벨을 코드 바로 아래에 둡니다.

qrdx 0.0.51 이하 버전은 이 필드를 사용하거나 라벨 행을 패딩에 두는 스펙을 거부하므로, 그런 스펙을 다른 곳에서 그리기 전에 엔진을 업데이트하세요.

## 공식 프레임 [#official-frames]

기본 제공 프레임 외에도 QRdx에는 공식 프레임 {facts.officialFrames}개가 있습니다. 행동 유도, 레스토랑과 카페, 상점과 패키지, 뷰티와 웰니스, 이벤트와 웨딩, 호텔과 여행, 부동산, 자동차와 주차, 건강과 교육, 스포츠와 피트니스, 비즈니스와 소셜, 비영리 단체와 커뮤니티 그룹을 위한 완성된 디자인이에요. 이 중 {facts.seasonalFrames}개는 음력 설, Holi, Eid, Diwali부터 Hanukkah, 부활절, 추수감사절, 크리스마스에 이르는 명절과 계절용입니다. 각 프레임은 라벨과 색상을 바꿀 수 있는 프레임 스펙이며 CC0로 공개되어 있고, 휴대폰 거리에서 스캔되는지 테스트를 거쳤습니다.

[Playground](/playground)에서 **Frame**을 연 다음 **More**를 여세요. 이름, 용도, 명절로 검색하거나 그룹을 고를 수 있습니다. 다가오는 명절과 계절의 프레임이 먼저 표시됩니다. @qrdx가 게시한 프레임은 [커뮤니티](/community/frames)에서도 볼 수 있어요.

엔진은 이 프레임들을 `OFFICIAL_FRAMES`로 내보냅니다.

```tsx
import { getOfficialFrame, QRCode } from "qrdx";

const diwali = getOfficialFrame("diwali-diya"); // undefined for an unknown id

{diwali && (
  <QRCode
    value="https://example.com/offers"
    frame={{ style: "custom", spec: diwali.spec, text: "Scan for offers" }}
  />
)}
```

`OFFICIAL_FRAME_INDEX`는 스펙 없이 모든 프레임을 나열하므로, 선택기에서 전체 라이브러리를 보여 주고 필요할 때만 스펙을 불러올 수 있습니다. [Image API](/docs/developers/image-api#community-items)와 [MCP 서버](/docs/developers/mcp)에서는 `item=frame:diwali-diya`처럼 공식 프레임을 커뮤니티 항목으로 사용하세요.

## 스캔이 잘 될까요? [#will-it-scan]

`getScanScore`는 디자인이 얼마나 안정적으로 스캔되는지 추정합니다. 브라우저에서 실행되며 필요할 때 [jsQR](https://github.com/cozmo/jsQR)을 불러옵니다.

```ts
import { getScanScore } from "qrdx";

const { score, grade, checks } = await getScanScore({
  value: "https://example.com",
  bodyPattern: "circle",
  cornerEyePattern: "gear",
});
// score: 0–100, grade: "great" | "ok" | "risky" | "fails"
// checks: [{ id, passed, message, fix? }]
```

확인하는 항목은 다음과 같습니다.

- **96px, 160px, 320px에서의 디코딩.** 각 너비로 디자인을 렌더링한 뒤 카메라로 찍은 것처럼 흐림과 대비 손실을 적용하고, 약간씩 다른 배율로 여러 번 디코딩합니다.
- **대비**: 모든 코드 색상(그라디언트 색상 지점, 눈 색상, 점 색상 포함)과 배경 사이의 대비, 그리고 밝은 배경에 어두운 코드인지 여부입니다.
- **로고 면적**: 오류 정정 수준으로 복구할 수 있는 범위와 비교합니다.
- **여백(quiet zone)**: 마진에 프레임이 추가하는 간격을 더한 값입니다.
- **눈 모양 위험도**: `circle` 눈은 일부 스캐너 앱에서 인식되지 않을 수 있습니다. 또한 저장된 디자인이 아직 사용 중이라면, 지원이 중단된 `curly` 눈은 엄격한 디코더에서 실패합니다.
- **스타일 조합** (`style-pair`): 자체 디코딩 테스트에서 함께 쓰면 실패하는 모양 조합입니다. 예를 들어 사각형 눈 옆의 `small-square` 점이나, 저장된 디자인에 남아 있는 지원 중단된 중심 모양이 있습니다(`getStylePairRisk` 참고).

`getImageScanScore(fileOrImage)`는 기존 이미지에 대해 같은 검사를 수행합니다. 디코딩된 내용과 함께, 픽셀에서 측정한 디코딩, 대비, 극성, 여백, 해상도 검사 결과를 반환합니다. [스캔 검사기](/tools/scan-checker)가 이 함수를 기반으로 만들어졌습니다.

<Callout type="info">
  이 점수는 오픈소스 디코더 하나를 기반으로 한 휴리스틱입니다. 휴대폰 카메라 앱은 대개 더 너그럽게 인식하므로 참고용으로 활용하고, 중요한 인쇄물은 직접 스캔해서 테스트하세요.
</Callout>

## 인쇄용 내보내기 [#print-ready-export]

`downloadPrintPDF`는 정확한 실제 크기의 벡터 PDF를 만듭니다. 모듈, 눈, 프레임은 벡터 경로로 출력됩니다(로고는 래스터 이미지로 유지됩니다).

```ts
import { downloadPrintPDF, downloadPrintSVG, getPrintLayout } from "qrdx";

const props = { value: "https://example.com", frame: { style: "banner-bottom" } } as const;

await downloadPrintPDF(props, {
  size: 40, // width of the code itself
  unit: "mm", // or "in"
  bleed: 3, // millimetres on every side
  cropMarks: true,
  colorMode: "cmyk",
});

await downloadPrintSVG(props, { size: 1.5, unit: "in" }); // width="…in" height="…in"

const layout = getPrintLayout(props, { size: 40 });
layout.trimWidth; // finished width in mm, frame included
layout.maxScanDistance; // 400 (mm)
```

- `size`는 코드의 너비입니다. 프레임이 있으면 완성된 크기가 그만큼 커집니다.
- 블리드를 설정하면 배경(또는 사각형 프레임의 색상)이 재단선 밖까지 확장되어, 재단 후에 흰 틈이 남지 않습니다. 재단 표시는 블리드 바깥에 놓입니다.
- `colorMode: "cmyk"`는 단순한 변환(`rgbToCmyk`: K = 1 − max(R, G, B), ICC 프로파일 없음, 순수한 검정은 K 값만으로 인쇄)을 사용합니다. 정확한 브랜드 색상이 중요하다면 인쇄소에 색상 관리 변환을 요청하세요.
- 선형 및 방사형 그라디언트는 PDF에서 부드러운 셰이딩으로 인쇄되며, PDF가 CMYK이면 CMYK로 출력됩니다. 인쇄용 SVG는 그라디언트를 유지하지만 RGB로 남습니다.
- PDF의 프레임 텍스트는 Helvetica Bold를 사용하므로 Latin-1 범위 밖의 문자는 표시되지 않을 수 있습니다. 다른 문자 체계에는 SVG를 사용하세요.
- `getQRAsPrintPDF`와 `getQRAsPrintPDFBuffer`는 파일을 다운로드하지 않고 반환하며, Node에서도 동작합니다.

**인쇄 크기 기준:** 코드는 너비의 약 열 배 거리에서 스캔되므로, 크기 ≈ 스캔 거리 ÷ 10입니다(20cm 거리라면 너비 2cm). 밀도가 높은 코드는 더 큰 크기가 필요하며, [인쇄 크기 계산기](/tools/print-size)가 이를 반영합니다.
