Wrap a QR code in ready-made artwork, or in your own.

## What Are Templates?

A template is SVG artwork drawn around the code: a box, a border, a badge. It gets the code as `children` and places it inside its own drawing. Colors, patterns and logos stay on the `QRCode` props, so a template works with any style.

## Available Templates

### Default
Classic black and white.

```tsx
import { QRCode } from 'qrdx';

<QRCode value="https://example.com" templateId="default" size={256} />
```

### Arrow
Modern geometric design.

```tsx
<QRCode value="https://example.com" templateId="Arrow" size={256} />
```

### Standard Box
Clean, structured design.

```tsx
<QRCode value="https://example.com" templateId="StandardBox" size={256} />
```

### Square Border
Bordered design with defined edges.

```tsx
<QRCode value="https://example.com" templateId="SquareBorder" size={256} />
```

### Striked Box
Dynamic design with diagonal elements.

```tsx
<QRCode value="https://example.com" templateId="StrikedBox" size={256} />
```

### Halloween
Seasonal Halloween theme.

```tsx
<QRCode value="https://example.com" templateId="Halloween" size={256} />
```

### Dot Ring
A round code. The code sits in a disc of dots inside a dark ring, with a line of text set along the ring. Which dots show comes from a hash of the code's content, so every link gets a ring of its own and the same link always gets the same one.

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  bodyPattern="circle-large"
  size={512}
/>
```

Its settings go in `customProps` (typed as `DotRingProps`):

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  customProps={{
    customText: "Scan for the menu",
    textPosition: "bottom",
    textColor: "#fde047",
    outerCircleColor: "#1e3a8a",
  }}
  size={512}
/>
```

| Prop | Default | Notes |
| --- | --- | --- |
| `customText` | "Scan the QR code" four times round | Text along the ring. Letters that don't fit around it are left out; `""` leaves the ring empty |
| `textPosition` | `"top"` | `"top"`: centered over the top, reading clockwise. `"bottom"`: centered along the bottom, reading left to right |
| `textRotation` | `0` | Turns the text around the center, in degrees |
| `textColor` | `#ffffff` | Text color |
| `fontFamily` | system font stack | CSS font family of the text |
| `fontWeight` | `900` | Font weight |
| `fontSize` | `32` | In the template's 593-unit drawing, where the code is 300 across |
| `fontLetterSpacing` | `3.5` | Extra space between letters, in the same units |
| `outerCircleColor` | `fgColor` | Ring color |
| `strokeWidth`, `strokeColor` | `0`, `#000000` | A stroke along both edges of the ring |
| `outerStrokeWidth`, `outerStrokeColor` | `strokeWidth`, `strokeColor` | The ring's outer edge only |
| `innerStrokeWidth`, `innerStrokeColor` | `strokeWidth`, `strokeColor` | The ring's inner edge only |

A logo goes in the middle as on any code. Long links (codes over 49 modules across) keep a light band between the code and the dots, so they still scan when printed small.

The text is SVG text in the font you choose; the default is the system font stack, so nothing is downloaded. SVG and PNG downloads in the browser use the viewer's fonts. PDF and EPS print it in Helvetica Bold, so use Latin-1 text there. `getQRAsPNG` from `qrdx/node` needs a font installed on the server, as frame labels do.

## Customize Templates

The built-in templates draw their artwork in `fgColor`. Everything else, such as patterns and a logo, is set on the code as usual:

```tsx
<QRCode
  value="https://example.com"
  templateId="Arrow"
  fgColor="#1a56db"
  imageSettings={{
    src: "/your-logo.png",
    width: 48,
    height: 48,
    excavate: true,
  }}
  size={512}
/>
```

## Template Registry

### Get All Templates

```tsx
import { getAllTemplates } from 'qrdx';

const templates = getAllTemplates();
```

### Get Template IDs

```tsx
import { getTemplateIds } from 'qrdx';

const ids = getTemplateIds();
// Returns: ['default', 'Arrow', 'StandardBox', ...]
```

## Custom Templates

Write your own template as a `TemplateDefinition`. Its `wrapper` gets the code as `children` and returns the SVG to draw. It draws on a 300 by 300 canvas, and the code arrives at that size too, so scale it down to leave room for your artwork. `props` carries the code's `fgColor` and `bgColor`.

This one draws a ring around the code:

```tsx
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg viewBox="0 0 300 300" width="300" height="300" xmlns="http://www.w3.org/2000/svg">
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

<QRCode
  value="https://example.com"
  customTemplate={ringTemplate}
  fgColor="#1a56db"
  size={256}
/>
```

Keep the code large enough to scan from where people will hold their phones, and leave a light gap between it and your artwork. Check the result with the [scan score](/docs/features/frames#will-it-scan).

## When to Use Templates

- **Brand Consistency** — Ensure all QR codes match
- **Quick Setup** — Get professional results fast
- **Seasonal Campaigns** — Use themed templates
- **Batch Generation** — Apply consistent styles

## Template Selection Guide

| Standard Box | Corporate | Professional |

| Striked Box | Marketing | Energetic |

| Dot Ring | Round codes, posters, stickers | Bold |
