A template is a frame that fits the code inside its own artwork. In the playground templates aren't a separate list. Arrow, Standard Box, Square Border, Striked Box, Halloween and Dot Ring are tiles in the frame picker's **Classic** group, next to the other [frames](/docs/features/frames), and picking any frame replaces the one before.

Templates differ from the other frames in one way: size. A frame adds space around the code, so `size` is the code's width and the image grows. A template draws its whole artwork at `size`, with the code smaller inside it.

## Built-in templates

Pass the id as `templateId`. The image API takes it as `template` and the CLI as `--template`.

| `templateId` | Name | Color |
|--------------|------|-------|
| `Arrow` | Arrow | The code's dark color (`fgColor`) |
| `StandardBox` | Standard Box | `fgColor` |
| `SquareBorder` | Square Border | `fgColor` |
| `StrikedBox` | Striked Box | Its own dark color |
| `Halloween` | Halloween | Its own orange, green and black |
| `DotRing` | Dot Ring | Its ring in `fgColor`, its text in white; both can change (below) |

`default` draws no artwork. It only insets the code a little, to 95% of `size`.

```tsx
import { QRCode } from 'qrdx';

<QRCode value="https://example.com" templateId="Arrow" fgColor="#1a56db" size={256} />
```

Colors, patterns and a logo stay on the code's own props, so a template works with any style:

```tsx
<QRCode
  value="https://example.com"
  templateId="StandardBox"
  fgColor="#1a56db"
  imageSettings={{
    src: "/your-logo.png",
    width: 48,
    height: 48,
    excavate: true,
  }}
  size={512}
/>
```

## Dot Ring

A round code. The code sits in a disc of dots inside a dark ring, with a line of text set along the ring. Which dots show comes from a hash of the code's content, so every link gets a ring of its own and the same link always gets the same one.

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  bodyPattern="circle-large"
  size={512}
/>
```

Its settings go in `customProps` (typed as `DotRingProps`):

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  customProps={{
    customText: "Scan for the menu",
    textPosition: "bottom",
    textColor: "#fde047",
    outerCircleColor: "#1e3a8a",
  }}
  size={512}
/>
```

| Prop | Default | Notes |
| --- | --- | --- |
| `customText` | "Scan the QR code" four times round | Text along the ring; `""` leaves the ring empty. Text too long for the ring is fitted (below) |
| `textFill` | `"none"` | `"repeat"` repeats the text round the whole ring (below) |
| `textPosition` | `"top"` | `"top"`: centered over the top, reading clockwise. `"bottom"`: centered along the bottom, reading left to right |
| `textRotation` | `0` | Turns the text around the center, in degrees |
| `textColor` | `#ffffff` | Text color |
| `fontFamily` | system font stack | CSS font family of the text |
| `fontWeight` | `900` | Font weight |
| `fontSize` | `32` | In the template's 593-unit drawing, where the code is 300 across. Long text may be drawn smaller |
| `fontLetterSpacing` | `3.5` | Extra space between letters, in the same units. Long text and `textFill` adjust it |
| `outerCircleColor` | `fgColor` | Ring color |
| `strokeWidth`, `strokeColor` | `0`, `#000000` | A stroke along both edges of the ring |
| `outerStrokeWidth`, `outerStrokeColor` | `strokeWidth`, `strokeColor` | The ring's outer edge only |
| `innerStrokeWidth`, `innerStrokeColor` | `strokeWidth`, `strokeColor` | The ring's inner edge only |

Text that fits the ring is set as given, centered over the top or along the bottom. Text too long for it never runs into its own start. The letters move closer first, then the font gets smaller, down to half the default size (the smallest frame labels get). The text then closes the ring with a word space where it meets its start. If it still doesn't fit at that size, it's cut after the last whole word that does.

A logo goes in the middle as on any code. Long links (codes over 49 modules across) keep a light band between the code and the dots, so they still scan when printed small.

The text is SVG text in the font you choose; the default is the system font stack, so nothing is downloaded. SVG and PNG downloads in the browser use the viewer's fonts. PDF and EPS print it in Helvetica Bold, so use Latin-1 text there. `getQRAsPNG` from `qrdx/node` needs a font installed on the server, as frame labels do.

### Filling the ring

A short phrase leaves part of the ring empty. Set `textFill: "repeat"` to repeat it as many times as fit, with the spacing evened out so the ring closes with the same gap as between the copies:

```tsx
<QRCode
  value="https://example.com/docs"
  templateId="DotRing"
  customProps={{ customText: "Read the docs *", textFill: "repeat" }}
  size={512}
/>
```

Give the phrase once. Text that already repeats a phrase, like `"Make your own * Make your own *"`, is read as that phrase, so it fills the ring the same way.

## Templates are frame specs

The artwork of Arrow, Standard Box, Square Border, Striked Box and Halloween is a [frame spec](/docs/features/frames#frame-specs), the same JSON format as every other frame, drawn by the same engine. `getTemplate(id).spec` returns it. Use it as a frame when you want frame sizing (the code keeps its size and the artwork grows around it) and the frame's color option:

```tsx
import { getTemplate, QRCode } from 'qrdx';

const spec = getTemplate('Arrow')?.spec;

<QRCode
  value="https://example.com"
  frame={spec && { style: 'custom', spec, color: '#1a56db' }}
  size={256}
/>
```

Dot Ring has no spec: its dots come from the code's content, so it draws them in code (see [Frames you draw in code](#frames-you-draw-in-code)).

`templateId` draws the same artwork as before. Saved designs, image URLs, CLI commands and code that use a template id look the same as they always have.

## Template registry

```tsx
import { getAllTemplates, getTemplate, getTemplateIds } from 'qrdx';

getTemplateIds(); // ['default', 'Arrow', 'StandardBox', ...]
getAllTemplates(); // every TemplateDefinition, with its id and name
getTemplate('Halloween'); // one by id
```

## Frames you draw in code

A frame spec describes fixed artwork. When the artwork has to be computed, write a `TemplateDefinition` and pass it as `customTemplate`. Its `wrapper` gets the code as `children` and returns the SVG to draw. It draws on a 300 by 300 canvas, and the code arrives at that size too, so scale it down to leave room for your artwork. `props` carries the code's `fgColor` and `bgColor`, and the third argument has the code's `url` and `pixelSize`.

This one draws a ring around the code:

```tsx
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg viewBox="0 0 300 300" width="300" height="300" xmlns="http://www.w3.org/2000/svg">
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

<QRCode
  value="https://example.com"
  customTemplate={ringTemplate}
  fgColor="#1a56db"
  size={256}
/>
```

Keep the code large enough to scan from where people will hold their phones, and leave a light gap between it and your artwork. Check the result with the [scan score](/docs/features/frames#will-it-scan).
