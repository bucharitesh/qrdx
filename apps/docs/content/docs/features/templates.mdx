Wrap a QR code in ready-made artwork, or in your own.

## What Are Templates?

A template is SVG artwork drawn around the code: a box, a border, a badge. It gets the code as `children` and places it inside its own drawing. Colors, patterns and logos stay on the `QRCode` props, so a template works with any style.

## Available Templates

### Default
Classic black and white.

```tsx
import { QRCode } from 'qrdx';

<QRCode value="https://example.com" templateId="default" size={256} />
```

### Arrow
Modern geometric design.

```tsx
<QRCode value="https://example.com" templateId="Arrow" size={256} />
```

### Standard Box
Clean, structured design.

```tsx
<QRCode value="https://example.com" templateId="StandardBox" size={256} />
```

### Square Border
Bordered design with defined edges.

```tsx
<QRCode value="https://example.com" templateId="SquareBorder" size={256} />
```

### Striked Box
Dynamic design with diagonal elements.

```tsx
<QRCode value="https://example.com" templateId="StrikedBox" size={256} />
```

### Halloween
Seasonal Halloween theme.

```tsx
<QRCode value="https://example.com" templateId="Halloween" size={256} />
```

## Customize Templates

The built-in templates draw their artwork in `fgColor`. Everything else, such as patterns and a logo, is set on the code as usual:

```tsx
<QRCode
  value="https://example.com"
  templateId="Arrow"
  fgColor="#1a56db"
  imageSettings={{
    src: "/your-logo.png",
    width: 48,
    height: 48,
    excavate: true,
  }}
  size={512}
/>
```

## Template Registry

### Get All Templates

```tsx
import { getAllTemplates } from 'qrdx';

const templates = getAllTemplates();
```

### Get Template IDs

```tsx
import { getTemplateIds } from 'qrdx';

const ids = getTemplateIds();
// Returns: ['default', 'Arrow', 'StandardBox', ...]
```

## Custom Templates

Write your own template as a `TemplateDefinition`. Its `wrapper` gets the code as `children` and returns the SVG to draw. It draws on a 300 by 300 canvas, and the code arrives at that size too, so scale it down to leave room for your artwork. `props` carries the code's `fgColor` and `bgColor`.

This one draws a ring around the code:

```tsx
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg viewBox="0 0 300 300" width="300" height="300" xmlns="http://www.w3.org/2000/svg">
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

<QRCode
  value="https://example.com"
  customTemplate={ringTemplate}
  fgColor="#1a56db"
  size={256}
/>
```

Keep the code large enough to scan from where people will hold their phones, and leave a light gap between it and your artwork. Check the result with the [scan score](/docs/features/frames#will-it-scan).

## When to Use Templates

- **Brand Consistency** — Ensure all QR codes match
- **Quick Setup** — Get professional results fast
- **Seasonal Campaigns** — Use themed templates
- **Batch Generation** — Apply consistent styles
