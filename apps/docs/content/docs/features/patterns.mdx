# Patterns

Change the shape of QR code elements for unique designs.

## Body Patterns

Control the shape of data dots. There are 9 body patterns: `circle` (default), `circle-large`, `square`, `diamond`, `circle-mixed`, `pacman`, `rounded`, `small-square` and `vertical-line`.

```tsx
import { QRCode } from 'qrdx';

<QRCode value="https://example.com" bodyPattern="circle" size={256} />
<QRCode value="https://example.com" bodyPattern="diamond" size={256} />
<QRCode value="https://example.com" bodyPattern="vertical-line" size={256} />
```

## Corner Eye Patterns

Control the shape of corner markers. There are 9 corner eye patterns (the React component defaults to `gear`; the CLI defaults to `square`): `square`, `rounded`, `gear`, `circle`, `diya`, `extra-rounded`, `message`, `pointy` and `curly`.

```tsx
<QRCode value="https://example.com" cornerEyePattern="square" />
<QRCode value="https://example.com" cornerEyePattern="gear" />
<QRCode value="https://example.com" cornerEyePattern="extra-rounded" />
```

## Corner Eye Dot Patterns

Control the dot inside each corner marker. There are 11 corner eye dot patterns (the React component defaults to `circle`; the CLI defaults to `square`): `square`, `rounded`, `circle`, `diamond`, `message`, `message-reverse`, `diya`, `diya-reverse`, `rounded-triangle`, `star` and `banner`.

```tsx
<QRCode value="https://example.com" cornerEyeDotPattern="square" />
<QRCode value="https://example.com" cornerEyeDotPattern="star" />
<QRCode value="https://example.com" cornerEyeDotPattern="rounded-triangle" />
```

## Combine Patterns

Mix different patterns for unique designs:

```tsx
<QRCode
  value="https://example.com"
  bodyPattern="rounded"
  cornerEyePattern="circle"
  cornerEyeDotPattern="circle"
  size={256}
/>
```

## Performance

### Fast Patterns
- `circle` — Excellent performance
- `square` — Very fast

### Medium Patterns
- `rounded` — Good balance
- `diamond` — Moderate

### Complex Patterns
- `pacman` — Higher processing
- `circle-mixed` — Variable complexity

## Pattern Selection

### For Brand Identity
```tsx
// Minimal, professional
<QRCode
  value="https://example.com"
  bodyPattern="rounded"
  cornerEyePattern="square"
/>

// Modern, tech-focused
<QRCode
  value="https://example.com"
  bodyPattern="circle"
  cornerEyePattern="rounded"
/>
```

### For Marketing
```tsx
// Eye-catching
<QRCode
  value="https://example.com"
  bodyPattern="pacman"
  cornerEyePattern="circle"
/>

// Elegant
<QRCode
  value="https://example.com"
  bodyPattern="diamond"
  cornerEyePattern="rounded"
/>
```

### For Print
```tsx
// High contrast
<QRCode
  value="https://example.com"
  bodyPattern="square"
  cornerEyePattern="square"
/>

// Smooth, professional
<QRCode
  value="https://example.com"
  bodyPattern="rounded"
  cornerEyePattern="rounded"
/>
```
