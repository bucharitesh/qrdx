"Scan me" फ़्रेम जोड़ें, डिज़ाइन को इस्तेमाल में लाने से पहले जाँचें कि वह स्कैन होता है या नहीं, और एक सटीक भौतिक साइज़ पर वेक्टर फ़ाइल एक्सपोर्ट करें।

## कॉल-टू-एक्शन फ़्रेम [#call-to-action-frames]

`frame` prop कोड के चारों ओर एक छोटे लेबल वाला फ़्रेम बनाता है। यह `QRCode`, `QRCodeSVG`, `QRCodeCanvas`, `getQRAsSVG`, `getQRData` और सभी डाउनलोड helpers पर काम करता है।

```tsx
import { QRCode } from "qrdx";

<QRCode
  value="https://example.com/menu"
  frame={{ style: "banner-bottom", text: "Scan for the menu", color: "#1e3a8a" }}
/>
```

फ़्रेम कोड के **चारों ओर** जोड़ा जाता है: आउटपुट बड़ा हो जाता है, और QR मॉड्यूल व quiet zone कभी ढके नहीं जाते, इसलिए स्कैन करने की क्षमता वैसी ही रहती है। कोड के बैकग्राउंड रंग का एक हल्का गैप कोड को फ़्रेम से अलग करता है।

| विकल्प | डिफ़ॉल्ट | नोट्स |
| --- | --- | --- |
| `style` | — | नीचे दिए गए {facts.frameStyles} स्टाइल में से एक, या `none` (`FRAME_STYLES`) |
| `text` | `"Scan me"` | अधिकतम 24 अक्षर। लेबल छिपाने के लिए `""` दें |
| `color` | `#000000` | फ़्रेम का रंग (`gradient-border`: शुरुआती रंग, डिफ़ॉल्ट बैंगनी) |
| `textColor` | फ़्रेम पर सफ़ेद, हल्के हिस्सों पर `color` | लेबल का रंग |
| `secondaryText` | कोई नहीं | दूसरा लेबल, अधिकतम 24 अक्षर: `banner-top-bottom` का निचला बैंड, `circle` का निचला आर्क, `menu-card` का फ़ुटर |
| `secondaryColor` | `#db2777` | `gradient-border` का अंतिम रंग |
| `fontScale` | `1` | 0.5 से 1.5 तक लेबल का साइज़; लेबल फिर भी जगह में फ़िट होने के लिए छोटे हो जाते हैं |

स्टाइल:

- बैनर और बॉर्डर: `banner-bottom`, `banner-top`, `banner-top-bottom`, `border`, `rounded-border`, `gradient-border`, `focus` (कोनों के ब्रैकेट)
- बबल: `speech-bubble`, `speech-bubble-top`, `chat-bubble`
- बैज: `circle` (रिंग के चारों ओर लगा टेक्स्ट), `badge` (रिबन), `sticker` (शैडो वाला डाई-कट)
- ऑब्जेक्ट: `polaroid`, `phone`, `ticket`, `tag` (छेद वाला हैंग टैग), `envelope`, `menu-card`

इन सभी को अपने ब्राउज़र में डिकोड होते हुए [आकार, आँखें और फ़्रेम](/docs/styles#frames) में देखें। हर फ़्रेम सादे आकारों और अपारदर्शी रंगों वाले टेक्स्ट से बना है, इसलिए SVG, PNG, PDF और EPS एक्सपोर्ट एक जैसे दिखते हैं (ग्रेडिएंट बॉर्डर बारीक ठोस रंग के चरणों से बनाया जाता है, और circle फ़्रेम के घुमावदार अक्षर हर फ़ॉर्मैट में घुमाया हुआ टेक्स्ट होते हैं)।

```tsx
<QRCode
  value="https://example.com"
  frame={{ style: "circle", text: "Scan me", secondaryText: "example.com", fontScale: 1.2 }}
/>
```

लेबल सिस्टम फ़ॉन्ट स्टैक इस्तेमाल करता है, इसलिए कुछ भी डाउनलोड नहीं होता। आउटपुट बड़ा हो जाता है, इसलिए अंतिम चौड़ाई और ऊँचाई चाहिए हो तो `getFrameDimensions(size, frame)` इस्तेमाल करें:

```ts
import { getFrameDimensions } from "qrdx";

getFrameDimensions(400, { style: "banner-bottom" }); // { width: 496, height: 568 }
```

`FRAME_STYLES`, `frameSchema` (zod) और `QRFrame` / `FrameStyle` टाइप सर्वर-साइड वैलिडेशन के लिए `qrdx/types` से भी एक्सपोर्ट होते हैं।

### CLI में [#in-the-cli]

```bash
qrdx generate "https://example.com/menu" --frame banner-bottom --frame-text "Scan for the menu" -o menu.png
```

`--frame-color` और `--frame-text-color` hex रंग लेते हैं। `--frame` के बिना टेक्स्ट या रंग देने पर `banner-bottom` इस्तेमाल होता है।

## आधिकारिक फ़्रेम [#official-frames]

बिल्ट-इन स्टाइल के अलावा, QRdx में {facts.officialFrames} आधिकारिक फ़्रेम हैं: कॉल टू एक्शन, रेस्टोरेंट और कैफ़े, दुकानों और पैकेजिंग, इवेंट और शादियों, होटल, यात्रा और रियल एस्टेट, स्वास्थ्य, फ़िटनेस और शिक्षा, और बिज़नेस व सोशल के लिए तैयार डिज़ाइन। इनमें से {facts.seasonalFrames} त्योहारों और मौसमों के लिए हैं, जैसे Lunar New Year, होली, ईद और दिवाली से लेकर Hanukkah, Easter, Thanksgiving और क्रिसमस तक। हर एक लेबल और रंगों वाला एक फ़्रेम स्पेक है जिसे आप बदल सकते हैं, यह CC0 के तहत जारी किया गया है, और हर एक का फ़ोन की दूरी पर स्कैन होने के लिए परीक्षण किया गया है।

[playground](/playground) में **Frame** और फिर **More** खोलें। नाम, उपयोग या त्योहार से खोजें, या कोई ग्रुप चुनें। आने वाले त्योहारों और मौसमों के फ़्रेम सबसे पहले दिखते हैं। ये आपको [कम्युनिटी](/community/frames) में भी मिलेंगे, जिन्हें @qrdx ने पब्लिश किया है।

इंजन इन्हें `OFFICIAL_FRAMES` के रूप में एक्सपोर्ट करता है:

```tsx
import { getOfficialFrame, QRCode } from "qrdx";

const diwali = getOfficialFrame("diwali-diya"); // undefined for an unknown id

{diwali && (
  <QRCode
    value="https://example.com/offers"
    frame={{ style: "custom", spec: diwali.spec, text: "Scan for offers" }}
  />
)}
```

`OFFICIAL_FRAME_INDEX` हर फ़्रेम को उसके स्पेक के बिना सूचीबद्ध करता है, ताकि picker पूरी लाइब्रेरी दिखा सके और स्पेक सिर्फ़ ज़रूरत पड़ने पर लोड करे। [image API](/docs/developers/image-api#community-items) और [MCP सर्वर](/docs/developers/mcp) में, किसी आधिकारिक फ़्रेम को कम्युनिटी आइटम की तरह इस्तेमाल करें, जैसे `item=frame:diwali-diya`।

## क्या यह स्कैन होगा? [#will-it-scan]

`getScanScore` अनुमान लगाता है कि कोई डिज़ाइन कितनी भरोसेमंद तरीके से स्कैन होता है। यह ब्राउज़र में चलता है और ज़रूरत पड़ने पर [jsQR](https://github.com/cozmo/jsQR) लोड करता है।

```ts
import { getScanScore } from "qrdx";

const { score, grade, checks } = await getScanScore({
  value: "https://example.com",
  bodyPattern: "circle",
  cornerEyePattern: "gear",
});
// score: 0–100, grade: "great" | "ok" | "risky" | "fails"
// checks: [{ id, passed, message, fix? }]
```

यह क्या जाँचता है:

- **96, 160 और 320 px पर डिकोडिंग।** डिज़ाइन को हर चौड़ाई पर रेंडर किया जाता है, उसमें कैमरे जैसा ब्लर और कंट्रास्ट की कमी जोड़ी जाती है, और थोड़े अलग स्केल पर कई बार डिकोड किया जाता है।
- **कंट्रास्ट** कोड के हर रंग (ग्रेडिएंट स्टॉप, आँख और डॉट के रंग समेत) और बैकग्राउंड के बीच, और क्या कोड हल्के पर गहरा है।
- **लोगो कवरेज**, इस तुलना में कि error-correction लेवल कितना ठीक कर सकता है।
- **Quiet zone**: मार्जिन, साथ ही फ़्रेम से जुड़ा गैप।
- **आँख के आकार का जोखिम**: `circle` आँखें कुछ स्कैनर ऐप्स से छूट सकती हैं (और बंद की जा चुकी `curly` आँखें, अगर कोई सेव किया डिज़ाइन अब भी उन्हें इस्तेमाल करता है, सख़्त डिकोडर में फ़ेल हो जाती हैं)।
- **स्टाइल जोड़ियाँ** (`style-pair`): ऐसे आकार जो हमारे डिकोड टेस्ट में साथ में फ़ेल होते हैं, जैसे चौकोर आँखों के बगल में `small-square` डॉट, और सेव किए डिज़ाइनों में बंद किए जा चुके centers (देखें `getStylePairRisk`)।

`getImageScanScore(fileOrImage)` किसी मौजूदा इमेज के लिए यही करता है: यह डिकोड की गई सामग्री के साथ पिक्सल से मापे गए डिकोड, कंट्रास्ट, polarity, quiet-zone और रेज़ोल्यूशन जाँच लौटाता है। [स्कैन चेकर](/tools/scan-checker) इसी पर बना है।

<Callout type="info">
  यह स्कोर एक ओपन-सोर्स डिकोडर पर बना अनुमान (heuristic) है। फ़ोन के कैमरा ऐप अक्सर ज़्यादा लचीले होते हैं, इसलिए इसे एक गाइड मानें और ज़रूरी प्रिंट को टेस्ट-स्कैन करें।
</Callout>

## प्रिंट के लिए तैयार एक्सपोर्ट [#print-ready-export]

`downloadPrintPDF` एक सटीक भौतिक साइज़ पर वेक्टर PDF लिखता है। मॉड्यूल, आँखें और फ़्रेम वेक्टर पाथ हैं (लोगो रैस्टर इमेज ही रहता है)।

```ts
import { downloadPrintPDF, downloadPrintSVG, getPrintLayout } from "qrdx";

const props = { value: "https://example.com", frame: { style: "banner-bottom" } } as const;

await downloadPrintPDF(props, {
  size: 40, // width of the code itself
  unit: "mm", // or "in"
  bleed: 3, // millimetres on every side
  cropMarks: true,
  colorMode: "cmyk",
});

await downloadPrintSVG(props, { size: 1.5, unit: "in" }); // width="…in" height="…in"

const layout = getPrintLayout(props, { size: 40 });
layout.trimWidth; // finished width in mm, frame included
layout.maxScanDistance; // 400 (mm)
```

- `size` कोड की चौड़ाई है; फ़्रेम तैयार साइज़ में जुड़ता है।
- ब्लीड के साथ, बैकग्राउंड (या चौकोर फ़्रेम का रंग) trim किनारे से आगे तक फैलता है, ताकि काटने पर सफ़ेद पट्टी न दिखे। क्रॉप मार्क ब्लीड के बाहर होते हैं।
- `colorMode: "cmyk"` एक सरल कन्वर्शन इस्तेमाल करता है (`rgbToCmyk`: K = 1 − max(R, G, B), कोई ICC प्रोफ़ाइल नहीं; शुद्ध काला केवल K से प्रिंट होता है)। जब सटीक ब्रांड रंग मायने रखें, तो अपने प्रिंटर से कलर-मैनेज्ड कन्वर्शन माँगें।
- लीनियर और रेडियल ग्रेडिएंट PDF में स्मूद शेडिंग के रूप में प्रिंट होते हैं, PDF के CMYK होने पर CMYK में; प्रिंट SVG उन्हें रखता है लेकिन RGB ही रहता है।
- PDF में फ़्रेम टेक्स्ट Helvetica Bold इस्तेमाल करता है, इसलिए Latin-1 के बाहर के अक्षर रेंडर न हो सकते हैं। दूसरी लिपियों के लिए SVG इस्तेमाल करें।
- `getQRAsPrintPDF` और `getQRAsPrintPDFBuffer` फ़ाइल को डाउनलोड करने के बजाय लौटाते हैं, और Node में भी काम करते हैं।

**कितना बड़ा प्रिंट करें:** कोड अपनी चौड़ाई के लगभग दस गुना दूरी से स्कैन होता है, इसलिए साइज़ ≈ स्कैन दूरी ÷ 10 (20 cm के लिए 2 cm चौड़ा)। ज़्यादा घने कोड को ज़्यादा चाहिए; [प्रिंट साइज़ कैलकुलेटर](/tools/print-size) इसका हिसाब रखता है।
