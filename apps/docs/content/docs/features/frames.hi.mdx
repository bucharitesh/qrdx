"Scan me" फ़्रेम जोड़ें, डिज़ाइन को शिप करने से पहले जाँचें कि वह स्कैन होता है, और एक सटीक भौतिक साइज़ पर वेक्टर फ़ाइल एक्सपोर्ट करें।

## कॉल-टू-एक्शन फ़्रेम [#call-to-action-frames]

QRdx जो भी फ़्रेम बनाता है, वह एक फ़्रेम स्पेक होता है: आकारों, लेबल और रंगों का छोटा-सा JSON विवरण। हर स्पेक को एक ही इंजन बनाता है, इसलिए फ़्रेम SVG, PNG, PDF और EPS में एक जैसा दिखता है। QRdx में {facts.frames} फ़्रेम हैं: {facts.frameStyles} बिल्ट-इन फ़्रेम और {facts.officialFrames} [आधिकारिक फ़्रेम](#official-frames)। आप अपना फ़्रेम भी बना सकते हैं या [कम्युनिटी](/community/frames) से चुन सकते हैं।

`frame` प्रॉप कोड के चारों ओर फ़्रेम बनाता है। यह `QRCode`, `QRCodeSVG`, `QRCodeCanvas`, `getQRAsSVG`, `getQRData` और सभी डाउनलोड हेल्पर पर काम करता है।

```tsx
import { QRCode } from "qrdx";

<QRCode
  value="https://example.com/menu"
  frame={{ style: "banner-bottom", text: "Scan for the menu", color: "#1e3a8a" }}
/>
```

फ़्रेम कोड के **चारों ओर** जोड़ा जाता है: आउटपुट बड़ा हो जाता है, और QR मॉड्यूल और क्वाइट ज़ोन कभी नहीं ढकते, इसलिए स्कैन होने की क्षमता वैसी ही रहती है। कोड के बैकग्राउंड रंग की एक हल्की खाली पट्टी कोड को फ़्रेम से अलग करती है।

### बिल्ट-इन फ़्रेम [#built-in-frames]

बिल्ट-इन फ़्रेम का नाम उसकी `style` से तय होता है। विकल्प उसके स्पेक के लेबल और रंग भरते हैं:

| विकल्प | डिफ़ॉल्ट | नोट्स |
| --- | --- | --- |
| `style` | — | नीचे दिए {facts.frameStyles} बिल्ट-इन फ़्रेम में से एक, या `none` (`FRAME_STYLES`) |
| `text` | `"Scan me"` | अधिकतम 24 अक्षर। लेबल छिपाने के लिए `""` दें |
| `color` | `#000000` | फ़्रेम का रंग (`gradient-border`: शुरुआती रंग, डिफ़ॉल्ट वायलेट) |
| `textColor` | फ़्रेम पर सफ़ेद, हल्के हिस्सों पर `color` | लेबल का रंग |
| `secondaryText` | कोई नहीं | दूसरा लेबल, अधिकतम 24 अक्षर: `banner-top-bottom` की निचली पट्टी, `circle` का निचला आर्क, `menu-card` का फ़ुटर |
| `secondaryColor` | `#db2777` | `gradient-border` का अंतिम रंग |
| `fontScale` | `1` | लेबल का साइज़ 0.5 से 1.5 तक; लेबल फिर भी फ़िट होने के लिए छोटे हो जाते हैं |

`style` के अनुसार बिल्ट-इन फ़्रेम:

- बैनर और बॉर्डर: `banner-bottom`, `banner-top`, `banner-top-bottom`, `border`, `rounded-border`, `gradient-border`, `focus` (कोने के ब्रैकेट)
- बबल: `speech-bubble`, `speech-bubble-top`, `chat-bubble`
- बैज: `circle` (रिंग के चारों ओर लिखा टेक्स्ट), `badge` (रिबन), `sticker` (शैडो के साथ डाई-कट)
- ऑब्जेक्ट: `polaroid`, `phone`, `ticket`, `tag` (छेद वाला हैंग टैग), `envelope`, `menu-card`

इनमें से हर नाम इंजन में एक स्पेक का प्रतिनिधित्व करता है, और ये नाम हमेशा के लिए मान्य रहते हैं। इन्हें इस्तेमाल करने वाले सेव किए डिज़ाइन, इमेज API लिंक, CLI फ़्लैग और कोड वही फ़्रेम बनाते रहते हैं। जो फ़्रेम लेबल न होने पर उसकी पंक्ति हटा देते हैं, जैसे बॉर्डर, वे अब भी ऐसा करते हैं।

`BUILT_IN_FRAMES` इन्हें उनके नामों और स्पेक के साथ सूचीबद्ध करता है (`BUILT_IN_FRAME_SPECS` में style के अनुसार स्पेक हैं)। `frameSpecOf` किसी भी फ़्रेम का स्पेक लौटाता है, और `getFrameColors` वे रंग जिनसे वह पेंट होता है:

```tsx
import { BUILT_IN_FRAMES, frameSpecOf, getFrameColors } from "qrdx";

BUILT_IN_FRAMES.map((frame) => frame.name); // ["Banner", "Top banner", …]

// A built-in style's spec, or a custom frame's own
const ticket = frameSpecOf({ style: "ticket" });

// The frame's options, else its spec's defaults
getFrameColors({ style: "border", color: "#1e3a8a" });
// { frame: "#1e3a8a", text: "#1e3a8a", accent: "#1e3a8a" }
```

लेबल और रंगों से ज़्यादा बदलने के लिए, बिल्ट-इन स्पेक से कस्टम फ़्रेम शुरू करें: `{ style: "custom", spec: frameSpecOf({ style: "ticket" }) }` वही टिकट बनाता है, और आप उसके आकार एडिट कर सकते हैं।

इन सभी को अपने ब्राउज़र में डिकोड होते हुए [आकार, आँखें और फ़्रेम](/docs/styles#frames) में देखें। हर फ़्रेम सादे आकारों और ठोस रंगों वाले टेक्स्ट से बना है, इसलिए SVG, PNG, PDF और EPS एक्सपोर्ट एक जैसे होते हैं (ग्रेडिएंट बॉर्डर बारीक ठोस रंग के चरणों से बनता है, और सर्कल फ़्रेम के मुड़े हुए अक्षर हर फ़ॉर्मैट में घुमाया हुआ टेक्स्ट होते हैं)।

```tsx
<QRCode
  value="https://example.com"
  frame={{ style: "circle", text: "Scan me", secondaryText: "example.com", fontScale: 1.2 }}
/>
```

लेबल सिस्टम फ़ॉन्ट स्टैक इस्तेमाल करता है, इसलिए कुछ डाउनलोड नहीं होता। क्योंकि आउटपुट बड़ा हो जाता है, अंतिम चौड़ाई और ऊँचाई चाहिए तो `getFrameDimensions(size, frame)` इस्तेमाल करें:

```ts
import { getFrameDimensions } from "qrdx";

getFrameDimensions(400, { style: "banner-bottom" }); // { width: 496, height: 568 }
```

`FRAME_STYLES`, `frameSchema` (zod) और `QRFrame` / `FrameStyle` टाइप सर्वर-साइड वैलिडेशन के लिए `qrdx/types` से भी एक्सपोर्ट होते हैं। `GRADIENT_FRAME_DEFAULTS` (ग्रेडिएंट बॉर्डर के डिफ़ॉल्ट रंग) और `FRAME_GAP_RATIO` उस कोड के लिए अब भी एक्सपोर्ट होते हैं जो इन्हें इस्तेमाल करता था; हर फ़्रेम की अपनी खाली जगह उसके स्पेक की पैडिंग है (`getFrameGapRatio`)।

### प्लेग्राउंड में [#in-the-playground]

**Design → Frame** में हर फ़्रेम के लिए एक ही पिकर है। **Classic** समूह में बिल्ट-इन फ़्रेम हैं, जिनके साथ शेप्ड कोड, आधिकारिक फ़्रेम और आपके सेव किए फ़्रेम हैं। हर फ़्रेम एक ही तरह से एडिट होता है: उसका लेबल, दूसरी पंक्ति, रंग और टेक्स्ट साइज़, और जिन फ़्रेम में आइकन हैं उनके आइकन। बिल्ट-इन फ़्रेम वाला डिज़ाइन अपना `style` नाम रखता है, इसलिए लिंक, इमेज URL और कोड स्निपेट छोटे रहते हैं।

**Shaped codes** समूह कोड को ही एक आकार में ढाल देता है: सजावटी बिंदुओं का सर्कल या दिल, या आपका अपलोड किया आकार ([`shape`](/docs/features/patterns#circle-codes))। शेप्ड कोड फ़्रेम की जगह लेता है: एक चुनने पर फ़्रेम हट जाता है, और फ़्रेम चुनने पर आकार हट जाता है।

### CLI में [#in-the-cli]

```bash
qrdx generate "https://example.com/menu" --frame banner-bottom --frame-text "Scan for the menu" -o menu.png
```

`--frame-color` और `--frame-text-color` हेक्स रंग लेते हैं। `--frame` के बिना टेक्स्ट या रंग देने पर `banner-bottom` इस्तेमाल होता है।

### फ़्रेम स्पेक [#frame-specs]

फ़्रेम स्पेक एक JSON है जिसमें `kind: "qrdx.frame"`, `version: 1`, एक `artboard` साइज़, एक `qr` बॉक्स जहाँ कोड रखा जाता है, डिफ़ॉल्ट `colors`, कोड के पीछे पेंट होने वाले `shapes` और `labels` होते हैं। शेप्स हैं: रेक्ट (वैकल्पिक छेद के साथ), सर्कल और रिंग, इलिप्स, पॉलीगॉन, पाथ, लाइन और बिल्ट-इन आइकन। इन्हें थीम टोकन (`frame`, `text`, `accent`, `background`), हेक्स रंग, दो रंगों के मिश्रण या ग्रेडिएंट से भरा जाता है। स्पेक में कोई मार्कअप, लिंक या इमेज नहीं होती। जो स्पेक आपने खुद नहीं लिखा, उसे स्टोर करने से पहले `qrdx/types` के `frameSpecSchema` या `getFrameSpecIssues` से जाँचें। इंजन बनाने से पहले उसे फिर जाँचता है।

बिल्ट-इन फ़्रेम ने ये वैकल्पिक फ़ील्ड जोड़े। इनके बिना स्पेक पहले की तरह बनते हैं:

| फ़ील्ड | क्या करता है |
| --- | --- |
| `labels[].collapse` | `{ y, height }`। जब लेबल में कोई टेक्स्ट नहीं दिखता, तो `y` से `y + height` तक की पट्टी काट दी जाती है: उसके नीचे की पंक्तियाँ ऊपर आ जाती हैं और आर्टवर्क छोटा हो जाता है। जो आकार पूरी तरह पट्टी के अंदर हैं वे छोड़ दिए जाते हैं, और जो उसे पार करते हैं वे छोटे हो जाते हैं। पट्टी कोड, उसकी पैडिंग या किसी दूसरी पट्टी को पार नहीं कर सकती। |
| `qr.plate` | `"opaque"` (डिफ़ॉल्ट) या `"background"`। इंजन कोड के नीचे कोड के बैकग्राउंड रंग का एक प्लेट पेंट करता है। जब वह बैकग्राउंड पारदर्शी हो, तो `"opaque"` प्लेट पेंट करता है और `background` सफ़ेद भरता है, ताकि आर्टवर्क क्वाइट ज़ोन में न दिखे। `"background"` उन्हें पारदर्शी रखता है और प्लेट नहीं बनाता। यह तभी मान्य है जब प्लेट के नीचे केवल `background` फ़िल हों, या ऐसी रिंग हो जिसका छेद प्लेट को समेटे हो। |
| `colors.text` | एक हेक्स रंग, या `frame`, `accent`, `background` और हेक्स रंगों का मिश्रण, जैसे ग्रेडिएंट बॉर्डर के लेबल के लिए `{ "mix": ["frame", "accent"], "amount": 0.5 }`। यह डिफ़ॉल्ट है; `textColor` फिर भी प्राथमिकता पाता है। |

टेक्स्ट लेबल की पंक्ति प्लेट की पैडिंग में भी जा सकती है, बशर्ते वह कोड से दूर रहे और सबसे बड़े टेक्स्ट साइज़ (`fontScale` 1.5) पर उसके कैपिटल अक्षर पैडिंग से बाहर रहें। बॉर्डर फ़्रेम इसी तरह अपना लेबल कोड के ठीक नीचे रखते हैं।

qrdx 0.0.51 और उससे पुराने वर्शन इन फ़ील्ड वाले या पैडिंग में लेबल पंक्ति रखने वाले स्पेक अस्वीकार कर देते हैं, इसलिए ऐसे स्पेक को कहीं और बनाने से पहले इंजन अपडेट करें।

## आधिकारिक फ़्रेम [#official-frames]

बिल्ट-इन फ़्रेम के अलावा, QRdx में {facts.officialFrames} आधिकारिक फ़्रेम हैं: कॉल टू एक्शन, रेस्तराँ और कैफ़े, दुकानों और पैकेजिंग, ब्यूटी और वेलनेस, इवेंट और शादियों, होटल और यात्रा, रियल एस्टेट, कार और पार्किंग, स्वास्थ्य और शिक्षा, खेल और फ़िटनेस, बिज़नेस और सोशल, और गैर-लाभकारी संस्थाओं और सामुदायिक समूहों के लिए बने-बनाए डिज़ाइन। इनमें से {facts.seasonalFrames} त्योहारों और मौसमों के लिए हैं, लूनर न्यू ईयर, होली, ईद और दिवाली से लेकर हनुक्का, ईस्टर, थैंक्सगिविंग और क्रिसमस तक। हर एक लेबल और रंगों वाला फ़्रेम स्पेक है जिन्हें आप बदल सकते हैं, CC0 के तहत जारी है, और हर एक का फ़ोन की दूरी पर स्कैन होने के लिए परीक्षण किया गया है।

[प्लेग्राउंड](/playground) में **Frame** खोलें और फिर **More**। नाम, उपयोग या त्योहार से खोजें, या कोई समूह चुनें। आने वाले त्योहारों और मौसमों के फ़्रेम सबसे पहले दिखते हैं। ये [कम्युनिटी](/community/frames) में भी मिलेंगे, जिन्हें @qrdx ने पब्लिश किया है।

इंजन इन्हें `OFFICIAL_FRAMES` के रूप में एक्सपोर्ट करता है:

```tsx
import { getOfficialFrame, QRCode } from "qrdx";

const diwali = getOfficialFrame("diwali-diya"); // undefined for an unknown id

{diwali && (
  <QRCode
    value="https://example.com/offers"
    frame={{ style: "custom", spec: diwali.spec, text: "Scan for offers" }}
  />
)}
```

`OFFICIAL_FRAME_INDEX` हर फ़्रेम को उसके स्पेक के बिना सूचीबद्ध करता है, ताकि पिकर पूरी लाइब्रेरी दिखा सके और स्पेक सिर्फ़ ज़रूरत पड़ने पर लोड करे। [इमेज API](/docs/developers/image-api#community-items) और [MCP सर्वर](/docs/developers/mcp) में आधिकारिक फ़्रेम को कम्युनिटी आइटम की तरह इस्तेमाल करें, जैसे `item=frame:diwali-diya`।

## क्या यह स्कैन होगा? [#will-it-scan]

`getScanScore` अनुमान लगाता है कि कोई डिज़ाइन कितनी भरोसेमंद तरह से स्कैन होता है। यह ब्राउज़र में चलता है और ज़रूरत पड़ने पर [jsQR](https://github.com/cozmo/jsQR) लोड करता है।

```ts
import { getScanScore } from "qrdx";

const { score, grade, checks } = await getScanScore({
  value: "https://example.com",
  bodyPattern: "circle",
  cornerEyePattern: "gear",
});
// score: 0–100, grade: "great" | "ok" | "risky" | "fails"
// checks: [{ id, passed, message, fix? }]
```

यह क्या जाँचता है:

- **96, 160 और 320 px पर डिकोडिंग।** डिज़ाइन को हर चौड़ाई पर रेंडर किया जाता है, उसमें कैमरे जैसा ब्लर और कंट्रास्ट की कमी जोड़ी जाती है, और थोड़े अलग स्केल पर उसे कुछ बार डिकोड किया जाता है।
- **कंट्रास्ट**: कोड के हर रंग (ग्रेडिएंट स्टॉप, आई और डॉट के रंग सहित) और बैकग्राउंड के बीच, और क्या कोड हल्के बैकग्राउंड पर गहरा है।
- **लोगो कवरेज**, और error-correction लेवल कितना हिस्सा रिकवर कर सकता है, इन दोनों की तुलना।
- **Quiet zone**: मार्जिन, और फ़्रेम से जुड़ने वाली अतिरिक्त जगह।
- **आई शेप का जोखिम**: `circle` आई कुछ स्कैनर ऐप्स में पकड़ में न आएँ (और बंद किए जा चुके `curly` आई, अगर कोई सेव किया हुआ डिज़ाइन अब भी उन्हें इस्तेमाल करता है, तो सख़्त डिकोडर में फ़ेल होते हैं)।
- **स्टाइल पेयर** (`style-pair`): ऐसे शेप जो हमारे डिकोड टेस्ट में साथ में फ़ेल होते हैं, जैसे स्क्वेयर आई के बगल में `small-square` डॉट, और सेव किए गए डिज़ाइनों में बंद किए जा चुके सेंटर (देखें `getStylePairRisk`)।

`getImageScanScore(fileOrImage)` किसी मौजूदा इमेज के लिए यही काम करता है: यह डिकोड किया गया कंटेंट लौटाता है, साथ में पिक्सेल से मापे गए डिकोड, कंट्रास्ट, पोलैरिटी, quiet-zone और रेज़ोल्यूशन के चेक भी देता है। [स्कैन चेकर](/tools/scan-checker) इसी पर बना है।

<Callout type="info">
  यह स्कोर एक ओपन-सोर्स डिकोडर पर बना अनुमान (heuristic) है। फ़ोन के कैमरा ऐप अक्सर ज़्यादा लचीले होते हैं, इसलिए इसे सिर्फ़ मार्गदर्शन मानें और ज़रूरी प्रिंट को टेस्ट-स्कैन करके देखें।
</Callout>

## प्रिंट-रेडी एक्सपोर्ट [#print-ready-export]

`downloadPrintPDF` एक सटीक भौतिक साइज़ पर वेक्टर PDF बनाता है। मॉड्यूल, आई और फ़्रेम वेक्टर पाथ होते हैं (लोगो रास्टर इमेज ही रहता है)।

```ts
import { downloadPrintPDF, downloadPrintSVG, getPrintLayout } from "qrdx";

const props = { value: "https://example.com", frame: { style: "banner-bottom" } } as const;

await downloadPrintPDF(props, {
  size: 40, // width of the code itself
  unit: "mm", // or "in"
  bleed: 3, // millimetres on every side
  cropMarks: true,
  colorMode: "cmyk",
});

await downloadPrintSVG(props, { size: 1.5, unit: "in" }); // width="…in" height="…in"

const layout = getPrintLayout(props, { size: 40 });
layout.trimWidth; // finished width in mm, frame included
layout.maxScanDistance; // 400 (mm)
```

- `size` कोड की चौड़ाई है; फ़्रेम तैयार साइज़ को बढ़ा देता है।
- ब्लीड होने पर बैकग्राउंड (या स्क्वेयर फ़्रेम का रंग) ट्रिम किनारे से आगे तक फैलता है, ताकि ट्रिम करने पर सफ़ेद पट्टी न बचे। क्रॉप मार्क ब्लीड के बाहर होते हैं।
- `colorMode: "cmyk"` एक सरल कन्वर्ज़न इस्तेमाल करता है (`rgbToCmyk`: K = 1 − max(R, G, B), कोई ICC प्रोफ़ाइल नहीं; शुद्ध काला सिर्फ़ K से प्रिंट होता है)। जब ब्रांड के सटीक रंग मायने रखते हों, तो अपने प्रिंटर से कलर-मैनेज्ड कन्वर्ज़न माँगें।
- लीनियर और रेडियल ग्रेडिएंट PDF में स्मूद शेडिंग के रूप में प्रिंट होते हैं, और PDF CMYK हो तो CMYK में; प्रिंट SVG उन्हें रखता है, पर RGB ही रहता है।
- PDF में फ़्रेम टेक्स्ट Helvetica Bold इस्तेमाल करता है, इसलिए Latin-1 से बाहर के अक्षर शायद रेंडर न हों। दूसरी लिपियों के लिए SVG इस्तेमाल करें।
- `getQRAsPrintPDF` और `getQRAsPrintPDFBuffer` फ़ाइल को डाउनलोड करने के बजाय लौटाते हैं, और Node में भी काम करते हैं।

**कितना बड़ा प्रिंट करें:** कोड अपनी चौड़ाई के लगभग दस गुना दूरी से स्कैन हो जाता है, इसलिए साइज़ ≈ स्कैन दूरी ÷ 10 (20 cm की दूरी के लिए 2 cm चौड़ा)। ज़्यादा घने कोड को ज़्यादा साइज़ चाहिए; [प्रिंट साइज़ कैलकुलेटर](/tools/print-size) इसका हिसाब रखता है।
