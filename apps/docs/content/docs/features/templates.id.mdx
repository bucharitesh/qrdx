Bungkus kode QR dengan desain siap pakai, atau dengan desain Anda sendiri.

## Apa Itu Template? [#what-are-templates]

Template adalah karya seni SVG yang digambar di sekeliling kode: kotak, bingkai, atau lencana. Template menerima kode sebagai `children` dan menempatkannya di dalam gambarnya sendiri. Warna, pola, dan logo tetap diatur pada props `QRCode`, sehingga template dapat digunakan dengan gaya apa pun.

## Template yang Tersedia [#available-templates]

### Default [#default]
Hitam putih klasik.

```tsx
import { QRCode } from 'qrdx';

<QRCode value="https://example.com" templateId="default" size={256} />
```

### Arrow [#arrow]
Desain geometris modern.

```tsx
<QRCode value="https://example.com" templateId="Arrow" size={256} />
```

### Standard Box [#standard-box]
Desain rapi dan terstruktur.

```tsx
<QRCode value="https://example.com" templateId="StandardBox" size={256} />
```

### Square Border [#square-border]
Desain berbingkai dengan tepi yang tegas.

```tsx
<QRCode value="https://example.com" templateId="SquareBorder" size={256} />
```

### Striked Box [#striked-box]
Desain dinamis dengan elemen diagonal.

```tsx
<QRCode value="https://example.com" templateId="StrikedBox" size={256} />
```

### Halloween [#halloween]
Tema Halloween musiman.

```tsx
<QRCode value="https://example.com" templateId="Halloween" size={256} />
```

## Menyesuaikan Template [#customize-templates]

Template bawaan menggambar karya seninya dengan `fgColor`. Hal lainnya, seperti pola dan logo, diatur pada kode seperti biasa:

```tsx
<QRCode
  value="https://example.com"
  templateId="Arrow"
  fgColor="#1a56db"
  imageSettings={{
    src: "/your-logo.png",
    width: 48,
    height: 48,
    excavate: true,
  }}
  size={512}
/>
```

## Registri Template [#template-registry]

### Mendapatkan Semua Template [#get-all-templates]

```tsx
import { getAllTemplates } from 'qrdx';

const templates = getAllTemplates();
```

### Mendapatkan ID Template [#get-template-ids]

```tsx
import { getTemplateIds } from 'qrdx';

const ids = getTemplateIds();
// Returns: ['default', 'Arrow', 'StandardBox', ...]
```

## Template Kustom [#custom-templates]

Tulis template Anda sendiri sebagai `TemplateDefinition`. `wrapper`-nya menerima kode sebagai `children` dan mengembalikan SVG yang akan digambar. Template digambar pada kanvas 300 kali 300, dan kode juga tiba dengan ukuran tersebut, jadi perkecil kode agar ada ruang untuk desain Anda. `props` membawa `fgColor` dan `bgColor` dari kode.

Contoh ini menggambar cincin di sekeliling kode:

```tsx
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg viewBox="0 0 300 300" width="300" height="300" xmlns="http://www.w3.org/2000/svg">
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

<QRCode
  value="https://example.com"
  customTemplate={ringTemplate}
  fgColor="#1a56db"
  size={256}
/>
```

Jaga agar kode cukup besar untuk dipindai dari jarak orang memegang ponselnya, dan sisakan celah terang antara kode dan desain Anda. Periksa hasilnya dengan [skor pemindaian](/docs/features/frames#will-it-scan).

## Kapan Menggunakan Template [#when-to-use-templates]

- **Konsistensi Merek** — Pastikan semua kode QR serasi
- **Penyiapan Cepat** — Dapatkan hasil profesional dengan cepat
- **Kampanye Musiman** — Gunakan template bertema
- **Pembuatan Massal** — Terapkan gaya yang konsisten
