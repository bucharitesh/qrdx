Terapkan gaya kode QR profesional secara instan.

## Apa Itu Templat? [#what-are-templates]

Templat menggabungkan warna, pola, dan gaya visual menjadi paket siap pakai.

## Templat yang Tersedia [#available-templates]

### Default [#default]
Hitam putih klasik.

```tsx
import { QRCode } from 'qrdx';

<QRCode value="https://example.com" templateId="default" size={256} />
```

### Arrow [#arrow]
Desain geometris modern.

```tsx
<QRCode value="https://example.com" templateId="Arrow" size={256} />
```

### Standard Box [#standard-box]
Desain bersih dan terstruktur.

```tsx
<QRCode value="https://example.com" templateId="StandardBox" size={256} />
```

### Square Border [#square-border]
Desain berbingkai dengan tepi yang tegas.

```tsx
<QRCode value="https://example.com" templateId="SquareBorder" size={256} />
```

### Striked Box [#striked-box]
Desain dinamis dengan elemen diagonal.

```tsx
<QRCode value="https://example.com" templateId="StrikedBox" size={256} />
```

### Halloween [#halloween]
Tema Halloween musiman.

```tsx
<QRCode value="https://example.com" templateId="Halloween" size={256} />
```

## Menyesuaikan Templat [#customize-templates]

Timpa pengaturan bawaan templat:

```tsx
<QRCode
  value="https://example.com"
  templateId="Arrow"
  fgColor="#your-brand-color"
  hideLogo={false}
  logo="/your-logo.png"
  size={512}
/>
```

## Registri Templat [#template-registry]

### Mendapatkan Semua Templat [#get-all-templates]

```tsx
import { getAllTemplates } from 'qrdx';

const templates = getAllTemplates();
```

### Mendapatkan ID Templat [#get-template-ids]

```tsx
import { getTemplateIds } from 'qrdx';

const ids = getTemplateIds();
// Returns: ['default', 'Arrow', 'StandardBox', ...]
```

## Templat Kustom [#custom-templates]

Buat templat Anda sendiri:

```tsx
const brandTemplate = {
  id: 'brand-template',
  name: 'Brand Template',
  colors: {
    fgColor: '#1a56db',
    bgColor: '#ffffff',
    eyeColor: '#0d47a1',
    dotColor: '#3b82f6'
  },
  bodyPattern: 'rounded',
  cornerEyePattern: 'rounded',
  cornerEyeDotPattern: 'rounded'
};

<QRCode
  value="https://example.com"
  customTemplate={brandTemplate}
  size={256}
/>
```

## Kapan Menggunakan Templat [#when-to-use-templates]

- **Konsistensi Merek** — Pastikan semua kode QR serasi
- **Penyiapan Cepat** — Dapatkan hasil profesional dengan cepat
- **Kampanye Musiman** — Gunakan templat bertema
- **Pembuatan Massal** — Terapkan gaya yang konsisten
