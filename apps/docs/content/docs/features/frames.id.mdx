Tambahkan bingkai "Scan me", pastikan desain dapat dipindai sebelum dirilis, dan ekspor file vektor pada ukuran fisik yang tepat.

## Bingkai ajakan bertindak [#call-to-action-frames]

Prop `frame` menggambar bingkai dengan label singkat di sekeliling kode. Prop ini berfungsi pada `QRCode`, `QRCodeSVG`, `QRCodeCanvas`, `getQRAsSVG`, `getQRData`, dan semua helper unduhan.

```tsx
import { QRCode } from "qrdx";

<QRCode
  value="https://example.com/menu"
  frame={{ style: "banner-bottom", text: "Scan for the menu", color: "#1e3a8a" }}
/>
```

Bingkai ditambahkan **di sekeliling** kode: hasil keluaran menjadi lebih besar, sementara modul QR dan zona tenang tidak pernah tertutup, sehingga kemudahan pemindaian tidak berubah. Celah terang dengan warna latar kode memisahkan kode dari bingkai.

| Opsi | Default | Catatan |
| --- | --- | --- |
| `style` | — | Salah satu dari {facts.frameStyles} gaya di bawah, atau `none` (`FRAME_STYLES`) |
| `text` | `"Scan me"` | Maksimal 24 karakter. Berikan `""` untuk menyembunyikan label |
| `color` | `#000000` | Warna bingkai (`gradient-border`: warna awal, default ungu) |
| `textColor` | putih pada bingkai, `color` pada area terang | Warna label |
| `secondaryText` | tidak ada | Label kedua, maksimal 24 karakter: pita bawah pada `banner-top-bottom`, busur bawah pada `circle`, footer pada `menu-card` |
| `secondaryColor` | `#db2777` | Warna akhir `gradient-border` |
| `fontScale` | `1` | Ukuran label dari 0,5 sampai 1,5; label tetap mengecil agar muat |

Gaya:

- Banner dan border: `banner-bottom`, `banner-top`, `banner-top-bottom`, `border`, `rounded-border`, `gradient-border`, `focus` (siku di sudut)
- Gelembung: `speech-bubble`, `speech-bubble-top`, `chat-bubble`
- Lencana: `circle` (teks tersusun mengelilingi cincin), `badge` (pita), `sticker` (potongan die-cut dengan bayangan)
- Objek: `polaroid`, `phone`, `ticket`, `tag` (tag gantung berlubang), `envelope`, `menu-card`

Lihat semuanya, didekode di browser Anda, di [Bentuk, mata, dan bingkai](/docs/styles#frames). Setiap bingkai hanya berupa bentuk dan teks polos dengan warna opak, sehingga hasil ekspor SVG, PNG, PDF, dan EPS sama (border gradien digambar sebagai langkah warna solid yang halus, dan huruf melengkung pada bingkai circle berupa teks yang diputar di setiap format).

```tsx
<QRCode
  value="https://example.com"
  frame={{ style: "circle", text: "Scan me", secondaryText: "example.com", fontScale: 1.2 }}
/>
```

Label menggunakan susunan font sistem, jadi tidak ada yang diunduh. Karena hasil keluaran membesar, gunakan `getFrameDimensions(size, frame)` saat Anda membutuhkan lebar dan tinggi akhir:

```ts
import { getFrameDimensions } from "qrdx";

getFrameDimensions(400, { style: "banner-bottom" }); // { width: 496, height: 568 }
```

`FRAME_STYLES`, `frameSchema` (zod), dan tipe `QRFrame` / `FrameStyle` juga diekspor dari `qrdx/types` untuk validasi di sisi server.

### Di CLI [#in-the-cli]

```bash
qrdx generate "https://example.com/menu" --frame banner-bottom --frame-text "Scan for the menu" -o menu.png
```

`--frame-color` dan `--frame-text-color` menerima warna hex. Jika teks atau warna diberikan tanpa `--frame`, yang dipakai adalah `banner-bottom`.

## Bingkai resmi [#official-frames]

Selain gaya bawaan, QRdx memiliki {facts.officialFrames} bingkai resmi: desain siap pakai untuk ajakan bertindak, restoran dan kafe, toko dan kemasan, acara dan pernikahan, hotel, perjalanan dan properti, kesehatan, kebugaran dan pendidikan, serta bisnis dan media sosial. {facts.seasonalFrames} di antaranya untuk hari raya dan musim, mulai dari Tahun Baru Imlek, Holi, Idulfitri, dan Diwali hingga Hanukkah, Paskah, Thanksgiving, dan Natal. Masing-masing berupa spesifikasi bingkai dengan label dan warna yang dapat Anda ubah, dirilis di bawah CC0, dan diuji agar dapat dipindai pada jarak ponsel.

Di [playground](/playground), buka **Frame** lalu **More**. Cari berdasarkan nama, kegunaan, atau hari raya, atau pilih sebuah grup. Bingkai untuk hari raya dan musim yang akan datang ditampilkan paling awal. Anda juga akan menemukannya di [komunitas](/community/frames), diterbitkan oleh @qrdx.

Engine mengekspornya sebagai `OFFICIAL_FRAMES`:

```tsx
import { getOfficialFrame, QRCode } from "qrdx";

const diwali = getOfficialFrame("diwali-diya"); // undefined for an unknown id

{diwali && (
  <QRCode
    value="https://example.com/offers"
    frame={{ style: "custom", spec: diwali.spec, text: "Scan for offers" }}
  />
)}
```

`OFFICIAL_FRAME_INDEX` mencantumkan setiap bingkai tanpa spesifikasinya, sehingga pemilih dapat menampilkan seluruh pustaka dan memuat spesifikasi hanya saat dibutuhkan. Di [image API](/docs/developers/image-api#community-items) dan [server MCP](/docs/developers/mcp), gunakan bingkai resmi sebagai item komunitas, misalnya `item=frame:diwali-diya`.

## Apakah bisa dipindai? [#will-it-scan]

`getScanScore` memperkirakan seberapa andal sebuah desain dapat dipindai. Fungsi ini berjalan di browser dan memuat [jsQR](https://github.com/cozmo/jsQR) sesuai kebutuhan.

```ts
import { getScanScore } from "qrdx";

const { score, grade, checks } = await getScanScore({
  value: "https://example.com",
  bodyPattern: "circle",
  cornerEyePattern: "gear",
});
// score: 0–100, grade: "great" | "ok" | "risky" | "fails"
// checks: [{ id, passed, message, fix? }]
```

Yang diperiksa:

- **Dekode pada 96, 160, dan 320 px.** Desain dirender pada setiap lebar, diberi keburaman dan penurunan kontras seperti kamera, lalu didekode beberapa kali pada skala yang sedikit berbeda.
- **Kontras** antara setiap warna kode (termasuk titik gradien, warna mata, dan warna titik) dengan latar belakang, serta apakah kode berwarna gelap di atas latar terang.
- **Cakupan logo** dibandingkan dengan yang dapat dipulihkan oleh tingkat koreksi kesalahan.
- **Zona tenang**: margin, ditambah celah yang ditambahkan bingkai.
- **Risiko bentuk mata**: mata `circle` mungkin tidak terdeteksi oleh beberapa aplikasi pemindai (dan mata `curly` yang sudah dihentikan, jika desain tersimpan masih memakainya, gagal pada dekoder ketat).
- **Pasangan gaya** (`style-pair`): bentuk yang gagal bersama dalam uji dekode kami, seperti titik `small-square` di samping mata persegi, dan bagian tengah yang sudah dihentikan pada desain tersimpan (lihat `getStylePairRisk`).

`getImageScanScore(fileOrImage)` melakukan hal yang sama untuk gambar yang sudah ada: fungsi ini mengembalikan isi yang didekode beserta pemeriksaan dekode, kontras, polaritas, zona tenang, dan resolusi yang diukur dari piksel. [Pemeriksa pemindaian](/tools/scan-checker) dibangun di atasnya.

<Callout type="info">
  Skor ini adalah heuristik yang dibangun di atas satu dekoder sumber terbuka. Aplikasi kamera ponsel sering kali lebih toleran, jadi anggap skor ini sebagai panduan dan uji pindai cetakan yang penting.
</Callout>

## Ekspor siap cetak [#print-ready-export]

`downloadPrintPDF` menulis PDF vektor pada ukuran fisik yang tepat. Modul, mata, dan bingkai berupa path vektor (logo tetap berupa gambar raster).

```ts
import { downloadPrintPDF, downloadPrintSVG, getPrintLayout } from "qrdx";

const props = { value: "https://example.com", frame: { style: "banner-bottom" } } as const;

await downloadPrintPDF(props, {
  size: 40, // width of the code itself
  unit: "mm", // or "in"
  bleed: 3, // millimetres on every side
  cropMarks: true,
  colorMode: "cmyk",
});

await downloadPrintSVG(props, { size: 1.5, unit: "in" }); // width="…in" height="…in"

const layout = getPrintLayout(props, { size: 40 });
layout.trimWidth; // finished width in mm, frame included
layout.maxScanDistance; // 400 (mm)
```

- `size` adalah lebar kode; bingkai menambah ukuran akhir.
- Dengan bleed, latar belakang (atau warna bingkai persegi) meluas melewati tepi potong sehingga pemotongan tidak menyisakan garis putih tipis. Tanda potong berada di luar bleed.
- `colorMode: "cmyk"` memakai konversi sederhana (`rgbToCmyk`: K = 1 − max(R, G, B), tanpa profil ICC; hitam murni dicetak hanya dengan K). Minta konversi dengan manajemen warna dari percetakan Anda jika warna merek yang akurat penting.
- Gradien linear dan radial dicetak sebagai shading halus di PDF, dalam CMYK jika PDF-nya CMYK; SVG cetak tetap menyimpannya tetapi tetap RGB.
- Teks bingkai di PDF memakai Helvetica Bold, sehingga karakter di luar Latin-1 mungkin tidak ditampilkan. Gunakan SVG untuk aksara lain.
- `getQRAsPrintPDF` dan `getQRAsPrintPDFBuffer` mengembalikan file alih-alih mengunduhnya, dan juga berfungsi di Node.

**Seberapa besar mencetaknya:** kode dapat dipindai dari jarak sekitar sepuluh kali lebarnya, jadi ukuran ≈ jarak pemindaian ÷ 10 (lebar 2 cm untuk 20 cm). Kode yang lebih padat membutuhkan ukuran lebih besar; [kalkulator ukuran cetak](/tools/print-size) memperhitungkannya.
