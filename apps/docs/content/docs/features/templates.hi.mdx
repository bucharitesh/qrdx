QR कोड को तैयार आर्टवर्क में लपेटें, या अपने खुद के आर्टवर्क में।

## टेम्पलेट क्या हैं? [#what-are-templates]

टेम्पलेट कोड के चारों ओर बना SVG आर्टवर्क होता है: एक बॉक्स, एक बॉर्डर, एक बैज। यह कोड को `children` के रूप में लेता है और उसे अपनी ड्रॉइंग के अंदर रखता है। रंग, पैटर्न और लोगो `QRCode` props पर ही रहते हैं, इसलिए टेम्पलेट हर स्टाइल के साथ काम करता है।

## उपलब्ध टेम्पलेट [#available-templates]

### Default [#default]
क्लासिक ब्लैक एंड व्हाइट।

```tsx
import { QRCode } from 'qrdx';

<QRCode value="https://example.com" templateId="default" size={256} />
```

### Arrow [#arrow]
आधुनिक ज्यामितीय डिज़ाइन।

```tsx
<QRCode value="https://example.com" templateId="Arrow" size={256} />
```

### Standard Box [#standard-box]
साफ़-सुथरा, व्यवस्थित डिज़ाइन।

```tsx
<QRCode value="https://example.com" templateId="StandardBox" size={256} />
```

### Square Border [#square-border]
साफ़ किनारों वाला बॉर्डर डिज़ाइन।

```tsx
<QRCode value="https://example.com" templateId="SquareBorder" size={256} />
```

### Striked Box [#striked-box]
तिरछे एलिमेंट वाला डायनेमिक डिज़ाइन।

```tsx
<QRCode value="https://example.com" templateId="StrikedBox" size={256} />
```

### Halloween [#halloween]
हैलोवीन की सीज़नल थीम।

```tsx
<QRCode value="https://example.com" templateId="Halloween" size={256} />
```

### Dot Ring [#dot-ring]
गोल कोड। कोड डॉट्स की एक डिस्क में रहता है, जो एक गहरे रिंग के अंदर होती है, और रिंग के साथ-साथ टेक्स्ट की एक लाइन लगी होती है। कौन-से डॉट्स दिखें, यह कोड के कंटेंट के हैश से तय होता है, इसलिए हर लिंक को अपना अलग रिंग मिलता है और एक ही लिंक को हमेशा वही रिंग मिलता है।

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  bodyPattern="circle-large"
  size={512}
/>
```

इसकी सेटिंग `customProps` में जाती हैं (टाइप `DotRingProps`):

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  customProps={{
    customText: "Scan for the menu",
    textPosition: "bottom",
    textColor: "#fde047",
    outerCircleColor: "#1e3a8a",
  }}
  size={512}
/>
```

| Prop | डिफ़ॉल्ट | नोट्स |
| --- | --- | --- |
| `customText` | "Scan the QR code" रिंग के चारों ओर चार बार | रिंग के साथ चलने वाला टेक्स्ट। जो अक्षर रिंग में नहीं समाते, वे छोड़ दिए जाते हैं; `""` देने पर रिंग खाली रहता है |
| `textPosition` | `"top"` | `"top"`: ऊपर बीच में, घड़ी की दिशा में पढ़ा जाता है। `"bottom"`: नीचे बीच में, बाएँ से दाएँ पढ़ा जाता है |
| `textRotation` | `0` | टेक्स्ट को केंद्र के चारों ओर डिग्री में घुमाता है |
| `textColor` | `#ffffff` | टेक्स्ट का रंग |
| `fontFamily` | सिस्टम फ़ॉन्ट स्टैक | टेक्स्ट की CSS फ़ॉन्ट फ़ैमिली |
| `fontWeight` | `900` | फ़ॉन्ट वेट |
| `fontSize` | `32` | टेम्पलेट की 593 यूनिट की ड्रॉइंग में, जहाँ कोड की चौड़ाई 300 है |
| `fontLetterSpacing` | `3.5` | अक्षरों के बीच अतिरिक्त जगह, उन्हीं यूनिट में |
| `outerCircleColor` | `fgColor` | रिंग का रंग |
| `strokeWidth`, `strokeColor` | `0`, `#000000` | रिंग के दोनों किनारों पर स्ट्रोक |
| `outerStrokeWidth`, `outerStrokeColor` | `strokeWidth`, `strokeColor` | सिर्फ़ रिंग का बाहरी किनारा |
| `innerStrokeWidth`, `innerStrokeColor` | `strokeWidth`, `strokeColor` | सिर्फ़ रिंग का भीतरी किनारा |

लोगो किसी भी कोड की तरह बीच में लगता है। लंबे लिंक (जिन कोड की चौड़ाई 49 मॉड्यूल से ज़्यादा हो) में कोड और डॉट्स के बीच हल्की पट्टी बनी रहती है, ताकि छोटे साइज़ में प्रिंट होने पर भी वे स्कैन हो सकें।

टेक्स्ट आपके चुने हुए फ़ॉन्ट में SVG टेक्स्ट होता है; डिफ़ॉल्ट सिस्टम फ़ॉन्ट स्टैक है, इसलिए कुछ भी डाउनलोड नहीं होता। ब्राउज़र में SVG और PNG डाउनलोड देखने वाले के फ़ॉन्ट इस्तेमाल करते हैं। PDF और EPS इसे Helvetica Bold में प्रिंट करते हैं, इसलिए वहाँ Latin-1 टेक्स्ट इस्तेमाल करें। `qrdx/node` का `getQRAsPNG` सर्वर पर इंस्टॉल किया हुआ फ़ॉन्ट माँगता है, जैसा फ़्रेम लेबल के लिए होता है।

## टेम्पलेट कस्टमाइज़ करें [#customize-templates]

बिल्ट-इन टेम्पलेट अपना आर्टवर्क `fgColor` में बनाते हैं। बाकी सब कुछ, जैसे पैटर्न और लोगो, कोड पर हमेशा की तरह सेट होता है:

```tsx
<QRCode
  value="https://example.com"
  templateId="Arrow"
  fgColor="#1a56db"
  imageSettings={{
    src: "/your-logo.png",
    width: 48,
    height: 48,
    excavate: true,
  }}
  size={512}
/>
```

## टेम्पलेट रजिस्ट्री [#template-registry]

### सभी टेम्पलेट पाएँ [#get-all-templates]

```tsx
import { getAllTemplates } from 'qrdx';

const templates = getAllTemplates();
```

### टेम्पलेट ID पाएँ [#get-template-ids]

```tsx
import { getTemplateIds } from 'qrdx';

const ids = getTemplateIds();
// Returns: ['default', 'Arrow', 'StandardBox', ...]
```

## कस्टम टेम्पलेट [#custom-templates]

अपना टेम्पलेट `TemplateDefinition` के रूप में लिखें। इसका `wrapper` कोड को `children` के रूप में लेता है और बनाने के लिए SVG लौटाता है। यह 300 गुणा 300 के कैनवास पर बनाता है, और कोड भी उसी साइज़ में आता है, इसलिए अपने आर्टवर्क के लिए जगह छोड़ने हेतु उसे छोटा करें। `props` में कोड के `fgColor` और `bgColor` होते हैं।

यह टेम्पलेट कोड के चारों ओर एक रिंग बनाता है:

```tsx
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg viewBox="0 0 300 300" width="300" height="300" xmlns="http://www.w3.org/2000/svg">
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

<QRCode
  value="https://example.com"
  customTemplate={ringTemplate}
  fgColor="#1a56db"
  size={256}
/>
```

कोड को इतना बड़ा रखें कि लोग जिस दूरी से फ़ोन पकड़ेंगे वहाँ से स्कैन हो सके, और उसके व आपके आर्टवर्क के बीच हल्की जगह छोड़ें। नतीजे को [स्कैन स्कोर](/docs/features/frames#will-it-scan) से जाँचें।

## टेम्पलेट कब इस्तेमाल करें [#when-to-use-templates]

- **ब्रांड में एकरूपता** — सुनिश्चित करें कि सभी QR कोड एक जैसे दिखें
- **तेज़ सेटअप** — प्रोफ़ेशनल नतीजे जल्दी पाएँ
- **सीज़नल कैंपेन** — थीम वाले टेम्पलेट इस्तेमाल करें
- **बैच जनरेशन** — एक जैसी स्टाइल लगाएँ

| Standard Box | कॉर्पोरेट | प्रोफ़ेशनल |

| Dot Ring | गोल कोड, पोस्टर, स्टिकर | बोल्ड |
