QRdxには、QRコードをアート作品にする方法が3つあります。

| | 仕組み | 出力 | コスト |
|---|---|---|---|
| **Logo QR** | ロゴの形の内側にあるモジュールはロゴの色になり、それ以外は明るいトーンに薄れます | ベクター形式（SVG、PDF、EPS、PNG） | フリー |
| **Image QR** | 本来の値を保つ中央の正方形を除き、すべてのモジュールに写真が表示されます（ハーフトーン） | ベクター形式（SVG、PDF、EPS、PNG） | フリー |
| **AIアート** | AI画像モデルがコードをシーンとして描き直し、すべての画像がスキャンできることを検証します | 1024 pxの画像、2048 pxの印刷用コピー | AIアートクレジット |

Logo QRとImage QRは`qrdx`ライブラリ自体が描画するため、オフラインでも、エディタ、サーバー、Nodeでも動作します。結果は常に本物のQRコードで、ファインダー、タイミング、アライメントの各パターンには手を加えません。

## エディタでの使い方 [#in-the-editor]

[Playground](/playground?tab=art)を開き、**アート**タブで**Logo QR**または**Image QR**を選びます。

1. ロゴまたは写真をアップロードします（PNG、JPG、WebP、SVG、1 MBまで）。透過PNGまたはSVGを使うと、最もきれいなLogo QRになります。
2. **強度**を設定します。低くすると見た目が通常のコードに近くなり、高くすると画像がより多く表示されます。
3. スライダーの横にある**スキャンチェック**を確認します。プレビューの[スキャンスコア](/docs/qr-detection)と同様に、アートコードをブラウザ内で3つのサイズでデコードします。

アート画像をアップロードすると、誤り訂正が`H`に設定され、アートに最も多くの余地が与えられます。画像がブラウザの外に出ることはなく、小さなカラーグリッド（幅64または96ピクセル）だけがデザインとともに保存されます。

## コードでの使い方 [#in-code]

モード、サンプリング済みの画像、任意の強度（0〜1、デフォルトは0.6）を指定した`art`プロパティを渡します。

```tsx
import { QRCodeSVG, loadQRArtImage } from 'qrdx';

// Browser: sample an uploaded file, a data URL or an <img>
const image = await loadQRArtImage(file, { mode: 'logo' });

<QRCodeSVG
  value="https://example.com"
  size={512}
  level="H"
  art={{ mode: 'logo', image, intensity: 0.7 }}
/>;
```

サーバーまたはNodeでは、画像を自分でデコードし、RGBAピクセルを`createQRArtImage`に渡します。

```ts
import sharp from 'sharp';
import { createQRArtImage } from 'qrdx';

const { data, info } = await sharp('photo.jpg')
  .ensureAlpha()
  .raw()
  .toBuffer({ resolveWithObject: true });

const image = createQRArtImage(
  { data, width: info.width, height: info.height },
  { maxSize: 96 }
);
// art={{ mode: 'halftone', image, intensity: 0.8 }}
```

`art.image`はプレーンなJSON（base64のRGBAを含む`{ width, height, data }`）なので、保存したデザインと一緒に保管し、画像を再取得することなく、どこでも同じコードを同期的に描画できます。

| オプション | 値 | 備考 |
|---|---|---|
| `mode` | `logo`、`halftone` | `halftone`はエディタでの「Image QR」です |
| `image` | `loadQRArtImage`または`createQRArtImage`から取得 | 最大192 × 192サンプル |
| `intensity` | `0`〜`1` | デフォルトは`0.6`。`0`では通常のコードに見えます |

アートはボディパターンを置き換えます。コーナーアイは`cornerEyePattern`、`cornerEyeDotPattern`、および色をそのまま保持します。アートはグラデーションの`fgColor`/`bgColor`の最初の色を使用し、明るい背景に暗い前景が必要です（色を反転させると、通常の見た目に戻ります）。

### スキャン性を保つ仕組み [#how-scannability-is-kept]

- **Logo QR**：ロゴ内の暗いモジュールは色が変更されますが、スキャナが暗いと認識できる輝度までしか暗くなりません。ロゴ内の明るいモジュールには、明るさのしきい値を超える淡い色合いが付きます。ロゴ外の暗いモジュールはグレーに薄れますが、暗さのしきい値より明るくなることはありません。
- **Logo QRのバッジ**：プレートの下にあるモジュールはどれも、コードワードを1つ損なう可能性があります。プレートは、どの誤り訂正ブロックも修復可能なコードワードの60%を超えて失わないサイズに設定されており、残りはカメラのために確保されます。強度を上げると、プレートはそのサイズまで大きくなります。小さなコードではロゴも小さくなり、最小のもの（バージョン1、LまたはMのバージョン2、Lのバージョン3）ではプレートを描画しません。
- **Image QR**：各モジュールは3 × 3のグリッドに分割されます。外側のセルには写真が表示され、モジュールの値に合わせて暗く、または明るく調整されます。中央のセルは前景色または背景色そのままで、スキャナがサンプリングする位置です。
- ファインダー、タイミング、アライメント、フォーマット、バージョンの各モジュールは、常にベタ塗りで描画されます。

印刷する前に`getScanScore(props)`でデザインを確認し、実際のスマートフォンのカメラでもテストしてください。

## アートコードのエクスポート [#exporting-art-codes]

アートコードはベクター図形なので、どの形式でエクスポートしても鮮明さが保たれます。

```ts
import { downloadQRCode, getQRAsEPS, getQRAsPrintPDF } from 'qrdx';

await downloadQRCode(props, { format: 'svg', size: { width: 1024, height: 1024 } });
const pdf = await getQRAsPrintPDF(props, { size: 40, unit: 'mm', colorMode: 'cmyk' });
const eps = await getQRAsEPS(props, { sizeMm: 40, bleedMm: 3, colorMode: 'cmyk' });
```

`getQRAsEPS`は、ポイント単位の`%%BoundingBox`を持つEPSF-3.0ファイルを書き出し、すべてのモジュール、アイ、フレームをPostScriptのパスとして出力します。印刷用PDFと同様に、線形グラデーションと放射状グラデーションをPostScript Level 3のシェーディングとして保持し、透明度は使用しません。PNGとJPEGのロゴは画像として埋め込まれ、それ以外の形式のロゴはブラウザ上で変換されますが、サーバーでは省かれます。フレームのテキストにはHelveticaが使われるため、Latin-1以外の文字は`?`として印刷されます。`svgToEPS(svg, { width })`は、このライブラリが生成する任意のSVGを変換します。

CLIもEPSを書き出せます：`qrdx generate "https://example.com" -o qr.eps`。

<IfAvailable feature="aiArt" id="ai-art" title="AIアート">

[AI QRアート](/ai/art)は、Vercel AI Gateway経由で{facts.artModel}を使い、コードをシーンに変えます。カテゴリで閲覧または検索できる{facts.aiArtStyles}種類のスタイルプリセットがあり、それぞれにスキャンチェックを通過したプレビューが付いています。ほかにも、避けたい要素の指定、**QRの視認性**スライダー（モデルがコードをどれだけ優先するか）、**創造性**スライダー（モデルがプロンプトをどれだけ自由に解釈するか）、1回の実行あたり1〜4つのバリエーション、そしてロゴやカラーパレットなど、色や形を引き継ぐ任意の参照画像があります。

すべての画像は、表示される前にサーバー上でチェックされます。QRdxはモデルに、シンプルな白黒のコード（誤り訂正H、正方形のモジュール、広いクワイエットゾーン）を送り、モジュールのグリッド、ファインダーアイ、クワイエットゾーンを保つよう指示します。そのうえで、モデルの画像をそのままの状態と、スマートフォンのカメラモデルを通した状態の両方でjsQRによってデコードします。失敗した場合は、モデルが描いた位置のモジュールグリッドを見つけ、モデル自身の画像上で、コードを必要最小限だけ強化します。まずファインダーアイとクワイエットゾーン、次にモジュールの順に、画像がスキャンできるまで強度を段階的に上げます。カメラの視野内でコードが小さい場合にも対応します。QRの視認性で、どこまで強化してよいかが決まります。それでも足りない場合に限り、画像をImage QRコードとして描き直します。それでも正確な内容にデコードされない画像は、納品されません。その後、ブラウザがバリエーションを採点して最良のものを選びます。1024 pxで、または2048 pxの印刷用コピー（リサンプリングして再度チェック済み）としてダウンロードできます。

納品された画像1枚につき、AIアートクレジットを1つ使用します。フリーアカウントは月3、Proは30、Businessは150で、ワークスペースの全員で共有します。失敗した画像やスキャンチェックに通らなかった画像ではクレジットを使用せず、印刷用コピーは無料です。AIアートはラスター画像で内容が固定されるため、編集可能なリンクにしたい場合は、[動的QRコード](/docs/dynamic-qr-codes)の短縮リンクを入れてください。
