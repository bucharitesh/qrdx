QRdxには、QRコードをアートにする方法が3つあります。

| | 仕組み | 出力 | コスト |
|---|---|---|---|
| **Logo QR** | ロゴの形の内側にあるモジュールはロゴの色になり、それ以外は明るいトーンに薄くなります | ベクター（SVG、PDF、EPS、PNG） | フリー |
| **Image QR** | 中央の正方形が本来の値を保ち、その周囲のすべてのモジュールに写真が表示されます（ハーフトーン） | ベクター（SVG、PDF、EPS、PNG） | フリー |
| **AIアート** | AI画像モデルがコードをシーンとして描き直し、すべての画像がスキャンできることを検証します | 1024 pxの画像、2048 pxの印刷用コピー | AIアートクレジット |

Logo QRとImage QRは`qrdx`ライブラリ自体が描画するため、オフライン、エディター、サーバー、Nodeで動作し、結果は常に本物のQRコードです。ファインダー、タイミング、アライメントの各パターンには手を加えません。

## エディターで使う [#in-the-editor]

[Playground](/playground?tab=art)を開き、**アート**タブで**Logo QR**または**Image QR**を選びます。

1. ロゴまたは写真をアップロードします（PNG、JPG、WebP、SVG、最大1 MB）。透過PNGまたはSVGを使うと、最もきれいなLogo QRになります。
2. **強度**を設定します。低くすると見た目が普通のコードに近くなり、高くすると画像がより多く表示されます。
3. スライダーの横にある**スキャンチェック**を確認します。プレビューの[スキャンスコア](/docs/qr-detection)と同様に、ブラウザー上で3つのサイズでアートコードをデコードします。

アート画像をアップロードすると、誤り訂正が`H`に設定され、アートに最も余裕が生まれます。画像がブラウザーの外に出ることはありません。デザインと一緒に保存されるのは、小さなカラーグリッド（幅64または96ピクセル）だけです。

## コードで使う [#in-code]

モード、サンプリング済みの画像、任意の強度（0〜1、デフォルトは0.6）を指定して`art`プロパティを渡します。

```tsx
import { QRCodeSVG, loadQRArtImage } from 'qrdx';

// Browser: sample an uploaded file, a data URL or an <img>
const image = await loadQRArtImage(file, { mode: 'logo' });

<QRCodeSVG
  value="https://example.com"
  size={512}
  level="H"
  art={{ mode: 'logo', image, intensity: 0.7 }}
/>;
```

サーバーやNodeでは、画像を自分でデコードし、RGBAピクセルを`createQRArtImage`に渡します。

```ts
import sharp from 'sharp';
import { createQRArtImage } from 'qrdx';

const { data, info } = await sharp('photo.jpg')
  .ensureAlpha()
  .raw()
  .toBuffer({ resolveWithObject: true });

const image = createQRArtImage(
  { data, width: info.width, height: info.height },
  { maxSize: 96 }
);
// art={{ mode: 'halftone', image, intensity: 0.8 }}
```

`art.image`は単純なJSON（base64のRGBAを持つ`{ width, height, data }`）なので、保存したデザインと一緒に保管でき、画像を再取得することなく、どこでも同期的に同じコードを描画できます。

| オプション | 値 | 備考 |
|---|---|---|
| `mode` | `logo`、`halftone` | `halftone`はエディターでの「Image QR」です |
| `image` | `loadQRArtImage`または`createQRArtImage`の結果 | 最大192 × 192サンプル |
| `intensity` | `0`〜`1` | デフォルトは`0.6`。`0`だと普通のコードに見えます |

アートは本体パターンを置き換えます。コーナーのアイは`cornerEyePattern`、`cornerEyeDotPattern`と色を維持します。アートはグラデーションの`fgColor`/`bgColor`の最初の色を使い、明るい背景に暗い前景が必要です（色を反転すると、通常の見た目に戻ります）。

### スキャン性を保つ仕組み [#how-scannability-is-kept]

- **Logo QR**：ロゴ内の暗いモジュールは色が変わりますが、スキャナーが暗いと読み取れる輝度までしか暗くしません。ロゴ内の明るいモジュールには、明るさのしきい値を上回る淡い色味が付きます。ロゴ外の暗いモジュールはグレーに薄くなりますが、暗さのしきい値より明るくなることはありません。
- **Logo QRのバッジ**：プレートの下にあるモジュールはどれも、コードワードを1つ損なう可能性があります。プレートは、どの誤り訂正ブロックも、修復できるコードワードの60%を超えて失わないサイズになっており、残りはカメラのために確保されます。強度を上げると、そのサイズまでプレートが大きくなります。小さなコードではロゴが小さくなり、最小のもの（バージョン1、LまたはMのバージョン2、Lのバージョン3）ではプレートを描きません。
- **Image QR**：各モジュールを3 × 3のグリッドに分割します。外側のセルには写真が表示され、モジュールの値に合わせて暗くまたは明るくされます。中央のセルは前景または背景の色そのままで、スキャナーがサンプリングするのはここです。
- ファインダー、タイミング、アライメント、フォーマット、バージョンの各モジュールは、常にベタで描画されます。

印刷する前に`getScanScore(props)`でデザインを確認し、実際のスマートフォンのカメラでテストしてください。

## アートコードのエクスポート [#exporting-art-codes]

アートコードはベクター図形なので、どの形式でエクスポートしても鮮明なままです。

```ts
import { downloadQRCode, getQRAsEPS, getQRAsPrintPDF } from 'qrdx';

await downloadQRCode(props, { format: 'svg', size: { width: 1024, height: 1024 } });
const pdf = await getQRAsPrintPDF(props, { size: 40, unit: 'mm', colorMode: 'cmyk' });
const eps = await getQRAsEPS(props, { sizeMm: 40, bleedMm: 3, colorMode: 'cmyk' });
```

`getQRAsEPS`は、ポイント単位の`%%BoundingBox`を持つEPSF-3.0ファイルを書き出し、すべてのモジュール、アイ、フレームをPostScriptのパスとして出力します。印刷用PDFと同様に、線形グラデーションと放射グラデーションを（PostScript Level 3のシェーディングとして）保持し、透明度はありません。PNGとJPEGのロゴは画像として埋め込まれます。それ以外のロゴ形式は、ブラウザーでは変換され、サーバーでは含まれません。フレームのテキストにはHelveticaを使うため、Latin-1以外の文字は`?`として印刷されます。`svgToEPS(svg, { width })`は、このライブラリが描画する任意のSVGを変換します。

CLIもEPSを書き出せます：`qrdx generate "https://example.com" -o qr.eps`

<IfAvailable feature="aiArt" id="ai-art" title="AIアート">

[AI QRアート](/ai/art)は、Vercel AI Gatewayを通じて{facts.artModel}で、コードをシーンに変えます。30種類以上のスタイルプリセット、避けたい要素、**QRの視認性**スライダー（モデルがコードをどれだけ強く優先するか）、**創造性**スライダー（プロンプトをどれだけ自由に解釈するか）、1回の実行あたり1〜4個のバリエーション、そして任意の参照画像（ロゴやパレットなど。その色と形が引き継がれます）が利用できます。

すべての画像は、表示される前にサーバーでチェックされます。QRdxはモデルに、白黒のシンプルなコード（誤り訂正H、正方形のモジュール、広いクワイエットゾーン）を送り、モジュールのグリッド、ファインダーのアイ、クワイエットゾーンを維持するよう指示します。その後、モデルの画像をjsQRで、そのままの状態と、スマートフォンのカメラを模したモデルを通した状態の両方でデコードします。失敗した場合は、モデルがコードを描いた位置のモジュールグリッドを見つけ、モデル自身の画像上で、できるだけ小さな変更でコードを強化します。最初にファインダーのアイとクワイエットゾーン、次にモジュールの順で、画像がスキャンできるまで強度を段階的に上げます。カメラから見てコードが小さい場合も同様です。QRの視認性は、どこまで強化してよいかを決めます。それでも足りない場合にのみ、画像をImage QRコードとして描き直します。それでも指定した内容と完全に一致しない画像は、提供されません。続いて、ブラウザーがバリエーションを採点して最良のものを選びます。ダウンロードは1024 px、または2048 pxの印刷用コピー（リサンプリングして再チェック済み）から選べます。

提供された画像1枚につき、AIアートクレジットを1つ消費します。フリーアカウントは月3、Proは30、Businessはワークスペースの全員で共有する150です。失敗した画像やスキャンチェックに通らなかった画像ではクレジットを消費せず、印刷用コピーは無料です。AIアートはラスター画像で内容が固定されるため、編集可能なリンクにしたい場合は、[動的QRコード](/docs/dynamic-qr-codes)の短縮リンクを埋め込んでください。
