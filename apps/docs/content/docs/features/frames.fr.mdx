Ajoutez un cadre « Scan me », vérifiez qu'un design se scanne avant de le diffuser, et exportez un fichier vectoriel à une taille physique exacte.

## Cadres d'appel à l'action [#call-to-action-frames]

La prop `frame` dessine autour du code un cadre avec un court libellé. Elle fonctionne sur `QRCode`, `QRCodeSVG`, `QRCodeCanvas`, `getQRAsSVG`, `getQRData` et sur tous les utilitaires de téléchargement.

```tsx
import { QRCode } from "qrdx";

<QRCode
  value="https://example.com/menu"
  frame={{ style: "banner-bottom", text: "Scan for the menu", color: "#1e3a8a" }}
/>
```

Le cadre est ajouté **autour** du code : le résultat est plus grand, et les modules du QR ainsi que la zone de silence ne sont jamais recouverts, donc la lisibilité au scan reste identique. Un léger espace, de la couleur de fond du code, sépare le code du cadre.

| Option | Par défaut | Remarques |
| --- | --- | --- |
| `style` | — | L'un des {facts.frameStyles} styles ci-dessous, ou `none` (`FRAME_STYLES`) |
| `text` | `"Scan me"` | 24 caractères maximum. Passez `""` pour masquer le libellé |
| `color` | `#000000` | Couleur du cadre (`gradient-border` : couleur de départ, violet par défaut) |
| `textColor` | blanc sur le cadre, `color` sur les zones claires | Couleur du libellé |
| `secondaryText` | aucun | Second libellé, 24 caractères maximum : la bande du bas de `banner-top-bottom`, l'arc inférieur de `circle`, le pied de `menu-card` |
| `secondaryColor` | `#db2777` | Couleur de fin de `gradient-border` |
| `fontScale` | `1` | Taille du libellé de 0,5 à 1,5 ; les libellés se réduisent toujours pour tenir |

Styles :

- Bannières et bordures : `banner-bottom`, `banner-top`, `banner-top-bottom`, `border`, `rounded-border`, `gradient-border`, `focus` (angles en équerre)
- Bulles : `speech-bubble`, `speech-bubble-top`, `chat-bubble`
- Badges : `circle` (texte disposé autour d'un anneau), `badge` (ruban), `sticker` (découpe à l'emporte-pièce avec ombre)
- Objets : `polaroid`, `phone`, `ticket`, `tag` (étiquette à suspendre avec un trou), `envelope`, `menu-card`

Retrouvez-les tous, décodés dans votre navigateur, dans [Formes, yeux et cadres](/docs/styles#frames). Chaque cadre est composé de formes simples et de texte avec des couleurs opaques, si bien que les exports SVG, PNG, PDF et EPS sont identiques (la bordure en dégradé est dessinée avec de fins paliers de couleur unie, et les lettres courbes du cadre circulaire sont du texte pivoté dans tous les formats).

```tsx
<QRCode
  value="https://example.com"
  frame={{ style: "circle", text: "Scan me", secondaryText: "example.com", fontScale: 1.2 }}
/>
```

Le libellé utilise la pile de polices du système, donc rien n'est téléchargé. Comme le résultat s'agrandit, utilisez `getFrameDimensions(size, frame)` quand vous avez besoin de la largeur et de la hauteur finales :

```ts
import { getFrameDimensions } from "qrdx";

getFrameDimensions(400, { style: "banner-bottom" }); // { width: 496, height: 568 }
```

`FRAME_STYLES`, `frameSchema` (zod) et les types `QRFrame` / `FrameStyle` sont aussi exportés depuis `qrdx/types` pour la validation côté serveur.

### Dans la CLI [#in-the-cli]

```bash
qrdx generate "https://example.com/menu" --frame banner-bottom --frame-text "Scan for the menu" -o menu.png
```

`--frame-color` et `--frame-text-color` acceptent des couleurs hexadécimales. Si vous passez du texte ou des couleurs sans `--frame`, `banner-bottom` est utilisé.

## Cadres officiels [#official-frames]

En plus des styles intégrés, QRdx propose {facts.officialFrames} cadres officiels : des designs prêts à l'emploi pour les appels à l'action, les restaurants et cafés, les commerces et emballages, les événements et mariages, l'hôtellerie, les voyages et l'immobilier, la santé, le sport et l'éducation, ainsi que le monde professionnel et les réseaux sociaux. {facts.seasonalFrames} d'entre eux sont dédiés aux fêtes et aux saisons, du Nouvel An lunaire, de Holi, de l'Aïd et de Diwali à Hanoucca, Pâques, Thanksgiving et Noël. Chacun est une spécification de cadre avec des libellés et des couleurs modifiables, publiée sous licence CC0, et chacun est testé pour se scanner à des distances de smartphone.

Dans le [Playground](/playground), ouvrez **Cadre** puis **Plus**. Recherchez par nom, usage ou fête, ou choisissez un groupe. Les cadres des fêtes et saisons à venir sont affichés en premier. Vous les trouverez aussi dans la [communauté](/community/frames), publiés par @qrdx.

Le moteur les exporte sous le nom `OFFICIAL_FRAMES` :

```tsx
import { getOfficialFrame, QRCode } from "qrdx";

const diwali = getOfficialFrame("diwali-diya"); // undefined for an unknown id

{diwali && (
  <QRCode
    value="https://example.com/offers"
    frame={{ style: "custom", spec: diwali.spec, text: "Scan for offers" }}
  />
)}
```

`OFFICIAL_FRAME_INDEX` liste tous les cadres sans leur spécification, afin qu'un sélecteur puisse afficher toute la bibliothèque et ne charger les spécifications qu'à la demande. Dans l'[Image API](/docs/developers/image-api#community-items) et le [serveur MCP](/docs/developers/mcp), utilisez un cadre officiel comme élément de la communauté, par exemple `item=frame:diwali-diya`.

## Est-ce que ça se scanne ? [#will-it-scan]

`getScanScore` estime la fiabilité du scan d'un design. Il s'exécute dans le navigateur et charge [jsQR](https://github.com/cozmo/jsQR) à la demande.

```ts
import { getScanScore } from "qrdx";

const { score, grade, checks } = await getScanScore({
  value: "https://example.com",
  bodyPattern: "circle",
  cornerEyePattern: "gear",
});
// score: 0–100, grade: "great" | "ok" | "risky" | "fails"
// checks: [{ id, passed, message, fix? }]
```

Ce qu'il vérifie :

- **Décodage à 96, 160 et 320 px.** Le design est rendu à chaque largeur, avec un flou et une perte de contraste simulant une caméra, puis décodé plusieurs fois à des échelles légèrement différentes.
- **Contraste** entre chaque couleur du code (y compris les étapes de dégradé, les couleurs des yeux et des points) et l'arrière-plan, et si le code est sombre sur fond clair.
- **Couverture du logo** par rapport à ce que le niveau de correction d'erreurs peut récupérer.
- **Zone de silence** : la marge, plus l'espace qu'ajoute un cadre.
- **Risque lié à la forme des yeux** : les yeux `circle` peuvent être ignorés par certaines applications de scan (et les yeux `curly`, abandonnés, font échouer les décodeurs stricts si un design enregistré les utilise encore).
- **Associations de styles** (`style-pair`) : des formes qui échouent ensemble lors de nos tests de décodage, comme des points `small-square` à côté d'yeux carrés, et les centres abandonnés dans les designs enregistrés (voir `getStylePairRisk`).

`getImageScanScore(fileOrImage)` fait la même chose pour une image existante : il renvoie le contenu décodé ainsi que des vérifications de décodage, de contraste, de polarité, de zone de silence et de résolution, mesurées à partir des pixels. Le [vérificateur de scan](/tools/scan-checker) repose dessus.

<Callout type="info">
  Le score est une heuristique fondée sur un seul décodeur open source. Les applications d'appareil photo des téléphones sont souvent plus tolérantes : considérez-le comme un repère et testez par un scan les impressions importantes.
</Callout>

## Export prêt à imprimer [#print-ready-export]

`downloadPrintPDF` écrit un PDF vectoriel à une taille physique exacte. Les modules, les yeux et les cadres sont des tracés vectoriels (un logo reste une image raster).

```ts
import { downloadPrintPDF, downloadPrintSVG, getPrintLayout } from "qrdx";

const props = { value: "https://example.com", frame: { style: "banner-bottom" } } as const;

await downloadPrintPDF(props, {
  size: 40, // width of the code itself
  unit: "mm", // or "in"
  bleed: 3, // millimetres on every side
  cropMarks: true,
  colorMode: "cmyk",
});

await downloadPrintSVG(props, { size: 1.5, unit: "in" }); // width="…in" height="…in"

const layout = getPrintLayout(props, { size: 40 });
layout.trimWidth; // finished width in mm, frame included
layout.maxScanDistance; // 400 (mm)
```

- `size` correspond à la largeur du code ; un cadre s'ajoute à la taille finale.
- Avec un fond perdu, l'arrière-plan (ou la couleur d'un cadre carré) dépasse le bord de coupe, de sorte que le rognage ne laisse aucun liseré blanc. Les traits de coupe se trouvent en dehors du fond perdu.
- `colorMode: "cmyk"` utilise une conversion simple (`rgbToCmyk` : K = 1 − max(R, V, B), sans profil ICC ; le noir pur s'imprime en K seul). Demandez à votre imprimeur une conversion avec gestion des couleurs quand les couleurs exactes de votre marque comptent.
- Les dégradés linéaires et radiaux sont imprimés sous forme de dégradés lisses dans le PDF, en CMYK quand le PDF est en CMYK ; le SVG d'impression les conserve mais reste en RVB.
- Le texte des cadres dans le PDF utilise Helvetica Bold, donc les caractères hors Latin-1 peuvent ne pas s'afficher. Utilisez le SVG pour les autres écritures.
- `getQRAsPrintPDF` et `getQRAsPrintPDFBuffer` renvoient le fichier au lieu de le télécharger, et fonctionnent aussi dans Node.

**Quelle taille imprimer :** un code se scanne à environ dix fois sa largeur, donc taille ≈ distance de scan ÷ 10 (2 cm de large pour 20 cm). Les codes plus denses demandent plus ; le [calculateur de taille d'impression](/tools/print-size) en tient compte.
