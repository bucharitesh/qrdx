Wende professionelle QR-Code-Stile sofort an.

## Was sind Vorlagen? [#what-are-templates]

Vorlagen kombinieren Farben, Muster und visuelle Stile zu einsatzbereiten Paketen.

## Verfügbare Vorlagen [#available-templates]

### Default [#default]
Klassisch in Schwarz und Weiß.

```tsx
import { QRCode } from 'qrdx';

<QRCode value="https://example.com" templateId="default" size={256} />
```

### Arrow [#arrow]
Modernes geometrisches Design.

```tsx
<QRCode value="https://example.com" templateId="Arrow" size={256} />
```

### Standard Box [#standard-box]
Klares, strukturiertes Design.

```tsx
<QRCode value="https://example.com" templateId="StandardBox" size={256} />
```

### Square Border [#square-border]
Design mit Rahmen und klar definierten Kanten.

```tsx
<QRCode value="https://example.com" templateId="SquareBorder" size={256} />
```

### Striked Box [#striked-box]
Dynamisches Design mit diagonalen Elementen.

```tsx
<QRCode value="https://example.com" templateId="StrikedBox" size={256} />
```

### Halloween [#halloween]
Saisonales Halloween-Thema.

```tsx
<QRCode value="https://example.com" templateId="Halloween" size={256} />
```

## Vorlagen anpassen [#customize-templates]

Überschreibe die Standardwerte einer Vorlage:

```tsx
<QRCode
  value="https://example.com"
  templateId="Arrow"
  fgColor="#your-brand-color"
  hideLogo={false}
  logo="/your-logo.png"
  size={512}
/>
```

## Vorlagen-Registry [#template-registry]

### Alle Vorlagen abrufen [#get-all-templates]

```tsx
import { getAllTemplates } from 'qrdx';

const templates = getAllTemplates();
```

### Vorlagen-IDs abrufen [#get-template-ids]

```tsx
import { getTemplateIds } from 'qrdx';

const ids = getTemplateIds();
// Returns: ['default', 'Arrow', 'StandardBox', ...]
```

## Eigene Vorlagen [#custom-templates]

Erstelle deine eigenen Vorlagen:

```tsx
const brandTemplate = {
  id: 'brand-template',
  name: 'Brand Template',
  colors: {
    fgColor: '#1a56db',
    bgColor: '#ffffff',
    eyeColor: '#0d47a1',
    dotColor: '#3b82f6'
  },
  bodyPattern: 'rounded',
  cornerEyePattern: 'rounded',
  cornerEyeDotPattern: 'rounded'
};

<QRCode
  value="https://example.com"
  customTemplate={brandTemplate}
  size={256}
/>
```

## Wann du Vorlagen nutzen solltest [#when-to-use-templates]

- **Einheitliche Marke** — Sorge dafür, dass alle QR-Codes zusammenpassen
- **Schneller Einstieg** — Erziele schnell professionelle Ergebnisse
- **Saisonale Kampagnen** — Nutze thematische Vorlagen
- **Stapelerstellung** — Wende einheitliche Stile an
