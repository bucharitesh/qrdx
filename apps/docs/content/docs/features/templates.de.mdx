Setze einen QR-Code in ein fertiges Design, oder in dein eigenes.

## Was sind Vorlagen? [#what-are-templates]

Eine Vorlage ist SVG-Grafik, die um den Code herum gezeichnet wird: ein Kasten, ein Rand, ein Badge. Sie erhält den Code als `children` und platziert ihn innerhalb ihrer eigenen Zeichnung. Farben, Muster und Logos bleiben in den `QRCode`-Props, deshalb funktioniert eine Vorlage mit jedem Stil.

## Verfügbare Vorlagen [#available-templates]

### Default [#default]
Klassisch in Schwarz und Weiß.

```tsx
import { QRCode } from 'qrdx';

<QRCode value="https://example.com" templateId="default" size={256} />
```

### Arrow [#arrow]
Modernes, geometrisches Design.

```tsx
<QRCode value="https://example.com" templateId="Arrow" size={256} />
```

### Standard Box [#standard-box]
Klares, strukturiertes Design.

```tsx
<QRCode value="https://example.com" templateId="StandardBox" size={256} />
```

### Square Border [#square-border]
Design mit Rand und klar definierten Kanten.

```tsx
<QRCode value="https://example.com" templateId="SquareBorder" size={256} />
```

### Striked Box [#striked-box]
Dynamisches Design mit diagonalen Elementen.

```tsx
<QRCode value="https://example.com" templateId="StrikedBox" size={256} />
```

### Halloween [#halloween]
Saisonales Halloween-Motiv.

```tsx
<QRCode value="https://example.com" templateId="Halloween" size={256} />
```

### Dot Ring [#dot-ring]
Ein runder Code. Der Code sitzt in einer Scheibe aus Punkten innerhalb eines dunklen Rings, mit einer Textzeile entlang des Rings. Welche Punkte sichtbar sind, ergibt sich aus einem Hash des Code-Inhalts. So bekommt jeder Link seinen eigenen Ring, und derselbe Link bekommt immer denselben.

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  bodyPattern="circle-large"
  size={512}
/>
```

Die Einstellungen kommen in `customProps` (typisiert als `DotRingProps`):

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  customProps={{
    customText: "Scan for the menu",
    textPosition: "bottom",
    textColor: "#fde047",
    outerCircleColor: "#1e3a8a",
  }}
  size={512}
/>
```

| Prop | Standard | Hinweise |
| --- | --- | --- |
| `customText` | „Scan the QR code“ viermal rund um den Ring | Text entlang des Rings. Buchstaben, die nicht herumpassen, entfallen; `""` lässt den Ring leer |
| `textPosition` | `"top"` | `"top"`: oben zentriert, im Uhrzeigersinn gelesen. `"bottom"`: unten zentriert entlang des Rings, von links nach rechts gelesen |
| `textRotation` | `0` | Dreht den Text um die Mitte, in Grad |
| `textColor` | `#ffffff` | Textfarbe |
| `fontFamily` | System-Schriftenstapel | CSS-Schriftfamilie des Textes |
| `fontWeight` | `900` | Schriftstärke |
| `fontSize` | `32` | In der 593 Einheiten großen Zeichnung der Vorlage, in der der Code 300 breit ist |
| `fontLetterSpacing` | `3.5` | Zusätzlicher Abstand zwischen den Buchstaben, in denselben Einheiten |
| `outerCircleColor` | `fgColor` | Farbe des Rings |
| `strokeWidth`, `strokeColor` | `0`, `#000000` | Eine Kontur an beiden Kanten des Rings |
| `outerStrokeWidth`, `outerStrokeColor` | `strokeWidth`, `strokeColor` | Nur die Außenkante des Rings |
| `innerStrokeWidth`, `innerStrokeColor` | `strokeWidth`, `strokeColor` | Nur die Innenkante des Rings |

Ein Logo kommt wie bei jedem Code in die Mitte. Lange Links (Codes mit mehr als 49 Modulen Breite) behalten ein helles Band zwischen Code und Punkten, damit sie auch klein gedruckt noch scannen.

Der Text ist SVG-Text in der von dir gewählten Schrift. Standard ist der System-Schriftenstapel, es wird also nichts heruntergeladen. SVG- und PNG-Downloads im Browser verwenden die Schriften des Betrachters. PDF und EPS drucken ihn in Helvetica Bold, verwende dort also Latin-1-Text. `getQRAsPNG` aus `qrdx/node` braucht eine auf dem Server installierte Schrift, genau wie Rahmenbeschriftungen.

## Vorlagen anpassen [#customize-templates]

Die integrierten Vorlagen zeichnen ihre Grafik in `fgColor`. Alles andere, etwa Muster und ein Logo, stellst du wie gewohnt am Code ein:

```tsx
<QRCode
  value="https://example.com"
  templateId="Arrow"
  fgColor="#1a56db"
  imageSettings={{
    src: "/your-logo.png",
    width: 48,
    height: 48,
    excavate: true,
  }}
  size={512}
/>
```

## Eigene Vorlagen [#custom-templates]

Schreibe deine eigene Vorlage als `TemplateDefinition`. Ihr `wrapper` erhält den Code als `children` und gibt das zu zeichnende SVG zurück. Er zeichnet auf einer Fläche von 300 mal 300, und der Code kommt ebenfalls in dieser Größe an. Skaliere ihn also herunter, damit Platz für deine Grafik bleibt. `props` enthält `fgColor` und `bgColor` des Codes.

Dieses Beispiel zeichnet einen Ring um den Code:

```tsx
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg viewBox="0 0 300 300" width="300" height="300" xmlns="http://www.w3.org/2000/svg">
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

<QRCode
  value="https://example.com"
  customTemplate={ringTemplate}
  fgColor="#1a56db"
  size={256}
/>
```

Halte den Code groß genug, dass er aus der Entfernung scannt, aus der Leute ihr Handy halten, und lass zwischen ihm und deiner Grafik einen hellen Abstand. Prüfe das Ergebnis mit dem [Scan-Score](/docs/features/frames#will-it-scan).

## Wann du Vorlagen verwenden solltest [#when-to-use-templates]

- **Markenkonsistenz** — Sorge dafür, dass alle QR-Codes zusammenpassen
- **Schneller Start** — Erziele schnell professionelle Ergebnisse
- **Saisonale Kampagnen** — Nutze thematische Vorlagen
- **Stapelerzeugung** — Wende einheitliche Stile an
