Verpacke einen QR-Code in fertige Grafiken oder in deine eigenen.

## Was sind Templates? [#what-are-templates]

Ein Template ist eine SVG-Grafik, die um den Code herum gezeichnet wird: eine Box, ein Rahmen, ein Badge. Es erhält den Code als `children` und platziert ihn innerhalb der eigenen Zeichnung. Farben, Muster und Logos bleiben in den `QRCode`-Props, sodass ein Template mit jedem Stil funktioniert.

## Verfügbare Templates [#available-templates]

### Default [#default]
Klassisch in Schwarz-Weiß.

```tsx
import { QRCode } from 'qrdx';

<QRCode value="https://example.com" templateId="default" size={256} />
```

### Arrow [#arrow]
Modernes geometrisches Design.

```tsx
<QRCode value="https://example.com" templateId="Arrow" size={256} />
```

### Standard Box [#standard-box]
Klares, strukturiertes Design.

```tsx
<QRCode value="https://example.com" templateId="StandardBox" size={256} />
```

### Square Border [#square-border]
Design mit Rahmen und klar definierten Kanten.

```tsx
<QRCode value="https://example.com" templateId="SquareBorder" size={256} />
```

### Striked Box [#striked-box]
Dynamisches Design mit diagonalen Elementen.

```tsx
<QRCode value="https://example.com" templateId="StrikedBox" size={256} />
```

### Halloween [#halloween]
Saisonales Halloween-Thema.

```tsx
<QRCode value="https://example.com" templateId="Halloween" size={256} />
```

## Templates anpassen [#customize-templates]

Die integrierten Templates zeichnen ihre Grafik in `fgColor`. Alles andere, etwa Muster und ein Logo, stellst du wie gewohnt am Code ein:

```tsx
<QRCode
  value="https://example.com"
  templateId="Arrow"
  fgColor="#1a56db"
  imageSettings={{
    src: "/your-logo.png",
    width: 48,
    height: 48,
    excavate: true,
  }}
  size={512}
/>
```

```tsx
const templates = getAllTemplates();
```

```tsx
const ids = getTemplateIds();

```

## Eigene Templates [#custom-templates]

Schreibe dein eigenes Template als `TemplateDefinition`. Der `wrapper` erhält den Code als `children` und gibt das zu zeichnende SVG zurück. Er zeichnet auf einer Leinwand von 300 mal 300, und der Code kommt ebenfalls in dieser Größe an. Skaliere ihn also herunter, um Platz für deine Grafik zu lassen. `props` enthält `fgColor` und `bgColor` des Codes.

Dieses Beispiel zeichnet einen Ring um den Code:

```tsx
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg viewBox="0 0 300 300" width="300" height="300" xmlns="http://www.w3.org/2000/svg">
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

<QRCode
  value="https://example.com"
  customTemplate={ringTemplate}
  fgColor="#1a56db"
  size={256}
/>
```

Halte den Code groß genug, damit er aus der Entfernung gescannt werden kann, aus der Leute ihr Smartphone halten, und lass zwischen Code und Grafik einen hellen Abstand. Prüfe das Ergebnis mit dem [Scan-Score](/docs/features/frames#will-it-scan).

## Wann Templates sinnvoll sind [#when-to-use-templates]

- **Einheitliche Marke** — Sorge dafür, dass alle QR-Codes zusammenpassen
- **Schneller Start** — Erhalte schnell professionelle Ergebnisse
- **Saisonale Kampagnen** — Nutze Templates mit passendem Thema
- **Stapelerzeugung** — Wende einheitliche Stile an
