QRdx 提供三种方式，把二维码变成艺术作品：

| | 工作原理 | 输出 | 费用 |
|---|---|---|---|
| **Logo QR** | 位于徽标形状内的模块采用徽标的颜色，其余模块淡化为较浅的色调 | 矢量（SVG、PDF、EPS、PNG） | 免费 |
| **Image QR** | 每个模块都显示照片内容，中心方块保留真实值（半色调） | 矢量（SVG、PDF、EPS、PNG） | 免费 |
| **AI 艺术** | 由 AI 图像模型把二维码重绘为一幅场景，并且每张图像都经过验证可扫描 | 1024 px 图像，2048 px 印刷版 | AI 艺术额度 |

Logo QR 和 Image QR 由 `qrdx` 库自身绘制，因此可以离线使用，在编辑器、服务器和 Node 中都能运行，而且结果始终是真正的二维码：定位图案、定时图案和对齐图案不会被改动。

## 在编辑器中 [#in-the-editor]

打开 [Playground](/playground?tab=art)，进入 **Art** 标签页，选择 **Logo QR** 或 **Image QR**：

1. 上传徽标或照片（PNG、JPG、WebP 或 SVG，最大 1 MB）。透明背景的 PNG 或 SVG 能得到最干净的 Logo QR。
2. 设置**强度**：低强度保持外观朴素的二维码，高强度则显示更多图片内容。
3. 查看滑块旁边的**扫描检查**。它会在浏览器中以三种尺寸解码艺术二维码，与预览中的[扫描评分](/docs/qr-detection)类似。

上传艺术图像后，纠错等级会设为 `H`，为艺术效果留出最大空间。图像不会离开你的浏览器：只有一个小的颜色网格（宽 64 或 96 像素）会随设计一起保存。

## 在代码中 [#in-code]

传入 `art` 属性，包含模式、采样后的图像和可选的强度（0 到 1，默认 0.6）：

```tsx
import { QRCodeSVG, loadQRArtImage } from 'qrdx';

// Browser: sample an uploaded file, a data URL or an <img>
const image = await loadQRArtImage(file, { mode: 'logo' });

<QRCodeSVG
  value="https://example.com"
  size={512}
  level="H"
  art={{ mode: 'logo', image, intensity: 0.7 }}
/>;
```

在服务器或 Node 中，请自行解码图像，并把 RGBA 像素传给 `createQRArtImage`：

```ts
import sharp from 'sharp';
import { createQRArtImage } from 'qrdx';

const { data, info } = await sharp('photo.jpg')
  .ensureAlpha()
  .raw()
  .toBuffer({ resolveWithObject: true });

const image = createQRArtImage(
  { data, width: info.width, height: info.height },
  { maxSize: 96 }
);
// art={{ mode: 'halftone', image, intensity: 0.8 }}
```

`art.image` 是普通 JSON（`{ width, height, data }`，其中 data 为 base64 编码的 RGBA），因此你可以将它与已保存的设计一起存储，并在任何地方同步渲染出相同的二维码，无需再次获取图片。

| 选项 | 取值 | 说明 |
|---|---|---|
| `mode` | `logo`、`halftone` | `halftone` 在编辑器中称为 "Image QR" |
| `image` | 来自 `loadQRArtImage` 或 `createQRArtImage` | 最多 192 × 192 个采样点 |
| `intensity` | `0` 到 `1` | 默认 `0.6`；`0` 看起来与普通二维码相同 |

艺术效果会替换主体图案；角落的定位点保留各自的 `cornerEyePattern`、`cornerEyeDotPattern` 和颜色。艺术效果使用渐变 `fgColor`/`bgColor` 的第一个颜色，并要求浅色背景上使用深色前景（颜色反转时会退回普通外观）。

### 如何保持可扫描性 [#how-scannability-is-kept]

- **Logo QR**：徽标内的深色模块会被重新着色，但只会加深到扫描器仍视为深色的亮度；徽标内的浅色模块会采用淡色调，并保持在浅色阈值之上。徽标外的深色模块会淡化为灰色，但不会比深色阈值更浅。
- **Logo QR 徽标底板**：底板下的每个模块都可能损坏一个码字。底板的大小经过设定，使任何纠错块损失的码字都不超过其可修复数量的 60%，其余部分留给相机使用。强度越高，底板越大，直至达到该上限。较小的二维码使用较小的徽标，最小的几种（版本 1、L 或 M 级的版本 2、L 级的版本 3）不绘制底板。
- **Image QR**：每个模块被分成 3 × 3 的网格。外围单元显示照片，并根据模块的值调深或调浅，中心保留精确的前景色或背景色，这正是扫描器采样的位置。
- 定位、定时、对齐、格式和版本模块始终以纯色绘制。

打印前请用 `getScanScore(props)` 检查任何设计，并用真实手机相机进行测试。

## 导出艺术二维码 [#exporting-art-codes]

艺术二维码是矢量图形，因此每种导出格式都能保持清晰：

```ts
import { downloadQRCode, getQRAsEPS, getQRAsPrintPDF } from 'qrdx';

await downloadQRCode(props, { format: 'svg', size: { width: 1024, height: 1024 } });
const pdf = await getQRAsPrintPDF(props, { size: 40, unit: 'mm', colorMode: 'cmyk' });
const eps = await getQRAsEPS(props, { sizeMm: 40, bleedMm: 3, colorMode: 'cmyk' });
```

`getQRAsEPS` 会写出 EPSF-3.0 文件，其中的 `%%BoundingBox` 以点为单位，每个模块、定位点和边框都是一条 PostScript 路径。与印刷版 PDF 一样，它保留线性和径向渐变（以 PostScript Level 3 渐变形式），并且没有透明度。PNG 和 JPEG 徽标会作为图像嵌入；其他格式的徽标在浏览器中会被转换，在服务器上则会被省略。边框文字使用 Helvetica，因此 Latin-1 以外的字符会打印为 `?`。`svgToEPS(svg, { width })` 可转换此库渲染的任何 SVG。

CLI 同样可以写出 EPS：`qrdx generate "https://example.com" -o qr.eps`。

[AI 二维码艺术](/ai/art)通过 Vercel AI Gateway，使用 {facts.artModel} 把你的二维码变成一幅场景。你可以按类别浏览或搜索 {facts.aiArtStyles} 种风格预设，每种都附有通过扫描检查的预览。此外还有需避免的内容、**二维码可见度**滑块（模型对二维码的偏重程度）、**创意度**滑块（模型解读提示词的自由程度）、每次生成 1 到 4 个变体，以及可选的参考图像（例如徽标或调色板），其颜色和形状会被沿用。

每张图像在你看到之前都会在服务器上检查。QRdx 向模型发送一个纯黑白二维码（纠错等级 H、方形模块、较宽的静区），并要求模型保留模块网格、定位点和静区。然后它用 jsQR 解码模型生成的图像，包括原图以及经过手机相机模型处理后的图像。如果解码失败，它会找到模型绘制的模块网格，并在模型自己的图像上尽可能少地增强二维码：先是定位点和静区，然后是模块，逐步提高强度，直到图像可以扫描，二维码在相机视野中较小时也是如此。二维码可见度决定它最多能增强到什么程度。只有在这样仍不够时，它才会把图像重绘为 Image QR 二维码。如果图像仍无法解码出你的确切内容，就不会交付。随后你的浏览器会对各个变体评分并选出最佳的一个；可以下载 1024 px 版本，或 2048 px 印刷版（经过重采样并再次检查）。

每张成功交付的图像消耗一个 AI 艺术额度：免费版账户每月 3 个，Pro 每月 30 个，Business 每月 150 个，由工作区所有成员共享。失败或未通过扫描检查的图像不消耗额度，印刷版也不收费。AI 艺术是位图，内容固定，因此如需可编辑的链接，请在其中放入[动态二维码](/docs/dynamic-qr-codes)的短链接。
