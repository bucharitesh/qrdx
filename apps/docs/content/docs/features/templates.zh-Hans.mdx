用现成的图案，或你自己的图案，把二维码包起来。

## 什么是模板？ [#what-are-templates]

模板是围绕二维码绘制的 SVG 图案：一个方框、一道边框、一枚徽章。它以 `children` 的形式接收二维码，并把二维码放进自己的绘图中。颜色、图案样式和徽标仍由 `QRCode` 的属性控制，因此模板可以搭配任何样式使用。

## 可用模板 [#available-templates]

### 默认 [#default]
经典黑白。

```tsx
import { QRCode } from 'qrdx';

<QRCode value="https://example.com" templateId="default" size={256} />
```

### 箭头 [#arrow]
现代几何设计。

```tsx
<QRCode value="https://example.com" templateId="Arrow" size={256} />
```

### 标准方框 [#standard-box]
简洁、规整的设计。

```tsx
<QRCode value="https://example.com" templateId="StandardBox" size={256} />
```

### 方形边框 [#square-border]
边缘分明的带边框设计。

```tsx
<QRCode value="https://example.com" templateId="SquareBorder" size={256} />
```

### 斜纹方框 [#striked-box]
带有斜向元素的动感设计。

```tsx
<QRCode value="https://example.com" templateId="StrikedBox" size={256} />
```

### 万圣节 [#halloween]
万圣节季节主题。

```tsx
<QRCode value="https://example.com" templateId="Halloween" size={256} />
```

### 圆点环 [#dot-ring]
圆形二维码。二维码位于深色圆环内的圆点圆盘中，圆环上沿环排布一行文字。显示哪些圆点由二维码内容的哈希值决定，因此每个链接都有自己独一无二的圆环，而同一个链接始终得到同一个圆环。

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  bodyPattern="circle-large"
  size={512}
/>
```

它的设置放在 `customProps` 中（类型为 `DotRingProps`）：

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  customProps={{
    customText: "Scan for the menu",
    textPosition: "bottom",
    textColor: "#fde047",
    outerCircleColor: "#1e3a8a",
  }}
  size={512}
/>
```

| 属性 | 默认值 | 说明 |
| --- | --- | --- |
| `customText` | “Scan the QR code”，沿圆环重复四次 | 沿圆环排布的文字。放不下的字母会被省略；设为 `""` 则圆环上不显示文字 |
| `textPosition` | `"top"` | `"top"`：在顶部居中，按顺时针方向阅读。`"bottom"`：在底部居中，从左到右阅读 |
| `textRotation` | `0` | 让文字绕中心旋转，单位为度 |
| `textColor` | `#ffffff` | 文字颜色 |
| `fontFamily` | 系统字体栈 | 文字的 CSS 字体族 |
| `fontWeight` | `900` | 字重 |
| `fontSize` | `32` | 以模板 593 单位的绘图为基准，其中二维码宽 300 |
| `fontLetterSpacing` | `3.5` | 字母之间的额外间距，单位相同 |
| `outerCircleColor` | `fgColor` | 圆环颜色 |
| `strokeWidth`、`strokeColor` | `0`、`#000000` | 沿圆环两侧边缘的描边 |
| `outerStrokeWidth`、`outerStrokeColor` | `strokeWidth`、`strokeColor` | 仅圆环外缘 |
| `innerStrokeWidth`、`innerStrokeColor` | `strokeWidth`、`strokeColor` | 仅圆环内缘 |

和其他二维码一样，可以在中间放置徽标。较长的链接（宽度超过 49 个模块的二维码）会在二维码与圆点之间保留一圈浅色带，这样即使印得很小也能被扫描。

文字是 SVG 文本，使用你选择的字体；默认是系统字体栈，因此不会下载任何字体。在浏览器中下载 SVG 和 PNG 时会使用查看者的字体。PDF 和 EPS 以 Helvetica Bold 打印文字，因此请在这两种格式中使用 Latin-1 文本。来自 `qrdx/node` 的 `getQRAsPNG` 需要服务器上安装字体，边框标签也是如此。

## 自定义模板 [#customize-templates]

内置模板用 `fgColor` 绘制其图案。其他一切，例如图案样式和徽标，仍照常设置在二维码上：

```tsx
<QRCode
  value="https://example.com"
  templateId="Arrow"
  fgColor="#1a56db"
  imageSettings={{
    src: "/your-logo.png",
    width: 48,
    height: 48,
    excavate: true,
  }}
  size={512}
/>
```

```tsx
import { getAllTemplates } from 'qrdx';

const templates = getAllTemplates();
```

```tsx
import { getTemplateIds } from 'qrdx';

const ids = getTemplateIds();
// Returns: ['default', 'Arrow', 'StandardBox', ...]
```

## 自定义模板 [#custom-templates]

把你自己的模板写成一个 `TemplateDefinition`。它的 `wrapper` 以 `children` 的形式接收二维码，并返回要绘制的 SVG。它在 300 × 300 的画布上绘制，二维码也以这个尺寸传入，所以请把它缩小，为你的图案留出空间。`props` 携带二维码的 `fgColor` 和 `bgColor`。

下面这个模板会在二维码周围画一圈圆环：

```tsx
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg viewBox="0 0 300 300" width="300" height="300" xmlns="http://www.w3.org/2000/svg">
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

<QRCode
  value="https://example.com"
  customTemplate={ringTemplate}
  fgColor="#1a56db"
  size={256}
/>
```

请让二维码足够大，确保人们手持手机的距离也能扫描，并在二维码与你的图案之间留出一道浅色间隙。用[扫描评分](/docs/features/frames#will-it-scan)检查效果。

## 何时使用模板 [#when-to-use-templates]

- **品牌一致性** — 确保所有二维码风格统一
- **快速设置** — 快速获得专业效果
- **季节性活动** — 使用主题模板
- **批量生成** — 套用一致的样式

## 模板选择指南 [#template-selection-guide]

| 模板 | 最适合 | 风格 |
|----------|----------|------|
| 默认 | 专业场景 | 中性 |
| 箭头 | 科技、现代 | 动感 |
| 标准方框 | 企业 | 专业 |
| 方形边框 | 正式场合 | 规整 |
| 斜纹方框 | 营销 | 活力 |
| 万圣节 | 季节性 | 趣味 |
| 圆点环 | 圆形二维码、海报、贴纸 | 醒目 |
