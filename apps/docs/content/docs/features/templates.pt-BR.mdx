Um template é uma moldura que encaixa o código dentro da própria arte. No Playground, os templates não ficam em uma lista separada. Arrow, Standard Box, Square Border, Striked Box, Halloween e Dot Ring são blocos no grupo **Classic** do seletor de molduras, ao lado das outras [molduras](/docs/features/frames), e escolher qualquer moldura substitui a anterior.

Os templates se diferenciam das outras molduras em um ponto: o tamanho. Uma moldura adiciona espaço ao redor do código, então `size` é a largura do código e a imagem cresce. Um template desenha a arte inteira em `size`, com o código menor dentro dela.

## Templates integrados [#built-in-templates]

Passe o id como `templateId`. A Image API recebe como `template` e a CLI como `--template`.

| `templateId` | Nome | Cor |
|--------------|------|-----|
| `Arrow` | Arrow | A cor escura do código (`fgColor`) |
| `StandardBox` | Standard Box | `fgColor` |
| `SquareBorder` | Square Border | `fgColor` |
| `StrikedBox` | Striked Box | Cor escura própria |
| `Halloween` | Halloween | Laranja, verde e preto próprios |
| `DotRing` | Dot Ring | Anel em `fgColor`, texto em branco; ambos podem mudar (abaixo) |

`default` não desenha arte. Ele apenas recua um pouco o código, para 95% de `size`.

```tsx
import { QRCode } from 'qrdx';

<QRCode value="https://example.com" templateId="Arrow" fgColor="#1a56db" size={256} />
```

Cores, padrões e logo continuam nas props do próprio código, então um template funciona com qualquer estilo:

```tsx
<QRCode
  value="https://example.com"
  templateId="StandardBox"
  fgColor="#1a56db"
  imageSettings={{
    src: "/your-logo.png",
    width: 48,
    height: 48,
    excavate: true,
  }}
  size={512}
/>
```

## Dot Ring [#dot-ring]

Um código redondo. O código fica em um disco de pontos dentro de um anel escuro, com uma linha de texto ao longo do anel. Os pontos exibidos vêm de um hash do conteúdo do código, então cada link ganha um anel só dele e o mesmo link sempre recebe o mesmo anel.

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  bodyPattern="circle-large"
  size={512}
/>
```

As configurações ficam em `customProps` (tipado como `DotRingProps`):

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  customProps={{
    customText: "Scan for the menu",
    textPosition: "bottom",
    textColor: "#fde047",
    outerCircleColor: "#1e3a8a",
  }}
  size={512}
/>
```

| Prop | Padrão | Notas |
| --- | --- | --- |
| `customText` | "Scan the QR code" quatro vezes ao redor | Texto ao longo do anel; `""` deixa o anel vazio. Texto longo demais para o anel é ajustado (abaixo) |
| `textFill` | `"none"` | `"repeat"` repete o texto ao redor de todo o anel (abaixo) |
| `textPosition` | `"top"` | `"top"`: centralizado no topo, lido no sentido horário. `"bottom"`: centralizado na parte de baixo, lido da esquerda para a direita |
| `textRotation` | `0` | Gira o texto em torno do centro, em graus |
| `textColor` | `#ffffff` | Cor do texto |
| `fontFamily` | pilha de fontes do sistema | Família de fonte CSS do texto |
| `fontWeight` | `900` | Peso da fonte |
| `fontSize` | `32` | No desenho de 593 unidades do template, em que o código tem 300 de largura. Texto longo pode ser desenhado menor |
| `fontLetterSpacing` | `3.5` | Espaço extra entre as letras, nas mesmas unidades. Texto longo e `textFill` o ajustam |
| `outerCircleColor` | `fgColor` | Cor do anel |
| `strokeWidth`, `strokeColor` | `0`, `#000000` | Um contorno nas duas bordas do anel |
| `outerStrokeWidth`, `outerStrokeColor` | `strokeWidth`, `strokeColor` | Só a borda externa do anel |
| `innerStrokeWidth`, `innerStrokeColor` | `strokeWidth`, `strokeColor` | Só a borda interna do anel |

Texto que cabe no anel é posicionado como foi escrito, centralizado no topo ou na parte de baixo. Texto longo demais nunca encosta no próprio começo. Primeiro as letras se aproximam, depois a fonte diminui, até a metade do tamanho padrão (o menor tamanho usado nos rótulos de moldura). O texto então fecha o anel com um espaço de palavra onde encontra o começo. Se mesmo assim não couber nesse tamanho, um texto que repete uma frase mantém tantas cópias inteiras quanto couberem, e qualquer outro texto é cortado depois da última palavra inteira que couber e termina com "…".

Um logo vai no meio, como em qualquer código. Links longos (códigos com mais de 49 módulos de largura) mantêm uma faixa clara entre o código e os pontos, para que ainda tenham leitura quando impressos pequenos.

O texto é texto SVG na fonte que você escolher; o padrão é a pilha de fontes do sistema, então nada é baixado. Downloads em SVG e PNG no navegador usam as fontes de quem está vendo. PDF e EPS imprimem em Helvetica Bold, então use texto Latin-1 nesses formatos. `getQRAsPNG` de `qrdx/node` precisa de uma fonte instalada no servidor, assim como os rótulos de moldura.

### Preenchendo o anel [#filling-the-ring]

Uma frase curta deixa parte do anel vazia. Defina `textFill: "repeat"` para repeti-la quantas vezes couber, com o espaçamento ajustado para que o anel feche com o mesmo intervalo que existe entre as cópias:

```tsx
<QRCode
  value="https://example.com/docs"
  templateId="DotRing"
  customProps={{ customText: "Read the docs *", textFill: "repeat" }}
  size={512}
/>
```

Informe a frase uma vez só. Um texto que já repete uma frase, como `"Make your own * Make your own *"`, é lido como essa frase, então preenche o anel do mesmo jeito.

## Templates são especificações de moldura [#templates-are-frame-specs]

A arte de Arrow, Standard Box, Square Border, Striked Box e Halloween é uma [especificação de moldura](/docs/features/frames#frame-specs), no mesmo formato JSON de todas as outras molduras, desenhada pelo mesmo motor. `getTemplate(id).spec` a retorna. Use-a como moldura quando quiser o dimensionamento de moldura (o código mantém o tamanho e a arte cresce ao redor) e a opção de cor da moldura:

```tsx
import { getTemplate, QRCode } from 'qrdx';

const spec = getTemplate('Arrow')?.spec;

<QRCode
  value="https://example.com"
  frame={spec && { style: 'custom', spec, color: '#1a56db' }}
  size={256}
/>
```

Dot Ring não tem especificação: seus pontos vêm do conteúdo do código, então ele os desenha em código (veja [Molduras que você desenha em código](#frames-you-draw-in-code)).

`templateId` desenha a mesma arte de antes. Designs salvos, URLs de imagem, comandos da CLI e códigos que usam um id de template continuam com a mesma aparência de sempre.

## Registro de templates [#template-registry]

```tsx
import { getAllTemplates, getTemplate, getTemplateIds } from 'qrdx';

getTemplateIds(); // ['default', 'Arrow', 'StandardBox', ...]
getAllTemplates(); // every TemplateDefinition, with its id and name
getTemplate('Halloween'); // one by id
```

## Molduras que você desenha em código [#frames-you-draw-in-code]

Uma especificação de moldura descreve uma arte fixa. Quando a arte precisa ser calculada, escreva um `TemplateDefinition` e passe-o como `customTemplate`. O `wrapper` dele recebe o código como `children` e retorna o SVG a desenhar. Ele desenha em uma tela de 300 por 300, e o código também chega nesse tamanho, então reduza-o para deixar espaço para a sua arte. `props` traz o `fgColor` e o `bgColor` do código, e o terceiro argumento traz o `url` e o `pixelSize` do código.

Este desenha um anel ao redor do código:

```tsx
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg viewBox="0 0 300 300" width="300" height="300" xmlns="http://www.w3.org/2000/svg">
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

<QRCode
  value="https://example.com"
  customTemplate={ringTemplate}
  fgColor="#1a56db"
  size={256}
/>
```

Mantenha o código grande o bastante para ter leitura de onde as pessoas vão segurar o celular, e deixe um espaço claro entre ele e a sua arte. Confira o resultado com a [pontuação de leitura](/docs/features/frames#will-it-scan).
