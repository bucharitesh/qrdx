Um template é uma moldura que encaixa o código dentro da própria arte. No Playground, os templates não ficam em uma lista separada. Arrow, Standard Box, Square Border, Striked Box, Halloween e Dot Ring são blocos no grupo **Classic** do seletor de molduras, junto com as outras [molduras](/docs/features/frames), e escolher qualquer moldura substitui a anterior.

Os templates se diferenciam das outras molduras em um ponto: o tamanho. Uma moldura adiciona espaço ao redor do código, então `size` é a largura do código e a imagem cresce. Um template desenha toda a arte em `size`, com o código menor dentro dela.

## Templates incluídos [#built-in-templates]

Passe o id como `templateId`. A Image API recebe como `template` e a CLI como `--template`.

| `templateId` | Nome | Cor |
|--------------|------|-----|
| `Arrow` | Arrow | A cor escura do código (`fgColor`) |
| `StandardBox` | Standard Box | `fgColor` |
| `SquareBorder` | Square Border | `fgColor` |
| `StrikedBox` | Striked Box | Cor escura própria |
| `Halloween` | Halloween | Laranja, verde e preto próprios |
| `DotRing` | Dot Ring | O anel em `fgColor`, o texto em branco; ambos podem mudar (veja abaixo) |

`default` não desenha arte. Ele só recua um pouco o código, para 95% de `size`.

```tsx
import { QRCode } from 'qrdx';

<QRCode value="https://example.com" templateId="Arrow" fgColor="#1a56db" size={256} />
```

Cores, padrões e logo continuam nas props do próprio código, então um template funciona com qualquer estilo:

```tsx
<QRCode
  value="https://example.com"
  templateId="StandardBox"
  fgColor="#1a56db"
  imageSettings={{
    src: "/your-logo.png",
    width: 48,
    height: 48,
    excavate: true,
  }}
  size={512}
/>
```

## Dot Ring [#dot-ring]

Um código redondo. O código fica em um disco de pontos dentro de um anel escuro, com uma linha de texto ao longo do anel. Os pontos exibidos vêm de um hash do conteúdo do código, então cada link ganha um anel só dele e o mesmo link sempre recebe o mesmo anel.

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  bodyPattern="circle-large"
  size={512}
/>
```

Os ajustes ficam em `customProps` (com o tipo `DotRingProps`):

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  customProps={{
    customText: "Scan for the menu",
    textPosition: "bottom",
    textColor: "#fde047",
    outerCircleColor: "#1e3a8a",
  }}
  size={512}
/>
```

| Prop | Padrão | Observações |
| --- | --- | --- |
| `customText` | "Scan the QR code" repetido quatro vezes ao redor | Texto ao longo do anel. Letras que não cabem ao redor são omitidas; `""` deixa o anel vazio |
| `textPosition` | `"top"` | `"top"`: centralizado na parte de cima, lido no sentido horário. `"bottom"`: centralizado na parte de baixo, lido da esquerda para a direita |
| `textRotation` | `0` | Gira o texto em torno do centro, em graus |
| `textColor` | `#ffffff` | Cor do texto |
| `fontFamily` | pilha de fontes do sistema | Família de fonte CSS do texto |
| `fontWeight` | `900` | Peso da fonte |
| `fontSize` | `32` | No desenho de 593 unidades do template, em que o código tem 300 de largura |
| `fontLetterSpacing` | `3.5` | Espaço extra entre as letras, nas mesmas unidades |
| `outerCircleColor` | `fgColor` | Cor do anel |
| `strokeWidth`, `strokeColor` | `0`, `#000000` | Um contorno nas duas bordas do anel |
| `outerStrokeWidth`, `outerStrokeColor` | `strokeWidth`, `strokeColor` | Só a borda externa do anel |
| `innerStrokeWidth`, `innerStrokeColor` | `strokeWidth`, `strokeColor` | Só a borda interna do anel |

Um logo vai no meio, como em qualquer código. Links longos (códigos com mais de 49 módulos de largura) mantêm uma faixa clara entre o código e os pontos, para que ainda possam ser lidos quando impressos pequenos.

O texto é texto SVG na fonte que você escolher; o padrão é a pilha de fontes do sistema, então nada é baixado. Os downloads em SVG e PNG no navegador usam as fontes de quem está vendo. PDF e EPS imprimem o texto em Helvetica Bold, então use texto Latin-1 nesses formatos. `getQRAsPNG` de `qrdx/node` precisa de uma fonte instalada no servidor, assim como os rótulos das molduras.

## Templates são especificações de moldura [#templates-are-frame-specs]

A arte de Arrow, Standard Box, Square Border, Striked Box e Halloween é uma [especificação de moldura](/docs/features/frames#frame-specs), o mesmo formato JSON de todas as outras molduras, desenhada pelo mesmo mecanismo. `getTemplate(id).spec` retorna essa especificação. Use-a como moldura quando quiser o dimensionamento de moldura (o código mantém o tamanho e a arte cresce ao redor) e a opção de cor da moldura:

```tsx
import { getTemplate, QRCode } from 'qrdx';

const spec = getTemplate('Arrow')?.spec;

<QRCode
  value="https://example.com"
  frame={spec && { style: 'custom', spec, color: '#1a56db' }}
  size={256}
/>
```

O Dot Ring não tem especificação: os pontos vêm do conteúdo do código, então ele os desenha em código (veja [Molduras que você desenha em código](#frames-you-draw-in-code)).

`templateId` desenha a mesma arte de antes. Designs salvos, URLs de imagem, comandos da CLI e códigos que usam um id de template continuam com a mesma aparência de sempre.

## Registro de templates [#template-registry]

```tsx
import { getAllTemplates, getTemplate, getTemplateIds } from 'qrdx';

getTemplateIds(); // ['default', 'Arrow', 'StandardBox', ...]
getAllTemplates(); // every TemplateDefinition, with its id and name
getTemplate('Halloween'); // one by id
```

## Molduras que você desenha em código [#frames-you-draw-in-code]

Uma especificação de moldura descreve uma arte fixa. Quando a arte precisa ser calculada, escreva um `TemplateDefinition` e passe-o como `customTemplate`. O `wrapper` recebe o código como `children` e retorna o SVG a ser desenhado. Ele desenha em um canvas de 300 por 300, e o código também chega nesse tamanho, então reduza-o para deixar espaço para a sua arte. `props` traz o `fgColor` e o `bgColor` do código, e o terceiro argumento tem o `url` e o `pixelSize` do código.

Este exemplo desenha um anel ao redor do código:

```tsx
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg viewBox="0 0 300 300" width="300" height="300" xmlns="http://www.w3.org/2000/svg">
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

<QRCode
  value="https://example.com"
  customTemplate={ringTemplate}
  fgColor="#1a56db"
  size={256}
/>
```

Mantenha o código grande o bastante para ser lido de onde as pessoas vão segurar o celular e deixe um espaço claro entre ele e a sua arte. Confira o resultado com a [pontuação de leitura](/docs/features/frames#will-it-scan).
