Envolva um QR code em uma arte pronta ou na sua própria.

## O que são templates? [#what-are-templates]

Um template é uma arte em SVG desenhada ao redor do código: uma caixa, uma borda, um selo. Ele recebe o código como `children` e o posiciona dentro do próprio desenho. Cores, padrões e logos continuam nas props do `QRCode`, então um template funciona com qualquer estilo.

## Templates disponíveis [#available-templates]

### Default [#default]
Preto e branco clássico.

```tsx
import { QRCode } from 'qrdx';

<QRCode value="https://example.com" templateId="default" size={256} />
```

### Arrow [#arrow]
Design geométrico moderno.

```tsx
<QRCode value="https://example.com" templateId="Arrow" size={256} />
```

### Standard Box [#standard-box]
Design limpo e estruturado.

```tsx
<QRCode value="https://example.com" templateId="StandardBox" size={256} />
```

### Square Border [#square-border]
Design com borda e contornos bem definidos.

```tsx
<QRCode value="https://example.com" templateId="SquareBorder" size={256} />
```

### Striked Box [#striked-box]
Design dinâmico com elementos diagonais.

```tsx
<QRCode value="https://example.com" templateId="StrikedBox" size={256} />
```

### Halloween [#halloween]
Tema sazonal de Halloween.

```tsx
<QRCode value="https://example.com" templateId="Halloween" size={256} />
```

### Dot Ring [#dot-ring]
Um código redondo. O código fica em um disco de pontos dentro de um anel escuro, com uma linha de texto ao longo do anel. Quais pontos aparecem vem de um hash do conteúdo do código, então cada link ganha um anel só dele e o mesmo link sempre recebe o mesmo anel.

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  bodyPattern="circle-large"
  size={512}
/>
```

As configurações ficam em `customProps` (com tipo `DotRingProps`):

```tsx
<QRCode
  value="https://example.com"
  templateId="DotRing"
  customProps={{
    customText: "Scan for the menu",
    textPosition: "bottom",
    textColor: "#fde047",
    outerCircleColor: "#1e3a8a",
  }}
  size={512}
/>
```

| Prop | Padrão | Observações |
| --- | --- | --- |
| `customText` | "Scan the QR code" quatro vezes ao redor | Texto ao longo do anel. As letras que não cabem no anel são omitidas; `""` deixa o anel vazio |
| `textPosition` | `"top"` | `"top"`: centralizado na parte de cima, lido no sentido horário. `"bottom"`: centralizado na parte de baixo, lido da esquerda para a direita |
| `textRotation` | `0` | Gira o texto em torno do centro, em graus |
| `textColor` | `#ffffff` | Cor do texto |
| `fontFamily` | fontes padrão do sistema | Família de fonte CSS do texto |
| `fontWeight` | `900` | Peso da fonte |
| `fontSize` | `32` | No desenho de 593 unidades do template, em que o código tem 300 de largura |
| `fontLetterSpacing` | `3.5` | Espaço extra entre as letras, nas mesmas unidades |
| `outerCircleColor` | `fgColor` | Cor do anel |
| `strokeWidth`, `strokeColor` | `0`, `#000000` | Um contorno nas duas bordas do anel |
| `outerStrokeWidth`, `outerStrokeColor` | `strokeWidth`, `strokeColor` | Só a borda externa do anel |
| `innerStrokeWidth`, `innerStrokeColor` | `strokeWidth`, `strokeColor` | Só a borda interna do anel |

Um logo vai no centro, como em qualquer código. Links longos (códigos com mais de 49 módulos de largura) mantêm uma faixa clara entre o código e os pontos, para que ainda sejam lidos quando impressos em tamanho pequeno.

O texto é texto SVG na fonte que você escolher; o padrão são as fontes do sistema, então nada é baixado. Os downloads em SVG e PNG no navegador usam as fontes de quem está vendo. PDF e EPS imprimem o texto em Helvetica Bold, então use texto Latin-1 nesses formatos. `getQRAsPNG` de `qrdx/node` precisa de uma fonte instalada no servidor, assim como os rótulos de moldura.

## Personalizar templates [#customize-templates]

Os templates integrados desenham a arte em `fgColor`. Todo o resto, como padrões e logo, é definido no código normalmente:

```tsx
<QRCode
  value="https://example.com"
  templateId="Arrow"
  fgColor="#1a56db"
  imageSettings={{
    src: "/your-logo.png",
    width: 48,
    height: 48,
    excavate: true,
  }}
  size={512}
/>
```

## Registro de templates [#template-registry]

### Obter todos os templates [#get-all-templates]

```tsx
import { getAllTemplates } from 'qrdx';

const templates = getAllTemplates();
```

### Obter os IDs dos templates [#get-template-ids]

```tsx
import { getTemplateIds } from 'qrdx';

const ids = getTemplateIds();
// Returns: ['default', 'Arrow', 'StandardBox', ...]
```

## Templates personalizados [#custom-templates]

Escreva seu próprio template como um `TemplateDefinition`. O `wrapper` dele recebe o código como `children` e retorna o SVG a ser desenhado. Ele desenha em uma tela de 300 por 300, e o código também chega nesse tamanho, então reduza-o para deixar espaço para a sua arte. `props` traz o `fgColor` e o `bgColor` do código.

Este desenha um anel ao redor do código:

```tsx
import { QRCode, type TemplateDefinition } from "qrdx";

const ringTemplate: TemplateDefinition = {
  id: "ring",
  name: "Ring",
  wrapper: (children, props) => (
    <svg viewBox="0 0 300 300" width="300" height="300" xmlns="http://www.w3.org/2000/svg">
      <circle
        cx="150"
        cy="150"
        r="140"
        fill="none"
        stroke={props?.fgColor ?? "#000000"}
        strokeWidth="8"
      />
      {/* The code at half size, centered */}
      <g transform="translate(75, 75) scale(0.5)">{children}</g>
    </svg>
  ),
};

<QRCode
  value="https://example.com"
  customTemplate={ringTemplate}
  fgColor="#1a56db"
  size={256}
/>
```

Mantenha o código grande o bastante para ser lido da distância em que as pessoas vão segurar o celular, e deixe um espaço claro entre ele e a sua arte. Confira o resultado com a [pontuação de leitura](/docs/features/frames#will-it-scan).

## Quando usar templates [#when-to-use-templates]

- **Consistência de marca** — Garanta que todos os QR codes combinem
- **Configuração rápida** — Tenha resultados profissionais rapidamente
- **Campanhas sazonais** — Use templates temáticos
- **Geração em lote** — Aplique estilos consistentes
