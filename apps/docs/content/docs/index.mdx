QRdx is an open-source (AGPL-3.0) QR code generator you can use in several ways: design codes in the [playground](/playground), render them in your own React app with the [`qrdx`](https://www.npmjs.com/package/qrdx) library, or generate them over HTTP and from AI assistants with the image API and MCP server. With an account you can also create dynamic codes whose destination you can change after printing.

## Quick example

```tsx
import { QRCode } from 'qrdx';

export default function App() {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      fgColor="#000000"
      bgColor="#ffffff"
    />
  );
}
```
