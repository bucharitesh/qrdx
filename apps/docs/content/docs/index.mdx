QRdx is an open-source (AGPL-3.0) QR code platform you can use in several ways:

- **Design static QR codes** in the [playground](/playground) and download PNG, JPG, SVG, PDF or EPS files. Free, unlimited and no account needed.
- **Create dynamic QR codes** with an account: short links you can repoint after printing, hosted mobile pages, smart routing and scan analytics, alone or with a team.
- **Build QR codes into your own software** with the [`qrdx`](https://www.npmjs.com/package/qrdx) React library, the CLI, the image API, the REST API and the MCP server.

Every dynamic code keeps redirecting on every plan, even after a downgrade or cancellation. See [Plans and limits](/docs/plans-and-limits) and the [Never-Hostage Guarantee](/guarantee).

## Quick example

```tsx
import { QRCode } from 'qrdx';

export default function App() {
  return (
    <QRCode
      value="https://example.com"
      size={512}
      fgColor="#000000"
      bgColor="#ffffff"
    />
  );
}
```
