Install `qrdx` and create your first QR code in minutes.

## Install the package

```package-install
qrdx@latest
```

`react` and `react-dom` (18 or newer) are peer dependencies, so `qrdx` uses the versions your app already has. PDF export is optional: install `jspdf` only if you need it.

## Quick Start

Create your first QR code:

```tsx
import { QRCode } from 'qrdx';

export default function App() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
    />
  );
}
```

That's it. You now have a working QR code.
