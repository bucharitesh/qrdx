## Componentes [#components]

### QRCode [#qrcode]

Componente principal para renderizar códigos QR.

```tsx
import { QRCode } from 'qrdx';

<QRCode
  value="https://example.com"
  size={256}
  fgColor="#000000"
  bgColor="#ffffff"
/>
```

#### Props [#props]

| Prop | Tipo | Valor por defecto | Descripción |
|------|------|---------|-------------|
| `value` | `string` | **obligatorio** | URL o texto que se va a codificar |
| `size` | `number` | `128` | Tamaño en píxeles |
| `scale` | `number` | `1` | Multiplicador de escala |
| `fgColor` | `ColorConfig` | `#000000` | Color del código QR |
| `bgColor` | `ColorConfig` | `#ffffff` | Color de fondo |
| `eyeColor` | `ColorConfig` | `fgColor` | Color de los marcadores de las esquinas |
| `dotColor` | `ColorConfig` | `fgColor` | Color del punto dentro de cada ojo de esquina |
| `bodyPattern` | `BodyPattern` | `'circle'` | Patrón de los puntos de datos |
| `cornerEyePattern` | `CornerEyePattern` | `'gear'` | Patrón de los marcadores de las esquinas |
| `cornerEyeDotPattern` | `CornerEyeDotPattern` | `'circle'` | Patrón del punto de las esquinas |
| `hideLogo` | `boolean` | `false` | Oculta el logotipo. No se dibuja ningún logotipo a menos que se defina `logo` |
| `logo` | `string` | — | URL del logotipo |
| `templateId` | `string` | `'default'` | ID de la plantilla |
| `customTemplate` | `TemplateDefinition` | — | Plantilla personalizada |
| `level` | `ErrorLevel` | `'Q'` | Corrección de errores |
| `autoLevel` | `boolean` | `false` | Sube `level` a H cuando el logotipo cubre más del 7 % del código (`AUTO_LEVEL_LOGO_COVERAGE`) |
| `margin` | `number` | `0` | Margen en módulos |
| `imageSettings` | `ImageSettings` | — | Ajustes del logotipo |
| `eyeColors` | `EyeColors` | — | Colores `outer` / `inner` por ojo para `topLeft`, `topRight` y `bottomLeft`; cada uno reemplaza a `eyeColor` / `dotColor` |
| `moduleScale` | `number` | `1` | Tamaño del módulo de datos, de 0.5 a 1. Cada patrón se detiene en el tamaño más pequeño que aún se escanea (`MODULE_SCALE_FLOOR`) |
| `frame` | `QRFrame` | — | Marco con llamada a la acción; consulta [Marcos e impresión](/docs/features/frames) |
| `art` | `QRArt` | — | Fusiona un logotipo o una foto con los módulos (Logo QR, Image QR); consulta [QR artístico](/docs/features/art-qr) |
| `frameLabelMarkers` | `boolean` | `false` | Para editores: marca cada etiqueta `<text>` del marco con `data-qrdx-frame-label` (`"text"`, `"secondaryText"` o el id de la etiqueta de una especificación). Las descargas y exportaciones nunca lo incluyen |

Los {facts.bodyPatterns} patrones de cuerpo, {facts.eyeShapes} ojos, {facts.eyeCentres} centros de ojo y {facts.frameStyles} marcos integrados se muestran en vivo en [Formas, ojos y marcos](/docs/styles).

## Funciones de descarga [#download-functions]

### downloadQRCode [#downloadqrcode]

Descarga códigos QR en varios formatos.

```tsx
downloadQRCode(
  qrProps: QRProps,
  options: {
    format: 'png' | 'jpg' | 'webp' | 'svg' | 'pdf' | 'eps';
    size: { width: number; height: number };
    filename?: string;
    quality?: number; // WebP only: 0 to 1 for lossy; lossless when left out
  }
): Promise<void>
```

### getQRCodeDataUrl [#getqrcodedataurl]

Obtén el código como URL de datos.

```tsx
getQRCodeDataUrl(
  qrProps: QRProps,
  format: DownloadFormat,
  size: DownloadSize,
  options?: { quality?: number } // WebP only
): Promise<string>
```

### getQRAsWebP [#getqraswebp]

El código como `Blob` WebP, sin pérdida a menos que se defina `quality`. Cuando el navegador no puede codificar WebP (Safari), lo genera el codificador sin pérdida integrado de qrdx. `canvasToWebP(canvas, options)` hace lo mismo con cualquier canvas, y `encodeWebPLossless(rgba, width, height)` codifica píxeles RGBA sin DOM.

```tsx
getQRAsWebP(
  qrProps: QRProps,
  options?: { quality?: number }
): Promise<Blob>
```

### copyQRCodeToClipboard [#copyqrcodetoclipboard]

Copia al portapapeles.

```tsx
copyQRCodeToClipboard(
  qrProps: QRProps,
  size?: DownloadSize
): Promise<void>
```

### getSVGString [#getsvgstring]

Obtén el marcado SVG.

```tsx
getSVGString(qrProps: QRProps): Promise<string>
```

## Funciones de impresión y escaneo [#print-and-scan-functions]

Estas funciones se documentan con ejemplos en sus páginas de funcionalidades.

| Función | Qué hace | Documentación |
|----------|--------------|------|
| `getQRAsSVG(props)` | Marcado SVG de un código, con su marco | [Marcos](/docs/features/frames) |
| `getQRAsPrintPDF`, `downloadPrintPDF` | PDF vectorial en un tamaño físico exacto, con sangrado, marcas de corte y CMYK (requiere `jspdf`) | [Exportación lista para imprimir](/docs/features/frames#print-ready-export) |
| `downloadPrintSVG` | SVG listo para imprimir en un tamaño físico exacto | [Exportación lista para imprimir](/docs/features/frames#print-ready-export) |
| `getQRAsEPS`, `downloadPrintEPS` | EPS vectorial para imprentas y herramientas de diseño | [Descargas](/docs/features/downloads) |
| `getScanScore(props)` | Estima con qué fiabilidad se escanea un diseño | [¿Se escaneará?](/docs/features/frames#will-it-scan) |
| `getImageScanScore(image)` | Puntúa una imagen de código QR que ya tienes (solo en el navegador) | [¿Se escaneará?](/docs/features/frames#will-it-scan) |
| `getQRAsPNG(props, { size })` | Bytes PNG en Node puro, sin DOM. Impórtala desde `qrdx/node`; requiere tener instalado `@resvg/resvg-js` o `sharp` | — |
| `scanQRPixels(pixels, expected)` | Comprueba que los píxeles RGBA en bruto se decodifican como `expected`, también si se desenfocan y se reducen; se ejecuta en Node | — |
| `getStylePairRisk(...)` | Avisa de combinaciones de ojo y patrón que algunos escáneres no reconocen | [Patrones](/docs/features/patterns) |

## Tipos [#types]

### Tipos principales [#core-types]

```tsx
type QRProps = {
  value: string;
  size?: number;
  level?: ErrorLevel;
  bgColor?: ColorConfig;
  fgColor?: ColorConfig;
  margin?: number;
  imageSettings?: ImageSettings;
  // ...
};

type ColorConfig =
  | string
  | { type: 'solid'; color: string }
  | LinearGradient
  | RadialGradient;

type ErrorLevel = 'L' | 'M' | 'Q' | 'H';
```

### Tipos de patrones [#pattern-types]

```tsx
// The arrays BODY_PATTERN, CORNER_EYE_PATTERNS, CORNER_EYE_DOT_PATTERNS and
// FRAME_STYLES (and their zod schemas) are exported from 'qrdx/types'.
// FRAME_STYLES names the built-in frames; each is a frame spec in
// BUILT_IN_FRAMES (from 'qrdx').

type BodyPattern =
  | 'circle' | 'circle-large' | 'square' | 'diamond' | 'circle-mixed'
  | 'pacman' | 'rounded' | 'small-square' | 'vertical-line'
  | 'horizontal-line' | 'liquid' | 'liquid-horizontal' | 'liquid-vertical'
  | 'classy' | 'classy-rounded' | 'leaf' | 'plus' | 'hexagon' | 'star'
  | 'heart' | 'random-dots' | 'mosaic' | 'octagon';

type CornerEyePattern =
  | 'square' | 'rounded' | 'gear' | 'circle' | 'diya' | 'extra-rounded'
  | 'message' | 'pointy' | 'leaf' | 'drop' | 'octagon' | 'bevel'
  | 'squircle' | 'cushion' | 'shield' | 'petal' | 'leaf-reverse';

type CornerEyeDotPattern =
  | 'square' | 'rounded' | 'circle' | 'message' | 'message-reverse'
  | 'diya' | 'diya-reverse' | 'rounded-triangle' | 'leaf' | 'drop' | 'plus'
  | 'cross-rounded' | 'hexagon' | 'octagon' | 'flower' | 'heart'
  | 'squircle' | 'dots' | 'extra-rounded' | 'leaf-reverse' | 'drop-reverse';

// Retired (deprecated) values still render for saved designs but are not
// offered: RETIRED_CORNER_EYE_PATTERNS, RETIRED_CORNER_EYE_DOT_PATTERNS.

type EyeColors = {
  topLeft?: { outer?: ColorConfig; inner?: ColorConfig };
  topRight?: { outer?: ColorConfig; inner?: ColorConfig };
  bottomLeft?: { outer?: ColorConfig; inner?: ColorConfig };
};

type QRFrame = {
  style: FrameStyle; // "none" or a built-in frame, see FRAME_STYLES
  text?: string; // up to 24 characters, default "Scan me"
  color?: string;
  textColor?: string;
  secondaryText?: string; // banner-top-bottom, circle, menu-card
  secondaryColor?: string; // gradient-border end color
  fontScale?: number; // 0.5 to 1.5
};
```

## Manejo de errores [#error-handling]

Envuelve las funciones asíncronas en try-catch:

```tsx
try {
  await downloadQRCode(props, options);
} catch (error) {
  console.error('Failed:', error);
}
```

Errores comunes:
- URL de imagen no válidas
- Fallos de red
- Parámetros de tamaño no válidos
- Contexto de canvas no disponible
