すべての[動的QRコード](/docs/dynamic-qr-codes)は、NFCタグにも設定できます。コードのNFCリンクをタグ、ステッカー、カードに書き込むと、スマートフォンをかざすだけで、QRコードと同じ宛先が開きます。タップはコードのアナリティクスにQRのスキャンと並んで表示され、別々に集計されます。すべてのプランで利用できます。

QRdxはタグやカードの販売、印刷、発送は行っていません。白紙のタグは任意のNFC販売店で購入し、コードのページから自分で書き込んでください。

## NFCリンク [#the-nfc-link]

コードのNFCリンクは、短縮リンクの末尾に `?nfc` を付けたものです。たとえば `https://qrdx.dev/q/aB3dE5f?nfc` や、[カスタムドメイン](/docs/custom-domains)の場合は `https://go.example.com/menu?nfc` のようになります。短縮リンクと同じリダイレクトを通るため、スマートルーティング、パスワード、スケジュール、スキャン数の上限はタップにも適用されます。`?nfc` は、アクセスがタップだったことをアナリティクスに伝えるだけです。QRコード自体のリンクは変わらず、すでに印刷したコードもこれまでどおり動作します。

リンクを確認するには、[ダッシュボード](/dashboard?to=codes)でコードを開き、概要タブで **NFCで使う** を選びます。[REST API](/docs/developers/rest-api)では、すべてのコードに `nfcLink` として含まれます。

## AndroidでタグにNFCを書き込む [#write-a-tag-on-android]

AndroidのChromeでは、コードのNFCページから直接タグに書き込めます。

1. スマートフォンの設定でNFCをオンにします。
2. Chromeでコードを開き、**NFCで使う** を選んで、**NFCタグに書き込む** をタップします。
3. ページに **書き込み完了** と表示されるまで、タグをスマートフォンの背面に平らに当てたままにします。
4. タグをスマートフォンにかざして確認します。リンクが開けば成功です。

Webページからの書き込みにはWeb NFCが必要で、これに対応しているのはAndroidのChromeだけです。パソコンでは、NFCページに代わりにQRコードが表示されます。それをAndroidスマートフォンでスキャンし、サインインして、そこでタグに書き込んでください。

### タグのロック [#locking-a-tag]

タグへの書き込み後、ブラウザが対応していればロックを促す表示が出ます。ロックしたタグは、自分を含め誰も二度と変更や消去ができません。そのため、カフェのテーブルに貼るステッカーのように、第三者に書き換えられる可能性がある場所のタグだけをロックしてください。タグに入っているのは宛先ではなくコードのリンクなので、ロックしたタグでも、QRdx側で移動先を変更できます。

## iPhoneでタグに書き込む [#write-a-tag-on-iphone]

SafariではNFCタグに書き込めないため、App Storeにある任意のNFC書き込みアプリを使います。

1. コードのNFCページからNFCリンクをコピーします。
2. アプリでURLレコードを追加し（アプリによってはLinkやURIと呼ばれます）、リンクを貼り付けます。
3. 書き込みを選び、アプリが完了を知らせるまで、iPhoneの上部をタグに当てたままにします。

書き込みには、iOS 13以降のiPhone 7以降が必要です。

## 購入するタグの選び方 [#which-tags-to-buy]

NTAG213、NTAG215、NTAG216のいずれかのチップを選んでください。ステッカー、カード、キーホルダー、リストバンドなどの形で販売されています。

| チップ | メモリ |
| --- | --- |
| NTAG213 | 144バイト |
| NTAG215 | 504バイト |
| NTAG216 | 888バイト |

qrdx.devのNFCリンクは約30バイトなので、3種類とも書き込めます。長いカスタムドメインや長い後半部分を持つリンクは、より多くの容量が必要です。NFCページには、必要なバイト数と対応するチップが表示されます。

NFCをオンにしたAndroidスマートフォンと、iPhone XS以降では、タグをかざすとすぐにリンクが開きます。アプリは不要です。

## NFC名刺 [#nfc-business-cards]

[vCard Plusページ](/docs/landing-pages)は **連絡先を保存** ボタンのある連絡先ページで、NFC名刺に適しています。vCard Plusページを開くコードでは、概要タブに **このカードをNFCに設定** が表示され、ページエディタには **NFCに設定** ボタンがあります。どちらも同じNFCページが開き、カード向けのガイドが表示されます。

1. 白紙のNFC名刺、またはお手持ちの名刺に貼るNFCステッカーを購入します。
2. カードにはコードのQRコードも印刷します。NFC非対応のスマートフォンや、NFCをオフにしているスマートフォンでは、代わりにQRコードをスキャンできます。
3. コードのNFCページから、各カードにNFCリンクを書き込みます。

各カードにはコードのリンクが入っているため、QRdxでvCard Plusページを編集すると、すでに配ったすべてのカードに反映されます。

## アナリティクスでのタップ [#taps-in-analytics]

コードのアナリティクスタブには、選択した期間の **QRスキャンとNFCタップ** が表示され、上部の合計には両方が含まれます。ワークスペースのアナリティクスページと共有アナリティクスページにも、同じ内訳が表示されます。

CSVエクスポートには `source` 列があり、各スキャンに `qr` または `nfc` が入ります。REST APIでは、[スキャンアナリティクス](/docs/developers/api/get-code-scans)に両方の件数を示す `sources` と、一覧の各スキャンの `source` が含まれます。`scan.created` の[Webhook](/docs/webhooks)にも `source` が含まれます。

NFCリンクの提供開始前のスキャンは、QRのスキャンとして集計されます。タップにもスキャンと同じルールが適用され、ボットやリンクのプレビューは集計されません。
