QRdxはオープンソース（AGPL-3.0）のQRコードプラットフォームです。アカウント不要で静的QRコードを無料でデザインできます。サインインすると、印刷後に内容を変更できる動的QRコード、モバイル向けページ、スキャン分析を利用できます。

動的QRコードは、ダウングレードや解約をした後でも、どのプランでもリダイレクトを続けます。これが[Never-Hostage保証](/guarantee)です。
