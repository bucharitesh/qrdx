QRdx에는 Slack 안에서 QR 코드를 만들어 주는 Slack 앱이 있습니다. 봇이 설치된 Slack 워크스페이스의 구성원이라면 누구나 링크나 임의의 텍스트로 코드를 만들 수 있습니다. QRdx 계정을 연결하면 스캔 수를 집계하고 나중에 이동 위치를 바꿀 수 있는 추적(동적) 코드도 만들 수 있습니다.

<IfAvailable feature="slackBot" id="add-the-bot-to-slack" title="Slack에 봇 추가하기">

1. QRdx에서 [설정 → 통합 → Slack](/settings/integrations/slack)을 열고 **Slack에 봇 추가**를 클릭해요. QRdx 계정이라면 요금제와 관계없이 누구나 추가할 수 있습니다.
2. Slack 워크스페이스를 선택하고 승인합니다. 봇은 슬래시 명령, 봇 멘션, 봇에게 온 다이렉트 메시지를 볼 수 있는 권한과 메시지를 게시할 권한을 요청합니다.
3. 설정 페이지로 돌아오면 봇을 추가한 Slack 워크스페이스 목록이 표시됩니다.

같은 Slack 앱은 채널에 [알림](/docs/notifications#slack-and-discord)도 게시합니다. 봇을 추가해도 알림이 켜지지 않으며, 알림을 추가해도 봇이 추가되지 않습니다.

</IfAvailable>

<IfAvailable feature="slackBot" id="make-a-qr-code" title="QR 코드 만들기">

| 위치 | 방법 | 코드가 표시되는 곳 |
| --- | --- | --- |
| 모든 채널 | `/qr` 뒤에 링크나 텍스트 입력 | 채널 |
| 봇이 있는 채널 | 링크나 텍스트와 함께 봇 멘션 | 스레드 |
| 봇과의 다이렉트 메시지 | 링크나 텍스트 전송 | DM |
| 모든 메시지 | **더 많은 작업** → **QR 코드 만들기** | 해당 메시지의 스레드 |

답변마다 QR 코드 이미지가 표시되고, 그 아래에 콘텐츠 내용, 버튼 세 개, 아래에서 설명할 스타일 메뉴가 나타납니다. 버튼은 **PNG 다운로드**(1024픽셀), **SVG 다운로드**, **편집기에서 열기**입니다. 편집기에서는 디자인을 더 바꿀 수 있습니다. 링크를 보내면 해당 링크가 입력된 편집기가 열리고, 텍스트를 보내면 빈 편집기가 열립니다. 텍스트는 링크에 담기지 않기 때문입니다.

바로가기는 메시지에서 처음 나오는 웹 주소로 코드를 만들고, 웹 주소가 없으면 메시지 전체 텍스트로 만듭니다. 봇이 해당 채널에 없으면 코드는 나에게만 보이고, 앱을 채널에 추가하라는 안내가 함께 표시됩니다.

`/qr`만 입력하거나 `/qr help`를 입력하면 명령어가 표시됩니다. QR 코드에 담기에 너무 긴 콘텐츠는 이미지 대신 짧은 설명이 표시되며, 이 설명은 나에게만 보입니다.

</IfAvailable>

<IfAvailable feature="slackBot" id="style-your-code" title="코드 꾸미기">

각 코드 아래에는 **모양**, **색상**, **프레임**, **로고** 메뉴 네 개가 있습니다. 항목을 고르면 코드가 그 자리에서 바뀌고 다운로드 링크도 새로 만들어집니다. 선택한 내용은 현재 코드 상태를 기준으로 적용됩니다. 코드를 만든 사람만 스타일을 바꿀 수 있습니다. 다른 사람이 선택하면 Slack에서 본인에게만 보이는 안내가 표시되고, 코드는 그대로 유지됩니다.

모양은 작은 크기에서도 잘 읽히는 편집기 기본 디자인 중 일부이며, **Plain**을 고르면 흰색 바탕에 검은색으로 돌아갑니다. 색상을 고르면 코드 전체가 해당 색상으로, 바탕은 흰색으로 바뀝니다. 프레임에는 "Scan me" 라벨이 추가되고, 로고는 편집기의 빠른 아이콘입니다.

코드를 만들 때 링크나 텍스트 뒤에 옵션을 추가해서 스타일을 지정할 수도 있습니다. 옵션 이름은 [QRdx CLI](/docs/developers/cli)와 같습니다.

```text
/qr qrdx.dev --look modern --fg 0051ff --frame banner-bottom --frame-text "Scan me"
```

첫 번째 옵션 앞에 있는 내용은 모두 콘텐츠로 처리됩니다. 모양이 먼저 적용되고 나머지 옵션이 그 위에 적용되므로, `--look royal --fg 0051ff`는 Royal의 도형을 유지한 채 파란색으로 만듭니다. 옵션은 멘션과 다이렉트 메시지에서도 사용할 수 있습니다. 옵션이나 값이 잘못되면 봇이 나에게만 알려 주고 사용할 수 있는 값을 보여 줍니다.

| 옵션 | 바뀌는 항목 | 값 |
| --- | --- | --- |
| `--look` | 편집기 프리셋 중 하나로 전체 디자인 변경 | `plain`, `classic`, `modern`, `royal`, `folio`, `caffeine`, `retro`, `bordeaux`, `blossom` |
| `--fg` (또는 `--color`) | 점, 그리고 따로 지정하지 않으면 모서리 눈 | `0051ff` 같은 16진수 색상 또는 `black`, `blue`, `green`, `red`, `purple`, `orange` |
| `--bg` | 배경 | `--fg`와 같음 |
| `--eye-color` | 모서리 눈 세 개 | `--fg`와 같음 |
| `--dot-color` | 모서리 눈의 중심 | `--fg`와 같음 |
| `--body` | 점 모양 | 편집기의 {facts.bodyPatterns}가지 점 모양 중 하나 (예: `rounded`, `circle`, `classy`) |
| `--eye` | 모서리 눈 모양 | {facts.eyeShapes}가지 눈 모양 중 하나 (예: `square`, `rounded`, `gear`) |
| `--dot` | 눈 중심 모양 | {facts.eyeCentres}가지 중심 모양 중 하나 (예: `square`, `rounded`, `circle`) |
| `--frame` | 코드 주위의 프레임 | `none` 또는 {facts.frameStyles}가지 기본 프레임 중 하나 (예: `banner-bottom`, `banner-top`, `speech-bubble`, `polaroid`) |
| `--frame-text` | 프레임 라벨 (최대 24자) | 임의의 텍스트이며, 공백이 있으면 따옴표로 묶어요. `--frame` 없이 사용하면 코드 아래 배너에 표시됩니다 |
| `--template` | 템플릿으로 그리는 프레임 | `Arrow`, `StandardBox`, `SquareBorder`, `StrikedBox`, `Halloween` |
| `--logo` | 가운데 아이콘 | `link`, `wifi`, `location`, `phone`, `email`, `whatsapp`, `instagram`, `file`, `calendar`, `none` |

스타일을 적용한 코드는 게시하기 전에 편집기와 같은 스캔 점수로 QRdx가 검사합니다. 휴대폰이 읽기 어려운 디자인이면 QRdx가 색을 더 어둡게 하거나, 모양을 단순하게 하거나, 오류 정정을 높이는 식으로 조정하고 코드 아래에 그 내용을 알려 줍니다. 그래도 부족하면(대개 콘텐츠가 길 때) 흰색 바탕에 검은색 코드와 안내 메시지가 표시됩니다. `/qr`로 만든 스타일 코드는 검사를 마친 뒤에 올라오므로 명령을 보내고 잠시 후에 표시됩니다.

**편집기에서 열기**를 클릭하면 색상, 모양, 프레임, 테두리 등 같은 디자인이 적용된 편집기가 열립니다. 로고 아이콘은 링크에 담기지 않으므로 편집기에서 다시 선택해야 해요.

바로가기로 만든 코드 중 나에게만 보이는 코드에는 메뉴가 없으며, 추적 코드는 기본 디자인이 유지됩니다.

</IfAvailable>

<IfAvailable feature="slackBot" id="tracked-codes" title="추적 코드">

일반 코드에는 링크 자체가 담깁니다. 추적 코드에는 내 링크로 리디렉션되는 짧은 링크(`https://qrdx.dev/q/<slug>`)가 담기므로, QRdx가 스캔 수를 집계하고 이동 위치를 바꿀 수 있습니다. Slack에서 추적 코드를 만들려면 QRdx 계정을 한 번 연결해야 해요.

1. `/qr link`를 실행합니다. 나에게만 보이는 버튼이 표시되고, 이 버튼을 누르면 QRdx가 열립니다. 버튼은 10분 동안 유효합니다.
2. 요청하면 QRdx에 로그인합니다. 그런 다음 **Slack으로 로그인**을 클릭하고 `/qr link`를 실행한 것과 같은 Slack 계정으로 로그인해요. Slack이 QRdx에 알려 주는 정보는 Slack 사용자와 워크스페이스뿐이며, QRdx는 이 둘이 일치하는지 확인합니다. 다른 사람의 Slack 계정으로 로그인하면 연결되지 않습니다.
3. 추적 코드를 보낼 QRdx 워크스페이스를 선택하고 **확인**을 클릭합니다. 이 연결로 해당 Slack 계정이 내 워크스페이스에 코드를 만들 수 있게 되므로, QRdx는 먼저 [본인 확인](/docs/help/privacy-and-security/two-step-verification#confirm-its-you)을 요청합니다.
4. Slack으로 돌아오면 봇이 연결된 QRdx 계정과 워크스페이스 이름이 담긴 다이렉트 메시지를 보냅니다. 직접 연결한 적이 없다면 `/qr unlink`를 실행하세요.
5. `/qr track` 뒤에 `https://` 또는 `http://`로 시작하는 링크를 입력합니다. 봇을 멘션하고 `track`과 링크를 함께 입력해도 됩니다.

코드는 짧은 링크, 그리고 코드가 속한 QRdx 워크스페이스 이름과 함께 채널에 표시됩니다. 대시보드의 해당 코드로 이동하는 **QRdx에서 열기** 버튼은 나에게만 보이는 별도 메시지로 전달됩니다. 코드 이름은 링크의 사이트 이름에 "from Slack"을 붙인 형태이며, 워크스페이스의 코드 목록에서 다른 코드와 똑같이 찾을 수 있습니다.

추적 코드에는 대시보드에서 만든 코드와 같은 규칙이 적용됩니다. 내 역할이 코드 생성을 허용해야 하고, 2단계 인증을 요구하는 워크스페이스라면 내 계정에도 2단계 인증이 켜져 있어야 하며, 요금제의 활성 동적 코드 한도도 적용됩니다. 한도에 도달하면 봇이 그 사실을 알리고 요금제 링크를 보여 줍니다. 이 조건은 매번 확인하므로, 워크스페이스를 나가거나 접근 권한을 잃으면 그 워크스페이스에서는 연결이 작동하지 않습니다.

Slack 계정은 Slack 워크스페이스마다 연결을 하나씩만 가질 수 있습니다. 이미 연결된 Slack 계정으로 `/qr link`를 실행하면 페이지에 어느 QRdx 워크스페이스에 연결되어 있는지, 그리고 그것이 다른 QRdx 계정에 있는지가 표시됩니다. 이때 버튼은 **연결 교체**로 표시되며, 클릭하기 전까지는 아무것도 바뀌지 않습니다. `/qr unlink`를 실행하거나 [설정 → 통합 → Slack](/settings/integrations/slack)의 **연결된 Slack 계정**에서 **연결 해제**를 클릭하면 연결이 삭제됩니다.

QRdx 워크스페이스의 소유자와 관리자는 [설정 → API 키 및 앱](/dashboard?to=settings/developers)에서 해당 워크스페이스에 연결된 모든 Slack 계정을 확인할 수 있습니다. Slack 워크스페이스, Slack 사용자 ID, 대신 작업하는 구성원, 연결 시점이 표시됩니다. 여기서 **해지**를 클릭하면 연결이 삭제됩니다. 워크스페이스에 [감사 로그](/docs/help/teams/audit-log)가 있으면 `/qr track`으로 만든 코드는 구성원 이름 뒤에 "via Slack"과 함께 Slack 사용자 ID 및 워크스페이스 ID가 기록되고, 연결 해지도 함께 기록됩니다.

</IfAvailable>

## 봇이 보관하는 정보 [#what-the-bot-keeps]

봇은 누군가 `/qr`을 실행하거나, 봇을 멘션하거나, 봇에게 직접 메시지를 보내거나, 해당 메시지에서 바로가기를 사용할 때만 메시지를 읽습니다. 메시지 내용은 저장하지 않습니다. QR 코드 이미지는 QRdx [Image API](/docs/developers/image-api)에서 가져오며, Slack이 메시지에 담긴 링크로 불러오므로 업로드되는 것은 없습니다.

QRdx는 Slack 워크스페이스마다 워크스페이스 ID와 이름, 봇의 Slack 사용자 ID, 봇 토큰(암호화됨), 그리고 봇을 추가한 QRdx 계정을 보관합니다. 연결된 Slack 계정마다 Slack 사용자 ID, QRdx 계정, 선택한 워크스페이스를 보관합니다. 연결할 때 Slack으로 로그인해도 저장되는 정보는 늘어나지 않습니다. QRdx는 Slack 사용자와 워크스페이스를 비교한 뒤 로그인 정보를 삭제합니다.<IfAvailable feature="slackBot"> 연결된 Slack 계정은 [데이터 내보내기](/docs/help/account-and-billing/export-your-data)에서 확인할 수 있습니다.</IfAvailable>

<IfAvailable feature="slackBot" id="remove-the-bot" title="봇 제거하기">

Slack에서 앱 페이지를 열고 **Remove App**을 선택하세요(또는 Slack 관리자에게 요청하세요). 그러면 QRdx가 해당 Slack 워크스페이스의 봇 토큰과 그곳에서 만든 모든 Slack 계정 연결을 삭제합니다. 이미 만든 코드는 QRdx에 그대로 남고, 추적 중인 코드도 계속 작동합니다.

</IfAvailable>

## 셀프 호스팅 [#self-hosting]

봇은 "Add to Slack" 알림과 같은 Slack 앱을 사용하며, 여기에 서명 시크릿을 추가합니다. `SLACK_CLIENT_ID`, `SLACK_CLIENT_SECRET`, `SLACK_SIGNING_SECRET`을 설정하세요. 프로덕션에서는 봇 토큰을 암호화하는 `INTEGRATION_ENCRYPTION_KEY`도 설정해야 합니다. 이 값들이 없으면 봇의 페이지와 엔드포인트가 만들어지지 않습니다. 저장소의 `plugins/slack/manifest.json`은 앱의 매니페스트이고, `plugins/slack/README.md`에는 이 매니페스트로 앱을 만드는 과정이 안내되어 있습니다. 매니페스트에는 `openid` 사용자 스코프와 리디렉션 URL `/api/integrations/slack/link/callback`이 포함되어 있으며, 사용자가 계정을 연결할 때 Sign in with Slack에 필요합니다.
