動的QRコードは、Webサイトの代わりにホスト型ページを開くことができます。リンク集、ビジネスページ、vCardに加えて、QRdxには、よくある印刷物の用途に合わせた5種類のページタイプがあります。それぞれテンプレートから始まり、ライブのスマートフォンプレビューを見ながら、ページエディタでブロックごとに変更できます。

| ページタイプ | 用途 | 最初に入っているブロック |
| --- | --- | --- |
| **メニュー** | カフェ、レストラン、バー | メニュー、Wi-Fi、営業時間、地図 |
| **クーポン** | 割引や無料特典 | バーコードと利用ボタン付きのクーポン |
| **イベント** | パーティー、カンファレンス、ウェビナー | カレンダー追加付きのイベント |
| **アプリのダウンロード** | 1つのコードですべてのアプリストアに対応 | アプリのダウンロード |
| **フィードバックとフォーム** | レビュー、NPS調査、登録 | フォーム、レビューリンク |

以下のブロックはすべて、他のページにも追加できます。

## メニュー [#menu]

**メニュー**ブロックは、セクション（前菜、メインなど）と商品を一覧にします。各商品には、説明、価格、価格の後ろに付ける注記（「グラス1杯」「時価」など）、写真、短いバッジ（「シェフのおすすめ」）のほか、次の項目を設定できます。

- **食事タグ:** ベジタリアン、ビーガン、グルテンフリー、乳製品不使用、ハラール、コーシャ、辛い、オーガニック。
- **アレルゲン:** EUと英国で飲食事業者に表示が義務付けられている14のアレルゲン（グルテン、甲殻類、卵、魚、ピーナッツ、大豆、乳、ナッツ類、セロリ、マスタード、ごま、亜硫酸塩、ルピナス、軟体動物）。「含有: …」と表示されます。
- **売り切れ:** 商品はメニューに残り、薄く表示されて売り切れの印が付きます。

1つのメニュー内の価格は、すべて選択した通貨で表示されます。セクションが2つ以上ある場合は、上部のショートカットチップから各セクションへ移動できます。1つのメニューには、最大30セクション、300商品まで登録できます。

**Wi-Fi**ブロックは、ネットワーク名とパスワードをコピーボタン付きで表示します。スマートフォンはWebページからネットワークに接続できないため、お客様はパスワードをコピーして、Wi-Fiの設定に貼り付けます。ページを開いた人は誰でもパスワードを見られます。

## クーポン [#coupon]

**クーポン**ブロックは、見出し、コピーボタン付きのコード、そして必要に応じて、レジで読み取れるバーコードを表示します。

- **Code 128**は、最大48文字の英字、数字、記号をエンコードできます（アクセント付き文字や絵文字は使えません）。
- **EAN-13**は、12桁（チェックディジットはQRdxが追加します）または13桁すべてを受け付けます。20～29で始まる番号は店舗内での使用向けに予約されているため、クーポンコードに適しています。

デフォルトでは、バーコードにクーポンコードがエンコードされます。ほかの値（POSの番号など）をエンコードするには、**バーコードの値**を設定します。

**有効開始日**と**有効期限**はカレンダー上の日付です。クーポンは、世界のどこかで初日が始まった時点で開始済みとなり、世界のすべての場所で最終日が終わった後にはじめて期限切れとなります。そのため、タイムゾーンの違いで早く「期限切れ」と表示されることはありません。期限切れのクーポンも表示されたままとなり、期限切れの印が付きます。

**利用ボタン**をオンにすると、利用数をカウントできます。訪問者がスタッフに画面を見せて**今すぐ利用**をタップすると、そのスマートフォンには時刻とともに「利用済み」と表示され、利用数がページの[回答](#responses)画面に反映されます。同じコードを別のスマートフォンで表示することは防げないため、ロックではなくカウンターとしてお使いください。

## イベント [#event]

**イベント**ブロックは、日時、会場と住所（**マップで開く**リンク付き）、オンラインリンク、主催者、そして**チケットを入手**などのボタンを表示します。時刻はイベントのタイムゾーンで入力し、訪問者にも同じタイムゾーンで表示されます（例: 「午後7:00～10:00 GMT+1」）。終日イベントや複数日にわたるイベントにも対応しています。終了時刻がない場合、イベントは1時間として扱われます。

**カレンダーに追加**では、Google カレンダー、Apple カレンダー（`.ics`ファイル）、Outlook.com、Yahoo カレンダーを選べます。`.ics`ファイルはページのアドレスから配信されるため、[カスタムドメイン](/docs/custom-domains)でも動作します。エディタのプレビューでは、ページを公開するまで無効です。イベントが終了すると、ブロックにその旨が表示され、カレンダーボタンは非表示になります。

## アプリのダウンロード [#app-download]

**アプリのダウンロード**ブロックには、App Storeのリンク（`apps.apple.com`）、Google Playのリンク（`play.google.com`）、Webサイトを設定します。訪問者に合ったストアが最初に表示されます。iPhoneとiPadのユーザーにはApp Storeのボタンが上に、AndroidのユーザーにはGoogle Playが上に、それ以外の人にはWebサイトが上に表示されます。ほかのリンクは下に残るため、迷うことはありません。

## フォーム [#forms]

**フォーム**ブロックは回答を集めます。質問には次の種類があります。

| タイプ | 訪問者の回答方法 |
| --- | --- |
| テキスト | 短い回答または長い回答（最大文字数を設定できます） |
| メール | メールアドレス |
| 電話 | 電話番号 |
| 星評価 | 3～10段階の星（選択可能で、デフォルトは5） |
| NPS | 「友人や同僚にどのくらい勧めたいか」を0～10で回答 |
| 選択 | 1つの選択肢。**複数回答を許可**がオンの場合は複数 |
| チェックボックス | チェック（例: 連絡への同意） |

質問を**必須**にすると、回答が必須になります。エラーは質問の横に表示され、送信後には、あなたが書いたお礼のメッセージが表示されます。質問は必要なものだけにし、連絡先の使いみちを明記してください。

スパム対策も組み込まれています。ボットだけが入力する非表示フィールドと、1台のデバイスがフォームを送信できる頻度の制限です。サーバーに[Cloudflare Turnstile](#cloudflare-turnstile)のキーが設定されている場合は、フォームでTurnstileの非表示チェックも実行されます。

### レビューリンク [#review-links]

**レビューリンク**ブロックは、「Googleでレビューを書く」（およびTripadvisor、Yelp、Facebook、Trustpilotなどのサイト）のボタンを表示します。フォームでどう回答したかにかかわらず、すべての訪問者に表示されます。Googleを含むレビューサイトでは、高く評価した人にだけレビューリンクを表示することが認められていないため、QRdxが評価に応じてリンクを非表示にすることはありません。

Google ビジネス プロフィールで**レビューを依頼**を選ぶと、レビューリンクをコピーできます。

## 回答 [#responses]

**ダッシュボード → ページとフォーム**でページを開き、**回答**を選びます（または`/dashboard/<workspace>/pages/<page id>/responses`にアクセスします）。回答は新しい順に1画面25件ずつ表示され、時刻（UTC）、訪問者がスキャンしたコード、すべての回答が確認できます。メールアドレスと電話番号はリンクになっています。

- **1つのページに複数のフォームがある場合:** タブでフォームごとに絞り込めます。
- **CSVをエクスポート:** 1件の回答が1行、1つの質問が1列になります。列は現在の質問の順に並び、その後に、削除済みで回答が残っている質問が続きます。質問の名前を変更しても、列は維持されます。
- **削除:** 回答を選択するか、1件ごとにごみ箱ボタンを使います。削除は元に戻せません。メンバーは自分が作成したページの回答を削除でき、オーナーと管理者はワークスペース内のどのページの回答でも削除できます。

回答はページに属します。ページを削除すると、そのページの回答も削除されます。

### 月間の上限 [#monthly-limits]

| プラン | 月あたりの回答数 |
| --- | --- |
| フリー | 50 |
| Pro | 1,000 |
| Business | 10,000 |

上限は、ワークスペース内のすべてのページが受け取った回答を、暦月（UTC）ごとに数えたもので、毎月1日にリセットされます。回答画面には、使用済みの件数が表示されます。

上限に達すると、フォームには「このフォームは現在回答を受け付けていません」と表示され、訪問者が入力した内容は保持されます。すでにある回答は、どのプランでも、ダウングレード後も含めて、削除されたり非表示になったりすることはありません。

## アクセスルール [#access-rules]

フォームとカレンダーファイルは、ページの[コードコントロール](/docs/code-controls)に従います。コードが一時停止中、後日開始の予約中、期限切れ、またはスキャン上限に達している間は、フォームは回答を受け付けず、`.ics`ファイルも配信されません。パスワード保護されたページでは、訪問者がパスワードを入力した後に、これらが使えるようになります。

## 通知とWebhook [#notifications-and-webhooks]

回答が届くたびに、回答内容を含む`form.submitted`イベントが送信されます。これを[メールまたはSlack/Discordの通知](/docs/notifications)や[Webhook](/docs/webhooks)（Zapier、Make、自社サーバー）に利用できます。

## プライバシー [#privacy]

回答は、ワークスペース内のページとともに保存されます。QRdxは、回答と一緒に訪問者のIPアドレスを保存しません。各回答には、その日のIPアドレスとブラウザのソルト付きハッシュだけが保持され、そこからどちらも復元することはできません。

## セルフホスティング [#self-hosting]

### Cloudflare Turnstile [#cloudflare-turnstile]

[Cloudflare Turnstile](https://developers.cloudflare.com/turnstile/)でフォームを保護するには、両方の変数を設定します。

```bash
NEXT_PUBLIC_TURNSTILE_SITE_KEY=0x4AAAAAAA...
TURNSTILE_SECRET_KEY=0x4AAAAAAA...
```

どちらか一方しか設定されていない場合、Turnstileはオフのままです。Turnstileのスクリプトは、ページの読み込み時ではなく、訪問者が初めてフォームに触れたときに読み込まれ、Cloudflareが訪問者のクリックを必要としない限り、非表示で実行されます。Cloudflareに接続できない場合でも回答は受け付けられるため、フィードバックが失われることはありません。ほかのスパム対策は引き続き有効です。

### カスタムドメイン [#custom-domains]

確認済みの[カスタムドメイン](/docs/custom-domains)では、フォームのエンドポイント（`/api/forms/...`）とカレンダーファイル（`/api/calendar/...`）がページと同じ場所から配信されるため、追加の設定なしで、フォームとカレンダーへの追加が動作します。
