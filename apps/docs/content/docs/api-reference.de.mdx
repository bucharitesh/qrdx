## Komponenten [#components]

### QRCode [#qrcode]

Hauptkomponente zum Rendern von QR-Codes.

```tsx
import { QRCode } from 'qrdx';

<QRCode
  value="https://example.com"
  size={256}
  fgColor="#000000"
  bgColor="#ffffff"
/>
```

#### Props [#props]

| Prop | Typ | Standard | Beschreibung |
|------|------|---------|-------------|
| `value` | `string` | **erforderlich** | URL oder Text, der codiert wird |
| `size` | `number` | `128` | Größe in Pixeln |
| `scale` | `number` | `1` | Skalierungsfaktor |
| `fgColor` | `ColorConfig` | `#000000` | Farbe des QR-Codes |
| `bgColor` | `ColorConfig` | `#ffffff` | Hintergrundfarbe |
| `eyeColor` | `ColorConfig` | `fgColor` | Farbe der Eckmarkierungen |
| `dotColor` | `ColorConfig` | `fgColor` | Farbe des Punkts in jedem Eckauge |
| `bodyPattern` | `BodyPattern` | `'circle'` | Muster der Datenpunkte |
| `cornerEyePattern` | `CornerEyePattern` | `'gear'` | Muster der Eckmarkierungen |
| `cornerEyeDotPattern` | `CornerEyeDotPattern` | `'circle'` | Muster des Eckpunkts |
| `hideLogo` | `boolean` | `false` | Blendet das Logo aus. Ohne gesetztes `logo` wird kein Logo gezeichnet |
| `logo` | `string` | — | Logo-URL |
| `templateId` | `string` | `'default'` | Template-ID |
| `customTemplate` | `TemplateDefinition` | — | Eigenes Template |
| `level` | `ErrorLevel` | `'Q'` | Fehlerkorrektur |
| `autoLevel` | `boolean` | `false` | Erhöht `level` auf H, wenn das Logo mehr als 7 % des Codes abdeckt (`AUTO_LEVEL_LOGO_COVERAGE`) |
| `margin` | `number` | `0` | Rand in Modulen |
| `imageSettings` | `ImageSettings` | — | Logo-Einstellungen |
| `eyeColors` | `EyeColors` | — | Farben `outer` / `inner` pro Auge für `topLeft`, `topRight` und `bottomLeft`; jede überschreibt `eyeColor` / `dotColor` |
| `moduleScale` | `number` | `1` | Größe der Datenmodule, 0.5 bis 1. Jedes Muster hört bei der kleinsten Größe auf, die sich noch scannen lässt (`MODULE_SCALE_FLOOR`) |
| `frame` | `QRFrame` | — | Rahmen mit Handlungsaufforderung; siehe [Rahmen & Druck](/docs/features/frames) |
| `art` | `QRArt` | — | Blendet ein Logo oder Foto in die Module ein (Logo QR, Image QR); siehe [Art QR](/docs/features/art-qr) |
| `frameLabelMarkers` | `boolean` | `false` | Für Editoren: markiert jedes Rahmenlabel `<text>` mit `data-qrdx-frame-label` (`"text"`, `"secondaryText"` oder die ID eines Spec-Labels). Downloads und Exporte enthalten das Attribut nie |

Alle {facts.bodyPatterns} Körpermuster, {facts.eyeShapes} Augen, {facts.eyeCentres} Augenzentren und {facts.frameStyles} Rahmenstile siehst du live unter [Formen, Augen und Rahmen](/docs/styles).

## Download-Funktionen [#download-functions]

### downloadQRCode [#downloadqrcode]

QR-Codes in mehreren Formaten herunterladen.

```tsx
downloadQRCode(
  qrProps: QRProps,
  options: {
    format: 'png' | 'jpg' | 'webp' | 'svg' | 'pdf' | 'eps';
    size: { width: number; height: number };
    filename?: string;
    quality?: number; // WebP only: 0 to 1 for lossy; lossless when left out
  }
): Promise<void>
```

### getQRCodeDataUrl [#getqrcodedataurl]

Als Data-URL abrufen.

```tsx
getQRCodeDataUrl(
  qrProps: QRProps,
  format: DownloadFormat,
  size: DownloadSize,
  options?: { quality?: number } // WebP only
): Promise<string>
```

### getQRAsWebP [#getqraswebp]

Der Code als WebP-`Blob`, verlustfrei, sofern `quality` nicht gesetzt ist. Wenn der Browser WebP nicht codieren kann (Safari), übernimmt das der integrierte verlustfreie Encoder von qrdx. `canvasToWebP(canvas, options)` macht dasselbe für jedes beliebige Canvas, und `encodeWebPLossless(rgba, width, height)` codiert RGBA-Pixel ohne DOM.

```tsx
getQRAsWebP(
  qrProps: QRProps,
  options?: { quality?: number }
): Promise<Blob>
```

### copyQRCodeToClipboard [#copyqrcodetoclipboard]

In die Zwischenablage kopieren.

```tsx
copyQRCodeToClipboard(
  qrProps: QRProps,
  size?: DownloadSize
): Promise<void>
```

### getSVGString [#getsvgstring]

SVG-Markup abrufen.

```tsx
getSVGString(qrProps: QRProps): Promise<string>
```

| `scanQRPixels(pixels, expected)` | Prüft, ob rohe RGBA-Pixel zu `expected` decodiert werden, auch unscharf und verkleinert; läuft in Node | — |

## Typen [#types]

### Kerntypen [#core-types]

```tsx
type QRProps = {
  value: string;
  size?: number;
  level?: ErrorLevel;
  bgColor?: ColorConfig;
  fgColor?: ColorConfig;
  margin?: number;
  imageSettings?: ImageSettings;
  // ...
};

type ColorConfig =
  | string
  | { type: 'solid'; color: string }
  | LinearGradient
  | RadialGradient;

type ErrorLevel = 'L' | 'M' | 'Q' | 'H';
```

### Mustertypen [#pattern-types]

```tsx
// The arrays BODY_PATTERN, CORNER_EYE_PATTERNS, CORNER_EYE_DOT_PATTERNS and
// FRAME_STYLES (and their zod schemas) are exported from 'qrdx/types'.

type BodyPattern =
  | 'circle' | 'circle-large' | 'square' | 'diamond' | 'circle-mixed'
  | 'pacman' | 'rounded' | 'small-square' | 'vertical-line'
  | 'horizontal-line' | 'liquid' | 'liquid-horizontal' | 'liquid-vertical'
  | 'classy' | 'classy-rounded' | 'leaf' | 'plus' | 'hexagon' | 'star'
  | 'heart' | 'random-dots' | 'mosaic' | 'octagon';

type CornerEyePattern =
  | 'square' | 'rounded' | 'gear' | 'circle' | 'diya' | 'extra-rounded'
  | 'message' | 'pointy' | 'leaf' | 'drop' | 'octagon' | 'bevel'
  | 'squircle' | 'cushion' | 'shield' | 'petal' | 'leaf-reverse';

type CornerEyeDotPattern =
  | 'square' | 'rounded' | 'circle' | 'message' | 'message-reverse'
  | 'diya' | 'diya-reverse' | 'rounded-triangle' | 'leaf' | 'drop' | 'plus'
  | 'cross-rounded' | 'hexagon' | 'octagon' | 'flower' | 'heart'
  | 'squircle' | 'dots' | 'extra-rounded' | 'leaf-reverse' | 'drop-reverse';

// Retired (deprecated) values still render for saved designs but are not
// offered: RETIRED_CORNER_EYE_PATTERNS, RETIRED_CORNER_EYE_DOT_PATTERNS.

type EyeColors = {
  topLeft?: { outer?: ColorConfig; inner?: ColorConfig };
  topRight?: { outer?: ColorConfig; inner?: ColorConfig };
  bottomLeft?: { outer?: ColorConfig; inner?: ColorConfig };
};

type QRFrame = {
  style: FrameStyle; // "none" or a frame, see FRAME_STYLES
  text?: string; // up to 24 characters, default "Scan me"
  color?: string;
  textColor?: string;
  secondaryText?: string; // banner-top-bottom, circle, menu-card
  secondaryColor?: string; // gradient-border end color
  fontScale?: number; // 0.5 to 1.5
};
```

## Fehlerbehandlung [#error-handling]

Verpacke asynchrone Funktionen in try-catch:

```tsx
try {
  await downloadQRCode(props, options);
} catch (error) {
  console.error('Failed:', error);
}
```

Häufige Fehler:
- Ungültige Bild-URLs
- Netzwerkfehler
- Ungültige Größenparameter
- Canvas-Kontext nicht verfügbar
