## 사용법 [#usage]

```tsx
import { QrCodeShareDialog } from "@/components/qr-code-share-dialog";
```

```tsx
<QrCodeShareDialog url="https://example.com/invite/abc123" />
```

대화상자에는 QR 코드, 복사 버튼이 있는 읽기 전용 링크 입력란, PNG 다운로드가 표시됩니다. 공유 시트를 지원하는 기기(대부분의 휴대폰)에서는 "공유…" 버튼을 누르면 공유 시트가 열려요.

## 예제 [#examples]

### 사용자 지정 트리거 [#custom-trigger]

도구 모음의 아이콘 버튼처럼 원하는 트리거를 children으로 전달하세요. `title`, `description`, `qr`로 대화상자를 사용자 지정할 수 있습니다.

<ComponentPreview name="qr-code-share-dialog-trigger" />

### 제어 모드 [#controlled]

이 대화상자는 [Dialog](https://ui.shadcn.com/docs/components/dialog)의 props를 그대로 받으므로 코드에서 직접 열 수 있습니다.

```tsx
const [open, setOpen] = useState(false);

<QrCodeShareDialog
  url="https://example.com"
  open={open}
  onOpenChange={setOpen}
/>
```
