## Utilizzo [#usage]

```tsx
import { QrCodeGenerator } from "@/components/qr-code-generator";
```

```tsx
<QrCodeGenerator defaultValue="https://example.com" />
```

L'anteprima si aggiorna mentre scrivi. Ogni pulsante di preset mostra un piccolo esempio del suo stile e i download usano il preset selezionato a 1024 pixel.

## Esempi [#examples]

### Preset personalizzati [#custom-presets]

Sostituisci i preset integrati con i tuoi. Un preset è composto da un `id`, un `name` e uno `style` con qualsiasi opzione di qrdx, inclusi gradienti, loghi e il `level` di correzione degli errori.

<ComponentPreview name="qr-code-generator-presets" />

I preset integrati sono esportati come `QR_CODE_PRESETS`, quindi puoi estenderli:

```tsx
import { QR_CODE_PRESETS, QrCodeGenerator } from "@/components/qr-code-generator";

<QrCodeGenerator
  presets={[
    ...QR_CODE_PRESETS,
    { id: "brand", name: "Brand", style: { fgColor: "#155DFC" } },
  ]}
/>
```

### Salvare il risultato [#saving-the-result]

`onChange` restituisce il testo e il preset selezionato a ogni modifica, ad esempio per memorizzare la scelta dell'utente:

```tsx
<QrCodeGenerator
  onChange={({ value, preset }) => saveDraft({ value, style: preset.style })}
/>
```
