## Usage

```tsx
import { QrCodeScanner } from "@/components/qr-code-scanner";
```

```tsx
<QrCodeScanner onResult={(value) => console.log(value)} />
```

People drop an image or click to pick one. Decoding runs in the browser with qrdx's [detection helpers](/docs/qr-detection), so the image never leaves the device. It reads image files, not a live camera feed.

The result appears with a copy button, plus an "Open link" button when it is an `http` or `https` URL.

## Examples

### Checking a result

`onResult` receives the decoded text, so you can act on it, for example to check in a ticket. `label` changes the heading in the drop zone. Download the sample code above and drop it in to see a valid ticket.
