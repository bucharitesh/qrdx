## 使い方 [#usage]

```tsx
import { QrCode } from "@/components/qr-code";
```

```tsx
<QrCode value="https://qrdx.dev" />
```

コードはアクセシブルな名前を持つSVGとして描画されます。そのため、どんなサイズでも鮮明に表示され、スクリーンリーダーはリンク先を読み上げます。

## 例 [#examples]

### サイズ [#sizes]

`size` は画面上の幅と高さをピクセルで指定します。ダウンロードには `downloadSize` が使われるため、ページ上では小さなコードでも、印刷に適したファイルを書き出せます。

<ComponentPreview name="qr-code-sizes" />

### 色 [#colors]

`fgColor` と `bgColor` には任意のCSSカラーを指定できます。`eyeColor` と `dotColor` は、3つの角の目を別々に色付けします。どのスキャナーでも読み取れるように、モジュールは背景より暗い色にしてください。

<ComponentPreview name="qr-code-colors" />

### グラデーション [#gradients]

色の代わりに qrdx のグラデーションを渡せます。`angle` を指定した `linear` か、`radial` を使います。グラデーションはPNG、SVG、PDFのダウンロードにも反映されます。

<ComponentPreview name="qr-code-gradient" />

### パターン [#patterns]

`bodyPattern` はデータモジュールの形、`cornerEyePattern` は角のフレーム、`cornerEyeDotPattern` はその内側のドットの形を指定します。すべての形については[パターン](/docs/features/patterns)をご覧ください。

<ComponentPreview name="qr-code-patterns" />

### ロゴ [#logo]

`logo` は中央に画像を配置し、その背後のモジュールを取り除きます。一部が隠れてもスキャンできるように、誤り訂正レベルは `H` を使用してください。データURLを使うとロゴがダウンロードにも含まれます。外部の画像を使う場合はCORSヘッダーが必要です。

<ComponentPreview name="qr-code-logo" />

### フレームテンプレート [#frame-templates]

`templateId` は、qrdx の[テンプレート](/docs/features/templates)をコードの周囲に描画します。`caption` と組み合わせると、フレームの下に行動を促す文言を表示できます。

<ComponentPreview name="qr-code-template" />

### ダウンロード形式 [#download-formats]

`downloadFormats` で表示するボタンを選びます。選べる形式は `png`、`jpg`、`svg`、`pdf` です。PDFへの書き出しには、オプションの `jspdf` パッケージ(`npm install jspdf`)が必要です。ボタンを非表示にするには `[]` を渡します。

<ComponentPreview name="qr-code-downloads" />

形式とサイズを1つのメニューにまとめたい場合は、[QRコードダウンロード](/docs/components/qr-code-download)を使用してください。

### ダークモード [#dark-mode]

ダークテーマでは、デフォルトの白い背景が最も安全です。明るい背景に暗いモジュールの組み合わせは、どのリーダーでもスキャンできます。代わりにテーマに合わせたい場合は、`fgColor="currentColor"` を設定し、背景を透明にします。この場合、ダークモードではコードが反転します。スマートフォンのカメラは読み取れますが、古いスキャナーの中には読み取れないものもあります。

<ComponentPreview name="qr-code-dark-mode" />

## Next.jsのページで使う [#in-a-nextjs-page]

`QrCode` はClient Componentです(ダウンロードボタンがあるため、ファイルの先頭に `"use client"` があります)。そのため、Server Componentのページからインポートして、サーバーのデータをpropsとして渡せます。

```tsx title="app/menu/page.tsx"
import { QrCode } from "@/components/qr-code";

export default function MenuPage() {
  return (
    <QrCode
      value="https://example.com/menu"
      caption="Scan to see the menu"
      filename="menu-qr"
    />
  );
}
```

コード自体は引き続きサーバー上で描画されるので、ボタンが操作可能になる前からページのHTMLに含まれています。App Routerでのコードの描画について詳しくは、[Next.jsのQRコード](/docs/nextjs)をご覧ください。

## リンク以外のコンテンツ [#any-content-not-only-links]

`value` は渡したとおりにエンコードされるため、Wi-Fiネットワーク、連絡先カード、`mailto:`、`tel:`、プレーンテキストなど、あらゆるQRペイロードを使えます。`label` を設定すると、スクリーンリーダーは生のペイロード(Wi-Fiの場合はパスワードが含まれます)ではなく、そのコードの用途を読み上げます。

```tsx title="components/guest-wifi.tsx"
import { QrCode } from "@/components/qr-code";

export function GuestWifi() {
  return (
    <QrCode
      value="WIFI:T:WPA;S:Cafe Guest;P:sunshine123;;"
      label="QR code to join the Cafe Guest Wi-Fi"
      caption="Cafe Guest Wi-Fi"
    />
  );
}
```

フォームからペイロードを作成するには、特殊文字を自動でエスケープする[Wi-Fi QRコード](/docs/components/wifi-qr-code)または[vCard QRコード](/docs/components/vcard-qr-code)を使用してください。

## 入力欄の値を使う [#a-value-from-an-input]

```tsx title="components/link-qr-code.tsx"
"use client";

import { useState } from "react";
import { QrCode } from "@/components/qr-code";

export function LinkQrCode() {
  const [value, setValue] = useState("https://example.com");
  return (
    <div className="grid justify-items-center gap-4">
      <input
        aria-label="Link"
        className="w-full rounded-md border px-3 py-2"
        value={value}
        onChange={(event) => setValue(event.target.value)}
      />
      {value ? <QrCode value={value} downloadFormats={[]} /> : null}
    </div>
  );
}
```

`downloadFormats={[]}` は、入力中にボタンを非表示にします。値が確定したらボタンを表示してください。

## 印刷に適したダウンロード [#print-ready-downloads]

```tsx title="components/table-code.tsx"
import { QrCode } from "@/components/qr-code";

export function TableCode() {
  return (
    <QrCode
      value="https://example.com/order?table=12"
      level="H"
      margin={4}
      downloadFormats={["svg", "png", "pdf"]}
      downloadSize={2048}
      filename="table-12"
    />
  );
}
```

- **SVG** はぼやけることなく任意のサイズに拡大できるため、印刷業者やデザインツールに渡すファイルとして最適です。
- `downloadSize={2048}` の **PNG** は、300ピクセル/インチで幅約17 cm(6.8インチ)までくっきりと印刷できます。`downloadSize` には50〜5000ピクセルを指定できます。
- **PDF** には、オプションの `jspdf` パッケージ(`npm install jspdf`)が必要です。
- `filename` は拡張子を除いたファイル名を指定します。例: `table-12.svg`、`table-12.png`。

## 確実にスキャンできるようにする [#make-sure-it-scans]

- **コントラスト。** 明るい背景に暗いモジュールの組み合わせは、どのリーダーでもスキャンできます。暗い背景に明るいコードの組み合わせは、ほとんどのスマートフォンのカメラでは機能しますが、古いスキャナーの中には読み取れないものもあります。
- **クワイエットゾーン。** `margin` のデフォルトは2モジュールです。コードを写真、模様、暗いページの上に置く場合は4にしてください。
- **ロゴ。** `logo` を使うときは `level="H"` を指定してください。ロゴで隠れたモジュールがあってもコードを読み取れます。
- **印刷サイズ。** 約25 cmの距離からスキャンする短いリンクには、幅約2.5 cmのコードが必要です。ほかの距離については[印刷サイズ計算ツール](/tools/print-size)で求められます。
- **テストする。** 完成したコードを何台かのスマートフォンでスキャンするか、画像を[スキャンチェッカー](/tools/scan-checker)にアップロードしてください。
