## Verwendung [#usage]

```tsx
import { WifiQrCode } from "@/components/wifi-qr-code";
```

```tsx
<WifiQrCode ssid="Cafe Guest" password="espresso-2024" />
```

Die Kameras von iOS und Android bieten an, dem Netzwerk beizutreten, sobald sie den Code scannen. Du brauchst dafür keine App.

## Beispiele [#examples]

### Varianten [#variants]

`showPassword` gibt das Passwort im Klartext aus, damit Gäste es eintippen können. Verwende `encryption="nopass"` für offene Netzwerke und `hidden` für Netzwerke, die ihren Namen nicht senden.

<ComponentPreview name="wifi-qr-code-variants" />

### Payload-Builder [#payload-builder]

`buildWifiPayload` gibt den `WIFI:`-Text zurück, den der Code kodiert. Die Funktion escaped `\`, `;`, `,`, `:` und `"` in Namen und Passwörtern. Genau daran scheitern handgeschriebene Payloads meistens. Du kannst sie mit jedem QR-Renderer verwenden oder den Payload zum Debuggen ausgeben.

### buildWifiPayload [#buildwifipayload]

`buildWifiPayload(network: WifiNetwork): string` nimmt dieselben Netzwerkfelder entgegen wie die Komponente: `ssid`, `password`, `encryption` und `hidden`.
