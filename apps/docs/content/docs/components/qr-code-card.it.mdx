## Utilizzo [#usage]

```tsx
import { QrCodeCard } from "@/components/qr-code-card";
```

```tsx
<QrCodeCard
  value="https://example.com/menu"
  title="Our menu"
  description="Scan to see today's specials."
/>
```

Tutto ciò che passi come children viene mostrato nel footer della card, per esempio un pulsante di copia o un [menu di download](/docs/components/qr-code-download).

## Esempi [#examples]

### Cornici [#frames]

`frame` mette la call to action sotto il codice (`"bottom"`), sopra (`"top"`) oppure omette la cornice (`"none"`). `cta` cambia l'etichetta, mentre `frameClassName` modifica lo stile della cornice, per esempio con il colore del tuo brand.

<ComponentPreview name="qr-code-card-frames" />

Per impostazione predefinita la cornice usa i colori `foreground` e `background` del tuo tema, quindi resta leggibile sia in modalità chiara sia in modalità scura. Il codice invece mantiene uno sfondo chiaro, che ogni scanner riesce a leggere.

### Stile del codice [#styling-the-code]

`qr` accetta qualsiasi opzione di stile di qrdx: `fgColor`, `bgColor`, gradienti, `bodyPattern`, pattern degli angoli, `logo` e `templateId`.

```tsx
<QrCodeCard
  value="https://example.com"
  qr={{
    fgColor: "#155DFC",
    bodyPattern: "rounded",
    cornerEyePattern: "extra-rounded",
  }}
/>
```
