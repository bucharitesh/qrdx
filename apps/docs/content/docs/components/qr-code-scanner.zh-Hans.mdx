## 用法 [#usage]

```tsx
import { QrCodeScanner } from "@/components/qr-code-scanner";
```

```tsx
<QrCodeScanner onResult={(value) => console.log(value)} />
```

用户可以拖入图片，也可以点击选择图片。解码在浏览器中通过 qrdx 的[检测辅助函数](/docs/qr-detection)完成，因此图片不会离开设备。它读取的是图片文件，而不是实时摄像头画面。

识别结果会连同复制按钮一起显示；如果结果是 `http` 或 `https` 网址，还会显示“打开链接”按钮。
