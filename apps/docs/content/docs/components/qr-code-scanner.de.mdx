## Verwendung [#usage]

```tsx
import { QrCodeScanner } from "@/components/qr-code-scanner";
```

```tsx
<QrCodeScanner onResult={(value) => console.log(value)} />
```

Nutzer:innen legen ein Bild per Drag-and-drop ab oder klicken, um eines auszuwählen. Die Dekodierung läuft im Browser mit den [Erkennungs-Helfern](/docs/qr-detection) von qrdx, sodass das Bild das Gerät nie verlässt. Die Komponente liest Bilddateien, keinen Live-Kamerastream.

Das Ergebnis erscheint mit einem Kopieren-Button und, wenn es eine `http`- oder `https`-URL ist, zusätzlich mit einem Button „Link öffnen".

## Beispiele [#examples]

### Ein Ergebnis prüfen [#checking-a-result]

`onResult` erhält den dekodierten Text, sodass du darauf reagieren kannst, zum Beispiel um ein Ticket einzuchecken. `label` ändert die Überschrift in der Drop-Zone. Lade den obigen Beispiel-Code herunter und lege ihn dort ab, um ein gültiges Ticket zu sehen.
