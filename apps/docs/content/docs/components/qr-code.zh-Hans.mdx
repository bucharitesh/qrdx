## 用法 [#usage]

```tsx
import { QrCode } from "@/components/qr-code";
```

```tsx
<QrCode value="https://qrdx.dev" />
```

二维码以 SVG 形式渲染,并带有无障碍名称,因此在任何尺寸下都保持清晰,屏幕阅读器也会读出它所链接的内容。

## 示例 [#examples]

### 尺寸 [#sizes]

`size` 设置屏幕上显示的宽度和高度,单位为像素。下载时使用 `downloadSize`,因此页面上较小的二维码也能导出可直接用于印刷的文件。

<ComponentPreview name="qr-code-sizes" />

### 颜色 [#colors]

`fgColor` 和 `bgColor` 接受任何 CSS 颜色。`eyeColor` 和 `dotColor` 可分别为三个角上的定位点着色。请保持码点比背景更深,以便所有扫描器都能读取二维码。

<ComponentPreview name="qr-code-colors" />

### 渐变 [#gradients]

传入 qrdx 渐变来代替颜色:带 `angle` 的 `linear`,或 `radial`。渐变会保留在 PNG、SVG 和 PDF 下载文件中。

<ComponentPreview name="qr-code-gradient" />

### 图案 [#patterns]

`bodyPattern` 决定数据码点的形状,`cornerEyePattern` 决定角上的外框,`cornerEyeDotPattern` 决定框内的圆点。所有形状请参见[图案](/docs/features/patterns)。

<ComponentPreview name="qr-code-patterns" />

### Logo [#logo]

`logo` 会在中心放置一张图片,并清除其后方的码点。请使用纠错等级 `H`,这样二维码被部分遮挡后仍可扫描。使用 data URL 可让 Logo 保留在下载文件中;远程图片需要 CORS 响应头。

<ComponentPreview name="qr-code-logo" />

### 边框模板 [#frame-templates]

`templateId` 会在二维码周围绘制 qrdx 的一种[以模板绘制的边框](/docs/features/templates)。可搭配 `caption`,在边框下方添加行动号召文案。

<ComponentPreview name="qr-code-template" />

### 下载格式 [#download-formats]

`downloadFormats` 用于选择按钮:`png`、`jpg`、`svg` 和 `pdf`。导出 PDF 需要可选的 `jspdf` 包(`npm install jspdf`)。传入 `[]` 可隐藏按钮。

<ComponentPreview name="qr-code-downloads" />

如需在一个菜单中同时选择格式和尺寸,请使用[二维码下载](/docs/components/qr-code-download)。

### 深色模式 [#dark-mode]

在深色主题中,默认的白色背景是最稳妥的选择:浅色底板上的深色码点可被所有读码器识别。如果想跟随主题,请设置 `fgColor="currentColor"` 并使用透明背景。这样二维码在深色模式下会反色,手机相机可以读取,但一些较旧的扫描器无法识别。

<ComponentPreview name="qr-code-dark-mode" />

## 在 Next.js 页面中 [#in-a-nextjs-page]

`QrCode` 是客户端组件(由于有下载按钮,其文件以 `"use client"` 开头),因此服务端组件页面可以导入它,并将服务端数据作为属性传入:

```tsx title="app/menu/page.tsx"
import { QrCode } from "@/components/qr-code";

export default function MenuPage() {
  return (
    <QrCode
      value="https://example.com/menu"
      caption="Scan to see the menu"
      filename="menu-qr"
    />
  );
}
```

二维码本身仍在服务端渲染,所以在按钮变为可交互之前,它就已经包含在页面的 HTML 中。有关在 App Router 中渲染二维码的更多内容,请参见 [Next.js 中的二维码](/docs/nextjs)。

## 任意内容,不只是链接 [#any-content-not-only-links]

`value` 会按你传入的内容原样编码,因此任何二维码载荷都可以使用:Wi-Fi 网络、联系人名片、`mailto:`、`tel:` 或纯文本。请设置 `label`,让屏幕阅读器读出二维码的用途,而不是原始载荷,因为 Wi-Fi 的载荷中包含密码。

```tsx title="components/guest-wifi.tsx"
import { QrCode } from "@/components/qr-code";

export function GuestWifi() {
  return (
    <QrCode
      value="WIFI:T:WPA;S:Cafe Guest;P:sunshine123;;"
      label="QR code to join the Cafe Guest Wi-Fi"
      caption="Cafe Guest Wi-Fi"
    />
  );
}
```

如需通过表单生成载荷,请使用 [Wi-Fi 二维码](/docs/components/wifi-qr-code) 或 [vCard 二维码](/docs/components/vcard-qr-code),它们会为你转义特殊字符。

## 来自输入框的值 [#a-value-from-an-input]

```tsx title="components/link-qr-code.tsx"
"use client";

import { useState } from "react";
import { QrCode } from "@/components/qr-code";

export function LinkQrCode() {
  const [value, setValue] = useState("https://example.com");
  return (
    <div className="grid justify-items-center gap-4">
      <input
        aria-label="Link"
        className="w-full rounded-md border px-3 py-2"
        value={value}
        onChange={(event) => setValue(event.target.value)}
      />
      {value ? <QrCode value={value} downloadFormats={[]} /> : null}
    </div>
  );
}
```

`downloadFormats={[]}` 会在用户仍在输入时隐藏按钮;等值确定后再显示它们。

## 可直接印刷的下载文件 [#print-ready-downloads]

```tsx title="components/table-code.tsx"
import { QrCode } from "@/components/qr-code";

export function TableCode() {
  return (
    <QrCode
      value="https://example.com/order?table=12"
      level="H"
      margin={4}
      downloadFormats={["svg", "png", "pdf"]}
      downloadSize={2048}
      filename="table-12"
    />
  );
}
```

- **SVG** 可缩放到任意大小而不模糊,因此是交给印刷店或设计工具的最佳文件。
- 设置为 `downloadSize={2048}` 的 **PNG**,在每英寸 300 像素下,最宽约 17 厘米(6.8 英寸)内都能清晰打印。`downloadSize` 的取值范围是 50 到 5000 像素。
- **PDF** 需要可选的 `jspdf` 包(`npm install jspdf`)。
- `filename` 用于指定不含扩展名的文件名:`table-12.svg`、`table-12.png`。

## 确保可以扫描 [#make-sure-it-scans]

- **对比度。** 浅色背景上的深色码点可被所有读码器扫描。深色背景上的浅色二维码在大多数手机相机上可用,但在一些较旧的扫描器上不行。
- **静区。** `margin` 默认为 2 个码点。当二维码放在照片、图案或深色页面上时,请使用 4。
- **Logo。** 使用 `logo` 时请搭配 `level="H"`,这样二维码在 Logo 遮住部分码点后仍可读取。
- **打印尺寸。** 从约 25 厘米处扫描短链接,需要约 2.5 厘米宽的二维码;其他距离可用[打印尺寸计算器](/tools/print-size)算出。
- **测试。** 用几部手机扫描最终的二维码,或将图片上传到[扫描检查器](/tools/scan-checker)。
