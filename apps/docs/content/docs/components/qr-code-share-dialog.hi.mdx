## उपयोग [#usage]

```tsx
import { QrCodeShareDialog } from "@/components/qr-code-share-dialog";
```

```tsx
<QrCodeShareDialog url="https://example.com/invite/abc123" />
```

डायलॉग में QR कोड, रीड-ओनली फ़ील्ड में लिंक और कॉपी बटन, और PNG डाउनलोड दिखता है। जिन डिवाइस में शेयर शीट होती है (ज़्यादातर फ़ोन), वहाँ "Share…" बटन उसे खोलता है।

## उदाहरण [#examples]

### कस्टम ट्रिगर [#custom-trigger]

अपना ट्रिगर children के रूप में दें, जैसे टूलबार में कोई आइकन बटन। `title`, `description` और `qr` से डायलॉग को कस्टमाइज़ किया जा सकता है।

<ComponentPreview name="qr-code-share-dialog-trigger" />

### कंट्रोल्ड [#controlled]

यह डायलॉग [Dialog](https://ui.shadcn.com/docs/components/dialog) के props स्वीकार करता है, इसलिए आप इसे कोड से खोल सकते हैं:

```tsx
const [open, setOpen] = useState(false);

<QrCodeShareDialog
  url="https://example.com"
  open={open}
  onOpenChange={setOpen}
/>
```
