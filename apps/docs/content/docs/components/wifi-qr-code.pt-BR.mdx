## Uso [#usage]

```tsx
import { WifiQrCode } from "@/components/wifi-qr-code";
```

```tsx
<WifiQrCode ssid="Cafe Guest" password="espresso-2024" />
```

As câmeras do iOS e do Android oferecem a opção de conectar à rede quando leem o código. Não é preciso instalar nenhum app.

## Exemplos [#examples]

### Variantes [#variants]

`showPassword` exibe a senha para convidados que preferem digitá-la. Use `encryption="nopass"` para redes abertas e `hidden` para redes que não divulgam o nome.

<ComponentPreview name="wifi-qr-code-variants" />

### Construtor de payload [#payload-builder]

`buildWifiPayload` retorna o texto `WIFI:` que o código codifica. Ele aplica escape em `\`, `;`, `,`, `:` e `"` nos nomes e nas senhas, que é onde os payloads escritos à mão costumam quebrar. Use-o com qualquer renderizador de QR code, ou para imprimir o payload ao depurar.

### buildWifiPayload [#buildwifipayload]

`buildWifiPayload(network: WifiNetwork): string` recebe os mesmos campos de rede do componente: `ssid`, `password`, `encryption` e `hidden`.
