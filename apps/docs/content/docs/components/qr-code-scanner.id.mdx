## Penggunaan [#usage]

```tsx
import { QrCodeScanner } from "@/components/qr-code-scanner";
```

```tsx
<QrCodeScanner onResult={(value) => console.log(value)} />
```

Pengguna dapat menjatuhkan gambar atau mengeklik untuk memilihnya. Proses decoding berjalan di browser dengan [helper deteksi](/docs/qr-detection) dari qrdx, sehingga gambar tidak pernah meninggalkan perangkat. Komponen ini membaca file gambar, bukan umpan kamera langsung.

Hasilnya muncul bersama tombol salin, ditambah tombol "Open link" jika hasilnya berupa URL `http` atau `https`.

## Contoh [#examples]

### Memeriksa hasil [#checking-a-result]

`onResult` menerima teks hasil decoding, sehingga Anda dapat melakukan tindakan terhadapnya, misalnya untuk memeriksa tiket masuk. `label` mengubah judul di area tarik dan lepas. Unduh kode contoh di atas lalu jatuhkan ke area tersebut untuk melihat tiket yang valid.
