## Uso [#usage]

```tsx
import { QrCodeCard } from "@/components/qr-code-card";
```

```tsx
<QrCodeCard
  value="https://example.com/menu"
  title="Our menu"
  description="Scan to see today's specials."
/>
```

Todo lo que pases como children se muestra en el pie de la tarjeta, por ejemplo un botón de copiar o un [menú de descarga](/docs/components/qr-code-download).

## Ejemplos [#examples]

### Marcos [#frames]

`frame` coloca la llamada a la acción debajo del código (`"bottom"`), encima (`"top"`) o elimina el marco (`"none"`). `cta` cambia el texto, y `frameClassName` modifica el estilo del marco, por ejemplo con el color de tu marca.

<ComponentPreview name="qr-code-card-frames" />

De forma predeterminada, el marco usa los colores `foreground` y `background` de tu tema, por lo que se lee bien tanto en modo claro como en modo oscuro. El código en sí mantiene un fondo claro, que cualquier lector puede escanear.

### Estilo del código [#styling-the-code]

`qr` acepta cualquier opción de estilo de qrdx: `fgColor`, `bgColor`, degradados, `bodyPattern`, patrones de esquina, `logo` y `templateId`.

```tsx
<QrCodeCard
  value="https://example.com"
  qr={{
    fgColor: "#155DFC",
    bodyPattern: "rounded",
    cornerEyePattern: "extra-rounded",
  }}
/>
```
