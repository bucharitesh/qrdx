`QrCodeCard` puts a QR code in a card with a call-to-action frame, a heading, a line of text and a footer for buttons. Use it where a code is the point of the card: a table tent, a check-in screen, an event poster preview, a "download our app" tile.

## Usage

```tsx title="components/example.tsx"
import { QrCodeCard } from "@/components/qr-code-card";
```

```tsx title="components/example.tsx"
<QrCodeCard
  value="https://example.com/menu"
  title="Our menu"
  description="Scan to see today's specials."
/>
```

Anything you pass as children renders in the card footer, such as a copy button or a [download menu](/docs/components/qr-code-download).

## Examples

### Frames

`frame` puts the call to action under the code (`"bottom"`), above it (`"top"`) or leaves the frame out (`"none"`). `cta` changes the label, and `frameClassName` restyles the frame, for example with your brand color.

<ComponentPreview name="qr-code-card-frames" />

The frame uses your theme's `foreground` and `background` colors by default, so it stays legible in light and dark mode. The code itself keeps a light background, which every scanner reads.

### Styling the code

`qr` takes any qrdx style option: `fgColor`, `bgColor`, gradients, `bodyPattern`, corner patterns, `logo` and `templateId`.

```tsx title="components/brand-card.tsx"
import { QrCodeCard } from "@/components/qr-code-card";

export function BrandCard() {
  return (
    <QrCodeCard
      value="https://example.com"
      title="example.com"
      qr={{
        fgColor: "#155DFC",
        bodyPattern: "rounded",
        cornerEyePattern: "extra-rounded",
      }}
    />
  );
}
```

## Accessibility and rendering

- The code sits in a `role="img"` element whose `aria-label` is `label`, or `QR code: <value>` without one. Set `label` when the value is not a public link.
- `title` renders as the card's heading and `description` under it; both take any React node.
- The component is a Client Component. A Server Component page can import it and pass server data as props, and the code is rendered on the server.
