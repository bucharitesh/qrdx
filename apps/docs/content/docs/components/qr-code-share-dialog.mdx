`QrCodeShareDialog` opens a dialog that shows a link as a QR code, with the link in a field you can copy, a PNG download and, on phones, the system share sheet. Use it behind a "Share" button wherever people hand a link to someone standing next to them: an invite, a document, a profile.

## Usage

```tsx title="components/example.tsx"
import { QrCodeShareDialog } from "@/components/qr-code-share-dialog";
```

```tsx title="components/example.tsx"
<QrCodeShareDialog url="https://example.com/invite/abc123" />
```

The dialog shows the code, the link in a read-only field with a copy button, and **Download PNG**. On devices with a share sheet (most phones), a **Share…** button opens it.

## Examples

### Custom trigger

Pass your own trigger as children, such as an icon button in a toolbar. `title`, `description` and `qr` customize the dialog.

<ComponentPreview name="qr-code-share-dialog-trigger" />

### Controlled

The dialog accepts the [Dialog](https://ui.shadcn.com/docs/components/dialog) props, so you can open it from code:

```tsx title="components/share-after-save.tsx"
"use client";

import { useState } from "react";
import { QrCodeShareDialog } from "@/components/qr-code-share-dialog";

export function ShareAfterSave({ url }: { url: string }) {
  const [open, setOpen] = useState(false);
  return (
    <>
      <button type="button" onClick={() => setOpen(true)}>
        Save and share
      </button>
      <QrCodeShareDialog url={url} open={open} onOpenChange={setOpen} />
    </>
  );
}
```

## Accessibility and rendering

- The dialog is your Dialog, so focus moves into it when it opens and returns to the trigger when it closes.
- The code has `aria-label="QR code: <url>"`, and the link field has a visually hidden "Link" label. The copy button's label changes to "Link copied" for a moment after a copy.
- The **Share…** button appears only where `navigator.share` exists, after the first render in the browser, so the server's HTML and the client's first paint match.
- Clicking the link field selects the whole link. Copying needs a secure context (HTTPS or localhost).
