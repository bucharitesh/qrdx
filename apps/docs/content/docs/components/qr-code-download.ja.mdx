## 使い方 [#usage]

```tsx
import { QrCodeDownload } from "@/components/qr-code-download";
```

```tsx
<QrCodeDownload value="https://qrdx.dev" />
```

メニューには、各形式が短い説明付きで表示されるほか、サイズの選択と「画像をコピー」が用意されています。「画像をコピー」を選ぶと、PNGがクリップボードにコピーされます。ファイルはブラウザー上で生成され、アップロードされることはありません。

## 例 [#examples]

### 形式 [#formats]

| 形式 | 出力 |
|--------|--------|
| `png` | QRコードの背景を含む画像 |
| `jpg` | 単色の背景を持つ画像 |
| `svg` | 任意のサイズに拡大縮小できるベクター形式 |
| `pdf` | 1ページのドキュメント。オプションの `jspdf` パッケージが必要です（`npm install jspdf`） |

ラスター形式のサイズは50〜5000ピクセルの範囲で指定できます。`sizes` に1つだけ指定すると、サイズの選択が非表示になります。
