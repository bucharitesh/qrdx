## उपयोग [#usage]

```tsx
import { QrCodeScanner } from "@/components/qr-code-scanner";
```

```tsx
<QrCodeScanner onResult={(value) => console.log(value)} />
```

यूज़र कोई इमेज ड्रॉप करते हैं या क्लिक करके चुनते हैं। डिकोडिंग ब्राउज़र में ही qrdx के [डिटेक्शन हेल्पर](/docs/qr-detection) से होती है, इसलिए इमेज डिवाइस से बाहर नहीं जाती। यह इमेज फ़ाइलें पढ़ता है, लाइव कैमरा फ़ीड नहीं।

नतीजा एक कॉपी बटन के साथ दिखता है, और अगर वह `http` या `https` URL है तो "Open link" बटन भी दिखता है।

## उदाहरण [#examples]

### नतीजा जाँचना [#checking-a-result]

`onResult` को डिकोड किया हुआ टेक्स्ट मिलता है, जिससे आप उस पर कार्रवाई कर सकते हैं, जैसे किसी टिकट को चेक-इन करना। `label` ड्रॉप ज़ोन का शीर्षक बदलता है। ऊपर दिया गया सैंपल कोड डाउनलोड करें और उसे ड्रॉप करके देखें कि वैध टिकट कैसा दिखता है।
