## 사용법 [#usage]

```tsx
import { QrCodeScanner } from "@/components/qr-code-scanner";
```

```tsx
<QrCodeScanner onResult={(value) => console.log(value)} />
```

이미지를 드롭하거나 클릭해서 선택할 수 있습니다. 디코딩은 qrdx의 [감지 도우미](/docs/qr-detection)를 사용해 브라우저에서 실행되므로 이미지가 기기 밖으로 나가지 않습니다. 이미지 파일을 읽으며, 실시간 카메라 영상은 읽지 않습니다.

결과에는 복사 버튼이 표시되고, 결과가 `http` 또는 `https` URL이면 "링크 열기" 버튼도 함께 표시됩니다.
