## Penggunaan [#usage]

```tsx
import { QrCodeGenerator } from "@/components/qr-code-generator";
```

```tsx
<QrCodeGenerator defaultValue="https://example.com" />
```

Pratinjau diperbarui saat Anda mengetik. Setiap tombol preset menampilkan contoh kecil gayanya, dan unduhan menggunakan preset yang dipilih pada ukuran 1024 piksel.

## Contoh [#examples]

### Preset kustom [#custom-presets]

Ganti preset bawaan dengan preset Anda sendiri. Sebuah preset terdiri dari `id`, `name`, dan `style` dengan opsi qrdx apa pun, termasuk gradien, logo, dan `level` koreksi kesalahan.

<ComponentPreview name="qr-code-generator-presets" />

Preset bawaan diekspor sebagai `QR_CODE_PRESETS`, sehingga Anda dapat memperluasnya:

```tsx
import { QR_CODE_PRESETS, QrCodeGenerator } from "@/components/qr-code-generator";

<QrCodeGenerator
  presets={[
    ...QR_CODE_PRESETS,
    { id: "brand", name: "Brand", style: { fgColor: "#155DFC" } },
  ]}
/>
```

### Menyimpan hasil [#saving-the-result]

`onChange` melaporkan teks dan preset yang dipilih pada setiap perubahan, misalnya untuk menyimpan pilihan pengguna:

```tsx
<QrCodeGenerator
  onChange={({ value, preset }) => saveDraft({ value, style: preset.style })}
/>
```
