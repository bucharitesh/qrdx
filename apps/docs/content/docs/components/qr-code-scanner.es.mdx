## Uso [#usage]

```tsx
import { QrCodeScanner } from "@/components/qr-code-scanner";
```

```tsx
<QrCodeScanner onResult={(value) => console.log(value)} />
```

Las personas sueltan una imagen o hacen clic para elegir una. La decodificación se ejecuta en el navegador con los [ayudantes de detección](/docs/qr-detection) de qrdx, así que la imagen nunca sale del dispositivo. Lee archivos de imagen, no una transmisión de cámara en vivo.

El resultado aparece con un botón de copiar, además de un botón "Abrir enlace" cuando es una URL `http` o `https`.

## Ejemplos [#examples]

### Comprobar un resultado [#checking-a-result]

`onResult` recibe el texto decodificado, así que puedes actuar con él, por ejemplo para registrar la entrada de un ticket. `label` cambia el encabezado de la zona de arrastre. Descarga el código de ejemplo de arriba y suéltalo para ver un ticket válido.
