`VCardQrCode` renders a code that saves a contact when a phone camera scans it, with the name and role under it. Use it on a business card, a staff directory, a conference badge or an email signature page.

## Usage

```tsx title="components/example.tsx"
import { VCardQrCode } from "@/components/vcard-qr-code";
```

```tsx title="components/example.tsx"
<VCardQrCode
  contact={{
    firstName: "Ada",
    lastName: "Lovelace",
    organization: "Analytical Engines",
    email: "ada@example.com",
  }}
/>
```

Phone cameras offer to save the contact when they scan the code. Empty fields are left out, which keeps the code small and quick to scan.

## Examples

### vCard builder

`buildVCard` returns the vCard 3.0 text the code encodes, with commas, semicolons, backslashes and line breaks escaped. Use it with any QR renderer, or to offer the same contact as a `.vcf` download.

<ComponentPreview name="vcard-qr-code-payload" />

Contact cards hold more text than a link, so the component uses error correction level `M` to keep the modules large. Add only the fields people need, and check how large to print it with the [print size calculator](/tools/print-size).

## Accessibility and rendering

- The code has `aria-label="QR code with the contact card for <name>"`. The card's fields are not read out.
- The name and the title and organization under the code are the figure's `<figcaption>`. Set `showDetails={false}` to show the code alone.
- The component is a Client Component, and the code is rendered on the server.

### VCardContact

`buildVCard(contact: VCardContact): string` writes `N`, `FN`, `ORG`, `TITLE`, `TEL` (work and mobile), `EMAIL`, `URL`, `ADR` and `NOTE` lines, each only when the field is set.
