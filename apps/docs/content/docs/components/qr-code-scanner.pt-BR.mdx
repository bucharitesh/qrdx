## Uso [#usage]

```tsx
import { QrCodeScanner } from "@/components/qr-code-scanner";
```

```tsx
<QrCodeScanner onResult={(value) => console.log(value)} />
```

As pessoas soltam uma imagem ou clicam para escolher uma. A decodificação roda no navegador com os [helpers de detecção](/docs/qr-detection) do qrdx, então a imagem nunca sai do dispositivo. Ele lê arquivos de imagem, não a transmissão de uma câmera ao vivo.

O resultado aparece com um botão de copiar, além de um botão "Abrir link" quando for uma URL `http` ou `https`.
