## 사용법 [#usage]

```tsx
import { QrCode } from "@/components/qr-code";
```

```tsx
<QrCode value="https://qrdx.dev" />
```

코드는 접근 가능한 이름이 있는 SVG로 렌더링됩니다. 그래서 어떤 크기에서도 선명하고, 스크린 리더가 코드가 연결된 대상을 읽어 줍니다.

## 예제 [#examples]

### 크기 [#sizes]

`size`는 화면에 표시되는 가로·세로 크기를 픽셀 단위로 정합니다. 다운로드에는 `downloadSize`가 사용되므로, 페이지에서는 작은 코드여도 인쇄에 적합한 파일로 내보낼 수 있습니다.

<ComponentPreview name="qr-code-sizes" />

### 색상 [#colors]

`fgColor`와 `bgColor`에는 모든 CSS 색상을 사용할 수 있습니다. `eyeColor`와 `dotColor`는 세 개의 모서리 눈 색상을 따로 지정합니다. 모든 스캐너가 코드를 읽을 수 있도록 모듈은 배경보다 어둡게 유지하세요.

<ComponentPreview name="qr-code-colors" />

### 그라디언트 [#gradients]

색상 대신 qrdx 그라디언트를 전달할 수 있습니다. `angle`을 지정한 `linear` 또는 `radial`을 사용합니다. 그라디언트는 PNG, SVG, PDF 다운로드에도 그대로 적용됩니다.

<ComponentPreview name="qr-code-gradient" />

### 패턴 [#patterns]

`bodyPattern`은 데이터 모듈의 모양을, `cornerEyePattern`은 모서리 프레임을, `cornerEyeDotPattern`은 그 안쪽 점의 모양을 정합니다. 모든 모양은 [패턴](/docs/features/patterns)에서 확인하세요.

<ComponentPreview name="qr-code-patterns" />

### 로고 [#logo]

`logo`는 중앙에 이미지를 배치하고 그 뒤의 모듈을 비웁니다. 일부가 가려져도 코드가 스캔되도록 오류 정정 레벨 `H`를 사용하세요. 데이터 URL을 사용하면 다운로드한 파일에도 로고가 유지되며, 원격 이미지는 CORS 헤더가 필요합니다.

<ComponentPreview name="qr-code-logo" />

### 프레임 템플릿 [#frame-templates]

`templateId`는 qrdx의 [템플릿으로 그리는 프레임](/docs/features/templates) 중 하나를 코드 주위에 그려요. `caption`과 함께 사용하면 프레임 아래에 행동 유도 문구를 넣을 수 있습니다.

<ComponentPreview name="qr-code-template" />

### 다운로드 형식 [#download-formats]

`downloadFormats`는 표시할 버튼을 정합니다. `png`, `jpg`, `svg`, `pdf`를 사용할 수 있습니다. PDF 내보내기에는 선택 패키지인 `jspdf`가 필요합니다(`npm install jspdf`). 버튼을 숨기려면 `[]`를 전달하세요.

<ComponentPreview name="qr-code-downloads" />

형식과 크기를 하나의 메뉴로 제공하려면 [QR Code Download](/docs/components/qr-code-download)를 사용하세요.

### 다크 모드 [#dark-mode]

다크 테마에서도 기본 흰색 배경이 가장 안전합니다. 밝은 타일 위의 어두운 모듈은 모든 리더에서 스캔됩니다. 대신 테마를 따르게 하려면 `fgColor="currentColor"`로 설정하고 배경을 투명하게 하세요. 그러면 다크 모드에서 코드가 반전되는데, 휴대폰 카메라는 읽을 수 있지만 일부 구형 스캐너는 읽지 못합니다.

## Next.js 페이지에서 [#in-a-nextjs-page]

`QrCode`는 클라이언트 컴포넌트입니다(다운로드 버튼 때문에 파일이 `"use client"`로 시작합니다). 따라서 서버 컴포넌트 페이지에서 가져와 서버 데이터를 props로 전달할 수 있습니다.

```tsx title="app/menu/page.tsx"
import { QrCode } from "@/components/qr-code";

export default function MenuPage() {
  return (
    <QrCode
      value="https://example.com/menu"
      caption="Scan to see the menu"
      filename="menu-qr"
    />
  );
}
```

코드 자체는 여전히 서버에서 렌더링되므로, 버튼이 상호작용 가능해지기 전에도 페이지 HTML에 포함되어 있습니다. App Router에서 코드를 렌더링하는 방법은 [Next.js의 QR 코드](/docs/nextjs)를 참고하세요.

## 링크뿐 아니라 모든 콘텐츠 [#any-content-not-only-links]

`value`는 전달한 그대로 인코딩되므로 Wi-Fi 네트워크, 연락처 카드, `mailto:`, `tel:`, 일반 텍스트 등 어떤 QR 페이로드든 사용할 수 있습니다. `label`을 설정하면 스크린 리더가 원본 페이로드 대신 코드의 기능을 읽어 줍니다. Wi-Fi의 경우 원본 페이로드에는 비밀번호가 들어 있습니다.

```tsx title="components/guest-wifi.tsx"
import { QrCode } from "@/components/qr-code";

export function GuestWifi() {
  return (
    <QrCode
      value="WIFI:T:WPA;S:Cafe Guest;P:sunshine123;;"
      label="QR code to join the Cafe Guest Wi-Fi"
      caption="Cafe Guest Wi-Fi"
    />
  );
}
```

폼에서 페이로드를 만들려면 특수 문자를 대신 이스케이프해 주는 [Wi-Fi QR Code](/docs/components/wifi-qr-code) 또는 [vCard QR Code](/docs/components/vcard-qr-code)를 사용하세요.

## 입력값 사용하기 [#a-value-from-an-input]

```tsx title="components/link-qr-code.tsx"
"use client";

import { useState } from "react";
import { QrCode } from "@/components/qr-code";

export function LinkQrCode() {
  const [value, setValue] = useState("https://example.com");
  return (
    <div className="grid justify-items-center gap-4">
      <input
        aria-label="Link"
        className="w-full rounded-md border px-3 py-2"
        value={value}
        onChange={(event) => setValue(event.target.value)}
      />
      {value ? <QrCode value={value} downloadFormats={[]} /> : null}
    </div>
  );
}
```

`downloadFormats={[]}`는 사용자가 입력하는 동안 버튼을 숨깁니다. 값이 확정되면 버튼을 표시하세요.

## 인쇄용 다운로드 [#print-ready-downloads]

```tsx title="components/table-code.tsx"
import { QrCode } from "@/components/qr-code";

export function TableCode() {
  return (
    <QrCode
      value="https://example.com/order?table=12"
      level="H"
      margin={4}
      downloadFormats={["svg", "png", "pdf"]}
      downloadSize={2048}
      filename="table-12"
    />
  );
}
```

- **SVG**는 흐려짐 없이 어떤 크기로든 확대할 수 있어, 인쇄소나 디자인 도구에 가장 적합한 파일입니다.
- `downloadSize={2048}`의 **PNG**는 300ppi 기준 약 17cm(6.8인치) 너비까지 선명하게 인쇄됩니다. `downloadSize`는 50~5000픽셀을 지정할 수 있습니다.
- **PDF**에는 선택 패키지인 `jspdf`가 필요합니다(`npm install jspdf`).
- `filename`은 확장자를 뺀 파일 이름을 지정합니다. 예: `table-12.svg`, `table-12.png`.

## 스캔이 되는지 확인하기 [#make-sure-it-scans]

- **대비.** 밝은 배경 위의 어두운 모듈은 모든 리더에서 스캔됩니다. 어두운 배경 위의 밝은 코드는 대부분의 휴대폰 카메라에서는 작동하지만 일부 구형 스캐너에서는 작동하지 않습니다.
- **여백.** `margin`의 기본값은 2모듈입니다. 코드를 사진, 패턴, 어두운 페이지 위에 놓을 때는 4를 사용하세요.
- **로고.** `logo`를 사용할 때는 `level="H"`를 사용하세요. 로고가 가리는 모듈이 있어도 코드가 유지됩니다.
- **인쇄 크기.** 약 25cm 거리에서 짧은 링크를 스캔하려면 너비 약 2.5cm의 코드가 필요합니다. 다른 거리는 [인쇄 크기 계산기](/tools/print-size)로 계산할 수 있습니다.
- **테스트.** 완성된 코드를 여러 대의 휴대폰으로 스캔하거나, 이미지를 [스캔 검사기](/tools/scan-checker)에 업로드해 보세요.
