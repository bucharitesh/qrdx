By the end of this page you will have a styled QR code in a Preact component and a button that saves it as a PNG. `qrdx/preact` has the React library's two SVG components, `QRCodeSVG` and `QRCode`, built for Preact. They draw with Preact's own `h`, so you need neither `preact/compat` nor `react`, and they draw the same SVG as the React components.

<NpmStatus package="qrdx" />

## Before you start

- A Preact 10 or newer project, with Vite or any other bundler.
- Node.js 18 or newer.

## Build it

### 1. Install qrdx

```package-install
qrdx
```

`preact` is an optional peer dependency of `qrdx`. Your app already has it.

### 2. Draw a code

```tsx title="src/components/menu-code.tsx"
import { QRCodeSVG } from "qrdx/preact";

export function MenuCode() {
  return (
    <QRCodeSVG
      value="https://example.com/menu"
      size={256}
      margin={4}
      bodyPattern="rounded"
      frame={{ style: "banner-bottom", text: "Scan me" }}
      aria-label="QR code for the menu"
    />
  );
}
```

The page shows a 256 px code with rounded modules and a "Scan me" banner under it.

{/* shot: preact-first-code | the framed code from menu-code.tsx in a Vite Preact project | run the example with npm create preact */}

`QRCodeSVG` takes every option the React `QRCodeSVG` takes: patterns, colors and gradients, logos (`imageSettings`), frames, shapes, templates and art. Attributes such as `class`, `style` or `aria-label` go on the `<svg>`, or on the frame's outer `<svg>` when there is a frame.

`QRCode` adds the React `QRCode`'s logo shortcut: `logo`, `logoOptions`, `hideLogo` and `scale`. It takes the code's props and `style` only; put `class` or `aria-label` on an element around it, or use `QRCodeSVG`.

```tsx title="src/components/logo-code.tsx"
import { QRCode } from "qrdx/preact";

export function LogoCode() {
  return <QRCode value="https://example.com" size={256} logo="/logo.png" level="H" />;
}
```

Both components redraw when a prop changes and skip the work when none did. Event handlers in the props are not put on the `<svg>`, as in React. Put them on an element around the code.

### 3. Save it as a file

The components only draw the code. Downloads, `toSVGString`, the scan score and the other functions come from `qrdx/core`. That is the engine the components already use, so it is not bundled twice.

```tsx title="src/components/downloadable-code.tsx"
import { downloadQRCode } from "qrdx/core";
import { QRCodeSVG } from "qrdx/preact";

const options = { value: "https://example.com", size: 256, margin: 4 };

export function DownloadableCode() {
  return (
    <>
      <QRCodeSVG {...options} />
      <button
        type="button"
        onClick={() =>
          downloadQRCode(options, {
            format: "png",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.png",
          })
        }
      >
        Download PNG
      </button>
    </>
  );
}
```

Clicking the button saves `qr-code.png` at 1024 px. Keep the options in one object, as above, so the file matches the code on screen. [Vanilla JavaScript](/docs/vanilla-js) covers `qrdx/core` in full.

## Server rendering

`renderToString` from `preact-render-to-string` writes the same SVG as `toSVGString` from `qrdx/core`. The only difference is escaping: Preact leaves `>` and `'` as they are in text, where the core writes `&gt;` and `&#x27;`. Browsers read both the same way.

`hydrate` keeps the server's `<svg>` and does not draw it again. The markup has no random ids, so the server and the browser always agree.

## With preact/compat

If your app already aliases `react` to `preact/compat`, the React components from `qrdx` work too: `import { QRCodeSVG } from "qrdx"`. `qrdx/preact` draws the same code without the alias, so prefer it when you add `qrdx` to a Preact app.

## If something goes wrong

- **`Failed to resolve import "react"`.** You imported from `qrdx` instead of `qrdx/preact`, in an app without `preact/compat`. Change the import.
- **A click handler on the component does nothing.** Handlers are dropped from the `<svg>`. Wrap the code in a `<button>` or a `<div>` and put the handler there.
- **`PDF export needs the optional "jspdf" package`.** Run `npm install jspdf` in the app.
