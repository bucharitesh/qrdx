## コンポーネント [#components]

### QRCode [#qrcode]

QRコードを描画するメインコンポーネントです。

```tsx
import { QRCode } from 'qrdx';

<QRCode
  value="https://example.com"
  size={256}
  fgColor="#000000"
  bgColor="#ffffff"
/>
```

#### Props [#props]

| Prop | 型 | デフォルト | 説明 |
|------|------|---------|-------------|
| `value` | `string` | **必須** | エンコードする URL またはテキスト |
| `size` | `number` | `128` | ピクセル単位のサイズ |
| `scale` | `number` | `1` | 拡大率 |
| `fgColor` | `ColorConfig` | `#000000` | QRコードの色 |
| `bgColor` | `ColorConfig` | `#ffffff` | 背景色 |
| `eyeColor` | `ColorConfig` | `fgColor` | コーナーマーカーの色 |
| `dotColor` | `ColorConfig` | `fgColor` | 各コーナーアイの内側のドットの色 |
| `bodyPattern` | `BodyPattern` | `'circle'` | データドットのパターン |
| `cornerEyePattern` | `CornerEyePattern` | `'gear'` | コーナーマーカーのパターン |
| `cornerEyeDotPattern` | `CornerEyeDotPattern` | `'circle'` | コーナードットのパターン |
| `hideLogo` | `boolean` | `false` | ロゴを非表示にします。`logo` を設定しない限り、ロゴは描画されません |
| `logo` | `string` | — | ロゴの URL |
| `templateId` | `string` | `'default'` | テンプレート ID |
| `customTemplate` | `TemplateDefinition` | — | カスタムテンプレート |
| `level` | `ErrorLevel` | `'Q'` | 誤り訂正レベル |
| `autoLevel` | `boolean` | `false` | ロゴがコードの 7% を超えて覆う場合、`level` を H に引き上げます（`AUTO_LEVEL_LOGO_COVERAGE`） |
| `margin` | `number` | `0` | モジュール単位の余白 |
| `imageSettings` | `ImageSettings` | — | ロゴの設定 |
| `eyeColors` | `EyeColors` | — | `topLeft`、`topRight`、`bottomLeft` ごとの `outer` / `inner` の色。それぞれ `eyeColor` / `dotColor` を上書きします |
| `moduleScale` | `number` | `1` | データモジュールのサイズ（0.5〜1）。各パターンは、スキャンできる最小サイズで止まります（`MODULE_SCALE_FLOOR`） |
| `frame` | `QRFrame` | — | 行動喚起フレーム。[フレームと印刷](/docs/features/frames)を参照してください |
| `art` | `QRArt` | — | ロゴや写真をモジュールに溶け込ませます（Logo QR、Image QR）。[アート QR](/docs/features/art-qr)を参照してください |
| `frameLabelMarkers` | `boolean` | `false` | エディタ向け。各フレームラベルの `<text>` に `data-qrdx-frame-label`（`"text"`、`"secondaryText"`、または仕様ラベルの ID）を付けます。ダウンロードやエクスポートには含まれません |

{facts.bodyPatterns} 種類のボディパターン、{facts.eyeShapes} 種類のアイ、{facts.eyeCentres} 種類のアイ中心、{facts.frameStyles} 種類のフレームスタイルは、すべて[シェイプ、アイ、フレーム](/docs/styles)で実際の表示を確認できます。

## ダウンロード関数 [#download-functions]

### downloadQRCode [#downloadqrcode]

QRコードを複数の形式でダウンロードします。

```tsx
downloadQRCode(
  qrProps: QRProps,
  options: {
    format: 'png' | 'jpg' | 'webp' | 'svg' | 'pdf' | 'eps';
    size: { width: number; height: number };
    filename?: string;
    quality?: number; // WebP only: 0 to 1 for lossy; lossless when left out
  }
): Promise<void>
```

### getQRCodeDataUrl [#getqrcodedataurl]

データ URL として取得します。

```tsx
getQRCodeDataUrl(
  qrProps: QRProps,
  format: DownloadFormat,
  size: DownloadSize,
  options?: { quality?: number } // WebP only
): Promise<string>
```

### getQRAsWebP [#getqraswebp]

コードを WebP の `Blob` として返します。`quality` を設定しない限りロスレスです。ブラウザーが WebP をエンコードできない場合（Safari）は、qrdx 内蔵のロスレスエンコーダーが生成します。`canvasToWebP(canvas, options)` は任意のキャンバスに対して同じ処理を行い、`encodeWebPLossless(rgba, width, height)` は DOM なしで RGBA ピクセルをエンコードします。

```tsx
getQRAsWebP(
  qrProps: QRProps,
  options?: { quality?: number }
): Promise<Blob>
```

### copyQRCodeToClipboard [#copyqrcodetoclipboard]

クリップボードにコピーします。

```tsx
copyQRCodeToClipboard(
  qrProps: QRProps,
  size?: DownloadSize
): Promise<void>
```

### getSVGString [#getsvgstring]

```tsx
getSVGString(qrProps: QRProps): Promise<string>
```

## 印刷とスキャンの関数 [#print-and-scan-functions]

これらの関数は、各機能ページで例とともに説明しています。

| 関数 | 機能 | ドキュメント |
|----------|--------------|------|
| `getQRAsSVG(props)` | フレームを含むコードの SVG マークアップ | [フレーム](/docs/features/frames) |
| `getQRAsPrintPDF`, `downloadPrintPDF` | 正確な物理サイズのベクター PDF。裁ち落とし、トンボ、CMYK に対応（`jspdf` が必要） | [印刷用エクスポート](/docs/features/frames#print-ready-export) |
| `downloadPrintSVG` | 正確な物理サイズの印刷用 SVG | [印刷用エクスポート](/docs/features/frames#print-ready-export) |
| `getQRAsEPS`, `downloadPrintEPS` | 印刷会社やデザインツール向けのベクター EPS | [ダウンロード](/docs/features/downloads) |
| `getScanScore(props)` | デザインがどの程度確実にスキャンできるかを推定します | [スキャンできますか？](/docs/features/frames#will-it-scan) |
| `getImageScanScore(image)` | 手元にある QRコード画像を採点します（ブラウザーのみ） | [スキャンできますか？](/docs/features/frames#will-it-scan) |
| `getQRAsPNG(props, { size })` | DOM なしの通常の Node で PNG のバイト列を返します。`qrdx/node` からインポートします。`@resvg/resvg-js` または `sharp` のインストールが必要です | — |
| `scanQRPixels(pixels, expected)` | 生の RGBA ピクセルが `expected` にデコードされるかを、ぼかしや縮小を加えた場合も含めて確認します。Node で動作します | — |
| `getStylePairRisk(...)` | 一部のスキャナーが読み取れないアイとパターンの組み合わせを警告します | [パターン](/docs/features/patterns) |

## 型 [#types]

### コア型 [#core-types]

```tsx
type QRProps = {
  value: string;
  size?: number;
  level?: ErrorLevel;
  bgColor?: ColorConfig;
  fgColor?: ColorConfig;
  margin?: number;
  imageSettings?: ImageSettings;
  // ...
};

type ColorConfig =
  | string
  | { type: 'solid'; color: string }
  | LinearGradient
  | RadialGradient;

type ErrorLevel = 'L' | 'M' | 'Q' | 'H';
```

### パターン型 [#pattern-types]

```tsx
// The arrays BODY_PATTERN, CORNER_EYE_PATTERNS, CORNER_EYE_DOT_PATTERNS and
// FRAME_STYLES (and their zod schemas) are exported from 'qrdx/types'.

type BodyPattern =
  | 'circle' | 'circle-large' | 'square' | 'diamond' | 'circle-mixed'
  | 'pacman' | 'rounded' | 'small-square' | 'vertical-line'
  | 'horizontal-line' | 'liquid' | 'liquid-horizontal' | 'liquid-vertical'
  | 'classy' | 'classy-rounded' | 'leaf' | 'plus' | 'hexagon' | 'star'
  | 'heart' | 'random-dots' | 'mosaic' | 'octagon';

type CornerEyePattern =
  | 'square' | 'rounded' | 'gear' | 'circle' | 'diya' | 'extra-rounded'
  | 'message' | 'pointy' | 'leaf' | 'drop' | 'octagon' | 'bevel'
  | 'squircle' | 'cushion' | 'shield' | 'petal' | 'leaf-reverse';

type CornerEyeDotPattern =
  | 'square' | 'rounded' | 'circle' | 'message' | 'message-reverse'
  | 'diya' | 'diya-reverse' | 'rounded-triangle' | 'leaf' | 'drop' | 'plus'
  | 'cross-rounded' | 'hexagon' | 'octagon' | 'flower' | 'heart'
  | 'squircle' | 'dots' | 'extra-rounded' | 'leaf-reverse' | 'drop-reverse';

// Retired (deprecated) values still render for saved designs but are not
// offered: RETIRED_CORNER_EYE_PATTERNS, RETIRED_CORNER_EYE_DOT_PATTERNS.

type EyeColors = {
  topLeft?: { outer?: ColorConfig; inner?: ColorConfig };
  topRight?: { outer?: ColorConfig; inner?: ColorConfig };
  bottomLeft?: { outer?: ColorConfig; inner?: ColorConfig };
};

type QRFrame = {
  style: FrameStyle; // "none" or a frame, see FRAME_STYLES
  text?: string; // up to 24 characters, default "Scan me"
  color?: string;
  textColor?: string;
  secondaryText?: string; // banner-top-bottom, circle, menu-card
  secondaryColor?: string; // gradient-border end color
  fontScale?: number; // 0.5 to 1.5
};
```

## エラー処理 [#error-handling]

非同期関数は try-catch で囲んでください。

```tsx
try {
  await downloadQRCode(props, options);
} catch (error) {
  console.error('Failed:', error);
}
```

よくあるエラー:
- 無効な画像 URL
- ネットワーク障害
- 無効なサイズパラメーター
- Canvas コンテキストが利用できない
