## コンポーネント [#components]

### QRCode [#qrcode]

QRコードを描画するメインのコンポーネントです。

```tsx
import { QRCode } from 'qrdx';

<QRCode
  value="https://example.com"
  size={256}
  fgColor="#000000"
  bgColor="#ffffff"
/>
```

#### プロパティ [#props]

| プロパティ | 型 | デフォルト | 説明 |
|------|------|---------|-------------|
| `value` | `string` | **必須** | エンコードするURLまたはテキスト |
| `size` | `number` | `128` | サイズ（ピクセル） |
| `scale` | `number` | `1` | 拡大率 |
| `fgColor` | `ColorConfig` | `#000000` | QRコードの色 |
| `bgColor` | `ColorConfig` | `#ffffff` | 背景色 |
| `eyeColor` | `ColorConfig` | `fgColor` | コーナーマーカーの色 |
| `dotColor` | `ColorConfig` | `fgColor` | 各コーナーアイの内側のドットの色 |
| `bodyPattern` | `BodyPattern` | `'circle'` | データドットのパターン |
| `cornerEyePattern` | `CornerEyePattern` | `'gear'` | コーナーマーカーのパターン |
| `cornerEyeDotPattern` | `CornerEyeDotPattern` | `'circle'` | コーナードットのパターン |
| `hideLogo` | `boolean` | `false` | ロゴを非表示にします。`logo` を設定しない限り、ロゴは描画されません |
| `logo` | `string` | — | ロゴのURL |
| `templateId` | `string` | `'default'` | テンプレートID |
| `customTemplate` | `TemplateDefinition` | — | カスタムテンプレート |
| `level` | `ErrorLevel` | `'Q'` | 誤り訂正 |
| `autoLevel` | `boolean` | `false` | ロゴがコードの7%を超えて覆う場合、`level` をHに引き上げます（`AUTO_LEVEL_LOGO_COVERAGE`） |
| `margin` | `number` | `0` | 余白（モジュール単位） |
| `imageSettings` | `ImageSettings` | — | ロゴの設定 |
| `eyeColors` | `EyeColors` | — | `topLeft`、`topRight`、`bottomLeft` ごとの `outer` / `inner` の色。それぞれ `eyeColor` / `dotColor` より優先されます |
| `moduleScale` | `number` | `1` | データモジュールのサイズ（0.5〜1）。各パターンは、スキャンできる最小のサイズで止まります（`MODULE_SCALE_FLOOR`） |
| `frame` | `QRFrame` | — | 行動喚起フレーム。[フレームと印刷](/docs/features/frames)をご覧ください |
| `art` | `QRArt` | — | ロゴや写真をモジュールに溶け込ませます（Logo QR、Image QR）。[Art QR](/docs/features/art-qr)をご覧ください |
| `frameLabelMarkers` | `boolean` | `false` | エディター向け：各フレームラベルの `<text>` に `data-qrdx-frame-label`（`"text"`、`"secondaryText"`、または仕様ラベルのID）を付けます。ダウンロードやエクスポートには含まれません |

{facts.bodyPatterns} 種類のボディパターン、{facts.eyeShapes} 種類のアイ、{facts.eyeCentres} 種類のアイ中心、{facts.frameStyles} 種類の組み込みフレームは、[図形、アイ、フレーム](/docs/styles)でライブ表示されます。

## ダウンロード関数 [#download-functions]

### downloadQRCode [#downloadqrcode]

QRコードを複数の形式でダウンロードします。

```tsx
downloadQRCode(
  qrProps: QRProps,
  options: {
    format: 'png' | 'jpg' | 'webp' | 'svg' | 'pdf' | 'eps';
    size: { width: number; height: number };
    filename?: string;
    quality?: number; // WebP only: 0 to 1 for lossy; lossless when left out
  }
): Promise<void>
```

### getQRCodeDataUrl [#getqrcodedataurl]

データURLとして取得します。

```tsx
getQRCodeDataUrl(
  qrProps: QRProps,
  format: DownloadFormat,
  size: DownloadSize,
  options?: { quality?: number } // WebP only
): Promise<string>
```

### getQRAsWebP [#getqraswebp]

QRコードをWebPの `Blob` として返します。`quality` を設定しない限りロスレスです。ブラウザーがWebPをエンコードできない場合（Safari）は、qrdx組み込みのロスレスエンコーダーが生成します。`canvasToWebP(canvas, options)` は任意のcanvasに対して同じ処理を行い、`encodeWebPLossless(rgba, width, height)` はDOMなしでRGBAピクセルをエンコードします。

```tsx
getQRAsWebP(
  qrProps: QRProps,
  options?: { quality?: number }
): Promise<Blob>
```

### copyQRCodeToClipboard [#copyqrcodetoclipboard]

クリップボードにコピーします。

```tsx
copyQRCodeToClipboard(
  qrProps: QRProps,
  size?: DownloadSize
): Promise<void>
```

### getSVGString [#getsvgstring]

SVGマークアップを取得します。

```tsx
getSVGString(qrProps: QRProps): Promise<string>
```

## 印刷とスキャンの関数 [#print-and-scan-functions]

これらの関数は、各機能のページで例とともに説明しています。

| 関数 | 機能 | ドキュメント |
|----------|--------------|------|
| `getQRAsSVG(props)` | フレームを含むコードのSVGマークアップ | [フレーム](/docs/features/frames) |
| `getQRAsPrintPDF`, `downloadPrintPDF` | 正確な物理サイズのベクターPDF。裁ち落とし、トンボ、CMYKに対応（`jspdf` が必要） | [印刷用エクスポート](/docs/features/frames#print-ready-export) |
| `downloadPrintSVG` | 正確な物理サイズの印刷用SVG | [印刷用エクスポート](/docs/features/frames#print-ready-export) |
| `getQRAsEPS`, `downloadPrintEPS` | 印刷会社やデザインツール向けのベクターEPS | [ダウンロード](/docs/features/downloads) |
| `getScanScore(props)` | デザインがどの程度確実にスキャンできるかを推定します | [スキャンできる？](/docs/features/frames#will-it-scan) |
| `getImageScanScore(image)` | 手元にあるQRコード画像を採点します（ブラウザーのみ） | [スキャンできる？](/docs/features/frames#will-it-scan) |
| `getQRAsPNG(props, { size })` | DOMなしの通常のNodeでPNGのバイト列を取得します。`qrdx/node` からインポートします。`@resvg/resvg-js` または `sharp` のインストールが必要です | — |
| `scanQRPixels(pixels, expected)` | 生のRGBAピクセルが `expected` にデコードされることを確認します。ぼかしや縮小をした場合も確認します。Nodeで動作します | — |
| `getStylePairRisk(...)` | 一部のスキャナーが読み取れないアイとパターンの組み合わせを警告します | [パターン](/docs/features/patterns) |

## 型 [#types]

### コア型 [#core-types]

```tsx
type QRProps = {
  value: string;
  size?: number;
  level?: ErrorLevel;
  bgColor?: ColorConfig;
  fgColor?: ColorConfig;
  margin?: number;
  imageSettings?: ImageSettings;
  // ...
};

type ColorConfig =
  | string
  | { type: 'solid'; color: string }
  | LinearGradient
  | RadialGradient;

type ErrorLevel = 'L' | 'M' | 'Q' | 'H';
```

### パターン型 [#pattern-types]

```tsx
// The arrays BODY_PATTERN, CORNER_EYE_PATTERNS, CORNER_EYE_DOT_PATTERNS and
// FRAME_STYLES (and their zod schemas) are exported from 'qrdx/types'.
// FRAME_STYLES names the built-in frames; each is a frame spec in
// BUILT_IN_FRAMES (from 'qrdx').

type BodyPattern =
  | 'circle' | 'circle-large' | 'square' | 'diamond' | 'circle-mixed'
  | 'pacman' | 'rounded' | 'small-square' | 'vertical-line'
  | 'horizontal-line' | 'liquid' | 'liquid-horizontal' | 'liquid-vertical'
  | 'classy' | 'classy-rounded' | 'leaf' | 'plus' | 'hexagon' | 'star'
  | 'heart' | 'random-dots' | 'mosaic' | 'octagon';

type CornerEyePattern =
  | 'square' | 'rounded' | 'gear' | 'circle' | 'diya' | 'extra-rounded'
  | 'message' | 'pointy' | 'leaf' | 'drop' | 'octagon' | 'bevel'
  | 'squircle' | 'cushion' | 'shield' | 'petal' | 'leaf-reverse';

type CornerEyeDotPattern =
  | 'square' | 'rounded' | 'circle' | 'message' | 'message-reverse'
  | 'diya' | 'diya-reverse' | 'rounded-triangle' | 'leaf' | 'drop' | 'plus'
  | 'cross-rounded' | 'hexagon' | 'octagon' | 'flower' | 'heart'
  | 'squircle' | 'dots' | 'extra-rounded' | 'leaf-reverse' | 'drop-reverse';

// Retired (deprecated) values still render for saved designs but are not
// offered: RETIRED_CORNER_EYE_PATTERNS, RETIRED_CORNER_EYE_DOT_PATTERNS.

type EyeColors = {
  topLeft?: { outer?: ColorConfig; inner?: ColorConfig };
  topRight?: { outer?: ColorConfig; inner?: ColorConfig };
  bottomLeft?: { outer?: ColorConfig; inner?: ColorConfig };
};

type QRFrame = {
  style: FrameStyle; // "none" or a built-in frame, see FRAME_STYLES
  text?: string; // up to 24 characters, default "Scan me"
  color?: string;
  textColor?: string;
  secondaryText?: string; // banner-top-bottom, circle, menu-card
  secondaryColor?: string; // gradient-border end color
  fontScale?: number; // 0.5 to 1.5
};
```

## エラー処理 [#error-handling]

非同期関数は try-catch で囲んでください。

```tsx
try {
  await downloadQRCode(props, options);
} catch (error) {
  console.error('Failed:', error);
}
```

よくあるエラー：
- 無効な画像URL
- ネットワーク障害
- 無効なサイズパラメーター
- Canvasコンテキストが利用できない
