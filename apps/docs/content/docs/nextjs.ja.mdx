`qrdx`はApp Routerのサーバー側とクライアント側のどちらでも動作します。`QRCodeSVG`と`QRCode`はクライアント専用のフックを使わないため、Server Componentからページ本体のHTMLに直接QRコードを出力でき、そのためのJavaScriptを送る必要はありません。Client Componentが必要になるのは、ブラウザー上で値が変わる場合と、ファイルをダウンロードする場合だけです。

<NpmStatus package="qrdx" />

## インストール [#install]

```package-install
qrdx@latest
```

`react`と`react-dom`はバージョン18以降がピア依存関係です。そのため、アプリで使用しているバージョンがそのまま使われます。

## Server Componentで使う [#in-a-server-component]

```tsx title="app/page.tsx"
import { QRCodeSVG } from "qrdx";

export default function Page() {
  return (
    <QRCodeSVG
      value="https://example.com"
      size={256}
      margin={4}
      role="img"
      aria-label="QR code for example.com"
    />
  );
}
```

SVGはサーバーが送信するHTMLに含まれます。JavaScriptが読み込まれる前から表示され、静的なページではビルド時に一度だけ生成されます。スクリーンリーダーは`aria-label`を読み上げます。

`margin`はコードの周囲にあるクワイエットゾーンで、単位はモジュールです。`QRCodeSVG`のデフォルトは`0`で、独自の余白を持つカードの中にコードを置く場合に向いています。QRの規格では4モジュールが求められており、背景が複雑な場合や暗い場合は、この値にしておくと安全です。

### ルートパラメーターやデータから生成する [#from-route-params-or-data]

```tsx title="app/tickets/[id]/page.tsx"
import { QRCodeSVG } from "qrdx";

export default async function TicketPage({
  params,
}: {
  params: Promise<{ id: string }>;
}) {
  const { id } = await params;
  const url = `https://example.com/check-in/${encodeURIComponent(id)}`;
  return <QRCodeSVG value={url} size={200} margin={4} level="H" />;
}
```

Next.jsは`params`をPromiseとして渡すため、ページは`async`にします。ユーザーやデータベースから取得した値は、URLに入れる前にエンコードしてください。レベル`H`ではコードの最大30%が損傷していても読み取れるため、折れたり傷ついたりしやすいバッジに役立ちます。

## Client Componentで使う [#in-a-client-component]

入力欄の値からコードを生成する場合は、Client Componentでコードを表示します。

```tsx title="components/live-qr-code.tsx"
"use client";

import { QRCodeSVG } from "qrdx";
import { useState } from "react";

export function LiveQrCode() {
  const [value, setValue] = useState("https://example.com");
  return (
    <div>
      <input
        aria-label="Text or link to encode"
        value={value}
        onChange={(event) => setValue(event.target.value)}
      />
      {value ? <QRCodeSVG value={value} size={200} margin={4} /> : null}
    </div>
  );
}
```

`QRCodeCanvas`もクライアントコンポーネントで（`"use client"`付きで提供されています）、描画できるのは通常の四角いモジュールだけです。スタイル付きのコードには`QRCodeSVG`を使ってください。

## ロゴを入れる [#with-a-logo]

```tsx title="components/logo-qr-code.tsx"
import { QRCode } from "qrdx";

export function LogoQrCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      margin={4}
      level="H"
      logo="/logo.png"
    />
  );
}
```

- **誤り訂正レベルH。** ロゴはコードの幅の約4分の1の大きさで描画され、背後のモジュールは消去されます。そのため、スキャンできるかどうかは誤り訂正に頼ることになります。また、`QRCode`は、コードで修復できないほど大きなロゴを自動的に縮小します。
- **ロゴの指定方法。** `logo`には、アプリ内のパス、URL、データURLを指定できます。ページ上では3つとも表示されます。ダウンロードにはデータURLが最も確実です。リモート画像をファイルにコピーするには、CORSヘッダーが必要になるためです。
- **確認する。** 何台かのスマートフォンでコードを試すか、スクリーンショットを[スキャンチェッカー](/tools/scan-checker)にアップロードしてください。

`logoOptions`では、ロゴのサイズ、余白、位置、トリミングを設定できます。詳しくは[ロゴ](/docs/features/logos)をご覧ください。

## SVGとしてダウンロードする [#download-as-svg]

```tsx title="components/download-svg-button.tsx"
"use client";

import { downloadQRCode } from "qrdx";

export function DownloadSvgButton({ value }: { value: string }) {
  return (
    <button
      type="button"
      onClick={() =>
        downloadQRCode(
          { value, level: "Q", margin: 4 },
          {
            format: "svg",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.svg",
          },
        )
      }
    >
      Download SVG
    </button>
  );
}
```

`downloadQRCode`はブラウザーのDOMを必要とするため、ボタンはClient Componentにします。Server Componentのページからこのボタンを表示し、値をpropsとして渡すことは可能です。他の形式のファイルには、`format`に`png`、`jpg`、`webp`、`eps`、`pdf`のいずれかを指定します（PDFにはオプションの`jspdf`パッケージが必要です）。すべてのオプションについては[ダウンロード](/docs/features/downloads)をご覧ください。

## 画像のURLが必要な場合 [#when-you-need-an-image-url]

メール、Open Graph画像、Markdownファイルなど、Reactを実行できない場所では、コンポーネントではなく画像のURLが必要です。[無料のQRコードAPI](/qr-code-api)なら、キーなしで画像のURLを取得できます。

```html
<img src="https://api.qrdx.dev/v1/qr?data=https://example.com&format=png" width="256" height="256" alt="QR code for example.com" />
```

## すぐに使えるコンポーネント [#ready-made-components]

[shadcn/uiレジストリ](/docs/developers/shadcn)を使うと、コンポーネントをプロジェクトにインストールできます。[ダウンロードボタン付きQRコード](/docs/components/qr-code)、カード、共有ダイアログ、ジェネレーター、スキャナー、Wi-Fiや連絡先のコードが用意されています。

```bash
npx shadcn@latest add https://qrdx.dev/r/qr-code.json
```

## その他のReact用QRコードライブラリ [#other-react-qr-code-libraries]

白黒の標準的なコードだけが必要なら、`qrcode.react`の方が軽量で、歴史も長いライブラリです。`qrdx`には、図形、グラデーション、フレーム、ロゴ、PNG/SVG/PDF/EPSでの書き出し、スキャンスコアといった機能が加わっています。違いについては、[qrcode.react](/compare/qrcode-react)と[qr-code-styling](/compare/qr-code-styling)との比較ページで詳しく説明しています。
