By the end of this page you will have a styled QR code in a Solid component that follows a signal, and a button that saves it as a PNG. `qrdx/solid` has the React library's two SVG components, `QRCodeSVG` and `QRCode`, built for SolidJS. They draw the same SVG as the React components, follow your signals, and render on a server.

<NpmStatus package="qrdx" />

## Before you start

- A Solid 1.8 or newer project (in the 1.x line), with Vite or SolidStart.
- Node.js 18 or newer.

## Build it

### 1. Install qrdx

```package-install
qrdx
```

`solid-js` is an optional peer dependency of `qrdx`. Your app already has it, and you do not need `react`.

### 2. Draw a code that follows a signal

```tsx title="src/components/menu-code.tsx"
import { createSignal } from "solid-js";
import { QRCodeSVG } from "qrdx/solid";

export function MenuCode() {
  const [color, setColor] = createSignal("#0f172a");
  return (
    <>
      <QRCodeSVG
        value="https://example.com/menu"
        size={256}
        margin={4}
        fgColor={color()}
        frame={{ style: "banner-bottom", text: "Scan me" }}
        aria-label="QR code for the menu"
      />
      <button type="button" onClick={() => setColor("#1d4ed8")}>
        Blue
      </button>
    </>
  );
}
```

The page shows a dark code with a "Scan me" banner. Click **Blue** and the code is redrawn in blue.

{/* clip: solid-signal-code | clicking the Blue button and the framed code turning blue | run the example with npm create solid */}

`QRCodeSVG` takes every option the React `QRCodeSVG` takes: patterns, colors and gradients, logos (`imageSettings`), frames, shapes, templates and art. Attributes such as `class`, `style` or `aria-label` go on the `<svg>`, or on the frame's outer `<svg>` when there is a frame.

`QRCode` adds the React `QRCode`'s logo shortcut: `logo`, `logoOptions`, `hideLogo` and `scale`. It takes the code's props and `style` only; put `class` or `aria-label` on an element around it, or use `QRCodeSVG`.

```tsx title="src/components/logo-code.tsx"
import { QRCode } from "qrdx/solid";

export function LogoCode() {
  return <QRCode value="https://example.com" size={256} logo="/logo.png" level="H" />;
}
```

Props are reactive, as with any Solid component. When `color()` changes, the code is redrawn. Event handlers in the props are not put on the `<svg>`, so put them on an element around the code.

### 3. Save it as a file

The components only draw the code. Downloads, `toSVGString`, the scan score and the other functions come from `qrdx/core`. That is the engine the components already use, so it is not bundled twice.

```tsx title="src/components/downloadable-code.tsx"
import { downloadQRCode } from "qrdx/core";
import { QRCodeSVG } from "qrdx/solid";

const options = { value: "https://example.com", size: 256, margin: 4 };

export function DownloadableCode() {
  return (
    <>
      <QRCodeSVG {...options} />
      <button
        type="button"
        onClick={() =>
          downloadQRCode(options, {
            format: "png",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.png",
          })
        }
      >
        Download PNG
      </button>
    </>
  );
}
```

Clicking the button saves `qr-code.png` at 1024 px. [Vanilla JavaScript](/docs/vanilla-js) covers `qrdx/core` in full.

## How it draws

The package has no Solid JSX in it, so it needs no Solid compiler and works with any build setup.

- In the browser, a component returns the `<svg>` element itself, built with `createElementNS` (no HTML is parsed). Solid puts it on the page, swaps in a new one when a prop change alters the markup, and removes it when the component unmounts.
- A prop change that draws the same markup leaves the page alone.

## Server rendering and hydration

With `renderToString` from `solid-js/web`, a component writes the same markup as `toSVGString` from `qrdx/core`, plus Solid's `data-hk` hydration key on the root element. `hydrate` uses that key to keep the server's `<svg>` instead of drawing it again. Inside `<NoHydration>`, the key is left out.

The markup has no random ids, so the server and the browser always agree.

## If something goes wrong

- **`Failed to resolve import "react"`.** You imported from `qrdx` instead of `qrdx/solid`. The main entry has the React components; change the import.
- **A click handler on the component does nothing.** Handlers are dropped from the `<svg>`. Wrap the code in an element and put the handler there.
- **`PDF export needs the optional "jspdf" package`.** Run `npm install jspdf` in the app.
