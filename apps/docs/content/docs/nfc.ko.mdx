모든 [동적 QR 코드](/docs/dynamic-qr-codes)는 NFC 태그에도 사용할 수 있습니다. 코드의 NFC 링크를 태그, 스티커 또는 카드에 기록하면, 여기에 휴대폰을 갖다 댄 사용자가 QR 코드와 같은 곳으로 이동합니다. 탭은 코드의 분석에서 QR 스캔과 함께 표시되며 따로 집계됩니다. 모든 요금제에서 사용할 수 있습니다.

QRdx는 태그나 카드를 판매, 인쇄, 배송하지 않습니다. 아무 NFC 공급업체에서 빈 태그나 카드를 구입한 뒤 코드 페이지에서 직접 기록하세요.

## NFC 링크 [#the-nfc-link]

코드의 NFC 링크는 짧은 링크 끝에 `?nfc`를 붙인 것입니다. 예를 들어 `https://qrdx.dev/q/aB3dE5f?nfc`이고, [사용자 지정 도메인](/docs/custom-domains)에서는 `https://go.example.com/menu?nfc`입니다. 짧은 링크와 같은 리디렉션을 거치므로 스마트 라우팅, 비밀번호, 일정, 스캔 제한이 탭에도 똑같이 적용됩니다. `?nfc`는 분석에 해당 방문이 탭이라는 것만 알려 줍니다. QR 코드는 기존 링크를 그대로 유지하므로, 이미 인쇄한 코드도 전과 똑같이 작동합니다.

NFC 링크를 찾으려면 [대시보드](/dashboard?to=codes)에서 코드를 열고 개요 탭의 **Use with NFC**를 선택하세요. [REST API](/docs/developers/rest-api)에서는 모든 코드에 `nfcLink`로 반환됩니다.

## Android에서 태그 기록하기 [#write-a-tag-on-android]

Android의 Chrome에서는 코드의 NFC 페이지에서 바로 태그를 기록할 수 있습니다.

1. 휴대폰 설정에서 NFC를 켭니다.
2. Chrome에서 코드를 열고 **Use with NFC**를 선택한 다음 **Write to NFC tag**를 탭합니다.
3. 페이지에 **Written**이 표시될 때까지 태그를 휴대폰 뒷면에 평평하게 대고 있습니다.
4. 태그를 휴대폰에 갖다 대어 테스트합니다. 링크가 열려야 합니다.

웹 페이지에서 기록하려면 Web NFC가 필요하며, 이는 Android의 Chrome에서만 지원됩니다. 컴퓨터에서는 NFC 페이지에 QR 코드가 대신 표시됩니다. Android 휴대폰으로 이 코드를 스캔하고 로그인한 뒤 그곳에서 태그를 기록하세요.

### 태그 잠금 [#locking-a-tag]

태그를 기록하고 나면 브라우저가 지원하는 경우 페이지에서 태그를 잠글지 물어봅니다. 잠긴 태그는 본인을 포함해 누구도 다시 변경하거나 지울 수 없습니다. 따라서 카페 테이블에 붙인 스티커처럼 낯선 사람이 덮어쓸 수 있는 곳에 놓인 태그만 잠그세요. 태그에는 목적지가 아니라 코드의 링크가 들어 있으므로, 잠긴 태그가 연결되는 곳은 QRdx에서 얼마든지 바꿀 수 있습니다.

## iPhone에서 태그 기록하기 [#write-a-tag-on-iphone]

Safari에서는 NFC 태그를 기록할 수 없으므로 App Store의 NFC 기록 앱을 사용하세요.

1. 코드의 NFC 페이지에서 NFC 링크를 복사합니다.
2. 앱에서 URL 레코드(앱에 따라 Link 또는 URI라고도 합니다)를 추가하고 링크를 붙여넣습니다.
3. Write를 선택하고 앱에 완료 메시지가 표시될 때까지 iPhone 윗부분을 태그에 대고 있습니다.

기록하려면 iOS 13 이상이 설치된 iPhone 7 이상이 필요합니다.

## 어떤 태그를 구입해야 하나요 [#which-tags-to-buy]

NTAG213, NTAG215 또는 NTAG216 칩을 찾아보세요. 스티커, 카드, 키 홀더, 손목밴드 형태로 판매됩니다.

| 칩 | 메모리 |
| --- | --- |
| NTAG213 | 144바이트 |
| NTAG215 | 504바이트 |
| NTAG216 | 888바이트 |

qrdx.dev의 NFC 링크는 약 30바이트이므로 세 칩 모두에 담을 수 있습니다. 긴 사용자 지정 도메인을 쓰거나 링크 뒷부분이 길면 더 많은 용량이 필요합니다. NFC 페이지에서 필요한 바이트 수와 사용할 수 있는 칩을 확인할 수 있습니다.

NFC가 켜진 Android 휴대폰과 iPhone XS 이상에서는 태그를 휴대폰에 대기만 하면 앱 없이 바로 링크가 열립니다.

## NFC 명함 [#nfc-business-cards]

[vCard Plus 페이지](/docs/landing-pages)는 **Save contact** 버튼이 있는 연락처 페이지로, NFC 명함으로 쓰기에 좋습니다. vCard Plus 페이지를 여는 코드에는 개요 탭에 **Put this card on NFC**가 표시되고, 페이지 편집기에는 **Put on NFC** 버튼이 있습니다. 둘 다 카드용 안내가 포함된 같은 NFC 페이지를 엽니다.

1. 빈 NFC 명함을 구입하거나, 이미 가지고 있는 명함에 붙일 NFC 스티커를 구입합니다.
2. 카드에 코드의 QR 코드도 함께 인쇄합니다. NFC가 없거나 꺼져 있는 휴대폰에서는 이 코드를 스캔하면 됩니다.
3. 코드의 NFC 페이지에서 각 카드에 NFC 링크를 기록합니다.

각 카드에는 코드의 링크가 들어 있으므로, QRdx에서 vCard Plus 페이지를 수정하면 이미 나눠 준 모든 카드에 반영됩니다.

## 분석에서 보는 탭 [#taps-in-analytics]

코드의 분석 탭에는 선택한 기간의 **QR scans and NFC taps**가 표시되며, 위쪽 합계에는 둘 다 포함됩니다. 워크스페이스의 분석 페이지와 공유 분석 페이지에도 같은 구분이 표시됩니다.

CSV 내보내기에는 각 스캔마다 `qr` 또는 `nfc` 값이 들어 있는 `source` 열이 있습니다. REST API에서는 [스캔 분석](/docs/developers/api/get-code-scans)에 두 값의 집계를 담은 `sources`와 나열된 각 스캔의 `source`가 포함되며, `scan.created`용 [웹훅](/docs/webhooks)에도 `source`가 포함됩니다.

NFC 링크가 생기기 전의 스캔은 QR 스캔으로 집계됩니다. 탭에도 스캔과 같은 규칙이 적용되어 봇과 링크 미리보기는 집계되지 않습니다.
