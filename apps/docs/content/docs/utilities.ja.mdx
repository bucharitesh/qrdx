色、コントラスト、QRコード処理のためのヘルパー関数です。

## カラーユーティリティ [#color-utilities]

### getSolidColor [#getsolidcolor]

任意のカラー設定から単色を取得します。

```tsx
import { getSolidColor } from 'qrdx';

const color = getSolidColor({
  type: 'linear',
  stops: [
    { offset: 0, color: '#ff6b6b' },
    { offset: 1, color: '#4ecdc4' }
  ],
  x1: 0, y1: 0, x2: 1, y2: 1
});
// Returns: "#ff6b6b"
```

### hexToRgb [#hextorgb]

16進数カラーをRGBに変換します。

```tsx
import { hexToRgb } from 'qrdx';

const rgb = hexToRgb('#ff6b6b');
// Returns: { r: 255, g: 107, b: 107 }
```

## コントラストのチェック [#contrast-checking]

### getContrastRatio [#getcontrastratio]

WCAGのコントラスト比を計算します。

```tsx
import { getContrastRatio } from 'qrdx';

const ratio = getContrastRatio('#000000', '#ffffff');
// Returns: 21
```

### getContrastLevel [#getcontrastlevel]

コントラストの評価を取得します。

```tsx
import { getContrastLevel } from 'qrdx';

const level = getContrastLevel(4.5);
// Returns: { level: 'AA', warning: false, message: 'Good contrast' }
```

**コントラストのガイドライン:**
- **`AAA`（7.0以上）** — 非常に良好なコントラスト
- **`AA`（4.5～7.0）** — 良好なコントラスト
- **`AA Large`（3.0～4.5）** — コントラストが低く、`warning: true` になります。スキャンしにくい場合があります
- **`Fail`（3.0未満）** — 推奨しません。`warning: true` になります

### getLuminance [#getluminance]

相対輝度を計算します。

```tsx
import { getLuminance } from 'qrdx';

const luminance = getLuminance(255, 255, 255);
// Returns: 1.0 (white)
```

## 検証 [#validation]

### validateSize [#validatesize]

ダウンロードサイズを検証します。

```tsx
import { validateSize } from 'qrdx';

const validation = validateSize(512, 512);
if (validation.isValid) {
  console.log("Valid size");
} else {
  console.error(validation.error);
}
```

## 例: コントラストチェッカー [#example-contrast-checker]

```tsx
import { getContrastRatio, getContrastLevel } from 'qrdx';
import { useState } from 'react';

export default function ContrastChecker() {
  const [fgColor, setFgColor] = useState('#000000');
  const [bgColor, setBgColor] = useState('#ffffff');

  const ratio = getContrastRatio(fgColor, bgColor);
  const level = getContrastLevel(ratio);

  return (
    <div>
      <input
        type="color"
        value={fgColor}
        onChange={(e) => setFgColor(e.target.value)}
      />
      <input
        type="color"
        value={bgColor}
        onChange={(e) => setBgColor(e.target.value)}
      />
      <p>Ratio: {ratio.toFixed(2)}:1</p>
      <p>Level: {level.level}</p>
      <p>{level.message}</p>
    </div>
  );
}
```

## 例: サイズ計算ツール [#example-size-calculator]

```tsx
import { validateSize } from 'qrdx';
import { useState } from 'react';

export default function SizeCalculator() {
  const [width, setWidth] = useState(512);
  const [height, setHeight] = useState(512);

  const validation = validateSize(width, height);

  return (
    <div>
      <input
        type="number"
        value={width}
        onChange={(e) => setWidth(Number(e.target.value))}
      />
      <input
        type="number"
        value={height}
        onChange={(e) => setHeight(Number(e.target.value))}
      />
      <p>{validation.isValid ? 'Valid' : validation.error}</p>
    </div>
  );
}
```
