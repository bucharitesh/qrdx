By the end of this page you will have a QR code rendered by a Server Component with no client JavaScript, a code built from a route param, a live code bound to an input, a code with your logo, and a button that saves an SVG. `QRCodeSVG` and `QRCode` use no client-only hooks, so a Server Component renders the code straight into the page's HTML. You need a Client Component only when the value changes in the browser or to save a file.

<NpmStatus package="qrdx" />

## Before you start

- A Next.js project on the App Router. The examples use the App Router's async `params`, as in Next.js 15 and 16.
- React 18 or newer, which the App Router already requires.

## Build it

### 1. Install qrdx

```package-install
qrdx
```

`react` and `react-dom` are peer dependencies, so your app's own versions are used.

### 2. Render a code in a Server Component

```tsx title="app/page.tsx"
import { QRCodeSVG } from "qrdx";

export default function Page() {
  return (
    <QRCodeSVG
      value="https://example.com"
      size={256}
      margin={4}
      role="img"
      aria-label="QR code for example.com"
    />
  );
}
```

Open the page. The `<svg>` is part of the HTML the server sends, so it shows before any JavaScript loads, a static page renders it once at build time, and screen readers get the `aria-label`.

{/* shot: nextjs-server-code | the 256 px code from app/page.tsx on an otherwise empty Next.js page, with the browser's "view source" showing the inline svg | run the example in a fresh create-next-app project */}

`margin` is the quiet zone around the code, in modules. It defaults to 0, which suits a code inside a card with its own padding. The QR standard asks for 4, the safe choice on a busy or dark background.

### 3. Build the value from a route param

```tsx title="app/tickets/[id]/page.tsx"
import { QRCodeSVG } from "qrdx";

export default async function TicketPage({
  params,
}: {
  params: Promise<{ id: string }>;
}) {
  const { id } = await params;
  const url = `https://example.com/check-in/${encodeURIComponent(id)}`;
  return <QRCodeSVG value={url} size={200} margin={4} level="H" />;
}
```

Visit `/tickets/A-12` and the code opens `https://example.com/check-in/A-12`. Next.js passes `params` as a promise, so the page is `async`. Encode anything that comes from a user or a database before it goes into a URL. Level `H` lets up to 30% of the code be damaged, which helps on a badge that gets folded or scratched.

### 4. Follow an input in a Client Component

```tsx title="components/live-qr-code.tsx"
"use client";

import { QRCodeSVG } from "qrdx";
import { useState } from "react";

export function LiveQrCode() {
  const [value, setValue] = useState("https://example.com");
  return (
    <div>
      <input
        aria-label="Text or link to encode"
        value={value}
        onChange={(event) => setValue(event.target.value)}
      />
      {value ? <QRCodeSVG value={value} size={200} margin={4} /> : null}
    </div>
  );
}
```

The code redraws on every keystroke, and the first value still renders on the server. A Server Component page can import this component as it is.

{/* clip: nextjs-live-code | typing a link into the input and the code redrawing with each keystroke | render components/live-qr-code.tsx and type "https://example.com/menu" */}

`QRCodeCanvas` is a Client Component too (it ships with `"use client"`), but it draws plain square modules only. Use `QRCodeSVG` or `QRCode` for styled codes.

### 5. Add a logo

```tsx title="components/logo-qr-code.tsx"
import { QRCode } from "qrdx";

export function LogoQrCode() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
      margin={4}
      level="H"
      logo="/logo.png"
    />
  );
}
```

`/logo.png` is a file in your project's `public` folder. The logo is drawn at a quarter of the code's width and the modules behind it are cleared, so the code relies on error correction to scan: that is why `level` is `H`. `QRCode` also shrinks a logo that is too big for the code to repair.

`logo` takes a path in your app, a URL or a data URL. For downloads a data URL is safest, because a remote image needs CORS headers before the browser may copy it into the file. `logoOptions` sets the logo's size, clear space, position and crop; see [Add a logo in code](/docs/features/logos).

### 6. Download as SVG

```tsx title="components/download-svg-button.tsx"
"use client";

import { downloadQRCode } from "qrdx";

export function DownloadSvgButton({ value }: { value: string }) {
  return (
    <button
      type="button"
      onClick={() =>
        downloadQRCode(
          { value, level: "Q", margin: 4 },
          {
            format: "svg",
            size: { width: 1024, height: 1024 },
            filename: "qr-code.svg",
          },
        )
      }
    >
      Download SVG
    </button>
  );
}
```

Clicking the button saves `qr-code.svg`, a 1024 px vector file. `downloadQRCode` needs the browser's DOM, so the button is a Client Component. A Server Component page can still render it and pass the value as a prop. For other files, set `format` to `png`, `jpg`, `webp`, `eps` or `pdf` (PDF needs the optional `jspdf` package). [Export and download](/docs/features/downloads) covers every option.

## When you need an image URL

Emails, Open Graph images, Markdown files and other places that cannot run React need an image URL rather than a component. The [QR code image API](/docs/developers/image-api) returns one with no key:

```html title="email.html"
<img src="https://api.qrdx.dev/v1/qr?data=https://example.com&format=png" width="256" height="256" alt="QR code for example.com" />
```

## Ready-made components

The [shadcn/ui registry](/docs/developers/shadcn) installs components into your project: a [QR code with download buttons](/docs/components/qr-code), a card, a share dialog, a generator, a scanner, and Wi-Fi and contact codes.

```bash title="Terminal"
npx shadcn@latest add https://qrdx.dev/r/qr-code.json
```

## If something goes wrong

- **`useRef only works in Client Components` (or the same for `useState`).** You rendered `QRCodeCanvas`, or a component with hooks, from a Server Component. Add `"use client"` at the top of that file, or render `QRCodeSVG` instead.
- **The logo shows on the page but not in the downloaded file.** The image comes from another origin without CORS headers. Serve it from `public`, or pass a data URL.
- **`PDF export needs the optional "jspdf" package`.** Run `npm install jspdf` in the app. The other formats need nothing extra.
