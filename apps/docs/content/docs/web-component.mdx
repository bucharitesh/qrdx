By the end of this page you will have a styled QR code drawn by the `<qrdx-code>` element in a plain HTML page, with object options set from a script and an export to PNG. `qrdx/element` is built on `qrdx/core`, so it draws the same SVG as the React `QRCodeSVG`, with every style, frame, logo and export. It needs no framework, and it works in frameworks that render DOM elements. It is tested in React 19 and Vue 3.

<NpmStatus package="qrdx" />

## Before you start

- A page you can add a `<script type="module">` to. No bundler is needed; one works too.
- For the bundler route, Node.js 18 or newer.

## Build it

### 1. Load the element

<Tabs items={["From a CDN", "With a bundler"]}>
<Tab value="From a CDN">

```html title="index.html"
<script
  type="module"
  src="https://cdn.jsdelivr.net/npm/qrdx/dist/element-define.browser.mjs"
></script>
```

`dist/element-define.browser.mjs` registers `<qrdx-code>`. It loads `dist/element.browser.mjs`, one ES module with the engine inside. Add `@` and a version after `qrdx` in the URL to pin one. The same paths work on unpkg.

</Tab>
<Tab value="With a bundler">

```package-install
qrdx
```

```js title="main.js"
import "qrdx/element/define"; // registers <qrdx-code>
```

Importing `qrdx/element` on its own registers nothing. Call `defineQRdxCode` yourself to choose the tag name:

```js title="main.js"
import { defineQRdxCode } from "qrdx/element";

defineQRdxCode(); // <qrdx-code>
defineQRdxCode("brand-qr"); // <brand-qr> as well
```

Calling it again is safe, and on a server it does nothing. It throws if another element already has the name.

</Tab>
</Tabs>

### 2. Put a code in the page

```html title="index.html"
<qrdx-code
  value="https://example.com/menu"
  size="256"
  margin="4"
  body-pattern="rounded"
  label="QR code for the menu"
></qrdx-code>
```

The page shows a 256 px code with rounded modules. Edit an attribute in the browser's inspector and the code redraws.

### 3. Set object options from a script

Gradients, frames, logos and the other object options are properties. Set them from a script:

```js title="main.js"
const qr = document.querySelector("qrdx-code");

qr.fgColor = {
  type: "linear",
  angle: 45,
  stops: [
    { color: "#1d4ed8", offset: 0 },
    { color: "#0f172a", offset: 100 },
  ],
};
qr.frame = { style: "banner-bottom", text: "Scan for the menu" };
qr.imageSettings = { src: "/logo.png", width: 40, height: 40, excavate: true };
qr.props = { eyeColor: "#be123c" };
```

The code is redrawn once, with the gradient, the banner, the logo and red eyes. Without a script, put object options in the `props` attribute as JSON:

```html title="index.html"
<qrdx-code
  value="https://example.com"
  props='{"frame": {"style": "banner-bottom", "text": "Scan me"}}'
></qrdx-code>
```

### 4. Export it

```js title="main.js"
qr.toSVGString(); // '<svg xmlns="http://www.w3.org/2000/svg" …'
await qr.toDataURL("png", { size: 1024 }); // "data:image/png;base64,…"
await qr.download({ format: "png", size: 1024, filename: "menu.png" });
```

`download` saves `menu.png` at 1024 px. The exports draw the code from `qr.options`, as `toSVGString` and `downloadQRCode` from `qrdx/core` do, without the element's `part`, `role` and `aria-label`. `toDataURL` and `download` default to PNG at the code's `size`. The formats are `png`, `jpg`, `webp`, `svg`, `pdf` and `eps`. Without a value they throw (`toSVGString`) or reject.

PDF needs the optional `jspdf` package. From a CDN, map it with an import map placed before the module script:

```html title="index.html"
<script type="importmap">
  { "imports": { "jspdf": "https://cdn.jsdelivr.net/npm/jspdf@4/+esm" } }
</script>
```

## Attributes

| Attribute | What it sets |
| --- | --- |
| `value` | The text or URL to encode. Nothing is drawn without it |
| `size` | Width and height in pixels (a frame adds to it) |
| `level` | Error correction: `L`, `M`, `Q` or `H` |
| `fg-color`, `bg-color`, `eye-color`, `dot-color` | Solid colors |
| `body-pattern`, `corner-eye-pattern`, `corner-eye-dot-pattern` | Shapes of the modules, eyes and eye dots |
| `margin` | Quiet zone, in modules |
| `template-id` | A built-in template |
| `module-scale` | Size of each module, 0.5 to 1 |
| `auto-level` | Raises error correction to `H` when a logo needs it |
| `shape` | `square`, `circle` or `heart` |
| `label` | What screen readers announce (default "QR code") |
| `props` | Any other option, as JSON |

Numbers and levels that cannot be read are ignored. [Shapes, eyes and frames](/docs/styles) draws every pattern.

## Properties

Each attribute is also a property, with the option's name: `qr.fgColor`, `qr.bodyPattern`, `qr.templateId`. Options that are objects are properties only: gradients and image fills, `frame`, `imageSettings`, `eyeColors`, `art`, `customTemplate` and `customProps`. `props` takes every option at once.

- An attribute or a named property wins over the same option in `props`. Between an attribute and its property, the one set last wins. Set a property to `undefined` to drop it.
- Properties do not write attributes back.
- Changes are batched. However many you make in a row, the code is redrawn once, in a microtask, and only if its markup changed.
- `qr.options` is what the code is drawn with, and `qr.svg` is the drawn `<svg>`.
- Properties set before the element is defined are picked up when it is.

An official frame comes from the file next to the element:

```js title="main.js"
import { getOfficialFrame } from "https://cdn.jsdelivr.net/npm/qrdx/dist/frames-official.mjs";

qr.frame = { style: "custom", spec: getOfficialFrame("wifi-card").spec };
```

## Styling and accessibility

The code is drawn in an open shadow root. The page's CSS cannot reach its paths, so a rule like `svg path { fill: red }` or `svg { width: 100% }` cannot break the code. Style the `<svg>` from outside with `::part(svg)`:

```css title="styles.css"
qrdx-code::part(svg) {
  border-radius: 12px;
}
```

The element is `inline-block`. Its `<svg>` keeps its `size` but shrinks to fit a narrower container.

The `<svg>` has `role="img"` and an `aria-label` from the `label` attribute, or "QR code" without one. The label never falls back to the value, which can hold a Wi-Fi password or contact details.

## Server rendering

`toQRdxCodeHTML(options)` returns the element's markup with the code already drawn in a declarative shadow root. Browsers show the code before any script runs, and the element takes over when it is defined. It runs in Node and needs no DOM.

```js title="server.js"
import { toQRdxCodeHTML } from "qrdx/element";

const html = toQRdxCodeHTML(
  {
    value: "https://example.com",
    size: 256,
    frame: { style: "banner-bottom", text: "Scan me" },
  },
  { label: "Link to example.com" }
);
// <qrdx-code value="https://example.com" size="256" label="Link to example.com"
//   props="{…}"><template shadowrootmode="open">…</template></qrdx-code>
```

Simple options become attributes and the rest go in `props` as JSON, so the element reads back the same options. `customTemplate` cannot be written as markup: set it as a property in the browser. Pass `tagName` if you registered another name.

## React 19

React 19 sets a prop as a property when the element has one, so objects work as props. Register the element once, before rendering:

```tsx title="components/menu-code.tsx"
import "qrdx/element/define";

export function MenuCode({ url }: { url: string }) {
  return (
    <qrdx-code
      value={url}
      size={256}
      body-pattern="rounded"
      frame={{ style: "banner-bottom", text: "Scan me" }}
      label="Menu"
    />
  );
}
```

For TypeScript, add the element to JSX in a `.d.ts` file:

```ts title="qrdx-code.d.ts"
import type { QRdxCodeElement, QRdxCodeJSXProps } from "qrdx/element";

declare module "react" {
  namespace JSX {
    interface IntrinsicElements {
      "qrdx-code": React.DetailedHTMLProps<
        React.HTMLAttributes<QRdxCodeElement>,
        QRdxCodeElement
      > &
        QRdxCodeJSXProps;
    }
  }
}
```

A `ref` gives you the element, for `toDataURL` and `download`.

## Vue

Tell Vue's compiler that `qrdx-code` is a custom element:

```js title="vite.config.js"
import vue from "@vitejs/plugin-vue";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [
    vue({
      template: {
        compilerOptions: { isCustomElement: (tag) => tag === "qrdx-code" },
      },
    }),
  ],
});
```

Then import `qrdx/element/define` once, in `main.js`, and bind options in templates. Vue sets a binding as a property when the element has one:

```vue title="src/App.vue"
<qrdx-code
  :value="url"
  :size="256"
  body-pattern="rounded"
  :frame="{ style: 'banner-bottom', text: 'Scan me' }"
  label="Menu"
/>
```

## If something goes wrong

- **Nothing is drawn.** The element has no `value`, or the defining script has not run. Check the attribute, and that `element-define` is loaded as a module.
- **A `qrdx-error` event fires.** The code cannot be drawn, for example because the value is too long for a QR code, or the `props` attribute is not a JSON object. The error is in `event.detail.error`. The element removes the old code and logs the error unless a listener calls `event.preventDefault()`:

  ```js title="main.js"
  qr.addEventListener("qrdx-error", (event) => {
    event.preventDefault();
    showMessage("That text is too long for a QR code.");
  });
  ```

- **`qrdx: <qrdx-code> is already defined by another element`.** Another script registered the same tag name. Pass `defineQRdxCode` another name.
- **TypeScript: `Property 'qrdx-code' does not exist on type 'JSX.IntrinsicElements'`.** Add the declaration from the React 19 section.
