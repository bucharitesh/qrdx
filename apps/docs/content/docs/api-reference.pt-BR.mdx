## Componentes [#components]

### QRCode [#qrcode]

Componente principal para renderizar QR codes.

```tsx
import { QRCode } from 'qrdx';

<QRCode
  value="https://example.com"
  size={256}
  fgColor="#000000"
  bgColor="#ffffff"
/>
```

#### Props [#props]

| Prop | Tipo | Padrão | Descrição |
|------|------|--------|-----------|
| `value` | `string` | **obrigatório** | URL ou texto a codificar |
| `size` | `number` | `128` | Tamanho em pixels |
| `scale` | `number` | `1` | Multiplicador de escala |
| `fgColor` | `ColorConfig` | `#000000` | Cor do QR code |
| `bgColor` | `ColorConfig` | `#ffffff` | Cor de fundo |
| `eyeColor` | `ColorConfig` | `fgColor` | Cor dos marcadores de canto |
| `dotColor` | `ColorConfig` | `fgColor` | Cor do ponto dentro de cada olho de canto |
| `bodyPattern` | `BodyPattern` | `'circle'` | Padrão dos pontos de dados |
| `cornerEyePattern` | `CornerEyePattern` | `'gear'` | Padrão dos marcadores de canto |
| `cornerEyeDotPattern` | `CornerEyeDotPattern` | `'circle'` | Padrão do ponto do canto |
| `hideLogo` | `boolean` | `false` | Oculta o logo. Nenhum logo é desenhado a menos que `logo` seja definido |
| `logo` | `string` | — | URL do logo |
| `templateId` | `string` | `'default'` | ID do template |
| `customTemplate` | `TemplateDefinition` | — | Template personalizado |
| `level` | `ErrorLevel` | `'Q'` | Correção de erros |
| `autoLevel` | `boolean` | `false` | Eleva `level` para H quando o logo cobre mais de 7% do código (`AUTO_LEVEL_LOGO_COVERAGE`) |
| `margin` | `number` | `0` | Margem em módulos |
| `imageSettings` | `ImageSettings` | — | Configurações do logo |
| `eyeColors` | `EyeColors` | — | Cores `outer` / `inner` por olho para `topLeft`, `topRight` e `bottomLeft`; cada uma substitui `eyeColor` / `dotColor` |
| `moduleScale` | `number` | `1` | Tamanho do módulo de dados, de 0.5 a 1. Cada padrão para no menor tamanho que ainda permite a leitura (`MODULE_SCALE_FLOOR`) |
| `frame` | `QRFrame` | — | Moldura de chamada para ação; veja [Molduras e impressão](/docs/features/frames) |
| `art` | `QRArt` | — | Mistura um logo ou foto nos módulos (Logo QR, Image QR); veja [Art QR](/docs/features/art-qr) |
| `frameLabelMarkers` | `boolean` | `false` | Para editores: marca cada `<text>` de rótulo da moldura com `data-qrdx-frame-label` (`"text"`, `"secondaryText"` ou o id de um rótulo da especificação). Downloads e exportações nunca o incluem |

Todos os {facts.bodyPatterns} padrões de corpo, {facts.eyeShapes} olhos, {facts.eyeCentres} centros de olho e {facts.frameStyles} molduras integradas são mostrados ao vivo em [Formas, olhos e molduras](/docs/styles).

## Funções de download [#download-functions]

### downloadQRCode [#downloadqrcode]

Baixe QR codes em vários formatos.

```tsx
downloadQRCode(
  qrProps: QRProps,
  options: {
    format: 'png' | 'jpg' | 'webp' | 'svg' | 'pdf' | 'eps';
    size: { width: number; height: number };
    filename?: string;
    quality?: number; // WebP only: 0 to 1 for lossy; lossless when left out
  }
): Promise<void>
```

### getQRCodeDataUrl [#getqrcodedataurl]

Obtém como data URL.

```tsx
getQRCodeDataUrl(
  qrProps: QRProps,
  format: DownloadFormat,
  size: DownloadSize,
  options?: { quality?: number } // WebP only
): Promise<string>
```

### getQRAsWebP [#getqraswebp]

O código como um `Blob` WebP, sem perdas, a menos que `quality` seja definido. Onde o navegador não consegue codificar WebP (Safari), o codificador sem perdas integrado do qrdx faz isso. `canvasToWebP(canvas, options)` faz o mesmo para qualquer canvas, e `encodeWebPLossless(rgba, width, height)` codifica pixels RGBA sem DOM.

```tsx
getQRAsWebP(
  qrProps: QRProps,
  options?: { quality?: number }
): Promise<Blob>
```

### copyQRCodeToClipboard [#copyqrcodetoclipboard]

Copia para a área de transferência.

```tsx
copyQRCodeToClipboard(
  qrProps: QRProps,
  size?: DownloadSize
): Promise<void>
```

### getSVGString [#getsvgstring]

Obtém a marcação SVG.

```tsx
getSVGString(qrProps: QRProps): Promise<string>
```

| `scanQRPixels(pixels, expected)` | Verifica se pixels RGBA brutos decodificam para `expected`, inclusive quando desfocados e reduzidos; roda em Node | — |

## Tipos [#types]

### Tipos principais [#core-types]

```tsx
type QRProps = {
  value: string;
  size?: number;
  level?: ErrorLevel;
  bgColor?: ColorConfig;
  fgColor?: ColorConfig;
  margin?: number;
  imageSettings?: ImageSettings;
  // ...
};

type ColorConfig =
  | string
  | { type: 'solid'; color: string }
  | LinearGradient
  | RadialGradient;

type ErrorLevel = 'L' | 'M' | 'Q' | 'H';
```

### Tipos de padrão [#pattern-types]

```tsx
// The arrays BODY_PATTERN, CORNER_EYE_PATTERNS, CORNER_EYE_DOT_PATTERNS and
// FRAME_STYLES (and their zod schemas) are exported from 'qrdx/types'.
// FRAME_STYLES names the built-in frames; each is a frame spec in
// BUILT_IN_FRAMES (from 'qrdx').

type BodyPattern =
  | 'circle' | 'circle-large' | 'square' | 'diamond' | 'circle-mixed'
  | 'pacman' | 'rounded' | 'small-square' | 'vertical-line'
  | 'horizontal-line' | 'liquid' | 'liquid-horizontal' | 'liquid-vertical'
  | 'classy' | 'classy-rounded' | 'leaf' | 'plus' | 'hexagon' | 'star'
  | 'heart' | 'random-dots' | 'mosaic' | 'octagon';

type CornerEyePattern =
  | 'square' | 'rounded' | 'gear' | 'circle' | 'diya' | 'extra-rounded'
  | 'message' | 'pointy' | 'leaf' | 'drop' | 'octagon' | 'bevel'
  | 'squircle' | 'cushion' | 'shield' | 'petal' | 'leaf-reverse';

type CornerEyeDotPattern =
  | 'square' | 'rounded' | 'circle' | 'message' | 'message-reverse'
  | 'diya' | 'diya-reverse' | 'rounded-triangle' | 'leaf' | 'drop' | 'plus'
  | 'cross-rounded' | 'hexagon' | 'octagon' | 'flower' | 'heart'
  | 'squircle' | 'dots' | 'extra-rounded' | 'leaf-reverse' | 'drop-reverse';

// Retired (deprecated) values still render for saved designs but are not
// offered: RETIRED_CORNER_EYE_PATTERNS, RETIRED_CORNER_EYE_DOT_PATTERNS.

type EyeColors = {
  topLeft?: { outer?: ColorConfig; inner?: ColorConfig };
  topRight?: { outer?: ColorConfig; inner?: ColorConfig };
  bottomLeft?: { outer?: ColorConfig; inner?: ColorConfig };
};

type QRFrame = {
  style: FrameStyle; // "none" or a built-in frame, see FRAME_STYLES
  text?: string; // up to 24 characters, default "Scan me"
  color?: string;
  textColor?: string;
  secondaryText?: string; // banner-top-bottom, circle, menu-card
  secondaryColor?: string; // gradient-border end color
  fontScale?: number; // 0.5 to 1.5
};
```

## Tratamento de erros [#error-handling]

Envolva as funções assíncronas em try-catch:

```tsx
try {
  await downloadQRCode(props, options);
} catch (error) {
  console.error('Failed:', error);
}
```

Erros comuns:
- URLs de imagem inválidas
- Falhas de rede
- Parâmetros de tamanho inválidos
- Contexto do canvas indisponível
