安装 `qrdx`,几分钟内即可创建你的第一个二维码。

<NpmStatus package="qrdx" />

## 安装软件包 [#install-the-package]

```package-install
qrdx@latest
```

`react` 和 `react-dom`(18 或更高版本)是对等依赖,因此 `qrdx` 会使用你的应用已有的版本。PDF 导出为可选功能:只有需要时才安装 `jspdf`。

## 快速开始 [#quick-start]

创建你的第一个二维码:

```tsx
import { QRCode } from 'qrdx';

export default function App() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
    />
  );
}
```

就这么简单。你现在已经有了一个可用的二维码。

想先设计一下?[在 Playground 中试用](/playground?open=code&lang=react):在那里设计好样式,然后将其复制为 React 组件。
