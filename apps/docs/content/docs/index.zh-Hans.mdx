QRdx 是一个开源(AGPL-3.0)的二维码平台。无需账号即可免费设计静态二维码;登录后还可使用动态二维码(印刷后仍可修改)、移动端页面和扫描分析。

在任何套餐下,每个动态二维码都会持续跳转,即使降级或取消订阅也一样。这就是 [Never-Hostage 保障](/guarantee)。
