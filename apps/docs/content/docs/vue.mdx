By the end of this page you will have a styled QR code in a Vue 3 component, rendered on the server and hydrated without a mismatch, and a button that saves it as a PNG. `qrdx/vue` has Vue versions of the React components, `QRCode` and `QRCodeSVG`, plus a `useQRCode` composable. They take the same props as the React components and draw the same SVG. The entry is built on `qrdx/core` and does not import `react`.

<NpmStatus package="qrdx" />

## Before you start

- A Vue 3.3 or newer project, with Vite or Nuxt. TypeScript checks the components' props from Vue 3.4.20 on.
- Node.js 18 or newer.

## Build it

### 1. Install qrdx

```package-install
qrdx
```

`vue` is an optional peer dependency, so your app's own Vue is used.

### 2. Draw a code

```vue title="src/App.vue"
<script setup lang="ts">
import { QRCode } from "qrdx/vue";
import { ref } from "vue";

const url = ref("https://example.com/menu");
</script>

<template>
  <QRCode
    :value="url"
    :size="256"
    :margin="4"
    body-pattern="rounded"
    :frame="{ style: 'banner-bottom', text: 'Scan for the menu' }"
    aria-label="QR code for the menu"
  />
</template>
```

The page shows a 256 px code with rounded modules and a banner under it. Change `url` and the code redraws, with Vue updating the `<svg>` in place.

{/* shot: vue-first-code | the framed code from src/App.vue in a Vite Vue project | run the example with npm create vue */}

`QRCode` takes the props of React's `QRCode`: every `QRProps` option, plus `logo`, `logoOptions`, `hideLogo` and `scale` for a logo. In a template, write them in kebab-case (`body-pattern`) or camelCase. A flag such as `auto-level` or `hide-logo` needs no value. `class`, `style`, `aria-label` and other attributes go on the `<svg>`, or on the frame's outer `<svg>` when there is a frame, and so do listeners such as `@click`.

### 3. Save it as a file with useQRCode

```vue title="src/components/DownloadCode.vue"
<script setup lang="ts">
import { useQRCode } from "qrdx/vue";
import { ref } from "vue";

const url = ref("https://example.com/menu");
const { svg, download } = useQRCode(() => ({
  value: url.value,
  size: 256,
  margin: 4,
  bodyPattern: "rounded",
}));
</script>

<template>
  <div v-html="svg" />
  <button type="button" @click="download({ format: 'png', size: 1024, filename: 'menu.png' })">
    Download PNG
  </button>
</template>
```

The code shows from its markup, and the button saves `menu.png` at 1024 px. `useQRCode(props)` takes `QRCode`'s props as an object, a ref, a reactive object or a getter, and returns:

- `svg`: the SVG markup as a computed ref. It follows the props and works during server rendering.
- `toDataURL(format, { size, quality })`: the code as a data URL.
- `download({ format, filename, size, quality })`: saves the code as a file.
- `options`: the options the code is drawn with, as a computed ref.

`toDataURL` and `download` default to PNG at the code's own `size`. The formats are `png`, `jpg`, `webp`, `svg`, `pdf` and `eps`. PNG, JPG and WebP need a browser, and PDF needs the optional `jspdf` package.

## QRCodeSVG and raw image settings

`QRCodeSVG` takes `QRProps`, like React's `QRCodeSVG`. A logo goes in `imageSettings`, in pixels:

```vue title="src/components/LogoCode.vue"
<script setup lang="ts">
import { QRCodeSVG } from "qrdx/vue";
</script>

<template>
  <QRCodeSVG
    value="https://example.com"
    :size="256"
    level="H"
    :image-settings="{ src: '/logo.png', width: 48, height: 48, excavate: true }"
  />
</template>
```

Prefer `QRCode` with `logo` and `logoOptions` unless you lay the logo out yourself.

## Server rendering and Nuxt

Both components render with Vue's server renderer (`vue/server-renderer`), so the code is part of the server's HTML. The markup has no random ids, so the browser hydrates it without a mismatch.

In Nuxt, use them in any page or component. They render on the server and hydrate in the browser. Inside `<ClientOnly>` they render in the browser only.

## More from qrdx/core

`qrdx/vue` re-exports everything in `qrdx/core`: `toSVGString`, `downloadQRCode`, `getQRCodeDataUrl`, `getScanScore`, the official frame library (`getOfficialFrame`) and the rest. [Vanilla JavaScript](/docs/vanilla-js) covers them. For PNG on a server, use `getQRAsPNG` from `qrdx/node`.

A custom template's `wrapper` is written with the `h` that `qrdx/vue` exports. That is the core's `h`, not Vue's, so import one of them under another name when a file needs both:

```ts title="src/labelled-template.ts"
import { h } from "qrdx/vue";

export const Labelled = {
  id: "Labelled",
  name: "Labelled",
  wrapper: (children, props) =>
    h(
      "svg",
      { viewBox: "0 0 300 340", xmlns: "http://www.w3.org/2000/svg" },
      h("g", { transform: "translate(20, 20) scale(0.87)" }, children),
      h("text", { x: "150", y: "325", textAnchor: "middle" }, props?.label)
    ),
};
```

Pass it as `customTemplate`, with its props in `customProps`: `<QRCode value="https://example.com" :custom-template="Labelled" :custom-props="{ label: 'Scan me' }" />`.

## If something goes wrong

- **`Failed to resolve component: QRCode`.** The component is not imported in that file. Add `import { QRCode } from "qrdx/vue"` to its `<script setup>`.
- **A prop has no effect.** You wrote it as an attribute string where it needs a value: `size="256"` passes a string, `:size="256"` a number. Object props such as `frame` and `image-settings` always need the colon.
- **`PDF export needs the optional "jspdf" package`.** Run `npm install jspdf` in the app.
