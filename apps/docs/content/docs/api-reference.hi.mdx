## कंपोनेंट [#components]

### QRCode [#qrcode]

QR कोड रेंडर करने वाला मुख्य कंपोनेंट।

```tsx
import { QRCode } from 'qrdx';

<QRCode
  value="https://example.com"
  size={256}
  fgColor="#000000"
  bgColor="#ffffff"
/>
```

#### Props [#props]

| Prop | टाइप | डिफ़ॉल्ट | विवरण |
|------|------|---------|-------------|
| `value` | `string` | **ज़रूरी** | एन्कोड करने के लिए URL या टेक्स्ट |
| `size` | `number` | `128` | पिक्सल में साइज़ |
| `scale` | `number` | `1` | स्केल मल्टीप्लायर |
| `fgColor` | `ColorConfig` | `#000000` | QR कोड का रंग |
| `bgColor` | `ColorConfig` | `#ffffff` | बैकग्राउंड का रंग |
| `eyeColor` | `ColorConfig` | `fgColor` | कॉर्नर मार्कर का रंग |
| `dotColor` | `ColorConfig` | `fgColor` | हर कॉर्नर आई के अंदर वाले डॉट का रंग |
| `bodyPattern` | `BodyPattern` | `'circle'` | डेटा डॉट का पैटर्न |
| `cornerEyePattern` | `CornerEyePattern` | `'gear'` | कॉर्नर मार्कर का पैटर्न |
| `cornerEyeDotPattern` | `CornerEyeDotPattern` | `'circle'` | कॉर्नर डॉट का पैटर्न |
| `hideLogo` | `boolean` | `false` | लोगो छिपाएँ। `logo` सेट न हो तो कोई लोगो नहीं बनता |
| `logo` | `string` | — | लोगो का URL |
| `templateId` | `string` | `'default'` | टेम्पलेट ID |
| `customTemplate` | `TemplateDefinition` | — | कस्टम टेम्पलेट |
| `level` | `ErrorLevel` | `'Q'` | एरर करेक्शन |
| `autoLevel` | `boolean` | `false` | लोगो कोड के 7% से ज़्यादा हिस्से को ढके तो `level` को H पर ले जाएँ (`AUTO_LEVEL_LOGO_COVERAGE`) |
| `margin` | `number` | `0` | मॉड्यूल में मार्जिन |
| `imageSettings` | `ImageSettings` | — | लोगो सेटिंग |
| `eyeColors` | `EyeColors` | — | `topLeft`, `topRight` और `bottomLeft` के लिए अलग-अलग `outer` / `inner` रंग; हर एक `eyeColor` / `dotColor` को ओवरराइड करता है |
| `moduleScale` | `number` | `1` | डेटा मॉड्यूल का साइज़, 0.5 से 1। हर पैटर्न उस सबसे छोटे साइज़ पर रुकता है जिस पर कोड अब भी स्कैन होता है (`MODULE_SCALE_FLOOR`) |
| `frame` | `QRFrame` | — | कॉल-टू-एक्शन फ़्रेम; देखें [फ़्रेम और प्रिंट](/docs/features/frames) |
| `art` | `QRArt` | — | लोगो या फ़ोटो को मॉड्यूल में मिलाएँ (Logo QR, Image QR); देखें [Art QR](/docs/features/art-qr) |
| `frameLabelMarkers` | `boolean` | `false` | एडिटर के लिए: हर फ़्रेम लेबल `<text>` पर `data-qrdx-frame-label` (`"text"`, `"secondaryText"` या स्पेक लेबल की id) लगाता है। डाउनलोड और एक्सपोर्ट में यह कभी शामिल नहीं होता |

सभी {facts.bodyPatterns} बॉडी पैटर्न, {facts.eyeShapes} आई, {facts.eyeCentres} आई सेंटर और {facts.frameStyles} फ़्रेम स्टाइल [शेप, आई और फ़्रेम](/docs/styles) में लाइव दिखाए गए हैं।

## डाउनलोड फ़ंक्शन [#download-functions]

### downloadQRCode [#downloadqrcode]

QR कोड को कई फ़ॉर्मैट में डाउनलोड करें।

```tsx
downloadQRCode(
  qrProps: QRProps,
  options: {
    format: 'png' | 'jpg' | 'webp' | 'svg' | 'pdf' | 'eps';
    size: { width: number; height: number };
    filename?: string;
    quality?: number; // WebP only: 0 to 1 for lossy; lossless when left out
  }
): Promise<void>
```

### getQRCodeDataUrl [#getqrcodedataurl]

डेटा URL के रूप में पाएँ।

```tsx
getQRCodeDataUrl(
  qrProps: QRProps,
  format: DownloadFormat,
  size: DownloadSize,
  options?: { quality?: number } // WebP only
): Promise<string>
```

### getQRAsWebP [#getqraswebp]

कोड को WebP `Blob` के रूप में देता है; `quality` सेट न हो तो लॉसलेस। जहाँ ब्राउज़र WebP एन्कोड नहीं कर सकता (Safari), वहाँ qrdx का बिल्ट-इन लॉसलेस एन्कोडर इसे बनाता है। `canvasToWebP(canvas, options)` किसी भी canvas के लिए यही करता है, और `encodeWebPLossless(rgba, width, height)` बिना DOM के RGBA पिक्सल एन्कोड करता है।

```tsx
getQRAsWebP(
  qrProps: QRProps,
  options?: { quality?: number }
): Promise<Blob>
```

### copyQRCodeToClipboard [#copyqrcodetoclipboard]

क्लिपबोर्ड पर कॉपी करें।

```tsx
copyQRCodeToClipboard(
  qrProps: QRProps,
```

### getSVGString [#getsvgstring]

SVG मार्कअप पाएँ।

## प्रिंट और स्कैन फ़ंक्शन [#print-and-scan-functions]

इनके उदाहरण संबंधित फ़ीचर पेजों पर दिए गए हैं।

| फ़ंक्शन | क्या करता है | डॉक्स |
|----------|--------------|------|
| `getQRAsSVG(props)` | कोड का SVG मार्कअप, उसके फ़्रेम समेत | [फ़्रेम](/docs/features/frames) |
| `getQRAsPrintPDF`, `downloadPrintPDF` | सटीक फ़िज़िकल साइज़ पर वेक्टर PDF, bleed, क्रॉप मार्क और CMYK के साथ (`jspdf` चाहिए) | [प्रिंट-रेडी एक्सपोर्ट](/docs/features/frames#print-ready-export) |
| `downloadPrintSVG` | सटीक फ़िज़िकल साइज़ पर प्रिंट-रेडी SVG | [प्रिंट-रेडी एक्सपोर्ट](/docs/features/frames#print-ready-export) |
| `getQRAsEPS`, `downloadPrintEPS` | प्रिंट शॉप और डिज़ाइन टूल के लिए वेक्टर EPS | [डाउनलोड](/docs/features/downloads) |
| `getScanScore(props)` | अनुमान लगाता है कि कोई डिज़ाइन कितने भरोसे से स्कैन होता है | [क्या यह स्कैन होगा?](/docs/features/frames#will-it-scan) |
| `getImageScanScore(image)` | आपके पास पहले से मौजूद QR कोड इमेज को स्कोर करता है (सिर्फ़ ब्राउज़र में) | [क्या यह स्कैन होगा?](/docs/features/frames#will-it-scan) |
| `getQRAsPNG(props, { size })` | सादे Node में PNG बाइट, बिना DOM के। इसे `qrdx/node` से इंपोर्ट करें; इसके लिए `@resvg/resvg-js` या `sharp` इंस्टॉल होना चाहिए | — |
| `scanQRPixels(pixels, expected)` | जाँचता है कि कच्चे RGBA पिक्सल डिकोड होकर `expected` देते हैं, धुंधला और छोटा करने पर भी; Node में चलता है | — |
| `getStylePairRisk(...)` | उन आई और पैटर्न जोड़ियों के बारे में चेतावनी देता है जिन्हें कुछ स्कैनर नहीं पढ़ पाते | [पैटर्न](/docs/features/patterns) |

## टाइप [#types]

### कोर टाइप [#core-types]

```tsx
type QRProps = {
  value: string;
  size?: number;
  level?: ErrorLevel;
  bgColor?: ColorConfig;
  fgColor?: ColorConfig;
  margin?: number;
  imageSettings?: ImageSettings;
  // ...
};

type ColorConfig =
  | string
  | { type: 'solid'; color: string }
  | LinearGradient
  | RadialGradient;

type ErrorLevel = 'L' | 'M' | 'Q' | 'H';
```

### पैटर्न टाइप [#pattern-types]

```tsx
// The arrays BODY_PATTERN, CORNER_EYE_PATTERNS, CORNER_EYE_DOT_PATTERNS and
// FRAME_STYLES (and their zod schemas) are exported from 'qrdx/types'.

type BodyPattern =
  | 'circle' | 'circle-large' | 'square' | 'diamond' | 'circle-mixed'
  | 'pacman' | 'rounded' | 'small-square' | 'vertical-line'
  | 'horizontal-line' | 'liquid' | 'liquid-horizontal' | 'liquid-vertical'
  | 'classy' | 'classy-rounded' | 'leaf' | 'plus' | 'hexagon' | 'star'
  | 'heart' | 'random-dots' | 'mosaic' | 'octagon';

type CornerEyePattern =
  | 'square' | 'rounded' | 'gear' | 'circle' | 'diya' | 'extra-rounded'
  | 'message' | 'pointy' | 'leaf' | 'drop' | 'octagon' | 'bevel'
  | 'squircle' | 'cushion' | 'shield' | 'petal' | 'leaf-reverse';

type CornerEyeDotPattern =
  | 'square' | 'rounded' | 'circle' | 'message' | 'message-reverse'
  | 'diya' | 'diya-reverse' | 'rounded-triangle' | 'leaf' | 'drop' | 'plus'
  | 'cross-rounded' | 'hexagon' | 'octagon' | 'flower' | 'heart'
  | 'squircle' | 'dots' | 'extra-rounded' | 'leaf-reverse' | 'drop-reverse';

// Retired (deprecated) values still render for saved designs but are not
// offered: RETIRED_CORNER_EYE_PATTERNS, RETIRED_CORNER_EYE_DOT_PATTERNS.

type EyeColors = {
  topLeft?: { outer?: ColorConfig; inner?: ColorConfig };
  topRight?: { outer?: ColorConfig; inner?: ColorConfig };
  bottomLeft?: { outer?: ColorConfig; inner?: ColorConfig };
};

type QRFrame = {
  style: FrameStyle; // "none" or a frame, see FRAME_STYLES
  text?: string; // up to 24 characters, default "Scan me"
  color?: string;
  textColor?: string;
  secondaryText?: string; // banner-top-bottom, circle, menu-card
  secondaryColor?: string; // gradient-border end color
  fontScale?: number; // 0.5 to 1.5
};
```

## एरर हैंडलिंग [#error-handling]

async फ़ंक्शन को try-catch में रखें:

```tsx
try {
  await downloadQRCode(props, options);
} catch (error) {
  console.error('Failed:', error);
}
```

आम एरर:
- गलत इमेज URL
- नेटवर्क फ़ेल होना
- गलत साइज़ पैरामीटर
- Canvas कॉन्टेक्स्ट उपलब्ध न होना
