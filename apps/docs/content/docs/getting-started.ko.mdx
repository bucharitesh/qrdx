`qrdx`를 설치하고 몇 분 만에 첫 QR 코드를 만들어 보세요.

<NpmStatus package="qrdx" />

## 패키지 설치 [#install-the-package]

```package-install
qrdx@latest
```

`react`와 `react-dom`(18 이상)은 피어 의존성이므로 `qrdx`는 앱에 이미 설치된 버전을 사용합니다. PDF 내보내기는 선택 사항입니다. 필요한 경우에만 `jspdf`를 설치하세요.

## 빠른 시작 [#quick-start]

첫 QR 코드를 만들어 보세요.

```tsx
import { QRCode } from 'qrdx';

export default function App() {
  return (
    <QRCode
      value="https://example.com"
      size={256}
    />
  );
}
```

이게 전부입니다. 이제 작동하는 QR 코드가 생겼습니다.

먼저 디자인해 보고 싶으신가요? [Playground에서 사용해 보세요](/playground?open=code&lang=react). 그곳에서 코드를 꾸민 다음 React 컴포넌트로 복사할 수 있습니다.
