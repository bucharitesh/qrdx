<IfAvailable feature="nonprofitDiscounts" id="non-profit-discount" title="Réduction pour les associations">

Les associations et organisations caritatives enregistrées bénéficient de {facts.nonprofitDiscountPercent}&nbsp;% de réduction sur Pro ou Business, facturés au mois ou à l'année. La réduction prend la forme d'un code à saisir au moment du paiement.

Pour demander un code :

1. Connectez-vous et ouvrez la [page des tarifs](/pricing).
2. Sous les offres, à côté de **Association ou organisation caritative ?**, cliquez sur **Demander un code**.
3. Indiquez le nom et le pays de votre organisation, votre numéro dans un registre des associations ou des organisations caritatives (ou un lien vers votre fiche dans un registre public), l'adresse e-mail à laquelle nous devons répondre, et l'offre souhaitée.
4. Cliquez sur **Envoyer la demande**.

La demande parvient par e-mail à l'équipe QRdx, qui vérifie l'enregistrement. Nous répondons généralement sous quelques jours. Si votre organisation est éligible, la réponse contient un code de réduction. Rien n'est débité avant le paiement.

Si le formulaire ne parvient pas à envoyer votre demande, écrivez à [support@qrdx.dev](mailto:support@qrdx.dev) avec les mêmes informations.

Pour utiliser le code :

1. Sur la [page des tarifs](/pricing), choisissez **Mensuel** ou **Annuel**, puis cliquez sur le bouton de mise à niveau de l'offre.
2. Au moment du paiement, saisissez le code dans le champ de réduction. Le prix baisse avant que vous ne payiez.

La réduction s'applique à chaque paiement de cet abonnement, renouvellements compris.

Comme tout premier paiement d'une offre payante, il est couvert par une garantie de remboursement de {facts.moneyBackDays} jours. Consultez la [politique de remboursement](/legal/refunds).
