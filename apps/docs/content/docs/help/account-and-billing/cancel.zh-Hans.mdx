## 取消 [#cancel]

1. 打开账单门户：头像菜单 → **管理账单**，或 **设置** → **套餐与用量** → **管理账单**。
2. 在账单门户中取消订阅。

## 取消后会怎样 [#what-happens-next]

- 你的套餐会在已付费周期结束前保持有效，之后不会再次扣费。
- 随后，你的账户将转为免费版。
- 所有动态二维码都会继续跳转，每一次扫描仍会被记录。
- 如果你超出了免费版的限额，在用量降到限额以内之前，将无法创建更多二维码。你仍然可以更改二维码的指向、归档二维码以及导出二维码。

参见[停止付费后，你的二维码会怎样](/docs/help/account-and-billing/never-hostage)。

## 删除账户也会取消订阅 [#deleting-your-account-cancels-too]

如果你[删除账户](/docs/help/account-and-billing/delete-your-account)，QRdx 会立即取消你的订阅。

## 退款 [#refunds]

取消订阅只会停止后续扣费，不会退还当前周期的费用。如果你在付费套餐首次付款后的 {facts.moneyBackDays} 天内取消，可以申请退回这笔款项：请使用账户的注册邮箱给 [support@qrdx.dev](mailto:support@qrdx.dev) 发送邮件。退款后套餐会立即终止，你的二维码将在免费版下继续可用。

其他费用请参见[退款政策](/legal/refunds)。
