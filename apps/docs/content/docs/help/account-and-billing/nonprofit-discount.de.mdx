<IfAvailable feature="nonprofitDiscounts" id="non-profit-discount" title="Nonprofit-Rabatt">

Eingetragene gemeinnützige Organisationen und Wohltätigkeitsorganisationen erhalten {facts.nonprofitDiscountPercent}% Rabatt auf Pro oder Business, bei monatlicher oder jährlicher Abrechnung. Den Rabatt bekommst du als Code, den du beim Checkout eingibst.

So fragst du einen Code an:

1. Melde dich an und öffne die [Preisseite](/pricing).
2. Klicke unter den Tarifen neben **Nonprofit oder Wohltätigkeitsorganisation?** auf **Code anfragen**.
3. Gib den Namen und das Land deiner Organisation an, deine Nummer in einem Register für Wohltätigkeitsorganisationen oder gemeinnützige Organisationen (oder einen Link zu deinem Eintrag in einem öffentlichen Register), die E-Mail-Adresse, an die wir antworten sollen, und den gewünschten Tarif.
4. Klicke auf **Anfrage senden**.

Die Anfrage geht per E-Mail beim QRdx-Team ein, und wir prüfen die Registrierung. Meist antworten wir innerhalb weniger Tage. Wenn deine Organisation berechtigt ist, enthält die Antwort einen Rabattcode. Bis zum Checkout wird dir nichts berechnet.

Wenn das Formular deine Anfrage nicht senden kann, schreib eine E-Mail mit denselben Angaben an [support@qrdx.dev](mailto:support@qrdx.dev).

So verwendest du den Code:

1. Wähle auf der [Preisseite](/pricing) **Monatlich** oder **Jährlich** und klicke auf die Upgrade-Schaltfläche für den Tarif.
2. Gib den Code beim Checkout im Rabattfeld ein. Der Preis sinkt, bevor du bezahlst.

Der Rabatt gilt für jede Zahlung dieses Abos, auch für Verlängerungen.

Wie bei jeder ersten Zahlung für einen kostenpflichtigen Tarif gilt auch hier eine {facts.moneyBackDays}-Tage-Geld-zurück-Garantie. Siehe die [Erstattungsrichtlinie](/legal/refunds).

</IfAvailable>
