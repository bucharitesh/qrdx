## フリーからアップグレードする [#upgrade-from-free]

1. [料金ページ](/pricing)に移動します。
2. **月払い**または**年払い**を選択します。
3. **Proにアップグレード**または**Businessにアップグレード**をクリックします。
4. 求められた場合はサインインし、チェックアウトで支払います。

支払いが完了すると、新しいプランが開始されます。

支払いは [Polar](https://polar.sh) が処理します。インドからのアクセスでは、価格がルピーで表示されます。

## すでに支払い中の場合にプランを変更する [#change-plan-when-you-already-pay]

プランの変更は、Polar が運営する請求ポータルで行います。次のいずれかから開いてください。

- アバターメニュー → **請求を管理**。
- **設定** → **プランと使用量** → **請求を管理**。
- [料金ページ](/pricing) → **Proに切り替え**または**Businessに切り替え**。

ポータルでは、ProとBusinessの間の切り替え、月払いと年払いの切り替え、カード情報の更新ができます。

## フリーにダウングレードする [#downgrade-to-free]

フリーに戻すには、[サブスクリプションをキャンセル](/docs/help/account-and-billing/cancel)してください。プランは、支払い済みの期間が終了するまで有効です。

## ダウングレードするとどうなるか [#what-happens-when-you-downgrade]

作成済みのコードは引き続き動作します。制限されるのは、新しく作成するものだけです。[支払いを止めた場合のコードの扱い](/docs/help/account-and-billing/never-hostage)をご覧ください。
