## フリーからアップグレードする [#upgrade-from-free]

1. [料金ページ](/pricing)を開きます。
2. **月払い**または**年払い**を選びます。
3. **Proにアップグレード**または**Businessにアップグレード**をクリックします。
4. サインインを求められた場合はサインインし、チェックアウトで支払います。

新しいプランは、支払いが完了した時点で開始されます。

支払いは [Polar](https://polar.sh) が処理します。QRdx が対応している国では、インドのルピーなど、その国の通貨で価格が表示され、チェックアウトでもその通貨で請求されます。

有料プランの最初の支払いには、{facts.moneyBackDays}日間の返金保証が付いています。[返金](/docs/help/account-and-billing/invoices#refunds)をご覧ください。

## すでに支払い中のプランを変更する [#change-plan-when-you-already-pay]

プランの変更は、Polar が運営する請求ポータルで行います。次のいずれかから開けます。

- アバターメニュー → **請求を管理**。
- **設定** → **プランと使用量** → **請求を管理**。
- [料金ページ](/pricing) → **Proに切り替え**または**Businessに切り替え**。

ポータルでは、Pro と Business の間の変更、月払いと年払いの切り替え、カードの更新ができます。

## フリーにダウングレードする [#downgrade-to-free]

フリーに戻すには、[サブスクリプションをキャンセル](/docs/help/account-and-billing/cancel)してください。プランは、支払い済みの期間の終わりまで有効です。

## ダウングレードするとどうなるか [#what-happens-when-you-downgrade]

作成済みのコードは引き続き動作します。制限されるのは、新しく作成するものだけです。[支払いを止めた場合のコードの扱い](/docs/help/account-and-billing/never-hostage)をご覧ください。
