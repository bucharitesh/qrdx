---
title: "Ekspor data Anda"
description: "Unduh semua isi akun Anda, atau ekspor data pemindaian dan respons formulir sebagai CSV."
---

## Semuanya sekaligus [#everything-at-once]

1. Buka **Settings** → **Profile & security**.
2. Di bawah **Your data**, klik **Download my data**.

Anda akan mendapatkan file ZIP berisi kode, data pemindaian, halaman, respons formulir, tema, dan detail akun Anda, dalam bentuk file JSON dan CSV, ditambah README yang menjelaskannya.

Anda dapat mengunduhnya hingga 3 kali per jam.

## Pemindaian satu kode [#scans-of-one-code]

Buka kode dari **Codes** lalu klik **Export CSV**. Anda mendapatkan hingga 50.000 pemindaian untuk rentang tanggal yang Anda pilih.

## Respons formulir [#form-responses]

Di **Pages**, buka menu halaman (**⋯**), pilih **Responses**, lalu klik **Export CSV**.

## Gambar kode QR [#qr-code-images]

Di **Codes**, pilih kode yang Anda inginkan, lalu klik **Download**. Anda mendapatkan ZIP berisi file PNG, WebP, atau SVG, beserta daftar kode dalam format CSV.
