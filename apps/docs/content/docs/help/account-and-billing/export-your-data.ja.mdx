---

## すべてを一度にエクスポート [#everything-at-once]

1. **設定** → **プロフィールとセキュリティ** に移動します。
2. **あなたのデータ** で、**データをダウンロード** をクリックします。

コード、スキャン、ページ、フォームの回答、テーマ、アカウント情報が JSON と CSV のファイルとして含まれた ZIP ファイルと、その内容を説明する README を入手できます。

ダウンロードは1時間に最大3回までです。

## 1つのコードのスキャン [#scans-of-one-code]

**コード** からコードを開き、**CSVをエクスポート** をクリックします。選択した期間のスキャンを最大50,000件まで取得できます。

## フォームの回答 [#form-responses]

**ページ** で、対象ページのメニュー（**⋯**）を開き、**回答** を選んで、**CSVをエクスポート** をクリックします。

## QRコードの画像 [#qr-code-images]

**コード** で、必要なコードを選択し、**ダウンロード** をクリックします。PNG、WebP、SVG のファイルをまとめた ZIP と、コードの CSV 一覧を入手できます。
