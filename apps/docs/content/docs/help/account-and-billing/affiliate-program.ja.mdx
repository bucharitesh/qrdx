アフィリエイトプログラムは qrdx.dev でのみ実施しています。セルフホストのQRdxサーバーでは利用できません。詳しくは[セルフホスティング](/docs/self-hosting#optional-services)をご覧ください。

<IfAvailable feature="affiliates">

QRdxのアフィリエイトプログラムでは、あなたが紹介したお客様が有料顧客となってから最初の{facts.affiliateCommissionMonths}か月間に支払った金額の{facts.affiliateCommissionPercent}%を報酬としてお支払いします。詳しいルールは[アフィリエイト規約](/legal/affiliate-terms)に記載しています。このページでは、各機能の場所を案内します。

## 申し込む [#apply]

1. QRdxにサインインするか、無料アカウントを作成します。
2. [アフィリエイトプログラムのページ](/affiliates)を開き、規約を読んで、簡単な申込フォームに記入します。
3. 申し込みは1件ずつ手作業で審査します。結果は**設定** → **アフィリエイトプログラム**に表示されます。

## リンクを共有する [#share-your-link]

承認されると、**設定** → **アフィリエイトプログラム**に紹介リンクと**コピー**ボタンが表示されます。そのリンクを開き、同じ訪問中に新しいQRdxアカウントを作成した方が、あなたの紹介になります。

- 紹介として認められるには、同じ訪問中にサインアップする必要があります。ページの再読み込み、QRdxを新しいタブで開くこと、ドキュメントとサイトのほかの部分を行き来することはできません。コードはサインアップ時に一緒に送られます。Cookieは使わず、相手のデバイスには何も保存されないため、後日の訪問でのサインアップは対象外です。
- リンクは、ランダムなコードで始まります。**コード**で、好きなコードに1回だけ変更できます。最初のコードのリンクも引き続き使えます。
- すでに存在するアカウントは、あなたの紹介にはなりません。また、アカウントは最初に得た紹介が維持されます。
- あなた自身のアカウントは対象外です。同じメールアドレスを別の表記にしたアカウントや、あなたがメンバーになっているワークスペースの方のアカウントも対象外です。

## 収益を確認する [#follow-your-earnings]

同じページに、次の項目が表示されます。

- **リンクの訪問数**（Cookieを使わずに集計し、繰り返しの訪問も再度カウントされます）、**サインアップ数**、**有料顧客数**。どなたが紹介されたかは表示されません。
- **保留中**：{facts.affiliateHoldDays}日間の待機期間中の報酬です。この間に返金やチャージバックがあると、その報酬は取り消されます。
- **支払い可能**：待機期間を過ぎて、まだ支払われていない報酬です。
- **支払い済み**：お送りした金額です。各支払いのPayPal取引IDも表示されます。

報酬は、お客様が支払った通貨（米ドルまたはインドルピー）で表示されます。お支払いは米ドルで行います。

## 支払いを受け取る [#get-paid]

**収益**でPayPalのメールアドレスを追加してください。このアドレスは送金先を決めるため、変更する前にご本人かどうかの確認をQRdxが求めます。変更のたびに、アカウントのメールアドレスにも通知が届きます。

お支払いは月に1回、手作業でPayPalを通じて米ドルで行います。支払い可能な報酬の合計が{facts.affiliateMinPayoutUsd}に達していることが条件です。ルピーの報酬は、支払日の欧州中央銀行の参考レートで換算します。各支払いには、使用したレートが表示されます。最低額に満たない残高は、翌月以降に繰り越されます。収益にかかる税金は、ご自身で対応してください。

報酬や支払いについてのご質問は、[support@qrdx.dev](mailto:support@qrdx.dev)までメールでお問い合わせください。
