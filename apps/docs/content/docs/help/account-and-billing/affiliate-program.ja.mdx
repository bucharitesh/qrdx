アフィリエイトプログラムはqrdx.devでのみ実施しています。セルフホストのQRdxサーバーでは利用できません。詳しくは[セルフホスティング](/docs/self-hosting#optional-services)をご覧ください。

<IfAvailable feature="affiliates">

QRdxのアフィリエイトプログラムでは、あなたが紹介したお客様が有料顧客として支払った最初の{facts.affiliateCommissionMonths}か月分の金額の{facts.affiliateCommissionPercent}%をお支払いします。完全なルールは[アフィリエイト規約](/legal/affiliate-terms)に記載しています。このページでは、各項目の場所を案内します。

## 申し込み [#apply]

1. QRdxにサインインするか、無料アカウントを作成します。
2. [アフィリエイトプログラムのページ](/affiliates)を開き、規約を読んで、簡単な申込フォームに入力します。
3. 申し込みはすべて手作業で審査します。結果は**設定** → **アフィリエイトプログラム**に表示されます。

## リンクを共有する [#share-your-link]

承認されると、**設定** → **アフィリエイトプログラム**に紹介リンクが**コピー**ボタンとともに表示されます。そのリンクを開き、同じ訪問中に新しいQRdxアカウントを作成した人が、あなたの紹介になります。

- 紹介として扱われるには、その訪問中に、ページを再読み込みしたり新しいタブでQRdxを開いたりせずにサインアップする必要があります。コードはサインアップと一緒に送られます。Cookieは使わず、相手の端末には何も保存しないため、後日の訪問でのサインアップは対象になりません。
- リンクは、ランダムなコードで始まります。**コード**で、好きなコードに一度だけ変更できます。最初のコードを使ったリンクも引き続き使えます。
- すでにあるアカウントを紹介にすることはできません。また、アカウントは最初に得た紹介が維持されます。
- ご自身のアカウントは対象外です。別の表記であなたのメールアドレスを使ったアカウントや、あなたが所属するワークスペースのメンバーも対象外です。

## 収益を確認する [#follow-your-earnings]

同じページに、次の内容が表示されます。

- **リンクの訪問数**（Cookieを使わずに集計し、繰り返しの訪問も再度カウントされます）、**サインアップ**、**有料顧客**。紹介した人が誰かは表示されません。
- **保留中**: {facts.affiliateHoldDays}日間の待機期間中の報酬。この期間内に返金やチャージバックがあると、報酬は取り消されます。
- **支払可能**: 待機期間を過ぎて、まだ支払われていない報酬。
- **支払済み**: お送りした金額。各支払いのPayPal取引IDも表示されます。

報酬は、お客様が支払った通貨（米ドルまたはインドルピー）で表示されます。支払いは米ドルで行います。

## 支払いを受け取る [#get-paid]

**収益**でPayPalのメールアドレスを追加します。このアドレスは送金先を決めるため、変更する前にQRdxが本人確認を求めます。変更のたびに、アカウントのメールアドレスにも通知します。

支払いはPayPalで米ドルにより、月に一度、手作業で行います。支払可能な金額の合計が{facts.affiliateMinPayoutUsd}に達した場合が対象です。ルピーの報酬は、支払日の欧州中央銀行の参考レートで換算し、各支払いに使用したレートが表示されます。最低額に満たない残高は繰り越されます。収益に対する税金はご自身で対応してください。

報酬や支払いについてのご質問は、[support@qrdx.dev](mailto:support@qrdx.dev)までメールでお問い合わせください。
