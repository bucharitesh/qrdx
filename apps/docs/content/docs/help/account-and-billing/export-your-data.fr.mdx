---

## Tout en une fois [#everything-at-once]

1. Allez dans **Paramètres** → **Profil et sécurité**.
2. Sous **Vos données**, cliquez sur **Télécharger mes données**.

Vous obtenez un fichier ZIP contenant vos codes, scans, pages, réponses aux formulaires, thèmes et informations de compte, sous forme de fichiers JSON et CSV, ainsi qu'un fichier README qui les décrit.

Vous pouvez le télécharger jusqu'à 3 fois par heure.

## Scans d'un code [#scans-of-one-code]

Ouvrez le code depuis **Codes** et cliquez sur **Exporter en CSV**. Vous obtenez jusqu'à 50,000 scans pour les dates sélectionnées.

## Réponses aux formulaires [#form-responses]

Dans **Pages**, ouvrez le menu de la page (**⋯**), choisissez **Réponses**, puis cliquez sur **Exporter en CSV**.

## Images de QR code [#qr-code-images]

Dans **Codes**, sélectionnez les codes souhaités, puis cliquez sur **Télécharger**. Vous obtenez un ZIP de fichiers PNG, WebP ou SVG, accompagné d'une liste CSV des codes.
