## 로그인 방법 [#ways-to-sign-in]

- **Google** 또는 **GitHub**.
- **이메일 코드**: 이메일을 입력한 다음, 전송된 6자리 코드를 입력해요. 코드는 5분 동안 유효합니다.

<IfAvailable feature="passkeys">
[패스키를 추가](/docs/help/privacy-and-security/passkeys)하면 지문, 얼굴 또는 화면 잠금으로도 로그인할 수 있습니다.
</IfAvailable>

처음 로그인하면 QRdx가 계정을 만듭니다. 기억해야 할 비밀번호는 없습니다.

Google 또는 GitHub로 로그인하는 경우, 해당 서비스에서 이메일 주소를 인증한 경우에만 QRdx가 계정을 만듭니다. 이메일이 인증되지 않았다면 먼저 인증하거나(GitHub에서는 **Settings** → **Emails**에서 주소 목록을 볼 수 있습니다) 이메일 코드로 로그인하세요.

## 내가 만들지 않은 내 주소의 계정 [#an-account-for-your-address-you-didnt-make]

QRdx에 내 주소로 된 계정이 이미 있는데 직접 만든 것이 아니라면 이메일 코드로 로그인하세요. 코드로 해당 주소가 내 것임이 확인되면, QRdx는 이전 가입자가 다시 접근하거나 계속 계정 데이터를 받는 데 쓸 수 있는 항목을 삭제합니다.

- Google 및 GitHub 연결과 모든 세션
- 2단계 인증과 신뢰할 수 있는 기기<IfAvailable feature="passkeys">, 그리고 패스키</IfAvailable>
- API 키와 계정 사용을 허용한 앱
- 설정해 둔 웹훅, Slack 및 Discord 알림, 그리고 스캔이나 폼 응답을 다른 도구로 보내도록 설정한 동기화

계정의 나머지 항목은 그대로 남으므로, 이후에 워크스페이스와 멤버를 확인하세요.

## Google 또는 GitHub 연결 [#link-google-or-github]

**설정** → **프로필 및 보안** → **로그인 방법**으로 이동합니다.

- **이메일 코드**는 항상 켜져 있어요.
- Google 또는 GitHub를 연결하면 한 번의 클릭으로 로그인할 수 있습니다. QRdx 계정과 같은 이메일 주소를 사용하는 계정이어야 합니다.
- 연결을 제거하려면 **연결 해제**를 클릭하세요.

## 이메일 주소 변경 [#change-your-email-address]

1. **설정** → **프로필 및 보안**으로 이동합니다.
2. **이메일** 옆의 **변경**을 클릭하고 [본인 확인](/docs/help/privacy-and-security/two-step-verification#confirm-its-you)을 합니다.
3. 새 주소를 입력하고, 그 주소로 전송된 코드를 입력합니다.

그러면 QRdx는 다른 모든 기기와 브라우저에서 로그아웃시키며, 이전 주소로 계정이 이동했다는 이메일을 보냅니다. 본인이 한 일이 아니라면 지원팀에 연락할 수 있는 방법도 함께 안내됩니다.

## 이메일에 접근할 수 없는 경우 [#lost-access-to-your-email]

아직 QRdx에 로그인할 수 있다면 위에서 설명한 대로 직접 이메일을 변경하세요. 메일함 없이 본인 확인을 하려면 <IfAvailable feature="passkeys">패스키, </IfAvailable>연결해 둔 Google 또는 GitHub 계정, 또는 켜져 있다면 2단계 인증 방법을 사용하세요. 로그아웃된 상태라면 먼저 <IfAvailable feature="passkeys">패스키 또는 </IfAvailable>연결된 Google 또는 GitHub 계정으로 로그인하세요.

위 방법이 모두 되지 않으면 사용하려는 주소에서 [support@qrdx.dev](mailto:support@qrdx.dev)로 이메일을 보내 주세요. 계정을 새 주소로 옮기는 일은 지원팀이 하는 가장 민감한 작업이므로 다음 절차를 따릅니다.

- **계정이 본인 것이라는 증거가 필요합니다.** 계정에 등록된 이메일 주소와 다음 중 하나를 요청드립니다.
  - QRdx를 결제한 적이 있다면 [인보이스](/docs/help/account-and-billing/invoices) 중 하나의 번호와 대략적인 결제 시기
  - 계정의 워크스페이스가 자체 [도메인](/docs/help/domains/custom-domains)을 사용한다면, 저희가 보내 드리는 DNS 레코드를 해당 도메인에 추가
- **이전 주소로 알리고 7일을 기다립니다.** 그 기간에 누군가 이전 주소에서 거절 답장을 보내면 절차를 중단합니다.
- **그런 다음 계정을 옮깁니다.** 계정의 이메일을 새 주소로 바꾸고, 모든 곳에서 로그아웃시키고, 이전 주소로 이메일을 보냅니다. 새 주소로 전송된 코드로 로그인하세요. 2단계 인증이 켜져 있다면 그대로 유지됩니다.

계정이 본인 것임을 확인할 수 없으면, 계정에 접근할 수 없게 되더라도 옮기지 않습니다. 엉뚱한 사람에게 넘겨주는 것이 더 큰 문제이기 때문입니다.

이전 주소를 사용할 수 없게 되기 전에 패스키를 추가하거나 Google 또는 GitHub를 연결해 두면 언제든 본인 확인을 할 수 있습니다.

## 다른 기기에서 로그아웃 [#sign-out-of-other-devices]

**설정** → **프로필 및 보안**의 **세션**에서 한 기기에서만 로그아웃하거나 **다른 모든 곳에서 로그아웃**을 클릭하세요.

## 로그인 문제 [#trouble-signing-in]

[로그인 코드나 이메일이 오지 않아요](/docs/help/troubleshooting/emails)를 참고하세요.
