인쇄한 코드는 안전합니다. 이것이 [Never-Hostage 보장](/guarantee)이며, 무료를 포함한 모든 요금제에 적용됩니다.

## 약속드리는 내용 [#what-we-promise]

- **정적 코드는 영원히 무료입니다.** 콘텐츠를 코드에 직접 담고 있어 만료되지 않습니다.
- **동적 코드는 계속 리디렉션됩니다.** 요금제를 낮추거나 결제에 실패하거나 해지한 후에도 마찬가지입니다.
- **일시 중지도, 광고도 없습니다.** 결제 문제로 코드를 일시 중지하지 않으며, 스캔하는 사용자를 QRdx 페이지로 보내지도 않습니다.
- **한도는 새로 만드는 것만 막습니다.** 기존 코드와 페이지는 계속 작동하며, 코드가 연결되는 대상도 그대로 바꿀 수 있습니다.
- **모든 것을 내보낼 수 있습니다.** 모든 요금제에서 코드, 스캔, 응답을 다운로드할 수 있습니다.
- **QRdx가 서비스를 종료하는 경우 12개월 전에 알려드리며**, 오픈소스 앱을 직접 운영할 수 있는 방법도 함께 안내합니다.

## 요금제를 낮춰도 계속 작동하는 것 [#what-keeps-working-after-a-downgrade]

- 모든 동적 코드와 모든 페이지.
- 이미 저장한 라우팅 규칙, 비밀번호, 일정, 픽셀.
- 이미 인증한 사용자 지정 도메인.

## 달라지는 것 [#what-changes]

- 새 요금제의 한도를 넘어 새 코드나 페이지를 만들 수 없습니다.
- 스캔 기록에는 새 요금제에 포함된 범위만 표시됩니다. 삭제되는 데이터는 없습니다.
- 무료 페이지에는 "Made with QRdx" 푸터가 다시 표시됩니다.
- 월별 한도에 도달하면 폼이 더 이상 응답을 받지 않습니다.
- 저장 용량 한도를 넘는 업로드는 차단됩니다.

## 코드가 중단되는 경우 [#what-does-stop-a-code]

직접 선택한 경우뿐입니다. 일시 중지, 종료일, 스캔 한도, 보관, 삭제가 해당합니다. 또한 QRdx는 악용에 사용되는 코드를 끌 수 있습니다.
