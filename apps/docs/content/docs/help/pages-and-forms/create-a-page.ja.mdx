---
title: "モバイルページを作成する"
description: "リンク集、メニュー、連絡先カード、クーポンなど、QRコード用のページを作成できます。Webサイトは不要です。"
---

QRdx は、QRコード用のモバイルページをホストします。ページはブロックを組み合わせて作成でき、QRコードを再印刷せずにいつでも編集できます。

## ページを作成する [#create-a-page]

1. ダッシュボードの **Pages** に移動し、**New page** をクリックします。
2. タイプを選びます。Link list、Business、vCard Plus、Menu、Coupon、Event、App download、Feedback & forms、PDF、Images、MP3 / Audio、Video、Custom page から選べます。
3. テンプレートを選びます。ブロック、色、テキストはあとからすべて変更できます。
4. 必要に応じてページに名前を付け、**Create page** をクリックします。

ページの作成と同時に、QRdx がそのページ用の動的QRコードを作成します。

[Playground](/playground) から始めることもできます。**QR code type** の横にある **Change** をクリックし、**Hosted pages** のいずれかを選んでください。

## 編集と公開 [#edit-and-publish]

ページエディターには、**Blocks**、**Design**、**Settings** の3つのタブがあります。

**Publish** をクリックするか、<kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>S</kbd> を押すまで、訪問者に表示される内容は変わりません。それまでの間、ヘッダーには「Unpublished changes」と表示されます。

未公開の編集内容はブラウザーに保存されるため、タブを閉じてもあとで続きから作業できます。

## QRコードを取得する [#get-the-qr-code]

ページエディターのヘッダーにある **QR code** をクリックすると、そのページのQRコードを開いてダウンロードできます。**View live** をクリックすると、公開済みのページが開きます。

ページにQRコードがない場合は、**Pages** でそのページのメニュー（**⋯**）を開き、**Create a QR code** を選んでください。

## プラン [#plans]

- **フリー**：3ページまで。小さな「Made with QRdx」フッターが表示されます。
- **Pro**：ページ数無制限。フッターなし。
- **Business**：ホワイトラベルページを無制限に作成でき、カスタムCSSも使えます。
