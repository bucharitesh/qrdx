QRdx 会为你的二维码托管一个移动端页面。页面由多个区块组成，你可以随时编辑，无需重新印刷二维码。

## 创建页面 [#create-a-page]

1. 在控制台中进入 **Pages**，然后点击 **New page**。
2. 选择类型：链接列表、商家、vCard Plus、菜单、优惠券、活动、应用下载、反馈与表单、PDF、图片、MP3 / 音频、视频或自定义页面。
3. 选择模板。之后你可以修改每个区块、颜色和文字。
4. 如有需要，为页面命名，然后点击 **Create page**。

创建页面的同时，QRdx 会为该页面创建一个动态二维码。

你也可以从 [Playground](/playground) 开始：点击 **QR code type** 旁边的 **Change**，然后选择其中一种 **Hosted pages**。

## 编辑与发布 [#edit-and-publish]

页面编辑器有三个标签页：**Blocks**、**Design** 和 **Settings**。

在你点击 **Publish** 或按下 <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>S</kbd> 之前，访问者看到的内容不会有任何变化。在此之前，页头会显示“Unpublished changes”。

未发布的修改会保存在浏览器中，因此你可以关闭标签页，稍后再回来继续编辑。

## 获取二维码 [#get-the-qr-code]

点击页面编辑器页头中的 **QR code**，即可打开该页面的二维码并下载。**View live** 会打开已发布的页面。

如果某个页面没有二维码，请在 **Pages** 中打开它的菜单（**⋯**），然后选择 **Create a QR code**。

## 套餐 [#plans]

- **免费版**：3 个页面，页脚带有小字“Made with QRdx”。
- **Pro**：页面数量不限，无页脚。
- **Business**：页面数量不限，支持白标页面和自定义 CSS。
