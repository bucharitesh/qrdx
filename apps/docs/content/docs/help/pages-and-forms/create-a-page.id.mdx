QRdx meng-hosting halaman seluler untuk kode QR Anda. Anda menyusunnya dari blok, dan dapat mengeditnya kapan saja tanpa mencetak ulang kodenya.

## Buat halaman [#create-a-page]

1. Buka **Pages** di dasbor Anda, lalu klik **New page**.
2. Pilih jenis: Link list, Business, vCard Plus, Menu, Coupon, Event, App download, Feedback & forms, PDF, Images, MP3 / Audio, Video, atau Custom page.
3. Pilih templat. Anda dapat mengubah setiap blok, warna, dan teks nanti.
4. Beri nama halaman jika Anda mau, lalu klik **Create page**.

QRdx membuat kode QR dinamis untuk halaman tersebut secara bersamaan.

Anda juga dapat memulai dari [Playground](/playground): klik **Change** di samping **QR code type** lalu pilih salah satu **Hosted pages**.

## Edit dan terbitkan [#edit-and-publish]

Editor halaman memiliki tiga tab: **Blocks**, **Design**, dan **Settings**.

Tidak ada yang berubah bagi pengunjung sampai Anda mengklik **Publish**, atau menekan <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>S</kbd>. Header menampilkan "Unpublished changes" hingga saat itu.

Hasil edit yang belum diterbitkan disimpan di browser Anda, jadi Anda dapat menutup tab dan kembali lagi.

## Dapatkan kode QR [#get-the-qr-code]

Klik **QR code** di header editor halaman untuk membuka kode halaman dan mengunduhnya. **View live** membuka halaman yang sudah diterbitkan.

Jika sebuah halaman belum memiliki kode, buka menunya (**⋯**) di **Pages** dan pilih **Create a QR code**.

## Paket [#plans]

- **Gratis**: 3 halaman, dengan footer kecil "Made with QRdx".
- **Pro**: halaman tanpa batas, tanpa footer.
- **Business**: halaman white-label tanpa batas dan CSS kustom.
