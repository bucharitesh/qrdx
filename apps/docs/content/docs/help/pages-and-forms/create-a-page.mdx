title: Create a mobile page

---

QRdx hosts a mobile page for your QR code. You build it from blocks, and you can edit it any time without reprinting the code.

## Create a page

1. Go to **Pages** in your dashboard and click **New page**.
2. Pick a type: Link list, Business, vCard Plus, Menu, Coupon, Event, App download, Feedback & forms, PDF, Images, MP3 / Audio, Video or Custom page.
3. Pick a template. You can change every block, color and text later.
4. Name the page if you like, then click **Create page**.

QRdx creates a dynamic QR code for the page at the same time.

You can also start from the [playground](/playground): click **Change** next to **QR code type** and pick one of the **Hosted pages**.

## Edit and publish

The page editor has three tabs: **Blocks**, **Design** and **Settings**.

Nothing changes for visitors until you click **Publish**, or press <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>S</kbd>. The header shows "Unpublished changes" until then.

Unpublished edits are kept in your browser, so you can close the tab and come back.

## Get the QR code

Click **QR code** in the page editor header to open the page's code and download it. **View live** opens the published page.

If a page has no code, open its menu (**⋯**) in **Pages** and choose **Create a QR code**.

## Plans

- **Free**: 3 pages, with a small "Made with QRdx" footer.
- **Pro**: unlimited pages, no footer.
- **Business**: unlimited white-label pages and custom CSS.
