QRdx héberge une page mobile pour votre QR code. Vous la construisez avec des blocs et vous pouvez la modifier à tout moment, sans réimprimer le code.

## Créer une page [#create-a-page]

1. Allez dans **Pages** dans votre tableau de bord et cliquez sur **Nouvelle page**.
2. Choisissez un type : Liste de liens, Entreprise, vCard Plus, Menu, Coupon, Événement, Téléchargement d'app, Commentaires et formulaires, PDF, Images, MP3 / Audio, Vidéo ou Page personnalisée.
3. Choisissez un modèle. Vous pourrez modifier ensuite chaque bloc, couleur et texte.
4. Donnez un nom à la page si vous le souhaitez, puis cliquez sur **Créer la page**.

QRdx crée en même temps un QR code dynamique pour la page.

Vous pouvez aussi partir du [Playground](/playground) : cliquez sur **Modifier** à côté de **Type de QR code** et choisissez l'une des **Pages hébergées**.

## Modifier et publier [#edit-and-publish]

L'éditeur de page comporte trois onglets : **Blocs**, **Design** et **Paramètres**.

Rien ne change pour les visiteurs tant que vous n'avez pas cliqué sur **Publier** ou appuyé sur <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>S</kbd>. L'en-tête affiche « Modifications non publiées » jusque-là.

Les modifications non publiées sont conservées dans votre navigateur : vous pouvez fermer l'onglet et revenir plus tard.

## Obtenir le QR code [#get-the-qr-code]

Cliquez sur **QR code** dans l'en-tête de l'éditeur de page pour ouvrir le code de la page et le télécharger. **Voir en ligne** ouvre la page publiée.

Si une page n'a pas de code, ouvrez son menu (**⋯**) dans **Pages** et choisissez **Créer un QR code**.

## Offres [#plans]

- **Gratuit** : 3 pages, avec un petit pied de page « Made with QRdx ».
- **Pro** : pages illimitées, sans pied de page.
- **Business** : pages en marque blanche illimitées et CSS personnalisé.
