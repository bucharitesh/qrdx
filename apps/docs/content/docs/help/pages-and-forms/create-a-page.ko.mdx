QRdx는 QR 코드용 모바일 페이지를 호스팅합니다. 블록으로 페이지를 구성하며, 코드를 다시 인쇄하지 않고도 언제든지 수정할 수 있습니다.

## 페이지 만들기 [#create-a-page]

1. 대시보드에서 **Pages**로 이동한 다음 **New page**를 클릭하세요.
2. 유형을 선택하세요: Link list, Business, vCard Plus, Menu, Coupon, Event, App download, Feedback & forms, PDF, Images, MP3 / Audio, Video 또는 Custom page.
3. 템플릿을 선택하세요. 모든 블록, 색상, 텍스트는 나중에 변경할 수 있어요.
4. 원하면 페이지 이름을 입력한 다음 **Create page**를 클릭하세요.

QRdx는 페이지를 만들 때 해당 페이지용 동적 QR 코드도 함께 만듭니다.

[Playground](/playground)에서 시작할 수도 있습니다. **QR code type** 옆의 **Change**를 클릭한 다음 **Hosted pages** 중 하나를 선택하세요.

## 편집 및 게시 [#edit-and-publish]

페이지 편집기에는 **Blocks**, **Design**, **Settings** 세 개의 탭이 있습니다.

**Publish**를 클릭하거나 <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>S</kbd>를 누르기 전까지는 방문자에게 보이는 내용이 바뀌지 않습니다. 그때까지 헤더에는 "Unpublished changes"가 표시됩니다.

게시하지 않은 수정 내용은 브라우저에 저장되므로 탭을 닫았다가 다시 돌아와도 됩니다.

## QR 코드 받기 [#get-the-qr-code]

페이지 편집기 헤더에서 **QR code**를 클릭하면 페이지의 코드를 열고 다운로드할 수 있습니다. **View live**를 클릭하면 게시된 페이지가 열립니다.

페이지에 코드가 없다면 **Pages**에서 해당 페이지의 메뉴(**⋯**)를 열고 **Create a QR code**를 선택하세요.

## 요금제 [#plans]

- **무료**: 페이지 3개, 하단에 작은 "Made with QRdx" 문구가 표시됩니다.
- **Pro**: 페이지 수 제한 없음, 하단 문구 없음.
- **Business**: 화이트 라벨 페이지 수 제한 없음, 사용자 지정 CSS 지원.
