QRdx hostet eine mobile Seite für deinen QR-Code. Du baust sie aus Blöcken auf und kannst sie jederzeit bearbeiten, ohne den Code neu zu drucken.

## Seite erstellen [#create-a-page]

1. Gehe in deinem Dashboard zu **Seiten** und klicke auf **Neue Seite**.
2. Wähle einen Typ: Linkliste, Business, vCard Plus, Speisekarte, Gutschein, Event, App-Download, Feedback & Formulare, PDF, Bilder, MP3 / Audio, Video oder Individuelle Seite.
3. Wähle eine Vorlage. Du kannst später jeden Block, jede Farbe und jeden Text ändern.
4. Gib der Seite bei Bedarf einen Namen und klicke dann auf **Seite erstellen**.

QRdx erstellt gleichzeitig einen dynamischen QR-Code für die Seite.

Du kannst auch im [Playground](/playground) starten: Klicke neben **QR-Code-Typ** auf **Ändern** und wähle eine der **Gehosteten Seiten**.

## Bearbeiten und veröffentlichen [#edit-and-publish]

Der Seiteneditor hat drei Tabs: **Blöcke**, **Design** und **Einstellungen**.

Für Besucher ändert sich erst etwas, wenn du auf **Veröffentlichen** klickst oder <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>S</kbd> drückst. Bis dahin zeigt die Kopfzeile „Nicht veröffentlichte Änderungen“ an.

Nicht veröffentlichte Änderungen bleiben in deinem Browser gespeichert. Du kannst den Tab also schließen und später weitermachen.

## QR-Code abrufen [#get-the-qr-code]

Klicke in der Kopfzeile des Seiteneditors auf **QR-Code**, um den Code der Seite zu öffnen und herunterzuladen. **Live ansehen** öffnet die veröffentlichte Seite.

Wenn eine Seite keinen Code hat, öffne unter **Seiten** ihr Menü (**⋯**) und wähle **QR-Code erstellen**.

## Tarife [#plans]

- **Kostenlos**: 3 Seiten, mit einem kleinen Footer „Made with QRdx“.
- **Pro**: unbegrenzt viele Seiten, kein Footer.
- **Business**: unbegrenzt viele White-Label-Seiten und eigenes CSS.
