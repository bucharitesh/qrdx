パスキーは、指紋、顔、デバイスの画面ロック、またはセキュリティキーを使って本人確認を行います。パスキーはお使いのデバイスまたはパスワードマネージャーに保存され、QRdx自身のサイトでのみ動作するため、偽サイトに情報を取られることはありません。

QRdxでは、パスキーは次の2つの役割を果たします。

- サインインページの **パスキーで続行** から、パスキーだけでサインインできます。
- メールコード、Google、GitHub<IfAvailable feature="sso">（またはワークスペースのシングルサインオン）</IfAvailable>でサインインしたあとの、[2段階認証](/docs/help/privacy-and-security/two-step-verification)の2段階目として使えます。

また、2段階認証のオン／オフなど、アカウントのセキュリティに関わる変更の前には、[本人確認](/docs/help/privacy-and-security/two-step-verification#confirm-its-you)にも使われます。メールにアクセスできない場合に便利です。

## パスキーを追加する [#add-a-passkey]

1. **設定** → **プロフィールとセキュリティ** に移動します。
2. **2段階認証** の下で **パスキーを追加** をクリックし、本人確認を行います。
3. 提案された名前（「Chrome on macOS」のようなブラウザーとシステムの名前）をそのまま使うか、任意の名前を入力して **続行** をクリックします。
4. ブラウザーがパスキーの保存先を尋ね、指紋、顔、または画面ロックで確認します。

2段階認証がオフの場合、パスキーを追加すると2段階認証がオンになり、保存用のバックアップコードが10個表示されます。パスキーが手元にないときは、このコードでサインインできます。

パスキーは、使用するたびに本人確認を行う必要があります。スマートフォン、コンピューター、パスワードマネージャーでは、指紋、顔、または画面ロックで確認します。セキュリティキーには、PINの設定が必要です。

パスキーが追加または削除されるたびに、QRdxはアカウントのメールアドレスに通知を送ります。

## パスキーでサインインする [#sign-in-with-a-passkey]

サインインページで、サインイン方法の一覧の下にある **パスキーで続行** をクリックし、使用するパスキーを選びます。パスキーでのサインインは2つの段階の両方を満たすため、QRdxから追加の確認は求められません。

メール欄にはパスキーの候補は表示されません。ボタンを使ってください。

パスキーでサインインできるのは、そのパスキーを追加したアカウントです。アカウントを新規作成することはできません。QRdxを初めて使う場合は、まずGoogle、GitHub、またはメールコードでサインインし、そのあとでパスキーを追加してください。

## パスキーを2段階目の確認として使う [#use-a-passkey-as-your-second-step]

2段階認証がオンの場合は、いつもどおりサインインします。するとブラウザーのパスキー画面が自動的に開くので、本人確認を行えばサインイン完了です。ブラウザーによっては、クリックしないと画面が開かないことがあります。その場合は **パスキーで続行** をクリックしてください。

パスキーが手元にない場合は、**認証コードを使用** （認証アプリを設定している場合）または **バックアップコードを使用** をクリックします。

パスキーが2段階目として使えるようになる前に追加していて、2段階認証がオフの場合、設定に **パスキーを2段階目として使用できます** と表示されます。**オンにする** をクリックしてこの方法を有効にし、本人確認を行い、パスキーで確認して、バックアップコードを保存します。

## 同期型パスキーとデバイス固定パスキー [#synced-and-device-bound-passkeys]

同期型パスキーは、パスワードマネージャーやiCloudキーチェーン、Googleパスワードマネージャーなどのクラウドキーチェーンにバックアップされます。そのアカウントでサインインしているすべてのデバイスで使えます。

デバイス固定パスキーは、作成したスマートフォン、コンピューター、またはセキュリティキーにのみ保存されます。ほかの場所でサインインするには、別のサインイン方法を使うか、そのデバイスにもパスキーを追加してください。

## パスキーの名前変更と削除 [#rename-or-remove-a-passkey]

**2段階認証** の下で、パスキーの横にあるメニューを開き、**名前を変更** または **削除** をクリックして、本人確認を行います。削除したパスキーは、QRdxではすぐに使えなくなります。お使いのデバイスやパスワードマネージャーには、そちらでも削除するまで一覧に残る場合があります。

そのパスキーが唯一の2段階目の確認方法である場合、削除すると2段階認証がオフになります。確認の前に、QRdxからその旨が通知されます。

パスキーを保存していたデバイスを紛失した場合は、別の方法でサインインして、そのパスキーを削除してください。

メールに送信されるコードでいつでもサインインできるため、最後のパスキーを削除してもサインインできなくなることはありません。
