패스키는 지문, 얼굴, 기기의 화면 잠금 또는 보안 키로 본인 여부를 확인합니다. 패스키는 기기나 비밀번호 관리자에 저장되며 QRdx 공식 사이트에서만 작동하므로, 비슷하게 만든 가짜 사이트는 패스키를 가로챌 수 없어요.

QRdx에서 패스키는 두 가지 역할을 합니다.

- 로그인 페이지의 **패스키로 계속하기**로 패스키만으로 로그인할 수 있어요.
- 이메일 코드, Google 또는 GitHub<IfAvailable feature="sso">(또는 워크스페이스의 싱글 사인온)</IfAvailable>으로 로그인한 뒤 [2단계 인증](/docs/help/privacy-and-security/two-step-verification)의 두 번째 단계로 사용할 수 있어요.

또한 2단계 인증을 켜거나 끄는 등 계정 보안을 변경하기 전에 [본인임을 확인](/docs/help/privacy-and-security/two-step-verification#confirm-its-you)하는 데도 쓰입니다. 이메일에 접근할 수 없을 때 유용해요.

## 패스키 추가 [#add-a-passkey]

1. **설정** → **프로필 및 보안**으로 이동하세요.
2. **2단계 인증**에서 **패스키 추가**를 클릭하고 본인임을 확인하세요.
3. 제안된 이름(예: "macOS의 Chrome" 같은 브라우저와 시스템 이름)을 그대로 쓰거나 원하는 이름을 입력한 다음 **계속**을 클릭하세요.
4. 브라우저가 패스키를 저장할 위치를 묻고 지문, 얼굴 또는 화면 잠금을 확인합니다.

2단계 인증이 꺼져 있으면 패스키를 추가할 때 2단계 인증이 켜지고, QRdx가 저장해 둘 백업 코드 10개를 보여 드립니다. 패스키가 없을 때 이 코드로 로그인할 수 있어요.

패스키는 사용할 때마다 본인 여부를 확인해야 합니다. 휴대폰, 컴퓨터, 비밀번호 관리자는 지문, 얼굴 또는 화면 잠금으로 확인해요. 보안 키는 PIN을 설정해야 합니다.

패스키를 추가하거나 삭제할 때마다 QRdx가 계정 이메일 주소로 알림을 보냅니다.

## 패스키로 로그인 [#sign-in-with-a-passkey]

로그인 페이지에서 로그인 방법 목록 아래쪽의 **패스키로 계속하기**를 클릭하고 사용할 패스키를 선택하세요. 패스키 로그인은 두 단계를 모두 거친 것으로 처리되므로 QRdx가 다른 것을 요구하지 않습니다.

이메일 입력란에는 패스키가 제안되지 않으니 버튼을 사용하세요.

패스키는 추가한 계정으로만 로그인할 수 있습니다. 계정을 만들 수는 없어요. QRdx를 처음 쓴다면 먼저 Google, GitHub 또는 이메일 코드로 로그인한 뒤 패스키를 추가하세요.

## 패스키를 두 번째 단계로 사용 [#use-a-passkey-as-your-second-step]

2단계 인증을 켜 두었다면 평소처럼 로그인하세요. 그러면 브라우저의 패스키 창이 자동으로 열리고, 본인임을 확인하면 로그인됩니다. 일부 브라우저는 클릭해야 창이 열려요. 그럴 때는 **패스키로 계속하기**를 클릭하세요.

패스키가 없나요? **인증 코드 사용**(인증 앱을 설정한 경우) 또는 **백업 코드 사용**을 클릭하세요.

패스키를 두 번째 단계로 쓸 수 없던 시기에 추가했고 2단계 인증이 꺼져 있다면, 설정에 **패스키를 두 번째 단계로 사용할 수 있어요**라고 표시됩니다. **켜기**를 클릭해 그렇게 사용하세요. 본인임을 확인하고, 패스키로 본인 여부를 확인한 다음, 백업 코드를 저장하면 됩니다.

## 동기화 패스키와 기기 전용 패스키 [#synced-and-device-bound-passkeys]

동기화 패스키는 iCloud 키체인이나 Google 비밀번호 관리자 같은 비밀번호 관리자 또는 클라우드 키체인에 백업됩니다. 해당 계정에 로그인한 모든 기기에서 사용할 수 있어요.

기기 전용 패스키는 패스키를 만든 휴대폰, 컴퓨터 또는 보안 키 한 곳에만 남습니다. 다른 곳에서 로그인하려면 다른 로그인 방법을 쓰거나 그 기기에도 패스키를 추가하세요.

## 패스키 이름 변경 또는 삭제 [#rename-or-remove-a-passkey]

**2단계 인증**에서 패스키 옆의 메뉴를 열고 **이름 바꾸기** 또는 **삭제**를 클릭한 다음 본인임을 확인하세요. 삭제한 패스키는 QRdx에서 즉시 작동하지 않아요. 기기나 비밀번호 관리자에는 그곳에서도 직접 삭제하기 전까지 목록에 남아 있을 수 있습니다.

그 패스키가 유일한 두 번째 단계라면 삭제할 때 2단계 인증이 꺼집니다. 확인하기 전에 QRdx가 알려 드려요.

패스키가 저장된 기기를 잃어버렸나요? 다른 방법으로 로그인한 뒤 해당 패스키를 삭제하세요.

이메일로 받은 코드로 언제든 로그인할 수 있으므로, 마지막 패스키를 삭제해도 계정에 접근하지 못하게 되지는 않아요.
