---
title: "누군가 스캔할 때 QRdx가 기록하는 정보"
description: "동적 QR 코드를 스캔하면 기록되는 데이터, 절대 저장하지 않는 정보, 그리고 보관 기간을 안내합니다."
---

스캔은 동적 QR 코드만 기록합니다. 정적 QR 코드는 콘텐츠를 코드 자체에 담고 있으며 QRdx를 거치지 않습니다.

## 스캔 시 기록되는 정보 [#what-a-scan-records]

- 네트워크를 기반으로 파악한 국가, 지역, 도시
- 기기 유형, 운영체제, 브라우저
- 유입된 사이트(있는 경우)
- 브라우저 언어
- A/B 테스트가 진행 중인 경우 방문자가 본 버전
- 네트워크 주소와 브라우저를 솔트 처리한 일별 해시. 방문자는 하루에 한 번만 집계됩니다.
- 코드 소유자가 [정밀 위치](/docs/precise-location)를 켜고 스캔한 사람이 브라우저에서 허용한 경우에 한해, 약 100 m 단위로 반올림한 위치. 스캔한 사람이 거부하면 아무것도 저장되지 않습니다.

## 절대 저장하지 않는 정보 [#what-it-never-stores]

QRdx는 스캔한 사람의 IP 주소를 저장하지 않습니다. 위의 해시는 IP 주소로 되돌릴 수 없으며 매일 바뀝니다.

봇과 링크 미리보기는 기록되지 않습니다.

## 스캔 기록 보관 기간 [#how-long-scans-are-kept]

스캔 기록은 코드가 존재하는 동안 보관됩니다. 얼마나 오래된 기록까지 볼 수 있는지는 요금제에 따라 달라집니다. 무료는 {facts.freeScanHistoryYears}년이고, Pro와 Business는 전체 기록을 볼 수 있습니다.

코드를 삭제하면 해당 코드의 스캔 기록도 영구적으로 삭제됩니다.

## 스캔하는 사람을 위한 쿠키 [#cookies-for-people-who-scan]

단축 링크나 모바일 페이지처럼 스캔한 사람이 보는 페이지에는 쿠키 배너가 표시되지 않으며, QRdx의 분석 도구나 지원 위젯도 로드되지 않습니다.

QRdx는 이런 페이지에 쿠키를 두 개 설정합니다. 하나는 올바르게 입력한 코드 비밀번호를 6시간 동안 기억합니다. 다른 하나는 코드가 정밀 위치를 요청할 때만 호스팅 페이지를 그 페이지를 연 스캔과 15분 동안 연결하여, 스캔한 사람이 공유한 위치가 해당 스캔에 추가되도록 합니다. 유료 요금제에서는 페이지 소유자가 자신의 페이지에 직접 분석 픽셀을 추가할 수 있습니다.

## QR 코드 스캐너 [#the-qr-code-scanner]

[QRdx 스캐너](/scan)는 스캔 기록을 사용자의 기기에만 보관합니다. 카메라 프레임과 이미지는 기기에서 읽으며 업로드되지 않습니다. Android에서 설치된 스캐너로 공유한 스크린샷도 마찬가지입니다. 링크를 열기 전에 확인할 때는 주소만 검사를 위해 전송되며, QRdx는 이를 보관하지 않습니다.
