---

동적 QR 코드만 스캔을 기록합니다. 정적 QR 코드는 콘텐츠를 코드 자체에 담고 있어서 QRdx를 거치지 않습니다.

## 스캔 시 기록되는 정보 [#what-a-scan-records]

- 네트워크를 기준으로 파악한 국가, 지역, 도시
- 기기 유형, 운영체제, 브라우저
- 유입 사이트(있는 경우)
- 브라우저 언어
- A/B 테스트가 진행 중인 경우, 방문자가 본 버전
- 네트워크 주소와 브라우저를 조합해 매일 솔트를 적용해 만든 해시. 방문자는 하루에 한 번만 집계됩니다.
- 코드 소유자가 [정밀 위치](/docs/precise-location)를 켰고 스캔한 사람이 브라우저에서 허용한 경우에 한해, 약 100m 단위로 반올림한 위치. 거부하면 아무것도 저장하지 않습니다.

## 절대 저장하지 않는 정보 [#what-it-never-stores]

QRdx는 스캔한 사람의 IP 주소를 저장하지 않습니다. 위의 해시는 IP 주소로 되돌릴 수 없고, 매일 바뀝니다.

봇과 링크 미리보기는 기록하지 않습니다.

## 스캔 기록 보관 기간 [#how-long-scans-are-kept]

스캔 기록은 코드가 존재하는 동안 보관됩니다. 플랜에 따라 확인할 수 있는 기간이 달라요. 무료는 90일, Pro는 3년, Business는 무제한입니다.

코드를 삭제하면 해당 코드의 스캔 기록도 영구적으로 삭제됩니다.

## 스캔하는 사람을 위한 쿠키 [#cookies-for-people-who-scan]

단축 링크와 모바일 페이지처럼 스캔한 사람에게 보이는 페이지에는 쿠키 배너가 없고, QRdx의 분석 도구나 지원 위젯도 불러오지 않습니다.

QRdx는 이런 페이지에서 쿠키를 두 개 설정합니다. 하나는 올바르게 입력한 코드 비밀번호를 6시간 동안 기억합니다. 다른 하나는 코드가 정밀 위치를 요청할 때에 한해, 호스팅 페이지를 그 페이지를 연 스캔과 15분 동안 연결해서 스캔한 사람이 공유한 위치가 해당 스캔에 추가되도록 합니다. 유료 플랜에서는 페이지 소유자가 자신의 페이지에 별도의 분석 픽셀을 추가할 수 있습니다.

## QR 코드 스캐너 [#the-qr-code-scanner]

[QRdx 스캐너](/scan)는 스캔 기록을 사용자의 기기에만 보관합니다. 카메라 프레임과 이미지는 기기에서 읽으며 업로드하지 않습니다. Android에서 설치된 스캐너로 공유한 스크린샷도 마찬가지입니다. 링크를 열기 전에 확인할 때는 주소만 검사용으로 전송되고, QRdx는 이를 보관하지 않습니다.
