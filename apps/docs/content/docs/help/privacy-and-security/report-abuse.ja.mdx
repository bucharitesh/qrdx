## 報告する [#report-it]

1. [報告フォーム](/report-abuse)を開きます。アカウントは不要です。
2. コードの短縮リンク、ページのリンク、または7文字の短縮コードを貼り付けます。
3. 理由を選び、詳細があれば入力して送信します。

対応結果を知りたい場合は、メールアドレスを入力してください。入力は任意です。

動的QRコードが開くすべてのページ（パスワードページや「キャンペーン終了」ページを含む）には、このフォームへのリンクがあります。

## その後の流れ [#what-happens-next]

担当者がすべての報告を24〜48時間以内に確認します。ルールに違反しているコードは、全員に対して無効になり、所有者が再び有効にすることはできません。

## 安全のために [#stay-safe]

信頼できないQRコードから開いたページでは、パスワード、カード番号、ワンタイムコードを入力しないでください。

## 静的QRコード [#static-codes]

静的QRコードは内容を直接保持しており、QRdxを経由しないため、こちらで無効にすることはできません。有害なWebサイトは、そのホスティング事業者または[Google Safe Browsing](https://safebrowsing.google.com/safebrowsing/report_phish/)に報告してください。

## コードが無効にされた場合 [#if-your-code-was-switched-off]

誤りだと思われる場合は、件名に「[appeal]」と書き、コードの短縮リンクを添えて [support@qrdx.dev](mailto:support@qrdx.dev) にメールしてください。

詳しくは[不正利用ポリシー](/legal/report-abuse)をご覧ください。
