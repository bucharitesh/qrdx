description: "패스키나 인증 앱으로 모든 로그인에 두 번째 단계를 추가하고, 백업 코드를 보관하고, 휴대폰을 잃어버렸을 때 다시 로그인하는 방법을 알아보세요."
---

2단계 인증(2FA라고도 해요)은 로그인에 두 번째 단계를 추가해요. 이메일 코드, Google 또는 GitHub<IfAvailable feature="sso"> (또는 워크스페이스의 싱글 사인온)</IfAvailable>로 로그인하고 나면 QRdx가 <IfAvailable feature="passkeys">패스키 또는 </IfAvailable>인증 앱의 6자리 코드를 요청해요. 다른 사람이 내 이메일이나 Google 계정에 접근하더라도 이 단계를 통과하지 못하면 QRdx에 들어올 수 없어요.

<IfAvailable feature="passkeys">
[패스키](/docs/help/privacy-and-security/passkeys)는 지문, 얼굴, 화면 잠금 또는 보안 키로 본인임을 확인해요. QRdx 공식 사이트에서만 작동하므로 비슷하게 만든 가짜 사이트에서는 가져갈 수 없어요.
</IfAvailable>

인증 앱도 사용할 수 있어요. 30초마다 바뀌는 6자리 코드를 보여 주는 앱이면 모두 되고, 대부분의 비밀번호 관리자에 있는 일회용 코드 기능도 포함돼요. QRdx는 두 번째 단계 코드를 이메일이나 문자 메시지로 보내지 않아요.

두 가지를 모두 설정해 두고, 로그인할 때 가까이 있는 것을 사용하면 돼요.

## 켜기 [#turn-it-on]

1. **설정** → **프로필 및 보안**으로 이동해요.
2. **2단계 인증**에서 **켜기**를 클릭하고 [본인 확인](#confirm-its-you)을 해요.
3. 아래 설명대로 두 번째 단계를 설정해요<IfAvailable feature="passkeys">: **패스키** 또는 **인증 앱**을 선택해요</IfAvailable>.
4. 백업 코드 10개를 저장해요. 코드를 복사하거나 텍스트 파일로 다운로드하고, 비밀번호 관리자 같은 안전한 곳에 보관하세요. QRdx는 이 코드를 한 번만 보여 줘요. **백업 코드를 저장했어요**를 체크하고 **완료**를 클릭해요.

<IfAvailable feature="passkeys">
패스키는 제안된 이름(예: "Chrome on macOS"처럼 브라우저와 시스템 이름)을 그대로 쓰거나 원하는 이름을 입력하고, **계속**을 클릭한 다음 브라우저가 패스키를 저장하도록 해요.
</IfAvailable>

인증 앱은 앱으로 QR 코드를 스캔하거나 그 아래에 표시된 키를 입력해요. 앱에 표시된 6자리 코드를 입력하고 **확인**을 클릭해요.

이제 2단계 인증이 켜지고, 계정에 로그인되어 있던 다른 모든 브라우저와 기기는 로그아웃돼요. 각 기기에서는 두 번째 단계와 함께 다시 로그인해야 해요. 2단계 인증을 켠 브라우저는 로그인 상태로 유지돼요.<IfAvailable feature="passkeys"> 나중에 다른 방법을 추가하려면 같은 섹션을 사용하세요. 이미 가지고 있는 백업 코드는 그대로 유지되고, 로그아웃되는 사람도 없어요.</IfAvailable>

<IfAvailable feature="passkeys">
2단계 인증에서 패스키를 쓸 수 있게 되기 전에 패스키를 추가했다면, 설정에 **패스키를 두 번째 단계로 사용할 수 있어요**라고 표시돼요. **켜기**를 클릭하고 본인 확인을 한 다음, 그 패스키로 본인임을 확인하고 백업 코드를 저장하세요. 이때 다른 기기도 로그아웃돼요.
</IfAvailable>

2단계 인증을 켜거나 끌 때, 방법을 추가하거나 삭제할 때, 새 백업 코드를 만들 때, 백업 코드를 사용할 때마다 계정의 이메일 주소로 알림을 보내요. 지원팀에 2단계 인증 해제를 요청한 경우에도 이메일을 보내요.

## 2단계 인증으로 로그인하기 [#sign-in-with-it]

평소처럼 로그인하세요. 그러면 QRdx가 두 번째 단계를 요청해요.

<IfAvailable feature="passkeys">
패스키가 있으면 브라우저의 패스키 창이 자동으로 열려요. 일부 브라우저는 클릭해야 열리는데, 그럴 때는 **패스키로 계속**을 클릭하세요. 창을 닫았거나 시간이 초과되었다면 다시 시도하거나 다른 방법을 선택하세요.
</IfAvailable>

단계 아래의 **인증 코드 사용**과 **백업 코드 사용**을 누르면 가지고 있는 다른 방법으로 전환돼요. QRdx는 이 브라우저에서 마지막으로 사용한 방법을 기억하고 다음에 그 방법으로 시작해요.

인증 코드는 30초마다 바뀌므로 코드가 거부되면 다음 코드가 나올 때까지 기다리세요.

로그인 단계마다 잘못된 코드를 5번까지 입력할 수 있어요<IfAvailable feature="passkeys">. 확인에 실패한 패스키도 1번으로 계산돼요</IfAvailable>. 그 이후에는 로그인을 처음부터 다시 시작해야 해요. 연속으로 10번 잘못 입력하면 QRdx는 15분 동안 내 계정의 코드를 받지 않아요.

이 단계는 10분 후에 만료돼요. 만료되면 다시 로그인하세요.

## 백업 코드 [#backup-codes]

백업 코드는 휴대폰<IfAvailable feature="passkeys">이나 패스키</IfAvailable>가 없을 때 두 번째 단계 대신 사용할 수 있어요. 두 번째 단계에서 **백업 코드 사용**을 클릭하고 코드 하나를 입력하세요. 코드는 `ABCDE-FGH23`처럼 생겼고, 대문자와 2부터 9까지의 숫자로 이루어져 있어요. 헷갈리기 쉬운 0, O, 1, I는 쓰지 않아요. 소문자로 입력해도 되고, 대시는 있어도 없어도 돼요. 각 코드는 한 번만 사용할 수 있어요.

로그인이나 본인 확인에 백업 코드를 사용할 때마다 남은 코드 수를 담아 계정의 이메일 주소로 알림을 보내요. 본인이 아니라면 누군가 내 백업 코드를 가지고 있는 것이니 즉시 지원팀에 문의하세요.

설정에서 남은 코드 수를 확인할 수 있어요. 2개 이하로 남으면 새 코드를 만드세요. **새 코드**를 클릭하고 본인 확인을 하면 돼요. 이전 코드는 더 이상 사용할 수 없어요.

## 신뢰하는 기기 [#trusted-devices]

두 번째 단계에서 **이 기기에서 30일 동안 다시 묻지 않기**를 체크하면 해당 브라우저에서 30일 동안 이 단계를 건너뛰어요. 내 기기에서만 사용하세요. 2단계 인증을 끄면 신뢰하는 기기가 모두 삭제돼요.

## 2단계 인증을 요구하는 로그인 [#which-sign-ins-ask-for-it]

모든 로그인이에요. 이메일 코드, Google, GitHub<IfAvailable feature="sso">, 워크스페이스 싱글 사인온</IfAvailable>이 모두 해당돼요. 이미 로그인한 브라우저에서 다시 로그인하는 경우도 포함돼요.

<IfAvailable feature="passkeys">
**패스키로 계속**으로 로그인하는 경우는 예외예요. 패스키 로그인은 기기와 지문, 얼굴 또는 화면 잠금이라는 두 가지 요소를 이미 사용하므로 QRdx가 두 번째 단계를 요구하지 않아요. QRdx는 이런 방식으로 본인을 확인하는 패스키만 받아요.
</IfAvailable>

## 방법 변경하기 [#change-your-methods]

**설정** → **프로필 및 보안**의 **2단계 인증**에서 인증 앱을 설정하거나 삭제<IfAvailable feature="passkeys">하고, 패스키를 추가하거나 이름을 바꾸거나 삭제</IfAvailable>할 수 있어요. 변경할 때마다 본인 확인을 요청해요.

마지막 방법을 삭제하면 2단계 인증이 꺼지고 백업 코드도 더 이상 작동하지 않아요. QRdx가 확인하기 전에 이를 알려 줘요.

## 본인 확인 [#confirm-its-you]

계정 보안과 관련된 변경 전에는 로그인한 상태여도 QRdx가 본인 확인을 요청해요. 대상은 다음과 같아요.

- 이메일 주소 변경
- 계정 삭제
- 2단계 인증 켜기 또는 끄기, 새 백업 코드 만들기
- 인증 앱 추가 또는 삭제<IfAvailable feature="passkeys">, 패스키 추가, 이름 변경 또는 삭제</IfAvailable>
- Google 또는 GitHub 계정 연결 또는 연결 해제
- API 키 생성, OAuth 앱 생성 또는 OAuth 앱의 새 클라이언트 시크릿 생성
- **승인** 화면에서 내 QRdx 계정 사용을 요청하는 앱 승인
- 웹훅 엔드포인트 추가, 엔드포인트 URL 변경, 서명 시크릿 표시 또는 교체
- Slack 또는 Discord 알림 웹훅 추가, 또는 스캔이나 폼 응답을 다른 도구로 보내는 연동 연결
- 워크스페이스에서: 워크스페이스 삭제, 멤버 역할 변경, 멤버 제거, 이메일이나 가입 링크로 관리자 초대, [2단계 인증 필수 설정](/docs/help/teams/require-two-step-verification) 또는 해제

<IfAvailable feature="sso">
워크스페이스의 싱글 사인온 연결을 만들거나 편집하거나 확인하거나 삭제할 때, 그리고 싱글 사인온을 필수로 설정할 때도 마찬가지예요.
</IfAvailable>

2단계 인증이 켜져 있으면 <IfAvailable feature="passkeys">패스키, </IfAvailable>인증 앱의 코드 또는 백업 코드로 확인해요. 백업 코드는 사용하면 소진돼요. QRdx는 여기서 이메일로 받은 코드를 제공하지 않으므로, 이메일에 접근하는 것만으로는 보안 설정을 바꿀 수 없어요.

2단계 인증이 꺼져 있으면 다음 중 하나로 확인해요.

- QRdx가 이메일로 보내 준 6자리 코드
- 연결해 둔 Google 또는 GitHub 계정으로 다시 로그인<IfAvailable feature="sso">, 또는 워크스페이스 싱글 사인온이 OIDC를 사용하는 경우 싱글 사인온으로 다시 로그인</IfAvailable>

<IfAvailable feature="passkeys">
패스키가 있다면 패스키로도 확인할 수 있어요.
</IfAvailable>

다시 로그인하면 해당 로그인 화면으로 이동해 계정을 선택하거나 로그인하라고 요청하고, 그다음 같은 페이지로 돌아와요. 자리를 비운 동안에는 변경 내용이 저장되지 않으므로 돌아와서 다시 변경하세요. 연결해 둔 계정을 사용하세요. QRdx는 다른 계정으로 전환하거나 새 계정을 만들지 않아요.

따라서 이메일에 접근할 수 없어도 다른 방법으로 확인할 수 있어요. 어느 방법도 쓸 수 없다면 [이메일 접근 권한을 잃은 경우](/docs/help/account-and-billing/sign-in#lost-access-to-your-email)를 참고하세요.

확인은 해당 브라우저에서 10분 동안 유지되므로 연달아 여러 번 변경해도 한 번만 요청해요.

로그인도 해당 브라우저에서 10분 동안 본인 확인으로 인정돼요. 2단계 인증이 켜져 있다면 두 번째 단계에 답한 로그인<IfAvailable feature="passkeys">이나 **패스키로 계속**을 사용한 로그인</IfAvailable>만 해당하고, 신뢰하는 기기라서 두 번째 단계를 건너뛴 로그인은 해당하지 않아요.<IfAvailable feature="sso"> ID 공급자의 앱 대시보드에서 QRdx를 여는 것도 두 번째 단계에 답하지 않았다면 인정되지 않아요.</IfAvailable>

다른 기기 로그아웃은 본인 확인을 요청하지 않으므로, 다른 사람이 내 계정에 접근했다면 즉시 로그아웃시킬 수 있어요.

## 끄기 [#turn-it-off]

**설정** → **프로필 및 보안**으로 이동하여 **2단계 인증**에서 **끄기**를 클릭하고 본인 확인을 진행해 주세요. 백업 코드와, 인증 앱을 설정했다면 인증 앱 설정이 삭제됩니다.

내가 속한 워크스페이스에서 [2단계 인증을 필수로 요구하는](/docs/help/teams/require-two-step-verification) 경우, 2단계 인증을 다시 켜기 전까지는 해당 워크스페이스에 들어갈 수 없습니다.

## 휴대폰과 백업 코드를 모두 분실한 경우 [#lost-your-phone-and-your-backup-codes]

<IfAvailable feature="passkeys">패스키, </IfAvailable>인증 앱 또는 백업 코드가 아직 있다면 그것으로 로그인한 뒤 설정에서 인증 방법을 변경해 주세요.

2단계 인증에 사용할 수 있는 방법을 모두 잃어버렸다면, 계정에 등록된 이메일 주소로 [support@qrdx.dev](mailto:support@qrdx.dev)에 메일을 보내 상황을 알려 주세요. 저희에게 메일을 보낸 사람이 본인이 아닐 수도 있으므로, 요청이 해당 주소에서 왔음을 확인한 뒤에는 지원팀의 해제 처리가 7일간 보류됩니다.

- **요청이 처리되는 날 해당 주소로 이메일을 보내 드립니다.** 그때까지는 아무것도 바뀌지 않으며, 현재 로그인한 기기에서는 계속 로그인된 상태로 유지됩니다.
- **직접 요청하지 않았다면 중단해 주세요.** 인증 앱이나 백업 코드로 로그인하면 해제가 취소됩니다.<IfAvailable feature="passkeys"> 패스키로 로그인해도 취소되지 않습니다. 이 초기화는 기기를 분실한 경우를 위한 것인데, 패스키가 분실한 기기에 있을 수 있기 때문입니다.</IfAvailable> **설정** → **프로필 및 보안**의 **2단계 인증**에서 **취소**를 클릭하고 [본인 확인](#confirm-its-you)을 하거나, 받은 이메일에 회신해도 됩니다. 취소되면 이메일로 알려 드려요.
- **해당 날짜에 2단계 인증이 꺼집니다.** 인증 앱 설정, 백업 코드, 신뢰하는 기기가 삭제되고,<IfAvailable feature="passkeys"> 패스키는 그대로 유지되며,</IfAvailable> 모든 기기에서 계정이 로그아웃됩니다. 이 사실도 이메일로 알려 드립니다. 이후 평소처럼 로그인한 다음 2단계 인증을 다시 켜 주세요.
