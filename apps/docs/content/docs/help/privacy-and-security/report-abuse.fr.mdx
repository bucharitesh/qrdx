## Le signaler [#report-it]

1. Ouvrez le [formulaire de signalement](/report-abuse). Vous n'avez pas besoin de compte.
2. Collez le lien court du code, le lien de la page ou le code court de 7 caractères.
3. Choisissez un motif, ajoutez des précisions si vous le souhaitez, puis envoyez.

Indiquez votre adresse e-mail si vous souhaitez savoir ce que nous avons fait. C'est facultatif.

Chaque page qu'ouvre un QR code dynamique QRdx, y compris les pages de mot de passe et de « campagne terminée », contient un lien vers le formulaire.

## Ce qui se passe ensuite [#what-happens-next]

Une personne examine chaque signalement sous 24 à 48 heures. Les codes qui enfreignent nos règles sont désactivés pour tout le monde, et leur propriétaire ne peut pas les réactiver.

## Restez prudent [#stay-safe]

Ne saisissez pas de mots de passe, de numéros de carte ni de codes à usage unique sur une page atteinte depuis un QR code auquel vous ne faites pas confiance.

## QR codes statiques [#static-codes]

Un QR code statique contient directement son contenu et ne passe jamais par QRdx : nous ne pouvons donc pas le désactiver. Signalez le site malveillant à son hébergeur ou à [Google Safe Browsing](https://safebrowsing.google.com/safebrowsing/report_phish/).

## Si votre code a été désactivé [#if-your-code-was-switched-off]

Si vous pensez que nous avons commis une erreur, écrivez à [support@qrdx.dev](mailto:support@qrdx.dev) avec « [appeal] » dans l'objet et le lien court du code.

Lisez la [politique complète en matière d'abus](/legal/report-abuse).
