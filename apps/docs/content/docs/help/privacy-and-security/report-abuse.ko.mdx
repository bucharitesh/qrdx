## 신고하기 [#report-it]

1. [신고 양식](/report-abuse)을 엽니다. 계정은 필요하지 않습니다.
2. 코드의 짧은 링크, 페이지 링크 또는 7자리 짧은 코드를 붙여넣습니다.
3. 사유를 선택하고 상세 내용을 추가한 뒤 보냅니다.

처리 결과를 받아보고 싶다면 이메일 주소를 남겨 주세요. 입력하지 않아도 됩니다.

비밀번호 페이지와 "캠페인 종료" 페이지를 포함해, 동적 QRdx 코드가 여는 모든 페이지에는 이 양식으로 연결되는 링크가 있습니다.

## 이후 진행 과정 [#what-happens-next]

담당자가 접수된 모든 신고를 24~48시간 이내에 검토합니다. 규정을 위반한 코드는 모든 사용자에게 비활성화되며, 코드 소유자도 다시 활성화할 수 없습니다.

## 안전하게 사용하기 [#stay-safe]

신뢰할 수 없는 QR 코드를 통해 들어간 페이지에는 비밀번호, 카드 번호, 일회용 코드를 입력하지 마세요.

## 정적 코드 [#static-codes]

정적 QR 코드는 콘텐츠를 코드 자체에 담고 있으며 QRdx를 거치지 않기 때문에 저희가 비활성화할 수 없습니다. 유해한 웹사이트는 해당 사이트의 호스팅 업체나 [Google Safe Browsing](https://safebrowsing.google.com/safebrowsing/report_phish/)에 신고해 주세요.

## 내 코드가 비활성화된 경우 [#if-your-code-was-switched-off]

잘못 처리되었다고 생각하신다면 제목에 "[appeal]"을 넣고 코드의 짧은 링크를 적어 [support@qrdx.dev](mailto:support@qrdx.dev)로 이메일을 보내 주세요.

전체 [악용 정책](/legal/report-abuse)도 읽어 보세요.
