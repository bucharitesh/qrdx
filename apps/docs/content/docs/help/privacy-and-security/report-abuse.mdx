---
title: Report a harmful QR code
description: Report a QRdx code, short link or page that leads to phishing, malware, scams or other harmful content.
---

If a QRdx code, short link or page leads to phishing, malware, a scam or other harmful content, report it and a person will look at it. You don't need an account.

## Report it

1. Open the [report form](/report-abuse). Every page a dynamic QRdx code opens, including the password and "campaign ended" pages, links to it too.
2. Paste the code's short link, the page link or the 7-character short code.
3. Choose a reason and add any details.
4. Leave your email address if you'd like to hear what we did. It's optional.
5. Send the report.

{/* shot: report-abuse-form | the report form with the link field, the reason choice and the optional email | /report-abuse */}

## What happens next

A person reviews every report within 24 to 48 hours. Codes that break our rules are switched off for everyone: scanners see "This QR code is no longer active", and the owner can't switch them back on.

## Stay safe

Don't enter passwords, card numbers or one-time codes on a page you reached from a QR code you don't trust.

## Static codes

A static code holds its content directly and never passes through QRdx, so we can't switch it off. Report the harmful website to its host or to [Google Safe Browsing](https://safebrowsing.google.com/safebrowsing/report_phish/).

## If your code was switched off

If you think we got it wrong, email [support@qrdx.dev](mailto:support@qrdx.dev) with "[appeal]" in the subject and the code's short link. Read the full [abuse policy](/legal/report-abuse).
