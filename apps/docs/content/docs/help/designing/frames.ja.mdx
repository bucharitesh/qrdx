フレームがあると、スキャンしたときに何が得られるのかが伝わります。

## フレームを追加する [#add-a-frame]

1. [Playground](/playground?tab=design&section=frame)で **デザイン** タブを開き、**フレーム** を選びます。
2. フレームを選びます。**クラシック** グループには、Arrow、Standard Box、Square Border、Striked Box、Halloween、Dot Ring など、標準のフレームが入っています。**その他** を開くとすべてのグループを検索付きで表示できます。フレームを選ぶと、それまでのフレームは置き換わります。
3. **ラベル** にテキストを入力するか、用意されたものから選びます。Scan me、Scan for menu、Join Wi-Fi、Leave a review、Follow us、Pay here、Save contact、Download the app から選べます。
4. **フレームの色**、**テキストの色**、**テキストサイズ** を設定します。フレームによっては **2行目** も設定できます。Arrow、Standard Box、Square Border、Dot Ring はコードのドットの色が使われ、Striked Box と Halloween は独自の色のままです。

## コードを図形の中に配置する [#put-the-code-in-a-shape]

同じ選択画面に **図形コード** グループがあります。**Dot circle** と **Heart** は、装飾用のドットで作った円やハートの中にコードを配置します。**Silhouette** は、お好みの形を使います。明るい背景または透明な背景に、暗い色またはべた塗りの図形を置いた PNG、JPEG、SVG をアップロードしてください。保持されるのは輪郭だけで、画像そのものは使われません。

スキャナーが読み取るのは中央のコードだけです。そのため、同じスキャン距離で読み取るには、図形コードを四角いコードより大きく印刷してください。図形はフレームの代わりになるため、一方を選ぶともう一方は解除されます。コードを収めるには細すぎる図形は、メッセージが表示されて使えません。

## フレームがスキャンの妨げになることはありません [#frames-never-hurt-scanning]

フレームはコードの外側に配置されます。コードのどのマスにも重なりません。

フレームのテキストは短くしてください。距離があっても読みやすいのは、3〜4語です。

## フレーム付きでダウンロードする [#download-with-the-frame]

フレームは、どの形式のダウンロードにも含まれます。印刷については、[QRコードをダウンロードして印刷する](/docs/help/getting-started/download-and-print)をご覧ください。
