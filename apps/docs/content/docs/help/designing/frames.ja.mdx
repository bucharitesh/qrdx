フレームを付けると、スキャンして何が得られるかを伝えられます。

## フレームを追加する [#add-a-frame]

1. [Playground](/playground?tab=design&section=frame)で **デザイン** タブを開き、**フレーム** を選びます。
2. フレームのスタイルを選びます。
3. **ラベル** にテキストを入力するか、用意されたものから選びます。Scan me、Scan for menu、Join Wi-Fi、Leave a review、Follow us、Pay here、Save contact、Download the app があります。
4. **フレームの色**、**テキストの色**、**テキストサイズ** を設定します。フレームによっては **2行目** も設定できます。

## コードを形の中に収める [#put-the-code-in-a-shape]

同じセクションの **シェイプコード** では、**Dot circle** と **Heart** を選ぶと、コードを装飾ドットで作った円やハートの中に収められます。**Silhouette** では好きな形を使えます。明るい背景または透明な背景に、暗い色またはベタ塗りの形を置いた PNG、JPEG、SVG をアップロードしてください。使われるのは輪郭だけで、画像そのものは使われません。

スキャナーが読み取るのは中央のコードだけです。同じスキャン距離で読み取るには、シェイプコードを四角いコードより大きく印刷してください。シェイプはフレームの代わりになるため、一方を選ぶともう一方は解除されます。コードを収めるには細すぎる形は、メッセージが表示されて受け付けられません。

## フレームがスキャンの妨げになることはありません [#frames-never-hurt-scanning]

フレームはコードの外側に配置されます。コードのモジュールを覆うことはありません。

フレームのテキストは短くしてください。離れた場所からは、3〜4語が最も読みやすくなります。

## フレーム付きでダウンロードする [#download-with-the-frame]

フレームは、どの形式のダウンロードにも含まれます。印刷については、[QRコードのダウンロードと印刷](/docs/help/getting-started/download-and-print)をご覧ください。
