フレームを付けると、スキャンしたときに何が得られるかが伝わります。

## フレームを追加する [#add-a-frame]

1. [Playground](/playground?tab=design&section=frame)で **Design** タブを開き、**Frame** を選びます。
2. フレームを選びます。**Classic** グループには、Arrow、Standard Box、Square Border、Striked Box、Halloween などの標準フレームがあります。**More** を開くと、すべてのグループを検索しながら探せます。フレームを選ぶと、それまで選んでいたフレームは置き換わります。
3. **Label** にテキストを入力するか、用意されたものから選びます。Scan me、Scan for menu、Join Wi-Fi、Leave a review、Follow us、Pay here、Save contact、Download the app から選べます。
4. **Frame color**、**Text color**、**Text size** を設定します。フレームによっては **Second line** も使えます。Arrow、Standard Box、Square Border は、代わりにコードのドットの色が使われます。Striked Box と Halloween は、それぞれ独自の色のままです。

## コードを形の中に配置する [#put-the-code-in-a-shape]

同じ選択画面に **Shaped codes** グループがあります。**Dot circle** と **Heart** は、装飾用のドットで作った円またはハートの中にコードを配置します。**Silhouette** では、お好みの形を使えます。明るい背景または透明な背景に、暗い色またはベタ塗りの形を置いた PNG、JPEG、SVG をアップロードしてください。保持されるのは輪郭だけで、画像そのものは使われません。

スキャナーが読み取るのは中央のコードだけです。同じスキャン距離で読み取れるようにするには、形付きのコードを正方形のコードより大きく印刷してください。形はフレームの代わりになるため、一方を選ぶともう一方は解除されます。コードを収めるには細すぎる形は、メッセージが表示されて使用できません。

## フレームがスキャンの妨げになることはありません [#frames-never-hurt-scanning]

フレームはコードの外側に配置されます。コードのマスを覆うことはありません。

フレームのテキストは短くしてください。3〜4語なら、離れた場所からでも読みやすくなります。

## フレーム付きでダウンロードする [#download-with-the-frame]

フレームは、どの形式のダウンロードにも含まれます。印刷については、[QRコードのダウンロードと印刷](/docs/help/getting-started/download-and-print)をご覧ください。
