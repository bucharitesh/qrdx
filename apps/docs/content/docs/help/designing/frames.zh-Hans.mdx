边框能告诉人们扫描之后会得到什么。

## 添加边框 [#add-a-frame]

1. 在 [Playground](/playground?tab=design&section=frame) 中，打开 **Design** 标签页，然后选择 **Frame**。
2. 选择一种边框。**Classic** 分组中是内置边框；**More** 会展开所有分组，并支持搜索。
3. 在 **Label** 中输入文字，或选择现成的文案：Scan me、Scan for menu、Join Wi-Fi、Leave a review、Follow us、Pay here、Save contact 或 Download the app。
4. 设置 **Frame color**、**Text color** 和 **Text size**。部分边框还有 **Second line**。

## 把二维码放进形状里 [#put-the-code-in-a-shape]

同一个选择器中还有 **Shaped codes** 分组。**Dot circle** 和 **Heart** 会把二维码放进由装饰性圆点组成的圆形或心形中。**Silhouette** 可以填充你自己的形状：上传一张 PNG、JPEG 或 SVG 图片，图中需有深色或实心的形状，背景为浅色或透明。系统只保留形状的轮廓，不会保留图片本身。

扫描器只读取中间的二维码，因此在相同的扫描距离下，带形状的二维码应比方形二维码打印得更大。形状会取代边框：选择其中一个，另一个就会被清除。如果形状太细，容不下二维码，系统会拒绝并给出提示。

## 边框不会影响扫描 [#frames-never-hurt-scanning]

边框位于二维码之外，不会遮住二维码的任何方块。

边框上的文字要简短。三四个词在远处最容易看清。

## 带边框下载 [#download-with-the-frame]

边框是每一种格式下载文件的一部分。关于打印，请参阅[下载并打印二维码](/docs/help/getting-started/download-and-print)。
