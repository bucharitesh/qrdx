边框能让人们在扫描之前就知道会得到什么。

## 添加边框 [#add-a-frame]

1. 在 [Playground](/playground?tab=design&section=frame) 中，打开 **Design** 标签页，然后选择 **Frame**。
2. 选择一种边框样式。
3. 在 **Label** 中输入文字，也可以选择现成的文案：扫我、扫码看菜单、加入 Wi-Fi、留下评价、关注我们、在此付款、保存联系人或下载应用。
4. 设置 **Frame color**、**Text color** 和 **Text size**。部分边框还提供 **Second line**。

## 把二维码放进形状里 [#put-the-code-in-a-shape]

在同一区域的 **Shaped code** 下，**Dot circle** 和 **Heart** 可以把二维码放进由装饰性圆点组成的圆形或心形中。**Silhouette** 则用你自己的形状来填充：上传一张 PNG、JPEG 或 SVG 图片，图中是深色或实心的形状，背景为浅色或透明。系统只保留它的轮廓，不会保留图片本身。

扫描器只读取中间的二维码，所以在相同的扫描距离下，带形状的二维码要比方形二维码印得更大。形状会取代边框：选择其中一个，另一个就会被清除。如果形状太细，容纳不下二维码，系统会拒绝并给出提示。

{/* end shaped codes */}

## 边框不会影响扫描 [#frames-never-hurt-scanning]

边框位于二维码之外，不会遮挡二维码的任何方块。

边框文字要简短。三四个字在远处看起来最清楚。

## 连同边框一起下载 [#download-with-the-frame]

边框是每一种格式的下载文件的一部分。关于打印，请参阅[下载与打印二维码](/docs/help/getting-started/download-and-print)。
