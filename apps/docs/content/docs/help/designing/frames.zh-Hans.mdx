边框能让人在扫描之前就知道会得到什么。

## 添加边框 [#add-a-frame]

1. 在 [Playground](/playground?tab=design&section=frame) 中，打开 **Design** 标签页，然后选择 **Frame**。
2. 选择一个边框。**Classic** 分组包含内置边框，其中有 Arrow、Standard Box、Square Border、Striked Box、Halloween 和 Dot Ring；**More** 会展开所有分组，并支持搜索。选择新边框会替换你之前选的边框。
3. 在 **Label** 中输入文字，或选择现成的文案：Scan me、Scan for menu、Join Wi-Fi、Leave a review、Follow us、Pay here、Save contact 或 Download the app。
4. 设置 **Frame color**、**Text color** 和 **Text size**。部分边框还有 **Second line**。Arrow、Standard Box、Square Border 和 Dot Ring 会采用二维码圆点的颜色，而 Striked Box 和 Halloween 则保留自己的颜色。

## 把二维码放进图形中 [#put-the-code-in-a-shape]

同一个选择器里有 **Shaped codes** 分组。**Dot circle** 和 **Heart** 会把二维码放进由装饰性圆点组成的圆形或心形中。**Silhouette** 可以填充你自己的图形：上传 PNG、JPEG 或 SVG 文件，图形为深色或纯色，背景为浅色或透明。只会保留图形的轮廓，不会保留图片本身。

扫描器只读取中间的二维码，所以在相同扫描距离下，带图形的二维码打印时要比方形二维码更大。图形会取代边框：选择其中一个，另一个就会被清除。如果图形太细，容不下二维码，系统会拒绝并给出提示。

## 边框不会影响扫描 [#frames-never-hurt-scanning]

边框位于二维码之外，不会遮盖二维码的任何方块。

边框文字要简短。三四个字（词）在远处最容易看清。

## 带边框下载 [#download-with-the-frame]

边框是每一种格式下载内容的一部分。打印方面，请参阅[下载并打印二维码](/docs/help/getting-started/download-and-print)。
