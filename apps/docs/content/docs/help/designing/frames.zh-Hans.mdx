边框能让人们在扫描之前就知道会得到什么。

## 添加边框 [#add-a-frame]

1. 在 [Playground](/playground?tab=design&section=frame) 中，打开 **Design** 标签页，然后选择 **Frame**。
2. 选择一个边框。可以按名称搜索，也可以选择一个分组：**Classic** 包含内置边框，如 Arrow、Standard Box、Square Border、Striked Box、Halloween 和 Dot Ring。选择新边框会替换你之前选的边框。如果想使用自己的设计图，请先登录，然后点击搜索框旁边的 **Upload SVG**：SVG 中的形状和颜色会变成边框。
3. 在 **Label** 中输入文字，或者选择现成的文案：Scan me、Scan for menu、Join Wi-Fi、Leave a review、Follow us、Pay here、Save contact 或 Download the app。
4. 设置 **Frame color**、**Text color** 和 **Text size**。部分边框还有 **Second line**。Arrow、Standard Box、Square Border 和 Dot Ring 会采用二维码圆点的颜色，Striked Box 和 Halloween 则保留自带的颜色。

## 把二维码放进形状里 [#put-the-code-in-a-shape]

同一个选择器中还有 **Shaped codes** 分组。**Dot circle** 和 **Heart** 会把二维码放进由装饰圆点组成的圆形或心形中。**Silhouette** 会填充你自己的形状：上传 PNG、JPEG 或 SVG，图片中应是深色或实心的形状，背景为浅色或透明。系统只保留它的轮廓，不会保留图片本身。

扫描器只会读取中间的二维码，因此在相同的扫描距离下，带形状的二维码要比方形二维码印得更大。形状会取代边框：选择其中一个，另一个就会被清除。如果形状太细，容纳不下二维码，系统会拒绝并给出提示。

## 边框不会影响扫描 [#frames-never-hurt-scanning]

边框位于二维码之外，不会遮挡二维码的任何方块。

边框文字要简短。三四个词在远处最容易看清。

## 带边框下载 [#download-with-the-frame]

边框会包含在每一种格式的下载文件中。关于打印，请参阅[下载并打印二维码](/docs/help/getting-started/download-and-print)。
