---
title: "Choisir des couleurs qui se scannent"
description: "Gardez un code foncé sur un fond clair, un contraste fort, et utilisez les dégradés avec précaution."
---

Les scanners recherchent des carrés foncés sur un fond clair. La plupart des problèmes de couleur viennent du non-respect de cette règle.

## Modifier les couleurs [#change-the-colors]

Dans le [Playground](/playground?tab=design&section=colors), ouvrez l'onglet **Design**, puis **Colors**.

- **Background** est la zone située derrière le code.
- **Foreground** colore les petits carrés qui contiennent vos données.
- **Eyes** colore les trois grands carrés des coins.
- **Dots** colore le centre de chaque carré de coin.

Chaque couleur peut être unie, en dégradé linéaire ou en dégradé radial. Les palettes situées sous les quatre couleurs les définissent toutes en une seule fois.

## Règles pour garder un code scannable [#rules-that-keep-a-code-scannable]

- **Code foncé, fond clair.** Les codes clairs sur fond foncé échouent dans certaines applications d'appareil photo.
- **Contraste fort.** Visez un rapport de contraste de 4.5:1 ou plus entre le code et le fond.
- **Des dégradés qui restent foncés.** Un dégradé convient si chacune de ses couleurs est assez foncée par rapport au fond.
- **Fond uni.** Une photo chargée derrière le code le rend plus difficile à lire.

## Vérifier le contraste [#check-the-contrast]

Le vérificateur de contraste, dans la barre d'outils au-dessus de l'aperçu, affiche le rapport pour vos couleurs. Il signale les paires inférieures à 4.5:1.

Le **Scan score** sous l'aperçu vérifie aussi le contraste, ainsi que la taille, la zone de silence et le logo. Voir [Vérifier un design avec le scan score](/docs/help/designing/scan-score).
