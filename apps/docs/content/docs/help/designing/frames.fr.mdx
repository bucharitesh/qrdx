Un cadre indique aux gens ce qu'ils obtiennent en scannant.

## Ajouter un cadre [#add-a-frame]

1. Dans le [Playground](/playground?tab=design&section=frame), ouvrez l'onglet **Design**, puis **Cadre**.
2. Choisissez un cadre. Le groupe **Classique** contient les cadres intégrés, dont Flèche, Boîte standard, Bordure carrée, Boîte barrée, Halloween et Anneau de points ; **Plus** ouvre tous les groupes, avec une recherche. Choisir un cadre remplace celui que vous aviez.
3. Saisissez votre texte dans **Libellé**, ou choisissez-en un prêt à l'emploi : Scannez-moi, Scannez pour le menu, Rejoignez le Wi-Fi, Laissez un avis, Suivez-nous, Payez ici, Enregistrez le contact ou Téléchargez l'appli.
4. Réglez la **Couleur du cadre**, la **Couleur du texte** et la **Taille du texte**. Certains cadres proposent aussi une **Deuxième ligne**. Flèche, Boîte standard, Bordure carrée et Anneau de points prennent à la place la couleur des points du code, tandis que Boîte barrée et Halloween gardent leurs propres couleurs.

## Placer le code dans une forme [#put-the-code-in-a-shape]

Le même sélecteur contient un groupe **Codes en forme**. **Cercle de points** et **Cœur** placent le code dans un cercle ou un cœur de points décoratifs. **Silhouette** remplit une forme de votre choix : importez un PNG, un JPEG ou un SVG contenant une forme sombre ou pleine sur un fond clair ou transparent. Seul son contour est conservé, jamais l'image.

Les lecteurs ne lisent que le code au centre : imprimez donc un code en forme plus grand qu'un code carré pour la même distance de scan. Une forme remplace le cadre : en choisir une efface l'autre. Une forme trop fine pour contenir le code est refusée avec un message.

{/* end shaped codes */}

## Les cadres n'altèrent jamais le scan [#frames-never-hurt-scanning]

Les cadres se placent à l'extérieur du code. Ils ne recouvrent jamais aucun de ses carrés.

Gardez un texte de cadre court. Trois ou quatre mots se lisent le mieux de loin.

## Télécharger avec le cadre [#download-with-the-frame]

Le cadre fait partie de chaque téléchargement, dans tous les formats. Pour l'impression, consultez [Télécharger et imprimer un QR code](/docs/help/getting-started/download-and-print).
