Un cadre indique aux utilisateurs ce qu'ils obtiennent en scannant.

## Ajouter un cadre [#add-a-frame]

1. Dans le [Playground](/playground?tab=design&section=frame), ouvrez l'onglet **Design**, puis **Cadre**.
2. Choisissez un cadre. Le groupe **Classique** contient les cadres intégrés, dont Flèche, Boîte standard, Bordure carrée, Boîte barrée et Halloween ; **Plus** ouvre tous les groupes, avec une recherche. Choisir un cadre remplace celui que vous aviez.
3. Saisissez votre texte dans **Libellé**, ou choisissez-en un prêt à l'emploi : Scannez-moi, Scannez pour le menu, Rejoindre le Wi-Fi, Laissez un avis, Suivez-nous, Payez ici, Enregistrer le contact ou Téléchargez l'application.
4. Réglez la **Couleur du cadre**, la **Couleur du texte** et la **Taille du texte**. Certains cadres ont aussi une **Deuxième ligne**. Flèche, Boîte standard et Bordure carrée prennent à la place la couleur des points du code, tandis que Boîte barrée et Halloween gardent leurs propres couleurs.

## Placer le code dans une forme [#put-the-code-in-a-shape]

Le même sélecteur comporte un groupe **Codes en forme**. **Cercle de points** et **Cœur** placent le code dans un cercle ou un cœur de points décoratifs. **Silhouette** remplit une forme de votre choix : importez un fichier PNG, JPEG ou SVG avec une forme sombre ou pleine sur un fond clair ou transparent. Seul son contour est conservé, jamais l'image.

Les lecteurs ne lisent que le code au centre : imprimez donc un code en forme plus grand qu'un code carré pour la même distance de scan. Une forme prend la place d'un cadre : en choisir une désactive l'autre. Une forme trop fine pour contenir le code est refusée avec un message.

{/* end shaped codes */}

## Les cadres ne nuisent jamais au scan [#frames-never-hurt-scanning]

Les cadres se placent à l'extérieur du code. Ils ne recouvrent jamais aucun de ses carrés.

Gardez le texte du cadre court. Trois ou quatre mots se lisent le mieux de loin.

## Télécharger avec le cadre [#download-with-the-frame]

Le cadre fait partie de chaque téléchargement, dans tous les formats. Pour l'impression, consultez [Télécharger et imprimer un QR code](/docs/help/getting-started/download-and-print).
