Un cadre indique aux gens ce qu'ils obtiennent en scannant.

## Ajouter un cadre [#add-a-frame]

1. Dans le [Playground](/playground?tab=design&section=frame), ouvrez l'onglet **Design**, puis **Cadre**.
2. Choisissez un cadre. Recherchez-le par nom ou choisissez un groupe : **Classique** contient les cadres intégrés, dont Arrow, Standard Box, Square Border, Striked Box, Halloween et Dot Ring. Choisir un cadre remplace celui que vous aviez. Pour utiliser votre propre illustration, connectez-vous et choisissez **Importer un SVG** à côté de la recherche : les formes et les couleurs du SVG deviennent un cadre.
3. Saisissez votre texte dans **Libellé**, ou choisissez-en un prêt à l'emploi : Scannez-moi, Scannez pour le menu, Rejoignez le Wi-Fi, Laissez un avis, Suivez-nous, Payez ici, Enregistrez le contact ou Téléchargez l'application.
4. Réglez la **Couleur du cadre**, la **Couleur du texte** et la **Taille du texte**. Certains cadres ont aussi une **Deuxième ligne**. Arrow, Standard Box, Square Border et Dot Ring prennent à la place la couleur des points du code, tandis que Striked Box et Halloween gardent leurs propres couleurs.

## Placer le code dans une forme [#put-the-code-in-a-shape]

Le même sélecteur contient un groupe **Codes en forme**. **Dot circle** et **Heart** placent le code dans un cercle ou un cœur de points décoratifs. **Silhouette** remplit une forme de votre choix : importez un PNG, un JPEG ou un SVG avec une forme sombre ou pleine sur un fond clair ou transparent. Seul son contour est conservé, jamais l'image.

Les lecteurs ne lisent que le code au centre : imprimez donc un code en forme plus grand qu'un code carré pour la même distance de scan. Une forme prend la place d'un cadre : en choisir une supprime l'autre. Une forme trop fine pour contenir le code est refusée avec un message.

## Les cadres ne nuisent jamais au scan [#frames-never-hurt-scanning]

Les cadres se placent à l'extérieur du code. Ils ne recouvrent jamais aucun de ses carrés.

Gardez un texte de cadre court. Trois ou quatre mots se lisent le mieux de loin.

## Télécharger avec le cadre [#download-with-the-frame]

Le cadre fait partie de chaque téléchargement, quel que soit le format. Pour l'impression, consultez [Télécharger et imprimer un QR code](/docs/help/getting-started/download-and-print).
