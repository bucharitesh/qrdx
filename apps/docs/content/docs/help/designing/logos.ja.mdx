## ロゴを追加する [#add-your-logo]

1. [Playground](/playground?tab=design&section=logo)で**デザイン**タブを開き、**ロゴ**を選びます。
2. **中央にロゴを表示**をオンにします。
3. **クイックアイコン**から選ぶか、**ブランドロゴ**でブランドを選ぶか、**ロゴをアップロード**をクリックします。
4. あとで変更するには、**置き換え**または**削除**をクリックします。

ロゴには、1 MB までの PNG、JPG、WebP、SVG ファイルを使用できます。透過 PNG または SVG がもっときれいに表示されます。

## ブランドのロゴを使う [#use-a-brands-logo]

**ブランドロゴ**を開くと、[Simple Icons](https://simpleicons.org)の{facts.brandLogos}ブランドのギャラリーが表示されます。Instagram、WhatsApp、PayPal、Spotify、Google Maps、各アプリストアなど、数多くのブランドがそろっています。人気のブランドが先頭に表示され、名前で検索することもできます。

- **カラー**：ブランド本来の色、黒、白から選べます。
- **プレート**：ロゴの背後に置く単色の図形です。白いロゴには常にブランドカラーのプレートが付き、非常に明るいブランドカラーの場合も同様です。

ロゴはアップロードした場合と同じようにデザインの中に保存されるため、コードが外部からロゴを読み込むことはありません。サイズ、形、プレートは**ロゴオプション**で変更できます。

各ブランドのマークは、それぞれの所有者に帰属します。ブランドへ誘導する目的、たとえば自分の Instagram プロフィールへの案内などに使用してください。一部のブランドは Simple Icons にマークの削除を依頼したため、ギャラリーには含まれていません。

## エラー訂正を「高」に設定する [#set-error-correction-to-high]

ロゴはコードの一部のマスを覆います。エラー訂正は、コードをスキャンするときにそのマスを復元する機能です。

**デザイン**タブで**エラー訂正**を開き、ロゴを使うときは必ず**高**を選んでください。高にすると、コードの最大 30% が覆われていても読み取れます。

## スコアが下がった場合 [#if-the-score-drops]

ロゴのサイズは QRdx が自動で調整します。ロゴを追加した後に**スキャンスコア**が下がった場合は、**エラー訂正**が**高**に設定されているか確認してください。

それでも読み取りにくいときは、すべてのマスをそのまま残す **Logo QR** を試してください。

## ロゴをドットの中に入れたい場合 [#want-the-logo-in-the-dots-instead]

**Logo QR** は、ロゴを上に重ねるのではなく、ロゴの形の内側にドットを描きます。詳しくは[ロゴや写真をコードに溶け込ませる](/docs/help/designing/art)をご覧ください。
