Playgroundのすべてのデザインに、0〜100の**スキャンスコア**が表示されます。プレビューの下に「スキャンスコア 92 · Great」のように表示されます。

## スコアの意味 [#what-the-score-means]

- **Great**（85以上）：そのまま印刷できます。
- **OK**（65〜84）：スキャンできるはずですが、警告を確認してください。
- **Risky**（65未満）：×印が付いたチェック項目を修正してください。
- **Fails**：テストでコードをデコードできなかったか、コントラストが低すぎます。印刷しないでください。

## 修正点を確認する [#see-what-to-fix]

スコアをクリックします。**Will it scan?** パネルに、すべてのチェック項目が一覧で表示されます。失敗した項目が先頭に並びます。

スコアでは次の項目をチェックします。

- **デコード**：カメラのようなぼかしをかけた状態で、小さいサイズでもコードを読み取れるかを確認します。
- **コントラスト**：コードと背景の明暗比は4.5:1以上にしてください。
- **明るい背景に暗いコード**：明るい背景に暗いコードの組み合わせは、より多くのアプリでスキャンできます。
- **ロゴのサイズ**：ロゴが、誤り訂正で復元できる範囲を超えて覆ってはいけません。
- **アイの形**：円形や波形のアイは、一部のスキャナーアプリでは読み取れません。
- **クリアスペース**：コードの周囲の空白の余白です。4モジュール分が理想的です。

## 簡単な修正方法 [#quick-fixes]

- コントラストが低い：コードを暗くするか、背景を明るくします。[スキャンできる色を選ぶ](/docs/help/designing/colors-and-contrast)をご覧ください。
- ロゴが大きすぎる：**誤り訂正**を**高**に設定します。[ロゴを追加する](/docs/help/designing/logos)をご覧ください。
- アイ：四角、角丸、歯車のいずれかのアイに切り替えます。
- クリアスペース：**余白**を**標準**または**大**に設定します。

## 印刷したコードを確認する [#check-a-printed-code]

スコアは画面上のデザインをテストします。すでに印刷したコードをテストするには、写真を撮って[スキャンチェッカー](/tools/scan-checker)にドロップしてください。画像がお使いのデバイスの外に送信されることはありません。
