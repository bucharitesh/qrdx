프레임은 스캔하면 무엇을 볼 수 있는지 사람들에게 알려 줍니다.

## 프레임 추가하기 [#add-a-frame]

1. [Playground](/playground?tab=design&section=frame)에서 **Design** 탭을 열고 **Frame**을 선택해요.
2. 프레임을 고르세요. **Classic** 그룹에 기본 프레임이 있고, **More**를 누르면 검색과 함께 모든 그룹이 열려요.
3. **Label**에 문구를 입력하거나 준비된 문구 중에서 고르세요: Scan me, Scan for menu, Join Wi-Fi, Leave a review, Follow us, Pay here, Save contact, Download the app.
4. **Frame color**, **Text color**, **Text size**를 설정해요. 일부 프레임에는 **Second line**도 있어요.

## 코드를 도형 안에 넣기 [#put-the-code-in-a-shape]

같은 선택 창에 **Shaped codes** 그룹이 있습니다. **Dot circle**과 **Heart**는 장식용 점으로 만든 원이나 하트 안에 코드를 넣어 줍니다. **Silhouette**은 직접 만든 도형을 채웁니다. 밝거나 투명한 배경에 어둡거나 단색인 도형이 있는 PNG, JPEG, SVG를 업로드하세요. 윤곽만 사용하며 그림 자체는 사용하지 않습니다.

스캐너는 가운데에 있는 코드만 읽습니다. 따라서 같은 스캔 거리를 원한다면 도형 코드를 정사각형 코드보다 크게 인쇄하세요. 도형은 프레임을 대신합니다. 하나를 고르면 다른 하나는 해제됩니다. 코드를 담기에 너무 얇은 도형은 메시지와 함께 거부됩니다.

## 프레임은 스캔에 영향을 주지 않습니다 [#frames-never-hurt-scanning]

프레임은 코드 바깥에 놓입니다. 코드의 어떤 사각형도 가리지 않습니다.

프레임 문구는 짧게 유지하세요. 멀리서는 서너 단어가 가장 잘 읽힙니다.

## 프레임과 함께 다운로드하기 [#download-with-the-frame]

프레임은 모든 형식의 모든 다운로드에 포함됩니다. 인쇄에 관해서는 [QR 코드 다운로드 및 인쇄하기](/docs/help/getting-started/download-and-print)를 참고하세요.
