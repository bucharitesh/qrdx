프레임은 스캔하면 무엇을 얻을 수 있는지 사람들에게 알려 줍니다.

## 프레임 추가하기 [#add-a-frame]

1. [Playground](/playground?tab=design&section=frame)에서 **디자인** 탭을 열고 **프레임**을 선택해요.
2. 프레임을 고르세요. 이름으로 검색하거나 그룹을 선택할 수 있습니다. **클래식**에는 Arrow, Standard Box, Square Border, Striked Box, Halloween, Dot Ring을 포함한 기본 프레임이 있습니다. 프레임을 고르면 기존에 사용하던 프레임이 바뀝니다. 직접 만든 아트워크를 사용하려면 로그인한 뒤 검색창 옆의 **SVG 업로드**를 선택하세요. SVG의 도형과 색상이 프레임이 됩니다.
3. **라벨**에 문구를 입력하거나 준비된 문구를 고르세요. Scan me, Scan for menu, Join Wi-Fi, Leave a review, Follow us, Pay here, Save contact, Download the app 중에서 선택할 수 있습니다.
4. **프레임 색상**, **텍스트 색상**, **텍스트 크기**를 설정하세요. 일부 프레임에는 **두 번째 줄**도 있습니다. Arrow, Standard Box, Square Border, Dot Ring은 대신 코드 점의 색상을 따르고, Striked Box와 Halloween은 자체 색상을 유지합니다.

## 코드를 도형 안에 넣기 [#put-the-code-in-a-shape]

같은 선택기에 **도형 코드** 그룹이 있습니다. **Dot circle**과 **Heart**는 코드를 장식용 점으로 만든 원이나 하트 안에 넣어 줍니다. **Silhouette**는 직접 만든 도형을 채웁니다. 밝거나 투명한 배경에 어둡거나 단색인 도형이 있는 PNG, JPEG, SVG를 업로드하세요. 윤곽선만 사용되며 그림 자체는 사용되지 않습니다.

스캐너는 가운데 있는 코드만 읽으므로, 같은 스캔 거리를 유지하려면 도형 코드를 정사각형 코드보다 크게 인쇄하세요. 도형은 프레임을 대신합니다. 하나를 고르면 다른 하나는 해제됩니다. 코드를 담기에 너무 얇은 도형은 메시지와 함께 거부됩니다.

## 프레임은 스캔에 영향을 주지 않아요 [#frames-never-hurt-scanning]

프레임은 코드 바깥에 놓입니다. 코드의 어떤 사각형도 가리지 않습니다.

프레임 문구는 짧게 유지하세요. 멀리서는 서너 단어가 가장 읽기 좋습니다.

## 프레임 포함해서 다운로드하기 [#download-with-the-frame]

프레임은 모든 형식의 다운로드에 포함됩니다. 인쇄에 대해서는 [QR 코드 다운로드 및 인쇄하기](/docs/help/getting-started/download-and-print)를 참고하세요.
