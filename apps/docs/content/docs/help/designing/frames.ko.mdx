프레임은 사람들이 스캔하면 무엇을 얻는지 알려 줍니다.

## 프레임 추가하기 [#add-a-frame]

1. [Playground](/playground?tab=design&section=frame)에서 **디자인** 탭을 열고 **프레임**을 선택해요.
2. 프레임을 고릅니다. **Classic** 그룹에는 Arrow, Standard Box, Square Border, Striked Box, Halloween을 포함한 기본 프레임이 있고, **더 보기**를 누르면 검색과 함께 모든 그룹이 열립니다. 프레임을 고르면 기존에 선택한 프레임이 바뀝니다.
3. **라벨**에 문구를 입력하거나 준비된 문구를 고르세요: Scan me, Scan for menu, Join Wi-Fi, Leave a review, Follow us, Pay here, Save contact, Download the app.
4. **프레임 색상**, **텍스트 색상**, **텍스트 크기**를 설정해요. 일부 프레임에는 **두 번째 줄**도 있습니다. Arrow, Standard Box, Square Border는 대신 코드 점의 색상을 따르고, Striked Box와 Halloween은 자체 색상을 유지합니다.

## 코드를 도형 안에 넣기 [#put-the-code-in-a-shape]

같은 선택 창에 **Shaped codes** 그룹이 있습니다. **Dot circle**과 **Heart**는 코드를 장식용 점으로 만든 원이나 하트 안에 넣어요. **Silhouette**는 직접 만든 도형을 채웁니다. 밝거나 투명한 배경에 어둡거나 단색인 도형이 있는 PNG, JPEG 또는 SVG를 업로드하세요. 윤곽선만 사용하고 그림은 사용하지 않습니다.

스캐너는 가운데에 있는 코드만 읽으므로, 같은 스캔 거리를 원한다면 도형 코드를 사각형 코드보다 크게 인쇄하세요. 도형은 프레임을 대신합니다. 하나를 고르면 다른 하나는 해제돼요. 코드를 담기에 너무 얇은 도형은 안내 메시지와 함께 거부됩니다.

{/* end shaped codes */}

## 프레임은 스캔을 방해하지 않아요 [#frames-never-hurt-scanning]

프레임은 코드 바깥에 놓입니다. 코드의 어떤 사각형도 가리지 않습니다.

프레임 문구는 짧게 유지하세요. 멀리서는 서너 단어가 가장 잘 읽혀요.

## 프레임과 함께 다운로드하기 [#download-with-the-frame]

프레임은 모든 형식의 모든 다운로드에 포함됩니다. 인쇄에 대해서는 [QR 코드 다운로드 및 인쇄하기](/docs/help/getting-started/download-and-print)를 참고하세요.
