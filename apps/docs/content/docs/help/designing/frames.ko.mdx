프레임은 스캔하면 무엇을 볼 수 있는지 사람들에게 알려 줘요.

## 프레임 추가하기 [#add-a-frame]

1. [Playground](/playground?tab=design&section=frame)에서 **디자인** 탭을 열고 **프레임**을 선택해요.
2. 프레임 스타일을 선택해요.
3. **라벨**에 문구를 직접 입력하거나 준비된 문구 중에서 선택해요. Scan me, Scan for menu, Join Wi-Fi, Leave a review, Follow us, Pay here, Save contact, Download the app이 있어요.
4. **프레임 색상**, **텍스트 색상**, **텍스트 크기**를 설정해요. 일부 프레임에는 **두 번째 줄**도 있어요.

## 코드를 도형 안에 넣기 [#put-the-code-in-a-shape]

같은 섹션의 **도형 코드**에서 **도트 원**과 **하트**를 선택하면 코드가 장식용 점으로 이루어진 원이나 하트 안에 들어가요. **실루엣**은 직접 만든 도형을 채워 줘요. 밝거나 투명한 배경에 어둡거나 단색인 도형이 있는 PNG, JPEG 또는 SVG를 업로드하세요. 윤곽선만 사용하고 그림은 사용하지 않아요.

스캐너는 가운데에 있는 코드만 읽어요. 그래서 같은 스캔 거리에서 읽히게 하려면 도형 코드를 정사각형 코드보다 더 크게 인쇄하세요. 도형은 프레임을 대신해요. 하나를 선택하면 다른 하나는 해제돼요. 코드를 담기에 너무 좁은 도형은 메시지와 함께 거부돼요.

{/* end shaped codes */}

## 프레임은 스캔에 영향을 주지 않아요 [#frames-never-hurt-scanning]

프레임은 코드 바깥에 놓여요. 코드의 어떤 사각형도 가리지 않아요.

프레임 문구는 짧게 유지하세요. 세 단어에서 네 단어 정도가 멀리서도 가장 잘 읽혀요.

## 프레임과 함께 다운로드하기 [#download-with-the-frame]

프레임은 모든 형식의 모든 다운로드에 포함돼요. 인쇄에 대한 내용은 [QR 코드 다운로드 및 인쇄하기](/docs/help/getting-started/download-and-print)를 참고하세요.
