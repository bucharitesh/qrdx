프레임은 스캔하면 무엇을 얻을 수 있는지 사람들에게 알려 줘요.

## 프레임 추가하기 [#add-a-frame]

1. [Playground](/playground?tab=design&section=frame)에서 **Design** 탭을 열고 **Frame**을 선택해요.
2. 프레임을 고르세요. **Classic** 그룹에는 Arrow, Standard Box, Square Border, Striked Box, Halloween, Dot Ring 등 기본 제공 프레임이 있어요. **More**를 누르면 검색과 함께 모든 그룹이 열려요. 프레임을 고르면 기존에 선택한 프레임이 바뀌어요.
3. **Label**에 문구를 입력하거나 준비된 문구 중에서 고르세요: Scan me, Scan for menu, Join Wi-Fi, Leave a review, Follow us, Pay here, Save contact, Download the app.
4. **Frame color**, **Text color**, **Text size**를 설정해요. 일부 프레임에는 **Second line**도 있어요. Arrow, Standard Box, Square Border, Dot Ring은 대신 코드 점의 색을 따르고, Striked Box와 Halloween은 고유한 색을 유지해요.

## 코드를 도형 안에 넣기 [#put-the-code-in-a-shape]

같은 선택기에 **Shaped codes** 그룹이 있어요. **Dot circle**과 **Heart**는 코드를 장식용 점으로 이루어진 원이나 하트 안에 넣어요. **Silhouette**는 직접 만든 도형을 채워요. 밝거나 투명한 배경에 어둡거나 단색인 도형이 있는 PNG, JPEG 또는 SVG를 업로드하세요. 윤곽선만 사용하고 그림은 사용하지 않아요.

스캐너는 가운데의 코드만 읽으므로, 같은 스캔 거리를 원한다면 도형 코드를 정사각형 코드보다 크게 인쇄하세요. 도형은 프레임을 대신해요. 하나를 고르면 다른 하나는 해제돼요. 코드를 담기에 너무 가는 도형은 메시지와 함께 거부돼요.

{/* end shaped codes */}

## 프레임은 스캔을 방해하지 않아요 [#frames-never-hurt-scanning]

프레임은 코드 바깥에 놓여요. 코드의 어떤 사각형도 가리지 않아요.

프레임 문구는 짧게 유지하세요. 세 단어나 네 단어가 멀리서 읽기에 가장 좋아요.

## 프레임과 함께 다운로드하기 [#download-with-the-frame]

프레임은 모든 형식의 다운로드에 포함돼요. 인쇄에 관해서는 [QR 코드 다운로드 및 인쇄하기](/docs/help/getting-started/download-and-print)를 참고하세요.
