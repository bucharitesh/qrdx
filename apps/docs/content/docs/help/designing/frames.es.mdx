Un marco les dice a las personas qué obtienen al escanear.

## Añade un marco [#add-a-frame]

1. En el [Playground](/playground?tab=design&section=frame), abre la pestaña **Design** y luego **Frame**.
2. Elige un estilo de marco.
3. Escribe tu texto en **Label**, o elige uno predefinido: Scan me, Scan for menu, Join Wi-Fi, Leave a review, Follow us, Pay here, Save contact o Download the app.
4. Ajusta el **Frame color**, el **Text color** y el **Text size**. Algunos marcos también tienen una **Second line**.

## Pon el código dentro de una forma [#put-the-code-in-a-shape]

En **Shaped code**, dentro de la misma sección, **Dot circle** y **Heart** colocan el código dentro de un círculo o de un corazón hechos de puntos decorativos. **Silhouette** rellena una forma propia: sube un PNG, JPEG o SVG con una forma oscura o sólida sobre un fondo claro o transparente. Solo se conserva su contorno, nunca la imagen.

Los lectores solo leen el código del centro, así que imprime un código con forma más grande que uno cuadrado para la misma distancia de escaneo. Una forma ocupa el lugar de un marco: al elegir una, se quita el otro. Si una forma es demasiado delgada para contener el código, se rechaza con un mensaje.

{/* end shaped codes */}

## Los marcos nunca afectan el escaneo [#frames-never-hurt-scanning]

Los marcos quedan fuera del código. Nunca cubren ninguno de sus cuadrados.

Mantén el texto del marco corto. Tres o cuatro palabras se leen mejor a distancia.

## Descarga con el marco [#download-with-the-frame]

El marco forma parte de todas las descargas, en todos los formatos. Para imprimir, consulta [Descarga e imprime un código QR](/docs/help/getting-started/download-and-print).
