Un marco les dice a las personas qué obtienen al escanear.

## Añade un marco [#add-a-frame]

1. En el [Playground](/playground?tab=design&section=frame), abre la pestaña **Diseño** y luego **Marco**.
2. Elige un marco. El grupo **Clásico** incluye los marcos integrados; **Más** abre todos los grupos, con búsqueda.
3. Escribe tu texto en **Etiqueta**, o elige uno predefinido: Escanéame, Escanea para ver el menú, Conéctate al Wi-Fi, Deja una reseña, Síguenos, Paga aquí, Guarda el contacto o Descarga la app.
4. Ajusta el **Color del marco**, el **Color del texto** y el **Tamaño del texto**. Algunos marcos también tienen una **Segunda línea**.

## Coloca el código dentro de una forma [#put-the-code-in-a-shape]

El mismo selector tiene un grupo **Códigos con forma**. **Círculo de puntos** y **Corazón** colocan el código dentro de un círculo o de un corazón hecho de puntos decorativos. **Silueta** rellena una forma propia: sube un PNG, JPEG o SVG con una forma oscura o sólida sobre un fondo claro o transparente. Solo se conserva su contorno, nunca la imagen.

Los lectores solo leen el código del centro, así que imprime un código con forma más grande que uno cuadrado para la misma distancia de escaneo. Una forma ocupa el lugar de un marco: al elegir una, se quita el otro. Si una forma es demasiado delgada para contener el código, se rechaza con un mensaje.

## Los marcos nunca perjudican el escaneo [#frames-never-hurt-scanning]

Los marcos quedan fuera del código. Nunca cubren ninguno de sus cuadrados.

Mantén el texto del marco corto. Tres o cuatro palabras se leen mejor a distancia.

## Descarga con el marco [#download-with-the-frame]

El marco forma parte de todas las descargas, en todos los formatos. Para imprimir, consulta [Descarga e imprime un código QR](/docs/help/getting-started/download-and-print).
