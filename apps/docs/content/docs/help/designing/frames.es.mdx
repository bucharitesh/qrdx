Un marco le dice a la gente qué obtiene al escanear.

## Añade un marco [#add-a-frame]

1. En el [Playground](/playground?tab=design&section=frame), abre la pestaña **Diseño** y después **Marco**.
2. Elige un marco. Busca por nombre o elige un grupo: **Clásicos** incluye los marcos integrados, entre ellos Arrow, Standard Box, Square Border, Striked Box, Halloween y Dot Ring. Al elegir un marco, reemplazas el que tenías. Para usar tu propio diseño, inicia sesión y elige **Subir SVG** junto al buscador: las formas y los colores del SVG se convierten en un marco.
3. Escribe tu texto en **Etiqueta** o elige uno predefinido: Scan me, Scan for menu, Join Wi-Fi, Leave a review, Follow us, Pay here, Save contact o Download the app.
4. Define el **Color del marco**, el **Color del texto** y el **Tamaño del texto**. Algunos marcos también tienen una **Segunda línea**. Arrow, Standard Box, Square Border y Dot Ring toman en cambio el color de los puntos del código, y Striked Box y Halloween conservan sus propios colores.

## Coloca el código en una forma [#put-the-code-in-a-shape]

El mismo selector tiene un grupo **Códigos con forma**. **Dot circle** y **Heart** colocan el código dentro de un círculo o un corazón de puntos decorativos. **Silhouette** rellena una forma tuya: sube un PNG, JPEG o SVG con una forma oscura o sólida sobre un fondo claro o transparente. Solo se conserva su contorno, nunca la imagen.

Los lectores solo leen el código del centro, así que imprime un código con forma más grande que uno cuadrado para la misma distancia de escaneo. Una forma ocupa el lugar de un marco: al elegir una, se quita el otro. Si una forma es demasiado delgada para contener el código, se rechaza con un mensaje.

## Los marcos nunca perjudican el escaneo [#frames-never-hurt-scanning]

Los marcos quedan fuera del código. Nunca cubren ninguno de sus cuadrados.

Mantén el texto del marco corto. Tres o cuatro palabras se leen mejor a distancia.

## Descarga con el marco [#download-with-the-frame]

El marco forma parte de todas las descargas, en todos los formatos. Para imprimir, consulta [Descargar e imprimir un código QR](/docs/help/getting-started/download-and-print).
