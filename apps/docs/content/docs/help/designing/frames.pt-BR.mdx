Uma moldura diz às pessoas o que elas recebem quando fazem a leitura.

## Adicione uma moldura [#add-a-frame]

1. No [Playground](/playground?tab=design&section=frame), abra a aba **Design** e depois **Frame**.
2. Escolha uma moldura. O grupo **Classic** tem as molduras nativas; **More** abre todos os grupos, com busca.
3. Digite seu texto em **Label** ou escolha um pronto: Scan me, Scan for menu, Join Wi-Fi, Leave a review, Follow us, Pay here, Save contact ou Download the app.
4. Defina a **Frame color**, a **Text color** e o **Text size**. Algumas molduras também têm uma **Second line**.

## Coloque o código em uma forma [#put-the-code-in-a-shape]

O mesmo seletor tem um grupo **Shaped codes**. **Dot circle** e **Heart** colocam o código em um círculo ou em um coração de pontos decorativos. **Silhouette** preenche uma forma sua: envie um PNG, JPEG ou SVG com uma forma escura ou sólida sobre um fundo claro ou transparente. Só o contorno é mantido, nunca a imagem.

Os leitores leem apenas o código no meio, então imprima um código com forma maior que um quadrado para a mesma distância de leitura. Uma forma ocupa o lugar de uma moldura: escolher uma remove a outra. Uma forma fina demais para conter o código é recusada com uma mensagem.

## Molduras não atrapalham a leitura [#frames-never-hurt-scanning]

As molduras ficam fora do código. Elas nunca cobrem nenhum dos quadrados dele.

Mantenha o texto da moldura curto. Três ou quatro palavras são mais fáceis de ler de longe.

## Baixe com a moldura [#download-with-the-frame]

A moldura faz parte de todos os downloads, em todos os formatos. Para impressão, veja [Baixe e imprima um QR code](/docs/help/getting-started/download-and-print).
