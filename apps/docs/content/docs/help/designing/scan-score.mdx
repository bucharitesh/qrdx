Every design in the [playground](/playground) gets a **Scan score** from 0 to 100, shown under the preview, for example "Scan score 92 · Great". It tests the code the way a phone camera would, so you can fix problems before you print.

{/* shot: scan-score-badge | the Scan score badge under the preview reading "Scan score 92 · Great" | /playground with a link typed */}

## What the score means

| Grade | Score | What to do |
| --- | --- | --- |
| **Great** | 85 or more | Ready to print. |
| **OK** | 65 to 84 | It should scan. Read the warnings. |
| **Risky** | Below 65 | Fix the checks marked with a cross. |
| **Fails** | | The code didn't decode at the largest test size, or the contrast is far too low. Don't print it. |

## See what to fix

Click the score. The **Will it scan?** panel lists every check, with the failed ones first.

{/* shot: will-it-scan-panel | the Will it scan? panel open with the list of checks and one failed check at the top | /playground, click the Scan score */}

The checks are:

- **Decoding**: the code is read at three sizes with a camera-like blur.
- **Contrast**: the code and background should differ by 4.5:1 or more.
- **Dark on light**: dark codes on light backgrounds scan in more apps.
- **Logo**: a logo must not cover more than error correction can rebuild, and must not touch a corner eye.
- **Eye shape**: circle and curly eyes fail in some scanner apps.
- **Quiet zone**: the empty border around the code. Four modules is ideal.

## Quick fixes

| The check | The fix |
| --- | --- |
| Low contrast | Make the code darker or the background lighter. See [Choose colors that scan](/docs/help/designing/colors-and-contrast). |
| Logo covers too much | Set **Error correction** to **High**, or make the logo smaller. See [Add a logo](/docs/help/designing/logos). |
| Eye shape | Switch to square, rounded or gear eyes. |
| Quiet zone | Set **Padding** to **Standard** or **Large**. |

## Check a printed code

The score tests the design on screen. To test a code you already printed, take a photo and drop it into the [scan checker](/tools/scan-checker). The image never leaves your device.
