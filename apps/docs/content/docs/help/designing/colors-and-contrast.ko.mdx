스캐너는 밝은 배경 위의 어두운 사각형을 찾습니다. 색상 문제는 대부분 이 규칙을 지키지 않아서 생깁니다.

## 색상 변경하기 [#change-the-colors]

[Playground](/playground?tab=design&section=colors)에서 **디자인** 탭을 열고 **색상**을 선택하세요.

- **배경**은 코드 뒤쪽 영역입니다.
- **전경**은 데이터를 담고 있는 작은 사각형의 색입니다.
- **눈**은 모서리에 있는 큰 사각형 세 개의 색입니다.
- **점**은 각 모서리 사각형의 중앙 색입니다.

각 색상은 단색, 선형 그라디언트, 원형 그라디언트 중에서 고를 수 있습니다. 네 가지 색상 아래의 팔레트를 선택하면 모든 색상이 한 번에 설정됩니다.

## 스캔되는 코드를 만드는 규칙 [#rules-that-keep-a-code-scannable]

- **어두운 코드, 밝은 배경.** 어두운 배경 위의 밝은 코드는 일부 카메라 앱에서 인식되지 않습니다.
- **강한 대비.** 코드와 배경 사이의 대비율을 4.5:1 이상으로 맞추세요.
- **그라디언트는 어둡게.** 그라디언트에 쓰인 모든 색이 배경과 비교해 충분히 어두우면 사용해도 괜찮습니다.
- **단순한 배경.** 코드 뒤에 복잡한 사진이 있으면 읽기 어려워집니다.

## 대비 확인하기 [#check-the-contrast]

미리보기 위쪽 도구 모음의 대비 검사기에서 현재 색상의 대비율을 확인할 수 있습니다. 4.5:1 미만인 색상 조합은 경고로 표시됩니다.

미리보기 아래의 **스캔 점수**도 대비를 확인하며, 크기, 여백, 로고도 함께 검사합니다. [스캔 점수로 디자인 확인하기](/docs/help/designing/scan-score)를 참고하세요.
