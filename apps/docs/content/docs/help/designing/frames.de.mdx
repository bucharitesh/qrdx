Ein Rahmen zeigt den Leuten, was sie beim Scannen bekommen.

## Rahmen hinzufügen [#add-a-frame]

1. Öffne im [Playground](/playground?tab=design&section=frame) den Tab **Design** und dann **Rahmen**.
2. Wähle einen Rahmen. Suche nach dem Namen oder wähle eine Gruppe: **Klassisch** enthält die integrierten Rahmen, darunter Arrow, Standard Box, Square Border, Striked Box, Halloween und Dot Ring. Wenn du einen Rahmen wählst, ersetzt er den bisherigen. Für eigene Grafiken meldest du dich an und wählst neben der Suche **SVG hochladen**: Die Formen und Farben der SVG werden zu einem Rahmen.
3. Gib deinen Text unter **Beschriftung** ein oder wähle eine fertige: Scan me, Scan for menu, Join Wi-Fi, Leave a review, Follow us, Pay here, Save contact oder Download the app.
4. Lege **Rahmenfarbe**, **Textfarbe** und **Textgröße** fest. Einige Rahmen haben auch eine **Zweite Zeile**. Arrow, Standard Box, Square Border und Dot Ring übernehmen stattdessen die Farbe der Punkte des Codes, und Striked Box und Halloween behalten ihre eigenen Farben.

## Den Code in eine Form setzen [#put-the-code-in-a-shape]

Dieselbe Auswahl enthält die Gruppe **Geformte Codes**. **Dot circle** und **Heart** setzen den Code in einen Kreis oder ein Herz aus dekorativen Punkten. **Silhouette** füllt eine eigene Form: Lade eine PNG-, JPEG- oder SVG-Datei mit einer dunklen oder einfarbigen Form auf hellem oder transparentem Hintergrund hoch. Nur der Umriss wird übernommen, nie das Bild.

Scanner lesen nur den Code in der Mitte. Drucke einen geformten Code daher größer als einen quadratischen, wenn die Scan-Entfernung gleich bleiben soll. Eine Form ersetzt einen Rahmen: Wenn du eine wählst, wird der andere entfernt. Eine Form, die zu schmal ist, um den Code aufzunehmen, wird mit einer Meldung abgelehnt.

{/* end shaped codes */}

## Rahmen beeinträchtigen den Scan nie [#frames-never-hurt-scanning]

Rahmen liegen außerhalb des Codes. Sie verdecken keines seiner Quadrate.

Halte den Rahmentext kurz. Drei oder vier Wörter lassen sich aus der Entfernung am besten lesen.

## Mit dem Rahmen herunterladen [#download-with-the-frame]

Der Rahmen ist in jedem Download und in jedem Format enthalten. Hinweise zum Drucken findest du unter [QR-Code herunterladen und drucken](/docs/help/getting-started/download-and-print).
