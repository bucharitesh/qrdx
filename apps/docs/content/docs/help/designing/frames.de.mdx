Ein Rahmen sagt den Leuten, was sie beim Scannen bekommen.

## Rahmen hinzufügen [#add-a-frame]

1. Öffne im [Playground](/playground?tab=design&section=frame) den Tab **Design** und dann **Frame**.
2. Wähle einen Rahmen. Die Gruppe **Classic** enthält die integrierten Rahmen, darunter Arrow, Standard Box, Square Border, Striked Box, Halloween und Dot Ring; **More** öffnet alle Gruppen mit Suche. Wenn du einen Rahmen auswählst, ersetzt er den bisherigen.
3. Gib deinen Text unter **Label** ein oder wähle einen vorgefertigten: Scan me, Scan for menu, Join Wi-Fi, Leave a review, Follow us, Pay here, Save contact oder Download the app.
4. Lege **Frame color**, **Text color** und **Text size** fest. Manche Rahmen haben außerdem eine **Second line**. Arrow, Standard Box, Square Border und Dot Ring übernehmen stattdessen die Farbe der Punkte des Codes, und Striked Box und Halloween behalten ihre eigenen Farben.

## Den Code in eine Form setzen [#put-the-code-in-a-shape]

Dieselbe Auswahl enthält die Gruppe **Shaped codes**. **Dot circle** und **Heart** setzen den Code in einen Kreis oder ein Herz aus dekorativen Punkten. **Silhouette** füllt eine Form deiner Wahl: Lade eine PNG-, JPEG- oder SVG-Datei mit einer dunklen oder vollflächigen Form auf hellem oder transparentem Hintergrund hoch. Nur der Umriss wird übernommen, nie das Bild.

Scanner lesen nur den Code in der Mitte. Drucke einen Code in einer Form daher größer als einen quadratischen, wenn die Scan-Entfernung gleich bleiben soll. Eine Form ersetzt den Rahmen: Wenn du eines von beiden auswählst, wird das andere entfernt. Eine Form, die zu schmal ist, um den Code aufzunehmen, wird mit einer Meldung abgelehnt.

{/* end shaped codes */}

## Rahmen beeinträchtigen das Scannen nie [#frames-never-hurt-scanning]

Rahmen liegen außerhalb des Codes. Sie verdecken nie eines seiner Quadrate.

Halte den Rahmentext kurz. Drei oder vier Wörter lassen sich aus der Entfernung am besten lesen.

## Mit Rahmen herunterladen [#download-with-the-frame]

Der Rahmen ist in jedem Format Teil jedes Downloads. Zum Drucken siehe [QR-Code herunterladen und drucken](/docs/help/getting-started/download-and-print).
