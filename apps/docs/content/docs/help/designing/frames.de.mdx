Ein Rahmen zeigt den Leuten, was sie beim Scannen bekommen.

## Rahmen hinzufügen [#add-a-frame]

1. Öffne im [Playground](/playground?tab=design&section=frame) den Tab **Design** und dann **Rahmen**.
2. Wähle einen Rahmen. In der Gruppe **Classic** findest du die eingebauten Rahmen, darunter Arrow, Standard Box, Square Border, Striked Box und Halloween. Mit **Mehr** öffnest du alle Gruppen, inklusive Suche. Wenn du einen Rahmen wählst, ersetzt er den bisherigen.
3. Gib deinen Text unter **Beschriftung** ein oder wähle einen vorgefertigten: Scan me, Scan for menu, Join Wi-Fi, Leave a review, Follow us, Pay here, Save contact oder Download the app.
4. Lege **Rahmenfarbe**, **Textfarbe** und **Textgröße** fest. Manche Rahmen haben auch eine **Zweite Zeile**. Arrow, Standard Box und Square Border übernehmen stattdessen die Farbe der Punkte des Codes, und Striked Box und Halloween behalten ihre eigenen Farben.

## Den Code in eine Form setzen [#put-the-code-in-a-shape]

Dieselbe Auswahl enthält die Gruppe **Geformte Codes**. **Dot circle** und **Heart** setzen den Code in einen Kreis oder ein Herz aus dekorativen Punkten. **Silhouette** füllt eine eigene Form: Lade ein PNG, JPEG oder SVG mit einer dunklen oder einfarbigen Form auf hellem oder transparentem Hintergrund hoch. Nur die Umrisse werden übernommen, nie das Bild.

Scanner lesen nur den Code in der Mitte. Drucke einen geformten Code deshalb größer als einen quadratischen, wenn die Scan-Entfernung gleich bleiben soll. Eine Form ersetzt einen Rahmen: Wenn du eine wählst, wird der andere entfernt. Eine Form, die zu dünn ist, um den Code aufzunehmen, wird mit einer Meldung abgelehnt.

{/* end shaped codes */}

## Rahmen beeinträchtigen den Scan nie [#frames-never-hurt-scanning]

Rahmen liegen außerhalb des Codes. Sie verdecken nie eines seiner Quadrate.

Halte den Rahmentext kurz. Drei oder vier Wörter lassen sich aus der Ferne am besten lesen.

## Mit Rahmen herunterladen [#download-with-the-frame]

Der Rahmen ist in jedem Download und in jedem Format enthalten. Zum Drucken siehe [QR-Code herunterladen und drucken](/docs/help/getting-started/download-and-print).
