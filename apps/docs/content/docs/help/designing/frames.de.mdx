Ein Rahmen zeigt den Leuten, was sie beim Scannen bekommen.

## Rahmen hinzufügen [#add-a-frame]

1. Öffne im [Playground](/playground?tab=design&section=frame) den Tab **Design** und dann **Rahmen**.
2. Wähle einen Rahmen. Die Gruppe **Classic** enthält die integrierten Rahmen; **Mehr** öffnet alle Gruppen, mit Suche.
3. Gib deinen Text unter **Beschriftung** ein oder wähle einen fertigen: Scan me, Scan for menu, Join Wi-Fi, Leave a review, Follow us, Pay here, Save contact oder Download the app.
4. Lege **Rahmenfarbe**, **Textfarbe** und **Textgröße** fest. Manche Rahmen haben außerdem eine **Zweite Zeile**.

## Den Code in eine Form setzen [#put-the-code-in-a-shape]

Dieselbe Auswahl enthält die Gruppe **Geformte Codes**. **Dot circle** und **Heart** setzen den Code in einen Kreis oder ein Herz aus dekorativen Punkten. **Silhouette** füllt eine Form deiner Wahl: Lade eine PNG-, JPEG- oder SVG-Datei mit einer dunklen oder vollflächigen Form auf hellem oder transparentem Hintergrund hoch. Nur der Umriss wird übernommen, nie das Bild.

Scanner lesen nur den Code in der Mitte. Drucke einen geformten Code daher größer als einen quadratischen, wenn die Scan-Entfernung gleich bleiben soll. Eine Form ersetzt den Rahmen: Wählst du eines von beiden, wird das andere entfernt. Eine Form, die zu dünn ist, um den Code aufzunehmen, wird mit einer Meldung abgelehnt.

{/* end shaped codes */}

## Rahmen beeinträchtigen den Scan nie [#frames-never-hurt-scanning]

Rahmen liegen außerhalb des Codes. Sie verdecken nie eines seiner Quadrate.

Halte den Rahmentext kurz. Drei oder vier Wörter lassen sich aus der Ferne am besten lesen.

## Mit Rahmen herunterladen [#download-with-the-frame]

Der Rahmen ist in jedem Format Teil jedes Downloads. Zum Drucken siehe [QR-Code herunterladen und drucken](/docs/help/getting-started/download-and-print).
