A frame tells people what they get when they scan.

## Add a frame

1. In the [playground](/playground?tab=design), open the **Design** tab, then **Frame**.
2. Pick a frame style.
3. Type your text in **Label**, or pick a ready-made one: Scan me, Scan for menu, Join Wi-Fi, Leave a review, Follow us, Pay here, Save contact or Download the app.
4. Set the **Frame color**, **Text color** and **Text size**. Some frames also have a **Second line**.

## Put the code in a shape

Under **Shaped code** in the same section, **Dot circle** and **Heart** put the code in a circle or a heart of decorative dots. **Silhouette** fills a shape of your own: upload a PNG, JPEG or SVG with a dark or solid shape on a light or clear background. Only its outline is kept, never the picture.

Scanners read only the code in the middle, so print a shaped code larger than a square one for the same scan distance. A shape takes the place of a frame: picking one clears the other. A shape that is too thin to hold the code is refused with a message.

{/* end shaped codes */}

## Frames never hurt scanning

Frames sit outside the code. They never cover any of its squares.

Keep the frame text short. Three or four words read best from a distance.

## Download with the frame

The frame is part of every download, in every format. For print, see [Download and print a QR code](/docs/help/getting-started/download-and-print).
