사용자 지정 도메인을 사용하면 코드에 `qrdx.dev` 링크 대신 `go.yourbrand.com/…`이 인코딩됩니다. 사람들이 스캔하기 전에 여러분의 브랜드를 먼저 보게 됩니다. Pro에는 도메인 5개, Business에는 25개가 포함돼요.

## 도메인 연결하기 [#connect-a-domain]

1. 대시보드에서 **Domains**로 이동한 뒤 **Add domain**을 클릭하세요.
2. 도메인을 입력하세요. 예: `go.yourbrand.com`. 서브도메인을 쓰는 것이 가장 좋습니다. 기존 메인 웹사이트는 그대로 유지됩니다.
3. QRdx가 보여 주는 DNS 레코드를 DNS 제공업체에 추가하세요. DNS 제공업체는 도메인을 구매했거나 도메인의 DNS를 관리하는 곳입니다. 값은 그대로 복사하세요.<IfAvailable feature="domainConnect"> **Set up with**와 제공업체 이름이 보이면 대신 그 버튼을 클릭할 수 있어요. 제공업체에서 승인하면 레코드가 자동으로 추가됩니다.</IfAvailable>
4. **Verify**를 클릭하세요.

레코드가 확인될 때까지 상태는 **Waiting for DNS**로 표시되고, 확인되면 **Verified**로 바뀝니다. DNS 변경은 보통 몇 분 안에 반영되지만 최대 48시간이 걸릴 수 있습니다.

## 코드에 사용하기 [#use-it-for-a-code]

- **새 코드:** **Create code**를 클릭하기 전에 **Short link domain**에서 도메인을 선택하세요.
- **기존 코드:** **Edit link**에서 도메인을 선택하고 저장한 뒤 코드를 다시 다운로드하세요. 인코딩된 링크가 바뀌었기 때문입니다.

## 인쇄한 코드도 계속 작동합니다 [#printed-codes-keep-working]

모든 코드는 `qrdx.dev` 링크로도 계속 작동합니다. 내 도메인으로 옮기기 전에 인쇄한 코드도 문제없이 작동해요.

다만 코드를 한 사용자 지정 도메인에서 다른 사용자 지정 도메인으로 옮기면, 이전 도메인으로 인쇄한 코드는 작동하지 않습니다. 저장하기 전에 QRdx가 경고해 드려요.
