---
title: "Eigene Domain verwenden"
description: "Verbinde eine eigene Domain wie go.yourbrand.com für die Kurzlinks deiner dynamischen Codes."
---

Mit einer eigenen Domain enthalten deine Codes `go.yourbrand.com/…` statt eines `qrdx.dev`-Links. Die Leute sehen deine Marke, bevor sie scannen. Pro enthält 5 Domains, Business 25.

## Domain verbinden [#connect-a-domain]

1. Gehe in deinem Dashboard zu **Domains** und klicke auf **Domain hinzufügen**.
2. Gib die Domain ein, zum Beispiel `go.yourbrand.com`. Am besten eignet sich eine Subdomain: Deine Hauptwebsite bleibt, wo sie ist.
3. Füge die DNS-Einträge, die QRdx dir anzeigt, bei deinem DNS-Anbieter hinzu, also dort, wo du die Domain gekauft hast oder ihr DNS verwaltest. Kopiere die Werte exakt.<IfAvailable feature="domainConnect"> Wenn du **Einrichten mit** und den Namen deines Anbieters siehst, kannst du stattdessen darauf klicken: Dein Anbieter fügt die Einträge hinzu, sobald du sie dort bestätigst.</IfAvailable>
4. Klicke auf **Verifizieren**.

Der Status zeigt **Warte auf DNS**, bis die Einträge gefunden werden, dann **Verifiziert**. DNS-Änderungen sind meist innerhalb weniger Minuten sichtbar, können aber bis zu 48 Stunden dauern.

## Für einen Code verwenden [#use-it-for-a-code]

- **Neuer Code:** Wähle deine Domain unter **Kurzlink-Domain**, bevor du auf **Code erstellen** klickst.
- **Bestehender Code:** Wähle die Domain unter **Link bearbeiten**, speichere und lade den Code dann erneut herunter. Der codierte Link hat sich geändert.

## Gedruckte Codes funktionieren weiter [#printed-codes-keep-working]

Jeder Code funktioniert außerdem weiterhin über seinen `qrdx.dev`-Link. Codes, die du vor dem Wechsel zu deiner Domain gedruckt hast, funktionieren weiter.

Wenn du einen Code von einer eigenen Domain auf eine andere umziehst, funktionieren Codes nicht mehr, die mit der alten Domain gedruckt wurden. QRdx warnt dich, bevor du speicherst.
