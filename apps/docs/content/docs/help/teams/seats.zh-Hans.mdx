---

## 可用席位数 [#how-many-seats-you-get]

- **Pro**：3 个席位，包括所有者。
- **Business**：席位数不限。
- **免费版**：1 个席位，仅限你本人。

工作区按所有者中最高的套餐计算。成员无需拥有自己的订阅。

## 待处理的邀请会占用席位 [#pending-invitations-use-a-seat]

邀请在被接受或撤销之前会一直占用一个席位。要释放席位，请在 **设置** → **团队** 页面找到该邀请，然后点击 **撤销**。

## 所有者的套餐变更后 [#if-the-owners-plan-changes]

已在工作区中的成员会保留。只有新的邀请会被拦截，直到有空闲席位为止。

## 移除成员 [#remove-someone]

在 **设置** → **团队** 页面，点击对方姓名旁的 **移除**，然后点击 **移除成员**。只有管理员和所有者可以移除成员，并且任何人都不能被移出自己的工作区。

对方创建的二维码和页面会保留在工作区中。

## 退出工作区 [#leave-a-workspace]

在工作区的 **设置** → **常规** 中，点击 **退出工作区**。

如果你是唯一的所有者，请先将其他人设为所有者。参见[团队角色](/docs/help/teams/roles)。你不能退出自己的工作区。

## 删除工作区 [#delete-a-workspace]

所有者可以在 **设置** → **常规** 中点击 **删除工作区**。确认时，请输入该工作区的 URL。你自己的工作区无法删除；它会在你[删除账号](/docs/help/account-and-billing/delete-your-account)时一并删除。

一切都不会停止工作。每个二维码、页面、文件和域名都会转移到其创建者自己的工作区，已印刷的二维码仍会继续跳转。该工作区的 API 密钥会被删除。
