QRdx에서 만드는 모든 것은 워크스페이스에 속합니다. 같은 워크스페이스의 모든 구성원은 같은 코드, 페이지, 파일, 도메인, 테마를 함께 사용합니다.

## 내 워크스페이스 [#your-own-workspace]

모든 계정에는 워크스페이스가 하나씩 자동으로 만들어지며, 사용자가 그 소유자입니다. 이 워크스페이스는 나가거나 삭제할 수 없습니다. Pro 또는 Business에서는 이 워크스페이스에 다른 사용자를 초대하거나, 그들을 위해 워크스페이스를 하나 더 만들 수 있습니다.

## 워크스페이스 만들기 [#create-a-workspace]

1. 사이드바 하단의 워크스페이스 전환기를 엽니다(휴대폰에서는 메뉴에 있습니다).
2. **Create workspace**를 클릭합니다.
3. **Workspace name**과 **Workspace URL**을 입력합니다(소문자, 숫자, 대시 3~48자).
4. **Create workspace**를 클릭합니다. QRdx가 새 워크스페이스로 전환해 줍니다.

워크스페이스를 더 만들려면 Pro 또는 Business가 필요합니다.

## 사용자 초대하기 [#invite-someone]

1. 해당 워크스페이스에서 **Settings** → **Team**으로 이동합니다.
2. 초대할 사용자의 이메일 주소를 입력하고 역할을 선택합니다. **Member** 또는 **Admin**입니다. [팀 역할](/docs/help/teams/roles)을 참고하세요.
3. **Create invite link**를 클릭합니다.

QRdx가 초대 이메일을 보내고, 직접 공유할 수 있는 링크도 보여 줍니다. 이메일이 발송되었는지는 확인 메시지에서 알려 줍니다.

관리자로 초대하려면 먼저 [본인 확인](/docs/help/privacy-and-security/two-step-verification#confirm-its-you)이 필요합니다. 단, 해당 브라우저에서 최근 10분 이내에 확인했다면 필요하지 않습니다.

## 초대 수락하기 [#accepting-an-invitation]

- 초대받은 사용자는 링크를 열고, 초대가 발송된 **같은 이메일 주소**로 로그인합니다.
- **Accept invitation**을 클릭해 수락하거나 **Decline**을 클릭해 거절합니다.
- 초대 링크는 48시간 후에 만료됩니다.

## 워크스페이스 간 전환 [#switch-between-workspaces]

워크스페이스 전환기를 사용해 내 워크스페이스와 소속된 다른 워크스페이스 사이를 이동할 수 있습니다. 새로 만드는 코드는 현재 있는 워크스페이스에 저장됩니다.
