## 제공되는 시트 수 [#how-many-seats-you-get]

- **Pro**: 소유자를 포함해 3시트.
- **Business**: 시트 무제한.
- **무료**: 1시트, 본인만 사용할 수 있어요.

워크스페이스에는 소유자들이 가진 플랜 중 가장 높은 플랜이 적용됩니다. 멤버가 별도로 구독할 필요는 없습니다.

## 대기 중인 초대도 시트를 사용합니다 [#pending-invitations-use-a-seat]

초대는 수락되거나 취소될 때까지 시트를 하나 차지합니다. 시트를 비우려면 **설정** → **팀** 페이지에서 해당 초대를 찾아 **취소**를 클릭하세요.

## 소유자의 플랜이 바뀌면 [#if-the-owners-plan-changes]

이미 워크스페이스에 있는 사람들은 그대로 유지됩니다. 빈 시트가 생길 때까지 새 초대만 차단됩니다.

## 멤버 제거하기 [#remove-someone]

**설정** → **팀** 페이지에서 제거할 사람의 이름 옆에 있는 **제거**를 클릭한 다음 **멤버 제거**를 클릭하세요. 멤버는 관리자와 소유자만 제거할 수 있으며, 본인의 워크스페이스에서는 누구도 제거할 수 없습니다.

해당 멤버가 만든 코드와 페이지는 워크스페이스에 그대로 남습니다.

## 워크스페이스 나가기 [#leave-a-workspace]

워크스페이스의 **설정** → **일반**에서 **워크스페이스 나가기**를 클릭하세요.

유일한 소유자라면 먼저 다른 사람을 소유자로 지정해야 합니다. [팀 역할](/docs/help/teams/roles)을 참고하세요. 본인의 워크스페이스는 나갈 수 없습니다.

## 워크스페이스 삭제하기 [#delete-a-workspace]

소유자는 **설정** → **일반**에서 **워크스페이스 삭제**를 클릭할 수 있습니다. 확인하려면 워크스페이스의 URL을 입력하세요. 본인의 워크스페이스는 삭제할 수 없으며, [계정을 삭제](/docs/help/account-and-billing/delete-your-account)하면 함께 삭제됩니다.

작동이 중단되는 것은 없습니다. 각 코드, 페이지, 파일, 도메인은 만든 사람의 개인 워크스페이스로 이동하며, 인쇄된 코드는 계속 리디렉션됩니다. 워크스페이스의 API 키는 삭제됩니다.
