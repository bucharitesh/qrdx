QRdxで作成したものはすべて、ワークスペースに属します。同じワークスペースのメンバーは、同じコード、ページ、ファイル、ドメイン、テーマを共同で扱います。

## 自分のワークスペース [#your-own-workspace]

アカウントごとに1つ、自動的に作成され、あなたがそのオーナーになります。このワークスペースから退出したり、削除したりすることはできません。ProまたはBusinessでは、このワークスペースにメンバーを招待することも、メンバー用に別のワークスペースを作成することもできます。

## ワークスペースを作成する [#create-a-workspace]

1. サイドバー下部のワークスペース切り替えを開きます（スマートフォンではメニュー内にあります）。
2. **ワークスペースを作成**をクリックします。
3. **ワークスペース名**と**ワークスペースURL**を入力します（小文字の英字、数字、ハイフンで3〜48文字）。
4. **ワークスペースを作成**をクリックします。QRdxが新しいワークスペースに切り替えます。

ワークスペースを追加で作成するには、ProまたはBusinessが必要です。

## メンバーを招待する [#invite-someone]

1. ワークスペースで**設定** → **チーム**に移動します。
2. 招待する相手のメールアドレスを入力し、ロールとして**メンバー**または**管理者**を選びます。[チームのロール](/docs/help/teams/roles)をご覧ください。
3. **招待リンクを作成**をクリックします。

QRdxが招待メールを送信し、ご自身で共有できるリンクも表示します。メールが送信されたかどうかは、確認メッセージで分かります。

管理者として招待する場合は、先に[本人確認](/docs/help/privacy-and-security/two-step-verification#confirm-its-you)が必要です。ただし、同じブラウザーで過去10分以内に本人確認を済ませている場合は不要です。

## 招待を承諾する [#accepting-an-invitation]

- 招待された人はリンクを開き、招待が送られた**同じメールアドレス**でサインインします。
- **招待を承諾**または**辞退**をクリックします。
- 招待リンクの有効期限は48時間です。

## ワークスペースを切り替える [#switch-between-workspaces]

ワークスペース切り替えを使うと、自分のワークスペースと、参加している他のワークスペースを行き来できます。作成したコードは、現在開いているワークスペースに保存されます。
