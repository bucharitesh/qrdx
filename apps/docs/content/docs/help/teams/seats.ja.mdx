## 利用できるシート数 [#how-many-seats-you-get]

- **Pro**：オーナーを含めて3シート。
- **Business**：シート数は無制限。
- **フリー**：1シート（あなた1人のみ）。

ワークスペースには、オーナーのプランのうち最も上位のプランが適用されます。メンバーが個別にサブスクリプションを契約する必要はありません。

## 保留中の招待もシートを使用します [#pending-invitations-use-a-seat]

招待は、承諾または取り消されるまでシートを1つ使用します。シートを空けるには、**設定** → **チーム**ページで該当の招待を見つけ、**取り消す**をクリックします。

## オーナーのプランが変わった場合 [#if-the-owners-plan-changes]

すでにワークスペースにいるメンバーはそのまま残ります。空きシートができるまでは、新しい招待だけができなくなります。

## メンバーを削除する [#remove-someone]

**設定** → **チーム**ページで、削除したい人の名前の横にある**削除**をクリックし、続けて**メンバーを削除**をクリックします。メンバーを削除できるのは管理者とオーナーだけです。また、本人自身のワークスペースからは誰も削除できません。

その人が作成したコードやページは、ワークスペースに残ります。

## ワークスペースから退出する [#leave-a-workspace]

ワークスペースの**設定** → **一般**で、**ワークスペースから退出**をクリックします。

あなたが唯一のオーナーの場合は、先に他のメンバーをオーナーにしてください。詳しくは[チームのロール](/docs/help/teams/roles)をご覧ください。自分自身のワークスペースからは退出できません。

## ワークスペースを削除する [#delete-a-workspace]

オーナーは、**設定** → **一般**で**ワークスペースを削除**をクリックできます。確認のため、ワークスペースのURLを入力してください。自分自身のワークスペースは削除できません。[アカウントを削除](/docs/help/account-and-billing/delete-your-account)すると、一緒に削除されます。

動作が止まるものはありません。コード、ページ、ファイル、ドメインはそれぞれ、作成した人自身のワークスペースに移動し、印刷済みのコードも引き続きリダイレクトされます。ワークスペースのAPIキーは削除されます。
