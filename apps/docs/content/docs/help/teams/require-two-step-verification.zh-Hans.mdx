---
title: "强制要求两步验证"
description: "要求工作区中的所有人先开启两步验证，才能打开该工作区。属于 Business 套餐的功能。"
---

所有者和管理员可以要求工作区中的每个人都使用[两步验证](/docs/help/privacy-and-security/two-step-verification)。尚未开启两步验证的成员在开启之前无法打开该工作区，因此仅仅登录了某人的邮箱，并不足以进入你的工作区。

强制要求两步验证属于 **Business** 套餐。只要工作区的某位所有者或账单成员使用 Business，该工作区就拥有此功能。请参阅[席位与工作区限制](/docs/help/teams/seats)。

## 开启方法 [#turn-it-on]

1. 先为你自己的账号开启两步验证，位置在**设置** → **个人资料与安全**。你自己没有开启时，无法强制要求他人开启。
2. 在工作区中，前往**设置** → **团队**。
3. 在**两步验证**下，开启**强制要求两步验证**。
4. 如果有成员尚未开启，QRdx 会告诉你有多少人，并在继续之前征求你的确认。
5. [确认是你本人操作](/docs/help/privacy-and-security/two-step-verification#confirm-its-you)。

只有所有者和管理员可以更改此设置，开启或关闭时都需要确认是你本人操作。

系统不会给任何人发送邮件。未开启两步验证的成员会在下次打开工作区时得知。

## 查看谁已开启 [#see-who-has-it-on]

在**设置** → **团队**页面，所有者和管理员可以看到每位成员的两步验证是**已开启**还是**未开启**。在手机上，该状态显示在每个人的邮箱地址下方。

## 未开启的成员会看到什么 [#what-members-without-it-see]

他们打开工作区时，会看到该工作区要求两步验证，并有一个**开启两步验证**按钮。点击后会进入**设置** → **个人资料与安全**；开启之后，点击**返回**工作区即可回到之前所在的页面。

在此之前，他们无法查看或更改该工作区中的任何内容。他们的其他工作区不受影响，照常使用。

这也包括工作区发送给他们的内容。他们在该工作区的邮件提醒、每周摘要以及 Slack 或 Discord 提醒都会停止，也无法添加新的提醒。他们设置的、用于把该工作区数据发送到其他工具的同步会暂停。开启两步验证后，提醒会恢复；已暂停的同步需要手动重新开启。

如果有人之后关闭了两步验证，该工作区会再次对他关闭，直到他重新开启为止。所有者和管理员也不例外。

## API 密钥 [#api-keys]

在工作区中创建的 API 密钥，无论创建者是否开启两步验证，都会继续对其创建者有效。两步验证保护的是登录，而密钥本身就是一种独立的凭据。任何人若无法打开工作区，就无法在其中创建新密钥，而所有者和管理员可以在工作区的**设置** → **开发者**中查看并撤销所有人的密钥。

通过 OAuth 连接到某人账号的应用，只会在该用户自己的工作区中生效，因此永远无法访问团队工作区。

## 工作区退出 Business 之后 [#if-the-workspace-leaves-business]

该要求不再生效，设置显示为关闭。如果工作区再次回到 Business，该要求会重新生效。

## 关闭方法 [#turn-it-off]

在**设置** → **团队**页面，关闭**强制要求两步验证**，并确认是你本人操作。未开启两步验证的成员可以立即重新打开工作区。
