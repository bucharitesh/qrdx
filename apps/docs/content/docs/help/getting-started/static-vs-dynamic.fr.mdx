title: "Statique ou dynamique : lequel vous faut-il ?"
description: "Les codes statiques stockent votre contenu dans le code et ne changent jamais. Les codes dynamiques stockent un lien court que vous pouvez modifier après l'impression."
---

## QR codes statiques [#static-qr-codes]

Un code statique stocke votre contenu dans le code lui-même : le lien, le mot de passe Wi-Fi ou la carte de contact.

- Il fonctionne indéfiniment, sans compte et sans serveur.
- Il est gratuit et illimité.
- Vous **ne pouvez pas le modifier** après l'impression. Pour changer le contenu, vous imprimez un nouveau code.
- Les scans ne sont pas comptabilisés.

Tout code que vous téléchargez depuis le [Playground](/playground) sans le rendre dynamique est statique.

## QR codes dynamiques [#dynamic-qr-codes]

Un code dynamique stocke un lien court, par exemple `qrdx.dev/q/aB3xY7k`. Ce lien court redirige chaque scan vers votre destination.

- Vous pouvez **modifier la destination** à tout moment, même après l'impression.
- Chaque scan est comptabilisé, avec le moment, le lieu et l'appareil utilisé.
- Vous pouvez le mettre en pause, le programmer, ajouter un mot de passe ou envoyer les scans vers différents liens.
- Il nécessite un compte QRdx gratuit. Le plan Gratuit inclut 10 codes dynamiques ; Pro et Business n'ont aucune limite.

Consultez [Créer un QR code dynamique](/docs/help/dynamic-codes/create).

## Que choisir [#which-to-choose]

Choisissez le **dynamique** lorsque :

- le code figure sur un support imprimé que vous ne pouvez pas remplacer facilement, comme un emballage, une enseigne ou un menu ;
- le lien peut changer, comme une offre saisonnière ou un menu ;
- vous voulez savoir combien de personnes le scannent.

Choisissez le **statique** lorsque :

- le contenu ne change jamais, comme les informations Wi-Fi ou une carte de contact ;
- vous ne souhaitez pas de compte ;
- vous ne voulez rien entre le scan et votre contenu.

## Les pages sont aussi dynamiques [#pages-are-dynamic-too]

Une [page mobile](/docs/help/pages-and-forms/create-a-page) hébergée par QRdx reçoit un QR code dynamique. Vous pouvez modifier la page à tout moment et le code imprimé continue de fonctionner.

## Les codes dynamiques continuent de fonctionner [#dynamic-codes-keep-working]

Un code dynamique continue de rediriger si vous passez à un plan inférieur, si vous résiliez ou si un paiement échoue. Consultez [Ce qui arrive à vos codes si vous cessez de payer](/docs/help/account-and-billing/never-hostage).
