title: Download and print a QR code
description: Pick the right file format and size, and get print-ready files with bleed and crop marks.
---

## Download

In the [playground](/playground), click the download icon above the preview, or press <kbd>D</kbd>. The **Download QR code** dialog opens with two tabs.

### Image file

Use this for screens, email, slides and most printing.

1. Choose a format: **PNG**, **JPG**, **SVG**, **PDF** or **EPS**.
2. Choose a size: Email (200 px), Web (400 px), Social (800 px), Print (1200 px), Poster (2000 px), or type your own.
3. Turn on **Transparent background** if you need it. JPG can't be transparent.
4. Click the download button at the bottom.

### Print-ready

Use this when a print shop asks for a file.

1. Set the **code width** in millimeters or inches.
2. Choose **RGB** or **CMYK**. Print shops usually want CMYK.
3. Add **3 mm bleed** if the background runs to the edge of the page, so trimming never leaves a white line.
4. Turn on **Crop marks** to show where to cut. Crop marks are added to PDFs.
5. Download a **PDF**, **SVG** or **EPS** file.

## Which format to choose

- **PNG** or **JPG**: pixel images for screens, email and documents.
- **SVG**, **EPS**, or a **PDF** from **Print-ready**: vector files that stay sharp at any size. Printers prefer these. A PDF from the **Image file** tab holds a picture of the code, so use Print-ready for anything you print.

## How big to print

Make the code about one tenth of the scanning distance.

- A business card read from 20 cm needs a code about 2 cm wide.
- A poster read from 1 m needs a code about 10 cm wide.

Codes that hold more content need more room. The [print size calculator](/tools/print-size) works out the minimum size for you.

## Leave a clear border

Keep empty space around the code. Scanners need it to find the code. The **Padding** setting in the **Design** tab adds it for you; **Standard** (4 modules) is the safe choice.

## Test before you print

Print one copy and scan it with two different phones, from the distance people will scan it. You can also upload a photo of a printed code to the [scan checker](/tools/scan-checker).
