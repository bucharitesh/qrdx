## QR codes estáticos [#static-qr-codes]

Um código estático guarda seu conteúdo dentro do próprio código: o link, a senha do Wi-Fi ou o cartão de contato.

- Funciona para sempre, sem conta e sem servidor.
- É grátis e ilimitado.
- Você **não pode alterá-lo** depois de imprimir. Para mudar o conteúdo, é preciso imprimir um novo código.
- As leituras não são contadas.

Todo código que você baixa do [Playground](/playground) sem torná-lo dinâmico é estático.

## QR codes dinâmicos [#dynamic-qr-codes]

Um código dinâmico guarda um link curto, como `qrdx.dev/q/aB3xY7k`. O link curto encaminha cada leitura para o seu destino.

- Você pode **alterar o destino** quando quiser, mesmo depois de imprimir.
- Cada leitura é contada, com informações de quando, onde e em qual dispositivo.
- Você pode pausá-lo, agendá-lo, adicionar uma senha ou enviar as leituras para links diferentes.
- Exige uma conta QRdx gratuita. O plano Grátis inclui 10 códigos dinâmicos; o Pro e o Business não têm limite.

Veja [Criar um QR code dinâmico](/docs/help/dynamic-codes/create).

## Qual escolher [#which-to-choose]

Escolha **dinâmico** quando:

- o código vai em algo impresso que não dá para substituir facilmente, como embalagens, placas ou cardápios;
- o link pode mudar, como uma oferta sazonal ou um cardápio;
- você quer saber quantas pessoas fazem a leitura.

Escolha **estático** quando:

- o conteúdo nunca muda, como os dados do Wi-Fi ou um cartão de contato;
- você não quer criar uma conta;
- você não quer nada entre a leitura e o seu conteúdo.

## As páginas também são dinâmicas [#pages-are-dynamic-too]

Uma [página para celular](/docs/help/pages-and-forms/create-a-page) hospedada pelo QRdx recebe um código dinâmico. Você pode editar a página quando quiser e o código impresso continua funcionando.

## Os códigos dinâmicos continuam funcionando [#dynamic-codes-keep-working]

Um código dinâmico continua redirecionando se você mudar para um plano inferior, cancelar ou se um pagamento falhar. Veja [O que acontece com seus códigos se você parar de pagar](/docs/help/account-and-billing/never-hostage).
