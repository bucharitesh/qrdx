QR 코드는 1분 정도면 만들 수 있습니다. 계정은 필요하지 않습니다.

## 코드 만들기 [#make-the-code]

1. [Playground](/playground)를 엽니다. QRdx 편집기입니다.
2. **URL**이 이미 선택되어 있습니다. Wi-Fi, 연락처 카드, WhatsApp 등 다른 유형이 필요하면 **QR 코드 유형** 옆의 **변경**을 클릭하고 유형을 고르세요.
3. **웹사이트 주소**에 링크를 입력합니다. 주소가 올바르면 바로 미리보기에 코드가 표시됩니다.
4. 선택 사항: **스타일로 시작하기**에서 원하는 스타일을 고르거나 **디자인** 탭을 열어 색상, 점, 눈, 로고, 프레임을 바꿉니다.
5. 미리보기 위의 다운로드 아이콘을 클릭하거나 <kbd>D</kbd>를 누릅니다. 형식과 크기를 선택한 다음 다운로드하세요.

주소 아래에는 스캔했을 때 열리는 곳이 표시됩니다. 예를 들어 "Scans open example.com"처럼 나타납니다. 인쇄하기 전에 꼭 확인하세요.

## 인쇄하기 전에 [#before-you-print]

미리보기 아래의 **스캔 점수**를 확인하세요. 85점 이상이면 아주 좋습니다. 65점 미만이면 X 표시가 된 항목을 고치세요. [스캔 점수로 디자인 확인하기](/docs/help/designing/scan-score)를 참고하세요.

그런 다음 본인의 휴대폰으로 코드를 스캔해 보세요.

## Playground에서 만든 코드는 정적 QR 코드입니다 [#codes-from-the-playground-are-static]

Playground에서 다운로드한 코드는 **정적**입니다. 링크가 코드 안에 저장됩니다. 코드는 영구적으로 작동하지만, 인쇄한 후에는 링크를 바꿀 수 없습니다.

나중에 링크를 바꿔야 할 수도 있다면 동적 QR 코드로 만드세요. [정적 QR 코드와 동적 QR 코드](/docs/help/getting-started/static-vs-dynamic)를 참고하세요.
