title: Make your first QR code
description: Create a QR code in the playground and download it. Free, with no account and no watermark.
---

You can make a QR code in about a minute. You don't need an account.

## Make the code

1. Open the [playground](/playground). This is the QRdx editor.
2. **URL** is already selected. For Wi-Fi, a contact card, WhatsApp or anything else, click **Change** next to **QR code type** and pick a type.
3. Type your link in **Website address**. The preview shows your code as soon as the address is valid.
4. Optional: pick a look under **Start from a style**, or open the **Design** tab to change colors, dots, eyes, the logo and the frame.
5. Click the download icon above the preview, or press <kbd>D</kbd>. Choose a format and size, then download.

Below the address, QRdx shows where scans will open, for example "Scans open example.com". Check it before you print.

## Before you print

Check the **Scan score** under the preview. A score of 85 or more is great. Below 65, fix the checks marked with a cross. See [Check a design with the scan score](/docs/help/designing/scan-score).

Then scan the code with your own phone.

## Codes from the playground are static

A code you download from the playground is **static**: the link is stored inside the code. It works forever, but you can't change it after printing.

If you might need to change the link later, make it a dynamic code instead. See [Static or dynamic](/docs/help/getting-started/static-vs-dynamic).
