---
title: Static or dynamic, which do you need?
description: Static codes store your content in the code and never change. Dynamic codes store a short link you can change after printing.
---

## Static QR codes

A static code stores your content inside the code itself: the link, the Wi-Fi password or the contact card.

- It works forever, with no account and no server.
- It's free and unlimited.
- You **can't change it** after printing. To change the content, you print a new code.
- Scans aren't counted.

Every code you download from the [playground](/playground) without making it dynamic is static.

## Dynamic QR codes

A dynamic code stores a short link, such as `qrdx.dev/q/aB3xY7k`. The short link forwards each scan to your destination.

- You can **change the destination** any time, even after printing.
- Every scan is counted, with when, where and on which device.
- You can pause it, schedule it, add a password or send scans to different links.
- It needs a free QRdx account. The Free plan includes 10 dynamic codes; Pro and Business have no limit.

See [Create a dynamic QR code](/docs/help/dynamic-codes/create).

## Which to choose

Choose **dynamic** when:

- the code goes on something printed that you can't easily replace, like packaging, signs or menus;
- the link might change, like a seasonal offer or a menu;
- you want to know how many people scan it.

Choose **static** when:

- the content never changes, like Wi-Fi details or a contact card;
- you don't want an account;
- you want nothing between the scan and your content.

## Pages are dynamic too

A [mobile page](/docs/help/pages-and-forms/create-a-page) hosted by QRdx gets a dynamic code. You can edit the page any time and the printed code keeps working.

## Dynamic codes keep working

A dynamic code keeps redirecting if you downgrade, cancel or a payment fails. See [What happens to your codes if you stop paying](/docs/help/account-and-billing/never-hostage).
