## 다운로드 [#download]

[Playground](/playground)에서 미리보기 위의 다운로드 아이콘을 클릭하거나 <kbd>D</kbd> 키를 누르세요. 탭이 두 개 있는 **QR 코드 다운로드** 대화상자가 열려요.

### 이미지 파일 [#image-file]

화면, 이메일, 슬라이드, 그리고 대부분의 인쇄에 사용하세요.

1. 형식을 선택하세요: **PNG**, **JPG**, **WebP**, **SVG**, **PDF** 또는 **EPS**.
2. 크기를 선택하세요: 이메일(200 px), 웹(400 px), 소셜(800 px), 인쇄(1200 px), 포스터(2000 px) 중에서 고르거나 직접 입력하세요.
3. 필요하면 **투명 배경**을 켜세요. JPG는 투명하게 만들 수 없어요.
4. 아래쪽의 다운로드 버튼을 클릭하세요.

### 인쇄용 [#print-ready]

인쇄소에서 파일을 요청할 때 사용하세요.

1. **코드 너비**를 밀리미터 또는 인치로 설정하세요.
2. **RGB** 또는 **CMYK**를 선택하세요. 인쇄소에서는 보통 CMYK를 원해요.
3. 배경이 페이지 가장자리까지 이어진다면 **3 mm 도련**을 추가하세요. 재단할 때 흰 선이 남지 않아요.
4. 자를 위치를 표시하려면 **재단선**을 켜세요. 재단선은 PDF에 추가돼요.
5. **PDF**, **SVG** 또는 **EPS** 파일을 다운로드하세요.

## 어떤 형식을 선택할까요 [#which-format-to-choose]

- **PNG**, **JPG**, **WebP**: 화면, 이메일, 문서에 쓰는 픽셀 이미지예요. WebP는 PNG와 같은 픽셀을 더 작은 파일로 담아서 웹사이트에 알맞아요.
- **SVG**, **EPS**, 또는 **인쇄용**에서 받은 **PDF**: 어떤 크기에서도 선명한 벡터 파일이에요. 인쇄소에서 선호해요. **이미지 파일** 탭의 PDF에는 코드의 그림이 들어 있으므로, 인쇄할 때는 반드시 인쇄용을 사용하세요.

## 인쇄 크기 [#how-big-to-print]

코드 크기는 스캔 거리의 약 10분의 1로 만드세요.

- 20 cm 거리에서 읽는 명함에는 너비 약 2 cm의 코드가 필요해요.
- 1 m 거리에서 읽는 포스터에는 너비 약 10 cm의 코드가 필요해요.

담긴 내용이 많은 코드일수록 더 큰 공간이 필요해요. [인쇄 크기 계산기](/tools/print-size)가 최소 크기를 계산해 드려요.

## 여백을 충분히 두세요 [#leave-a-clear-border]

코드 주위에 빈 공간을 두세요. 스캐너가 코드를 찾는 데 필요해요. **디자인** 탭의 **여백** 설정에서 자동으로 추가할 수 있으며, **표준**(4 모듈)이 안전한 선택이에요.

## 인쇄 전에 테스트하세요 [#test-before-you-print]

한 장을 인쇄해서 서로 다른 휴대폰 두 대로, 사람들이 실제로 스캔할 거리에서 스캔해 보세요. 인쇄된 코드 사진을 [스캔 검사기](/tools/scan-checker)에 업로드해도 돼요.
