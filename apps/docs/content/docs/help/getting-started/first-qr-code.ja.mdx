---
title: "最初のQRコードを作る"
description: "Playgroundでダウンロードまでできます。無料で、アカウント登録もウォーターマークも不要です。"
---

QRコードは約1分で作れます。アカウントは必要ありません。

## コードを作る [#make-the-code]

1. [Playground](/playground)を開きます。QRdxのエディタです。
2. **URL**があらかじめ選択されています。Wi-Fi、連絡先カード、WhatsAppなどを作る場合は、**QR code type**の横にある**Change**をクリックして、タイプを選びます。
3. **Website address**にリンクを入力します。アドレスが有効になると、すぐにプレビューにコードが表示されます。
4. 任意：**Start from a style**でデザインを選ぶか、**Design**タブを開いて、色、ドット、アイ、ロゴ、フレームを変更します。
5. プレビューの上にあるダウンロードアイコンをクリックするか、<kbd>D</kbd>を押します。形式とサイズを選んでダウンロードします。

アドレスの下には、スキャンしたときに開くページが「Scans open example.com」のように表示されます。印刷する前に確認してください。

## 印刷する前に [#before-you-print]

プレビューの下にある**Scan score**を確認します。85以上なら優秀です。65未満の場合は、×印が付いたチェック項目を修正してください。詳しくは[スキャンスコアでデザインを確認する](/docs/help/designing/scan-score)をご覧ください。

そのあと、ご自身のスマートフォンでコードをスキャンしてみてください。

## Playgroundのコードは静的です [#codes-from-the-playground-are-static]

Playgroundでダウンロードしたコードは**静的**です。リンクはコード自体に保存されます。ずっと使えますが、印刷後にリンクを変更することはできません。

あとでリンクを変更する可能性がある場合は、代わりに動的QRコードを作成してください。詳しくは[静的と動的の違い](/docs/help/getting-started/static-vs-dynamic)をご覧ください。
