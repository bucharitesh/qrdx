## 静的QRコード [#static-qr-codes]

静的QRコードは、リンク、Wi-Fiのパスワード、連絡先カードなどのコンテンツをコード自体に保存します。

- アカウントもサーバーも不要で、ずっと使えます。
- 無料で、作成数に制限はありません。
- 印刷後に**変更することはできません**。内容を変えるには、新しいコードを印刷し直します。
- スキャン数はカウントされません。

[Playground](/playground)で動的にせずにダウンロードしたコードは、すべて静的QRコードです。

## 動的QRコード [#dynamic-qr-codes]

動的QRコードは、`qrdx.dev/q/aB3xY7k` のような短縮リンクを保存します。この短縮リンクが、スキャンのたびにリンク先へ転送します。

- 印刷後でも、いつでも**リンク先を変更**できます。
- スキャンのたびに、日時、場所、使用デバイスが記録されカウントされます。
- 一時停止、スケジュール設定、パスワードの追加、スキャンの振り分けができます。
- 無料のQRdxアカウントが必要です。フリープランには動的QRコードが10個含まれ、ProとBusinessには上限がありません。

[動的QRコードを作成する](/docs/help/dynamic-codes/create)をご覧ください。

## どちらを選ぶか [#which-to-choose]

次の場合は**動的**を選びます。

- パッケージ、看板、メニューなど、簡単に差し替えられない印刷物にコードを載せる場合
- 季節限定のオファーやメニューなど、リンクが変わる可能性がある場合
- 何人がスキャンしたかを知りたい場合

次の場合は**静的**を選びます。

- Wi-Fiの情報や連絡先カードなど、内容が変わらない場合
- アカウントを作りたくない場合
- スキャンからコンテンツの間に何も挟みたくない場合

## ページも動的です [#pages-are-dynamic-too]

QRdxがホストする[モバイルページ](/docs/help/pages-and-forms/create-a-page)には、動的QRコードが割り当てられます。ページはいつでも編集でき、印刷済みのコードはそのまま使い続けられます。

## 動的QRコードは使い続けられます [#dynamic-codes-keep-working]

プランをダウングレードしたりキャンセルしたりした場合や、支払いに失敗した場合でも、動的QRコードはリダイレクトを続けます。[お支払いを停止した場合のコードの扱い](/docs/help/account-and-billing/never-hostage)をご覧ください。
