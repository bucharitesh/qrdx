title: "制作你的第一个二维码"
description: "在 Playground 中创建二维码并下载。免费，无需账号，没有水印。"
---

大约一分钟就能做出一个二维码。你不需要账号。

## 制作二维码 [#make-the-code]

1. 打开 [Playground](/playground)。这是 QRdx 的编辑器。
2. 默认已选中 **URL**。如果要生成 Wi-Fi、名片、WhatsApp 或其他类型的二维码，请点击 **二维码类型** 旁边的 **更改**，然后选择一种类型。
3. 在 **网站地址** 中输入你的链接。地址有效后，预览会立即显示你的二维码。
4. 可选：在 **从样式开始** 下选择一种外观，或打开 **设计** 标签页，更改颜色、圆点、定位眼、Logo 和边框。
5. 点击预览上方的下载图标，或按 <kbd>D</kbd>。选择格式和尺寸，然后下载。

在地址下方，QRdx 会显示扫描后将打开的位置，例如“扫描后打开 example.com”。打印前请先核对。

## 打印前 [#before-you-print]

查看预览下方的 **扫描评分**。85 分或以上就很好。低于 65 分时，请修复标有叉号的检查项。参见[用扫描评分检查设计](/docs/help/designing/scan-score)。

然后用你自己的手机扫描这个二维码。

## 来自 Playground 的二维码是静态的 [#codes-from-the-playground-are-static]

从 Playground 下载的二维码是**静态**的：链接直接存储在二维码内部。它可以永久使用，但打印后无法再更改。

如果以后可能需要更改链接，请改为创建动态二维码。参见[静态还是动态](/docs/help/getting-started/static-vs-dynamic)。
