## ダウンロード [#download]

[Playground](/playground)で、プレビューの上にあるダウンロードアイコンをクリックするか、<kbd>D</kbd>を押します。**QRコードをダウンロード**ダイアログが開き、2つのタブが表示されます。

### 画像ファイル [#image-file]

画面表示、メール、スライド、そしてほとんどの印刷に使えます。

1. 形式を選びます。**PNG**、**JPG**、**WebP**、**SVG**、**PDF**、**EPS**から選べます。
2. サイズを選びます。メール(200 px)、Web(400 px)、ソーシャル(800 px)、印刷(1200 px)、ポスター(2000 px)から選ぶか、任意のサイズを入力します。
3. 必要な場合は**背景を透過**をオンにします。JPGは透過にできません。
4. 下部のダウンロードボタンをクリックします。

### 印刷用 [#print-ready]

印刷会社からファイルを求められたときに使います。

1. **コードの幅**をミリメートルまたはインチで設定します。
2. **RGB**か**CMYK**を選びます。印刷会社では通常CMYKが求められます。
3. 背景がページの端まで広がっている場合は、**3 mmの塗り足し**を追加します。裁断しても白い線が残りません。
4. **トンボ**をオンにすると、裁断位置が表示されます。トンボはPDFに追加されます。
5. **PDF**、**SVG**、**EPS**のいずれかのファイルをダウンロードします。

## 形式の選び方 [#which-format-to-choose]

- **PNG**、**JPG**、**WebP**: 画面、メール、ドキュメント向けのピクセル画像です。WebPはPNGと同じピクセルをより小さいファイルで保持するので、Webサイトに向いています。
- **SVG**、**EPS**、または**印刷用**で作成した**PDF**: どんなサイズでも鮮明なベクターファイルです。印刷会社にはこちらが好まれます。**画像ファイル**タブのPDFにはコードの画像が埋め込まれるため、印刷するものには印刷用を使ってください。

## 印刷サイズの目安 [#how-big-to-print]

コードの大きさは、スキャンする距離の約10分の1にします。

- 20 cmの距離から読み取る名刺には、幅約2 cmのコードが必要です。
- 1 mの距離から読み取るポスターには、幅約10 cmのコードが必要です。

多くの内容を含むコードには、より広いスペースが必要です。[印刷サイズ計算ツール](/tools/print-size)で最小サイズを算出できます。

## 余白を確保する [#leave-a-clear-border]

コードの周囲には空白を残してください。スキャナーがコードを見つけるために必要です。**デザイン**タブの**余白**設定で自動的に追加できます。**標準**(4モジュール)なら安心です。

## 印刷前にテストする [#test-before-you-print]

1部を印刷し、実際にスキャンされる距離から2台の異なるスマートフォンでスキャンしてください。印刷したコードの写真を[スキャンチェッカー](/tools/scan-checker)にアップロードして確認することもできます。
