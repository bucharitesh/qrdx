---
title: "Erstelle deinen ersten QR-Code"
description: "Erstelle einen QR-Code im Playground und lade ihn herunter. Kostenlos, ohne Konto und ohne Wasserzeichen."
---

Einen QR-Code erstellst du in etwa einer Minute. Ein Konto brauchst du dafür nicht.

## Den Code erstellen [#make-the-code]

1. Öffne den [Playground](/playground). Das ist der QRdx-Editor.
2. **URL** ist bereits ausgewählt. Für Wi-Fi, eine Kontaktkarte, WhatsApp oder etwas anderes klickst du neben **QR-Code-Typ** auf **Ändern** und wählst einen Typ.
3. Gib deinen Link unter **Website-Adresse** ein. Die Vorschau zeigt deinen Code, sobald die Adresse gültig ist.
4. Optional: Wähle unter **Mit einem Stil starten** ein Aussehen aus oder öffne den Tab **Design**, um Farben, Punkte, Augen, das Logo und den Rahmen zu ändern.
5. Klicke auf das Download-Symbol über der Vorschau oder drücke <kbd>D</kbd>. Wähle ein Format und eine Größe und lade den Code herunter.

Unter der Adresse zeigt QRdx, wohin Scans führen, zum Beispiel „Scans öffnen example.com". Prüfe das, bevor du druckst.

## Vor dem Drucken [#before-you-print]

Prüfe den **Scan-Score** unter der Vorschau. Ein Wert von 85 oder mehr ist sehr gut. Bei unter 65 behebst du die Prüfungen, die mit einem Kreuz markiert sind. Siehe [Design mit dem Scan-Score prüfen](/docs/help/designing/scan-score).

Scanne den Code anschließend mit deinem eigenen Handy.

## Codes aus dem Playground sind statisch [#codes-from-the-playground-are-static]

Ein Code, den du aus dem Playground herunterlädst, ist **statisch**: Der Link ist im Code selbst gespeichert. Er funktioniert für immer, aber nach dem Drucken kannst du ihn nicht mehr ändern.

Falls du den Link später vielleicht ändern musst, erstelle stattdessen einen dynamischen Code. Siehe [Statisch oder dynamisch](/docs/help/getting-started/static-vs-dynamic).
