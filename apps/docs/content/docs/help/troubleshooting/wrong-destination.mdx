---
title: A code opens the wrong page
description: Why a QR code opens an old or unexpected link, and how to find out what it really holds.
---

A code that opens an old or unexpected page is either a static code that still holds the old link, or a dynamic code with a setting that sends the scan elsewhere. Find out which first, then work down the list.

## First, see what the code holds

Take a photo of the printed code and drop it into the [scan checker](/tools/scan-checker). It shows exactly what the code contains.

- If it shows your website address, the code is **static**.
- If it shows a short link like `qrdx.dev/q/…` or one on your own domain, the code is **dynamic**.

## A static code opens the old link

The code was downloaded before it was made dynamic, so it holds the old link itself and can't be changed. Make the code dynamic and print the new version. Confirm it: the scan checker shows a short link. See [Create a dynamic QR code](/docs/help/dynamic-codes/create).

## A dynamic code still opens the old destination

The new destination wasn't saved. In the playground, changing the address isn't enough: click **Point it to the new address**. In the dashboard, open **Edit link**, change the **Destination URL** and click **Save changes**. Confirm it: scan again. QRdx doesn't cache redirects, so the next scan uses the new destination. See [Change where a code points](/docs/help/dynamic-codes/change-the-link).

## Some people land on a different page

A smart routing rule or an A/B test sends some scans elsewhere. Open the code's **Settings** tab, then **Smart routing**. The first matching rule wins, so check the order. Open **Test your rules (uses unsaved changes)** and click **Run test** to see where a scan would go. In an A/B test, each visitor keeps their version for the day, so two people can see different pages. See [Send scans to different links](/docs/help/dynamic-codes/routing).

## The code opens your fallback page

The code is paused, past its end date or past its scan limit, so scans go to its **Fallback URL**. Open **Access & schedule** on the **Settings** tab and resume the code, or change the dates or limit. See [Pause, schedule or limit a code](/docs/help/dynamic-codes/pause-schedule-limit).

## The link has extra text after a question mark

You set UTM parameters, so scans open your link with `utm_` tags added. That's expected, and the page is the same.

## The right page opens, but it looks old

The phone is showing a cached copy of your website, not of the redirect. Reload the page in the browser.

## Still wrong

[Contact support](/docs/help/contact) with the code's short link and what the scan opened.
