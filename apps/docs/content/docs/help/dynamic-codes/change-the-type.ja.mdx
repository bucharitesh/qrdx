---
title: "印刷済みのコードが開く先を変更する"
description: "ウェブサイトリンクのコードをホスト型ページに、またはページをリンクに戻せます。印刷したコードはそのまま使えます。"
---

動的QRコードは、ウェブサイトリンクまたはホスト型ページのどちらかを開きます。印刷後でも、この2つを切り替えられます。短縮リンクは変わらないため、印刷済みのすべてのコードは、次回のスキャン時に新しいページまたはリンクを開きます。スキャンも同じコードで引き続きカウントされます。

## ウェブサイトリンクをページに切り替える [#turn-a-website-link-into-a-page]

1. **Codes** からコードを開き、**Change type** をクリックします。
2. ページタイプを選び、続けてテンプレートを選びます。
3. **Continue to editor** をクリックして、ページを作成します。
4. **Publish** をクリックします。

公開するまでは、スキャンは引き続き元のリンクに移動します。公開せずにエディタを離れた場合、何も変更されません。未公開の編集内容は、このブラウザに残ります。

## ページをリンクに戻す [#turn-a-page-back-into-a-link]

1. コードを開き、**Change type** をクリックします。
2. **Website link** を選び、アドレスを入力して **Switch to website link** をクリックします。

ページは **Pages** に残ります。元に戻すには、もう一度 **Change type** を開き、**Switch back** の中からそのページを選びます。

## 別のページタイプに切り替える [#switch-to-another-page-type]

**Another page type** から、タイプを選びます。新しいページは、選んだテンプレートから始まり、古いページから引き継げるものが引き継がれます。引き継がれるのは、ページ名、設定、ロゴのほか、テンプレートにも存在するブロック（ヘッダー、リンク、連絡先など）です。引き継げないものは、ダイアログに一覧が表示されます。それらは古いページに残り、古いページは **Pages** に保存されます。

## 変わらないもの [#what-stays-the-same]

短縮リンク、スキャン履歴、フォルダ、タグ、メモ、QRデザイン、パスワード、スケジュール、スキャン上限は変わりません。

一部の設定は、片方のタイプでのみ機能します。

- スマートルーティング、A/Bテスト、UTMパラメータ、コンバージョン計測は、ウェブサイトリンクでのみ適用されます。
- トラッキングピクセルは、ホスト型ページでのみ読み込まれます。

これらの設定は切り替えても保持され、元のタイプに戻すと再び機能します。保存されていても使われていない設定は、コードの **Settings** タブに表示されます。

## プラン [#plans]

新しいページは、作成した他のページと同じく、プランのホスト型ページ数に含まれます。コードが開かなくなったページも、**Pages** から削除するまでは数に含まれます。すでにあるページに戻す場合、数は増えません。[プランと制限](/docs/plans-and-limits)をご覧ください。

## 切り替えを取り消す [#undo-a-switch]

切り替えのたびに、コードの以前の設定が **Version history** に保存されます。以前のバージョンを復元すると、そのバージョンが開いていたページが残っている限り、タイプも元に戻ります。

## APIから [#from-the-api]

`PATCH /v1/codes/{id}` で `kind` を送信します。[コードを更新する](/docs/developers/api/update-code)をご覧ください。
