<Callout type="warn">
  किसी कोड को आर्काइव करने, ट्रैश में भेजने या डिलीट करने से वह **काम करना बंद कर देता है**। प्रिंट किए गए कोड को आराम से बंद करने के लिए, उसे [पॉज़ करें](/docs/help/dynamic-codes/pause-schedule-limit) और इसके बजाय एक फ़ॉलबैक URL जोड़ें।
</Callout>

## आर्काइव [#archive]

**Codes** में कोड के मेन्यू से **Archive** चुनें।

- स्कैन करने वालों को "This QR code is no longer active" दिखता है।
- आर्काइव किए गए कोड आपके प्लान की कोड लिमिट में नहीं गिने जाते।
- कोड को फिर से चालू करने के लिए **Unarchive** चुनें। फ़्री प्लान पर इसके लिए एक खाली कोड स्लॉट चाहिए।

## ट्रैश में भेजें [#move-to-the-trash]

कोड के मेन्यू से **Move to trash** चुनें।

- स्कैन करने वालों को "This QR code is no longer active" दिखता है।
- Codes साइडबार में **Trash** खोलें और कोड को वापस लाने के लिए **Restore** चुनें।
- QRdx ट्रैश को अपने आप कभी खाली नहीं करता।

## हमेशा के लिए डिलीट करें [#delete-forever]

**Trash** में **Delete forever** चुनें।

- स्कैन करने वालों को "QR code not found" दिखता है।
- कोड की स्कैन हिस्ट्री डिलीट हो जाती है।
- इसे वापस नहीं किया जा सकता।
