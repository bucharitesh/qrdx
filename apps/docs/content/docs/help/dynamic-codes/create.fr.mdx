---
title: "Créer un QR code dynamique"
description: "Créez un code que vous pouvez modifier après l'impression, depuis le Playground ou depuis votre tableau de bord."
---

Un code dynamique contient un lien court qui redirige vers votre destination. Vous avez besoin d'un compte QRdx gratuit. L'offre Gratuit inclut 10 codes dynamiques ; Pro et Business n'ont aucune limite.

## Depuis le Playground [#from-the-playground]

1. Ouvrez le [Playground](/playground?type=url) et saisissez votre lien dans **Adresse du site web**.
2. Sous l'adresse, repérez la carte **QR code dynamique**.
3. Si vous n'êtes pas connecté, cliquez sur **Connectez-vous pour le rendre dynamique** puis connectez-vous. Votre lien est toujours là à votre retour.
4. Cliquez sur **Rendre dynamique**.

La carte affiche maintenant votre lien court et « Les scans mènent à » votre destination. Téléchargez le code comme d'habitude : il encode désormais le lien court.

Les codes dynamiques créés depuis le Playground fonctionnent pour les liens de sites web. Pour un autre contenu, créez une [page mobile](/docs/help/pages-and-forms/create-a-page), qui obtient aussi un code dynamique.

## Depuis votre tableau de bord [#from-your-dashboard]

1. Allez dans **Codes** dans votre tableau de bord et cliquez sur **Nouveau code**.
2. Sous **Lien**, choisissez **Lien de site web**.
3. Renseignez **URL de destination** et, si vous le souhaitez, un **Titre**.
4. Cliquez sur **Créer le code**.

Vous pouvez ensuite télécharger le code ou cliquer sur **Voir les statistiques** pour l'ouvrir.

## Choisir la fin de votre lien court [#choose-your-own-short-link-ending]

Avec Pro et Business, renseignez **Fin personnalisée** pour choisir la fin du lien court, par exemple `qrdx.dev/q/spring-menu`. Elle peut compter de 3 à 64 lettres, chiffres, tirets ou tirets bas.

Avec Gratuit, QRdx choisit pour vous une courte fin aléatoire.

## Lorsque vous atteignez la limite [#when-you-reach-the-limit]

Avec Gratuit, seuls les codes actifs comptent dans les 10. Les codes archivés et ceux de la corbeille ne comptent pas. Archivez un code que vous n'utilisez plus, ou [passez à Pro](/pricing).
