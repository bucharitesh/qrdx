<Callout type="warn">
  コードをアーカイブ、ゴミ箱に移動、または削除すると、**コードは動作しなくなります**。印刷済みのコードを穏やかに終了したい場合は、代わりに[一時停止](/docs/help/dynamic-codes/pause-schedule-limit)してフォールバックURLを設定してください。
</Callout>

## アーカイブ [#archive]

**Codes**にあるコードのメニューから**アーカイブ**を選択します。

- スキャンした人には「This QR code is no longer active」と表示されます。
- アーカイブしたコードは、プランのコード数の上限には含まれません。
- コードを再び有効にするには、**アーカイブ解除**を選択します。フリーでは、空きのコード枠が必要です。

## ゴミ箱に移動 [#move-to-the-trash]

コードのメニューから**ゴミ箱に移動**を選択します。

- スキャンした人には「This QR code is no longer active」と表示されます。
- Codesのサイドバーで**ゴミ箱**を開き、**復元**を選択すると元に戻せます。
- QRdxがゴミ箱を自動的に空にすることはありません。

## 完全に削除 [#delete-forever]

**ゴミ箱**で**完全に削除**を選択します。

- スキャンした人には「QR code not found」と表示されます。
- コードのスキャン履歴は削除されます。
- この操作は元に戻せません。
