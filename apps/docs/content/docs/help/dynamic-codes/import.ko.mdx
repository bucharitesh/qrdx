## CSV 파일에서 가져오기 [#from-a-csv-file]

1. **Codes**로 이동해 **Import CSV**를 클릭해요.
2. 한 행에 코드 하나씩 담은 CSV 파일을 업로드해요.

필수 열은 대상 주소뿐이에요. 제목, 폴더, 태그, 사용자 지정 back-half도 넣을 수 있어요. 파일은 최대 {facts.importRows}행, 최대 10 MB까지 가능해요. 코드를 만들기 전에 모든 행을 먼저 검사하며, 문제가 있는 행은 건너뛰고 목록으로 보여 드려요.

파일 안의 모든 코드에 적용할 폴더와 태그를 고를 수도 있어요. 자체 폴더가 있는 행은 그 폴더를 그대로 유지하고, 파일에 지정한 태그는 행에 있는 태그에 추가돼요.

큰 파일은 진행 표시줄이 채워지는 동안 나누어 전송돼요. 일시 중지했다가 다시 시작할 수 있어요. 페이지가 새로고침되거나 연결이 끊기면 가져오기가 멈추고 다시 시작하거나 재시도하라고 안내하며, 같은 코드가 두 번 만들어지지 않아요. 완료되면 각 행의 짧은 링크가 담긴 결과 CSV를 내려받거나, 새 코드를 PNG 또는 SVG 파일로 담은 ZIP을 내려받을 수 있어요.

무료에서는 코드를 한 번에 하나씩 가져올 수 있어요. Pro와 Business에서는 여러 개를 한꺼번에 가져올 수 있어요.

## 다른 서비스에서 가져오기 [#from-another-service]

**Codes** 페이지에서 **Import**를 클릭하고 현재 코드가 있는 곳을 선택하세요.

- **Bitly**: Bitly에 로그인한 다음 링크를 선택해요.
- **Rebrandly**와 **Short.io**: 해당 서비스의 API 키를 붙여 넣어요.
- **QR Code Generator PRO, Uniqode, Flowcode, QR TIGER, ME-QR, TinyURL, Hovercode, Scanova** 등: 해당 서비스에서 내보낸 파일을 업로드해요.

## 인쇄된 코드를 계속 사용하기 [#keep-printed-codes-working]

인쇄된 코드는 여전히 이전 서비스를 가리켜요. 마이그레이션 가이드에서 코드를 계속 작동하게 하는 방법과 기존 back-half를 유지하는 방법을 설명해요.

[Bitly, Rebrandly 등에서 옮기기](/docs/migrate)를 참고하세요.
