---
title: "更改已印刷二维码打开的内容"
description: "将网站链接二维码改为托管页面，或把页面改回链接。已印刷的二维码仍可正常使用。"
---

动态二维码可以打开网站链接或托管页面，印刷之后也能在两者之间切换。短链接不会改变，因此每一份已印刷的二维码在下次被扫描时都会打开新的页面或链接，扫描次数也会继续累计在同一个二维码上。

## 将网站链接改为页面 [#turn-a-website-link-into-a-page]

1. 在 **Codes** 中打开该二维码，点击 **Change type**。
2. 选择页面类型，再选择模板。
3. 点击 **Continue to editor**，然后制作页面。
4. 点击 **Publish**。

在你发布之前，扫描仍会跳转到原来的链接。如果离开编辑器时没有发布，则不会有任何变化。尚未发布的修改会保留在当前浏览器中。

## 将页面改回链接 [#turn-a-page-back-into-a-link]

1. 打开该二维码，点击 **Change type**。
2. 选择 **Website link**，输入网址，然后点击 **Switch to website link**。

该页面仍保留在 **Pages** 中。如需恢复，请再次打开 **Change type**，在 **Switch back** 下选择它。

## 切换到另一种页面类型 [#switch-to-another-page-type]

在 **Another page type** 下选择一种类型。新页面以你所选的模板为起点，并从旧页面中带over适用的内容：页面名称、设置和徽标，以及模板同样具备的区块，例如页眉、链接或联系方式。对话框中会列出不适用的内容。这些内容会留在旧页面上，而旧页面会保留在 **Pages** 中。

## 保持不变的内容 [#what-stays-the-same]

短链接、扫描历史、文件夹、标签、备注、二维码设计、密码、计划时间和扫描次数上限都不会改变。

有些设置只对其中一种类型有效：

- 智能路由、A/B 测试、UTM 参数和转化跟踪仅适用于网站链接。
- 跟踪像素仅在托管页面上加载。

切换时这些设置会被保留，切换回来后即可再次生效。二维码的 **Settings** 标签页会列出已保存但当前未使用的设置。

## 套餐 [#plans]

新页面与你创建的其他页面一样，会计入套餐的托管页面数量。二维码不再打开的页面，在你从 **Pages** 中将其删除之前仍会计入。切换回已有的页面不会增加数量。参见[套餐与限额](/docs/plans-and-limits)。

## 撤销切换 [#undo-a-switch]

每次切换都会把该二维码之前的设置保存到 **Version history** 中。恢复到较早的版本即可切换回原来的类型，前提是它当时打开的页面仍然存在。

## 通过 API [#from-the-api]

在 `PATCH /v1/codes/{id}` 请求中发送 `kind`。参见[更新二维码](/docs/developers/api/update-code)。
