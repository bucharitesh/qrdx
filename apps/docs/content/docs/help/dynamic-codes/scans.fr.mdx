---
title: "Consulter vos scans"
description: "Découvrez combien de personnes ont scanné un QR code dynamique, quand, où et avec quel appareil."
---

Chaque scan d'un code dynamique est comptabilisé. Les codes statiques ne sont pas suivis.

## Un seul code [#one-code]

Allez dans **Codes** et cliquez sur le nom du code. Le haut de la page affiche :

- **Total des scans** et **Scans sur la période** (les dates que vous avez choisies).
- **Visiteurs uniques** : chaque visiteur compte une seule fois par jour.
- **Dernier scan**.

En dessous, **Scans QR et NFC** répartit les visites entre le QR code et les [tags NFC](/docs/nfc) qui portent le lien du code. Viennent ensuite des graphiques pour les pays, les villes, les appareils, les systèmes d'exploitation, les navigateurs et les sources de trafic, ainsi que les moments où les gens scannent et la langue utilisée. Avec Pro et Business, les codes qui [demandent la position précise](/docs/precise-location) listent aussi les lieux que les utilisateurs ont choisi de partager.

## Tous vos codes [#all-your-codes]

La page **Analytics** de votre tableau de bord affiche les totaux de tous vos codes, vos meilleurs codes, les pays, les appareils et les langues. **Comparer les codes** place jusqu'à 4 codes côte à côte.

## Périodes et historique [#date-ranges-and-history]

Choisissez 7, 30 ou 90 jours, 1 an ou 3 ans. La durée de consultation dépend de votre offre :

- **Gratuit** : 90 jours.
- **Pro** : 3 ans.
- **Business** : illimitée.

## Télécharger vos scans [#download-your-scans]

Sur la page d'un code, ouvrez l'onglet **Analytics** et cliquez sur **Exporter en CSV**. Vous obtenez jusqu'à 50.000 scans pour les dates sélectionnées, avec l'heure, le lieu, l'appareil, le système d'exploitation, le navigateur et la source de chacun, le type (scan de QR code ou toucher NFC), et la position partagée le cas échéant.

## Ce qui n'est pas comptabilisé [#what-isnt-counted]

Les robots et les aperçus de liens ne sont pas comptabilisés. Si un même réseau scanne le même code plus de 20 fois en une minute, les scans supplémentaires ne sont pas comptés. Le code s'ouvre quand même à chaque fois.

## Confidentialité [#privacy]

QRdx ne stocke jamais l'adresse IP d'une personne qui scanne. Consultez [Ce que QRdx enregistre lorsque quelqu'un scanne](/docs/help/privacy-and-security/scan-data).
