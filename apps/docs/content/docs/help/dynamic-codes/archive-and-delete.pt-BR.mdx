<Callout type="warn">
  Arquivar, mover para a lixeira ou excluir um código **faz com que ele pare de funcionar**. Para aposentar um código impresso com mais cuidado, [pause-o](/docs/help/dynamic-codes/pause-schedule-limit) e adicione uma URL alternativa.
</Callout>

## Arquivar [#archive]

Escolha **Arquivar** no menu do código em **Códigos**.

- Quem fizer a leitura vê "Este QR code não está mais ativo".
- Códigos arquivados não contam para o limite de códigos do seu plano.
- Escolha **Desarquivar** para reativar o código. No plano Grátis, você precisa de um espaço livre para código.

## Mover para a lixeira [#move-to-the-trash]

Escolha **Mover para a lixeira** no menu do código.

- Quem fizer a leitura vê "Este QR code não está mais ativo".
- Abra a **Lixeira** na barra lateral de Códigos e escolha **Restaurar** para recuperá-lo.
- O QRdx nunca esvazia a lixeira por conta própria.

## Excluir de vez [#delete-forever]

Na **Lixeira**, escolha **Excluir permanentemente**.

- Quem fizer a leitura vê "QR code não encontrado".
- O histórico de leituras do código é excluído.
- Essa ação não pode ser desfeita.
