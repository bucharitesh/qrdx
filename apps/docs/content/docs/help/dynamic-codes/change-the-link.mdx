---
title: Change where a code points
description: Edit the destination of a dynamic QR code. Printed copies open the new link on the next scan.
---

You can change the destination of a dynamic code at any time. Every printed copy opens the new link on its next scan.

## From your dashboard

1. Go to **Codes**.
2. Open the code's menu (**⋯**) and choose **Edit link**. You can also open the code and click **Edit link**.
3. Change the **Destination URL**.
4. Click **Save changes**.

QRdx confirms with "Scans now open the updated destination."

## From the playground

If the code is open in the playground, change the address. The card says "Printed codes still open" your old link until you click **Point it to the new address**.

## Changes take effect right away

QRdx doesn't cache redirects. The next scan opens the new destination, on every phone.

## Don't change the short link itself

Changing the destination is always safe. Changing the code's **back-half** or **domain** is not: codes already printed with the old short link stop working.

## Undo a change

1. Open the code from **Codes**.
2. Under **Settings**, open **Version history**.
3. Click **Restore** next to the version you want, then **Restore version**.

QRdx keeps up to 100 versions of each code.

## Open a page instead

To make the code open a hosted page instead of a link, use **Change type** on the code's page. See [Change what a printed code opens](/docs/help/dynamic-codes/change-the-type).

## Static codes can't change

A static code stores the link inside the code. To change it, you need to print a new code. See [Static or dynamic](/docs/help/getting-started/static-vs-dynamic).
