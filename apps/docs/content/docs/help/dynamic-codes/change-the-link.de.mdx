---
title: "Ändern, wohin ein Code verweist"
description: "Bearbeite das Ziel eines dynamischen QR-Codes. Gedruckte Exemplare öffnen beim nächsten Scan den neuen Link."
---

Du kannst das Ziel eines dynamischen QR-Codes jederzeit ändern. Jedes gedruckte Exemplar öffnet beim nächsten Scan den neuen Link.

## Im Dashboard [#from-your-dashboard]

1. Gehe zu **Codes**.
2. Öffne das Menü des Codes (**⋯**) und wähle **Link bearbeiten**. Du kannst auch den Code öffnen und auf **Link bearbeiten** klicken.
3. Ändere die **Ziel-URL**.
4. Klicke auf **Änderungen speichern**.

QRdx bestätigt mit „Scans öffnen jetzt das aktualisierte Ziel."

## Im Playground [#from-the-playground]

Wenn der Code im Playground geöffnet ist, ändere die Adresse. Die Karte zeigt „Gedruckte Codes öffnen weiterhin" deinen alten Link, bis du auf **Auf die neue Adresse umleiten** klickst.

## Änderungen gelten sofort [#changes-take-effect-right-away]

QRdx speichert Weiterleitungen nicht im Cache. Der nächste Scan öffnet das neue Ziel, auf jedem Smartphone.

## Den Kurzlink selbst nicht ändern [#dont-change-the-short-link-itself]

Das Ziel zu ändern ist immer unbedenklich. Den **Back-Half** oder die **Domain** des Codes zu ändern, ist es nicht: Codes, die bereits mit dem alten Kurzlink gedruckt wurden, funktionieren dann nicht mehr.

## Eine Änderung rückgängig machen [#undo-a-change]

1. Öffne den Code unter **Codes**.
2. Öffne unter **Einstellungen** den **Versionsverlauf**.
3. Klicke neben der gewünschten Version auf **Wiederherstellen** und dann auf **Version wiederherstellen**.

QRdx speichert bis zu 100 Versionen pro Code.

## Stattdessen eine Seite öffnen [#open-a-page-instead]

Damit der Code statt eines Links eine gehostete Seite öffnet, nutze **Typ ändern** auf der Seite des Codes. Siehe [Ändern, was ein gedruckter Code öffnet](/docs/help/dynamic-codes/change-the-type).

## Statische Codes lassen sich nicht ändern [#static-codes-cant-change]

Ein statischer QR-Code speichert den Link im Code selbst. Um ihn zu ändern, musst du einen neuen Code drucken. Siehe [Statisch oder dynamisch](/docs/help/getting-started/static-vs-dynamic).
