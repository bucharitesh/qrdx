<Callout type="warn">
  Archiver, mettre à la corbeille ou supprimer un code **l'empêche de fonctionner**. Pour retirer en douceur un code imprimé, [mettez-le plutôt en pause](/docs/help/dynamic-codes/pause-schedule-limit) et ajoutez une URL de secours.
</Callout>

## Archiver [#archive]

Choisissez **Archiver** dans le menu du code, dans **Codes**.

- Les utilisateurs qui scannent le code voient « Ce QR code n'est plus actif ».
- Les codes archivés ne comptent pas dans la limite de codes de votre offre.
- Choisissez **Désarchiver** pour réactiver le code. Avec l'offre Gratuit, vous avez besoin d'un emplacement de code libre.

## Mettre à la corbeille [#move-to-the-trash]

Choisissez **Mettre à la corbeille** dans le menu du code.

- Les utilisateurs qui scannent le code voient « Ce QR code n'est plus actif ».
- Ouvrez **Corbeille** dans la barre latérale Codes et choisissez **Restaurer** pour le récupérer.
- QRdx ne vide jamais la corbeille automatiquement.

## Supprimer définitivement [#delete-forever]

Dans **Corbeille**, choisissez **Supprimer définitivement**.

- Les utilisateurs qui scannent le code voient « QR code introuvable ».
- L'historique des scans du code est supprimé.
- Cette action est irréversible.
