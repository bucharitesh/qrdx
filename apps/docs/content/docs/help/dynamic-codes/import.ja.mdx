## CSVファイルから [#from-a-csv-file]

1. **Codes** に移動し、**Import CSV** をクリックします。
2. 1行に1つのコードを記載したCSVファイルをアップロードします。

必須の列は宛先のみです。タイトル、フォルダ、タグ、カスタムのバックハーフも含められます。ファイルには最大 {facts.importRows} 行まで、サイズは最大10 MBまで含められます。作成の前にすべての行がチェックされ、問題のある行はスキップされて一覧表示されます。

ファイル内のすべてのコードに対して、フォルダとタグを選ぶこともできます。行に独自のフォルダがある場合はそれが優先され、ファイルのタグは選んだタグに追加されます。

大きなファイルは、進行状況バーが進むあいだ、分割して送信されます。一時停止して再開することもできます。ページが再読み込みされたり、接続が切れたりした場合はインポートが停止し、再開または再試行を選べます。コードが二重に作成されることはありません。完了したら、各行の短縮リンクを含む結果CSV、または新しいコードをPNGまたはSVGファイルにまとめたZIPをダウンロードできます。

フリーでは一度にインポートできるコードは1つです。ProとBusinessでは一度に複数をインポートできます。

## ほかのサービスから [#from-another-service]

**Codes** ページで **Import** をクリックし、現在コードがある場所を選びます。

- **Bitly**: Bitlyにサインインし、リンクを選びます。
- **Rebrandly** と **Short.io**: そのサービスのAPIキーを貼り付けます。
- **QR Code Generator PRO、Uniqode、Flowcode、QR TIGER、ME-QR、TinyURL、Hovercode、Scanova** など: そのサービスのエクスポートファイルをアップロードします。

## 印刷済みのコードを使い続ける [#keep-printed-codes-working]

印刷済みのコードは、まだ以前のサービスを指しています。移行ガイドでは、それらを使い続ける方法と、元のバックハーフを維持する方法を説明しています。

[Bitly、Rebrandlyなどからの移行](/docs/migrate)をご覧ください。
