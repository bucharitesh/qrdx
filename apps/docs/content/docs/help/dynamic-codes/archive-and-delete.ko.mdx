<Callout type="warn">
  코드를 보관하거나 휴지통으로 옮기거나 삭제하면 **코드가 작동하지 않습니다**. 인쇄된 코드를 부드럽게 중단하려면 대신 [일시중지](/docs/help/dynamic-codes/pause-schedule-limit)하고 대체 URL을 추가하세요.
</Callout>

## 보관 [#archive]

**Codes**에서 코드의 메뉴를 열고 **Archive**를 선택하세요.

- 스캔하는 사람에게 "This QR code is no longer active"라는 메시지가 표시됩니다.
- 보관된 코드는 플랜의 코드 한도에 포함되지 않습니다.
- 코드를 다시 켜려면 **Unarchive**를 선택하세요. 무료 플랜에서는 사용 가능한 코드 슬롯이 하나 필요합니다.

## 휴지통으로 이동 [#move-to-the-trash]

코드의 메뉴에서 **Move to trash**를 선택하세요.

- 스캔하는 사람에게 "This QR code is no longer active"라는 메시지가 표시됩니다.
- Codes 사이드바에서 **Trash**를 열고 **Restore**를 선택하면 코드를 되돌릴 수 있어요.
- QRdx는 휴지통을 자동으로 비우지 않습니다.

## 완전히 삭제 [#delete-forever]

**Trash**에서 **Delete forever**를 선택하세요.

- 스캔하는 사람에게 "QR code not found"라는 메시지가 표시됩니다.
- 코드의 스캔 기록이 삭제됩니다.
- 이 작업은 되돌릴 수 없습니다.
