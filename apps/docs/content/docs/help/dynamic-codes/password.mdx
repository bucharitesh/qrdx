---
title: Protect a code with a password
description: Ask for a password before a dynamic QR code opens its destination.
---

Pro and Business plans can put a password on a dynamic code.

## Add a password

1. Open the code from **Codes**.
2. Under **Settings**, open **Access & schedule**.
3. Type a **Password** of 4 to 64 characters and save.

## What scanners see

Scanners see "This QR code is password protected", with a **Password** field and a **Continue** button.

After the right password, that browser stays unlocked for 6 hours.

## Share the password separately

Anyone with the password can open the code. Share it the way you'd share any password, not printed next to the code.

## Remove the password

Clear the **Password** field and save. Removing it works on any plan.
