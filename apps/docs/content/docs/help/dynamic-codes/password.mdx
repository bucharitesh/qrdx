---
title: Protect a code with a password
description: Ask for a password before a dynamic QR code opens its destination.
---

A password on a dynamic code makes scanners type it before they reach your destination. Use it for a code that opens something private, like a staff page or an event program.

<Callout type="info">
  Passwords are part of Pro and Business. Removing a password works on any plan. See [Plans and what they include](/docs/help/account-and-billing/plans).
</Callout>

## Add a password

1. Open the code from **Codes** and go to its **Settings** tab.
2. Open **Access & schedule**.
3. Type a **Password** of 4 to 64 characters.
4. Click **Save changes**. The code's status reads "Live and password protected."

{/* shot: password-field-access-schedule | the Password field in the Access & schedule panel, filled, before Save changes | Dashboard, Codes, open a code, Settings, Access & schedule */}

## What scanners see

Scanners see a plain page titled "This QR code is password protected", with a **Password** field and a **Continue** button. After the right password, that browser stays unlocked for 6 hours, so they aren't asked again on every scan.

{/* shot: password-page-scanner | the page a scanner sees: "This QR code is password protected" with the Password field and Continue button | scan a password-protected code */}

## Share the password separately

Anyone with the password can open the code. Share it the way you'd share any password, not printed next to the code.

## Change or remove the password

QRdx never shows the current password. To change it, type a new one in the **Password** field and save. To remove it, click **Remove password** (or clear the field) and save; the panel says "The password will be removed when you save".

## If something goes wrong

### People say the password doesn't work

Check that you clicked **Save changes**, and that you shared the password with the exact characters, including capitals.

### You've forgotten the password

Set a new one. The old password stops working as soon as you save.

### Someone was asked again

The password is remembered for 6 hours in one browser. A different browser or device, or a cleared browser, is asked again.
