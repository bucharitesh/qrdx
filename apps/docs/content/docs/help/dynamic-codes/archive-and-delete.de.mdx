---
title: "QR-Codes archivieren, löschen und wiederherstellen"
description: "Was mit einem gedruckten Code passiert, wenn du ihn archivierst, in den Papierkorb verschiebst oder endgültig löschst."
---

<Callout type="warn">
  Wenn du einen Code archivierst, in den Papierkorb verschiebst oder löschst, **funktioniert er nicht mehr**. Um einen gedruckten Code schonend außer Betrieb zu nehmen, [pausiere ihn](/docs/help/dynamic-codes/pause-schedule-limit) und hinterlege stattdessen eine Fallback-URL.
</Callout>

## Archivieren [#archive]

Wähle im Menü des Codes unter **Codes** die Option **Archivieren**.

- Beim Scannen sehen Nutzer „Dieser QR-Code ist nicht mehr aktiv".
- Archivierte Codes zählen nicht zum Code-Limit deines Plans.
- Wähle **Archivierung aufheben**, um den Code wieder zu aktivieren. Im Plan Kostenlos brauchst du dafür einen freien Code-Platz.

## In den Papierkorb verschieben [#move-to-the-trash]

Wähle im Menü des Codes **In den Papierkorb verschieben**.

- Beim Scannen sehen Nutzer „Dieser QR-Code ist nicht mehr aktiv".
- Öffne in der Seitenleiste von Codes den **Papierkorb** und wähle **Wiederherstellen**, um den Code zurückzuholen.
- QRdx leert den Papierkorb nie automatisch.

## Endgültig löschen [#delete-forever]

Wähle im **Papierkorb** die Option **Endgültig löschen**.

- Beim Scannen sehen Nutzer „QR-Code nicht gefunden".
- Der Scan-Verlauf des Codes wird gelöscht.
- Das lässt sich nicht rückgängig machen.
