이 설정은 모두 한곳에 있어요. **Codes**에서 코드를 열고 **Settings** 아래의 **Access & schedule**을 여세요.

## 코드 일시 중지 [#pause-a-code]

**Pause code**를 켜고 저장하세요. **Codes**에서 코드의 메뉴로 **Pause**를 선택해도 되고, 다시 켜려면 **Resume**을 선택하세요.

일시 중지는 모든 요금제에서 사용할 수 있어요.

## 시작일과 종료일 설정 [#set-start-and-end-dates]

**Starts**, **Ends** 또는 둘 다 입력하세요. 시작 전이나 종료 후의 스캔은 목적지에 도달하지 않습니다.

기간이 정해진 캠페인에 사용하세요. Pro와 Business에서만 사용할 수 있어요.

## 스캔 횟수 제한 [#cap-the-scans]

**Scan limit**을 설정하세요. 설정한 횟수만큼 스캔되면 코드가 종료됩니다. Pro와 Business에서만 사용할 수 있어요.

## 사람들에게 보이는 화면 [#what-people-see]

코드가 활성 상태가 아니면 스캔한 사람에게 QRdx 브랜딩이 없는 간단한 페이지가 표시됩니다.

- 일시 중지됨: "This campaign is paused".
- 시작일 전: "This campaign hasn't started yet".
- 종료일 이후 또는 스캔 제한 도달 후: "This campaign has ended".

## 대신 유용한 곳으로 보내기 [#send-people-somewhere-useful-instead]

**Fallback URL**을 입력하면 일시 중지되었거나 종료된 코드의 스캔을 홈페이지 같은 원하는 페이지로 보낼 수 있습니다. 시작일 전에는 적용되지 않습니다.

## 요금제를 낮춘 후 [#after-a-downgrade]

이미 저장한 설정은 계속 작동합니다. 설정을 제거하는 데는 유료 요금제가 필요하지 않습니다.
