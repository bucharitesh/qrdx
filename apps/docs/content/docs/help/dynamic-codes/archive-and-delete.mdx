---
title: Archive, delete and restore codes
description: What happens to a printed code when you archive it, move it to the trash or delete it forever.
---

When you're done with a dynamic code, you can archive it, move it to the trash or delete it forever. Each one stops the code from working, in a different way.

<Callout type="warn">
  Archiving, trashing or deleting a code stops it from working. To retire a printed code gently, [pause it](/docs/help/dynamic-codes/pause-schedule-limit) and add a fallback URL instead.
</Callout>

## Which to choose

| | Scanners see | Counts toward your limit | Comes back with |
| --- | --- | --- | --- |
| **Pause** | The fallback URL, or "This campaign is paused" | Yes | **Resume** |
| **Archive** | "This QR code is no longer active" | No | **Unarchive** |
| **Move to trash** | "This QR code is no longer active" | No | **Restore** |
| **Delete forever** | "QR code not found" | No | Nothing. It's gone. |

## Archive a code

In **Codes**, open the code's menu (**⋯**) and choose **Archive**. Archived codes don't count toward your plan's code limit. Choose **Unarchive** to turn the code back on. On Free, you need a free code slot.

## Move a code to the trash

Open the code's menu and choose **Move to trash**. To see trashed codes, open **Filter** in the toolbar and set **Status** to **Trash**. There, each code's menu offers **Restore** and **Delete forever**. QRdx never empties the trash on its own.

{/* shot: codes-trash-filter | the Codes list filtered to Trash, with a trashed code's menu showing Restore and Delete forever | Dashboard, Codes, Filter, Status, Trash */}

## Delete a code forever

In the trash, choose **Delete forever** on one code, or **Empty trash** to delete everything in it. The code's scan history and version history are deleted with it, and nothing can bring it back. Scanners see "QR code not found".

## If something goes wrong

### Unarchive or Restore is refused

You're on Free and already have 10 active codes. Archive another code first, or [upgrade](/pricing).

### You deleted a code and want its scans back

They're gone with the code. Before deleting a code you might need, [export its scans](/docs/help/dynamic-codes/scans#download-your-scans).
