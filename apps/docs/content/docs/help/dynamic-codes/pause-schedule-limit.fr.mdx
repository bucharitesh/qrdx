title: "Mettre en pause, planifier ou limiter un code"
description: "Désactivez un QR code dynamique, définissez des dates de début et de fin, plafonnez ses scans et choisissez où rediriger les personnes lorsque le code est terminé."
---

Tout se trouve au même endroit : ouvrez le code depuis **Codes**, puis, sous **Paramètres**, ouvrez **Accès et planification**.

## Mettre un code en pause [#pause-a-code]

Activez **Mettre le code en pause** et enregistrez. Vous pouvez aussi choisir **Mettre en pause** dans le menu du code, dans **Codes**, puis **Reprendre** pour le réactiver.

La mise en pause fonctionne avec tous les forfaits.

## Définir des dates de début et de fin [#set-start-and-end-dates]

Renseignez **Début**, **Fin**, ou les deux. Les scans effectués avant le début ou après la fin n'atteignent pas votre destination.

Utilisez cette option pour une campagne à dates fixes. Réservé aux forfaits Pro et Business.

## Plafonner les scans [#cap-the-scans]

Définissez une **Limite de scans**. Une fois ce nombre de scans atteint, le code prend fin. Réservé aux forfaits Pro et Business.

## Ce que voient les utilisateurs [#what-people-see]

Lorsqu'un code n'est pas actif, les personnes qui le scannent voient une page simple, sans marque QRdx :

- En pause : « Cette campagne est en pause ».
- Avant la date de début : « Cette campagne n'a pas encore commencé ».
- Après la date de fin ou la limite de scans : « Cette campagne est terminée ».

## Rediriger vers une page utile [#send-people-somewhere-useful-instead]

Renseignez **URL de secours** pour envoyer les scans d'un code en pause ou terminé vers une page de votre choix, par exemple votre page d'accueil. Elle ne s'applique pas avant la date de début.

## Après un passage à un forfait inférieur [#after-a-downgrade]

Les paramètres déjà enregistrés continuent de fonctionner. Supprimer un paramètre ne nécessite jamais un forfait payant.
