## 从 CSV 文件导入 [#from-a-csv-file]

1. 前往**二维码**页面,点击**导入 CSV**。
2. 上传 CSV 文件,每行对应一个二维码。

唯一必填的列是目标地址。你还可以包含标题、文件夹、标签和自定义后缀。文件最多可有 {facts.importRows} 行,大小不超过 10 MB。创建任何二维码之前,系统会先检查每一行;有问题的行会被跳过,并在列表中显示。

你还可以为文件中的所有二维码统一选择文件夹和标签。已有自己文件夹的行会保留原文件夹,文件的标签会追加到你所选的标签之中。

大文件会分批发送,同时进度条逐步填满。你可以暂停和继续。如果页面刷新或网络连接中断,导入会停止,并提示你继续或重试,同一个二维码不会被重复创建。导入完成后,你可以下载结果 CSV(包含每一行的短链接),或下载新建二维码的 ZIP 压缩包(PNG 或 SVG 文件)。

在免费版中,一次只能导入一个二维码。Pro 和 Business 可以一次导入多个。

## 从其他服务导入 [#from-another-service]

在**二维码**页面点击**导入**,然后选择你的二维码目前所在的服务。

- **Bitly**:登录 Bitly,然后选择链接。
- **Rebrandly** 和 **Short.io**:粘贴该服务的 API 密钥。
- **QR Code Generator PRO、Uniqode、Flowcode、QR TIGER、ME-QR、TinyURL、Hovercode、Scanova** 等:上传该服务导出的文件。
