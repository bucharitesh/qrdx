title: "パスワードでQRコードを保護する"
description: "動的QRコードがリンク先を開く前に、パスワードの入力を求めます。"
---

ProプランとBusinessプランでは、動的QRコードにパスワードを設定できます。

## パスワードを追加する [#add-a-password]

1. **Codes**からコードを開きます。
2. **Settings**の下にある**Access & schedule**を開きます。
3. 4〜64文字の**Password**を入力して保存します。

## スキャンした人に表示される画面 [#what-scanners-see]

スキャンした人には「This QR code is password protected」と表示され、**Password**欄と**Continue**ボタンが表示されます。

正しいパスワードを入力すると、そのブラウザーは6時間ロック解除された状態になります。

## パスワードは別の手段で共有する [#share-the-password-separately]

パスワードを知っている人は誰でもコードを開けます。パスワードは通常のパスワードと同じように共有し、コードの横に印刷しないでください。

## パスワードを解除する [#remove-the-password]

**Password**欄を空にして保存します。解除はどのプランでも行えます。
