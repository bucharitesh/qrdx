---
title: "Criar um QR code dinâmico"
description: "Crie um código que você pode alterar depois de impresso, pelo Playground ou pelo seu painel."
---

Um código dinâmico guarda um link curto que redireciona para o seu destino. Você precisa de uma conta QRdx grátis. O plano Grátis inclui 10 códigos dinâmicos; Pro e Business não têm limite.

## Pelo Playground [#from-the-playground]

1. Abra o [Playground](/playground?type=url) e digite o seu link em **Endereço do site**.
2. Abaixo do endereço, encontre o card **QR code dinâmico**.
3. Se você não estiver logado, clique em **Entre para tornar dinâmico** e faça login. Seu link continua lá quando você voltar.
4. Clique em **Tornar dinâmico**.

Agora o card mostra o seu link curto e "As leituras vão para" o seu destino. Baixe o código normalmente: agora ele codifica o link curto.

Os códigos dinâmicos criados no Playground funcionam para links de sites. Para outros tipos de conteúdo, crie uma [página mobile](/docs/help/pages-and-forms/create-a-page), que também recebe um código dinâmico.

## Pelo seu painel [#from-your-dashboard]

1. Acesse **Códigos** no seu painel e clique em **Novo código**.
2. Em **Link**, escolha **Link de site**.
3. Preencha **URL de destino** e, se quiser, um **Título**.
4. Clique em **Criar código**.

Depois você pode baixar o código ou clicar em **Ver análises** para abri-lo.

## Escolha o final do seu link curto [#choose-your-own-short-link-ending]

No Pro e no Business, preencha **Final personalizado** para escolher o final do link curto, por exemplo `qrdx.dev/q/spring-menu`. Ele pode ter de 3 a 64 letras, números, hifens ou sublinhados.

No Grátis, o QRdx escolhe para você um final aleatório curto.

## Quando você atingir o limite [#when-you-reach-the-limit]

No Grátis, só os códigos ativos contam para os 10. Códigos arquivados e códigos na lixeira não contam. Arquive um código que você não usa mais ou [faça upgrade para o Pro](/pricing).
