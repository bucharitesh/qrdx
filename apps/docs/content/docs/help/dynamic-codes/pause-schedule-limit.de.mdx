title: "Einen Code pausieren, planen oder begrenzen"
description: "Schalte einen dynamischen QR-Code ab, lege Start- und Enddatum fest, begrenze seine Scans und bestimme, wohin beendete Codes Personen weiterleiten."
---

Alles findest du an einer Stelle: Öffne den Code unter **Codes**, dann unter **Settings** den Bereich **Access & schedule**.

## Einen Code pausieren [#pause-a-code]

Aktiviere **Pause code** und speichere. Du kannst auch im Menü des Codes unter **Codes** die Option **Pause** wählen und mit **Resume** den Code wieder einschalten.

Das Pausieren funktioniert in jedem Tarif.

## Start- und Enddatum festlegen [#set-start-and-end-dates]

Fülle **Starts**, **Ends** oder beides aus. Scans vor dem Start oder nach dem Ende erreichen dein Ziel nicht.

Nutze das für eine Kampagne mit festen Terminen. Nur Pro und Business.

## Scans begrenzen [#cap-the-scans]

Lege ein **Scan limit** fest. Nach dieser Anzahl an Scans endet der Code. Nur Pro und Business.

## Was Personen sehen [#what-people-see]

Wenn ein Code nicht aktiv ist, sehen Scanner eine schlichte Seite ohne QRdx-Branding:

- Pausiert: „This campaign is paused".
- Vor dem Startdatum: „This campaign hasn't started yet".
- Nach dem Enddatum oder dem Scan-Limit: „This campaign has ended".

## Stattdessen auf eine nützliche Seite weiterleiten [#send-people-somewhere-useful-instead]

Trage eine **Fallback URL** ein, um Scans eines pausierten oder beendeten Codes auf eine Seite deiner Wahl zu schicken, zum Beispiel deine Startseite. Vor dem Startdatum gilt sie nicht.

## Nach einem Downgrade [#after-a-downgrade]

Einstellungen, die du bereits gespeichert hast, funktionieren weiter. Eine Einstellung zu entfernen erfordert nie einen kostenpflichtigen Tarif.
