---
title: Bring codes from another service
description: Import links from a CSV file, or move your codes from Bitly, Dub and other QR code services.
---

## From a CSV file

1. Go to **Codes** and click **Import CSV**.
2. Upload a CSV file with one code per row.

The only required column is the destination. You can also include a title, folder, tags and a custom back-half. A file can have up to 1,000 rows and be up to 1 MB.

On Free you can import one code at a time. Pro and Business can import many at once.

## From another service

Click **Import** on the **Codes** page and pick where your codes are now.

- **Dub** and **Bitly**: sign in to that service and pick the links.
- **Rebrandly** and **Short.io**: paste an API key from that service.
- **QR Code Generator PRO, Uniqode, Flowcode, QR TIGER, ME-QR, TinyURL, Hovercode, Scanova** and others: upload the export file from that service.

## Keep printed codes working

Printed codes still point to the old service. The migration guide explains how to keep them working, and how to keep your original back-halves.

See [Move from Bitly, Dub, Rebrandly and others](/docs/migrate).
