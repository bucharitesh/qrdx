---
title: "Mude para onde um código aponta"
description: "Edite o destino de um QR code dinâmico. As cópias impressas abrem o novo link na próxima leitura."
---

Você pode mudar o destino de um código dinâmico a qualquer momento. Todas as cópias impressas abrem o novo link na próxima leitura.

## Pelo painel [#from-your-dashboard]

1. Vá em **Códigos**.
2. Abra o menu do código (**⋯**) e escolha **Editar link**. Você também pode abrir o código e clicar em **Editar link**.
3. Altere a **URL de destino**.
4. Clique em **Salvar alterações**.

O QRdx confirma com "As leituras agora abrem o destino atualizado."

## Pelo Playground [#from-the-playground]

Se o código estiver aberto no Playground, altere o endereço. O cartão avisa que os "Códigos impressos ainda abrem" o link antigo até você clicar em **Apontar para o novo endereço**.

## As mudanças valem na hora [#changes-take-effect-right-away]

O QRdx não faz cache de redirecionamentos. A próxima leitura abre o novo destino, em qualquer celular.

## Não mude o próprio link curto [#dont-change-the-short-link-itself]

Mudar o destino é sempre seguro. Mudar o **final do link** ou o **domínio** do código não é: os códigos já impressos com o link curto antigo deixam de funcionar.

## Desfazer uma mudança [#undo-a-change]

1. Abra o código em **Códigos**.
2. Em **Configurações**, abra o **Histórico de versões**.
3. Clique em **Restaurar** ao lado da versão que você quer e depois em **Restaurar versão**.

O QRdx guarda até 100 versões de cada código.

## Abrir uma página em vez de um link [#open-a-page-instead]

Para fazer o código abrir uma página hospedada em vez de um link, use **Alterar tipo** na página do código. Veja [Mude o que um código impresso abre](/docs/help/dynamic-codes/change-the-type).

## QR codes estáticos não podem ser alterados [#static-codes-cant-change]

Um QR code estático guarda o link dentro do próprio código. Para mudá-lo, você precisa imprimir um novo código. Veja [Estático ou dinâmico](/docs/help/getting-started/static-vs-dynamic).
