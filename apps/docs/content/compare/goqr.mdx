goQR.me is one of the simplest ways to make a QR code: type your content, pick colors, download. It is free for static codes, allows commercial and print use, and offers vector downloads (SVG and EPS) without registration. It also runs a QR code API that returns an image from a URL, which is handy in emails or server templates. QRdx is for when you want the code to look designed, or want to render it inside your own React app.

## Who each tool is for

goQR.me fits anyone who needs a plain, reliable code fast, especially if they want EPS files or an image URL they can drop into an `img` tag. Editable, trackable codes are offered separately through its QR-Server management platform.

QRdx fits designers who want patterns, gradients, logos and frames, people who need editable codes with scan analytics, and developers who want a component or an image API they can style and ship.

## Where goQR.me is the better choice

- You want the plainest possible code with nothing to configure.

## Key differences

- **Design:** goQR.me changes colors; QRdx changes shapes, colors and gradients, and adds logos and frames.
- **Logo:** goQR.me handles custom logo codes on request through a separate page. QRdx lets you upload a logo in the editor.
- **Integration:** goQR.me integrates over HTTP. QRdx has a hosted [image API](/docs/developers/image-api) too (SVG, PNG or EPS), plus a React library with TypeScript types, a CLI and an MCP server.
- **Editable codes:** goQR.me offers them through QR-Server. QRdx has dynamic codes built in: 10 on the Free plan and unlimited on Pro ($5/mo or $48/yr).

## Switching from goQR.me

1. Paste the same content into the [QRdx playground](/playground). Your existing static codes keep working, so nothing needs replacing.
2. Style the code and save the look as a theme.
3. Developers: run `npm install qrdx` and render the `QRCode` component with the same value. The [docs](/docs) cover props for patterns, colors and logos.
4. Test the result on a few phones, especially with a logo or low-contrast colors.
