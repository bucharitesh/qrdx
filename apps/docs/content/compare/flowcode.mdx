Flowcode is a marketing platform built around tracked QR codes. Each Flowcode points to a redirect, often to a Flowcode landing page, and the value is in the analytics, audience data and integrations behind it. QRdx is a design-first QR platform: static codes that work forever with no service in between, plus dynamic codes and hosted pages when you need to edit or track.

## Who each tool is for

Flowcode fits brands running campaigns who want scan data, landing pages and CRM connections in one product. Its self-serve plans are Free (up to 2 Flowcodes, analytics for 500 scans), Pro Plus ($25/mo billed annually, up to 50 Flowcodes and landing pages, analytics for 6,000 scans) and Growth ($250, annual only, starting at 150 Flowcodes with geo-location analytics, CRM integrations and API access). Larger plans are usage-based or custom.

QRdx fits designers, small businesses and developers who want polished codes without a big subscription: static codes need no account, the Free plan includes 10 dynamic codes and 3 hosted pages, and Pro is $5/mo or $48/yr. Developers can use the REST API, the MCP server or the React library.

## Where Flowcode is the better choice

- You need native **CRM or CDP integrations** and audience data. QRdx has hosted pages, scan analytics and tracking pixels, plus webhooks and Zapier-compatible hooks on Business, but no built-in CRM connectors.
- You want a managed platform with sales support for large campaigns.

## Key differences

- **Code model:** Flowcodes are tracked through Flowcode's service. QRdx static codes need no service at all, and QRdx dynamic codes keep redirecting on every plan, even after you cancel ([Never-Hostage Guarantee](/guarantee)).
- **Free tier:** Flowcode's free plan allows 2 codes. QRdx allows unlimited static codes and 10 dynamic codes with the full editor.
- **Developer access:** Flowcode's API starts on Growth. QRdx's REST API is on every plan, alongside an MCP server, an npm package with React components, and a CLI.
- **Openness:** QRdx is open source (AGPL-3.0) and self-hostable.

## Switching from Flowcode

1. Leave printed Flowcodes on an active plan until you reprint them; they redirect through Flowcode.
2. Design new codes in the [QRdx playground](/playground) and save the style as a theme.
3. Use a QRdx dynamic code for anything you may need to change later, or point a static code straight at its destination.
4. Test on several phones before printing.
