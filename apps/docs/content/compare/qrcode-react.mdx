If you need a QR code in a React app, qrcode.react is the default choice, and for good reason. It is tiny, has no runtime dependencies, supports every React version from 16.8 to 19, and is used enormously: about 39.5 million npm downloads in the last 30 days, against 63 for QRdx's `qrdx` package. QRdx actually builds on qrcode.react's encoder, and its source credits it under the ISC license.

## Who each library is for

qrcode.react is for apps that need a correct, plain QR code with minimal weight. It exports `QRCodeSVG` and `QRCodeCanvas`, with props for size, error-correction level, colors, margin, title, minimum version and an embedded image with excavation.

QRdx is for apps where the code is part of the brand: custom body patterns, eye shapes, gradients, frames and built-in downloads, plus a visual playground that exports the matching component code.

## Where qrcode.react is the better choice

- **Licensing.** qrcode.react is ISC, a permissive license that is easy to ship in closed-source products. QRdx is AGPL-3.0, a strong copyleft license; check with your legal team before using it in proprietary software.
- **Bundle size.** qrcode.react has no runtime dependencies. QRdx depends on jsqr and zod for scanning and validation; jspdf is an optional peer dependency, needed only for PDF export.
- **Maturity.** qrcode.react is on version 4 with a very large user base. QRdx is pre-1.0 and its API may still change.
- **Older React.** qrcode.react supports React 16.8 and up.

## Key differences

- **Styling:** qrcode.react supports foreground and background colors and a logo. QRdx adds patterns, eye styles, gradients and templates.
- **Export:** QRdx includes download and data-URI helpers for PNG, JPG, SVG and PDF.
- **Extras:** QRdx includes a contrast checker and QR detection utilities.

## Switching from qrcode.react

1. Install with `npm install qrdx`.
2. Replace `QRCodeSVG` with the `QRCode` component from `qrdx`. The `value`, `size`, `level`, `bgColor` and `fgColor` props carry over.
3. Add `bodyPattern`, `cornerEyePattern` and `cornerEyeDotPattern`, or design the code in the [playground](/playground) and copy the generated component.
4. Read the [docs](/docs) for logos, gradients and download helpers, and confirm the license fits your project.
