QRdx is an open-source QR code platform. You can design a QR code in your browser at [qrdx.dev](/) and download it with no account and no watermark. A free account adds dynamic codes you can change after printing, with scan analytics. Developers can make codes from a URL, a REST API, an MCP server or the `qrdx` React library. The code is all on [GitHub](https://github.com/bucharitesh/qrdx).

## Free, with no account

The [playground](/playground) is the generator. Choose what the code holds, such as a link, Wi-Fi details, a contact card or a UPI payment, then style it with {facts.bodyPatterns} body patterns, {facts.eyeShapes} corner-eye shapes, {facts.eyeCentres} eye centers, {facts.frames} call-to-action frames, colors, gradients and a logo. Logo QR and Image QR blend a logo or a photo into the dots themselves. They're drawn as vectors with no AI involved, so they work in every download format.

Before you download, the scan score checks the design. It renders the code in your browser at 96, 160 and 320 pixels, lowers the contrast and blurs it the way a phone camera would, then decodes it and checks that the text matches what you typed. If a size fails, it tells you what to change, like raising the contrast or using bigger dots.

Downloads come as PNG, JPG, SVG, PDF or EPS. For a print shop, the Print-ready tab sets the code's width in millimeters or inches, RGB or CMYK, a 3 mm bleed and crop marks.

A static code keeps its content inside the code, so it never expires, has no scan limit and never passes through QRdx's servers. There are a few other free tools too: a [bulk generator](/tools/bulk) that turns a CSV into up to 5,000 codes in your browser, a [scanner](/scan), a [scan checker](/tools/scan-checker) for an image you already have, and a [print size calculator](/tools/print-size).

## What an account adds

A dynamic code holds a short link instead, so you can change where it points after printing and see when, where and on which device people scanned it. It can also open a hosted mobile page, like a link list, a menu, a contact card, a coupon, an event or a form.

The Free plan includes 10 dynamic codes, 3 hosted pages and 90 days of analytics history. Pro costs $5 a month. It makes codes and pages unlimited and adds smart routing, A/B tests, passwords, schedules, tracking pixels and teams of up to 3 people<IfAvailable feature="customDomains">, plus 5 custom domains</IfAvailable>. Business costs $15 a month and adds webhooks, conversion tracking, white-label pages and unlimited team members. The [pricing page](/pricing) has the whole list.

Scans are unlimited on every plan. Under the [Never-Hostage Guarantee](/guarantee), every dynamic code keeps redirecting after a downgrade, a failed payment or a cancellation, and going over a limit only stops you from creating more. If QRdx ever shuts down, you get at least 12 months' notice and a documented way to run the open-source app yourself.

The whole web app is open source under the AGPL-3.0, including the editor, accounts, dynamic codes, hosted pages, teams and the docs. You can run it on your own server with Docker Compose or Node.js, against Postgres or a Neon database. The [self-hosting guide](/docs/self-hosting) has the steps. It also says that the Docker setup is new, so if something breaks, please [open an issue](https://github.com/bucharitesh/qrdx/issues). The plan limits are defined in one file, so you can change them for your own instance.

The parts you'd build into your own work are MIT-licensed: the `qrdx` engine and React library, the `@qrdx/cli` command-line tool, and the plugins for Chrome, Figma, Raycast and Canva. The plugins aren't in their stores yet, so for now you [install them from source](/plugins).

The QRdx name and logo aren't covered by those licenses. If you run a modified version for other people, give it your own name. The [trademark policy](https://github.com/bucharitesh/qrdx/blob/main/TRADEMARK.md) explains what's fine.

## For developers

The quickest way to get a QR code from code is the [image API](/docs/developers/image-api). It's a URL that returns an SVG, PNG or EPS, and it needs no key:

```md
![QR code](https://api.qrdx.dev/v1/qr?data=https://qrdx.dev)
```

It draws solid colors only. For logos and gradients, design the code in the playground.

The [MCP server](/docs/developers/mcp) at `https://mcp.qrdx.dev/mcp` lets Claude, ChatGPT, Cursor, VS Code and other MCP apps make styled QR codes in a chat. It also builds the payloads that are easy to get wrong by hand, like Wi-Fi details with a semicolon in the network name. Its tools are read-only, and it needs no account or key. In Claude Code:

```bash
claude mcp add --transport http qrdx https://mcp.qrdx.dev/mcp
```

The [REST API](/docs/developers/rest-api) at `https://api.qrdx.dev/v1` creates and edits dynamic codes, reads scan analytics and reports conversions. It takes an [API key](/docs/developers/api-keys) you create in settings, or an OAuth 2.0 access token when your app acts for other QRdx users. The OpenAPI 3.1 document is at [qrdx.dev/openapi.json](/openapi.json), and a Free account can make 1,000 requests a day. On Business, signed webhooks send scans, code changes and form responses to your own URL.

The `qrdx` package renders and exports styled codes in React, and the [shadcn/ui registry](/docs/developers/shadcn) has ready-made components built on it, such as a scanner and a Wi-Fi code.

## What's not there yet

QRdx doesn't have its own two-step verification, passkeys or single sign-on yet. You sign in with Google, GitHub or a one-time email code. The site is in English only, and the Chrome extension is in the Chrome Web Store, while the Figma, Raycast and Canva plugins install from source until they're listed in their stores.

If you find something that doesn't work, or a code the scan score rates well that your phone won't read, [open an issue](https://github.com/bucharitesh/qrdx/issues).
