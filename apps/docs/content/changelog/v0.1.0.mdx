## Dynamic QR codes

Print a code once and change where it points later. Every [dynamic code](/docs/dynamic-qr-codes) is a short link that counts its scans, with when, where and on which device.

- **Organize** with tags and folders, duplicate a code, restore an earlier version, and bring deleted codes back from the trash.
- **Control** each code: pause it, add a password, set start and end dates, cap the number of scans and choose a fallback URL.
- **Smart routing** sends each scan to a different URL by device, country, language, time or scan count, runs A/B tests and adds UTM parameters. [Learn more](/docs/smart-routing).
- **Your codes keep working.** A downgrade, failed payment or cancellation never stops a code from redirecting. Read the [guarantee](/guarantee).

## Hosted pages and forms

- Build a mobile [landing page](/docs/landing-pages) for a code from blocks, with no website needed: link lists, business pages, contact cards, menus, coupons, events and app downloads.
- Collect answers with [forms](/docs/forms-and-pages) and read them in a response inbox.
- Upload PDFs, images, audio and video for your pages.
- Add tracking pixels and measure conversions on paid plans.

## Custom domains and notifications

- Serve short links from [your own domain](/docs/custom-domains).
- Get [email alerts](/docs/notifications), a weekly digest, and Slack or Discord messages when your codes are scanned or a form gets a response.
- Signed [webhooks](/docs/webhooks) for scans, code changes and form responses, ready for Zapier, Make and n8n.

## Teams and plans

- Invite people to a team workspace with roles, and share codes and themes.
- Three plans: Free, Pro ($5 a month or $48 a year) and Business ($15 a month or $144 a year), with prices in rupees for India. See [pricing](/pricing).

## For developers

- A REST API for dynamic codes, with OAuth scopes.
- The [image API](/docs/developers/image-api) returns a QR code as SVG, PNG or EPS from a URL, with no API key.
- The [MCP server](/mcp) lets Claude, Cursor, VS Code and other AI assistants make QR codes.
- Add QR code components to your app from the [shadcn/ui registry](/docs/developers/shadcn).

## Art and export

- **Logo QR** and **Image QR** blend a logo or photo into the modules of a real, scannable code. They are vector and free. See [Art QR](/docs/features/art-qr).
- **AI art v2**: style presets, QR visibility and creativity controls, seeds, up to four variations per run, a 2x upscale for print and monthly credits of its own.
- **EPS export** for print in the editor, the qrdx library, the CLI, the image API and the MCP server.
- The editor adds padding control, frames, a scan score and print sizes.
