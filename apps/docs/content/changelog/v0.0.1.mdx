Welcome to QRdx! Create, customize, and export beautiful QR codes with professional-grade tools.

## ✨ Key Features

- **Advanced Customization** - Full color control with gradients and 12+ unique patterns
- **Logo Integration** - Add your brand logo with automatic sizing and scannability protection
- **Professional Exports** - Download as SVG, PNG, PDF, or JPEG in high resolution
- **Theme Library** - 20+ pre-designed themes and templates for quick customization
- **Real-time Preview** - See changes instantly as you customize
- **Scannability Validation** - Built-in checker ensures your QR codes work everywhere

## 🎨 Customization Options

```tsx
import { QRCode } from 'qrdx'

export function Example() {
  return (
    <QRCode
      value="https://qrdx.dev"
      fgColor="#667eea"
      bgColor="#ffffff"
      bodyPattern="circle"
      logo="/logo.png"
      size={256}
    />
  )
}
```
