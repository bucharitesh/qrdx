# Getting help with QRdx

## Start with the docs

- [Docs](https://qrdx.dev/docs) cover the playground, dynamic codes and hosted pages, the REST API, the image API, the MCP server, the React library, the CLI and [self-hosting](https://qrdx.dev/docs/self-hosting).
- The [help center](https://qrdx.dev/docs/help) covers accounts, billing, privacy and security on qrdx.dev.
- If you're working with an AI agent, point it at [llms.txt](https://qrdx.dev/llms.txt) or the full docs in [llms-full.txt](https://qrdx.dev/llms-full.txt).

## Where to go

| You want to | Go to |
| --- | --- |
| Ask how to do something, or get help with your setup | [Q&A in Discussions](https://github.com/qrdxinc/qrdx/discussions/new?category=q-a) |
| Report a bug | [Bug report](https://github.com/qrdxinc/qrdx/issues/new?template=bug_report.yml) |
| Get help running your own instance | [Self-hosting problem](https://github.com/qrdxinc/qrdx/issues/new?template=self_hosting.yml) |
| Point out something wrong in the docs | [Docs problem](https://github.com/qrdxinc/qrdx/issues/new?template=docs_problem.yml) |
| Suggest a feature | [Feature request](https://github.com/qrdxinc/qrdx/issues/new?template=feature_request.yml), or [Ideas](https://github.com/qrdxinc/qrdx/discussions/new?category=ideas) to talk it through first |
| Show something you made | [Show and tell](https://github.com/qrdxinc/qrdx/discussions/new?category=show-and-tell) |
| Get help with your qrdx.dev account, billing or a refund | Email [support@qrdx.dev](mailto:support@qrdx.dev) |
| Report a security vulnerability | Privately, as [SECURITY.md](SECURITY.md) describes |
| Report a QR code or page used for phishing or other abuse | The [report form](https://qrdx.dev/report-abuse) |

## Email or GitHub?

Email [support@qrdx.dev](mailto:support@qrdx.dev) about anything tied to your account: sign-in, plans, invoices and refunds. The [contact page](https://qrdx.dev/docs/help/contact) says what to include.

Questions about the code, the APIs or self-hosting go to [Discussions](https://github.com/qrdxinc/qrdx/discussions/categories/q-a), so the answer is public and the next person can find it. Don't post account details, API keys or `.env` values there.
